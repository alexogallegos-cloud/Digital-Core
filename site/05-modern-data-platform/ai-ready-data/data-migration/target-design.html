Modelo target — Medallion (BigQuery)

Bronze · bank_bronze

Réplica raw 1:1 de SAP + CRM (todo STRING + metadata técnica). Espejo fiel auditable; conserva flags de borrado y MANDT.

Silver · bank_silver

Entidades conformadas, tipadas, deduplicadas, FK validadas. DATS→DATE · ALPHA · CURR/TCURX · filter_deleted · country_map · cuarentena.

Gold · bank_gold

Dimensional + Customer 360 mastereado. Entity resolution + merge + surrogate keys + agregados.
