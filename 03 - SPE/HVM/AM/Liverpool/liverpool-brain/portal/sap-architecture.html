Hipótesis de Modernización (Framework 7R)

Replatform — Brownfield S/4HANA

  • Menor riesgo — 213 tablas Z migran como están
  • Deuda técnica persiste · Costo y tiempo mínimos
  • SAP moderniza MM, FI, LE en S/4HANA automáticamente
  • Señal: ZIM_CNST y ZZSTATUS_MI requieren revisión

Repurchase — SAP GTS

  • Global Trade Services — estándar SAP para pedimentos
  • Elimina las 213 tablas Z del módulo ZIM
  • Mayor beneficio · Mayor complejidad de migración
  • Señal clave: cambio 14→16 dígitos SAT (oct-2025) manejado manualmente — GTS lo haría estándar

Refactor — Microservicio

  • Extraer lógica ZIM como servicio independiente
  • Consume API MM-PUR de S/4HANA
  • Mayor flexibilidad · Requiere re-engineering completo
  • Señal: los 33 FMs Z propios son la API interna candidata
