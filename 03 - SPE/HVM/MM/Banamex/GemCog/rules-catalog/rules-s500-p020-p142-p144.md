| **Regulador** | Interno |
| **Programa ejecutor** | P020 |
| **Evidencia código** | Análisis fuente (dt-mainframe-analyst): elevar Traza de código a archivo:línea exacta |
| **Dataset DMSII** | Análisis interno: derivar de Campos COBOL / DASDL |

**Descripción:** Si el hostname del servidor corresponde a Monterrey (WS-DH-HOSTNAME-MTY), P020 activa WS-SOLO-VDM=1, lo que restringe el procesamiento de archivos TEF y la apertura del archivo I03-TEF-VDM exclusivamente a la instancia de Valle de México. La instancia MTY opera en modo consulta-online únicamente.

**Fórmula/pseudocódigo:**
```
IF WS-DH-HOSTNAME-MTY
   MOVE 1 TO WS-SOLO-VDM-VA   ← campo pasa de 0→1; condición 88 (VALUE 0) queda FALSE
(* En VDM: field=0, 88 TRUE → se abre I03-TEF-VDM *)
(* En MTY: field=1, 88 FALSE → TEF no se abre → MTY opera solo en modo consulta-online *)
IF WS-88-SOLO-VDM              ← TRUE = campo es 0 = NO es MTY = abrir TEF
   PERFORM apertura-TEF-y-S151REGISTRA
```

**Vocabulario en la fórmula:** WS-SOLO-VDM · WS-DH-HOSTNAME-MTY · I03-TEF-VDM

| Campo | Descripción |
|-------|-------------|
| `88 WS-88-SOLO-VDM VALUE 0` | Condición 88 TRUE cuando `WS-SOLO-VDM-VA = 0` (estado inicial — sin restricción MTY). FALSE cuando MTY detectado (field=1). El nombre "SOLO-VDM" refiere al efecto — en VDM el campo no se modifica y la condición permanece TRUE. |

**Excepciones:**
- En entornos PBA/SIT/UAT esta restricción no aplica (hostname no es producción MTY).
- **Trampa de condición 88**: `WS-88-SOLO-VDM VALUE 0` es TRUE en el estado inicial (VDM, sin MTY detectado). MTY activa el flag a 1, lo que hace la condición FALSE. El campo field=0 significa "no hay restricción MTY activa" — la condición 88 nombra el efecto (solo VDM procesa TEF) no el trigger.

**Estado validación:** pendiente HITL
