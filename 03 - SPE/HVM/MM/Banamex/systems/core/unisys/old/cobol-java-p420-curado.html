CardBalanceConsolidationService.java@Service · Spring Batch Java 21 
@Service @RequiredArgsConstructor
public class CardBalanceConsolidationService {

  private final SaldosTbReader     reader;
  private final ConsolidatedWriter  writer;
  private final FechaProcesoService fechaService;

  @Transactional
  public ConsolidationResult consolidate() {

    // RN-S500-420-001: fechaProceso = fechaLinea − 1 día
    LocalDate processingDate =
      fechaService.getLineDate().minusDays(1);

    var totals = new ConsolidationTotals();
    for (CsiRegion r : List.of(CSI_04_MTY, CSI_10_VMX)) {
      var records = reader.readSaldosTb(
          processingDate, r, ProductType.CUENTA_MAESTRA);
      processRecords(records, totals, OutputTape.CINTACM);
    }

    // Pattern matching → sealed interface
    // Reemplaza EVALUAR WS-TB-TIPO-REG
    switch (record) {
      case HeaderRecord h  → validateHeader(h, processingDate);
      case DetailRecord d  → processDetail(d, totals);
      case TrailerRecord t → buildSyntheticTrailer(t, totals);
    }

  private void processDetail(
      DetailRecord rec, ConsolidationTotals t) {
    // RN-S500-420-004: 1=MXN, otro=USD
    if (rec.currency() == Currency.MXN) {
      t.addMxn(rec.balanceMxn()); // HALF_EVEN
    } else {
      t.addUsd(rec.balanceUsd());
    }
    t.incrementCustomerCount();

    writer.write(rec);
    // RN-S500-420-005: cuadre ahora configurable
    // batch.validate-trailer=warn (no aborta)
  }
}

ID ReglaDescripciónImplementación Java
RN-S500-420-001La fecha de proceso = fecha de línea − 1 día. La base DMSII ya avanzó al día siguiente antes de que corra P420.fechaService.getLineDate().minusDays(1)
RN-S500-420-002El header de cada archivo se valida contra la fecha de proceso. Discrepancia → log, no aborto.HeaderValidator.validate(h, processingDate)
RN-S500-420-003Path de archivos Cheques usa prefijo S001 (no S500) — hardcode en COBOL. Debe externalizarse.cheques.source-prefix=S001 en config
RN-S500-420-004NUMMON=1 → Moneda Nacional (MXN). Cualquier otro valor → Dólares (USD).Currency.fromCode(rec.numMoneda())
RN-S500-420-005La validación del trailer (conteo + importes) está comentada en COBOL. Discrepancias no abortan el proceso — riesgo operativo latente.batch.validate-trailer=warn|off|strict
