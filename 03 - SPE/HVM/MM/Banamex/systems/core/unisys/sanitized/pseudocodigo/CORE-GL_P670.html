P670 · Impresión de Backups de Movimientos (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P670.cbl (1488 LOC) · Paso de reporte/backup post-cierre diario · BC-18

Convenciones: nombres traducidos (Unisys→legible); [P670 Lnnnn] = línea de fuente (cols 1-6); (BR: RN-CORE-GL-NNN) = regla de negocio del KB.

1. Resumen funcional

P670 (LISMOVSXCONT — Listado de Movimientos por Contrato) lee un archivo plano de movimientos previamente generado por los pasos P106, P108, P109 o P158, y reproduce su contenido en uno o más archivos backup físicos en el sistema de archivos Unisys MCP. El programa opera como un motor de distribución de impresión por secciones: cada registro de entrada es o bien un marcador de inicio de nueva sección de backup (OPCION1=INICI / OPCION2=BACK), o bien una línea a imprimir con control de avance (OPCION2=PAGE o número de líneas). Adicionalmente genera un archivo de auditoría permanente (I01-MOVIMIENTOS) con la traza de la ejecución. P670 recibe del WFL tres parámetros dinámicos (número de sistema, nombre del paso y fecha) y resuelve el pack físico de destino consultando CONSISDIA; si esa consulta falla, el programa termina con STATUS=-1 (terminación anormal). No accede directamente a DMSII — actúa como utilitario de post-proceso sobre archivos planos.

2.6 Interfaz CONSISDIA (WKS-CORE-GLB01SISDIA) — Función 1

Consulta la BD de control CORE-GLB01SISDIA para obtener:

  • WKS-B01-NOMPACMOV (PIC X(17)): pack físico donde residen los archivos de backup.
  • Entrada requerida: WKS-B01-SISTEMA, WKS-B01-FUNCION=1, WKS-B01-CSI.

       ├─ OPEN INPUT ARCHIVOENT

       ├─ PERFORM 02-0150-IMPRIME-BACKUPS UNTIL WS-EOF-MOV = 1
       │    ├─ [IF OPCION1=INICI AND OPCION2=BACK]:
       │    │    ├─ SI W88-BACK-ABIERTO: CLOSE MOVIMIENTOS WITH SAVE (BR: RN-CORE-GL-603)
       │    │    └─ Abrir nuevo backup (CHANGE TITLE, OPEN OUTPUT MOVIMIENTOS)
       │    ├─ [ELSE IF OPCION2=PAGE]:

       │    │    └─ WRITE AFTER WKS-OPCION2-NUM; ADD 1 TO WKS-NUM-LINE
       │    └─ READ ARCHIVOENT (siguiente registro)
       ├─ PERFORM 02-0500-FIN-IMPRESION
       │    └─ CLOSE ARCHIVOENT WITH RELEASE
