CORE-GL · P610 a Java 21 Spring Boot

P610 recibe tres parámetros (función, sistema y un número que puede ser fecha, conteo o estatus) y ejecuta una de nueve funciones sobre la librería de control LIBCTL: registrar el conteo de registros OK, desactivar la base en B03SISMEN, avisar fin de día al motor de registro contable, fijar estatus en B03 o B04, crear el archivo E01 vacío del día, actualizar la fecha del control corporativo y generar el archivo TANDEM para INFOICA. No tiene lógica de negocio propia: traduce parámetros a llamadas. Un código de función desconocido deja la tarea en error.

/** USING W77-FUNCION, W77-SISTEMA, W77-NUMREG: tres parámetros, el tercero de uso genérico. */
public record SolicitudControl(FuncionControl funcion,
                               int sistema,          // 9(03)
                               long numReg) {        // 9(08): fecha AAAAMMDD, conteo o estatus según la función

    /** WKS-FECHA-8D-R: los primeros seis dígitos (AAAAMM) para B03-AAMM. */
    public int anioMes()   { return (int) (numReg / 100); }

    /** WKS-PAR-FEC-6D: los últimos seis dígitos (AAMMDD) para archivos de 6 dígitos y TANDEM. */
    public String fecha6() { return "%06d".formatted(numReg % 1_000_000); }
}

public enum FuncionControl {
    GRABA_TAMANO(1), DESACTIVA_GLOBAL(2), ENVIA_FIN_DE_DIA(3), DESACTIVA_PERIODO(4),
    GRABA_STABDSAL(5), ACTUALIZA_B04(6), CREA_ARCHIVO_E01(7), ACTUALIZA_CONTROL_CORP(8),
    GENERA_ARCHIVO_ICA(9);

    final int codigo;
    FuncionControl(int c) { codigo = c; }

    static Optional<FuncionControl> de(int c) {
        return Arrays.stream(values()).filter(f -> f.codigo == c).findFirst();
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class ControlCicloTasklet implements Tasklet {       // 000300-LLAMA-LIBCTL

    private final Map<FuncionControl, OperacionControl> operaciones;   // un bean por función
    @Value("#{jobParameters['funcion']}") private int funcion;
    @Value("#{jobParameters['sistema']}") private int sistema;
    @Value("#{jobParameters['numReg']}")  private long numReg;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        var f = FuncionControl.de(funcion).orElseThrow(() ->
                new ParametroInvalidoException("PARAMETRO INVALIDO: %02d".formatted(funcion)));  // SET MYSELF(STATUS) TO -1
        operaciones.get(f).ejecuta(new SolicitudControl(f, sistema, numReg));
        return RepeatStatus.FINISHED;
    }
}

@Component(FuncionControl.Nombres.DESACTIVA)
@RequiredArgsConstructor
public class DesactivaOperacion implements OperacionControl {   // 000320-DESACTIVA

    private final SistemaMensualRepository b03;                 // B03SISMEN vía LIBCTL
    private final SistemaDiaRepository b01;                     // B01SISDIA

    @Override
    @Transactional
    public void ejecuta(SolicitudControl s) {
        var reg = b03.findBySistema(s.sistema())                // CONSISMEN F1: el resultado no se revisa en el fuente
                .orElseThrow(() -> new RegistroNoEncontradoException("B03SISMEN", s.sistema()));
        if (s.funcion() == FuncionControl.DESACTIVA_GLOBAL) {
            reg.setStabdsal(99);                                // base desactivada
        } else {
            b01.findBySistema(s.sistema()).ifPresent(dia -> {   // si CONSISDIA falla, se graba sin cambios
                reg.setAnioMes(0, dia.fechaProceso() / 100);    // WKS-B03-AAMM(1)
                reg.setStabdsal(1);
            });
        }
        b03.save(reg);                                          // MANTSISMEN F37
    }
}

@Component(FuncionControl.Nombres.FIN_DE_DIA)
@RequiredArgsConstructor
public class FinDeDiaOperacion implements OperacionControl {    // 000330-ENVIA-98

    private final RegistroContableClientFactory registro;       // CORE-GLL002R{sistema} / CARGAMOV1
    private final P610Properties props;

    @Override
    public void ejecuta(SolicitudControl s) {
        var cliente = registro.para(s.sistema());               // DAME_TIT con fallback "(CORE-GL)CORE-GL/OBJECT/L002/REGISTRA ON CMEMP"
        boolean seisDigitos = props.sistemasFecha6Digitos().contains(s.sistema());
        var aviso = seisDigitos
                ? AvisoMovimiento.seisDigitos(98, s.sistema(), s.fecha6())        // FECMOV = FECCONT = FECVAL
                : AvisoMovimiento.ochoDigitos(98, s.sistema(), s.numReg());
        int resultado = cliente.cargaMovimiento(aviso);
        if (resultado != 0) {
            log.warn("CARGAMOV1 función 98 sistema {} resultado {}", s.sistema(), resultado);  // el fuente lo ignora
        }
    }
}
@Component(FuncionControl.Nombres.STABDSAL)
public class GrabaStabdsalOperacion implements OperacionControl {    // 000340-GRABA-STABDSAL
    private static final Set<Long> PERMITIDOS = Set.of(1L, 3L, 5L, 99L);

    @Override
    public void ejecuta(SolicitudControl s) {
        if (!PERMITIDOS.contains(s.numReg())) {
            log.warn("STABDSAL {} no permitido para sistema {}; se ignora", s.numReg(), s.sistema());
            return;                                             // el fuente no deja rastro
        }
        b03.actualizaStabdsal(s.sistema(), (int) s.numReg());  // CONSISMEN F09
    }
}

@Component(FuncionControl.Nombres.ACTUALIZA_B04)
public class ActualizaB04Operacion implements OperacionControl {     // 000350-ACTB04-SISTEMA
    @Override
    @Transactional
    public void ejecuta(SolicitudControl s) {
        if (s.numReg() <= 1 || s.numReg() >= 5) {               // solo 2, 3 o 4
            log.warn("ESTATUS {} fuera de rango para B04; se ignora", s.numReg());
            return;
        }
        b04.findBySistemaAndProductoAndInstrumento(s.sistema(), 0, 0)    // B04SISTEM F1
           .ifPresent(r -> { r.setEstatus((int) s.numReg()); b04.save(r); });   // MANTB04SISTEM F37
    }
}

Riesgos de migración
Resultados de LIBCTL sin revisar

W77-RESULT-LIBCON se recibe en cada llamada a CONSISMEN, MANTSISMEN, CONSISDIA, B04SISTEM, MANTB04SISTEM y CARGAMOV1, pero ninguna rama lo evalúa (líneas 1536-1629). Un fallo en la base de control termina la tarea con estado normal.

Valores fuera de rango ignorados

Las funciones 5 y 6 descartan sin mensaje los estatus que no están en sus conjuntos permitidos (líneas 1607 y 1616).

Transacción fija en el archivo TANDEM

La función 9 escribe cada día un detalle con importe 1.1, cuenta 9999 9999999 y autorización P09999999 (líneas 1732-1751). Todos los valores están compilados.

Fallbacks de librería con versión fija

Si el catálogo de versiones no responde, LIBCTL se fija en la versión 02MTP009 (línea 1499) y el motor de registro en la librería genérica REGISTRA (línea 1576).

Fecha sin siglo

La función 9 y los sistemas de seis dígitos usan WKS-PAR-FEC-6D, que descarta los dos primeros dígitos del año.

Recreación del archivo E01

La función 7 hace OPEN OUTPUT sin verificar si el archivo ya existe; ejecutarla fuera de orden puede borrar movimientos ya escritos.

Pendiente de revisión SME

  • Confirmar el propósito de la transacción fija del archivo TANDEM (importe 1.1, cuenta 9999 9999999) y si INFOICA la trata como señal o como movimiento.
  • En la función 8 la comparación de cada sistema se hace contra la fecha nueva del header, no contra la anterior; confirmar con SME si el mensaje NO HA SIDO PROCESADO DESDE se interpreta así en operación.
