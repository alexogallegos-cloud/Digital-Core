CORE-GL · P010 a Java 21 Spring Boot

LINEA espera eventos de COMS con ESPERACOMS y, cuando llega un mensaje, lo recibe en un buffer de 1920 bytes cuyo header trae el código de resultado que decide si se procesa, se rechaza o se reenvía a otro nodo CSI. Por cada pantalla (11 a 30 de consulta y 81 a 88 de administración) separa los campos con UNSTRING, valida numéricos con JUSTIFIER de LOCSUP, aplica la validación de entidad y facultad cuando la seguridad está activa, y llama a CORE-GLLIB030 en la librería LIB-CONS del sistema. Registra cada operación en la bitácora de CORE-GLL010 y responde por COMS. No genera asientos contables. Las interrupciones del operador (HI) encienden el monitor, activan o desactivan la seguridad, recargan catálogos y terminan el programa.

/** WKS-MSG: 1920 bytes = header de 36 posiciones + WKS-TEXTO X(1884). */
public record ComsMessage(Header header, String texto) {

    public record Header(char prefijo, char aplDestino,
                         int csiDestino,            // WKS-MSGHDR-CCR-DES 9(02)
                         int lstOrigen,             // 9(04), REDEFINES binario 9(08) COMP
                         Estacion estacion,
                         int csiOrigen,             // WKS-MSGHDR-CCR-ORG 9(02)
                         int copOrigen, String facultad,
                         char aplOrigen,
                         int resultado,             // WKS-MSGHDR-RES 9(02)
                         String mascara,            // X(5): 3 dígitos de sistema + 2 de pantalla
                         String pwr) {
        public ResultadoHeader tipo() { return ResultadoHeader.of(resultado); }
    }

    /** TPO X + sucursal 9(04) + privilegio X + caja 9(02). La sucursal se conserva con ceros. */
    public record Estacion(char tipo, String sucursal, char privilegio, String caja) {}
}

/** Niveles 88 de WKS-MSGHDR-RES. */
public enum ResultadoHeader {
    TERMINAL(1), APLICACION(2, 4), MAESTRO(3), RED(11, 12),
    NO_EXISTE_APLICACION(32), ERROR(31, 33), OTRO;

    private final Set<Integer> valores;
    ResultadoHeader(Integer... v) { this.valores = Set.of(v); }

    static ResultadoHeader of(int r) {
        return Arrays.stream(values()).filter(t -> t.valores.contains(r)).findFirst().orElse(OTRO);
    }
}
@Component
@RequiredArgsConstructor
public class LineaGateway {

    private final PantallaDispatcher pantallas;      // 300000-PROCESA-MSG
    private final CatalogoMensajes mensajes;         // WKS-ELE-MSG(n)

    /** 200000-PROC: una iteración del ciclo por cada mensaje recibido de COMS. */
    @ServiceActivator(inputChannel = "comsEntrada", outputChannel = "comsSalida")
    public ComsRespuesta atiende(ComsMessage msg) {
        return switch (msg.header().tipo()) {
            case APLICACION, RED, MAESTRO, TERMINAL -> pantallas.procesa(msg);
            case NO_EXISTE_APLICACION -> rechazo(msg, 29);
            case ERROR                -> rechazo(msg, 30);
            case OTRO                 -> rechazo(msg, 31);
        };
    }

    private ComsRespuesta rechazo(ComsMessage msg, int codigo) {
        // MOVE 1867 TO W77-LONG-MSG: la respuesta de error ocupa el área de texto completa
        return ComsRespuesta.error(msg.header(), mensajes.texto(codigo), 1867);
    }
}
@Configuration
public class ComsIntegrationConfig {

    /** ESPERACOMS + RECEIVE CS-COMS-IN: el adaptador entrega solo eventos de tipo mensaje. */
    @Bean
    IntegrationFlow entradaComs(ComsInboundAdapter coms, LineaGateway gateway) {
        return IntegrationFlow.from(coms, c -> c.poller(Pollers.fixedDelay(Duration.ZERO)))
                .filter(ComsEvento.class, ComsEvento::esMensaje)      // ACCEPT, TIMEOUT y HI no generan respuesta
                .transform(ComsEvento::mensaje)
                .handle(gateway, "atiende")
                .channel("comsSalida")
                .get();
    }
}

@Service
@RequiredArgsConstructor
public class AutorizacionService {

    private final SeguridadProperties seguridad;
    private final EntidadService entidades;          // 300010-CHECA-ENTIDAD
    private final FacultadClient facultades;         // 420210-CHECA-SEGURIDAD -> VALIDA_FACULTAD

    public Autorizacion autoriza(Peticion p, ComsMessage.Header h) {
        boolean local = h.resultado() != 2;          // un mensaje reenviado (RES = 2) ya se validó en el nodo origen
        Autorizacion a = Autorizacion.noEvaluada();
        if (seguridad.validar() && local) {
            a = entidades.checa(p, h);
        }
        if (seguridad.validar() && local && p.sinError()) {
            a = a.con(facultades.valida(p.claveTransaccion(), h));
        }
        return a;
    }
}

    private final EntidadSucursalRepository entidades;   // WKS-TAB..WKS-TAB4: 5 bloques de 999 x 30

    public Autorizacion checa(Peticion p, ComsMessage.Header h) {
        String sucursalTerminal = h.estacion().sucursal();
        int facultad = entidades.facultad(sucursalTerminal, p.sistema())   // 300012..300016-BUSCA
                                .orElse(0);                                // no encontrado: W77-FACULTAD queda en 0
        return switch (facultad) {
            case 1 -> (p.pantalla() == 17)
                        ? Autorizacion.denegada(87)                      // P17 Totales Nacionales
                        : p.sucursalCaptura().equals(sucursalTerminal)
                            ? Autorizacion.autorizada()
                            : Autorizacion.denegada(87);
            case 2 -> Autorizacion.autorizada();                         // acceso a cualquier sucursal
            case 3 -> Autorizacion.denegada(87);
            default -> Autorizacion.noEvaluada();                        // W77-CVE-RESOL = 0, sin error
        };
    }
}

enum Transaccion { ALTA, BAJA, CAMB, CONS }       // W88-CVE-TRA

@Component
@RequiredArgsConstructor
class ClaveSupervisorValidator {
    private final SupervisoresProperties sup;

    private final CsiValidator csi;                // 420070-VALIDA-NUM-CSI

    /** 310081-PANTALLA-81. Se respeta el orden del COBOL: cada paso puede sobrescribir el código anterior. */
    int valida(String trx, int apuntadorSistema, String csiCapturado, String claveSup) {
        int codigo = 0;
        Optional<Transaccion> t = Transaccion.parse(trx);
        if (t.isEmpty()) codigo = 36;
        if (codigo == 0 && apuntadorSistema == 0) {
            codigo = (t.get() == Transaccion.ALTA) ? 0 : 40;
        }
        codigo = csi.valida(csiCapturado, codigo);
        if (!sup.todas().contains(claveSup)) codigo = 35;                // 420100-VALIDA-CVE-SUP
        boolean actualiza = t.isPresent() && sup.actualizan().contains(claveSup);
        boolean consulta  = t.filter(x -> x == Transaccion.CONS).isPresent()
                            && sup.consultan().contains(claveSup);
        if (!actualiza && !consulta) codigo = 98;
        return codigo;
    }
}

@Component
class EsquemaSistemaValidator {

    /** 400000-VERIFICA-TIPO-ESQUEMA: 0 = se puede llamar a la librería de consulta. */
    int valida(int apuntador, SistemaCatalogo s) {
        if (apuntador <= 0 || apuntador >= 500) return 40;
        return switch (s.estatus()) {                          // WKS-TAB-STASIS desde B04SISTEM
            case 3    -> s.tipoExpgm() == 2 ? 0 : 41;          // 410000-CALL-LIBXSIS
            case 1, 2 -> 40;
            default   -> 26;
        };
    }

@Component
@RequiredArgsConstructor
class FechaConsultaValidator {

    /** 420120-VALIDA-NUM-FEC + 420122-VALIDA-FEC. Devuelve la fecha efectiva y el código. */
    Resultado valida(String fechaCapturada, int pantalla, FechasSistema f) {
        // JUSTIFIER IN LOCSUP función 3: no numérico o cero se reemplaza por FECCON, sin error
        String fecha = Numerico.esValido(fechaCapturada) && !Numerico.esCero(fechaCapturada)
                ? fechaCapturada : f.feccon();
        if (pantalla >= 30) {
            return new Resultado(fecha, 0);                      // pantallas 30 en adelante no validan pertenencia
        }
        if (fecha.equals(f.feccon()) || fecha.equals(f.fecpro())) {
            return new Resultado(fecha, 0);
        }
        List<String> archivadas = f.fechasArchivadas().stream()   // FECPROC(1..10), hasta el primer cero
                .takeWhile(d -> !Numerico.esCero(d)).toList();
        if (archivadas.isEmpty()) {
            return new Resultado(fecha, 0);   // comportamiento actual: sin fechas archivadas no se asigna el 19
        }
        return new Resultado(fecha, archivadas.contains(fecha) ? 0 : 19);
    }

    record Resultado(String fecha, int codigo) {}
}
@Component
@RequiredArgsConstructor
class RuteoCsiService {

    private final RuteoProperties props;   // linea.ruteo.sistemas-sin-sucursal: [1, 66]
                                           // linea.ruteo.sistemas-siempre-locales: [264]
    private final CatalogoSucursales sucursales;   // WKS-NUM-CSI(sucursal)

    /** 420030-VALIDA-NUM-SUC: decide si se atiende aquí o se reenvía a otro CSI. */
    Ruteo decide(Peticion p, ComsMessage.Header h, SistemaCatalogo s, boolean csiYaCambiado) {
        if (csiYaCambiado || p.sucursal() == 0) return Ruteo.local();
        if (props.sistemasSinSucursal().contains(p.sistema())) {
            return h.resultado() == 2 ? Ruteo.regresaAlOrigen(99)      // RES = 3, CCR-DES = CCR-ORG
                                      : Ruteo.error(99);
        }
        if (h.resultado() == 2) return Ruteo.local();                  // ya viene reenviado
        if (s.modoSistema() == 0) {
            if (Pantallas.noRuteables(p.pantalla())) return Ruteo.local(); // 11, 13-16, 19-26
            int csi = sucursales.csiDe(p.sucursal());
            if (csi == 0) return Ruteo.error(45);
            if (props.sistemasSiempreLocales().contains(p.sistema())) return Ruteo.local();
            return csi != h.csiDestino() ? Ruteo.reenvia(csi) : Ruteo.local();   // RES = 2
        }
        int csiRestringido = s.csiRestringido();                       // WKS-TAB-CSIRES (RESCSI de B03)
        return (csiRestringido > 0 && csiRestringido != h.csiDestino())
                ? Ruteo.reenvia(csiRestringido) : Ruteo.local();
    }
}

Riesgos de migración
Claves de supervisor en el fuente

Las claves que autorizan las pantallas de administración 81 a 88 están compiladas como valores de los niveles 88 W88-NUM-SUP, W88-NUM-SUPACT y W88-NUM-SUPCONS (líneas 10305-10313). Cualquier persona con acceso al fuente o al listado de compilación las conoce, y cambiarlas exige recompilar. No se reproducen en esta página a propósito.

Validación de entidad que no niega por omisión

En 300010-CHECA-ENTIDAD, si la combinación sucursal y sistema no está en el catálogo, la facultad queda en 0 y no se asigna el error 87 (líneas 12173-12190). La petición sigue y solo la detiene 420210-CHECA-SEGURIDAD.

Seguridad desactivable en caliente

HI 42 desactiva todas las validaciones de entidad y facultad sin reinicio (líneas 10662-10666). El brain indica que existen controles administrativos, pero el programa no exige ninguna autorización adicional.

Fechas de consulta aceptadas sin validar

En 420120-VALIDA-NUM-FEC una fecha no numérica o en cero se reemplaza por FECCON (líneas 16469-16470), y si no hay fechas archivadas el error 19 nunca se asigna.

Ruteo y librerías por número de sistema compilados

410000-CALL-LIBXSIS tiene una cadena de 25 IF con el número de sistema y el nombre de librería LIB-CONSnnnn fijos (líneas 16049-16186), con los sistemas 43 y 501 comentados. Los sistemas 1, 66 y 264, la sucursal 859 de la pantalla 24 y el CSI 32 tienen tratamiento especial en código.

Contenido del mensaje en el log

Ante un error de RECEIVE el programa escribe en el log LJ el header completo y WKS-TEXTO (líneas 17160-17167), que puede incluir números de cuenta capturados por el usuario.
