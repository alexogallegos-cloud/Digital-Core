P620 · Modificador de Archivo de Directorios (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P620.cbl (210 LOC) · utilitario batch de administración de directorios MCP · BC-14

Convenciones: nombres traducidos (Unisys→legible); [P620 Lnnnn] = línea fuente; (BR: RN-CORE-GL-NNN) = regla de negocio.

1. Resumen funcional

P620 es el gestor de altas y bajas del archivo de directorios del sistema CORE-GL (CORE-GL/FILE/I10/DEPURAR/DIRECTORIOS/007). Recibe cinco parámetros externos vía PROCEDURE DIVISION USING: opción de operación (A=alta / B=baja), ruta de directorio, nombre de pack Unisys, código CSI y días de retención. Su núcleo de persistencia es atómico: lee el archivo original, construye un archivo temporal con la modificación aplicada, y si no hubo errores reemplaza el original por el temporal usando semántica MCP (PURGE sobre el original, CHANGE ATTRIBUTE TITLE sobre el temporal). Integra la librería de control de versiones CTLVERS para resolver dinámicamente el título real del directorio, y la librería SOPORTECOMS para obtener el identificador del CSI en ejecución. Es un utilitario de infraestructura invocado por JCL del ciclo nocturno de CORE-GL; no accede a ningún dataset DMSII.

2.2 Formato del registro de directorio

Registro de texto punto-delimitado, 80 bytes:

USER(4) . DIR(30) . PACK(17) . CSI(2) . DIA(2)

Ejemplo: CORE-GL.CORE-GL/FILE/I10/DEPURAR.CMEMP.01.4 (BR: RN-CORE-GL-576)

3. Mapa de control (jerarquía PERFORM)

0000-INICIA                         [P620 L94]   ← punto de entrada
├── PERFORM 0100-LIBRERIAS          [P620 L101]
│   ├── CHANGE ATTRIBUTE CTLVER → CTLVERS
│   ├── CALL DAME_TIT ("CORE-GLDIR") → WKS-TIT-LIB
│   │   └── SI resultado = 0: asignar título real a A01-DIR-INPUT y WKS-TIT-CORE-GLDIR
│   ├── CHANGE ATTRIBUTE SOPORTECOMS
│   ├── CHANGE ATTRIBUTE LIB-DISP → título hardcodeado
│   └── CALL CSIID → WKS-SOPCOMS / CANCEL SOPORTECOMS
├── MOVE "CORE-GL" → WKS-PARAM-USER   [P620 L102]  ⚠ [HARDCODE-SOSPECHOSO]
├── SI WKS-OPCION = "A" OR "B"     [P620 L103]  (BR: RN-CORE-GL-571)
│   └── INSPECT WKS-PARAM-DIR → contar "/" → W77-SLASH  [P620 L104]
│       └── SI W77-SLASH > 1       [P620 L105]  (BR: RN-CORE-GL-572, RN-CORE-GL-578)
│           └── PERFORM 0200-PROCESO
│               ├── OPEN INPUT A01-DIR-INPUT
│               ├── READ A01-DIR-INPUT (primer registro)
│               ├── OPEN OUTPUT A01-DIR2-INPUT
│               ├── PERFORM 0210-CREA-ARCH UNTIL W77-FIN = 1
│               │   ├── SI registro = SPACES → saltar
│               │   ├── UNSTRING A01-REG-DIR → WKS-USER, WKS-DIR, WKS-PACK, WKS-CSI
│               │   ├── SI OPCION="B" AND DIR+PACK+CSI coincide → omitir (BR: RN-CORE-GL-575)
│               │   ├── SINO SI DIR+PACK+CSI coincide → WKS-DUPLI=1 (BR: RN-CORE-GL-574)
│               │   ├── SINO → WRITE A01-REG2-DIR (copia registro)
│               │   └── READ A01-DIR-INPUT (siguiente)
│               ├── CLOSE A01-DIR2-INPUT WITH SAVE
│               └── SI OPCION="A"
│                   ├── SI WKS-DUPLI=1 → log error "EL REGISTRO YA EXISTE" / W77-ERROR=1
│                   └── SINO → PERFORM 0220-PROCESA-ALTA
│                       ├── SI PARAM-DIA > 4 → MOVER 4 (BR: RN-CORE-GL-573)
│                       ├── OPEN EXTEND A01-DIR2-INPUT
│                       ├── STRING USER.DIR.PACK.CSI.DIA → A01-REG2-DIR (BR: RN-CORE-GL-576)
│                       ├── WRITE A01-REG2-DIR
│                       └── CLOSE A01-DIR2-INPUT WITH SAVE
│           └── SI W77-ERROR=0:    [P620 L107]  (BR: RN-CORE-GL-577, RN-CORE-GL-580)
│               ├── CLOSE A01-DIR-INPUT WITH PURGE
│               ├── OPEN INPUT A01-DIR2-INPUT
│               ├── CHANGE ATTRIBUTE TITLE OF A01-DIR2-INPUT TO WKS-TIT-CORE-GLDIR
│               └── CLOSE A01-DIR2-INPUT WITH SAVE
│           └── SINO → siguiente sentencia (original intacto, TEMP huérfano)
│   └── SINO (W77-SLASH <= 1):
│       └── log "EL NIVEL DEL DIRECTORIO DEBE DE SER > 2"
└── SINO (OPCION inválida):
    └── log "LA ACCION DEBE DE SER ALTA (A) O BAJA (B)"
STOP RUN                            [P620 L125]

4.2 · Inicializar_Librerías

PROCEDIMIENTO Inicializar_Librerías():            // 0100-LIBRERIAS · [P620 L127]
```
PROCEDIMIENTO Inicializar_Librerías():            // 0100-LIBRERIAS · [P620 L127]

  // — Resolver título real del directorio via CTLVERS —
  CAMBIAR ATRIBUTO LIBACCESS    DE "CTLVER" A BYFUNCTION   // [P620 L129]
  CAMBIAR ATRIBUTO FUNCTIONNAME DE "CTLVER" A "CTLVERS"    // [P620 L130]
  // (mecanismo Unisys MCP: enlaza dinámicamente la función CTLVERS a la referencia CTLVER)

  MOVER "CORE-GLDIR"             A id_librería               // WKS-ID-LIB [P620 L132]
  LLAMAR "DAME_TIT IN CTLVER" CON id_librería,
                                    título_librería        // WKS-TIT-LIB
                               DANDO resultado_dame_tit   // W77-RESULT [P620 L133-L135]

  SI resultado_dame_tit = 0 ENTONCES
    // — Asignar título real a ambas referencias —
    CAMBIAR ATRIBUTO TÍTULO DE directorio_original
      A título_librería                                    // A01-DIR-INPUT ← WKS-TIT-LIB [P620 L137]
    MOVER título_librería A título_directorio_core-gldir      // WKS-TIT-CORE-GLDIR [P620 L138]
    // (WKS-TIT-CORE-GLDIR se usa al final para renombrar el TEMP al título real)
  FIN-SI
  // Si resultado != 0: A01-DIR-INPUT conserva el título MCP por defecto del FD

  // — Configurar SOPORTECOMS para obtener datos del CSI —
  CAMBIAR ATRIBUTO LIBACCESS    DE "SOPORTECOMS" A BYFUNCTION  // [P620 L140]
  CAMBIAR ATRIBUTO FUNCTIONNAME DE "SOPORTECOMS" A "SOPORTECOMS"  // [P620 L141-L142]

  // — Fijar librería de mensajes al operador (hardcodeada) —
  CAMBIAR ATRIBUTO TÍTULO DE "LIB-DISP"
    A "(S000)S000/UTILITY/DESPLIEGA/OBJ/LIB ON PACK."    // [P620 L143-L144]
    // ⚠ [HARDCODE-SOSPECHOSO]: ruta física de LIB-DISP hardcodeada sin resolver por CTLVERS

  // — Obtener identificador del CSI en ejecución —
  LLAMAR "CSIID IN SOPORTECOMS" CON datos_soportecoms    // WKS-SOPCOMS [P620 L146]
  // Llena: WKS-NUMCSI, WKS-NOMEQUIPO, WKS-NOMCSI, WKS-LINEA-BATCH
  CANCELAR "SOPORTECOMS"                                  // [P620 L147] — libera memoria MCP
```

4.3 · Proceso_Principal

PROCEDIMIENTO Proceso_Principal():            // 0200-PROCESO · [P620 L149]
```
PROCEDIMIENTO Proceso_Principal():            // 0200-PROCESO · [P620 L149]

  // — Fase 1: Abrir original y crear temporal filtrado —
  ABRIR ENTRADA directorio_original           // OPEN INPUT A01-DIR-INPUT [P620 L151]
  MOVER CERO   A indicador_fin               // W77-FIN = 0 [P620 L152]
  LEER directorio_original
    AL FINAL MOVER 1 A indicador_fin         // W77-FIN = 1 si archivo vacío [P620 L153]

  ABRIR SALIDA directorio_temporal           // OPEN OUTPUT A01-DIR2-INPUT [P620 L155]

  // — Copiar todos los registros aplicando la transformación (alta u baja) —
  MIENTRAS indicador_fin ≠ 1 HACER
    EJECUTAR Copiar_Registro_Con_Filtro       // PERFORM 0210-CREA-ARCH
  FIN-MIENTRAS
  « [P620 L156] · BR: RN-CORE-GL-575, RN-CORE-GL-574 »

  CERRAR directorio_temporal CON SAVE        // [P620 L157] — temporal persiste
  « BR: RN-CORE-GL-580 »

  // — Fase 2: Si es ALTA, verificar duplicado y proceder —
  SI opcion = "A" ENTONCES                   // WKS-OPCION [P620 L159]

    SI indicador_duplicado = 1 ENTONCES      // WKS-DUPLI [P620 L160]
    « BR: RN-CORE-GL-574 »
      MOVER "EL REGISTRO YA EXISTE" A texto_mensaje  // TEXTO-LJ [P620 L161]
      LLAMAR "LJ IN LIB-DISP" CON contador_lj, mensaje_lj  // [P620 L162]
      MOVER 1 A código_error                 // W77-ERROR = 1 [P620 L163]
      // ⚠ [DESCARTE-SILENCIOSO]: la alta no se realiza; el TEMP sin el nuevo registro
      // queda en disco como huérfano si W77-ERROR=1

    SINO  // No hay duplicado: insertar el nuevo registro
      EJECUTAR Procesar_Alta                 // PERFORM 0220-PROCESA-ALTA [P620 L165]
      « BR: RN-CORE-GL-573, RN-CORE-GL-576, RN-CORE-GL-579 »
    FIN-SI

  FIN-SI
  // Nota: si OPCION="B", no hay acción adicional tras la copia filtrada
  // (la baja ya se materializó al omitir el registro coincidente en 0210-CREA-ARCH)
```

4.4 · Copiar_Registro_Con_Filtro

PROCEDIMIENTO Copiar_Registro_Con_Filtro():            // 0210-CREA-ARCH · [P620 L167]
```
PROCEDIMIENTO Copiar_Registro_Con_Filtro():            // 0210-CREA-ARCH · [P620 L167]
// Ejecutado en bucle: procesa un registro por iteración.
// Aplica la lógica de alta/baja: para BAJA omite el registro coincidente;
// para ALTA detecta duplicados y copia los demás.

  SI registro_directorio = SPACES ENTONCES   // A01-REG-DIR [P620 L169]
    SIGUIENTE SENTENCIA                       // omite registros en blanco [P620 L170]
    // ⚠ [DESCARTE-SILENCIOSO]: registros vacíos no se copian al temporal

  SINO
    // — Desempaquetar el registro punto-delimitado —
    DESEMPAQUETAR registro_directorio         // A01-REG-DIR [P620 L172]
      DELIMITADO POR punto                   // WKS-PUNTO = "."
      EN: usuario_lectura,                   // WKS-USER  [P620 L172]
          dir_lectura,                        // WKS-DIR   [P620 L173]
          pack_lectura,                       // WKS-PACK  [P620 L174]
          csi_lectura                         // WKS-CSI   [P620 L175]
    // Nota: el campo DIA no se extrae; solo se usa USER/DIR/PACK/CSI para comparación
    « [P620 L172-L175] · BR: RN-CORE-GL-576 »

    // — Decisión: BAJA con coincidencia triple → omitir registro —
    SI dir_lectura  = dir_param   Y          // WKS-DIR  = WKS-PARAM-DIR  [P620 L176]
       pack_lectura = pack_param  Y          // WKS-PACK = WKS-PARAM-PACK [P620 L177]
       csi_lectura  = csi_param   Y          // WKS-CSI  = WKS-PARAM-CSI  [P620 L178]
       opcion       = "B" ENTONCES           // WKS-OPCION = "B"          [P620 L179]
      SIGUIENTE SENTENCIA                    // omite: efecto de baja [P620 L180]
      // La omisión del WRITE equivale a la eliminación lógica del registro
      « BR: RN-CORE-GL-575 »

    SINO
      // — Decisión: ALTA o BAJA sin coincidencia → verificar duplicado —
      SI dir_lectura  = dir_param   Y        // [P620 L182]
         pack_lectura = pack_param  Y        // [P620 L183]
         csi_lectura  = csi_param   ENTONCES // [P620 L184]
        MOVER 1 A indicador_duplicado        // WKS-DUPLI = 1 [P620 L185]
        // Registro existe: si la operación es ALTA, se rechazará en 0200-PROCESO
        « BR: RN-CORE-GL-574 »
        // Nota: incluso en ALTA con duplicado, el registro existente SÍ se copia al TEMP

      SINO
        // — Registro no coincide: copiar al temporal —
        MOVER  registro_directorio                           // A01-REG-DIR
          A    registro_temporal                            // A01-REG2-DIR [P620 L187]
        ESCRIBIR registro_temporal                          // WRITE A01-REG2-DIR [P620 L188]
      FIN-SI
    FIN-SI
  FIN-SI

  // — Leer siguiente registro del original —
  LEER directorio_original
    AL FINAL MOVER 1 A indicador_fin         // W77-FIN = 1 [P620 L190]
```
