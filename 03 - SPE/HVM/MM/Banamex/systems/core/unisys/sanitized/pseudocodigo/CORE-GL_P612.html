P612 · Dispatcher de WFLs para LINEA online (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P612.cbl (87 LOC) · Lanzador de jobs WFL del batch online · BC-18

Convenciones: nombres traducidos (Unisys→legible); [P612 Lnnnn] = origen en fuente; (BR: RN-CORE-GL-###) = regla de negocio.

1. Resumen funcional

P612 es el dispatcher de WFLs del ciclo online LINEA de CORE-GL (General Ledger de LegacyCore). Recibe un código de operación de 5 caracteres (WKS-PARAMETRO) desde el hub online P010 y busca secuencialmente en los archivos de control CORE-GL/FILE/EJECUCIONWFL/NN. (NN = 01 a 99) el primer registro con ese código y estado pendiente (STATUS=0). Al encontrarlo lanza el Work Flow Language (WFL) correspondiente en el pack CMEMP, marca el registro como ejecutado (STATUS=1) y termina. Es el programa más simple del sistema CORE-GL: 87 LOC, sin dependencias de librerías externas, sin lógica de negocio. Su equivalente moderno es una llamada de 3-5 líneas a un orquestador de jobs.

4.1 · Control_Principal

PROCEDIMIENTO Control_Principal():            // 00-0000-CONTROL · [P612 L4700]
```
PROCEDIMIENTO Control_Principal():
    // Punto de entrada; WKS-PARAMETRO ya fue inicializado por USING
    // WKS-NFILE inicia en 00 (VALUE ZERO implícito de FD)

    MIENTRAS WKS-NFILE < 99:
        EJECUTAR Buscar_Siguiente_Archivo()      // 00-0050-BUSCA-FILE
    // Condición de salida: WKS-NFILE alcanzó 99 O EXIT PERFORM desde el sub-párrafo

    RETORNAR   // STOP RUN
```

```
PROCEDIMIENTO Buscar_Siguiente_Archivo():

    contador_archivo  // WKS-NFILE (9(02)) += 1         « [P612 L5500] »

    // Construir título dinámico del archivo actual
    // WKS-TIT-ARC = "CORE-GL/FILE/EJECUCIONWFL/" + ZZ(contador_archivo) + "."
    CAMBIAR ATRIBUTO TÍTULO de archivo_wfls  // A04-WFLS
        POR titulo_arc  // WKS-TIT-ARC                   « [P612 L5600-L5700] »
    // Patrón Unisys: CHANGE ATTRIBUTE TITLE OF A04-WFLS TO WKS-TIT-ARC

    // Verificar si el archivo existe en el sistema de archivos MCP
    SI atributo_residente_de_archivo_wfls = 0:            « [P612 L5800] »
        // ATTRIBUTE RESIDENT = 0 → el archivo no existe
        // La lista de archivos es sparse: el primer hueco detiene el scan
        // ⚠ [DESCARTE-SILENCIOSO]: archivos con número mayor al hueco no se escanean
        EXIT PERFORM   // terminar el loop externo de búsqueda
    SINO:
        // El archivo existe → abrirlo en modo lectura-escritura simultánea
        ABRIR I-O archivo_wfls  // A04-WFLS               « [P612 L6100] »
        // Apertura I-O necesaria para WRITE posterior de STATUS=1
        // (BR: RN-CORE-GL-473)

    // Reiniciar indicador de fin de archivo para este ciclo
    MOVER 0 A indicador_fin  // W77-EOF = ZERO            « [P612 L6200] »

    // Leer el primer registro del archivo
    LEER archivo_wfls                                     « [P612 L6300] »
        AL FIN: MOVER 1 A indicador_fin  // W77-EOF = 1 (archivo vacío)

    // Procesar registros hasta encontrar coincidencia o agotar el archivo
    MIENTRAS indicador_fin ≠ 1:                           « [P612 L6400] »
        EJECUTAR Leer_Y_Despachar_Registro()  // 00-0100-LEEARCHIVO

    // Cerrar y persistir el archivo (WITH SAVE retiene en MCP)
    CERRAR archivo_wfls CON SAVE                          « [P612 L6500] »
```

```
                // Cadena: "START (CORE-GL)<nombre-34chars> ON CMEMP"

                // WRITE R01-REG-WFL                        « [P612 L7500] »
```
