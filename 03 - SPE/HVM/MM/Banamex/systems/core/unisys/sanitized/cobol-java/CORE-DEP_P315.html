Con la fecha de proceso (fecha línea de B02 menos un día) y los parámetros de B00, P315 recorre CORE-DEPB04MOVIMIENTO y escribe en GERENCIA los movimientos desde el día primero del mes. Después recorre CORE-DEPB03CONTRATOS: los contratos de ahorro (producto 500, instrumento 6) no cancelados van a GERENCIA con su saldo promedio de B06 y al listado de capitalización; los que tienen indicador de cancelación automática van al listado de cancelados. Todo contrato vigente con estatus de beneficencia 3, 6, 7 u 8 se escribe en FILE-ART61 con una leyenda de situación y, cuando cumple fecha y monto, con la fecha de traspaso a beneficencia: el primer viernes hábil del año siguiente. P315 no calcula intereses; lista el interés capitalizado que ya trae B03.

public enum DestinoContrato { GERENCIA_Y_CAPITALIZACION, CANCELADO_SIN_MOV, CANCELADO_Y_SALDO_CERO, ART61 }

@Component
@RequiredArgsConstructor
class SelectorContratos implements ItemProcessor<Contrato, ContratoClasificado> {

    private final P315Properties props;   // producto-ahorro: 500, instrumento-ahorro: 6

    @Override
    public ContratoClasificado process(Contrato c) {
        var destinos = EnumSet.noneOf(DestinoContrato.class);

        if (c.producto() == props.productoAhorro() && c.instrumento() == props.instrumentoAhorro()) {
            if (c.status() != 2) {                                     // 2 = cancelado
                destinos.add(DestinoContrato.GERENCIA_Y_CAPITALIZACION); // INV-INDCAN 0, CANCELO 0
            }
        } else if (c.staCancel() > 0 && !c.migradoS111()) {
            if (Set.of(0, 1, 5).contains(c.status())) {
                destinos.add(DestinoContrato.CANCELADO_SIN_MOV);           // INV-CANCELO-S = 1
            } else if (c.status() == 4 && c.saldoActual().signum() == 0) {
                destinos.add(DestinoContrato.CANCELADO_Y_SALDO_CERO);      // INV-CANCELO-S = 2
            }
        }
        // Independiente de lo anterior: contratos vigentes en beneficencia.
        if (Set.of(0, 1, 5).contains(c.status()) && Set.of(3, 6, 7, 8).contains(c.staBenef())) {
            destinos.add(DestinoContrato.ART61);
        }
        return destinos.isEmpty() ? null : new ContratoClasificado(c, destinos);
    }
}

    SituacionArt61 situacion(Contrato c, LocalDate fechaProceso) {
        return switch (c.staBenef()) {
            case 7 -> SituacionArt61.SALIDA_POR_BLOQUEO;
            case 6 -> SituacionArt61.SALIDA_POR_REACTIVACION;
            case 8 -> SituacionArt61.ENTRADA_POR_DESBLOQUEO;
            default -> YearMonth.from(c.fechaBenef()).equals(YearMonth.from(fechaProceso))
                    ? SituacionArt61.ENTRADA     // entró en el mes de proceso
                    : SituacionArt61.DENTRO;     // ya estaba en Artículo 61
        };
    }

    }

Si B00-IMP-300SMDF viene en cero se usa 20 187.00 compilado (línea 953), y el comentario de la línea 949 menciona una base de 67.20 que no corresponde a ese importe. La regla de monto del Artículo 61 queda atada a un valor que nadie mantiene.

Pérdida de signo en el saldo regulatorio

W77-SDO-TOT S9(13)V99 se mueve a WS-ART-SDO 9(12)V99 (línea 1480). Un saldo total negativo se reporta como positivo en el archivo de Artículo 61.

Trailer de GERENCIA mezclado

WS-TOT-SDOACT acumula importes de movimientos (línea 1264) y saldos de contratos (línea 1429); el trailer no sirve como cifra de control de una sola magnitud.

Error de puntuación en el listado de cancelados

El punto de la línea 1943 deja ADD 4 TO WS-LINEA1 fuera del IF y el contador de líneas crece en cada detalle.

Hardcodes de producto y estatus

Producto 500, instrumento 6, estatus 0, 1, 2, 4 y 5 de contrato y estatus 3, 6, 7 y 8 de beneficencia están compilados en 52111000-SEL. Se trasladan a application.yml o a un catálogo.

Pendiente de revisión SME
  • Confirmar si B00-IMP-300SMDF se mantiene con la unidad de referencia vigente para el Artículo 61 de la LIC; el fuente y sus comentarios hablan de salario mínimo del Distrito Federal.
  • Confirmar si LOCSUP función 8 con 0090 suma días naturales o hábiles a la fecha Art. 61.
  • Validar con el área regulatoria si la condición de mismo año (línea 1519) es intencional.
  • El nombre del componente habla de capitalización mensual, pero P315 no calcula intereses: lista B03-INTS-CAPIT tal como viene. Confirmar qué paso capitaliza.
  • El acceso a B06 se hace con 90000006-B06SXCTO-LOCK sobre una base abierta con OPEN INQUIRY (línea 894); el copybook CORE-DEP/INC/PRO/25MTP002 que contiene ese párrafo no viene en el fuente para confirmar si en realidad es un FIND.
