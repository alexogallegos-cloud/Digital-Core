CORE-DEPProgramaCOBOL

Fuente: P280.cbl (1651 LOC · 66 párrafos propios + 7 COPY-PRO) · Rol: servidor COMS terciario + consolidador de errores batch · MTP: 25MTP004

Convenciones: nombres traducidos (Unisys→legible); [P280 Lnnnnnn] = número de secuencia COBOL de la línea fuente (cols 1-6); (BR: RN-CORE-DEP-xxx) = regla de negocio.

1. Resumen funcional

P280 (PROGRAM-ID: LINCOMS) es la tercera instancia del servidor de comunicaciones (COMS) del sistema CORE-DEP — captación bancaria LegacyCore. Tiene una doble misión secuencial: primero, ciclo de validación B52: itera sobre el dataset DMSII B52SXCSIFECH comparando datos del cliente obtenidos de S016 (CSI alternativo, tipo-persona, ubicación geográfica) contra los almacenados, y actualiza cuando hay discrepancia dentro de una transacción DMSII; segundo, consolidación de reporte de errores: al cierre del ciclo recoge los archivos de error generados por el módulo L050 asíncrono y por el propio P280, los ordena por fecha/copia/secuencia/hora y produce el reporte impreso V00-REPORTE1 por CSI. El parámetro de arranque (TASKVALUE) selecciona el índice DMSII para el barrido (modo 1 = índice primario B52SXCSIFECH con CSI=0; modo 2 = dataset secuencial CORE-DEPB52CTRLDEPRET). El programa se detiene automáticamente al detectar un cambio de fecha de máquina entre iteraciones, evitando procesar errores de un día con la fecha del siguiente. (BR: RN-CORE-DEP-228, RN-CORE-DEP-229, RN-CORE-DEP-230, RN-CORE-DEP-231, RN-CORE-DEP-232, RN-CORE-DEP-233)
