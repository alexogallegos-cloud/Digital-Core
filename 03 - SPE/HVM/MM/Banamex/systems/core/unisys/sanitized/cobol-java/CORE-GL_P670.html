CORE-GL · P670 a Java 21 Spring Boot

Recibe por parámetro el sistema, un identificador de paso de ocho caracteres (bitácora o MOVXCONT) y una fecha de seis dígitos, con los que arma el título del archivo de entrada; el pack de disco lo toma de la librería de control CORE-GLL001. Cada registro de entrada trae una línea de 132 caracteres y dos campos de control: una marca INICI BACK abre un nuevo listado cuyo título viene en la propia línea, PAGE produce un salto de página y un número indica cuántas líneas avanzar. Al llegar a 16 millones de líneas en un listado, lo cierra y continúa en otro con un número de parte en el título. También crea vacío un archivo I01 que sirve como marca de residencia.

/** REG-IMPRESION: 132 de línea + control de 5 y 4 posiciones. */
public sealed interface LineaImpresionDiferida
        permits LineaImpresionDiferida.InicioBackup, LineaImpresionDiferida.SaltoPagina,
                LineaImpresionDiferida.Avance {

    String texto();                                   // LINEA-IMPRESION X(132)

    /** WKS-OPCION1-IMP = "INICI" y WKS-OPCION2-IMP = "BACK": el texto es el título del listado. */
    record InicioBackup(String texto) implements LineaImpresionDiferida {}
    /** WKS-OPCION2-IMP = "PAGE". */
    record SaltoPagina(String texto) implements LineaImpresionDiferida {}
    /** Cualquier otro: WKS-OPCION2-NUM líneas de avance. */
    record Avance(String texto, int lineas) implements LineaImpresionDiferida {}

    static LineaImpresionDiferida parse(String r) {
        String texto = r.substring(0, 132);
        String op1 = r.substring(133, 138), op2 = r.substring(139, 143);
        if (op1.equals("INICI") && op2.equals("BACK")) return new InicioBackup(texto);
        if (op2.equals("PAGE")) return new SaltoPagina(texto);
        if (!op2.chars().allMatch(Character::isDigit)) {                 // el COBOL no lo valida
            throw new FormatoLineaException("Avance no numérico: '" + op2 + "'");
        }
        return new Avance(texto, Integer.parseInt(op2));
    }
}
/** WKS-PARAMETROS (PROCEDURE DIVISION USING): sistema 9(03) + id de paso X(08) + fecha X(06). */
public record ParametrosP670(int sistema, String idPaso, String fechaAmd) {
    public ParametrosP670 {
        if (!idPaso.matches("[A-Z0-9]{1,8}")) throw new IllegalArgumentException("idPaso");
        if (!fechaAmd.matches("\\d{6}")) throw new IllegalArgumentException("fechaAmd");
    }
}

    private final P670Properties props;          // p670.lib-control-respaldo: "(CORE-GL)CORE-GL/OBJECT/L001/CONTROL ON CMEMP"

    @Override
    public RepeatStatus execute(StepContribution sc, ChunkContext ctx) {
        ParametrosP670 p = Parametros.de(ctx);
        String titulo = ctlver.titulo("CORE-GLL001CTL").orElse(props.libControlRespaldo());
        var b01 = control.consultaSistemaDia(titulo, p.sistema(), /* funcion */ 1);
        if (b01.resultado() != 0) {
            throw new ProcesoAbortadoException("CONSISDIA resultado " + b01.resultado()); // STATUS -1
        }
        ctx.getStepContext().getStepExecution().getJobExecution()
           .getExecutionContext().putString("pack", b01.packMovimientos());   // WKS-B01-NOMPACMOV
        return RepeatStatus.FINISHED;
    }

@Bean

                    FlatFileItemReader<LineaImpresionDiferida> lector,

    return new StepBuilder("imprimeBackups", repo)
            .<LineaImpresionDiferida, LineaImpresionDiferida>chunk(500, tx)
            .reader(lector)          // ARCHIVOENT, línea -> LineaImpresionDiferida.parse
            .writer(escritor)        // abre, escribe y cierra listados según los comandos

@Component
@StepScope
@RequiredArgsConstructor
public class ListadosPorBackupWriter implements ItemWriter<LineaImpresionDiferida>, ItemStream {

    private final SalidaImpresion salida;     // impresora / archivo de spool
    private final P670Properties props;
    private Listado actual;                   // MOVIMIENTOS + W77-BACK-ABIERTO
    private TituloListado titulo;             // WKS-TIT-LIST
    private long lineas;                      // WKS-NUM-LINE

    @Override
    public void write(Chunk<? extends LineaImpresionDiferida> chunk) {
        for (LineaImpresionDiferida l : chunk) {
            switch (l) {
                case LineaImpresionDiferida.InicioBackup ib -> {
                    cierraActual();                                  // CLOSE MOVIMIENTOS WITH SAVE
                    titulo = TituloListado.desde(ib.texto(), props.patronTitulo()); // valida el título
                    actual = salida.abre(titulo.conParte(1));        // "001" en WKS-VAR-TMP
                    lineas = 0;
                }
                case LineaImpresionDiferida.SaltoPagina sp -> { verificaCorte(); escribe(sp.texto(), true, 0); }
                case LineaImpresionDiferida.Avance av     -> escribe(av.texto(), false, av.lineas());
            }
        }
    }

    private void escribe(String texto, boolean pagina, int avance) {
        if (actual == null) throw new SinListadoAbiertoException();   // el COBOL escribe sin OPEN
        actual.escribe(texto, pagina, avance);                        // AFTER PAGE / AFTER n
        lineas++;
    }
}
    /** 000078-256-ARMA-NVO-NOM: al llegar al límite, cierra y abre la parte siguiente. */
    private void verificaCorte() {
        if (lineas < props.maxLineasPorParte()) return;         // 16000000
        cierraActual();
        actual = salida.abre(titulo.siguienteParte());          // WKS-VAR2 = WKS-CONT, sin desbordar
        lineas = 0;
    }

/** WKS-TIT-LIST: 21 posiciones + parte de 3 + 32 posiciones. */
public record TituloListado(String prefijo, String sufijo, int parte) {
    TituloListado conParte(int p) { return new TituloListado(prefijo, sufijo, p); }
    TituloListado siguienteParte() {
        if (parte >= 999) throw new IllegalStateException("Demasiadas partes para " + this);
        return conParte(parte + 1);       // en COBOL WKS-CONT es 9(01) y vuelve a 0 tras el 9
    }
    @Override public String toString() { return prefijo + "%03d".formatted(parte) + sufijo.strip() + "."; }
}

Riesgos de migración
Título de archivo tomado del contenido

En 02-0150-IMPRIME-BACKUPS el título del listado se toma de LINEA-IMPRESION del registro INICI BACK (líneas 1157-1162). Quien pueda escribir el archivo de entrada decide dónde se crean archivos de impresión. En Java el nombre debe validarse contra un patrón permitido.

Escritura sin listado abierto

Si el archivo no empieza con un registro INICI BACK, las líneas siguientes se escriben en MOVIMIENTOS sin haberlo abierto (líneas 1166-1173). El resultado depende del manejo de errores del MCP.

Avance de líneas con campo no validado

Cuando el control no es PAGE, se usa WKS-OPCION2-NUM, un REDEFINES numérico de un campo alfanumérico (líneas 44-46), en AFTER WKS-OPCION2-NUM. Espacios u otro texto producen un avance indefinido.

Contador de partes de un dígito

WKS-CONT es PIC 9(01) (línea 968). Después de la parte 9, ADD 1 lo deja en 0 y los títulos se repiten; un listado de más de diez partes sobrescribiría las anteriores.

El corte por volumen solo se evalúa en saltos de página

000078-256-ARMA-NVO-NOM, que revisa el límite de 16000000 líneas, solo se invoca en registros PAGE (línea 1167); WKS-NUM-LINE cuenta además una línea por registro y no por línea física avanzada.

Pendiente de revisión SME
  • WKS-FECHA-PROCESO no recibe valor: las asignaciones están comentadas (líneas 1086-1091) y su conversión en 01-0140-MUEVE-SISFEC no se usa. Confirmar que la fecha del título viene solo del parámetro WKS-FECHA-IDPASO.
  • WKS-PACK-IDPASO se mueve a WKS-PACK-ARCH en la línea 989 antes de recibir valor; se sobrescribe en la línea 1083 con el pack de LIB-CONTROL. Confirmar que no hay un caso en que se use el valor inicial.
  • Confirmar qué proceso revisa la residencia del archivo I01-MOVIMIENTOS, que se abre y se cierra sin registros (líneas 1130 y 1195).
  • Los layouts WKS-TIT-LIST y LINEA-IMPRESION-TMP colocan el número de parte en las posiciones 22 a 24 del título (WKS-VAR, líneas 957-974); confirmar con un ejemplo real que esas posiciones no contienen parte del nombre del archivo.
