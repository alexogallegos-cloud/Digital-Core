CORE-DEP · P420 a Java 21 Spring Boot

Lee cuatro archivos secuenciales de 90 bytes: SALDOSTB de Cuenta Maestra y de Cheques, cada uno con su versión de Monterrey (ruta 04) y de Valle de México (ruta 10). Obtiene la fecha de proceso de CORE-DEPB02CONTROL retrocediendo un día con LOCSUP y exige que el header de cada archivo traiga esa fecha. Copia el header del primer archivo y todos los detalles a la cinta del producto (CINTACM o CINTACH) y, al llegar el trailer del segundo archivo, escribe un trailer consolidado con registros e importes MN y DL. Emite además un listado de cifras de control por plaza.

/** WS-REGTB: un registro de 90 bytes con tres vistas REDEFINES, discriminadas por WS-TB-TIPO-REG. */
public sealed interface SaldoTbRecord
        permits SaldoTbRecord.Header, SaldoTbRecord.Detalle,
                SaldoTbRecord.Trailer, SaldoTbRecord.Otro {

    String raw();   // la cinta de salida recibe el registro tal cual (WRITE ... FROM WS-REGTB)

    /** Tipo '0'. Posiciones 1-32; FILLER X(57). */
    record Header(String sisOrigen, String sisDestino,
                  LocalDate fecProceso, LocalDate fecBase,      // 9(08) AAAAMMDD
                  BigDecimal tipoCambio,                        // 9(04)V9(04) -> escala 4
                  String raw) implements SaldoTbRecord {}

    /** Tipo '1'. Contrato como String para conservar ceros a la izquierda. */
    record Detalle(String numContrato,                          // 9(12)
                   int producto, int instrumento, int moneda,
                   char signoSaldo,                             // X: P420 no lo usa
                   BigDecimal saldoMn,                          // 9(12)V99 -> escala 2
                   int limiteCredito, int csi, int sucursal,
                   BigDecimal autPendMn,                        // 9(08)V99
                   int status,
                   BigDecimal saldoDl,                          // 9(12)V99
                   BigDecimal autPendDl,                        // 9(08)V99
                   String raw) implements SaldoTbRecord {}

    /** Tipo '9'. */
    record Trailer(long numRegistros,                           // 9(08)
                   BigDecimal totSaldoMn, BigDecimal totSaldoDl, // 9(16)V99
                   String raw) implements SaldoTbRecord {}

    /** Cualquier otro tipo: P420 no lo copia ni lo reporta. */
    record Otro(String raw) implements SaldoTbRecord {}

    static SaldoTbRecord parse(String r) {
        return switch (r.charAt(0)) {
            case '0' -> new Header(r.substring(1, 5), r.substring(5, 9),
                    Fixed.fechaAmd(r, 9), Fixed.fechaAmd(r, 17), Fixed.decimal(r, 25, 8, 4), r);
            case '1' -> Fixed.detalle(r);   // offsets: 1,13,17,21,24,25,39,42,44,48,58,59,73
            case '9' -> new Trailer(Fixed.entero(r, 1, 8), Fixed.decimal(r, 9, 18, 2),
                    Fixed.decimal(r, 27, 18, 2), r);
            default  -> new Otro(r);
        };
    }
}

                             Step validaVersion,            // 10000000-LIBRERIAS + 20000050-CHECO-VER

                             Step concentraCheques) {       // 50004000 + 50005000 -> CINTACH

                .start(validaVersion)
                .next(fechaProceso)
                .next(concentraCuentaMaestra)
                .next(concentraCheques)
                .build();
        // 70000000-CIERRO (CLOSE ... WITH SAVE) lo hace cada ItemWriter al cerrar su step.
    }
}
@Bean
Step concentraCuentaMaestra(JobRepository repo, PlatformTransactionManager tx,
                            P420Properties props, ResourceLoader rl,
                            @Value("#{jobExecutionContext['fechaProceso']}") LocalDate fecha,
                            ConcentradorProcessor procesadorCm,
                            FlatFileItemWriter<SaldoTbRecord> cintaCmWriter) {

    Resource[] entradas = props.entradas().cuentaMaestra().stream()
            .map(p -> rl.getResource(props.resuelve(p, fecha)))
            .toArray(Resource[]::new);

    var lector = new MultiResourceItemReaderBuilder<SaldoTbRecord>()
            .name("saldosTbCuentaMaestra")
            .resources(entradas)
            .comparator((a, b) -> 0)        // NO ordenar por nombre: P420 depende de leer MTY antes que VDM
            .delegate(saldoTbLineReader())  // LineMapper -> SaldoTbRecord.parse
            .build();

    return new StepBuilder("concentraCuentaMaestra", repo)
            .<SaldoTbRecord, SaldoTbRecord>chunk(180, tx)   // BLOCK CONTAINS 180 RECORDS
            .reader(lector)
            .processor(procesadorCm)        // @StepScope: estado WS-1VEZ..WS-7VEZ por step
            .writer(cintaCmWriter)
            .build();
}

@Component
@RequiredArgsConstructor
public class FechaProcesoTasklet implements Tasklet {

    private final ControlCaptacionRepository control;   // CORE-DEPB02CONTROL, acceso de solo lectura (OPEN INQUIRY)
    private final CalendarioBancario calendario;         // reemplaza LOCSUP

    @Override
    public RepeatStatus execute(StepContribution contribution, ChunkContext ctx) {
        LocalDate fechaLinea = control.findFechaLinea()
                .orElseThrow(() -> new ProcesoAbortadoException(
                        "ERROR REG. DE CONTROL VACIO"));            // CALL SYSTEM DMTERMINATE

        // 20002100-PROY-FEC: LOCSUP función 15, formato 12, desplazamiento 1.
        // Las fechas ya se proyectaron al día siguiente; se retrocede uno para obtener la de proceso.
        LocalDate fechaProceso = calendario.retrocede(fechaLinea, 1)
                .orElseThrow(() -> new ProcesoAbortadoException(
                        "ERROR AL ACCESAR LOCSUP"));                 // 40000000-CALL-FECPRO

        ctx.getStepContext().getStepExecution().getJobExecution()
           .getExecutionContext().put("fechaProceso", fechaProceso);
        return RepeatStatus.FINISHED;
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class ConcentradorProcessor implements ItemProcessor<SaldoTbRecord, SaldoTbRecord> {

    @Value("#{jobExecutionContext['fechaProceso']}") private LocalDate fechaProceso;
    @Value("#{stepExecution.stepName}")             private String familia;   // CM o CH
    private boolean headerEscrito;                                         // WS-6VEZ / WS-8VEZ

    @Override
    public SaldoTbRecord process(SaldoTbRecord rec) {
        return switch (rec) {
            case SaldoTbRecord.Header h  -> procesaHeader(h);
            case SaldoTbRecord.Detalle d -> procesaDetalle(d);
            case SaldoTbRecord.Trailer t -> procesaTrailer(t);
            case SaldoTbRecord.Otro o    -> null;   // tipo distinto de 0/1/9: se descarta sin aviso
        };
    }

    /** 50008010-HEADER-CINTACM: la fecha base de cada archivo debe ser la de proceso. */
    private SaldoTbRecord procesaHeader(SaldoTbRecord.Header h) {
        if (!h.fecBase().equals(fechaProceso)) {
            throw new ProcesoAbortadoException(                         // CALL SYSTEM DMTERMINATE
                "FECEXT Y FECINT ARCH SDOTB %s DIFIEREN;EXT: %s INT: %s"
                    .formatted(familia, fechaProceso, h.fecBase()));
        }
        if (headerEscrito) {
            return null;            // el header del segundo archivo se valida pero no va a la cinta
        }
        headerEscrito = true;
        return h;
    }
    private Acumulador porArchivo = Acumulador.vacio();   // WS-TOTCTES-REG, WS-IMPCTES*-REG

    /** 50008020-GRABO-DETALLE: copia el detalle a la cinta y acumula importes por moneda. */
    private SaldoTbRecord procesaDetalle(SaldoTbRecord.Detalle d) {
        porArchivo = (d.moneda() == 1)
                ? porArchivo.masRegistro().masMn(d.saldoMn())    // MN
                : porArchivo.masRegistro().masDl(d.saldoDl());   // cualquier otra moneda va a DL
        return d;
    }

/** Acumuladores con la capacidad de los PIC originales. */
public record Acumulador(long registros, BigDecimal mn, BigDecimal dl) {
    private static final BigDecimal TOPE_9_12_V99 = new BigDecimal("999999999999.99");

    static Acumulador vacio() {
        return new Acumulador(0, BigDecimal.ZERO.setScale(2), BigDecimal.ZERO.setScale(2));
    }
    Acumulador masRegistro()          { return new Acumulador(registros + 1, mn, dl); }
    Acumulador masMn(BigDecimal v)    { return new Acumulador(registros, tope(mn.add(v)), dl); }
    Acumulador masDl(BigDecimal v)    { return new Acumulador(registros, mn, tope(dl.add(v))); }

    /** ADD sin ON SIZE ERROR en COBOL pierde el dígito alto en silencio; aquí se falla. */
    private static BigDecimal tope(BigDecimal v) {
        if (v.compareTo(TOPE_9_12_V99) > 0) throw new DesbordamientoAcumuladorException(v);
        return v;   // suma de importes con escala 2: exacta, sin redondeo
    }
}
    private final P420Properties props;

    /**
     * 50008030-TRAILER, primer bloque. En el fuente ambas ramas del IF son NEXT SENTENCE
     * y el abort está comentado: un trailer que no cuadra pasa sin aviso.
     * Se conserva ese comportamiento por defecto y se deja la validación activable.
     */
    private void validaTrailer(SaldoTbRecord.Trailer t) {
        boolean cuadra = t.totSaldoMn().compareTo(porArchivo.mn()) == 0
                && t.totSaldoDl().compareTo(porArchivo.dl()) == 0
                && t.numRegistros() == porArchivo.registros();
        if (!cuadra) {
            log.warn("TRA.DIF. A SUMA DE REG. DE {}. trailer={} calculado={}",
                     familia, t, porArchivo);
            if (props.validarTrailer()) {          // p420.validar-trailer: false (comportamiento actual)
                throw new TrailerDescuadradoException(familia, t, porArchivo);
            }
        }
    }
    private final ReporteCifrasControl reporte;   // REPORTE (PRINTER) -> JasperReports / CSV
    private Acumulador total = Acumulador.vacio();  // WS-TOT-CTES, WS-TOT-SDOSMN, WS-TOT-SDOSDL
    private int trailersVistos;                     // WS-7VEZ / WS-9VEZ

    private SaldoTbRecord procesaTrailer(SaldoTbRecord.Trailer t) {
        validaTrailer(t);
        String plaza = (trailersVistos == 0) ? "M O N T E R R E Y   " : "V A L L E  D/ M E X.";
        reporte.renglon(familia, plaza, porArchivo);           // WRITE REG-IMP FROM WS-DET-SDOTB
        total = new Acumulador(total.registros() + porArchivo.registros(),
                               total.mn().add(porArchivo.mn()), total.dl().add(porArchivo.dl()));
        porArchivo = Acumulador.vacio();

        if (trailersVistos++ == 0) {
            return null;            // falta el archivo de Valle: el trailer de MTY no va a la cinta
        }
        var consolidado = Fixed.trailer(total.registros(), total.mn(), total.dl());   // tipo '9'
        total = Acumulador.vacio();
        return consolidado;         // WRITE REG-CINTACM FROM WS-REGTB
    }

Riesgos de migración
Trailer de entrada sin validar

En 50008030-TRAILER y 50009030-TRAILER (líneas 1603-1625 y 1801-1823) las dos ramas del IF son NEXT SENTENCE y el abort está comentado. P420 no detecta archivos incompletos ni duplicados.

Signo del saldo ignorado en cifras de control

WS-TBDE-SIGSDO (línea 355) no se lee en ningún párrafo. Los totales del trailer consolidado y del reporte suman importes sin signo; un saldo deudor se sumaría como positivo. El detalle viaja intacto a la cinta, así que el impacto es sobre las cifras de control.

Desbordamiento silencioso

Los acumuladores por archivo son PIC 9(12)V99 y los totales PIC 9(13)V99, sin ON SIZE ERROR. Si se excede la capacidad, COBOL pierde los dígitos altos sin aviso. La versión Java falla de forma explícita.

Dependencia del orden de lectura

La etiqueta de plaza del reporte, el header que se escribe y el momento del trailer consolidado dependen de que se procese primero el archivo de Monterrey (WS-7VEZ y WS-9VEZ). El MultiResourceItemReader debe configurarse sin reordenar recursos.

Hardcodes de rutas y plazas

Prefijos CORE-DEP y S001, nodos 04 y 10, WS-TOT-CI = 10 en el título del listado y los nombres de plaza están compilados. Se trasladan a application.yml.
