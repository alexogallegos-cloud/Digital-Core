CORE-GL · P168 a Java 21 Spring Boot

P168 recibe sistema y fecha de proceso en un parámetro de 11 dígitos. Carga el archivo de saldos ACC en un indexado temporal por número de cuenta y luego recorre el AHR, ordenado por cuenta: al cambiar de cuenta compara el saldo de mayor y su signo del último movimiento contra el saldo y signo de ACC, y graba las cuentas que no cuadran en ARCH-CTAS. Para ocho cuentas INTEL fijas en el código arma además un archivo con encabezado de saldos de apertura y cierre más el detalle de movimientos, lo envía por INTELARSND y dispara un WFL de transferencia. Al final imprime el reporte de diferencias con los movimientos de cada cuenta descuadrada y deja un archivo bandera BANDE-P168.

@Component
@RequiredArgsConstructor
public class CargaAccTasklet implements Tasklet {

    private static final String FIN_ARCHIVO = "END OF FILE";   // ACCI-ENDOFFILE del trailer
    private final SaldoAccRepository saldos;
    private final FlatFileItemReader<RegistroAcc> accReader;   // ARCH-ACC, 360 bytes, layout CBII

    @Override
    @Transactional
    public RepeatStatus execute(StepContribution sc, ChunkContext ctx) throws Exception {
        saldos.deleteAllInBatch();                             // OPEN OUTPUT / CLOSE / OPEN I-O: recrea vacío
        accReader.open(new ExecutionContext());
        try {
            for (RegistroAcc r; (r = accReader.read()) != null; ) {
                if (r.raw().startsWith(FIN_ARCHIVO)) break;   // trailer de CBII
                var s = new SaldoAcc(r.numeroCuenta(),
                        Pic.trunca(r.saldo(), 14, 2),          // 9(15)V99 a 9(14)V99
                        r.signoSaldo());
                if (!saldos.existsById(s.getCuenta())) {
                    saldos.save(s);                            // WRITE ... INVALID KEY NEXT SENTENCE
                } else {
                    sc.incrementFilterCount(1);                // duplicado: gana el primero, sin aviso en el fuente
                }
            }
        } finally {
            accReader.close();
        }
        return RepeatStatus.FINISHED;
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class ConciliacionAhrProcessor implements ItemProcessor<MovimientoAhr, DiferenciaSaldo> {

    private final SaldoAccRepository acc;          // ARCH-ACC2
    private String cuentaAnterior;                 // WKS-CUENTA-ANT
    private MovimientoAhr ultimo;                  // WKS-CUENTA-T, WKS-SALDO-T, WKS-SSDO-T

    /** El AHR llega ordenado por cuenta; el saldo que se compara es el del último movimiento. */
    @Override
    public DiferenciaSaldo process(MovimientoAhr m) {
        if (m.cuenta().equals(cuentaAnterior)) {
            ultimo = m;
            return null;
        }
        DiferenciaSaldo dif = (cuentaAnterior == null) ? null : comparaCierre();
        cuentaAnterior = m.cuenta();
        ultimo = m;
        return dif;                                // se escribe en ARCH-CTAS (upsert)
    }

    private DiferenciaSaldo comparaCierre() {
        BigDecimal saldoAhr = Pic.trunca(ultimo.saldoMayor(), 14, 2);     // WKS-SALDO-T 9(14)V99
        return acc.findById(cuentaAnterior)
                .map(a -> (saldoAhr.compareTo(a.getSaldo()) == 0
                           && ultimo.signoSaldoMayor() == a.getSigno().charAt(0))
                        ? null                                             // cuenta cuadrada
                        : new DiferenciaSaldo(cuentaAnterior, saldoAhr, a.getSaldo(),
                                              ultimo.signoSaldoMayor(), a.getSigno().charAt(0)))
                .orElseGet(() -> new DiferenciaSaldo(cuentaAnterior, saldoAhr,
                                              BigDecimal.ZERO.setScale(2),
                                              ultimo.signoSaldoMayor(), ' '));   // no existe en ACC
    }
    // Al fin del archivo NO se compara la última cuenta: el fuente no tiene ese cierre.
}

/** 20300-CALCULA-SDOINI. El resultado se guarda sin signo y la naturaleza indica el lado. */
public final class SaldoAperturaIntel {

    public static Apertura calcula(MovimientoAhr m) {
        BigDecimal mayor = m.saldoMayor();               // AHRST-LDGR-AMT 9(15)V99
        BigDecimal txn   = m.importe();                  // AHRST-TXN-AMT  9(15)V99
        boolean acreedor = m.signoSaldoMayor() == '+';
        boolean abono    = m.cargoAbono() == 'C';        // AHRST-DR-CR-IND

        BigDecimal saldo; char nat;
        if (acreedor) {
            if (abono) { saldo = mayor.subtract(txn); nat = txn.compareTo(mayor) > 0 ? 'D' : 'C'; }
            else       { saldo = mayor.add(txn);      nat = 'C'; }
        } else {
            if (abono) { saldo = mayor.add(txn);      nat = 'D'; }
            else       { saldo = mayor.subtract(txn); nat = txn.compareTo(mayor) > 0 ? 'C' : 'D'; }
        }
        // W77-SDO-INTEL S9(14)V99 se mueve a A00-R00-INTE-SDO-APERTURA 9(14)V99: se pierde el signo.
        return new Apertura(Pic.trunca(saldo.abs(), 14, 2), nat);
    }

    public record Apertura(BigDecimal saldo, char naturaleza) {}
}

/** 30300-GRABA-DET1: magnitud del descuadre que se imprime en AUDSDOS. */
public static BigDecimal diferencia(DiferenciaSaldo d) {
    BigDecimal ahr = d.saldoAhr(), acc = d.saldoAcc();
    BigDecimal dif = (d.signoAhr() == d.signoAcc())
            ? ahr.subtract(acc).abs()        // mismo lado: mayor menos menor
            : ahr.add(acc);                  // lados opuestos: suma de magnitudes
    return Pic.trunca(dif, 14, 2);           // WKS-SALDO-T 9(14)V99, COMPUTE sin ON SIZE ERROR
}

@RequiredArgsConstructor
public class EnvioIntelarService {

    private final EncabezadoIntelFactory encabezados;
    private final SeguimientoIntel seguimiento;
    private final P168Properties props;
    private final MessageChannel intelarOut;      // reemplaza INTELARSND IN ADMONXFERS

    /** 20400-VERI-CTAS-FALTAN: las cuentas INTEL sin movimientos se envían con apertura = cierre. */
    public void completaFaltantes(ArchivoIntel archivo) {
        for (String cuenta : seguimiento.faltantes(props)) {
            var c = encabezados.cierre(cuenta);
            archivo.encabezado(cuenta, c.saldoCierre(), c.naturalezaCierre(),   // apertura
                                       c.saldoCierre(), c.naturalezaCierre());  // cierre
        }
    }

    /** 20190-ENVIA-INTELAR: el título hasta el primer punto es el nombre que recibe el canal. */
    public void envia(ArchivoIntel archivo) {
        String nombre = archivo.titulo().split("\\.", 2)[0];
        boolean ok = intelarOut.send(MessageBuilder.withPayload(archivo.path())
                .setHeader("intelar.nombre", nombre).build());
        if (!ok) {
            throw new EnvioIntelarException("ERROR EN EL ENVIO POR INTELAR DEL ARCHIVO " + nombre);
        }
    }
}

Riesgos de migración
Última cuenta del AHR sin conciliar

La comparación de saldos solo ocurre al cambiar de cuenta en 20100-LEE-ARCH-AHR (líneas 1605-1677) y no hay cierre después del fin de archivo; la última cuenta solo se concilia si el AHR trae un registro final que fuerce el cambio.

Truncamiento de saldos

Los saldos de origen son 9(15)V99; WKS-SALDO-T y ACC-SALDO son 9(14)V99 y WKS-SDO-AHR, que va al archivo de diferencias y al reporte, es 9(12)V99 (línea 199). Saldos grandes se comparan o reportan sin sus dígitos altos.

Duplicados de ACC descartados en silencio

ARCH-ACC2 usa solo el número de cuenta como llave y el WRITE con llave repetida se ignora (líneas 1565-1566). Una cuenta con más de un registro en ACC se concilia contra el primero.

Errores de envío no detienen el paso

Un error de INTELARSND (líneas 1712-1719) solo se registra, y el WFL de transferencia lanzado con CALL SYSTEM WFL (línea 1526) no se verifica.

Hardcodes

Ocho cuentas INTEL (líneas 1141-1148), el título por omisión del controlador de transferencias, el prefijo CORE-DEP del parámetro del WFL, el pack CMEMP de los archivos de trabajo y el CSI 10 del título del reporte (línea 1495) están compilados.

Pendiente de revisión SME
  • Confirmar si el AHR de CBII trae un registro final (trailer AHRST-REC-TRAILER) que actúe como centinela; de lo contrario la última cuenta nunca se concilia.
  • En 30100-LEE-AHR (líneas 1818-1825) después del AT END de ARCH-CTAS2 el programa vuelve a ejecutar 30300-GRABA-DET1 con el último registro leído; confirmar en una corrida real si la última cuenta descuadrada se imprime dos veces.
  • Confirmar si el envío INTELAR fallido debe abortar el paso, como propone la versión Java, o mantener el comportamiento actual.
  • La razón de que el parámetro del WFL lleve prefijo CORE-DEP en un programa de CORE-GL no está documentada en el fuente.
  • Validar con SME si las ocho cuentas INTEL siguen vigentes.
