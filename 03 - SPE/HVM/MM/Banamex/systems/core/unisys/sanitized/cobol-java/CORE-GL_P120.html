CORE-GL · P120 a Java 21 Spring Boot

P120 lee el registro de control de CORE-GLBD02ADSALDO para obtener CSI y fecha base, crea el archivo CONCENTRA con un header y recorre CORE-GLB02SDOSUC escribiendo un registro de 90 bytes por cada sistema activo de cada sucursal, a la vez que imprime el listado de concentración con la variación del día. Después recorre CORE-GLB05SDOCNC para el listado de conceptos con sus totales, toma los importes SAR de CORE-GLB07TOTSDO por posición de CSI, acumula los saldos SAR globales de CORE-GLB08GLOSAR e imprime los dos reportes SAR. Cualquier excepción DMSII distinta de NOTFOUND termina el programa con SET MYSELF(STATUS) TO -1.

@ConfigurationProperties("core-gl")
public record CsiCatalogo(Map<Integer, Csi> csis) {
    public record Csi(String siglas, String nombre) {}

    /** NOMBRE-CSI(77-CSI): en COBOL un índice 2, 3, 5 u 8 da espacios y uno mayor que 10 sale del arreglo. */
    public Csi de(int csi) {
        Csi c = csis.get(csi);
        if (c == null) throw new IllegalStateException("CSI sin catálogo: " + csi);
        return c;
    }
}
/** W-REG-SALDOS: un buffer de 90 bytes; la vista la decide el primer campo (CVES). */
public sealed interface ConcentraRecord
        permits ConcentraRecord.Header, ConcentraRecord.Sucursal,
                ConcentraRecord.Cliente, ConcentraRecord.Global, ConcentraRecord.Trailer {

    /** CVES X(02) = "HR". */
    record Header(int csiOrigen, int sistema, LocalDate fechaProceso,
                  int diaCreacion, int horaCreacion) implements ConcentraRecord {}

    /** W-REG-SUCURSAL. Saldos 9(18)V99 COMP: BigDecimal escala 2. */
    record Sucursal(int sistema, int sucursal, int moneda,
                    BigDecimal saldoAnterior, BigDecimal saldoActual,
                    LocalDate fecha) implements ConcentraRecord {}

    /** W-REG-CLIENTE, W-REG-GLOBALES y W-TRAILER-SDOS: definidos en el layout, P120 no los escribe. */
    record Cliente(int sistema, int sucursal, int moneda, long cuentas, int institucion,
                   String nombre, BigDecimal saldoAnterior, BigDecimal saldoActual,
                   LocalDate fecha) implements ConcentraRecord {}
    record Global(int sistema, int moneda, BigDecimal saldoAnterior,
                  BigDecimal saldoActual, LocalDate fecha) implements ConcentraRecord {}
    record Trailer(int sistema, long registros) implements ConcentraRecord {}
}

                            Step saldosSucursal,      // 2000-PROCESO UNTIL 77-EOF = 1

                .start(control)
                .next(saldosSucursal)
                .next(conceptos)
                .next(totalesSar)
                .next(reportesSar)
                .build();
        // 7000-CIERRA (CLOSE SALDOS WITH LOCK) lo hace el ItemWriter al cerrar su step.
    }
}
@Component
@RequiredArgsConstructor
public class ControlSaldosTasklet implements Tasklet {

    private final ControlSaldoRepository control;   // registro B92 de CORE-GLBD02ADSALDO

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        var b92 = control.findControl()
                .orElseThrow(() -> new ProcesoAbortadoException(
                        "CORE-GL/P120 NO EXISTE REG DE FECHAS"));        // SET MYSELF(STATUS) TO -1

        var ec = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        ec.putInt("csi", b92.csi());                                    // 77-CSI
        ec.put("fechaBase", b92.fecha().toLocalDate());                 // FECHA-BASE
        return RepeatStatus.FINISHED;
    }
}

En la línea 1198 ADD B08-GSAR-ANT-INFO TO 77-ANT-ISTE. El reporte SAR imprime INFONAVIT anterior en cero e ISSSTE anterior inflado.

PANO es PIC 9(02); el nombre de CONCENTRA solo lleva año de dos dígitos.
