Fuente: COBOL_P194.cbl (854 LOC)

Rol en batch: Utilidad de depuración de archivos · bloque P194-P197 en WFL LOTE (tras P167/P177)

Convenciones: nombres traducidos (Unisys→legible); [P194 Lnnnn] = línea origen; (BR: RN-CORE-GL-NNN) = regla.

Autor original: Autor 04, Diciembre 2016. Revisión: 21MTP002 (Marzo 2021).

1. Resumen funcional

P194 es un programa utilitario de mantenimiento del sistema CORE-GL (LegacyCore, Unisys ClearPath MCP COBOL85). Su función es depurar directorios en disco leyendo de un archivo de control la lista de rutas a limpiar, con su usuario, pack, CSI y días de retención asignados. A partir de la fecha de proceso del sistema CORE-DEP (consultada vía CONSISDIA), precalcula hasta cuatro fechas de retención (1 a 4 días atrás en el calendario) y selecciona la apropiada por directorio para invocar la rutina REMUEVE_ARCHIVOS de la librería BORRA. La política de retención es diferenciada: en equipos de producción se conserva siempre 1 día, ignorando el valor declarado en el archivo de control; en equipos de pruebas se respeta el número de días del archivo con una base desplazada 4 días atrás. Solo se depuran directorios cuyo CSI coincida con el CSI del equipo en ejecución, o si el equipo tiene CSI 32 (alcance global).

2. Datos y archivos

2.1 Archivo de entrada

A01-DIR-INPUTDISKCORE-GL/FILE/I10/DEPURAR/DIRECTORIOS/007.Secuencial
MAXRECSIZE=80, FRAMESIZE=8BLOCK 100 RECORDS

Layout registro A01-REG-DIR PIC X(80) — campos separados por punto .:

CAMPO 1: WKS-USER  PIC X(04) — usuario propietario del directorio
CAMPO 2: WKS-DIR   PIC X(30) — ruta del directorio (path)
CAMPO 3: WKS-PACK  PIC X(17) — nombre del pack de disco (ej. CMEMP)
CAMPO 4: WKS-CSI   PIC X(02) / WKS-CSI-NUM PIC 9(02) — CSI asignado
CAMPO 5: WKS-DIAS  PIC X(02) / WKS-DIAS-NUM PIC 9(02) — días de retención
Ejemplo de línea: CORE-GL.CORE-GL/FILE/TEMP.CMEMP.01.02

2.4 Sin acceso DMSII

P194 no abre directamente ninguna base de datos DMSII. El acceso a fechas del sistema se realiza exclusivamente vía CONSISDIA IN CORE-GLL001 (que internamente accede a CORE-GLB01SISDIA).

```
// ── Llamada a THECALENDAR: retroceder 1 día en el calendario ─────────
funcion_calendario = 15                                // W77-FUNCION · [P194 L797] ⚠ [HARDCODE: func=15]
delta_dias         = "00000001"                        // WKS-FECHA2 · [P194 L798] ⚠ [HARDCODE: 1 día siempre]

    USANDO funcion_calendario,                         // W77-FUNCION = 15 (restar N días)
           fecha_calculo,                              // WKS-FECHA1 — entrada/salida: se actualiza con la fecha - 1 día
           delta_dias,                                 // WKS-FECHA2 = "00000001"
           formato_calendario                          // W77-FORMATO = 13

// Resultado: WKS-FECHA1 ahora contiene fecha_calculo - 1 día

// ── Conversión a formato juliano ──────────────────────────────────────

4.4 · Procesar_Directorio_y_Borrar

PROCEDIMIENTO Procesar_Directorio_y_Borrar():        // 0200-LLAMA-BORRADO · [P194 L814]
```
// ── Paso 1: Parsear renglón del archivo de control ─────────────────────
DESENSAMBLAR registro_directorio                       // A01-REG-DIR · [P194 L816-820]
    DELIMITADO POR "."                                 // WKS-PUNTO
    EN usuario_directorio,                             // WKS-USER    PIC X(04)
       ruta_directorio,                                // WKS-DIR     PIC X(30)
       pack_disco,                                     // WKS-PACK    PIC X(17)
       csi_directorio,                                 // WKS-CSI     PIC X(02) / WKS-CSI-NUM PIC 9(02)
       dias_retencion                                  // WKS-DIAS    PIC X(02) / WKS-DIAS-NUM PIC 9(02)

// ── Paso 2: Armar título de directorio en formato MCP ─────────────────
// (BR: RN-CORE-GL-915)
ENSAMBLAR titulo_directorio                            // WKS-DIRECTORIO PIC X(58) · [P194 L821-828]
    DESDE: "("            // literal
           usuario_directorio                          // WKS-USER
           ")"            // literal
           ruta_directorio                             // WKS-DIR
           " ON "         // literal ⚠ [HARDCODE: separador MCP]
           pack_disco                                  // WKS-PACK
           "."            // literal — punto terminal MCP ⚠ [HARDCODE]
// Ej. resultado: "(CORE-GL)CORE-GL/FILE/TEMP/007 ON CMEMP."

// ── Paso 3: Determinar fecha de remoción según entorno ────────────────
// (BR: RN-CORE-GL-912, RN-CORE-GL-913)
SI equipo_es_produccion ENTONCES                       // W88-EQUIPO-PRODUCCION · [P194 L830]
    // ⚠ [HARDCODE] Forzar retención a 1 día en producción sin importar el archivo
    dias_retencion_num = 1                             // WKS-DIAS-NUM = 1 · [P194 L831]

    SI dias_retencion_num = 1 ENTONCES                 // [P194 L832-833] — siempre verdadero
        fecha_remocion = fecha_retencion_1d            // WKS-FECHA-1 → WKS-REM-FECHA
    SINO SI dias_retencion_num = 2 ENTONCES            // [P194 L835-836] ⚠ [CÓDIGO MUERTO en producción]
        fecha_remocion = fecha_retencion_2d            // WKS-FECHA-2 → WKS-REM-FECHA
    SINO SI dias_retencion_num = 3 ENTONCES            // [P194 L838-839] ⚠ [CÓDIGO MUERTO en producción]
        fecha_remocion = fecha_retencion_3d            // WKS-FECHA-3 → WKS-REM-FECHA
    SINO SI dias_retencion_num = 4 ENTONCES            // [P194 L841-842] ⚠ [CÓDIGO MUERTO en producción]
        fecha_remocion = fecha_retencion_4d            // WKS-FECHA-4 → WKS-REM-FECHA
    SINO                                               // [P194 L843-844] ⚠ [CÓDIGO MUERTO en producción]
        fecha_remocion = fecha_retencion_1d            // WKS-FECHA-1 → WKS-REM-FECHA (default fallback)
    FIN-SI

    // NOTA: En equipos de PRUEBAS, este bloque se omite.
    // WKS-REM-FECHA ya fue asignado en 0100-LIBRERIAS (línea L770) como
    // fecha_proceso - 1 día - 4 días adicionales.
FIN-SI

// ── Paso 4: Filtrar por CSI — solo depurar si corresponde al equipo ───
// (BR: RN-CORE-GL-914)
SI csi_equipo_ejecucion = csi_directorio               // WKS-NUMCSI = WKS-CSI-NUM · [P194 L846]
   O csi_equipo_ejecucion = 32                         // WKS-NUMCSI = 32 ⚠ [HARDCODE: CSI maestro global] · [P194 L847]
ENTONCES
    resultado_borrado = 0                              // W77-RESULT · [P194 L848]
    DESPLEGAR titulo_directorio                        // DISPLAY WKS-DIRECTORIO · [P194 L849]

    LLAMAR REMUEVE_ARCHIVOS EN BORRA                   // [P194 L850-853]
