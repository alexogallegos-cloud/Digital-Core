Al arrancar obtiene la fecha contable de CORE-DEP con CONSISDIA, carga del catálogo 6 la naturaleza contable (cargo, abono o no contable) de cada clave de transacción y del catálogo 1822 las horas de corte de pesos y de dólares, y se ubica en el siguiente corte según la hora actual. En cada evento de COMS lee de forma incremental MOVCORE-DEP desde el último registro guardado en A03-CTL-ENVIO, toma las altas de sistema 500, función 1, origen 1 o 3, formato 2 e indicador EXTNET 4 del archivo de descripciones, y por cada clave de transacción escribe un detalle en el archivo de la moneda y acumula conteos e importes de cargos y abonos. Las eliminaciones (funciones 2, 21 y 22) se buscan en el archivo indexado A05-AUTORIZACIONES y generan detalles de eliminación. Al llegar la hora de corte en día hábil escribe el trailer, cierra el archivo, lo envía por INTELARSND y reinicia los totales.

@Component
@RequiredArgsConstructor
public class CortesScheduler implements ApplicationRunner {

    private final CalendarioBancario calendario;
    private final CatalogoCortes cortes;               // catálogo 1822
    private final CatalogoNaturaleza naturaleza;       // catálogo 6
    private final RecuperacionArchivoAbierto recuperacion;   // 030301-STATUS-FILE-P / -D
    private final JobLauncher launcher;
    private final Job concentraCtamre;
    private final P055Properties props;

    @Override
    public void run(ApplicationArguments args) {
        naturaleza.cargar();
        cortes.cargar();
        if (calendario.esHabil(LocalDate.now())) {       // IF WKS-FECHA1 = 1
            props.monedas().values().forEach(recuperacion::cerrarSiVencido);
        }
    }

    /** PERFORM 030100-PROCESO UNTIL W77-FIN = 1: cada evento o timeout de ESPERACOMS dispara un barrido. */
    @Scheduled(fixedDelayString = "${p055.espera-entre-barridos:PT300S}")   // W77-ESPERACOMS-TIEMPO VALUE 300
    void barrido() throws Exception {
        launcher.run(concentraCtamre, new JobParametersBuilder()
                .addLocalDateTime("instante", LocalDateTime.now())
                .toJobParameters());
    }
}
@Component
@RequiredArgsConstructor
public class CatalogoCortes {

    private static final int INDICADOR_PESOS = 2;     // "INDICADOR 2 PESOS Y EL 3 DOLAR"
    private static final int INDICADOR_DOLARES = 3;
    private final CatalogoS080Client s080;          // L710_CONSUL_DETALLE IN S080L710
    private volatile Map<Integer, List<LocalTime>> porIndicador = Map.of();

    public void cargar() {
        porIndicador = s080.consultaDetalle(151, 55, 1822)   // sistema 151, programa 55
                .stream()
                .filter(r -> r.dato(2) == INDICADOR_PESOS || r.dato(2) == INDICADOR_DOLARES)
                .collect(Collectors.groupingBy(r -> (int) r.dato(2),
                        Collectors.mapping(r -> horaHhmm(r.dato(3)),
                                Collectors.collectingAndThen(Collectors.toList(),
                                        l -> l.stream().sorted().toList()))));
    }

    /** Equivale a WKS-HORA-CORTE(i); 9999 marcaba el fin de la tabla. */
    public Optional<LocalTime> corte(int indicador, int indice) {
        var l = porIndicador.getOrDefault(indicador, List.of());
        return indice >= 1 && indice <= l.size() ? Optional.of(l.get(indice - 1)) : Optional.empty();
    }

    private static LocalTime horaHhmm(long v) { return LocalTime.of((int) (v / 100), (int) (v % 100)); }
}
@Component

class VerificadorCorte {

    private final CatalogoCortes cortes;
    private final CalendarioBancario calendario;
    private final Clock reloj;

    enum Accion { SIN_ARCHIVOS, ACUMULAR, CERRAR_EN_ESTE_BARRIDO }

    /** 030302-VERIFICA-ENVIO para una moneda. */
    Accion evaluar(int indicador, EstadoMoneda estado) {
        Optional<LocalTime> corte = cortes.corte(indicador, estado.getIndiceCorte());
        if (corte.isEmpty()) return Accion.SIN_ARCHIVOS;             // HORA-CORTE = 9999

        LocalTime ahora = LocalTime.now(reloj).truncatedTo(ChronoUnit.MINUTES);   // WKS-HM-MAQ-4D
        boolean llegoCorte = !ahora.isBefore(corte.get());                         // = OR >
        boolean habil = calendario.esHabil(LocalDate.now(reloj));
        return (llegoCorte && habil) ? Accion.CERRAR_EN_ESTE_BARRIDO : Accion.ACUMULAR;
    }
}

public class CtamreProcessor implements ItemProcessor<MovimientoCORE-DEP, List<CtamreRecord>> {

    private final DescripcionesCORE-DEP descripciones;   // A02-DESCORE-DEP (030376-LEE-DATOS-ADIC / ADIC2)
    private final AutorizacionesRepository autorizaciones;   // A05-AUTORIZACIONES
    private final DetalleFactory detalles;
    @Value("#{stepExecution.stepName}") private String moneda;

    /** 030373-SELECCIONA-CTAMRE + 030374-VALIDA-REGISTRO. */
    @Override
    public List<CtamreRecord> process(MovimientoCORE-DEP m) {
        if (m.moneda() != codigoMoneda()) return null;             // 1 pesos, 5 dólares
        if (m.sistema() != 500) return null;

        return switch (m.funcion()) {
            case 1 -> esAltaCtamre(m) ? detalles.altas(m, autorizaciones.registra(m)) : null;
            case 2 -> detalles.eliminacion(m, autorizaciones.buscaPorAutorizacion(m.autAElimCORE-GL()));
            case 21 -> detalles.eliminacionPorProceso(m);                 // 500010
            case 22 -> detalles.eliminacionPorProcesoAut(m);              // 500030
            default -> null;
        };
    }

    private boolean esAltaCtamre(MovimientoCORE-DEP m) {
        int extnet = (m.formato() == 2) ? descripciones.indicadorExtnet(m) : 0;
        return m.status() >= 1 && m.status() <= 4
                && (m.origen() == 1 || m.origen() == 3)
                && m.formato() == 2
                && extnet == 4;
    }
}

class DetalleFactory {

    private final CatalogoNaturaleza catalogo6;   // WKS-CAT6-AFC
    private final AcumuladorCtamre acumulador;

    /** 400040-MUEVE-DATOS-CTAMRE + 400022-CARGA-DATOS-CTAMRE, una vez por clave distinta de 0. */
    List<CtamreRecord> altas(MovimientoCORE-DEP m, Autorizacion aut) {
        var out = new ArrayList<CtamreRecord>();
        for (int i = 1; i <= 5 && m.claveTransaccion(i) != 0; i++) {
            int clave = m.claveTransaccion(i);
            int naturaleza = (clave > 0 && clave < 5001) ? catalogo6.naturaleza(clave) : 0;
            BigDecimal importe = m.importe(i);                       // 9(16)V99 -> escala 2
            acumulador.alta(naturaleza, importe);

                    m.autoriza(), m.sucursalMda(), m.cuentaMda(), naturaleza, m.referencia(),

                    m.horaMov().truncatedTo(ChronoUnit.MINUTES), m.fechaMov(),
                    m.autCORE-GL(), m.moneda(), descripcion(m.status(), naturaleza)));

        return out;
    }

        String estado = (status == 1) ? "APLICADO" : "ELIMINADO";
        return switch (naturaleza) {
            case 1 -> "MOVIMIENTO %s DE CARGO".formatted(estado);
            case 2 -> "MOVIMIENTO %s DE ABONO".formatted(estado);
            case 9 -> "MOVIMIENTO %s NO CONTA".formatted(estado);
            default -> "";                                          // ninguna rama del IF: descripción vacía
        };
    }

@Component
@StepScope
public class AcumuladorCtamre {

    private static final BigDecimal TOPE_9_16_V99 = new BigDecimal("9999999999999999.99");
    private long movimientos, cargos, abonos, noContables;
    private BigDecimal importeCargos = BigDecimal.ZERO.setScale(2);
    private BigDecimal importeAbonos = BigDecimal.ZERO.setScale(2);

    /** 040040-ACUMULA-TOTALES. La suma de importes de escala 2 es exacta: no hay redondeo. */
    void alta(int naturaleza, BigDecimal importe) {
        movimientos++;                                   // ADD 1 TO WKS-NUM-TOTAL-MOV-PES
        switch (naturaleza) {
            case 1 -> { cargos++; importeCargos = tope(importeCargos.add(importe)); }
            case 2 -> { abonos++; importeAbonos = tope(importeAbonos.add(importe)); }
            case 9 -> noContables++;                     // se cuenta pero no viaja en el trailer
            default -> { }                               // naturaleza 0: solo cuenta en movimientos
        }
    }

    private static BigDecimal tope(BigDecimal v) {
        if (v.compareTo(TOPE_9_16_V99) > 0) throw new DesbordamientoAcumuladorException(v);
        return v;
    }
}

Riesgos de migración
Truncamiento al armar el detalle

500-R02-IMPORTRAN es PIC 9(14)V99 (línea 994) y recibe A00-R01-IMPORTE PIC 9(16)V99; también se truncan REFNUM (9(18) a 9(16)) y AUTORIZA (9(18) a 9(08)). Un importe mayor a 99,999,999,999,999.99 llegaría recortado al receptor sin aviso.

Naturaleza contable limitada a claves menores a 5001

400040-MUEVE-DATOS-CTAMRE (líneas 3657-3659) solo consulta el catálogo 6 para claves de 1 a 5000. Las demás salen con naturaleza 0, sin descripción y fuera de los totales de cargos y abonos del trailer.

Altas eliminadas sumadas como activas

400022-CARGA-DATOS-CTAMRE describe como MOVIMIENTO ELIMINADO las altas con estatus mayor a 1 (líneas 3990-3997), pero 040040-ACUMULA-TOTALES las suma a cargos y abonos activos sin revisar el estatus. Las cifras activas del trailer pueden incluir movimientos eliminados.

Errores de control y envío sin efecto

Todos los REWRITE de A03-CTL-ENVIO usan INVALID KEY NEXT SENTENCE (por ejemplo líneas 3033, 3159 y 3370) y un fallo de INTELARSND solo se registra en bitácora. En ambos casos el proceso sigue como si hubiera funcionado.

Fecha del header distinta a la del nombre

020500-HEADER-CTAMRE pone en 500-R01-FECPROC la fecha de máquina de seis dígitos (línea 3229), mientras que el título del archivo usa WKS-FECHA-PROCESO de CONSISDIA (línea 3101). Después de medianoche o en reproceso, header y nombre no coinciden.

Archivo sin cierre en día inhábil

El trailer y el envío exigen W88-HABIL. En día inhábil los detalles se siguen agregando pero el archivo nunca se cierra ni se envía.

Hardcodes

Prefijo CORE-GL/FILE/INTS/15122S01, códigos 000000145886 y 000000145857, textos BARRIDO DE CUENTAS CONCENTRADORAS, conversión de CSI 32 a nodo 10, monedas 1 y 5, límite de clave 5001 y ESPERACOMS de 300. Se trasladan a application.yml.
