P142 · Extracción diaria BD07→CTOREP para Teradata (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: P142.cbl (~14569 LOC · PROCEDURE L13876–14569) · Job batch CORE-DEP · BC-06

Convenciones: nombres traducidos (Unisys→legible); [P142 Lnnnn] = origen; (BR: RN-CORE-DEP-...) = regla.

Nota de alcance: P142 es data-heavy — la DATA DIVISION ocupa L1–L13875 (~95% del fuente). Solo se documenta la PROCEDURE (L13876–14569). Muchas estructuras declaradas en WORKING-STORAGE (tasas ISR, interfaces CORE-GL/S408/S272, cat-9991) NO se ejercitan en esta PROCEDURE — ver §5.

1. Resumen funcional

P142 ("PROGRAM-ID: P142", JUNIO/2021) es un extractor batch de un solo propósito: recorre secuencialmente todos los contratos del dataset DMSII CORE-DEPB01CONTRATOS (dentro de la base CORE-DEPBD07ATRIBUCTA — atributos de calificación de cuentas de captación) y genera el archivo secuencial CTOREP de registros fijos de 1200 bytes, destinado a ser enviado a Teradata para análisis de "CREDITOS CAN" (crédito captación) (BR: RN-CORE-DEP-123). El archivo lleva cabecera (TREG=1), N detalles (TREG=2) y trailer con conteo (TREG=9) (BR: RN-CORE-DEP-124).

Antes de extraer, deriva su contexto de ejecución: identifica el host (VDM vs otros) para fijar el CSI de origen (BR: RN-CORE-DEP-136), valida/proyecta la fecha de proceso desde el registro de control B02 con override opcional por parámetro de tarea (BR: RN-CORE-DEP-128), y clasifica el período como semanal/mensual vía la librería de calendario S006 LOCSUP/THECALENDAR (BR: RN-CORE-DEP-126, RN-CORE-DEP-127). El único canal de excepciones es el archivo acumulativo F02-PROBLEMAS con timestamps (BR: RN-CORE-DEP-137); no retorna errores al llamador y aborta con CALL SYSTEM DMTERMINATE ante fallas fatales. El filtro de calidad exige B01-NUM-DATO(1) = 0 ó 1; cualquier otro valor se reporta a PROBLEMAS y el registro NO se exporta (BR: RN-CORE-DEP-125).

DATA-BASE SECTION — DMSII [P142 L72–76]:

  • DB CORE-DEPBD07ATRIBUCTA — base de atributos de calificación de cuenta (ATRIBUCTA).
  • 01 CORE-DEPB02CONTROL — registro de control del lote (fecha proceso, fecha línea/siguiente día hábil).
  • 01 CORE-DEPB01CONTRATOS — dataset de contratos: fuente de la extracción. Campos clave usados en detalle: B01-CSI-CONTRATO, B01-NUM-CONTRATO, B01-FEC-PROALT/MAQALT/HOR-MAQALT, B01-FEC-PROACT/MAQACT/HOR-MAQACT, B01-IND-PANTALLA, B01-FEC-ACTPAN, B01-NUM-DATO(1..5) y 6 subcampos numéricos por grupo, B01-ALFA-DATO(1..5) y 6 subcampos alfanuméricos por grupo [P142 L14193–14270].

Layout CTOREP (WKS-CTOREP-*) — 3 tipos de registro (BR: RN-CORE-DEP-124):

  • Header WKS-CTOREP-HEADER (TREG=1): SIS-ORI="CORE-DEP", HED-FEC-GEN-ARCH (= fecha proceso), HED-CSI-ORI.
  • Detalle WKS-CTOREP-DETALLE (TREG=2): CSI-CONTRATO, CSI-COBERTURA (=WKS-CSIL), NUM-CONTRATO(12), fechas de alta/actualización, + 5 grupos numéricos (WKS-DET-NUM-, cada uno FECPROACT×2 + FECMAQACT×2 + HORMAQACT×2 + DATO + FILLER) + 5 grupos alfanuméricos (WKS-DET-ALFA-).
  • Trailer WKS-CTOREP-TRAILER (TREG=9): WKS-TRA-TOTAL = WKS-CONTADOR (registros escritos).

Constantes de identidad / hardcodes [P142 L13914–13917]: W77-USO-LIBLJ=2, PASO="P142", MTP/versión="25MTP004", ID="CORE-DEPP142".

4.1 DECLARATIVES — manejo de interrupción

PROCEDIMIENTO Manejar_Interrupcion_Corte_Archivo():   // 000-INTERRUPCIONES · [P142 L13878-13896]
  USE AS INTERRUPT PROCEDURE
  DESHABILITAR interrupciones                          // DISALLOW INTERRUPT
  SI atributo TASKVALUE(este_programa) = 1 ENTONCES     // corta archivo problemas
     SI archivo F02-PROBLEMAS está ABIERTO ENTONCES
        CERRAR F02-PROBLEMAS CON SAVE
        ESPERAR 5 segundos                              // WAIT 5
        ABRIR F02-PROBLEMAS en modo EXTEND
     SINO
        (siguiente sentencia — no-op)
  MOVER 0 A TASKVALUE(este_programa)
  HABILITAR interrupciones                              // ALLOW INTERRUPT

Handler asíncrono: cuando el operador señala TASKVALUE=1, rota el archivo de problemas (cierra+reabre en EXTEND) sin interrumpir la extracción.

Nota anti-alucinación: P142 es un extractor puro. La PROCEDURE (L13876-14569) implementa únicamente extracción B01→CTOREP + control de fecha/host + bitácora. Las reglas RN-CORE-DEP-122, 129–135 describen estructuras declaradas en la voluminosa DATA DIVISION (interfaces GL/tasas/crédito heredadas del "esqueleto" común CORE-DEP) que este programa no invoca en su ruta de ejecución; se marcan "Solo DATA" para no atribuirles lógica inexistente. Hallazgos técnicos: ⚠ código muerto 50004000-INTELAR-PROB (llamador comentado, L14158) y WAIT(5) (L14157); ⚠ antipatrón de alcance de IF WS-GRP > 0 en Num_Grp/Alf_Grp (MOVEs terminados en punto salen del scope del IF, inofensivo porque grp∈[1..5]).
