Redes de Pago
2 sistemas
SPEI / Banxico
Sistema de Pagos Electrónicos Interbancarios · Circular 14/2017 · ISO 13616
↔ BIDIRECCIONAL CORE-DEP + CORE-GL CRÍTICO
Red de pagos interbancarios en tiempo real. Banxico también provee el calendario operativo via librería THECALENDAR (P677). Corte operativo: 14:55 (campo HORSPEI en BD13).
L091_ASINCRONA (CORE-DEP) L093_ASINCRONA (CORE-DEP) P020/LINCOMS (CORE-DEP) P165 (CORE-DEP) P677 (CORE-GL) P109 (CORE-GL)
Riesgo separación
NIO (16 chars) es el identificador único Banxico — debe preservarse en el target. I11-REPLICA WAIT 1200s hardcodeado (VDM↔MTY) — riesgo timeout en cloud.
CECOBAN / ICA / TANDEM
Centro de Compensación Bancaria · Compensación interbancaria de cheques
→ OUTBOUND CORE-GL
Genera y transmite archivo TANDEM/ICA para compensación interbancaria. APL-ORI=0236 (código institución LegacyCore), APL-DES=0264, COD-SER=20 hardcodeados.
P610 F09 (CORE-GL) L020 (CORE-DEP — bridge S127)
Riesgo separación
APL-ORI=0236 es el código de institución LegacyCore en CECOBAN — punto de separación #3. Mecanismo XFER Unisys requiere equivalente en el target.

CNBV — Serie B (Reportes Prudenciales)
B-0111A balances · B-0111B movimientos
→ OUTBOUND CORE-GL GLOBAL-DEPENDENCY
Cadena: P130 (agrupador) → P131 (traductor) → PAQUETECONTABLE 90 bytes/registro → S254/PeopleSoft → CNBV. BUG activo: P108 mapea sector 15 → sector 11 siempre desde creación (RN-CORE-GL-124).

Riesgo separación #1
SETID="BNMEX" en P131: 14 ocurrencias hardcodeadas. Loop DREG-FOBA (obligación FOBAPROA 1994-1999) embebida en código. BUG-PROD sector 15→11.
CNBV — FraudLink / S711
Reporte diario de movimientos fraudulentos
→ OUTBOUND CORE-DEP
P103 (CORE-DEP) genera reporte batch diario hacia S711 via INTELARSND. Ruta: CORE-DEP/FILE/S711/FRAUDLINK/{CSI}/{FECHA}. Claves de fraude 2001/2444/2496 + BANCO=0002 hardcodeado.

SAT / Anexo 20 (CFDI Retenciones)
CFDI XML Anexo 20 · RFC-ORD · RFC-BENEF · NOM-BENEF
→ OUTBOUND CORE-DEP + CORE-GL HARDCODED
Retención IVA 16% / IVA-fronterizo 11% / ISR 0.50% hardcodeados como constantes en P020, P010, P142, P144. Campos RFC persistidos en BD10 DMSII (RFC-ORD ALPHA(13), RFC-BENEF ALPHA(18)).
P020, P010, P142, P144 (CORE-DEP)BD10 DMSII (CORE-GL)
Riesgo
IVA y exención USD hardcodeados — si SAT modifica el IVA/exención requiere recompilación; la tasa ISR se toma del catálogo S080 del sistema productivo.

Sistemas Corporativos Global / LegacyCore
4 sistemas
SCIG (Sistema Contable Integral Gráfico)
Plataforma contabilidad corporativa GlobalBank
→ OUTBOUND CORE-GL GLOBAL-SYSTEM
P130 genera MOVSCIG + MOVSCIG1; P109 genera headers CIG específicos S264/SPEI (WKS-HD264-CIG, WKS-TR264-CIG). Mecanismo: INTELARSND/ADMONXFERS.
Riesgo separación
Sistema Global — post-separación este canal debe desactivarse o redirigirse al sistema contable LegacyCore independiente.
S254 / PeopleSoft (ERP GL Corporativo)
GL corporativo downstream · SETID="BNMEX"
→ OUTBOUND CORE-GL SEP #2
P131/TRADUCTOR → PAQUETECONTABLE (90 bytes, 2 registros por movimiento GL) → S254 → CNBV. Repositorio intermedio entre CORE-GL y el regulador CNBV.
Riesgo separación #2
SETID="BNMEX" identifica la entidad LegacyCore en PeopleSoft — 14 ocurrencias en P131. Debe redirigirse al ERP independiente post-divestiture.
GlobalDirect (Cash Management Corporativo)
Portal corporativo Global · Tesorería de clientes institucionales
→ OUTBOUND CORE-GL GLOBAL-SYSTEM
BD13.B04CTLGLOBALDIR (~16M registros) — tabla de control: campos ESTATUS, REINTENTOS, NIO SPEI. Liga transacciones GlobalDirect con Banxico.
Riesgo separación
Tabla B04CTLGLOBALDIR deberá migrarse o desacoplarse. NIO SPEI en tabla Global liga Banxico con sistema Global — punto de ruptura.
Global ALR/AHR/OCM (Interface GL Pre-Separación)
Account Ledger Records · Account History · One Cash Mgmt
↔ BIDIRECCIONAL CORE-GL SEP #3
P150: interface ALR/AHR/OCM con BRANCH=484 hardcodeado (ID LegacyCore en jerarquía Global). P151: sufijo BNE en campos SWIFT (ALRINT-SWIFT-CCY-CODE-BNE).
Riesgo separación #3
BRANCH=484: identificador de LegacyCore en Global — debe desactivarse al completar divestiture. Interface activa mientras compartan infraestructura GL.

Analytics y Observabilidad
3 sistemas
Splunk (Observabilidad Operacional)
Gestión de logs y dashboarding · WFL_SPLUNK
→ OUTBOUND CORE-GL ANTIPATRÓN
P810/STSTOTALES agrega totales por sucursal/caja/banco/moneda desde MOVDIA. Acoplamiento crítico: la app de negocio conoce directamente al destino de telemetría — antipatrón a eliminar.
Target
Pipeline OpenTelemetry nativo. WFL_SPLUNK se retira; P810 reimplementado como servicio publicando a topic/stream, desacoplado del backend de observabilidad.
Teradata (Data Warehouse Analytics)
Cartera de crédito y contratos · P142/S408LINCRED
→ OUTBOUND CORE-DEP
P142/S408LINCRED extrae cartera de contratos B01CONTRATOS para carga batch en Teradata. 30+ funciones de interface. RN-CORE-DEP-136
P142 S408LINCRED (CORE-DEP)
DATALAKE (Trazabilidad SPEI)
Plataforma moderna · Solo S264/SPEI actualmente
→ OUTBOUND condicional CORE-GL
P109 genera archivo DATALAKE solo cuando W77-SISTEMA-PARAMETRO=264. No escribe para ningún otro sistema. Integración moderna incipiente.
Nota target
La exclusividad S264 sugiere integración experimental. En el target, todos los sistemas deberían alimentar el data lake sin condición de parámetro.

Mensajería · Pagos Internacionales · Antifraude
3 sistemas
IBM MQ / WebSphere (Mensajería Asíncrona)
5 copias COMS · HA VDM↔MTY · WAIT 1200s
↔ BIDIRECCIONAL CORE-DEP HARDCODED
L091/L093 implementan buffer circular MEM[0:2015] con TTL/dead-letter propietarios. I11-REPLICA VDM↔MTY con WAIT 1200s hardcodeado. L093 enruta a Fraud Manager via TIPO-PROC.
Target
Sustituir buffer propietario por broker nativo (Kafka, SQS, etc.) con TTL/DLQ estándar. Eliminar WAIT 1200s — configurar como parámetro del orquestador.
SWIFT / S703 (Pagos Internacionales)
BIC ISO 9362 · ISO 4217 · S422 contrapartes
↔ BIDIRECCIONAL CORE-DEP + CORE-GL
P109 (W77=703) → path SWIFT. P150/P151: campos ACCI-SWIFT-CCY-CODE, ALRINT-SWIFT-CCY-CODE-BNE (ISO 4217). S422: CTE-SWIFT (11c) y CTR-CODSWIFT (12c) — BIC codes clientes.

Mecanismos de entrega

7 protocolos de integración AS-IS

INTELARSND / ADMONXFERS
Distribución de ficheros propietaria Unisys MCP. Destinos: SCIG (MOVSCIG), S711 (FRAUDLINK), sistemas LATAM (LOG151-ETL/LOG151-GEN → S404).
IBM MQ via L091/L093
Mensajería asíncrona inter-nodo. L091=inbound SPEI; L093=outbound + Fraud Manager. Buffer circular MEM[0:2015] propietario.
I11-REPLICA (cross-CSI)
Replicación VDM↔MTY para alta disponibilidad SPEI. WAIT 1200s hardcodeado — riesgo en cloud.
XFER (Unisys)
Transferencia de ficheros Unisys MCP. Usado por P610 F09 para enviar archivo ICA/TANDEM a INFOICA/CECOBAN.
PAQUETECONTABLE (DMSII file)
Archivo intermedio 90 bytes/registro generado por P131. Repositorio entre CORE-GL y S254/PeopleSoft para CNBV.
THECALENDAR (lib Unisys)
Librería Unisys de calendario operativo Banxico. Usada por P677 (CORE-GL) para validar días hábiles y corte SPEI.
DATALAKE file
Fichero generado por P109 exclusivamente para S264/SPEI. Integración moderna incipiente — en el target debe generalizarse.
