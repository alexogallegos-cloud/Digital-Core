1. Resumen funcional

P168 es el auditor de cuadre de saldos CBII del sistema CORE-GL. Reconcilia, cuenta por cuenta, los saldos del archivo AHR (histórico de movimientos CBII generado por CORE-DEP, mayor auxiliar) contra los saldos del archivo ACC (saldos contables CBII). Para hacerlo construye primero un archivo indexado en memoria ACC2 a partir del ACC secuencial, lo que permite búsqueda O(1) por número de cuenta. Luego recorre el AHR ordenado por cuenta/fecha: cuando detecta un cambio de cuenta, busca en ACC2 y compara saldo LDGR-AMT con signo — si cuadra, la cuenta se omite del reporte; si difiere o está ausente en ACC, la graba en el archivo ARCH-CTAS como diferencia con ambos saldos para auditoría.

En paralelo, P168 identifica hasta 8 cuentas catalogadas como INTEL (tabla hardcodeada WKS-CUENTAS-INTELLIMATCH). Para esas cuentas genera un archivo de detalle con encabezado (saldo apertura reconstruido + saldo cierre de ACC) más un registro por cada movimiento AHR, y al finalizar lo transfiere al sistema IntelliMatch vía el canal INTELAR (INTELARSND IN ADMONXFERS). Termina con un reporte impreso de diferencias (V00-REP-SDOS) y escribe el archivo bandera ARCHIVO-P168 con la constante "BANDE-P168" para señalizar ejecución exitosa al WFL orquestador.

```
CALCULAR mm_compilacion = MOD(DIV(hora_comp, 60), 60)
CALCULAR ss_compilacion = MOD(hora_comp, 60)

// Obtener fecha máquina actual (CRONOS2K)
```

PROCEDIMIENTO Recorrer_AHR_y_Procesar_INTEL():    // 20000-LEE-AHR · [P168 L1575]
> Fase central: recorre AHR, reconcilia contra ACC2, genera INTEL para cuentas especiales.

```
MOVER 0 A indicador_fin_ahr, contador_diferencias_W77, indicador_primera_cuenta_1A

ABRIR SALIDA ARCH-INTEL, ARCH-INTEL-INTELAR
ABRIR ENTRADA ARCH-AHR
ABRIR ENTRADA ARCH-ACC2                          // abierto para acceso random

LEER ARCH-AHR AL FIN MOVER 1 A indicador_fin_ahr

SI indicador_fin_ahr = 0 ENTONCES

    // Inicializar contexto con primera cuenta
    MOVER cuenta_AHR        A cuenta_anterior, cuenta_INTEL_actual
    //       AHRST-ACCT-NBR    WKS-CUENTA-ANT    W77-CTA-INTEL

    SI W88-CTA-INTEL (primera cuenta es INTEL) ENTONCES
        MOVER 0 A indicador_encontrado_INTEL       // W77-ENCONTRE
        EJECUTAR Leer_ACC2_y_Preparar_Encabezado_INTEL    // 20200-LEE-ACC2
        EJECUTAR Calcular_Saldo_Apertura_INTEL            // 20300-CALCULA-SDOINI
```
