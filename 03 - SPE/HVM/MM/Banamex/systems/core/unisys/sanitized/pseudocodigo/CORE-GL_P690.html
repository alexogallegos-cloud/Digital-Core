P690 · LEE-MOVSNNN · Cierre definitivo de movimientos (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P690.cbl (824 LOC) · Paso de cierre batch post-conciliación · BC-18

Convenciones: nombres traducidos (Unisys→legible); [P690 Lnnnn] = línea en fuente; (BR: RN-CORE-GL-NNN) = regla de negocio.

1. Resumen funcional

P690 (PROGRAM-ID: LEE-MOVSNNN) es el programa de cierre definitivo de movimientos del ciclo batch nocturno de CORE-GL. Su única responsabilidad es recorrer el archivo de movimientos del día (A01-MOVSNNN, título dinámico MOVS{NNN}) y marcar como procesados todos los registros con FUNCION=99 (pendiente). Para cada registro elegible, transiciona su estado a FUNCION=11 + STATUS=1, estampa la fecha de contabilización oficial del día (FECCONT), el identificador del sistema procesador (SISTEMA) y le asigna un número de autorización secuencial (AUT-CORE-GL = CONTADOR – 1). El programa recibe un único parámetro del WFL caller: el número de sistema (W77-SISTEMA-PARAMETRO, 9(03)), que controla qué archivo de movimientos se abre y qué stamp se graba. La ruta del archivo y el límite máximo de registros a procesar se obtienen dinámicamente de CONSISDIA IN CORE-GL-L001; un fallo de esa llamada aborta el programa con SET MYSELF(STATUS) TO -1 antes de abrir ningún archivo.

3. Mapa de control

000000-INIC-PROGRAMA
│
├── PERFORM 020400-LIBRERIAS
│     ├── CHANGE ATTRIBUTE ... CTRLVERS, LOCSUP, LIB-DISP
│     ├── CALL "DAME_TIT IN CTRLVERS" × 2 (S080BD01CON, CORE-GLL001CTL)
│     └── CALL "CONSISDIA IN CORE-GL-L001"  ← fallo → STATUS=-1 (aborta)
│
├── PERFORM 100-BUSCA-IND-FECARCMOV VARYING W77-IND
│     └── [cuerpo vacío: EXIT] ← el VARYING avanza el índice hasta FECCON = FECARCMOV(W77-IND)
│
├── OPEN I-O A01-MOVSNNN
│
├── PERFORM 500-LEE-A01-MOVSNNN  ← lectura de cebado (salta header)
│
├── PERFORM 200-REGRABA UNTIL CONTADOR > NIVARCMOV(DIASEM) OR W77-FIN=1
│     ├── PERFORM 500-LEE-A01-MOVSNNN  ← lee siguiente registro
│     └── IF FUNCION=99: actualiza campos y REWRITE
│
├── CLOSE A01-MOVSNNN WITH SAVE
└── STOP RUN

200-REGRABA (activo)
  └── PERFORM 500-LEE-A01-MOVSNNN
      IF A00-R01-FUNCION = 99 AND W77-FIN = ZERO
        [6 asignaciones + REWRITE A00-R01-REGMOV]

210-REGRABA-REG  ⚠ [CÓDIGO-MUERTO — comentado en 000000-INIC-PROGRAMA]
  └── IF FUNCION=99 AND CONTADOR<2000000 AND W77-FIN=0
        [ADD W77-NUMREG + REWRITE + DISPLAY on error]
      PERFORM 500-LEE-A01-MOVSNNN

500-LEE-A01-MOVSNNN
  └── ADD 1 TO WKS-CONTADOR → READ A01-MOVSNNN AT END MOVE 1 TO W77-FIN

Patrón de lectura: El programa usa pre-read (priming read): lee el primer registro (header A00-R00-HDR-MOV) antes de entrar al loop. El loop lee el siguiente registro al inicio de cada iteración, garantizando que el header nunca sea evaluado con IF FUNCION=99.

> Nota técnica: el párrafo no contiene lógica propia. El PERFORM VARYING ejecuta 100- repetidamente incrementando W77-IND; el EXIT hace que el control regrese al PERFORM.
