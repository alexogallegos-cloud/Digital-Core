CORE-GL · P630 a Java 21 Spring Boot

P630 recibe un parámetro de 12 posiciones con el tipo de archivo, una fecha AAMMDD y el número de sistema. Obtiene de CORE-GLB01SISDIA el pack donde residen los movimientos del sistema y arma el título (CORE-GL)CORE-GL/FILE/{tipo}S{sistema}/{fecha} ON {pack}. Con el tipo CON abre en lectura cada archivo (CB2 y CTD solo para CORE-DEP, MOV y DES para todos), lee el primer registro y escribe su fecha en el log LJ. Con cualquier otro tipo abre ese archivo en I-O, lee el primer registro, le pone HD y la fecha del parámetro con el siglo 20 sumado, y lo reescribe.

// ---------------------------------------------------------------------------
enum TipoArchivo { CON, MOV, DES, CB2, CTD }

/** WKS-PARAMETRO: FILE X(03) + FECHA 9(06) + SISTEMA 9(03). */
record HeaderParametros(TipoArchivo tipo, LocalDate fecha, int sistema) {

    static HeaderParametros parse(String p) {
        TipoArchivo t = TipoArchivo.valueOf(p.substring(0, 3));      // falla si no es un tipo conocido
        LocalDate f = LocalDate.of(2000 + Integer.parseInt(p.substring(3, 5)),   // pivote fijo: siglo 20xx
                                   Integer.parseInt(p.substring(5, 7)),
                                   Integer.parseInt(p.substring(7, 9)));
        return new HeaderParametros(t, f, Integer.parseInt(p.substring(9, 12)));
    }
}

@Component
@RequiredArgsConstructor
class RutaArchivoMovimientos {
    private final P630Properties props;

    String titulo(TipoArchivo tipo, int sistema, LocalDate fecha, String pack) {
        return props.ruta().replace("{tipo}", tipo.name())
                .replace("{sistema:000}", "%03d".formatted(sistema))
                .replace("{fecha:yyMMdd}", fecha.format(DateTimeFormatter.ofPattern("yyMMdd")))
                .replace("{pack}", pack.strip());
    }
}
@Bean
Job headerArchivos(JobRepository repo, Step resuelvePack, Step consultaHeaders, Step actualizaHeader) {
    JobExecutionDecider modo = (job, step) -> new FlowExecutionStatus(
            job.getJobParameters().getString("tipo").equals("CON") ? "CONSULTA" : "ACTUALIZA");

    return new JobBuilder("CORE-GLP630", repo)
            .start(resuelvePack)                                  // 020400-LIBRERIAS
            .next(modo).on("CONSULTA").to(consultaHeaders)        // 020400-CONSULTA
            .from(modo).on("ACTUALIZA").to(actualizaHeader)       // 020400-ACTUALIZA
            .end()
            .build();
}

HeaderMovimientos.java · ActualizaHeaderTasklet.javarecord · Tasklet con FileChannelJava 21
/** Primeros 10 bytes del registro de 990 de A01-ERRSNNN. */
sealed interface PrimerRegistro permits PrimerRegistro.Header, PrimerRegistro.Detalle {

    /** WKS-MOV-ID-HD = "HD" + WKS-MOV-FECHD 9(08) AAAAMMDD. */
    record Header(LocalDate fecha) implements PrimerRegistro {}

    /** Mismos bytes leídos como FUNCION/FORMATO COMP + SISTEMA, PRODUCTO, ... COMP. */
    record Detalle(byte[] crudo) implements PrimerRegistro {}

    static PrimerRegistro de(byte[] r) {
        boolean esHeader = r[0] == 'H' && r[1] == 'D';
        return esHeader
                ? new Header(LocalDate.parse(new String(r, 2, 8, StandardCharsets.ISO_8859_1),
                                             DateTimeFormatter.BASIC_ISO_DATE))
                : new Detalle(r);
    }
}
@Component
@StepScope
@RequiredArgsConstructor
class ActualizaHeaderTasklet implements Tasklet {

    private static final int LONG_REGISTRO = 990;
    private final RutaArchivoMovimientos rutas;
    private final ArchivosMcp archivos;            // adaptador al almacenamiento de archivos

    @Value("#{jobParameters['tipo']}")    private String tipo;
    @Value("#{jobParameters['fecha']}")   private LocalDate fecha;    // ya con el siglo 20xx
    @Value("#{jobParameters['sistema']}") private Integer sistema;
    @Value("#{jobExecutionContext['pack']}") private String pack;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) throws IOException {
        Path p = archivos.resuelve(rutas.titulo(TipoArchivo.valueOf(tipo), sistema, fecha, pack));
        try (FileChannel ch = FileChannel.open(p, StandardOpenOption.READ, StandardOpenOption.WRITE)) {
            ByteBuffer r = ByteBuffer.allocate(LONG_REGISTRO);
            if (ch.read(r, 0) < LONG_REGISTRO) {
                throw new ArchivoVacioException(p);                     // COBOL: AT END y aun así REWRITE
            }
            if (PrimerRegistro.de(r.array()) instanceof PrimerRegistro.Header h) {
                log.info("FECHA ARCHIVO {}", h.fecha());
            } else {
                throw new SinHeaderException(p);                        // cambio deliberado frente al COBOL
            }
            r.put(0, "HD".getBytes(StandardCharsets.ISO_8859_1));
            r.put(2, fecha.format(DateTimeFormatter.BASIC_ISO_DATE).getBytes(StandardCharsets.ISO_8859_1));
            ch.write(r.rewind(), 0);                                    // REWRITE WKS-MOV-DATOS
            ch.force(true);                                             // CLOSE ... WITH SAVE
        }
        return RepeatStatus.FINISHED;
    }
}

// ---------------------------------------------------------------------------
/** 020400-CONSULTA: lista de archivos a revisar según el sistema. */
List<TipoArchivo> tiposAConsultar(int sistema) {
    return props.consulta().tiposPorSistema()
            .getOrDefault(String.valueOf(sistema), props.consulta().tiposPorDefecto());
}
@Component
@StepScope
@RequiredArgsConstructor
class ConsultaHeadersTasklet implements Tasklet {

    private final RutaArchivoMovimientos rutas;
    private final ArchivosMcp archivos;
    @Value("#{jobParameters['fecha']}")   private LocalDate fecha;
    @Value("#{jobParameters['sistema']}") private Integer sistema;
    @Value("#{jobExecutionContext['pack']}") private String pack;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) throws IOException {
        for (TipoArchivo t : tiposAConsultar(sistema)) {
            Path p = archivos.resuelve(rutas.titulo(t, sistema, fecha, pack));
            String fechaHeader = archivos.primerRegistro(p)               // OPEN INPUT + READ + CLOSE WITH RELEASE
                    .map(r -> switch (PrimerRegistro.de(r)) {
                        case PrimerRegistro.Header h -> h.fecha().toString();
                        case PrimerRegistro.Detalle d -> "SIN HEADER";
                    })
                    .orElse("ARCHIVO VACIO O INEXISTENTE");               // el COBOL repite la fecha anterior
            log.info("FECHA ARCHIVO {} : {}", t, fechaHeader);
        }
        return RepeatStatus.FINISHED;
    }
}

Riesgos de migración
Reescritura sin validar el header

020400-ACTUALIZA (líneas 400-416) no comprueba que el primer registro traiga HD ni que la lectura haya sido exitosa antes del REWRITE. En un archivo sin header se corrompe el primer movimiento.

Errores de grabación solo en DISPLAY

Un REWRITE fallido solo emite DISPLAY ERROR EN GRABAR HD (línea 415), no deja mensaje en el log LJ y el programa termina normal.

Siglo fijo

ADD 20000000 (línea 413) convierte AAMMDD a AAAAMMDD asumiendo siempre 20xx.

Fecha repetida en consulta

En 020400-DESPLIEGA (líneas 434-437) un archivo vacío hereda en el log la fecha del archivo anterior.

Archivo público y hardcodes

El FD declara SECURITYTYPE IS PUBLIC (línea 41). El prefijo (CORE-GL)CORE-GL/FILE/, la regla de CORE-DEP para CB2 y CTD y el título de respaldo de la librería L001 (línea 469) están compilados.

Pendiente de revisión SME
  • Confirmar con el SME si las validaciones nuevas en la actualización (archivo no vacío y primer registro con HD) son aceptables o si existen archivos que deben recibir header sin tenerlo.
  • Confirmar en qué pack residen los archivos DES, CB2 y CTD; P630 usa el pack de MOV para todos.
  • En modo consulta la fecha del parámetro forma parte del título, así que solo se consultan los archivos de esa fecha; validar que así se usa en la operación.
  • Confirmar quién invoca P630 (WFL de soporte u operador) para definir si en la plataforma destino debe ser un job, un endpoint administrativo o ambos.
