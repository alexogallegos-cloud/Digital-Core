P050 · Activador de Medios de Acceso / Avisos de Apertura (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: P050.cbl (1837 LOC) · PROGRAM-ID: P050LIN · Servidor COMS online (modo LINEA) · BC-05

Convenciones: nombres traducidos (Unisys→legible); [P050 Lnnnn] = número de línea en fuente; (BR: RN-CORE-DEP-NNN) = regla de negocio; // nombre_original = nombre COBOL original.

1. Resumen funcional

P050LIN es el servidor COMS online de activación de medios: recibe avisos de apertura de cuenta desde el archivo GENMDA (vía librería L010 con entry points CORE-DEPL010FECGENMDA / CORE-DEPL010USAGENMDA) y los envía al sistema externo S016 para activar tarjetas y medios de acceso asociados a cada contrato nuevo. Corre en modo LINEA como programa COMS continuo, despertando cada 5 minutos con un timer de cociente (división de minutos entre 5) y procesando dentro de ventanas horarias fijas: días hábiles 07:00–20:00; sábados 07:00–24:00; domingos 00:00–16:00 (este rango extendido de fin de semana fue incorporado el 24 de marzo de 2020 como requisito Charity III). Cada aviso se clasifica por tipo de registro (WS-O-UG-TIPO-REG): apertura normal (tipo 2) se enruta a la librería S016L428 EP B04CTsB08MDA o STA-BENEFICENCIA según el estatus del contrato; reactivación de cuenta global (tipo 4, Charity III) usa el EP STA-BENEFICENCI2. Los avisos procesados se registran en el archivo PROCMED; al agotar cada archivo GENMDA de un día, el programa cierra el archivo, genera el reporte impreso "001DETACTIVAMED" (R01-ACTMEDIOS) con totales de leídos, aceptados, rechazados, no existentes y no enviados, y abre el siguiente archivo PROCMED.
