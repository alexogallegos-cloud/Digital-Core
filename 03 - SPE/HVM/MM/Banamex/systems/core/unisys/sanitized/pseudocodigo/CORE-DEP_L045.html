Convenciones: nombres traducidos (Unisys ALGOL→legible); [L045 Lnnnn] = línea física del fuente; (BR: RN-CORE-DEP-...) = regla de rules-core-dep-algol-wfl-stubs.md.

1. Resumen funcional

L045 es plomería fina de concurrencia, no lógica de negocio: son ~40 líneas efectivas que exponen tres primitivas a los programas de la línea Teletón. Mantiene en memoria compartida un arreglo de 4 ranuras de autorización (AUTORIZACION, declarado [0:4] pero usado sólo en 1..4) y un semáforo MCP (EVENT E_USO_AUT) para serializar el registro de una autorización; ofrece además una utilería que consulta al sistema, vía DCKEYIN, si un archivo del directorio de bitácora de P045 está "IN USE". No abre ninguna base DMSII, no ejecuta transacciones y no persiste nada: todo su estado vive en la memoria de la librería mientras ésta permanece congelada [L045 L71]. El documento es corto a propósito: la fuente no da para más.

El vínculo con "Teletón" no está en el código sino en la ubicación (TELETON) y en la ruta de bitácora que la propia librería consulta, (CORE-DEP)CORE-DEP/FILE/LOG/P045/ [L045 L17]; el corpus corrobora el emparejamiento en el encabezado de P045: "LEVANTA LA LINEA TELEON P045,P046 (L045,L046)" [P045.cbl L82]. (BR: RN-CORE-DEP-881)

4.1 · Archivo_En_Uso(nombre_archivo) → entero

```
// Parámetro: nombre_archivo  // EA_INUSE — EBCDIC ARRAY [0]   [L045 L11]

DECLARAR area_comando, area_respuesta  // SCR1, SCR2 — ARRAY [0:200]   [L045 L14]

LIMPIAR area_comando CON 48"00" POR (TAMAÑO(area_comando) * 6)          [L045 L16]

COMPONER EN area_comando:
   "PD (CORE-DEP)CORE-DEP/FILE/LOG/P045/"    ⚠ [HARDCODE-SOSPECHOSO] ruta fija   [L045 L17]
   , nombre_archivo POR 25 caracteres                                     [L045 L18]

EJECUTAR_COMANDO_MCP(area_comando) DEVOLVIENDO area_respuesta   // DCKEYIN [L045 L19]

SI area_respuesta DESPLAZADA 55 caracteres = "IN USE"                     [L045 L20]
   ⚠ [HARDCODE-SOSPECHOSO] desplazamiento fijo 55 dentro de la respuesta del MCP
   Archivo_En_Uso := 1                                                    [L045 L21]
SINO
   Archivo_En_Uso := 0                                                    [L045 L23]
FIN-SI
```
« `[L045 L10-L24]` · BR: RN-CORE-DEP-881 »

> `DCKEYIN` inyecta un comando de consola del MCP (`PD` = Print Directory) y devuelve la salida textual. El acoplamiento es doble: al **texto exacto** de la respuesta del sistema operativo (`"IN USE"`) y a su **posición exacta** (offset 55). Cualquier cambio de formato de la consola MCP rompe la detección de forma silenciosa: la función devolvería `0` ("libre") ante un archivo ocupado. ⚠

4.2 · Validar_Y_Registrar_Autorizacion(ranura, autorizacion) → entero

PROCEDIMIENTO Validar_Y_Registrar_Autorizacion(ranura, autorizacion) → entero:  // VALIDAAUT · [L045 L26]
```
// Parámetros: ranura  // COPIA   — INTEGER  [L045 L27]
//             autorizacion // AUTORIZ — DOUBLE  [L045 L28]

DECLARAR contador, error   // CONTADOR, ERROR — enteros locales (ALGOL los inicializa en 0) [L045 L31]

REGISTRAR_EPILOGO Liberar_Semaforo    // EPILOG PROCEDURE LIBERA  [L045 L32]
   // se ejecutará SIEMPRE al salir del bloque, con o sin excepción

SI ranura > 0 Y ranura < 5                                         [L045 L34]
   ADQUIRIR semaforo_uso_autorizacion       // PROCURE(E_USO_AUT)  [L045 L36]

   // ---- sección crítica ----
   PARA contador := 1 HASTA 4 PASO 1                                [L045 L37]
       SI AUTORIZACION[contador] = autorizacion                     [L045 L38]
          contador := 10        // marca de "encontrado"; el PASO lo lleva a 11 y corta el ciclo [L045 L39]
       FIN-SI
   FIN-PARA

   SI contador = 11    // se salió por la marca ⇒ autorización DUPLICADA   [L045 L40]
      error := 1                                                    [L045 L41]
   SINO                // el ciclo terminó normalmente con contador = 5
      AUTORIZACION[ranura] := autorizacion                          [L045 L43]
   FIN-SI
   // ---- fin sección crítica ----

   LIBERAR semaforo_uso_autorizacion        // LIBERATE(E_USO_AUT)  [L045 L44]
SINO
   error := 2      // ranura fuera de rango: NO se adquiere el semáforo   [L045 L47]
FIN-SI

Validar_Y_Registrar_Autorizacion := error                           [L045 L48]
```
« `[L045 L26-L49]` · BR: RN-CORE-DEP-881 »

Observaciones AS-IS:

- **La detección de duplicado es global, no por ranura**: el barrido recorre las 4 ranuras buscando el mismo valor `autorizacion`, sin importar `ranura`. Si la autorización ya está registrada por *otro* proceso, el llamador recibe `1` y su ranura **no se escribe**.
- ⚠ **Idioma frágil**: la salida anticipada del ciclo se implementa mutando la variable de control (`contador := 10`) y detectando después el valor `11` (10 + el paso). Es correcto para `UNTIL 4 STEP 1`, pero se rompe en silencio si alguien cambia el límite, el paso o el valor centinela.
- ⚠ `error` nunca se inicializa explícitamente en la vía feliz; el retorno `0` depende de la inicialización a cero de las variables locales de ALGOL.
- ⚠ **Doble liberación**: el `EPILOG` `LIBERA` `[L045 L32-L33]` ejecuta `LIBERATE(E_USO_AUT)` a la salida del bloque, y la vía normal ya liberó el evento en `[L045 L44]`. Cada llamada exitosa libera el mismo `EVENT` dos veces.
- ⚠ **Liberación sin adquisición**: si `ranura` está fuera de rango (`error := 2`) **nunca se ejecutó `PROCURE`**, pero el `EPILOG` libera igual. Una llamada con parámetro inválido puede abrir la sección crítica que otro proceso tenía tomada.

4.3 · Liberar_Semaforo

PROCEDIMIENTO Liberar_Semaforo():  // EPILOG PROCEDURE LIBERA · [L045 L32]
```
LIBERAR semaforo_uso_autorizacion    // LIBERATE(E_USO_AUT)   [L045 L33]
```
« `[L045 L32-L33]` »

> Procedimiento trivial de una sentencia. Se declara como `EPILOG` dentro de `VALIDAAUT`, por lo que el compilador lo invoca automáticamente al abandonar el bloque, incluida la salida por excepción. Es la red de seguridad que evita dejar el `EVENT` tomado si el proceso cae dentro de la sección crítica — al precio de la doble liberación descrita arriba.

4.4 · Liberar_Autorizacion(ranura) → entero

PROCEDIMIENTO Liberar_Autorizacion(ranura) → entero:  // LIBERAAUT · [L045 L51]
```
// Parámetro: ranura  // COPIA — INTEGER   [L045 L52]

DECLARAR error   // ERROR — entero local (inicializado en 0 por ALGOL)  [L045 L54]

SI ranura > 0 Y ranura < 5                          [L045 L55]
   AUTORIZACION[ranura] := 0                        [L045 L56]
SINO
   error := 2                                       [L045 L58]
FIN-SI

Liberar_Autorizacion := error                       [L045 L59]
```
« `[L045 L51-L60]` · BR: RN-CORE-DEP-881 »

> ⚠ **Asimetría de concurrencia**: `LIBERAAUT` **no** ejecuta `PROCURE(E_USO_AUT)`. Escribe la tabla compartida fuera de la sección crítica que `VALIDAAUT` sí respeta. Un `LIBERAAUT` concurrente con un `VALIDAAUT` puede vaciar una ranura entre el barrido de duplicados y la escritura, o dejar registrada una autorización que ya se dio por liberada. La regla `RN-CORE-DEP-881` describe la serialización como si cubriera todo el acceso a `AUTORIZACION`; la fuente muestra que sólo cubre la mitad. « divergencia KB: RN-CORE-DEP-881 »
>
> ⚠ Tampoco valida que la ranura contenga algo, ni quién la ocupaba: `LIBERAAUT(3)` borra la ranura 3 sea de quien sea.

⚠ [CÓDIGO-MUERTO] arranque de prueba comentado con "%%":
   %% REPLACE EA_INUSE2 BY "19971201/01";    [L045 L69]
   %% FILEINUSE(EA_INUSE2);                  [L045 L70]

CONGELAR(TEMPORAL)    // FREEZE(TEMPORARY)   [L045 L71]

« [L045 L62-L72] »

FREEZE(TEMPORARY) deja la librería residente mientras haya usuarios; al desaparecer el último, la pila se descongela y la tabla AUTORIZACION se pierde. No hay recuperación tras caída: las autorizaciones vivas en el momento del reinicio desaparecen sin traza.

Las dos líneas comentadas [L045 L69-L70] revelan la única prueba de humo que existió (FILEINUSE("19971201/01"), un nombre de archivo con formato fecha AAAAMMDD/NN), y son la única pista del formato esperado en el parámetro de FILEINUSE.

5.2 Divergencias con el KB

Afirmación del KB (RN-CORE-DEP-881)Lo que muestra la fuente
"Serializa el acceso concurrente a las autorizaciones mediante EVENT E_USO_AUT (PROCURE/LIBERATE)"Cierto sólo para VALIDAAUT [L045 L36, L44]. LIBERAAUT escribe AUTORIZACION sin PROCURE [L045 L51-L60]. « divergencia KB: RN-CORE-DEP-881 »
"arreglo AUTORIZACION[0:4]"Declarado así [L045 L8], pero el índice 0 es inalcanzable: ambos guardas exigen COPIA > 0 [L045 L34, L55]. Capacidad real = 4 ranuras.
"DCKEYIN para detectar si el archivo de log está en uso"Confirmado [L045 L17-L20]; la ruta consultada es específicamente la bitácora de P045, no un archivo Teletón genérico.
"LIBERATE(E_USO_AUT) // EPILOG" (pseudocódigo del KB)El EPILOG existe [L045 L32-L33] además del LIBERATE explícito [L045 L44]: son dos liberaciones por llamada, no una.
