L040_LIGAS · Fachada de Control de Enlace hacia la Librería de Ligas CORE-DEPL039BD04 (CORE-DEP · ALGOL)

CORE-DEPLibreríaALGOL

Fuente: l040.alg (371 LOC) · Librería residente de control (FREEZE(CONTROL)) · BC — (arquitectura AS-IS, sin BC de negocio)

Convenciones: nombres traducidos (Unisys ALGOL→legible); [L040 Lnnnn] = línea física del fuente; (BR: RN-CORE-DEP-...) = regla de rules-core-dep-algol-wfl-stubs.md.

1. Resumen funcional

L040 es plomería fina de arquitectura: una fachada (proxy) de enlace, no una librería de negocio. Su propio encabezado lo declara sin ambigüedad: "LIBRERIA DE CONTROL CORE-DEPL040LIGA: CONTROLA LINKS DE LIBRERIA CORE-DEPL039BD04" [L040 L12-L14]. Los nueve procedimientos exportados son forwarders de una sola sentencia: si la bandera de enlace está activa, delegan literalmente en su homónimo _C de la librería LIGACALL (que es CORE-DEPL039BD04, resuelta por título en tiempo de ejecución); si no, devuelven 99. Ninguna resolución contrato↔tarjeta, tarjeta↔TEF o cuenta↔cuenta ocurre en este fuente — toda vive en CORE-DEPL039BD04 [L040 L16-L18].

El valor real del fuente está en dos sitios: (a) la resolución dinámica del título de CORE-DEPL039BD04 contra el catálogo de versiones CTLVER [L040 L252-L267], que permite cambiar de objeto sin recompilar a los consumidores; y (b) el bucle de control por interrupción de operador PROC_CONTROL [L040 L281-L335], que permite suspender y restablecer en caliente el enlace a CORE-DEPL039BD04 desde consola, sin bajar la línea.

Confirmación del contexto solicitado ("DA-TARJETA"): verificada en el corpus. El párrafo COBOL compartido 20000500-CORE-DEPL040-DA-TARJETA [procedur.cbl L5103] ejecuta CALL "CORE-DEPL040_DAME_TARJETA IN CORE-DEPL040LIGA" [procedur.cbl L5137]; el entry point existe en esta fuente [L040 L155] y su cuerpo se limita a reenviar a CORE-DEPL040_DAME_TARJETA_C en LIGACALL [L040 L161-L162]. Es decir: "DA-TARJETA" es el nombre del párrafo llamador en COBOL, no el del servicio en ALGOL, y el número de tarjeta lo resuelve CORE-DEPL039BD04, no L040. (BR: RN-CORE-DEP-890)

4.1 · Verificar_Version

PROCEDIMIENTO Verificar_Version():  // CHECA_VERSION · [L040 L122]
```
DECLARAR identificador_librería  = "CORE-DEPL040LIGA"   // EVA_ID_CORE-DEPL040   [L040 L125]
         version_librería        = "25MTP002"       // EVA_VER_CORE-DEPL040  [L040 L126]
         ⚠ [HARDCODE-SOSPECHOSO] identidad y versión embebidas en el objeto

COPIAR MYSELF.HOSTNAME A nombre_host   // EA_MY_HOST                     [L040 L127]

SI nombre_host = "ACYPBETA"                                              [L040 L128]
   ⚠ [HARDCODE-SOSPECHOSO] nombre de host embebido
   es_host_CDL := VERDADERO          // B_HOST_CDL                       [L040 L129]
FIN-SI

SI NO es_host_CDL                                                        [L040 L130]
   SI CHECAME(identificador_librería, version_librería) < 0   // en CTLVER [L040 L132]
      DESPLEGAR_HI("ERROR MI NOMBRE NO CORRESP. AL DE CTLVER", "E>050110<") [L040 L134-L135]
      MYSELF.STATUS := -1        // marca la tarea en error               [L040 L136]
   FIN-SI
   DESENLAZAR_LIBRERIA(CTLVER)   // DELINKLIBRARY(CTLVER)                 [L040 L138]
FIN-SI
```
« `[L040 L122-L140]` · BR: RN-CORE-DEP-890 »

Observaciones AS-IS:

- ⚠ **Bypass de control de versión por host**: en `ACYPBETA` la validación contra el catálogo `CTLVER` **no se ejecuta en absoluto**, y `CTLVER` tampoco se desenlaza (el `DELINKLIBRARY` está dentro del mismo `IF NOT B_HOST_CDL`). Una versión desalineada arranca sin protesta en ese host.
- ⚠ `MYSELF.STATUS := -1` marca la tarea como errónea pero **no interrumpe el flujo**: `CHECA_VERSION` retorna, `PROC_LEVANTA` continúa activando `B_LLAMAL039` `[L040 L274]` y la librería sigue exportando. La detección de versión incorrecta no impide operar.
- El nombre del `END OF` está mal escrito en la fuente: `END OF CHECHA_VERSION` `[L040 L140]` (comentario de cierre, sin efecto funcional).

Observaciones AS-IS:

- ⚠ **Colisión de espacio de códigos**: `99` significa "enlace a CORE-DEPL039BD04 suspendido", pero se devuelve por el mismo canal que los códigos propios del servicio remoto. Si CORE-DEPL039BD04 usa `99` para algún resultado de negocio, el llamador no puede distinguir "no hay servicio" de ese resultado. `[NO-DETERMINADO]` — el catálogo de códigos de CORE-DEPL039BD04 no está en esta fuente.
- ⚠ **Los buffers de salida no se tocan en la rama degradada**: con `B_LLAMAL039 = FALSE` el llamador recibe `99` y su `EA_SALIDA` **intacto** (contenido previo, posiblemente de una llamada anterior). El fuente no lo blanquea.
- `CORE-DEPL040_CONINFOCTE` está declarado físicamente **después** de `PROC_CONTROL` `[L040 L337]`, fuera del bloque contiguo de los demás entry points: rastro de una adición posterior.

4.3 · Resolver_Titulo_De_L039

PROCEDIMIENTO Resolver_Titulo_De_L039():  // PROC_DAME_TIT_CORE-DEPL039 · [L040 L252]
```
DECLARAR identificador_L039 = "CORE-DEPL039BD04"    // EVA_ID_CORE-DEPL039   [L040 L255]
         título_resuelto[0:71]                   // EA_TIT            [L040 L256]
         resultado                               // RESULT — ⚠ declarado y nunca usado [L040 L257]

SI DAME_TIT(identificador_L039, título_resuelto) < 0    // consulta a CTLVER  [L040 L259]
   DESPLEGAR("ERROR CALL CTLVER CORE-DEPL039BD04")                          [L040 L261]
   // ⚠ no aborta, no marca MYSELF.STATUS, no apaga B_LLAMAL039
SINO
   REEMPLAZAR LIGACALL.TITLE POR título_resuelto POR 72 caracteres      [L040 L264]
   // enlace BYTITLE diferido: se fija el objeto físico de CORE-DEPL039BD04
FIN-SI

⚠ [CÓDIGO-MUERTO]  % DELINKLIBRARY(CTLVER);                            [L040 L266]
```
« `[L040 L252-L267]` · BR: RN-CORE-DEP-890 »

> ⚠ `[DESCARTE-SILENCIOSO]` Si `CTLVER` no resuelve el título, la única consecuencia es un renglón de bitácora. `B_LLAMAL039` queda (o se pone) en `TRUE` y `LIGACALL.TITLE` conserva su valor anterior — vacío en el arranque inicial, u obsoleto tras un HI 2. Los entry points seguirán intentando delegar sobre un enlace mal resuelto; el fallo se manifestará más tarde y en otro sitio.
>
> ⚠ `[CÓDIGO-MUERTO]` `% DELINKLIBRARY(CTLVER);` `[L040 L266]` está comentado. Combinado con `CHECA_VERSION`, que **sí** desenlaza `CTLVER` `[L040 L138]` antes de que `PROC_DAME_TIT_CORE-DEPL039` lo use `[L040 L273-L275]`, la reactivación por HI 2 `[L040 L301]` vuelve a invocar `DAME_TIT` sobre una librería ya desenlazada — el MCP la re-enlazará por `FUNCTIONNAME`. Comportamiento dependiente del sistema: `[NO-DETERMINADO]`.

4.4 · Levantar_Enlace

PROCEDIMIENTO Levantar_Enlace():  // PROC_LEVANTA · [L040 L270]
```
EJECUTAR Verificar_Version                  // CHECA_VERSION          [L040 L273]
enlace_a_L039_activo := VERDADERO           // B_LLAMAL039 := TRUE    [L040 L274]
EJECUTAR Resolver_Titulo_De_L039            // PROC_DAME_TIT_CORE-DEPL039 [L040 L275]
LLAMAR CORE-DEPL040_99_LEVANTA_C EN LIGACALL    // arranque del lado remoto [L040 L276]
```
« `[L040 L270-L278]` · BR: RN-CORE-DEP-890 »

> ⚠ **Orden invertido**: la bandera de enlace se enciende `[L040 L274]` **antes** de resolver el título `[L040 L275]`. Entre ambas sentencias existe una ventana en la que un entry point concurrente delegaría sobre un `LIGACALL` sin título. Con `SHARING = PRIVATE` la ventana es por instancia, pero no es nula.
>
> `CORE-DEPL040_99_LEVANTA_C` `[L040 L79-L80]` es un procedimiento **sin parámetros ni retorno** (`PROCEDURE`, no `INTEGER PROCEDURE`) del lado CORE-DEPL039BD04: es su rutina de arranque/inicialización. Su efecto es `[NO-DETERMINADO]` desde esta fuente.

4.5 · Bucle_De_Control_Operador

PROCEDIMIENTO Bucle_De_Control_Operador():  // PROC_CONTROL · [L040 L281]
```
DECLARAR evento, numero_hi, usuarios_libreria   // I_EVENTO, I_NUM_HI, LIB_USERS [L040 L284-L286]

usuarios_libreria := 1        // arranque optimista                     [L040 L287]

MIENTRAS numero_hi ≠ 4  Y  usuarios_libreria ≠ 0                        [L040 L288]
   // HI 4 = "DESABILITA CORE-DEPL040LIGA": no tiene rama CASE propia; corta el bucle aquí
   evento := ESPERAR_Y_REINICIAR(timeout 2 s, MYSELF.EXCEPTIONEVENT)     [L040 L290]
   // WAITANDRESET((2), ...) → 1 = venció el timeout ; 2 = llegó la interrupción de operador
   usuarios_libreria := MYSELF.LIBRARYUSERS   // ¿queda alguien enlazado? [L040 L291]

   SEGÚN evento                                                          [L040 L292]
      CASO 2:   // interrupción de operador (HI)                         [L040 L294]
         numero_hi := MYSELF.TASKVALUE   // el operador transporta el nº en TASKVALUE [L040 L295]

         SEGÚN numero_hi                                                 [L040 L296]
            CASO 1:   // SUSPENDER la liga con CORE-DEPL039BD04
               DESPLEGAR_HI("SE SUSPENDE LIGA A L039", "E>041001<")      [L040 L298]
               enlace_a_L039_activo := FALSO                             [L040 L299]
               DESENLAZAR_LIBRERIA(LIGACALL)                             [L040 L300]

            CASO 2:   // REHACER la liga
               EJECUTAR Resolver_Titulo_De_L039                          [L040 L301]
               DESPLEGAR_HI("SE HACE LIGA A L039", "E>041001<")          [L040 L302]
               enlace_a_L039_activo := VERDADERO                         [L040 L303]
```
