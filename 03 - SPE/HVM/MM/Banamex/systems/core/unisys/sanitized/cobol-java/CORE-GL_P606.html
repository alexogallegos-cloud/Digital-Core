CORE-GL · P606 a Java 21 Spring Boot

P606 (PROGRAM-ID LEE-ARCHMOVYDES) recibe sistema, fecha, ventana de fecha y hora, sucursal, caja y clave de transacción. Abre el archivo diario de movimientos CORE-GL del sistema, carga del catálogo S080 523 la tabla de naturalezas de cada clave y, según qué parámetros vienen informados, aplica uno de doce filtros. Por cada movimiento seleccionado escribe una línea CSV por cada una de sus hasta cinco claves e importes y, al terminar, envía el archivo por INTELAR. El archivo de datos adicionales se abre pero no se lee.

/** A00-R01-REGMOV (450 bytes, COMP). Solo los campos que P606 usa o que definen la forma del registro. */
public record MovimientoCORE-GL(
        int funcion, int formato, int sistema,
        int producto,              // REDEFINES: TIPOCREDITO / TIPO-PROD según sistema
        int instrumento,           // REDEFINES: PORTAFOLIO / FONDO
        int tipoMovimiento,
        int libroContable,         // REDEFINES IND-CONTA; el catálogo de valores no está en P606
        List<ClaveImporte> claves, // CVEIMP-OC: OCCURS 5 TIMES, se corta en la primera clave 0
        int moneda, int origen,
        int fecMov, int horMov,    // 9(08) AAAAMMDD / 9(06) HHMMSS, COMP
        int fecCont, int fecVal,
        int sucursalInicial, int cajaInicial,
        int status) {

    /** A00-R01-ELE-CVEIMP. ESQCON se redefine como TM (tipo de movimiento contable). */
    public record ClaveImporte(int claveTransaccion,       // 9(06) COMP
                               int indicadorLey,
                               int esquemaContable,
                               BigDecimal importe,          // 9(16)V99 COMP -> escala 2
                               int claveDesvio, int guiaDesvio) {}

    static List<ClaveImporte> claves(ClaveImporte[] ocurrencias) {
        var r = new ArrayList<ClaveImporte>(5);
        for (var c : ocurrencias) {
            if (c.claveTransaccion() == 0) break;          // UNTIL A00-R01-CVETRAN(W77-IND) = 0
            r.add(c);
        }
        return List.copyOf(r);
    }
}

@Component
@RequiredArgsConstructor
public class InicioP606Tasklet implements Tasklet {        // 00050-INICIO

    private final ControlDiarioClient control;             // CONSISDIA IN LIB-CONTROL (B01SISDIA)
    private final P606Properties props;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        var p = ParametrosP606.de(ctx);                     // nueve parámetros USING
        var b01 = control.consulta(p.sistema());

        // Corrección de orden: primero se resuelve la fecha y después se arman los títulos.
        // En el fuente el MOVE a WKS-CORE-GL-FEMOV (línea 2024) ocurre antes del default (línea 2076).
        LocalDate fecha = p.fecha().orElse(b01.fechaProceso());
        LocalDate fechaFin = (p.horaFin() > 0 && p.fechaFin().isEmpty())
                ? b01.fechaProceso() : p.fechaFin().orElse(null);

        var exec = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        exec.put("tituloMovimientos", props.titulo(props.entrada().movimientos(),
                p.sistema(), props.compatibilidadFechaCero() ? null : fecha, b01.pack()));
        exec.put("fechaFin", fechaFin);
        return RepeatStatus.FINISHED;
    }
}
@Service
@RequiredArgsConstructor
public class CatalogoTransaccionesService {             // 00100-CATALOGOS

    private final CatalogoS080Client s080;              // L710_CONSUL_DETALLE IN S080BD01CON
    private final P606Properties props;                 // catalogo-maestro: 523, clave: 20

    public Optional<DescriptorCatalogo> buscaDescriptor(int sistema) {
        var consulta = ConsultaL710.de(props.catalogoMaestro(), props.clave()).conLlave1(sistema);
        while (true) {
            var r = s080.consulta(consulta);
            if (r.resultado() != 0 && r.resultado() != 1) {
                log.warn("NO SE LOCALIZO EL CATALOGO DE TRANSACIONES");      // W77-EOF = 2
                return Optional.empty();
            }
            if (r.dato(2) == 1) {
                return Optional.of(new DescriptorCatalogo(r.dato(3), r.dato(4), r.dato(5)));  // tipo, número, formato
            }
            consulta = consulta.siguiente(r);           // continúa la lectura desde la última llave
        }
    }

    /** 00120-CAT-TRANS: si no hay descriptor, el fuente sigue sin tabla de naturalezas. */
    public TablaNaturalezas cargaTabla(int sistema) {
        return buscaDescriptor(sistema)
                .map(d -> cargaTransacciones(sistema, d))
                .orElse(TablaNaturalezas.vacia());       // mismo efecto que no ejecutar 00120
    }
}

/** 00200-PROC: cada combinación de parámetros presentes elige un filtro. */
public sealed interface FiltroMovimientos extends Predicate<MovimientoCORE-GL>
        permits PorDia, PorSucursal, PorSucursalCaja, DesdeHora, PorRango,
                PorSucursalDesdeHora, PorSucCajaDesdeHora, PorMovDesdeHora,
                PorSucCajaRango, PorSucursalRango, PorClave, PorClaveYFecha {

    static Optional<FiltroMovimientos> de(ParametrosP606 p) {
        var firma = p.firma();   // qué parámetros vienen en cero y cuáles no, en el orden del IF
        return Optional.ofNullable(switch (firma) {
            case "0000000" -> new PorDia();
            case "0000100" -> new PorSucursal(p.sucursal());
            case "0000110" -> new PorSucursalCaja(p.sucursal(), p.caja());
            case "1100000" -> new DesdeHora(p.fechaIni(), p.horaIni());
            case "1111000" -> new PorRango(p);
            // ... siete combinaciones más, una por rama del IF anidado
            default -> null;     // WRITE REG-REPORTE FROM WKS-LINEA-ERROR
        });
    }
}
/** 01200-CON-X-RANGO. */
public record PorRango(int fecIni, int horIni, int fecFin, int horFin) implements FiltroMovimientos {

    @Override
    public boolean test(MovimientoCORE-GL m) {
        if (m.funcion() != 1) return false;
        if (fecFin > fecIni) {
            // Varios días: el filtro de STATUS y ORIGEN está comentado en el fuente (líneas 2394-2395).
            return (m.fecMov() == fecIni && m.horMov() >= horIni)
                || (m.fecMov() > fecIni && m.fecMov() < fecFin)
                || (m.fecMov() == fecFin && m.horMov() <= horFin);
        }
        if (fecFin == fecIni) {
            // Un solo día: aquí sí se exige STATUS = 1 y la fecha solo se acota por abajo.
            return m.status() == 1
                && m.fecMov() >= fecIni
                && m.horMov() >= horIni && m.horMov() <= horFin;
        }
        return false;    // fecha final anterior a la inicial: no se selecciona nada y no hay aviso
    }
}
/** 01600-CON-X-SUC-TIEMPO, traducido tal como está escrito. */
public record PorSucursalRango(int fecIni, int horIni, int fecFin, int horFin, int suc)
        implements FiltroMovimientos {

    @Override
    public boolean test(MovimientoCORE-GL m) {
        if (m.funcion() != 1 || m.sucursalInicial() != suc) return false;
        if (fecFin > fecIni) {
            return (m.fecMov() >= fecIni && m.horMov() >= horIni)      // no acota por fecha final
                || (m.fecMov() > fecIni && m.fecMov() < fecFin)
                || (m.fecMov() <= fecFin && m.horMov() <= horFin);     // no acota por fecha inicial
        }
        if (fecFin == fecIni) {
            return m.status() == 1 && (m.origen() == 1 || m.origen() == 2)
                && m.fecMov() >= fecIni
                && (m.horMov() >= horIni || m.horMov() <= horFin);     // siempre verdadero si horIni <= horFin
        }
        return false;
    }
}

/** 01600-LEE-CORE-GLMOVANT, 01700-CONSULTA-MOVTOS y 02000-MUEVE-DATOS. */
@Component
@StepScope
@RequiredArgsConstructor
public class ExtraeMovimientoProcessor implements ItemProcessor<MovimientoCORE-GL, List<LineaExtMov>> {

    private final FiltroMovimientos filtro;
    private final TablaNaturalezas naturalezas;          // WKS-GRUPO-PARAM OCCURS 10000
    @Value("#{jobParameters['claveTransaccion']}") private Integer claveParam;   // 0 = todas

    @Override
    public List<LineaExtMov> process(MovimientoCORE-GL m) {
        if (!filtro.test(m)) return null;
        return m.claves().stream()
                .filter(c -> claveParam == 0 || c.claveTransaccion() == claveParam)   // 02000-VAL-CVETRAN
                .map(c -> {
                    int clave = c.claveTransaccion();
                    if (clave > 9999) {                    // WKS-DET-CLAVE es PIC 9(04): el MOVE truncaría
                        throw new ClaveFueraDeRangoException(m, clave);
                    }
                    return LineaExtMov.de(m, c, naturalezas.en(clave));   // WKS-PT-*(WKS-DET-CLAVE)
                })
                .toList();
    }
}

Riesgos de migración
Fecha por defecto que no llega al archivo

WKS-PARAM-FECHA se copia al título de los archivos en la línea 2024 y el default desde B01SISDIA se aplica en la línea 2076, cuando ya no se usa. Con fecha cero el programa busca el archivo con fecha 000000.

Condición horaria siempre verdadera

En 01600-CON-X-SUC-TIEMPO, caso de un día (líneas 2571-2574), la hora se evalúa con OR entre el límite inferior y el superior, de modo que cualquier hora pasa. En el caso de varios días (líneas 2547-2558) los términos no acotan bien la fecha.

Filtros de estatus y origen comentados de forma parcial

Las condiciones STATUS = 1 y ORIGEN 1 o 2 están comentadas en las consultas de varios días y en las de día completo, pero activas en las de un solo día con hora. El mismo movimiento puede aparecer o no según cómo se pidió la consulta.

Truncamiento de clave usada como subíndice

A00-R01-CVETRAN es PIC 9(06) y se mueve a WKS-DET-CLAVE PIC 9(04) (línea 2636), que luego indexa la tabla de 10,000 naturalezas (líneas 2641-2643).

Errores que no detienen el proceso

Si no se encuentra el catálogo 523 o falla el envío INTELAR, solo se escribe en la bitácora. Con parámetros inválidos el reporte ni se cierra con SAVE ni se envía.

Identificación incorrecta en bitácora

El programa se registra como PASO-LJ = "P726" (línea 2013), no como P606; los mensajes de esta ejecución en la bitácora aparecen con otro número de programa.
