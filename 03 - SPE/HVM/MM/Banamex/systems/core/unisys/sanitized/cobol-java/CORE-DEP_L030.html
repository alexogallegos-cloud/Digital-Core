La librería exporta cuatro entry points. CORE-DEPL030INICIO da de alta o reinicia la llave usuario, paso y copia de un programa. CORE-DEPL030PROCESO recibe el número de proceso, si es proceso o subproceso, si es inicio o fin, la hora y 24 caracteres de información variable; valida la secuencia de inicio y fin, toma el tiempo de reloj con TIME(11) y, al fin, acumula transcurrido, número de transacciones, último, máximo y mínimo. CORE-DEPL030CONSUL y CORE-DEPL030CONSULNVA devuelven esos acumulados en un área EBCDIC de posiciones fijas, convertidos a HHMMSScc y transacciones por segundo. Todo vive en arreglos LONG ARRAY que se redimensionan en caliente; nada se persiste.

/** Estado que en ALGOL vive en LONG ARRAY globales de la librería compartida por todos. */
@Component
public class TiemposRegistry {

    /** LA_LLAVE: usuario 9(4) + paso 9(3) + copia 9(2). */
    public record Llave(int usuario, int paso, int copia) {}

    /** LA_PROCESO: proceso y subproceso en curso por llave. */
    static final class EnCurso {
        int proceso, subproceso;          // 0 = ninguno
        String nombreProceso = "", nombreSubproceso = "";
        int hora;                         // HHMMSS informada por el llamador
        String infoVariable = "";         // 24 caracteres
    }

    /** LA_TIMEXPROC / LA_TIMEXPROC_ANT: acumulados por llave y número de proceso. */
    final Map<Llave, EnCurso> enCurso = new ConcurrentHashMap<>();
    final Map<Llave, ConcurrentSkipListMap<Integer, Acumulado>> porProceso = new ConcurrentHashMap<>();

    /** LA_PROCMAXMIN: tiempos de subprocesos de la corrida más larga y más corta de cada proceso. */
    final Map<ClaveProceso, MaxMinSubprocesos> maxMin = new ConcurrentHashMap<>();

    public record ClaveProceso(int proceso, Llave llave) {}   // 1000000000 * proceso + llave
}
/** EA_INPUT de CORE-DEPL030PROCESO: 54 caracteres EBCDIC de posiciones fijas. */
public record SolicitudProceso(
        TiemposRegistry.Llave llave,   // [0..8]   usuario(4) paso(3) copia(2)
        int proceso,                   // [9..11]
        Tipo tipo,                     // [12]     1 proceso, 2 subproceso
        Evento evento,                 // [13]     1 inicio, 2 fin
        int hora,                      // [14..19] HHMMSS
        String infoVariable,           // [20..43] 24 caracteres
        String nombreProceso) {        // [44..53] 10 caracteres

    public enum Tipo { PROCESO, SUBPROCESO }
    public enum Evento { INICIO, FIN }

    /** Los valores fuera de rango se conservan como null para devolver los códigos 4 y 8. */
    public static SolicitudProceso parse(byte[] ebcdic) {
        String s = new String(ebcdic, Charset.forName("Cp1047"));
        var llave = new TiemposRegistry.Llave(Integer.parseInt(s.substring(0, 4)),
                Integer.parseInt(s.substring(4, 7)), Integer.parseInt(s.substring(7, 9)));
        Tipo tipo = switch (s.charAt(12)) { case '1' -> Tipo.PROCESO; case '2' -> Tipo.SUBPROCESO; default -> null; };
        Evento ev = switch (s.charAt(13)) { case '1' -> Evento.INICIO; case '2' -> Evento.FIN; default -> null; };
        return new SolicitudProceso(llave, Integer.parseInt(s.substring(9, 12)), tipo, ev,
                Integer.parseInt(s.substring(14, 20)), s.substring(20, 44), s.substring(44, 54));
    }
}

@Service
@RequiredArgsConstructor
public class TiemposProcesoService {

    private final TiemposRegistry reg;

    /** CORE-DEPL030INICIO: si la llave existe se limpian sus acumulados; si no, se da de alta. */
    public int inicio(byte[] eaInput) {
        var llave = SolicitudProceso.llaveDe(eaInput);
        reg.enCurso.put(llave, new TiemposRegistry.EnCurso());
        reg.porProceso.put(llave, new ConcurrentSkipListMap<>());
        reg.maxMin.keySet().removeIf(k -> k.llave().equals(llave));   // LA_PROCMAXMIN de la llave
        return 0;   // el original no asigna resultado al procedimiento
    }
}
/** CHECAPROCESO: devuelve el mismo código numérico que la librería (0 = válido). */
int valida(SolicitudProceso s, TiemposRegistry.EnCurso c) {
    if (c == null) return 1;                               // USER, PASO, COPIA NO DADO DE ALTA
    if (s.tipo() == null) return 8;                        // TIPO DE PROCESO INVALIDO
    return switch (s.tipo()) {
        case PROCESO -> {
            if (s.evento() == null) yield 4;
            yield switch (s.evento()) {
                case INICIO -> c.proceso > 0 ? 2 : 0;      // ya hay proceso en curso
                case FIN    -> c.proceso == 0 ? 3 : 0;     // no hay proceso que terminar
            };
        }
        case SUBPROCESO -> {
            if (c.proceso == 0) yield 7;                   // subproceso sin proceso en curso
            if (s.evento() == null) yield 4;
            yield switch (s.evento()) {
                case INICIO -> c.subproceso > 0 ? 5 : 0;
                case FIN    -> c.subproceso == 0 ? 6 : 0;
            };
        }
    };
}
/** Acumulado por llave y proceso (LA_TIMEXPROC). */
public final class Acumulado {
    Duration total = Duration.ZERO, ultimo = Duration.ZERO;
    Duration maximo = Duration.ZERO, minimo = Duration.ZERO;
    long transacciones;
    long inicioNanos;
    int horaMaximo, horaMinimo;
    String infoMaximo = "", infoMinimo = "";

    void inicia() { inicioNanos = System.nanoTime(); }   // TIME(11) * 2.4 en microsegundos

    /** LLENAARRAYS, rama FIN. Con un reloj monotónico no hay cruce de medianoche que corregir. */
    boolean termina(int hora, String info) {
        Duration d = Duration.ofNanos(System.nanoTime() - inicioNanos);
        total = total.plus(d);
        transacciones++;
        ultimo = d;
        boolean esMax = d.compareTo(maximo) > 0;
        if (esMax) { maximo = d; horaMaximo = hora; infoMaximo = info; }
        if (minimo.isZero() || d.compareTo(minimo) < 0) { minimo = d; horaMinimo = hora; infoMinimo = info; }
        return esMax;
    }
}
// Recomendación: publicar además cada duración en un Timer de Micrometer
// ("core-dep.proceso", tags llave y proceso) para que el monitor lea percentiles.
/** RESIZEMAXMIN + REZISE_MAXMIN: alta atómica de la entrada de máximos y mínimos. */
MaxMinSubprocesos maxMinDe(TiemposRegistry.ClaveProceso clave) {
    // computeIfAbsent hace búsqueda y alta en una sola operación atómica, a diferencia del
    // MASKSEARCH fuera del LOCK (LK_MAXMIN) del original.
    return reg.maxMin.computeIfAbsent(clave, k -> new MaxMinSubprocesos());
}

/** CONTIMEXPROC (función 1): procesos con transacciones a partir de 'siguiente', hasta 'cuantos'. */
public PaginaTiempos consulta(TiemposRegistry.Llave llave, int siguiente, int cuantos) {
    var mapa = reg.porProceso.get(llave);
    if (mapa == null) return PaginaTiempos.error(1);
    var filas = mapa.tailMap(siguiente, false).entrySet().stream()
            .filter(e -> e.getValue().transacciones > 0)
            .limit(cuantos)
            .map(e -> {
                var a = e.getValue();
                double ultSeg = a.ultimo.toNanos() / 1e9, totSeg = a.total.toNanos() / 1e9;
                return new FilaTiempos(e.getKey(), a.nombre, Hmscc.de(a.total), a.transacciones,
                        ultSeg > 0 ? (long) (1 / ultSeg) : 99_999_999L,              // TXSEG
                        totSeg > 0 ? (long) (a.transacciones / totSeg) : 99_999_999L, // TXSEGPRO
                        a.horaMaximo, Hmscc.de(a.maximo), a.infoMaximo);
            })
            .toList();
    boolean fin = filas.size() < cuantos || filas.isEmpty()
            || mapa.higherKey(filas.get(filas.size() - 1).proceso()) == null;
    return new PaginaTiempos(0, fin, filas);                 // DF_O_CON_FIN
}

Riesgos de migración
Índice fuera de rango al reiniciar una llave

En CORE-DEPL030INICIO el ciclo de la línea 295 llega hasta SIZE(...) en lugar de SIZE(...) - 1 sobre LA_PROCMAXMIN; puede provocar una falla de índice dentro de la librería compartida.

Campo equivocado en la consulta

La línea 678 escribe en DF_O_CON_TXSEG cuando debería escribir en DF_O_CON_TXSEGPRO; el monitor muestra una tasa incorrecta cuando el tiempo total es cero.

Concurrencia parcial

La librería es SHAREDBYALL, pero solo el alta de llaves y de máximos y mínimos toma interlock, y la búsqueda de máximos y mínimos se hace fuera del candado. Los RESIZE de LA_TIMEXPROC y todas las actualizaciones de acumulados se hacen sin protección.

Métricas que siempre valen cero

Los tiempos de E/S y de proceso están deshabilitados (líneas 466-467) pero se siguen acumulando y devolviendo en la consulta.

Estado solo en memoria

Los acumulados se pierden si la librería se descongela o el sistema se reinicia; no hay histórico ni persistencia.
