CORE-GL · P199 a Java 21 Spring Boot

Obtiene la fecha de proceso de la librería de control de CORE-GL, carga del catálogo 6 de S080 las claves de transacción aplicables con su naturaleza, abre la base con hasta seis reintentos y retoma la lectura de MOVS desde el registro guardado en CTLP199. Cada movimiento de función 1 de la sucursal 342 y caja 36 genera hasta cinco altas en B08 con status AC, una por clave; las funciones 2, 21 y 22 marcan como CA los registros que corresponden a una autorización, a un proceso o a un rango de autorizaciones. Mantiene totales por BIN de tarjeta en memoria, confirma la transacción y el punto de reinicio cada 20,000 operaciones y al final imprime el listado de totales.

@Bean
Job migracionCaptacion(JobRepository repo, Step fechaProceso, Step catalogos,
                       Step diaMigracion, Step migra, Step totales) {
    return new JobBuilder("CORE-GLP199", repo)
            .start(fechaProceso)              // 204000-LIBRERIAS
            .next(catalogos)                  // 206200-CATALOGO6
            .next(diaMigracion)               // 206400-CATALOGO1565, desactivado por propiedad
                .on("NO_MIGRACION").end()     // equivalente a W88-NO-MIGRACION y 602000-TERMINA
            .from(diaMigracion).on("*").to(migra)
            .next(totales)                    // 480000-GUARDA-TOTALES
            .end().build();
}

class FechaMigracionTasklet implements Tasklet {

    private final ControlCORE-GLClient control;   // CONSISDIA IN CORE-GL-L001

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        JobParameters p = ctx.getStepContext().getStepExecution().getJobParameters();
        String sistema = p.getString("sistema");                  // W77-PARAMETRO

        SistemaDia dia = control.consisdia(sistema, 1)
                .orElseThrow(() -> new ProcesoAbortadoException(
                        "NO PUEDO OBTENER FECHA DE PROCESO"));   // el fuente no se detiene aquí

        // TASKVALUE > 0 al lanzar el programa sustituye la fecha de la librería de control.
        LocalDate fecha = Optional.ofNullable(p.getLocalDate("fechaReproceso"))
                .orElse(dia.fecPro());
        ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext()
           .put("fechaProceso", fecha);
        ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext()
           .put("packMovs", dia.nomPacMov());
        return RepeatStatus.FINISHED;
    }
}

@Component
@RequiredArgsConstructor
class MovimientoMigracionRouter implements ItemWriter<MovimientoCORE-DEP> {

    private final AltaMigracionHandler altas;           // 462000-VALIDA-MIG
    private final CancelacionMigracionHandler bajas;    // 464000-CANCELA y función 2

    @Override
    public void write(Chunk<? extends MovimientoCORE-DEP> chunk) {
        for (MovimientoCORE-DEP m : chunk) {
            switch (m.funcion()) {
                case 21, 22 -> bajas.porProceso(m);               // sin filtro de sucursal: está comentado
                case 2      -> bajas.porAutorizacion(m.autAElimCORE-GL());
                default     -> altas.registra(m);                 // la función 1 se filtra adentro
            }
        }
        // Al cerrar el chunk: END-TRANSACTION AUDIT, REWRITE de CTLP199 y BEGIN-TRANSACTION.
    }
}

@Component
@RequiredArgsConstructor
class AltaMigracionHandler {

    private final MigracionCaptacionRepository b08;     // CORE-GLB08TDMIGCAP
    private final CatalogoClavesMigracion catalogo;
    private final TotalesPorBin totales;
    private final FiltroProperties filtro;

    void registra(MovimientoCORE-DEP m) {
        if (m.sucTran() != filtro.sucursalTransaccion() || m.cajaTran() != filtro.cajaTransaccion()) return;
        for (int occ = 1; occ <= 5; occ++) {                         // A00-R01-CVEIMP-OC OCCURS 5
            int clave = m.cveTran(occ);
            if (clave == 0) break;                                   // MOVE 6 TO WKS-NUM-OCURR
            var tarjeta = Tarjeta.de(m.mdaCta());                     // 9(16): BIN 9(06) + cuenta 9(10)
            boolean existe = b08.existe(m.fechaMigracion(), tarjeta.bin(), tarjeta.cuenta(),
                                        m.autCORE-GL(), occ);           // FIND FIRST B08SXFECTAR
            if (m.funcion() == 1 && !existe && catalogo.clave(clave).isPresent()) {
                b08.save(MigracionCaptacion.activa(m, occ));          // STATUS "AC"
                totales.suma(tarjeta.bin(), catalogo.clave(clave).get(), m.importe(occ));
            }
        }
    }
}

/** Tabla WKS-CVES-BIN: hasta 10 BIN con contadores CEROS, CON ABONO y SOBREGIRO. */
@Component
class TotalesPorBin {

    private static final int MAX_BINS = 10;                  // p199.totales.max-bins
    private final Map<String, Totales> porBin = new LinkedHashMap<>();

    /** 462258-RESTA-A-SDO. La naturaleza debe salir de la clave del registro cancelado. */
    void resta(String bin, ClaveMigracion claveDelRegistro, BigDecimal importe) {
        Totales t = porBin.get(bin);
        if (t == null) return;                               // AT END NEXT SENTENCE
        if (importe.signum() == 0) {
            t.ceros().decrementa();
        } else if (claveDelRegistro.naturaleza() == 9) {
            t.sobregiro().resta(importe);                    // admite negativo, a diferencia del PIC 9(16)V99
        } else {
            t.conAbono().resta(importe);
        }
    }
}

            }
        });

Riesgos de migración
Interruptor diario de migración desactivado

En 200000-INICIO (líneas 1767-1770) la carga del catálogo 1565 y la terminación por W88-NO-MIGRACION están comentadas. P199 migra cualquier día en que se ejecute.

Fecha de proceso aceptada aunque CONSISDIA falle

El punto de la línea 1828 cierra el IF y el MOVE de la fecha de la línea 1829 se ejecuta siempre. SET MYSELF(STATUS) TO -1 no detiene el programa.

Totales por BIN con naturaleza equivocada y sin signo

462258-RESTA-A-SDO usa WKS-NUM-CVETRANS, que las cancelaciones no actualizan, y descuenta sobre acumuladores sin signo. El listado de totales puede mostrar importes positivos donde deberían ser negativos.

Cancelación repetida

Las búsquedas de 706010 y 706030 no filtran STATUS = AC; un registro ya cancelado vuelve a marcarse y a restarse.

Siglo fijo

MOVE 20 TO WKS-FEC-MIG-CC (línea 1762) fija el siglo de la fecha de migración y de la fecha máquina.

Hardcodes

Sucursal 342 y caja 36 como único origen migrable, confirmación cada 20,000 operaciones, diez BIN como máximo en la tabla de totales, selector 4, 5 y 6 del campo 14 del catálogo 6 y el título de respaldo de la librería CORE-GL-L001. Se trasladan a application.yml.
