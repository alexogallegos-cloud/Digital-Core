1. Resumen funcional

Alcance real: plomería de instrumentación. No hay lógica de negocio en este archivo y el documento es corto a propósito.

S038MAPLIPROC es la capa COBOL de invocación de MAPLI (Monitoreo de APLIcaciones): 7 párrafos que un programa anfitrión incluye por COPY y ejecuta por PERFORM para (a) resolver dinámicamente el TITLE de la librería ALGOL CORE-DEPL035 y (b) envolver 6 de sus entry points con el patrón fijo limpiar resultado → CALL … IN CORE-DEPL035 → dejar el código en WS-S038L035-RESULT.

Es el par de PROCEDURE del copybook de datos S038MAPLIWORK.cbl (196 LOC, 0 párrafos), que declara todas las estructuras WS-S038L035-nn-ENTRADA/SALIDA y está excluido del corpus de pseudocódigo con justificación registrada en PIPELINE/ts/webgen/content/core-dep/_registry/corpus_exclusions.yaml:12-13. La implementación real detrás de los CALL está documentada en libraries/L035.pseudo.md (fachada ALGOL, 11 entry points) y libraries/L036.pseudo.md (implementación, 12 entry points _C + acceso a CORE-DEPBD05MAPLI).

Consumidores verificados por COPY "CORE-DEP/INC/MAPLI/PRO/15MTP001" (22 programas): P005, P010, P102, P104, P105, P108, P109, P120, P125, P127, P130, P155, P160, P168, P180, P190, P195, P199, P200, P305, P310, P320. Los PERFORM de conveniencia que agrupan estos párrafos (70000950-INI-PGM-MAPLI, etc.) viven en el copybook hermano INC/PRO/procedur.cbl [L16600-16771]. P080 NO usa el COPY: tiene una copia inline de los 6 párrafos [P080 L8167-L8243] ⚠ [CLON-DIVERGENTE] (ver §5).

Este copybook no evalúa nunca el resultado de las llamadas: deja el código en WS-S038L035-RESULT y la decisión queda en el anfitrión (verificado: RN-CORE-DEP-152 describe cómo P144 lo lee y activa W77-ID-ERR-LIB-MAPLI).

4. Lógica por sección

4.1 1000038-S038L035 — Ligar_Libreria_MAPLI [S038MAPLIPROC L16-L35]

Resuelve en ejecución el TITLE del objeto de la librería CORE-DEPL035 preguntándoselo al servicio de control de versiones CTLVERS, en vez de cablearlo. Es el espejo COBOL de lo que L035 hace con L036 (PROC_DAME_TIT_S038L036, libraries/L035.pseudo.md §2).

PROCEDIMIENTO Ligar_Libreria_MAPLI():                    // 1000038-S038L035 · [S038MAPLIPROC L16]

    MOVER 0   A clave_error_versiones                    // S000-CTR-CVEERROR   [L17]
    MOVER "CORE-DEPL035" A id_libreria_solicitada            // S000-CTR-LIBID      [L18]  ⚠ [HARDCODE-SOSPECHOSO]

    LLAMAR "DAME_TIT" EN LIBRERÍA CTLVERS                //                     [L20-L23]
        CON  id_libreria_solicitada                      // S000-CTR-LIBID
             titulo_objeto_resuelto  (salida)            // S000-CTR-NOMLIB
        DEVOLVIENDO clave_error_versiones                // S000-CTR-CVEERROR

    SI clave_error_versiones = 0 ENTONCES                //                     [L25]
        CAMBIAR ATRIBUTO TITLE DE LA LIBRERÍA "CORE-DEPL035"
                A titulo_objeto_resuelto                 // CHANGE ATTRIBUTE    [L26-L27]
    SINO                                                 //                     [L28]
        MOVER 020901 A codigo_mensaje                    // WS-0101-CODI-MSG    [L29]  ⚠ [HARDCODE-SOSPECHOSO]
        MOVER 01     A tipo_mensaje                      // WS-0101-TIPO-MSG    [L30]  ⚠ [HARDCODE-SOSPECHOSO]
        MOVER clave_error_versiones A error_formateado   // WS-MSG-N-02         [L31]
        CONCATENAR "ERROR EN CALL CTLVERS MAPLI (CORE-DEPL035) " ‖
                   " RESULT=" ‖ error_formateado
                   EN texto_mensaje                      // WS-0101-TEXT-MSG    [L32-L34]
        EJECUTAR 70000050-MENSAJE                        // párrafo del anfitrión [L35]
    FIN-SI                                               // (punto final del párrafo, [L35])

⚠ [CONTINUA-TRAS-ERROR] — la rama de error solo emite mensaje y retorna: no aborta, no marca bandera ni impide las llamadas posteriores. Si CTLVERS falla, el TITLE de CORE-DEPL035 queda como esté (valor de compilación) y los 6 CALL siguientes se resolverán contra ese objeto o fallarán en tiempo de enlace. El manejo queda íntegramente en el anfitrión. « [S038MAPLIPROC L28-L35] »

⚠ [COMENTARIO-DESACTUALIZADO] — la cabecera declara NOMBRE DEL ARCHIVO: CORE-DEP/INCLUDE/MAPLI/PROCEDURE/15MTP001 [S038MAPLIPROC L5-L6], ruta que no corresponde a la del COPY real usado por los 22 consumidores (CORE-DEP/INC/MAPLI/PRO/15MTP001).
