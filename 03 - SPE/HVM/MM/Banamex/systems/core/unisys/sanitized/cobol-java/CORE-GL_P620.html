CORE-GL · P620 a Java 21 Spring Boot

P620 recibe la opción A o B, el directorio, el pack, el CSI y los días de retención. Valida la opción y que el directorio tenga más de una diagonal, obtiene el título real del archivo con DAME_TIT de CTLVER y copia el archivo a uno temporal omitiendo la entrada que coincide por directorio, pack y CSI. En un alta, si la entrada ya existía, marca error; si no, agrega al final un registro USER.DIR.PACK.CSI.DIA con USER fijo en CORE-GL y días topados a 4. Sin error, purga el original y deja el temporal con el título del original.

DirectorioDepuracionService.java@Service · @TransactionalJava 21
@Service
@RequiredArgsConstructor
public class DirectorioDepuracionService {

    private static final String USUARIO = "CORE-GL";        // MOVE "CORE-GL" TO WKS-PARAM-USER
    private final DirectorioDepuracionRepository repo;
    private final Bitacora bitacora;                       // CALL LJ IN LIB-DISP
    private final P620Properties props;                    // p620.dias-maximos

    /** 0000-INICIA. Una sola transacción reemplaza la copia a TEMP + PURGE + SAVE. */
    @Transactional
    public void ejecuta(AltaBajaDirectorio cmd) {
        if (cmd.opcion() == null) {
            throw new ValidacionException("LA ACCION DEBE DE SER ALTA (A) O BAJA (B)");
        }
        long diagonales = cmd.directorio().chars().filter(ch -> ch == '/').count();
        if (diagonales <= 1) {                             // IF W77-SLASH > 1
            throw new ValidacionException("EL NIVEL DEL DIRECTORIO DEBE DE SER > 2");
        }
        switch (cmd.opcion()) {
            case A -> alta(cmd);
            case B -> baja(cmd);
        }
        // Si alta() o baja() lanzan excepción, el rollback deja la tabla intacta,
        // igual que cuando W77-ERROR > 0 deja el archivo original sin purgar.
    }
}
/** 0100-LIBRERIAS: DAME_TIT IN CTLVER resuelve el título vigente del archivo CORE-GLDIR. */
@Component
@RequiredArgsConstructor
class TituloArchivoResolver {

    private final CatalogoVersionesClient ctlver;
    private final P620Properties props;

    String titulo() {
        return ctlver.dameTitulo("CORE-GLDIR")
                .orElseThrow(() -> new IllegalStateException(
                        "CTLVER no devolvió título para CORE-GLDIR"));   // en COBOL se sigue con el título del FD
    }
}

DirectorioDepuracionService.java · DirectorioDepuracionRepository.java@Transactional · Spring Data JPAJava 21
/** 0200-PROCESO, rama de alta. */
private void alta(AltaBajaDirectorio cmd) {
    boolean existe = repo.existsByDirectorioAndPackAndCsi(
            cmd.directorio(), cmd.pack(), cmd.csiTexto());     // WKS-DUPLI = 1
    if (existe) {
        bitacora.error("EL REGISTRO YA EXISTE");
        throw new RegistroDuplicadoException(cmd);            // MOVE 1 TO W77-ERROR
    }
    procesaAlta(cmd);                                          // 0220-PROCESA-ALTA
}
/** 0210-CREA-ARCH, rama de baja: omitir al copiar equivale a borrar. */
private void baja(AltaBajaDirectorio cmd) {
    int borrados = repo.deleteByDirectorioAndPackAndCsi(
            cmd.directorio(), cmd.pack(), cmd.csiTexto());
    if (borrados == 0) {
        // El COBOL no avisa cuando no encuentra la entrada: reescribe el archivo igual.
        bitacora.info("BAJA SIN COINCIDENCIAS: " + cmd);
    }
}

public interface DirectorioDepuracionRepository extends JpaRepository<DirectorioDepuracion, Long> {
    boolean existsByDirectorioAndPackAndCsi(String dir, String pack, String csi);
    @Modifying int deleteByDirectorioAndPackAndCsi(String dir, String pack, String csi);
}
/** 0220-PROCESA-ALTA. */
private void procesaAlta(AltaBajaDirectorio cmd) {
    var d = new DirectorioDepuracion();
    d.usuario    = USUARIO;                                   // siempre CORE-GL
    d.directorio = cmd.directorio();
    d.pack       = cmd.pack();
    d.csi        = cmd.csiTexto();
    d.dias       = Math.min(cmd.dias(), props.diasMaximos()); // IF WKS-PARAM-DIA > 4 MOVE 4
    repo.save(d);
}

Riesgos de migración
Renombre con título no resuelto

Si DAME_TIT IN CTLVER no devuelve 0, WKS-TIT-CORE-GLDIR no se asigna (líneas 136-138), pero 0000-INICIA purga el original y cambia el título del temporal a ese valor (líneas 108-113).

Variables de control sin inicializar

W77-SLASH, W77-ERROR y WKS-DUPLI no tienen VALUE (líneas 43, 44 y 46). INSPECT TALLYING acumula sobre W77-SLASH y las decisiones de alta y de reemplazo dependen de W77-ERROR y WKS-DUPLI.

Errores de entrada sin estatus

Opción inválida o directorio de nivel bajo solo envían mensaje a LIB-DISP y terminan con STOP RUN normal; el WFL no lo detecta.

Sin rollback entre PURGE y SAVE

Si la tarea falla después de CLOSE A01-DIR-INPUT WITH PURGE (línea 108) y antes de CLOSE A01-DIR2-INPUT WITH SAVE (línea 113), el archivo original desaparece.

Hardcodes

Títulos CORE-GL/FILE/I10/DEPURAR/DIRECTORIOS/007. y TEMP., usuario CORE-GL, tope de 4 días y la ruta de LIB-DISP están compilados.

Pendiente de revisión SME
  • Confirmar cómo inicializa el compilador MCP la WORKING-STORAGE sin VALUE (W77-SLASH, W77-ERROR, WKS-DUPLI); de eso depende que la validación de profundidad y el reemplazo funcionen en la primera ejecución.
  • Confirmar si el cambio de TITLE de un archivo abierto en INPUT seguido de CLOSE WITH SAVE (líneas 109-113) renombra el archivo en disco o crea una copia.
  • Validar si otros programas leen el archivo de directorios; de ser así, la versión Java necesita una exportación con el formato USER.DIR.PACK.CSI.DIA y el relleno de espacios actual.
  • La variable W77-DIAS-MENOS y el resultado de CSIID IN SOPORTECOMS no se usan; confirmar que no hay lógica pendiente asociada.
