P073 · Monitor/Relay de Movimientos GL online (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P073.cbl (1782 LOC) · Programa ONLINE COMS · BC-10

Convenciones: nombres traducidos (Unisys→legible); [P073 Lnnnn] = línea origen en fuente; (BR: RN-CORE-GL-nnn) = regla de negocio.

1. Resumen funcional

P073 (PROGRAM-ID CORE-GLP073) es un servidor online COMS del sistema de Libro Mayor CORE-GL de LegacyCore. Su función es recibir mensajes de consulta de movimientos contables diarios enviados por otros sistemas vía protocolo SA2 compacto (37 bytes de encabezado), localizar dinámicamente la librería L011 del sistema solicitante y retornar el conjunto de movimientos (hasta 23 por respuesta) para la fecha, sucursal, caja y moneda indicados. El programa opera en modo daemon: arranca una sola vez, habilita la entrada COMS bajo la clave "ONLINE", y permanece en bucle atendiendo mensajes hasta recibir una señal HI-4 (fin normal por operador) o HI-6 (terminación de emergencia). Es estructuralmente análogo a P071, con dos diferencias clave: cubre 14 sistemas de punteo en lugar de 18 (excluye los sistemas 252 y 408) y usa encabezado SA2 de 37 bytes en lugar de 77.

2.6 Layout del mensaje de entrada (nivel 2)

WKS-MSG-ENT-NIVEL2 — redefine WKS-MSG-TEXTO (1835 bytes):

  • WKS-ENIV2-SUC (4) — sucursal origen
  • WKS-ENIV2-FECHA (8) — fecha del movimiento (AAAAMMDD)
  • WKS-ENIV2-CAJA (4) — caja origen
  • WKS-ENIV2-MON (4) — moneda
  • WKS-ENIV2-SIS (4) — sistema solicitante
  • WKS-ENIV2-CONT (10): AUTAPL(8) + NUMREG(2) — continuación de paginación

2.7 Layout del mensaje de salida (nivel 2)

WKS-MSG-SAL-NIVEL2 — redefine WKS-MENSAJE-SAL (1835 bytes):

  • Cabecera: SUC(4) + FECHA(8) + CAJA(4) + MON(4) + SIS(4) + CONT: AUTCON(8)+NUMREG(2)
  • WKS-SNIV2-DATOS OCCURS 23 TIMES — WKS-SNIV2-RESPUESTA (75 bytes):
  • CVETRN(6) — clave de trayectoria contable
  • NATURA(1) — naturaleza del movimiento (débito/crédito)
  • IMP PIC 9(14)V9(02) — importe
  • AUTAPL(8) — autorización aplicación (0=slot vacío)
  • CUENTA(20) — cuenta contable
  • SUCPROM(4) — sucursal promotora
  • REF(20) — referencia

2.8 Layout del bloque para librería L011 (WKS-PUNTEO-MOVTOS)

WKS-L011-FUNCION(2) + FECHA(8) + SUCURSAL(4) + CAJA(4) + MONEDA(4) + CONT(10) + DATOS OCCURS 23: CVETRN(6)+IMPORTE(14V2)+AUTAPL(8)+REF(20)+CUENTA(20)+SUC(4)+NATURA(1)

4. Lógica por sección

4.1 DECLARATIVES — INTERRUPT-BY-HI SECTION

PROCEDIMIENTO Manejador_Interrupcion():            // INTERRUPT-BY-HI · 000A-BEGIN-INTERRUPT · [P073 L992]
  DESHABILITAR interrupciones futuras               // DISALLOW INTERRUPT [P073 L993]
  MOVER atributo TASKVALUE de MYSELF → valor_interrupcion  // W77-HI [P073 L994]

  SI valor_interrupcion = 2  // W88-HI-2 = prende monitor
    SI indicador_monitor_activo = 0
      MOVER "PRENDE MONITOR" → TEXTO-LJ
      LLAMAR "LJ IN LIB-DISP" (log al operador)                // [P073 L997-998]
      MOVER 1 → indicador_monitor_activo                        // [P073 L999]
      MOVER WKS-FECHA-MAQ6D → WKS-FECHA-MON                    // [P073 L1000]
      ACEPTAR WKS-HR-MAQUINA DESDE TIME                         // [P073 L1001]
      MOVER WKS-HHMMSS-MAQUINA → WKS-HORA-MON                  // [P073 L1002]
      ABRIR SALIDA A01-MONITOR                                   // [P073 L1003]
    SINO
      (siguiente sentencia — monitor ya activo)
  SINO SI valor_interrupcion = 3  // W88-HI-3 = apaga monitor
    SI indicador_monitor_activo = 1
      CERRAR A01-MONITOR CON SAVE                                // [P073 L1009]
      MOVER "APAGA MONITOR" → TEXTO-LJ
      LLAMAR "LJ IN LIB-DISP"                                   // [P073 L1010-1011]
      MOVER 0 → indicador_monitor_activo                        // [P073 L1012]
    SINO
      (siguiente sentencia)
  SINO SI valor_interrupcion = 4  // W88-HI-4 = fin normal
    MOVER "FIN NORMAL POR OPERADOR" → TEXTO-LJ
    LLAMAR "LJ IN LIB-DISP"                                     // [P073 L1017-1018]
    MOVER 1 → indicador_fin                                     // [P073 L1019]
  SINO SI valor_interrupcion = 6  // W88-HI-6 = emergencia
    MOVER "TERMINACION DE EMERGENCIA" → TEXTO-LJ
    LLAMAR "LJ IN LIB-DISP"                                     // [P073 L1022-1023]
    MOVER 1 → indicador_fin                                     // [P073 L1024]
  SINO  // HI desconocida — documenta los HI válidos al operador
    MOVER "     HI2   -> PRENDE MONITOR"   → TEXTO-LJ; LLAMAR LJ
    MOVER "     HI3   -> APAGA MONITOR "   → TEXTO-LJ; LLAMAR LJ
    MOVER "     HI4   -> FIN NORMAL POR OPERADOR" → TEXTO-LJ; LLAMAR LJ
                                                                // [P073 L1026-1031]
  HABILITAR interrupciones                                      // ALLOW INTERRUPT [P073 L1032]
FIN PROCEDIMIENTO
