1. Resumen funcional

GENARCHSDOS (P174) es el programa batch que genera el archivo de saldos de contratos de captación para el sistema receptor Tandem (S036). Ejecuta en dos nodos: si el CSI (Centro de Servicio Integral) es 04 (MTY, Monterrey) sólo genera el archivo local; si el CSI es 10 (VDM, Valle de México) genera su propio archivo, espera el de MTY transferido vía XRAPID, valida su header, consolida ambos archivos, los ordena por número de contrato mediante SORT, y produce el archivo final en formato TANDEM con estructura HDR1 + HDR2 + registros-detalle + TRL1 + TRL2. En ambos nodos se emite un reporte impreso de cifras de control (R01-CIFRAS) con totales de registros leídos, grabados, importes de saldo actual y disponible, y marcas de tiempo. La fuente de datos es el data set DMSII CORE-DEPB03CONTRATOS (base de captación CORE-DEPBD01CAPTACION), abierta en modo INQUIRY (solo lectura).

WS-HD1-REC-CNT=1, WS-HD1-REC-TYP="FH", WS-HD1-REF-TYP="0"

WS-HD1-ATM-IMP-STRT-DAT="99999999" ⚠ [HARDCODE-SOSPECHOSO — centinela]
WS-HD1-ATM-IMP-STRT-TIM="999999999999" ⚠ [HARDCODE-SOSPECHOSO — centinela]

WS-SDOB24-HDR2 — Header-2 TANDEM tipo "BH" (~334 bytes):

WS-HD2-REC-CNT=2, WS-HD2-REC-TYP="BH"
WS-HD2-CRD-ISS="CMAE" ⚠ [HARDCODE-SOSPECHOSO — institución emisora LegacyCore]

WS-SDOSB24-DETALLE — Registro detalle TANDEM (seg0 300 bytes + seg2 42 bytes = 342 bytes):

Seg0: WS-DET-SEG0-LGTH=300, contador, clave primaria (CMAE+NUM+tipo "01")
      WS-DET-SEG0-ACCT-STAT, WS-DET-SEG0-REC-TYP="F"
      AVAIL-BAL, LEDG-BAL, AMT-ON-HLD (en centavos: valor * 100)
      CRNCY-CDE=484 ⚠ [HARDCODE-SOSPECHOSO — MXN código ISO 4217]
      USER-FLD-ACI (50 chars), USER-FLD-REGN (50 chars), USER-FLD-CUS (50 chars)
Seg2: LGTH=42, TTL-FLOAT=0, DAYS-DELINQ=0, MONTHS-ACTIVE=0
      CYCLE-1..3=0  ⚠ [HARDCODE-SOSPECHOSO — siempre ceros]

Trailers TANDEM:

WS-SDOSB24-TRL1: REC-TYP="BT", NUM-RECS = TOT-MTY + TOT-VDM, AMT=suma LEDG-BAL
WS-SDODB24-TRL2: REC-TYP="FT", NXT-FILE-IND="0", NUM-RECS = TOT-VDM + TOT-MTY
