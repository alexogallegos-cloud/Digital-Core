CORE-DEP · P131 a Java 21 Spring Boot

P131 lee el archivo de 300 posiciones que deja Teradata y, por cada detalle, traduce el tipo de evaluación a esquema, busca en memoria las reglas del producto, instrumento y moneda, y calcula la comisión aplicando una cascada de exenciones: producto no registrado o inactivo, periodo de gracia, excepción manual, reglas B13 en orden de prelación y, si nada aplica, cobro pleno. En los esquemas 5 y 6 evalúa además los rewards de B14 por canal y número de movimientos. Cada resultado se escribe en el archivo de respuesta RESEVAL y genera hasta tres asientos en el archivo de posteo: no contable por el monto exentado, cargo por la comisión y abono por el reward, con claves de transacción fijas por esquema. También produce un listado de totales por esquema y producto.

@Component
@StepScope
@RequiredArgsConstructor
public class EvaluacionEppProcessor implements ItemProcessor<RegistroEpp, ResultadoEpp> {

    private final MotorComisiones comisiones;   // 000300-CALCULO-COMISION (reglas B13)
    private final MotorRewards rewards;         // 000300-BUSCA-REGLA-REWARD (reglas B14)
    private final GeneradorPosteo posteo;       // 000300-GENERA-DET-POSTE

    @Override
    public ResultadoEpp process(RegistroEpp reg) {
        if (reg.tipoRegistro() != 2) return null;            // header y trailer no se evalúan
        var ev = reg.detalle();
        var tipo = TipoEvaluacion.de(ev.tipoEvaluacionRaw());
        if (tipo.isEmpty()) {
            return ResultadoEpp.error(ev, Excepcion.ESQUEMA_INVALIDO,     // TIP-EXC 08
                    "ERROR: ESQUEMA INVALIDO[" + "%02d".formatted(ev.tipoEvaluacionRaw()) + "]");
        }
        // Estado nuevo por registro: equivale a 000300-INI-VARS, pero sin variables compartidas.
        Comision c = comisiones.calcula(ev, tipo.get());
        var r = ResultadoEpp.de(ev, c).conAsientos(posteo.deComision(ev, tipo.get(), c));
        if (tipo.get().conRewards()) {
            for (Reward rw : rewards.evalua(ev)) {
                r = r.conReward(rw).conAsientos(posteo.deReward(ev, rw));
            }
        }
        return r;
    }
}

/** Llave de T1 (reglas B13): producto, instrumento, moneda y esquema de comisión. */
public record LlaveReglaComision(int producto, int instrumento, int moneda, int esquema) {

    /** La evaluación mixta busca la regla de comisión de su esquema base: 05 usa 01 y 06 usa 02. */
    static LlaveReglaComision de(EvaluacionEpp ev) {
        int esquema = switch (ev.tipoEvaluacionRaw()) {
            case 5 -> 1;
            case 6 -> 2;
            default -> ev.tipoEvaluacionRaw();
        };
        return new LlaveReglaComision(ev.producto(), ev.instrumento(), ev.moneda(), esquema);
    }
}

@Component
public class ReglasComisionCache {
    // T1-TABLA-REGLAS-COMISIONES OCCURS 60: se carga una vez por archivo desde CORE-DEPB13PREGCOMEPP.
    private Map<LlaveReglaComision, ProductoComision> porLlave = Map.of();

    public void carga(List<ProductoComision> b13) {
        if (b13.size() > 60) throw new CapacidadTablaException("T1", b13.size(), 60);
        porLlave = b13.stream().collect(Collectors.toUnmodifiableMap(ProductoComision::llave, p -> p));
    }

    public Optional<ProductoComision> busca(LlaveReglaComision k) {
        return Optional.ofNullable(porLlave.get(k));   // reemplaza la búsqueda lineal FIND-PRODUCTO
    }
}
@Service
@RequiredArgsConstructor
public class MotorComisiones {

    private final ReglasComisionCache t1;
    private final CalendarioBancario calendario;      // CALL-CALENDAR función 02, formato 13
    private final EvaluadorReglasB13 reglasB13;       // 000300-VAL-REGLA-B13

    /** El orden de la cascada es parte de la regla de negocio: la primera que aplica gana. */
    public Comision calcula(EvaluacionEpp ev, TipoEvaluacion tipo) {
        var prod = t1.busca(LlaveReglaComision.de(ev));
        if (prod.isEmpty())                 return Comision.error(Excepcion.PROD_NO_REGISTRADO);   // 09
        if (prod.get().status() == 2)       return Comision.error(Excepcion.PROD_INACTIVO);        // 10

        BigDecimal importe = prod.get().importeComision();          // 9(08)V99
        if (enPeriodoDeGracia(ev, prod.get()))
            return Comision.exenta(importe, Excepcion.PERIODO_GRACIA, "EX %100.00  PERIODO DE GRACIA");
        if (ev.codExcepcionManual() > 0)
            return Comision.exenta(importe, Excepcion.EXCEPCION_MANUAL,
                    "EX %%100.00  EXCEPCION MANUAL[%04d]".formatted(ev.codExcepcionManual()));

        return reglasB13.evalua(ev, prod.get())
                .orElseGet(() -> Comision.cobroPleno(importe));     // 13: NO CUMPLE CON REGLA
    }

    private LocalDate fechaArchivo;   // WKS-FEC-ARC: se fija al abrir EVCOMIS (beforeStep)

    private boolean enPeriodoDeGracia(EvaluacionEpp ev, ProductoComision p) {
        // Cuenta nueva: desde la apertura hasta la fecha del archivo; si no, entre los dos cortes.
        LocalDate desde = ev.esCuentaNueva() ? ev.fecApertura() : ev.fecCorteAnt();
        LocalDate hasta = ev.esCuentaNueva() ? fechaArchivo : ev.fecUltCorte();
        return calendario.diasEntre(desde, hasta) <= p.diasPeriodoGracia();
    }
}
@Component
@RequiredArgsConstructor
public class EvaluadorReglasB13 {

    /** Excepciones 01..07 en el orden del fuente: nómina, empleado, segmento, grupo BIN,
     *  tipo de persona, saldo promedio y movimientos. */
    private final List<ExcepcionComision> excepciones;   // @Order(1..7)
    private final Clock clock;                           // WKS-FEC-SAMD: fecha de proceso

    public Optional<Comision> evalua(EvaluacionEpp ev, ProductoComision prod) {
        LocalDate hoy = LocalDate.now(clock);
        return prod.reglasEnOrdenDePrelacion().stream()   // WKS-PRELACIONES (i, 1..99), corta en 0
                .limit(99)
                .filter(r -> r.status() == 1 && r.vigenteEn(hoy))   // FEC-FIN = 0: sin vencimiento
                .map(r -> primeraExcepcionQueAplica(ev, r))
                .flatMap(Optional::stream)
                .findFirst();                              // UNTIL WKS-CUMPLE-REGLA = 1
    }

    private Optional<Comision> primeraExcepcionQueAplica(EvaluacionEpp ev, ReglaB13 r) {
        return excepciones.stream()
                .filter(e -> e.tipo() == r.tipoExcepcion())
                .map(e -> e.aplica(ev, r))
                .flatMap(Optional::stream)
                .findFirst();
    }
}

/** Importes PIC 9(08)V99: escala 2. COMPUTE sin ROUNDED trunca. */
public final class Waiver {

    private static final BigDecimal CIEN = new BigDecimal("100");

    /** CP = 1: waiver como monto fijo; nunca deja una comisión negativa. */
    static Comision porCantidad(BigDecimal importeComi, BigDecimal waiver) {
        BigDecimal comi = (waiver.compareTo(importeComi) > 0 || importeComi.signum() == 0)
                ? BigDecimal.ZERO.setScale(2)
                : importeComi.subtract(waiver);
        return new Comision(comi, importeComi.subtract(comi));      // WKS-COMI, WKS-IMP-EXC
    }

    /** CP = 2: waiver como porcentaje del importe de la regla. */
    static Comision porPorcentaje(BigDecimal importeComi, BigDecimal pctWaiver) {
        if (pctWaiver.compareTo(CIEN) > 0) {
            // En COBOL, WKS-COMI sin signo guardaría el valor absoluto de la resta negativa.
            throw new ReglaInvalidaException("Waiver mayor a 100%: " + pctWaiver);
        }
        BigDecimal exencion = importeComi.multiply(pctWaiver)
                .divide(CIEN, 2, RoundingMode.DOWN);                // trunca como el COMPUTE
        return new Comision(importeComi.subtract(exencion), exencion);
    }
}

@Service
@RequiredArgsConstructor
public class MotorRewards {

    private static final BigDecimal CIEN = new BigDecimal("100");
    private final ReglasRewardCache t2;     // T2-TABLA-REGLAS-REWARDS (B14), llave con esquema 03

    /** Devuelve todos los rewards que dispara el registro: una regla puede pagar en varios canales. */
    public List<Reward> evalua(EvaluacionEpp ev) {
        var prod = t2.busca(ev.producto(), ev.instrumento(), ev.moneda());
        if (prod.isEmpty())           return List.of(Reward.error(Excepcion.REW_NO_REGISTRADO));  // 14
        if (prod.get().status() == 2) return List.of(Reward.error(Excepcion.REW_INACTIVO));       // 15

        var pagados = new ArrayList<Reward>();
        for (ReglaB14 r : prod.get().reglas()) {                    // todas las reglas, sin corte
            if (r.status() != 1) continue;
            for (var mov : ev.canales()) {                          // canales 1..7
                if (mov.canal() == r.tipoCanal() && mov.numMovs() >= r.movsMinimos()) {
                    BigDecimal monto = (r.indicador() == 1)
                            ? r.waiver()                            // cantidad fija
                            : mov.importe().multiply(r.waiver())
                                 .divide(CIEN, 2, RoundingMode.DOWN); // 9(08)V99 sin ROUNDED
                    pagados.add(Reward.de(r, mov, monto));
                }
            }
        }
        return pagados.isEmpty() ? List.of(Reward.noCumple()) : pagados;   // 17
    }
}

@Component
@RequiredArgsConstructor
public class RespuestaTeradataMapper {

    private final P131Properties props;
    private final Clock clock;

    /** Una línea por comisión y otra por cada reward; los rewards numeran 10, 11, 12... en MON. */
    public List<DetalleRespuesta> mapea(ResultadoEpp r, AtomicLong secuencia) {
        var lineas = new ArrayList<DetalleRespuesta>();
        var ev = r.evaluacion();
        lineas.add(DetalleRespuesta.de(secuencia.incrementAndGet(), ev, ev.moneda(),
                r.comision().motivo(), LocalDate.now(clock)));
        int contador = props.respuesta().monedaInicialRewards();   // WKS-CONT-REWARDS = 10 en INI-VARS
        for (Reward rw : r.rewards()) {
            lineas.add(DetalleRespuesta.de(secuencia.incrementAndGet(), ev, contador++,
                    rw.motivo(), LocalDate.now(clock)));
        }
        return lineas;
    }
}

@Component
@RequiredArgsConstructor
public class GeneradorPosteo {

    private final P131Properties.Posteo cfg;
    private final ReferenciaPeriodo referencias;   // 000300-ASIGNA-REF: "PERIODO ... AL ..."

    public List<AsientoPosteo> deComision(EvaluacionEpp ev, TipoEvaluacion t, Comision c) {
        var asientos = new ArrayList<AsientoPosteo>(2);
        var claves = t.esRenta() ? cfg.claves().renta() : cfg.claves().saldo();
        if (c.exencion().signum() > 0)
            asientos.add(AsientoPosteo.noContable(ev, cfg.cajaComisiones(), claves.exencion(),
                    c.exencion(), referencias.de(ev, true)));
        if (c.comision().signum() > 0)
            asientos.add(AsientoPosteo.cargo(ev, cfg.cajaComisiones(), claves.cargo(),
                    c.comision(), referencias.de(ev, false)));
        return asientos;                     // nunca genera abono: el reward va aparte
    }

    public List<AsientoPosteo> deReward(EvaluacionEpp ev, Reward rw) {
        return rw.monto().signum() > 0
                ? List.of(AsientoPosteo.abono(ev, cfg.cajaRewards(), cfg.claves().reward(),
                          rw.monto(), referencias.de(ev, false)))
                : List.of();
    }
}

Riesgos de migración
Abono de reward arrastrado entre registros

WKS-REWARD nunca se reinicia (solo se asigna en las líneas 2593 y 2596). Una vez que un registro gana reward, las evaluaciones de comisión posteriores pasan la condición IF WKS-REWARD > 0 de 000300-GENERA-DET-POSTE (línea 2693) y generan abonos 1293 no justificados, con conteo en WKS-NUN-ABO pero sin importe en WKS-TOT-ABO, lo que descuadraría el trailer de posteo.

Excepción manual abierta a cualquier código

000300-VAL-EXC-MANUAL (líneas 2034-2036) exenta al cien por ciento cualquier código de excepción manual mayor que cero; la restricción a 0101 y 0202 está comentada.

Waiver porcentual mayor a 100

En 000300-COMISION-BY-EXC, si B13 trae un porcentaje mayor que 100, WKS-COMI (sin signo) recibe el valor absoluto de una resta negativa y se cobra comisión en lugar de exentar.

Inconsistencia de esquemas 5 y 6

La cabecera del programa asocia 5 con saldo y 6 con renta; los niveles 88 (líneas 183-184) y las claves de posteo los asocian al revés. Lo que se ejecuta es lo de los niveles 88.

Credencial embebida en el WFL de impresión

En la línea 3325, el WFL que envía el listado a impresión incluye un ACCESSCODE con usuario y contraseña en claro para un host de desarrollo. El valor se omite en este documento (****) y debe retirarse del fuente y moverse a un almacén de secretos.

Hardcodes de posteo e interfaz

Sistema 000000000500, número de archivo 005, sucursal 0511, cajas 71 y 72, claves 0833, 0835, 2523, 2524 y 1293, tipo de moneda 001 y el valor inicial 10 del contador de rewards están compilados. Se trasladan a application.yml.
