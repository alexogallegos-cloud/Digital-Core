P075 · Informe de Cambio de Día (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: P075.cbl (239 LOC) · Programa BATCH de control — dispara INIBATCH en L080 para señalizar cierre del día bancario a P080 · BC-14

Convenciones: nombres traducidos (Unisys→legible); [P075 Lnnnn] = número de secuencia COBOL (cols 1–6); (BR: RN-CORE-DEP-nnn) = regla de negocio verificada en KB.

1. Resumen funcional

P075 es un programa batch utilitario de control (dominio CTL) cuya única responsabilidad es señalizar el cierre del día bancario al procesador central P080 a través de la librería L080 (CORE-DEPL080CTRL). No procesa registros ni accede a bases de datos DMSII: su lógica es exclusivamente de orquestación y validación de control.

El programa recibe un único parámetro desde el WFL (W77-PARAM-WFL, valor esperado = 1). Al arrancar, valida que su propia versión (CORE-DEPP075 / 25MTP003) sigue autorizada en el catálogo central de versiones (CTLVERS). A continuación resuelve dinámicamente el título físico de la librería CORE-DEPL080CTRL mediante DAME_TIT IN CTLVERS. Solo si esta resolución es exitosa y el parámetro es exactamente 1, invoca el entry point INIBATCH que efectivamente notifica el cambio de día a P080.

Punto crítico de comportamiento: el fallo en la validación de versión (RN-CORE-DEP-022) marca el estatus de salida como error pero no interrumpe el flujo — el programa continúa intentando la notificación. En cambio, el fallo en la llamada a INIBATCH (RN-CORE-DEP-026) sí produce un estatus de error visible al orquestador WFL/scheduler.

2.1 Archivos y datasets

_P075 no declara FILE-CONTROL ni FD. No accede a datasets DMSII. No hay archivos de entrada ni salida directos._

3. Mapa de control

000000-MODULO-CONTROL-PROGRAMA (SECTION)              [P075 L13900]
  └─ 000000-MODULO-DE-CONTROL                         [P075 L14200]  ← punto de entrada
       │
       ├─ PERFORM 10000100-VERSIONES                   [P075 L15200]
       │    └─ CHANGE ATTRIBUTE LIBACCESS/FUNCTIONNAME de "CTLVERS"
       │       (configura acceso a CTLVERS por nombre de función — idioma MCP)
       │
       ├─ PERFORM 20000100-CHECAME-VERSION             [P075 L15300]
       │    └─ CALL "CHECAME IN CTLVERS"
       │       USING W77-S000-MY-ID, W77-S000-MY-VERSION
       │       GIVING S000-CTR-CVEERROR
       │
       ├─ SI S000-CTR-CVEERROR < 0                     [P075 L15400]
       │    ├─ PERFORM 70000050-MENSAJE ("ERROR DE VERSION")
       │    ├─ CHANGE ATTRIBUTE STATUS OF MYSELF TO -1
       │    └─ ⚠ [DESCARTE-SILENCIOSO] — NO hay STOP RUN; flujo continúa (BR: RN-CORE-DEP-022)
       │
       ├─ PERFORM 100000-L080                          [P075 L15900]
       │    ├─ MOVER 0 A S000-CTR-CVEERROR             (reinicio del indicador)
       │    ├─ MOVER "CORE-DEPL080CTRL" A S000-CTR-LIBID
       │    ├─ PERFORM 20000100-DAME-TIT-VERS
       │    │    └─ CALL "DAME_TIT IN CTLVERS"
       │    │       USING S000-CTR-LIBID, S000-CTR-NOMLIB
       │    │       GIVING S000-CTR-CVEERROR
       │    ├─ SI ok (=0): CHANGE ATTRIBUTE TITLE OF "CORE-DEPL080CTRL" TO S000-CTR-NOMLIB
       │    └─ SI error (≠0): registra mensaje ⚠ SIN marcar STATUS=-1  (BR: RN-CORE-DEP-024)
       │
       ├─ SI S000-CTR-CVEERROR = 0                     [P075 L16000]
       │    ├─ SI W77-PARAM-WFL = 1                    [P075 L16100]  (BR: RN-CORE-DEP-023)
       │    │    └─ PERFORM 200000-INIBATCH
       │    │         ├─ PERFORM 205000-INIBATCH-CALL
       │    │         │    └─ CALL "CORE-DEPL080INIBATCHP080 IN CORE-DEPL080CTRL"
       │    │         │       GIVING WKS-L080-RESULT              (BR: RN-CORE-DEP-025)
       │    │         └─ SI WKS-L080-RESULT > 0
       │    │              ├─ PERFORM 70000050-MENSAJE ("ERROR EN LLAMADO INIBATCH")
       │    │              └─ CHANGE ATTRIBUTE STATUS OF MYSELF TO -1  (BR: RN-CORE-DEP-026)
       │    └─ SINO (parámetro ≠ 1)
       │         ├─ STRING "VALUE ERRONEO PARA EJECUTAR P075 " + valor → WS-0101-TEXT-MSG
       │         ├─ PERFORM 70000050-MENSAJE
       │         └─ CHANGE ATTRIBUTE STATUS OF MYSELF TO -1
       │
       └─ STOP RUN                                     [P075 L16900]

Auxiliares (invocados desde el flujo principal):
  70000050-MENSAJE        [P075 L20900]  ← despachador: DISPLAY directo (W77-USO-LIBLJ=0)
                                            o ruta LJ (W77-USO-LIBLJ≠0)

4.3 · Resolver_Librería_L080

PROCEDIMIENTO Resolver_Librería_L080():                     // 100000-L080 · [P075 L17100]
// ── Reinicio del indicador y selección de librería ───────────────────────────
MOVER 0              A código_error_versión          // S000-CTR-CVEERROR — reinicio explícito
MOVER "CORE-DEPL080CTRL" A id_librería_control           // S000-CTR-LIBID — identifica la librería lógica

« [P075 L17200-L17300] »

// ── Resolución del título físico vigente de L080 ─────────────────────────────
EJECUTAR Obtener_Título_Librería()                   // PERFORM 20000100-DAME-TIT-VERS

SI código_error_versión = 0                          // S000-CTR-CVEERROR = 0
   // Aplicar el título resuelto: dirige "CORE-DEPL080CTRL" a la versión física activa
   CHANGE ATTRIBUTE TITLE OF "CORE-DEPL080CTRL" TO título_librería_resuelto  // S000-CTR-NOMLIB
   // Después de este punto, CALL "... IN CORE-DEPL080CTRL" apunta a la versión vigente del catálogo
SINO
   MOVER código_error_versión A campo_numérico_2dig  // S000-CTR-CVEERROR → WS-MSG-N-02
   STRING "ERROR EN CALL CTLVERS CORE-DEPL080 "
          " RESULT=", campo_numérico_2dig
          DELIMITED BY SIZE HACIA texto_mensaje        // WS-0101-TEXT-MSG
   EJECUTAR Registrar_Mensaje()                       // PERFORM 70000050-MENSAJE
   // ⚠ [DESCARTE-SILENCIOSO] — SIN CHANGE ATTRIBUTE STATUS=-1.
   // Efecto: código_error_versión ≠ 0 inhabilita la rama INIBATCH en Módulo_de_Control (L16000),
   // pero el run termina sin señal de error en el estatus de salida del programa.
FIN-SI
