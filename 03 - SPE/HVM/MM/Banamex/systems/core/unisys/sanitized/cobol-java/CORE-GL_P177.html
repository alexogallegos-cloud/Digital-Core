CORE-GL · P177 a Java 21 Spring Boot

El parámetro de cinco dígitos trae el tipo de corrida y el número de sistema. En movimientos, P177 lee LOG151, conserva los de función 01 y estatus 01 con origen 1 o 3, separa línea y lote por el tipo de proceso y, para el sistema 500, descarta los procesos TELETON 40 a 43; ordena por contrato y expande cada movimiento en hasta cinco registros S015, uno por clave de transacción que deba ir a estado de cuenta, con naturaleza, referencia, leyenda, TaxID y el ramal TESOFE para las cuentas contables 60 y 61. En saldos, toma de cada cuenta el concepto de saldo actual (clave 2), lo escribe en SALDOS015 de 180 bytes, ordena y lo vuelca a SDOSYMOVS015. Ambos flujos cierran con un trailer de registros e importe total.

/** W77-SIST-PARAM PIC 9(05): dos dígitos de tipo de corrida y tres de sistema. */
public record ParametroCorrida(int tipo, int sistema) {
    static ParametroCorrida de(String sistParam) {             // p.ej. "02500"
        return new ParametroCorrida(Integer.parseInt(sistParam.substring(0, 2)),
                                    Integer.parseInt(sistParam.substring(2, 5)));
    }
}

@Component
public class TipoCorridaDecider implements JobExecutionDecider {
    @Override
    public FlowExecutionStatus decide(JobExecution job, StepExecution step) {
        var p = ParametroCorrida.de(job.getJobParameters().getString("sistParam"));
        return switch (p.tipo()) {
            case 1, 2 -> new FlowExecutionStatus("MOVIMIENTOS");
            case 3    -> new FlowExecutionStatus("SALDOS");
            default   -> new FlowExecutionStatus("NADA");      // el fuente no hace nada ni avisa
        };
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class SeleccionMovimientosProcessor implements ItemProcessor<RegistroLog151, RegistroLog151> {

    private final P177Properties props;
    @Value("#{jobParameters['sistParam']}") private String sistParam;

    @Override
    public RegistroLog151 process(RegistroLog151 m) {
        if (m.funcion() == 99) return null;                  // trailer del LOG: fin de lectura
        boolean candidato = m.funcion() == 1 && m.status() == 1
                && (m.origen() == 1 || m.origen() == 3)
                && cumpleCondicionTesofe(m);
        if (!candidato) return null;

        var p = ParametroCorrida.de(sistParam);
        if (p.tipo() == 1) return m.tipoProceso() < props.umbralProcesoLote() ? m : null;
        if (p.tipo() == 2 && m.tipoProceso() >= props.umbralProcesoLote()) {
            boolean excluido = p.sistema() == props.teleton().sistema()
                    && props.teleton().procesosExcluidos().contains(m.tipoProceso());
            return excluido ? null : m;                      // 200-060-FILTRA-MOVS-TELETON
        }
        return null;
    }

    /**
     * Fuente: (ESTACION > 0 OR (ESTACION > 0 AND CTACON = 60 OR 61)).
     * Por precedencia COBOL (AND antes que OR) equivale a ESTACION > 0 OR CTACON = 61.
     * Se reproduce tal cual; ver riesgo.
     */
    private static boolean cumpleCondicionTesofe(RegistroLog151 m) {
        return m.estacion() > 0 || m.cuentaContable() == 61;
    }
}

    private final CatalogoTransacciones catalogo;   // WKS-T-PARAMETROS-TRANS OCCURS 5000
    private final DatosAdicionales l02;             // 31100-DATADIC

    @Override
    public List<RegistroS015> process(RegistroLog151 m) {
        var adic = l02.lee(m.apuntadorDatos());
        var salida = new ArrayList<RegistroS015>();
        for (int k = 0; k < 5; k++) {
            ClaveImporte ci = m.claves().get(k);
            if (!props.esClaveReal(ci.clave())) continue;
            int clave4 = Math.toIntExact(ci.clave() % 10_000);       // MOVE 9(06) a 9(04): conserva los 4 dígitos bajos
            var r = RegistroS015.movimiento(m, clave4, ci.importe(), adic, k);
            r = naturaleza.aplica(r);                                 // 31000-NATURALEZA
            r = leyendas.aplica(r, m, adic, k);                       // 31200 + 13300 TaxID

Riesgos de migración
Precedencia de AND y OR en condiciones TESOFE

Las condiciones de las líneas 3572-3573 y 4188-4189 usan relaciones abreviadas (CTACON = 60 OR 61, SUBC = 62 OR 63) dentro de expresiones con AND. COBOL evalúa AND antes que OR, por lo que la cuenta 61 y la subcuenta 63 se aceptan sin las demás condiciones.

Truncamiento de clave e importe

A00-R01-CVETRAN es 9(06) y A00-R01-S015-CVETRA 9(04); A00-R01-IMPORTE es 9(16)V99 y A00-R01-S015-IMP S9(13)V99. Los MOVE de las líneas 3637 y 3639 pierden dígitos altos sin aviso.

Índices fuera de tabla

WKS-PT-ENVEDC (OCCURS 5000) se indexa con claves de hasta 9999 en la línea 3666 y WKS-POSCI-TAX (OCCURS 10000) con CVETRAN de hasta seis dígitos en la línea 3848.

Validaciones solo informativas

Archivo sin header o vacío (líneas 3423-3442 y 3368-3385) y errores del catálogo S080 se reportan pero no detienen el paso. S015 puede recibir una interfaz vacía o sin TaxID.

Orden distinto al documentado

Los dos SORT ordenan solo por contrato; la llave de sucursal promotora está comentada en las líneas 3407 y 3462.

Hardcodes

Sistema 500 y procesos 40-43 de TELETON, umbral 20 entre línea y lote, rangos de claves reales, claves 1009, 1072, 3018, 4016, 3009 y 3036, cuentas 60 y 61, subcuentas 62 y 63, tipo de registro 81 y sistema origen S001.
