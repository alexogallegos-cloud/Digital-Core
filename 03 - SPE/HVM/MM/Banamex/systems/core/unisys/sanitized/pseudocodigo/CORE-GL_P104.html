P104 · Punteo (conciliación de totales por clave SNNN ⟷ CORE-GL) (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P104.cbl (~3345 LOC) · Rol batch: paso de conciliación contable (punteo) · BC-11

Convenciones: nombres traducidos (Unisys→legible); [P104 Lnnnn] = línea fuente; (BR: RN-...) = regla de negocio; ⚠ = hallazgo SME.

1. Resumen funcional

P104 ("Punteo") concilia los totales contables por clave de transacción entre el sistema de origen (aplicación que envía movimientos, referida como SNNN) y el CORE-GL. Recibe el número de sistema como parámetro (PROCEDURE DIVISION USING W77-SISTEMA-PARAM). Ejecuta un punteo en dos niveles: primero compara totales por clave (párrafo 30000); si detecta descuadres levanta las banderas W77-BAN-DIFSNNN / W77-BAN-DIFCORE-GL y escala a un segundo punteo a detalle por contrato-clave (párrafo 50000) para localizar el contrato específico que causa la diferencia. « [P104 L1708-1715] · BR: RN-CORE-GL-791 »

Las diferencias se enrutan a dos archivos separados por lado responsable (CVESNNNDIF origen, CVECORE-GLDIF CORE-GL) y se emiten dos reportes impresos (totales por clave y detalle). Como parte del esquema de alta disponibilidad IBM (2015), en la primera corrida del día actualiza la base de control de procesos B05, pero sólo para los sistemas 804 y 203 (identificadores embebidos en código). « [P104 L1718-1722] · BR: RN-CORE-GL-794 »

4.2 Inicialización

PROCEDIMIENTO Inicio_Programa():                       // 10000-INICIO-PROGRAMA · [P104 L1725]
    Configurar acceso por función a "SOPORTECOMS"
    LLAMAR CSIID(SOPORTECOMS) DEVOLVIENDO datos_host    // WKS-DATOSHOST (CSI, equipo)
    Configurar acceso por función a "CTRLVERS"

    LLAMAR DAME_TIT(CTRLVERS) → titulo_libreria, estatus // control de versión librería contable

        Registrar mensaje "ERROR EN CTLVERS, USO LIBRERIA DE CONTROL SIN RELEASE NI MTP"
        Apuntar CORE-GLLIBCONTROL a "(CORE-GL)CORE-GL/OBJECT/L001/CONTROL" (versión base)
    SINO
        Apuntar CORE-GLLIBCONTROL al título versionado devuelto

    SI estatus_ctlvers < 0
        Registrar "ERROR EN CTLVERS, NO EXISTE IDENTIFICADOR (S080BD01CON)"
        Apuntar CORE-GLLIBCONTROL a "(S080)S080/OBJECT/L700"
    SINO
        Apuntar CATALOGOS al título versionado
    EJECUTAR Limpia_Arreglos()                          // 10050-LIMPIA-ARREGLO
    SI sistema_param = 402 O 600                         // ⚠ [HARDCODE] plataforma GLOBAL
        MOVER "C" A plataforma_1, plataforma_2, sistema_letra
    SINO
        MOVER "S" A plataforma_1, plataforma_2, sistema_letra
    MOVER sistema_param A (todos los campos-sistema de títulos y reportes)
    MOVER 1 A funcion_B01; MOVER csi_host A campos_csi
    // --- Alta disponibilidad IBM ---
    LLAMAR CONSISDIA(CORE-GLLIBCONTROL) USING dataset_sisdia DEVOLVIENDO resultado  // lee CORE-GLB01SISDIA
    SI fecha_propia_del_ejecutable = 0                  // primera corrida del día

        MOVER B01-FECPRO151 A fecha_proceso_151

        MOVER fecha_propia_del_ejecutable A fecha_proceso
    SI (sistema_param = 804 O 203) Y fecha_propia = 0
        EJECUTAR Verifica_B05()                         // 010000-VERIFICA-B05
    EJECUTAR Carga_Catalogos()                          // 10100-CARGA-CATALOGOS
    MOVER 1 A funcion_B01; recargar campos_csi
    // (bloque CONSISDIA duplicado quedó comentado en fuente L1828-1835 — código muerto)
    MOVER fecha_proceso A fecha_titulo_CVES / CVECORE-GL
    ACEPTAR hora_maquina DESDE TIME
    // fecha y hora de compilación (para versión en reporte):
    MOVER ATTRIBUTE NAME OF MYSELF A hora_compilacion
    LLAMAR CONVERT-DATE(LOCSUP) USING hora_compilacion → fecha_dma
    EJECUTAR A2K_Conv_DMA_a_DMCA (THRU EXIT)            // agrega siglo a la fecha
    Descomponer fecha/hora de compilación en DD/MM/AA y HH:MM:SS (COMPUTE con DIV/MOD)
    EJECUTAR A2K_Acepta_Fecha_Hoy (THRU EXIT)          // fecha del sistema MMDDCCAA
    Armar fecha de proceso AAMMDD para títulos de listados

    MOVER 1 A num_archivo_CVES; MOVER 2 A num_archivo_CVECORE-GL
    MOVER 1 A apuntador_CVE, apuntador_CVECORE-GL
    Registrar "INICIO PROCESO CON FECHA <fecha>"
    // --- Validación de HEADER del archivo de origen (CVETRAN) ---
    ABRIR ENTRADA origen_SNNN                            // CVETRAN
    MOVER ATTRIBUTE LASTRECORD OF CVETRAN A ultimo_registro
    LEER origen_SNNN INTO header_punteo
    SI header.FECPRO = fecha_esperada
        SI header.SIST = sistema_param  → OK
        SINO  Registrar error "HD ARCHIVO PUNTEO DEL SIST <param> <> <disp>"; SET MYSELF(STATUS) = -1
    SINO  Registrar error "HD ARCHIVO PUNTEO ... FECHA ERRONEA"; SET MYSELF(STATUS) = -1
    // --- Validación de TRAILER de CVETRAN ---
    CALCULAR apuntador = ultimo_registro + 1;  SEEK CVETRAN RECORD
    LEER origen_SNNN INTO trailer_punteo;  ultimo_registro = ultimo_registro - 1
    SI trailer.CVEREG = 1                                // hay trailer
        MOVER trailer.TOTREG A ultimo_registro
        SI trailer.TOTREG = ultimo_registro  → OK
        SINO  Registrar "ERROR EN NUM. DE REGISTROS DEL TRAILER ... ARCHIVO PUNTEO1"; SET STATUS = -1
    SINO  Registrar "ERROR ARCHIVO PUNTEO1 ... SIN TRAILER"; SET STATUS = -1
    CERRAR origen_SNNN CON RELEASE
    // --- Mismas validaciones de header y trailer para CVETRANCORE-GL ---
    ABRIR ENTRADA core-gl; LEER header; validar FECPRO y SIST (idéntico patrón); validar trailer
    CERRAR core-gl CON RELEASE
