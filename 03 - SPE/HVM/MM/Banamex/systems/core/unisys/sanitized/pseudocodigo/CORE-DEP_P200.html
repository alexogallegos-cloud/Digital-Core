P200 · Generador de Tasas para Tesorería por Rangos (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: P200.cbl (1557 LOC) · Batch nocturno LOTE · BC-12

Convenciones: nombres traducidos (Unisys→legible); [P200 Lnnnn] = línea en fuente; (BR: RN-CORE-DEP-...) = regla.

1. Resumen funcional

P200 genera el archivo de tasas pagadas para Tesorería (I01-RANGOS) a partir de los rangos de saldo calificados en la librería S080 de Captación LegacyCore. El proceso opera en cinco pasos secuenciales: (1) carga en memoria una tabla tridimensional de tasas brutas/netas por instrumento × tipo de persona × rango de saldo, consultando la BD DMSII y la librería externa S080; (2) itera todos los contratos activos de CORE-DEPB03CONTRATOS, asigna cada uno a su rango de saldo y escribe un archivo puente temporal (I02-RGOSPTE); (3) clasifica el archivo puente y consolida registros del mismo rango sumando saldos y contando cuentas; (4) clasifica el archivo final de Tesorería por producto/persona/rango/tasa; (5) genera un reporte de validación impreso (R01-RGOSDO).

El archivo puente está concebido como efímero (comentario fuente: "SE TIRA AL FINAL CLOSE WITH PURGE"), pero la línea activa usa CLOSE WITH SAVE; el CLOSE WITH PURGE está comentado — ⚠ divergencia diseño/implementación. El programa registra su actividad en la librería MAPLI (L035) mediante cuatro actividades monitoreadas.

WKS-R           — índice rango actual (1..20)

PROCEDIMIENTO Inicializar_Working():                     // 20003000-INICIA-WORKING · [P200 L692]
  EJECUTAR Obtener_Fecha_Maquina()                       // 90000000-DAME-FEC-MAQUINA (COPY)
  ACEPTAR hora_maquina DESDE TIME                        // WKS-TIME-MAQ

  // Editar fecha batch (AAAAMMDD → DD/MES/AAAA)
  MOVER año_batch  → año_edit_batch
  MOVER tabla_meses(mes_batch) → mes_edit_batch          // WKS-TB-MES (ENEFEB...DIC)
  MOVER dia_batch  → dia_edit_batch

  // Editar fecha máquina
  MOVER año_maq  → año_edit_maq
  MOVER tabla_meses(mes_maq) → mes_edit_maq
  MOVER dia_maq  → dia_edit_maq

  // Poblar header de I01-RANGOS
  MOVER fecha_batch → FECINI-H, FECFIN-H
  MOVER fecha_maquina → FECCREA-H
  MOVER hora_maquina  → HORACREA-H

  // Determinar día de la semana de fecha_batch (función 6 LOCSUP)
  MOVER fecha_batch → S006_fecha1; MOVER 6 → S006_funcion
  EJECUTAR Llamar_LOCSUP()
  MOVER S006_fecha1 → dia_sem_hoy                        // WKS-DIA-SEMHOY

  // Determinar día de la semana de fecha_linea (función 6 LOCSUP)
  MOVER fecha_linea → S006_fecha1; MOVER 6 → S006_funcion
  EJECUTAR Llamar_LOCSUP()
  MOVER S006_fecha1 → dia_sem_linea                      // WKS-DIA-SEMPROX

  // Clasificar tipo de proceso
  SI dia_sem_hoy > dia_sem_linea:
    MOVER 1 → es_semanal                                 // WKS-ES-SEMANAL
  SI mes(fecha_linea) ≠ mes(fecha_batch):
    MOVER 1 → es_mensual                                 // WKS-ES-MENSUAL
