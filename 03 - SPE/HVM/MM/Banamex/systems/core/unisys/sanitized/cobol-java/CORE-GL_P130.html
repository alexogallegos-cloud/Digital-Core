CORE-GL · P130 a Java 21 Spring Boot

Lee secuencialmente el LOG151 del sistema origen, cuyo registro A00-R01-REGMOV trae hasta cinco pares clave de transacción e importe. Por cada movimiento con función 1 recorre los slots ocupados, valida clave y tipo de esquema, fecha contable, sucursal iniciadora, libro, sucursal promotora y tipo de crédito contra catálogos que carga al inicio desde CPPS (librerías L700 y L710), y sustituye cada dato erróneo por un valor de desvío marcándolo con una letra de la A a la G. Los movimientos con desvío se escriben en DESVIOS y en el reporte de rechazos; los de status 1 alimentan CVETRAN, CVETRANFS y PUNTEO, y para el sistema 403 se genera además el archivo ATLAS de compra y venta de divisas. Al cierre envía las interfaces vía INTELAR y dispara el WFL siguiente.

/** A00-R01-REGMOV: cabecera del movimiento y hasta cinco slots clave-importe (A00-R01-CVEIMP, 95 bytes). */
public record MovimientoLog151(
        int funcion,            // 9(02) COMP: 1 graba, 2 solo MOVSCIG, 99 fin de archivo
        int formato,
        int sistema,            // 9(04) COMP: sistema origen (402, 403, 404, 707, 804...)
        List<SlotContable> slots,
        Datos datos) {          // resto del registro: fechas, sucursales, contrato, moneda, status...

    public static final int MAX_SLOTS = 5;   // OCCURS 5 TIMES

    /** Recorrido de 21000-ESCOGE-MOVS: se detiene en el primer slot con clave e importe en cero. */
    public List<SlotContable> slotsOcupados() {
        return slots.stream().limit(MAX_SLOTS)
                .takeWhile(s -> !(s.claveTransaccion() == 0 && s.importe().signum() == 0))
                .toList();
    }
}

/** A00-R01-ELE-CVEIMP (19 bytes en COMP de Unisys, 4 bits por dígito). */
public record SlotContable(
        int claveTransaccion,   // 9(06) COMP
        int indicadorLey,       // 9(02) COMP
        int esquemaContable,    // 9(04) COMP; A00-R01-TM lo redefine como tipo de movimiento
        BigDecimal importe,     // 9(16)V99 COMP -> escala 2, siempre no negativo
        int claveDesvio,        // 9(04) COMP
        int guiaDesvio) {}      // 9(04) COMP

@Configuration
@EnableConfigurationProperties(P130Properties.class)
public class AgrupadorJobConfig {

    @Bean
    Job agrupadorCORE-GL(JobRepository repo, P130Properties props,
                      Step verificaB05, Step cargaCatalogos, Step procesaMovimientos,
                      Step generaBitacora, Step generaTotalesPorClave, Step generaRechazos,
                      Step actualizaB05) {
        // 010000/010200: control de alta disponibilidad solo para los sistemas de props.altaDisponibilidad()
        JobExecutionDecider altaDisp = (job, step) ->
                props.altaDisponibilidad().contains(props.sistema()) && props.banderaB05()
                        ? new FlowExecutionStatus("HA") : new FlowExecutionStatus("NO_HA");

        return new JobBuilder("CORE-GLP130", repo)
                .start(altaDisp).on("HA").to(verificaB05).next(cargaCatalogos)
                .from(altaDisp).on("NO_HA").to(cargaCatalogos)
                .next(procesaMovimientos)      // 20000-PROCESA-MOVIMIENTOS
                .next(generaBitacora)          // 30000-GENERA-BITACORA
                .next(generaTotalesPorClave)   // 35000 + 60300: hoy corre para todos los sistemas
                .next(generaRechazos)          // 60000-GENERA-RECHAZOS
                .next(actualizaB05)            // tasklet que no hace nada si no aplica alta disponibilidad
                .end().build();
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class EscogeMovimientosProcessor implements ItemProcessor<MovimientoLog151, SalidasMovimiento> {

    private final P130Properties props;
    private final ValidadorMovimiento validador;   // 21125-VALIDA-INFORMACION
    private final AtlasCollector atlas;            // 21049-CHECA-ATLAS

    @Override
    public SalidasMovimiento process(MovimientoLog151 mov) {
        var salidas = new SalidasMovimiento(mov);
        switch (mov.funcion()) {
            case 1 -> {
                atlas.revisa(mov);                                  // misma posición en ambas ramas
                for (SlotContable slot : mov.slotsOcupados()) {     // VARYING W77-INDCVE ... UNTIL
                    salidas.agrega(validador.valida(mov, slot));    // 21100-GRABA-ARCHIVOS
                }
                salidas.conMovsCig(true).conEtl(props.esquemaEtl().contains(mov.sistema()));
            }
            case 2 -> salidas.conMovsCig(true).conEtl(props.esquemaEtl().contains(mov.sistema()));
            default -> { return null; }      // cualquier otra función se descarta sin aviso (RN-CORE-GL-061)
        }
        return salidas;
    }
}

public enum Desvio { A_FECHA, B_SUC_INICIATIVA, C_SUC_PROMOTORA, D_CLAVE, E_TIPO_CREDITO, F_LIBRO, G_ESQUEMA }

@Service
@RequiredArgsConstructor
public class ValidadorMovimiento {

    private final CatalogosContables cat;   // WKS-PT-*, WKS-LIBRO-LM, WKS-NUM-TC... cargados de CPPS L700/L710
    private final P130Properties props;

    /** Primer bloque de 21125: valida clave y TM; reproduce el orden exacto del fuente. */
    void validaClave(ResultadoValidacion r) {
        int clave = r.clave(), tm = r.tipoEsquema();
        if (props.form4().contains(r.sistema())) {                         // W88-SIST-FORM4
            if (clave == cat.claveDesvio() || clave == 0 || cat.numLeyendas(clave, 1) == 0) {
                r.desvia(Desvio.D_CLAVE);                                  // 21126: clave := clave de desvío
            }
            return;
        }
        if (clave == cat.claveDesvio() || clave == 0) {
            r.desvia(Desvio.D_CLAVE);
            if (tm != 1 && tm != 2) r.desvia(Desvio.G_ESQUEMA);            // 21127: TM := TM de desvío
        } else if (tm == 1 || tm == 2) {
            if (!cat.existe(clave, tm)) r.desvia(Desvio.D_CLAVE);
        } else {
            // TM inválido: el fuente marca D y G siempre, aunque la clave exista.
            // El IF siguiente (línea 8556) ya evalúa la clave de desvío, no la original.
            r.desvia(Desvio.D_CLAVE);
            r.desvia(Desvio.G_ESQUEMA);
        }
    }
    void validaFechaYSucursal(ResultadoValidacion r, LocalDate fechaProceso) {
        // Desvío A: la fecha contable distinta a la de proceso se sobrescribe, no se rechaza.
        if (r.mov().fechaContable().equals(fechaProceso)) {
            r.fechaContable(r.mov().fechaContable());
        } else {
            r.fechaContable(fechaProceso);
            r.desvia(Desvio.A_FECHA);
        }

        int indTm = props.form4().contains(r.sistema()) ? 1 : r.tipoEsquema();   // W77-INDTM
        int nat = cat.naturaleza028(r.clave(), indTm);                           // WKS-PT-NATS028
        r.naturaleza028(nat);

        if (nat == 1 || nat == 2) {
            int suc = r.mov().sucursalIniciativa();

    void validaLibroYCentralizacion(ResultadoValidacion r, Indices idx) {

                idx.fija(indLib, indMon);

                r.libro(cat.libroDesvio());
                idx.fija(cat.libroDesvio() + 1, 1);
                r.desvia(Desvio.F_LIBRO);
            }

        if (cat.indicadorS254(r.clave(), r.indTm()) == 2) {

            if (lm.centraliza() && lm.sucursalCentralizadora() > 0) {
                r.sucursalPromotora(lm.sucursalCentralizadora());
            } else if (lm.centraliza()) {
                r.sucursalPromotora(cat.sucursalDesvio());
                r.desvia(Desvio.C_SUC_PROMOTORA);
            } else {
                int suc = r.mov().sucursalPromotora();
                if (suc > 0 && suc <= props.sucursalMaxima()) {
                    r.sucursalPromotora(suc);
                } else {
                    r.sucursalPromotora(cat.sucursalDesvio());
                    r.desvia(Desvio.C_SUC_PROMOTORA);
                }
            }
        }
    }
    void validaTipoCredito(ResultadoValidacion r) {
        if (!props.sistemasCredito().contains(r.sistema())
                || props.sinValidarTipoCredito().contains(r.sistema())) {   // 404 y 414
            return;
        }
        int tc = r.tipoCredito();
        boolean desvio;
        if (tc == cat.tipoCreditoDesvio()) {
            desvio = true;
        } else if (tc > 0 && tc < 100) {
            desvio = r.sistema() != 403 && cat.numTipoCredito(tc) == 0;     // 403 no consulta catálogo
        } else {
            desvio = true;
        }
        if (desvio) {
            r.productoDesvio(tc);                       // RMC-PRODUC-D conserva el valor original
            r.tipoCredito(cat.tipoCreditoDesvio());
            r.desvia(Desvio.E_TIPO_CREDITO);
        }
    }

@Component
@RequiredArgsConstructor
public class CvetranWriter implements ItemWriter<ResultadoValidacion> {

    private final FlatFileItemWriter<Cvetran> cvetran, cvetranE;
    private final FlatFileItemWriter<CvetranFs> cvetranFs;
    private final PunteoWriter punteo;                     // 21155-GRABA-PUNTEO
    private final CatalogosContables cat;
    private final P130Properties props;

    @Override
    public void write(Chunk<? extends ResultadoValidacion> chunk) throws Exception {
        for (var r : chunk) {
            if (r.mov().status() != 1) continue;
            int tipoProc = r.mov().tipoProceso();
            var reg = r.toCvetran()
                    .cveRegistro(tipoProc >= 80 && tipoProc <= 89 ? tipoProc : 1)   // W88-NPROCESO
                    .evento(props.form4().contains(r.sistema()) ? 0 : cat.evento(r.clave(), r.tipoEsquema()))
                    .fideicomiso(fideicomiso(r));
            cvetran.write(Chunk.of(reg));
            if (props.integradoFfs().contains(r.sistema())) cvetranFs.write(Chunk.of(reg.toFs()));

            // Comportamiento real del fuente: el punto de la línea 8390 cierra el IF del 403,
            // así que CVETRANE se escribe para todos los sistemas.
            var ext = reg.conAuxiliares403(r.sistema() == 403 ? r.mov().cliente403() : reg.numAux());
            cvetranE.write(Chunk.of(ext));
            punteo.agrega(r);
        }
    }

    private long fideicomiso(ResultadoValidacion r) {
        return switch (r.sistema()) {
            case 402 -> r.mov().fideicomiso402();
            case 707, 203 -> 0L;                               // internacional y transferencias
            default -> r.mov().fideicomiso();
        };
    }
}

Riesgos de migración
Punto que cierra antes el IF del sistema 403

En 21105-STATUS-UNO el punto al final de la línea 8390 termina el IF W77-SISTEMA-PARAM = 403. Las líneas 8391 a 8397, incluido WRITE REG-CVETRANE, se ejecutan para todos los sistemas, y RMC-FEC-PART recibe el intercompany fuera del 403. La indentación sugiere lo contrario.

Subíndice de libro con desbordamiento y estado arrastrado

W77-INDLIB es PIC 9(02); COMPUTE W77-INDLIB = A00-R01-IND-CONTA + 1 (línea 8605) convierte el libro 99 en subíndice 00. En sistemas que no son de crédito ni central, el bloque de centralización (líneas 8638 a 8668) usa W77-INDLIB y W77-INDMON con el valor que dejó el registro anterior.

Clave válida reemplazada cuando el esquema es inválido

Con tipo de esquema distinto de 1 y 2 (líneas 8552 a 8560) el programa marca desvío D y G de forma incondicional y el IF posterior evalúa la clave de desvío, no la original.

Código muerto y lógica comentada

El desvío H se evalúa pero nunca se asigna. Hay IF comentados sobre W88-SISTEMA-ESQ-ETL en las líneas 6354, 8265, 8291 y 8312 que dejan activas las ramas ELSE, y un límite de depuración de 200 registros comentado en la línea 8038.

Límite del ciclo de tipos de crédito

21107-TIPO-CRED itera hasta WKS-IND-10, que en 15080 recibe la última clave cargada del catálogo y no el máximo; si CPPS no entrega las claves en orden ascendente, las mayores no se buscan. En cada iteración sin coincidencia A00-R01-TIPOCREDITO se pone en cero.

Hardcodes de sistemas y rangos

Sistemas 252, 402, 403, 404, 414, 707, 804 y 203, tope de sucursal 10000, monedas 0, 1 y 3 y claves 11 y 5 de ATLAS, nodo de impresión CSI por 100, y en 21104 producto e instrumento forzados a cero para la consulta S016. Todo pasa a application.yml.

  • Confirmar si algún sistema que no es de crédito ni central tiene claves con indicador S254 igual a 2; de ser así, la centralización depende de índices del registro anterior.
  • RN-CORE-GL-063 indica desvío D solo si la clave no existe; el fuente lo aplica siempre que el tipo de esquema es inválido. Revisar la redacción de la regla o el comportamiento esperado.
  • RN-CORE-GL-069 dice que la alerta ESENDAUTO se levanta en la primera ocurrencia de cada desvío; en el fuente se levanta al cierre (21131 desde 20500-CERRAR-ARCH) según contadores. Validar.
