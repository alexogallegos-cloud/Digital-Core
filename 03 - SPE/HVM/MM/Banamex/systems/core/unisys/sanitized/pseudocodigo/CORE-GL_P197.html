P197 · ROTABASE — Rotación de bases y actualización de saldos cíclicos (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P197.cbl (3195 LOC) · Programa ejecutor del paso MANTCICLO (batch de fin de día / cierre de mes) · LegacyCore · Unisys ClearPath MCP (COBOL85 + DMSII)

Convenciones: nombres traducidos (Unisys→legible); [P197 Lnnnn] = origen; (BR: RN-...) = regla de negocio. Se conserva el nombre COBOL original entre comentarios.

1. Resumen funcional

P197 (PROGRAM-ID interno ROTABASE) es el programa de mantenimiento cíclico de la base de saldos y de la base de movimientos del sistema contable CORE-GL. Recibe como parámetro el número de sistema y, según la configuración de bases de ese sistema (dataset de control CORE-GLB03SISMEN), ejecuta el proceso diario siempre y —cuando detecta cierre de mes— además el proceso mensual de rotación de bases. [P197 L10-13,L1370-1445]

El proceso diario borra los niveles/contadores del día en curso en las bases de saldos y movimientos, y regenera la posición del día siguiente. El proceso mensual aplica la política de retención por número de ciclos (NUMCICDIA, NUMCICMES): calcula fechas de borrado y elimina información vencida de los datasets diarios (posición, posición contable, estado de cuenta) y mensuales (saldos mensuales consolidados), consolida los saldos del mes, recrea (CREATE) físicamente los datasets de saldos/posición y avanza los contadores de número de base. (BR: RN-CORE-GL-807, RN-CORE-GL-809, RN-CORE-GL-810, RN-CORE-GL-811)

Es un programa de plomería de datos DMSII de alto impacto: su rol en el batch (secuencia P194-P197) es preparar/rotar las bases al pasar de un ciclo contable al siguiente. Está protegido por un control de alta disponibilidad (dataset B05PROCESOS) para no ejecutarse dos veces el mismo día, y por un semáforo de estatus de base de saldos (STABDSAL). Todos los errores se registran vía la librería de despliegue LIB-DISP y, ante fallo DMSII, el programa se auto-marca con estatus -1 (aborta).

2. Datos y archivos

Bases DMSII (DATA-BASE SECTION) [P197 L41-44]

  • BASESDO = CORE-GLBD11SDOCORE-GL — base de saldos del sistema. Estructuras usadas:
  • B00-SDO-* — arreglo de control de niveles por día (LECARCDIA, MOVCICDIA, SDOCICDIA, ocurre por día del mes).
  • B20SXSDOMENCON / registro CORE-GLB20SDOMENCON — saldos mensuales consolidados (clave AAMM+concepto+producto+instrumento+moneda). (BR: RN-CORE-GL-810)
  • B21SXSDMENCON1 / CORE-GLB21SDMENCON1 — detalle de saldos mensuales consolidados por índice de concepto.
  • B70SXPOSICION / CORE-GLB70POSICION — posición financiera diaria (clave CSI+fecha+producto+instrumento+moneda). (BR: RN-CORE-GL-810)
  • B71SXPOSDIAAD1 / CORE-GLB71POSDIAAD1 — posición diaria adicional (índice fijo 26).
  • B72SXPOSCONTA / CORE-GLB72POSCONTA — posición contable (clave CSI+fecha+cuenta).
  • B80SXEDOCTA / CORE-GLB80EDOCTA — estado de cuenta (clave fecha de contabilización).
  • BASEMOV = CORE-GLBD12MC001CORE-GL — base de movimientos cíclicos. Estructuras: B01SXMOVCTO/CORE-GLB01MOVCTO (movimientos por fecha contable), B02SXIMPADICIC/CORE-GLB02IMPADI (importes adicionales), B03SXDATADIC/CORE-GLB03DATADI (datos adicionales), B00-MOV-* (control de niveles).
  • BASEHIS = CORE-GLBD13MOVHICORE-GL — comentada / no usada [P197 L44] ⚠ [CÓDIGO MUERTO].

Archivo de salida (FILE-CONTROL / FD) [P197 L30,L36-39]

  • V00-REPORTE2 (ASSIGN TO PRINTER, registro PIC X(132)) — reporte de impresión de mensajes "ADMINISTRADOR DE MOVIMIENTOS". Título físico dinámico WKS-TIT-REPORTE2 ((CORE-GL)Snnn/LIST/P197/...).

Parámetros de entrada (LINKAGE — PROCEDURE DIVISION USING) [P197 L1365-1368]

  • WKS-PARAM-SISTEMA — número de sistema a procesar (entrada, obligatorio > 0). (BR: RN-CORE-GL-808)
  • WKS-SAL-NOMBD11 — salida: nombre de la base de saldos abierta.
  • WKS-SAL-NOMBD12 / WKS-SAL-NOMBD12-INI — salida: nombre de la base de movimientos vigente / la inicializada por rotación.

Datasets/registros de control (WORKING-STORAGE, vía librerías)

  • CORE-GLB01SISDIA (entry CONSISDIA de LIB-CONTROL): fechas de proceso/consulta por sistema y CSI (funciones 1..11). [P197 L400-625]
  • CORE-GLB03SISMEN (entry CONSISMEN): configuración mensual de bases por sistema — TIPBD, STABDSAL, NUMCICDIA, NUMCICMES, AAMM(n), NOMBDSAL, NOMBDMOV(n), NUMBDMOV(n), MODSIS, RESCSI (funciones 1,9,15,17).
  • CORE-GLB04SISTEMA (entry B04SISTEM): estatus de esquema/proyección del sistema.
  • CORE-GLB05PROCESOS (entry B05PROCESOS): control de ejecución de procesos (alta disponibilidad) — STAPGM, NUMPRO, FCHPRO.

Librerías externas invocadas (CALL … IN/OF …)

  • SOPORTECOMS (CSIID) → obtiene el número de CSI del host. [P197 L1863]
  • CTLVER (DAME_TIT) → resuelve el título físico de una librería por versión. [P197 L1535,L1648]

  • GENERALSUPPORT (CURRENT_DATE) → fecha/hora de máquina. [P197 L1461]

  • LIB-DISP (LJ) → despliegue/registro de mensajes y errores.
  • LIB-L002 (CONTROLES) → registro de bitácora de control del sistema.

  • B71-SDO-KEYIND = 26 — índice fijo de posición diaria adicional. [P197 L2669,L2696,L2705]
