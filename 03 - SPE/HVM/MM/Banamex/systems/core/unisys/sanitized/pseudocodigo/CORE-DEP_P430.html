P430 · Fusión de Archivos Gerenciales X/Gerencial (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: p430.cbl (537 líneas de fuente propias + COPY compartidos) · batch de reconciliación gerencial · BC-12

Convenciones: nombres traducidos (Unisys→legible); [p430 Lnnnn] = origen en archivo fuente (col. 7-12); (BR: RN-CORE-DEP-...) = regla de negocio aplicada.

Versión: CORE-DEPP430 · 25MTP005 · FEB/2006 Cuenta MAX 2da. Etapa.

1. Resumen funcional

P430 es el concentrador gerencial multi-CSI del sistema de captación CORE-DEP (Banco Nacional de México / LegacyCore). Su función es leer los archivos X/Gerencial de los dos Centros de Servicio Integral —GERENCIAL-MTY (Monterrey) y GERENCIAL-VDM (México/Valle de México)— y fusionarlos en una sola cinta de salida (GERENCIAL-TAPE, CORE-DEP/FILE/INTS/50003S02/10/YYYYMMDD/AHOSDOS.), que alimenta el proceso ETL de reportes gerenciales nacionales de ahorros.

El programa opera exclusivamente en modalidad mensual: verifica que la fecha de proceso sea fin de mes y aborta si no se cumple la condición. Además valida header y trailer de cada archivo de entrada —conteo de registros e importe acumulado— antes de escribir el resultado consolidado. Genera también un reporte impreso (IMPRESION-CSI) con el desglose por plaza (MTY y VDM) de número de cuentas e importes integrados y faltantes en el sistema de clientes.

El programa consulta la base DMSII CORE-DEPBD01CAPTACION solo en modo INQUIRY (lectura) para obtener la fecha de proceso desde el dataset de control CORE-DEPB02CONTROL y para validar el día operativo mediante la librería compartida LOCSUP (S006).

2.4 Layout del registro de salida (D-REG-GERENCIAL, 90 chars)

Versión DISPLAY del registro de entrada, expandida a 90 caracteres. El trailer de salida agrega:

  • D-GER-NUME-CTESI (8): número de contratos integrados en clientes
  • D-GER-IMPO-CTESI (12V99): importe de contratos integrados
  • D-GER-NUME-CTENO (8): número de contratos faltantes en clientes
  • D-GER-IMPO-CTENO (12V99): importe de contratos faltantes

4.6 Párrafo 20002000-FECHA-PRO — Obtención y Validación de Fecha de Proceso

PROCEDIMIENTO Obtener_Fecha_Proceso():               // 20002000-FECHA-PRO · [p430 L294010]

  // Busca el registro de control B02 para obtener la fecha de proceso
  EJECUTAR 90000002-B02CONTROL-FIND      // [COPY 25MTP002] — FIND primer registro de CORE-DEPB02CONTROL

  SI WS-STATUS-BASE > 0 ENTONCES
    SI WS-STATUS-BASE = 1 ENTONCES
      MOVER "ERROR REG. DE CONTROL VACIO    " → mensaje_error
      EJECUTAR 70000050-MENSAJE
      LLAMAR SYSTEM DMTERMINATE
    SINO
      CONCATENAR "ERROR AL HACER FIND A B02 " + WS-STATUS-BASE → mensaje_error
      EJECUTAR 70000050-MENSAJE
      LLAMAR SYSTEM DMTERMINATE
    FIN-SI
  FIN-SI

  // Proyecta la fecha para determinar si es fin de mes (condición mensual)
  EJECUTAR 20002100-PROY-FEC  [hasta 20002100-EXIT]

  // Validación de proceso mensual (regla obligatoria)
  SI WS-MENSUAL ≠ 1 ENTONCES
    MOVER "HOY NO ES MENSUAL            " → mensaje_error   // ⚠ programa aborta si no es fin de mes
    EJECUTAR 70000050-MENSAJE
    LLAMAR SYSTEM DMTERMINATE
  FIN-SI

  // Inicializa registro de salida y propaga fechas a títulos de archivos
  MOVER LOW-VALUES              → registro_gerencial_display  // D-REG-GERENCIAL
  MOVER fecha_proceso            → FECHA-GER   // título GERENCIAL-MTY (6 dígitos YYMMDD)
  MOVER fecha_proceso            → FECHA-GER1  // título GERENCIAL-VDM
  MOVER fecha_proceso            → FECHA-GER2  // título GERENCIAL-TAPE (8 dígitos YYYYMMDD)
  MOVER fecha_proceso            → carátula_fecha  // WS-CARAT-FECHA

  // Copia componentes dd/mm/aa a campos auxiliares
  MOVER WS-PRO-DD → WS-PRO-DD1 ; MOVER WS-PRO-MM → WS-PRO-MM1 ; MOVER WS-PRO-AA → WS-PRO-AA1
  MOVER fecha_proceso_DMA       → D-GER-FEC-PROCESO  // fecha proceso en formato DMA

  // Propaga fecha al encabezado de reporte (campos de impresión)
  MOVER WS-PRO-DD → WS-GEREN-DIA1 ; MOVER WS-PRO-MM → WS-GEREN-MES1 ; MOVER WS-PRO-AA → WS-GEREN-ANO1

  // ⚠ [HARDCODE-SOSPECHOSO] Fija identificadores del sistema en el header de la cinta
  MOVER "CORE-DEP"              → D-GER-NUM-SISTEMA   // [p430 L642]
  MOVER "SISTEMA CAPTACION" → D-GER-NOM-SISTEMA   // [p430 L643]
  MOVER 1                   → D-GER-TIPO-REG       // tipo 1 = registro header [p430 L644]

  MOVER B02-NUM-CSI         → número_CSI_carátula  // WS-CARAT-CI
  MOVER 0                   → subnodo_carátula      // WS-CARAT-SUBNODO

4.7 Párrafo 20002100-PROY-FEC — Proyección de Fecha (¿Es Fin de Mes?)

PROCEDIMIENTO Proyectar_Fecha():                     // 20002100-PROY-FEC · [p430 L319010]

  // Determina si la fecha de proceso es fin de mes proyectando un día adelante
  SI fecha_val_task > 0 ENTONCES   // fecha viene por parámetro TASKVALUE (override operativo)
    MOVER fecha_val_task            → WS-S006-FECHA1
    MOVER 1                         → WS-S006-FECHA2    // suma 1 día
    MOVER 13                        → WS-S006-FORMATO   // formato AMD
    MOVER 13                        → WS-S006-FUNCION   // función: proyectar fecha
    EJECUTAR 40000000-CALL-FECPRO   // llama LOCSUP para proyectar fecha_val_task + 1 día
    MOVER WS-S006-FECHA1            → WS-FEC-CALCULADA-AMD1  // fecha proyectada desde parámetro
  SINO                              // fecha viene de B02-FECHA-LINEA (base de datos)
    MOVER B02-FECHA-LINEA           → WS-FEC-CALCULADA-AMD   // fecha proyectada desde base
  FIN-SI

  // Proyecta un día hacia atrás la fecha linea para obtener la fecha de proceso real
  EJECUTAR 20002110-DIAPRO

4.8 Párrafo 20002110-DIAPRO — Cálculo de Fecha de Proceso (−1 día)

PROCEDIMIENTO Calcular_Fecha_Proceso():              // 20002110-DIAPRO · [p430 L329010]

  // Resta 1 día a la fecha linea actual para obtener la fecha de proceso real
  // (al correr este paso las fechas ya fueron proyectadas al siguiente día operativo)
  MOVER B02-FECHA-LINEA      → WS-S006-FECHA1
  MOVER 1                    → WS-S006-FECHA2    // resta 1 día
  MOVER 12                   → WS-S006-FORMATO   // formato entrada AMD
  MOVER 15                   → WS-S006-FUNCION   // función: restar días hábiles
  EJECUTAR 40000000-CALL-FECPRO  // llama LOCSUP; resultado en WS-S006-FECHA1

  // Determina si es fin de mes comparando el mes del día calculado contra el mes proyectado
  SI fecha_val_task > 0 ENTONCES
    MOVER fecha_val_task       → fecha_proceso     // WS-FECHA-PRO
    SI WS-PRO-MM ≠ WS-CALCULADA-MM1 ENTONCES
      MOVER 1                  → indicador_mensual  // WS-MENSUAL: es cambio de mes → proceso mensual
    FIN-SI
  FIN-SI

  SI fecha_val_task = 0 ENTONCES
    MOVER WS-S006-FECHA1       → fecha_proceso     // WS-FECHA-PRO = fecha linea − 1 día
    SI WS-PRO-MM ≠ WS-CALCULADA-MM ENTONCES
      MOVER 1                  → indicador_mensual  // WS-MENSUAL
    FIN-SI
  FIN-SI

  // WS-MENSUAL = 1 indica que la fecha de proceso es fin de mes → programa continúa
  // WS-MENSUAL = 0 → programa aborta en 20002000-FECHA-PRO

PROCEDIMIENTO Procesar_Detalle():                    // 50004300-DETALLE · [p430 L449510]
