P046 · Driver Online Revocaciones/Cancelaciones Telethon (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: P046.cbl (51 LOC · ALGOL wrapper) · Canal online COMS Telethon · BC-17

Convenciones: nombres traducidos (Unisys MCP→legible); [P046 Lnnnn] = origen en fuente (col 7+, número secuencial); (BR: RN-CORE-DEP-...) = regla de negocio.

Nota de lenguaje: P046 es ALGOL (no COBOL). No tiene PROCEDURE DIVISION ni párrafos; el cuerpo es secuencial/plano. Los bloques lógicos se enumeran como secciones funcionales equivalentes.

1. Resumen funcional

P046 es un programa driver en ALGOL que actúa como envolvente (wrapper) de la librería L046/REVOCA del subsistema Telethon de captación. Su única responsabilidad es inicializar el canal de comunicación en línea (COMS) y delegar la transmisión de revocaciones/cancelaciones al procedimiento ENVIA_CANCELACIONES contenido en esa librería. Antes de invocar el canal, resuelve dinámicamente el título de la librería a través del control de versiones (CTLVER / función DAME_TIT), con un fallback fijo hardcodeado para garantizar operación si la consulta falla. Finalmente configura opciones de diagnóstico MCP y construye un nombre único de listado basado en la marca de tiempo del sistema.

El programa se activa condicionalmente desde WFL LINEA CORE-DEP únicamente cuando el archivo de control CORE-DEPBD06TELETON\CONTROL está residente en DMSII; de lo contrario, permanece deshabilitado en COMS sin ninguna acción (BR: RN-CORE-DEP-106).

3. Mapa de control

P046 es ALGOL plano: un único bloque BEGIN…END sin párrafos COBOL. El flujo es estrictamente secuencial:

P046  BEGIN
│
├─ [DECLARACIONES]
│    ├─ LIBRARY CTLVER  →  DAME_TIT, CHECAME          [P046 L10000700–L10001600]
│    ├─ LIBRARY TIME_OUT                               [P046 L10001800]
│    └─ PROCEDURE ENVIA_CANCELACIONES (importada)      [P046 L10002000–L10002400]
│
├─ B1. Resolver_Titulo_Libreria                        [P046 L10002900–L10003300]
│    └─ DAME_TIT("CORE-DEPL046REVO", EA_TIT)
│         ├─ [FALLA] → TITLE := fallback fijo          (BR: RN-CORE-DEP-641)
│         └─ [OK]    → TITLE := EA_TIT dinámico
│
├─ B2. Desconectar_Control_Versiones                   [P046 L10003500]
│    └─ DELINKLIBRARY(CTLVER)
│
├─ B3. Configurar_Opciones_Diagnostico_MCP             [P046 L10003700–L10004000]
│    └─ MYSELF.OPTIONS := flags BDBASE+FAULT+DSED+ARRAYS
│
├─ B4. Construir_Nombre_Listado_Dinamico               [P046 L10004200–L10004400]
│    └─ MYSELF.BDNAME := "CORE-DEP/LIST/P046/1000/R000/" + TIME(15) + "."  (BR: RN-CORE-DEP-642)
│
└─ B5. Habilitar_Canal_y_Despachar_Cancelaciones       [P046 L10004600–L10004900]
     ├─ ENABLE(COMSINHDR, "ONLINE")
     └─ ENVIA_CANCELACIONES(COMSINHDR, COMSOUTHDR, DCIINPUTEVENT, DCITASKEVENT)
         (control no retorna a P046; TIME_OUT gestiona el bloqueo online)

END.

4. Lógica por sección

4.1 B1. Resolver_Titulo_Libreria() // [P046 L10002900–L10003300]

// Constante de identificación de versión: "CORE-DEPL046REVO"
identificador_version  // EVA_TIMEOUT = "CORE-DEPL046REVO"  ⚠ [HARDCODE]
titulo_resuelto        // EA_TIT[0:71] — array de 72 bytes

resultado := LLAMAR DAME_TIT(identificador_version, titulo_resuelto)
             // DAME_TIT de LIBRARY CTLVER (CTLVERS) · retorna entero negativo si falla

SI resultado < 0 ENTONCES
    // CTLVER no pudo resolver el título → usar fallback fijo
    REEMPLAZAR TIME_OUT.TITLE POR
        "(CORE-DEP)CORE-DEP/OBJECT/L046/REVOCA/25MTP002 ON CAPTACION"
        // ⚠ [HARDCODE-SOSPECHOSO] versión 25MTP002 hardcodeada; puede quedar
        //   desactualizada respecto a la versión vigente en producción
SINO
    // CTLVER resolvió el título dinámicamente
    REEMPLAZAR TIME_OUT.TITLE POR titulo_resuelto PARA 72 bytes
FIN SI

4.3 B3. Configurar_Opciones_Diagnostico_MCP() // [P046 L10003700–L10004000]

// Activar flags de diagnóstico y volcado en el descriptor del proceso (MYSELF)
opciones_proceso  // MYSELF.OPTIONS — atributo MCP del proceso corriente

CALCULAR opciones_proceso :=
    opciones_proceso
    Y activar_flag(BDBASE  : bit 1)   // volcado a BDBASE al terminar
    Y activar_flag(FAULT   : bit 1)   // captura de faults/abends
    Y activar_flag(DSED    : bit 1)   // DMSII SEDAS trace
    Y activar_flag(ARRAYS  : bit 1)   // protección de bounds en arrays

// Equivalente ALGOL: * & 1[VALUE(BDBASE):1] & 1[VALUE(FAULT):1]
//                      & 1[VALUE(DSED):1]   & 1[VALUE(ARRAYS):1]

4.4 B4. Construir_Nombre_Listado_Dinamico() // [P046 L10004200–L10004400]

// Construir nombre único de listado combinando prefijo fijo y marca de tiempo
mensaje_listado   // E_MSG[0:70]
nombre_listado    // MYSELF.BDNAME — nombre del archivo de listado del proceso

REEMPLAZAR mensaje_listado POR
    "CORE-DEP/LIST/P046/1000/R000/"   // ⚠ [HARDCODE] — prefijo fijo de ruta de listado
    , TIME(15).[15:48]            // timestamp del sistema: dígitos de posición 15 a 48
    , "."                         // sufijo separador

MOVER mensaje_listado A nombre_listado
    // MYSELF.BDNAME := E_MSG → el SO MCP asignará este nombre al listado de salida

4.5 B5. Habilitar_Canal_y_Despachar_Cancelaciones() // [P046 L10004600–L10004900]

// Habilitar el header de entrada COMS como canal online
LLAMAR ENABLE(cabecera_entrada_coms, "ONLINE")
       // cabecera_entrada_coms = COMSINHDR (INPUTHEADER)
       // "ONLINE" activa la capacidad de recibir transacciones del canal COMS

// Delegar el procesamiento al procedimiento ENVIA_CANCELACIONES de la librería L046/REVOCA
LLAMAR ENVIA_CANCELACIONES(
    cabecera_entrada_coms,          // COMSINHDR — canal de entrada COMS
    cabecera_salida_coms,           // COMSOUTHDR — canal de salida COMS
    evento_entrada_dci,             // MYSELF.DCIINPUTEVENT — evento DCI de entrada
    evento_tarea_dci                // MYSELF.DCITASKEVENT  — evento DCI de tarea/tarea
)
// TIME_OUT gestiona el bloqueo; si no hay actividad en el período configurado,
// la librería TIME_OUT termina el proceso. P046 no retorna desde esta llamada.
