P103 · FRAUDLINK — Generador de reporte diario de fraude (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: P103.cbl (334 LOC) · BATCH diario · BC-10

Convenciones: nombres traducidos (Unisys→legible); [P103 Lnnnnnn] = número de secuencia fuente cols 1-6; (BR: RN-CORE-DEP-xxx) = regla de negocio.

1. Resumen funcional

P103 (FRAUDLINK) es un programa batch diario del sistema CORE-DEP (Captación / Cargos y Abonos de Cuentas de Cheque, Banco Nacional de México) que extrae todos los movimientos del día con clave de fraude monitoreada (2001, 2444 o 2496) y genera un archivo de texto de longitud fija que se entrega al sistema S711 (gestión y bloqueo de fraude). El programa no bloquea cuentas directamente: produce el feed que S711 consume para ejecutar el bloqueo operativo. La cobertura por movimiento es de tres niveles: la clave principal del movimiento en B07MOVDIA, hasta 5 claves adicionales SAD internas del mismo registro B07 y hasta 10 claves adicionales externas de la base B13MOVCVES, para un máximo teórico de 16 registros de fraude por movimiento. El archivo de salida incluye un header de identificación (tipo "1"), registros de detalle (tipo "2") y un trailer de control (tipo "9") con contador e importe total para que S711 valide la integridad del envío.

(BR: RN-CORE-DEP-173, RN-CORE-DEP-175)

4.7 · Procesar_Movimientos_B07

PROCEDIMIENTO Procesar_Movimientos_B07():                     // 50001000-PROCESO · [P103 L139500]
Ciclo principal. Recorre secuencialmente todos los movimientos del día en B07MOVDIA. Por cada movimiento
aplicado evalúa fraude en tres niveles: clave principal, 5 claves adicionales SAD de B07 y hasta 10 en B13.

```
EJECUTAR Leer_Siguiente_Movimiento_B07()    // 90000007-B07MOVDIA-FINDN [COPY PRO/25MTP002]

SI estado_base > 0                          // WS-STATUS-BASE
ENTONCES
    SI estado_base = 1
    ENTONCES
        MOVER 1 A fin_de_archivo_b07        // W77-EOF-B07 = 1 — fin normal; termina ciclo UNTIL
    SINO
        CONSTRUIR mensaje "ERR FINDN A B07 {estado_base}" → texto_mensaje
        EJECUTAR Emitir_Mensaje_Error()
        LLAMAR SISTEMA DMTERMINATE          // error de lectura ≠ EOF → abort total

SI estado_base = 0                          // lectura exitosa
ENTONCES
    SI status_movimiento = 1                // B07-STATUS-MOVTO = 1
    ENTONCES
        CONTINUAR CON SIGUIENTE             // NEXT SENTENCE — omitir movimiento sin mensaje
        // ⚠ [DESCARTE-SILENCIOSO] — STATUS=1 = "en proceso / pendiente de aplicación"
        // Semántica exacta no confirmada en fuente ni DASDL; requiere validación operaciones CORE-DEP
    SINO
        // Descomponer autorización en partes mediante REDEFINES:
        MOVER autorización_movimiento A WKS-AUTORIZ-MOV  // B07-AUTORIZACION
        // → WKS-SUC-OPE(4), WKS-CAJ-OPE(2), WKS-SEQ-OPE(8) — solo WKS-SUC-OPE se usa aquí

        // Nivel 1: clave principal del movimiento B07
        MOVER CERO A índice_b07             // W77-IND-B07 = 0 (se usará en OPERO5-B07)
        EJECUTAR Evaluar_Clave_Principal_B07()

        // Nivel 2: hasta 5 claves adicionales SAD internas de B07
        EJECUTAR Evaluar_Claves_Adicionales_B07() 5 VECES

        // Nivel 3: claves externas en B13 (solo si el movimiento las tiene)
        SI indicador_movsads > 0            // B07-IND-MOVSADS > 0
        ENTONCES
            EJECUTAR Evaluar_Claves_B13()
```

4.8 · Evaluar_Clave_Principal_B07

PROCEDIMIENTO Evaluar_Clave_Principal_B07():                  // 50001100-MOV-ORIG · [P103 L144500]
Evalúa si la clave del movimiento principal de B07 es una clave de fraude monitoreada.

```

ENTONCES
    MOVER 0002           A código_banco     // WKS-REG-E03-BCO = 0002 (LegacyCore) ⚠ [HARDCODE-SOSPECHOSO]

4.9 · Evaluar_Claves_Adicionales_B07

PROCEDIMIENTO Evaluar_Claves_Adicionales_B07():               // 50001200-OPERO5-B07 · [P103 L146900]
Evalúa cada una de las hasta 5 claves de movimientos adicionales SAD del grupo `B07-OTROS-MOVSAD`.
Se invoca 5 TIMES desde PROCESO; `W77-IND-B07` avanza de 0 a 5, una unidad por invocación.

4.10 · Evaluar_Claves_B13

PROCEDIMIENTO Evaluar_Claves_B13():                           // 50001300-MOVS-B13 · [P103 L149500]
Accede a B13MOVCVES buscando registros adicionales del mismo contrato/autorización del movimiento B07.
Si existen, delega el escaneo de cada clave a `Evaluar_Clave_B13_Individual()`.

```
MOVER nro_contrato_b07   A ws_num_contrato   // B07-NUM-CONTRATO → WS-NUM-CONTRATO [COPY WOR]
MOVER autorización_b07   A ws_autorización   // B07-AUTORIZACION → WS-AUTORIZACION  [COPY WOR]
MOVER 0 A flag_sin_b13                       // W77-SIN-B13 = 0

EJECUTAR Buscar_B13_por_Contrato_Autoriz()   // 90000013-B13SXCTOAUT-FIND [COPY PRO/25MTP002]

SI estado_base > 0                           // WS-STATUS-BASE
ENTONCES
    SI estado_base = 1
    ENTONCES
        MOVER 1 A flag_sin_b13              // W77-SIN-B13 = 1 — no hay B13, no es error
