Toma la fecha contable del archivo de control corporativo y abre el LOG de cada CSI válido (2, 4 y 10). Verifica que la fecha del header coincida y que las ocho cifras del trailer cuadren con lo leído; un LOG sin trailer o con diferencias detiene el proceso. Después ordena los movimientos interregionales con estatus operado o aplicado por CSI, moneda, fecha y aplicación, acumula cargos y abonos por llave en el archivo indexado CORE-GL/FILE/COMPENSACION y copia esos movimientos al LOG general, que vuelve a ordenar para detección de diferencias. Emite la carátula de control de los LOG y el listado de movimientos eliminados.

/** WS-REG-LOG (160 bytes) con dos vistas REDEFINES además del detalle. */
public sealed interface RegistroLogCsi permits LogHeader, LogDetalle, LogTrailer {}

/** WS-REG-LOG-CONTROL: primer registro de cada LOG transmitido por XFER. */
public record LogHeader(String identificador,     // X(06)
                        String csi,               // X(03) abreviatura del CSI emisor
                        LocalDate fechaContable,  // 9(08) AAAAMMDD
                        String claveSistema,      // X(04)
                        LocalDateTime generado)   // FECHA 9(08) + HH MM SS
        implements RegistroLogCsi {}

/** WS-RG-LOG-TRAILER: cifras declaradas por el emisor. Operado = índice 1, aplicado = índice 2. */
public record LogTrailer(CifrasControl operado, CifrasControl aplicado) implements RegistroLogCsi {
    public static final String IDENT = "TRAILER";    // WS-RLT-IDENT X(07)
}

/** NCO/ICO, NAO/IAO, NCA/ICA, NAA/IAA: conteos 9(06) e importes 9(18)V99. */
public record CifrasControl(long numCargos, BigDecimal impCargos,
                            long numAbonos, BigDecimal impAbonos) {
    public static final CifrasControl CERO =
            new CifrasControl(0, BigDecimal.ZERO.setScale(2), 0, BigDecimal.ZERO.setScale(2));
}

static RegistroLogCsi parse(String r) {
    if (r.startsWith(LogTrailer.IDENT)) {
        return new LogTrailer(
                new CifrasControl(Fixed.entero(r, 7, 6),  Fixed.decimal(r, 13, 20, 2),
                                  Fixed.entero(r, 33, 6), Fixed.decimal(r, 39, 20, 2)),
                new CifrasControl(Fixed.entero(r, 59, 6), Fixed.decimal(r, 65, 20, 2),
                                  Fixed.entero(r, 85, 6), Fixed.decimal(r, 91, 20, 2)));
    }
    return LogDetalle.parse(r);   // el header se consume aparte: es siempre el primer registro
}
public record LogDetalle(int csiOrigen, int csiDestino,
                         int aplOrigen, int aplDestino,          // 9(04)
                         EstatusTrn estatus,                     // WS-RDI-STA-TRN
                         CodigoServicio servicio,                // WS-RDI-COD-SER
                         BigDecimal importe,                     // 9(16)V99 -> escala 2
                         int moneda,                             // 9(03)
                         LocalDate fechaContable,                // 9(08)
                         String raw) implements RegistroLogCsi { // se copia íntegro a LOG-GRAL

    public boolean interregional() { return csiOrigen != csiDestino; }
}

public enum EstatusTrn {
    ENVIADO(1), APLICADO(2), OPERADO(3), DENEGADO(4), PENDIENTE(5);
    final int codigo;
    EstatusTrn(int c) { codigo = c; }
    public boolean compensable() { return this == APLICADO || this == OPERADO; }
}

/** 10 cargo, 20 abono, 11 y 21 eliminación: la eliminación resta en lugar de sumar. */
public enum CodigoServicio {
    CARGO(10, Naturaleza.CARGO, 1), ELIM_CARGO(11, Naturaleza.CARGO, -1),
    ABONO(20, Naturaleza.ABONO, 1), ELIM_ABONO(21, Naturaleza.ABONO, -1);
    final int codigo; final Naturaleza naturaleza; final int signo;
    CodigoServicio(int c, Naturaleza n, int s) { codigo = c; naturaleza = n; signo = s; }
    public static Optional<CodigoServicio> de(int c) {
        return Arrays.stream(values()).filter(v -> v.codigo == c).findFirst();   // RDI-COD-SER-VAL
    }
}

@Configuration
public class ConcentraLogsJobConfig {

    /** 0000-MODULO-PRINCIPAL y 2000-PROCESA-SISTEMA. */
    @Bean
    Job concentraLogs(JobRepository repo,
                      Step fechaControl,          // 1000-INICIA-PROCESO + 11500-OBTIENE-FECHA-CTRL
                      Step verificaLogs,          // 2001-VERIFICA-CSIS: cuadre contra trailer, por CSI
                      Step concentraCompensacion, // 2010-PROCESA-CSI: SORT1 y COMPENSACION
                      Step ordenaLogGeneral) {    // 3000-PROCESA-LOG-GRAL: SORT2 sobre LOG-GRAL
        return new JobBuilder("CORE-GLP116", repo)
                .start(fechaControl)
                .next(verificaLogs)              // si un LOG no cuadra, el job se detiene aquí
                .next(concentraCompensacion)
                .next(ordenaLogGeneral)
                .build();
    }

    @Bean
    Step concentraCompensacion(JobRepository repo, PlatformTransactionManager tx,
                               MultiResourceItemReader<LogDetalle> logsCsi,   // LOGCSI de los CSI 2, 4 y 10
                               CompensacionWriter compensacion,
                               FlatFileItemWriter<LogDetalle> logGeneral) {
        return new StepBuilder("concentraCompensacion", repo)
                .<LogDetalle, LogDetalle>chunk(1000, tx)
                .reader(logsCsi)
                .processor(d -> d.interregional() && d.estatus().compensable() ? d : null)
                .writer(new CompositeItemWriter<>(List.of(compensacion, logGeneral)))
                .build();
    }
}

@Component
@RequiredArgsConstructor
public class FechaControlTasklet implements Tasklet {

    private final P116Properties props;
    private final ArchivoControlCorporativo control;   // lee el primer registro de CONTROL/CORP
    private final HostInfo host;                        // CSIID OF SOPORTECOMS

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        LocalDate fechaContable = control.fechaProceso(props.archivoControl())
                .orElseThrow(() -> new ProcesoAbortadoException("ARCHIVO DE CONTROL SIN REGISTRO"));

        int csi = props.csiAlias().getOrDefault(host.numCsi(), host.numCsi());
        if (csi == 10) csi = props.csiTandem();                         // PTER-CSI-CORP
        if (!props.csiValidos().contains(csi)) {
            throw new ProcesoAbortadoException("CSI INVALIDO EN LIB-CONTROL"); // SET MYSELF(STATUS) TO -1
        }
        var ec = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        ec.put("fechaContable", fechaContable);
        ec.put("csiLocal", csi);
        return RepeatStatus.FINISHED;
    }
}
@Component
@StepScope
public class VerificaLogTasklet implements Tasklet {

    @Value("#{jobExecutionContext['fechaContable']}") private LocalDate fechaContable;
    private final LogCsiRepository logs;                 // un Resource por CSI válido
    private final CuadreTrailer cuadre;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        for (Resource log : logs.delDia(fechaContable)) {
            try (var lector = LogCsiReader.abre(log)) {
                LogHeader h = lector.header();
                if (!h.fechaContable().equals(fechaContable)) {
                    throw new LogInvalidoException(log, "FECHA CONTABLE NO CORRESPONDE CON FECHA PROCESO");
                }
                var acumulado = new AcumuladorCifras();
                LogTrailer trailer = null;
                for (RegistroLogCsi r; (r = lector.siguiente()) != null; ) {   // 20023-LEE-LOG-CSI
                    if (r instanceof LogTrailer t) { trailer = t; break; }
                    acumulado.suma((LogDetalle) r);                            // 20021-SUMARIZA
                }
                // LOW-VALUES, HIGH-VALUES o fin físico sin trailer: el archivo llegó truncado.
                cuadre.valida(log, Optional.ofNullable(trailer), acumulado);   // 20025-BUSCA-DIFERENCIA
            }
        }
        return RepeatStatus.FINISHED;
    }
}

    public LogDetalle consolida(LogDetalle d) {
        var m = props.csiConsolidacion();
        return d.conCsi(m.getOrDefault(d.csiOrigen(), d.csiOrigen()),
                        m.getOrDefault(d.csiDestino(), d.csiDestino()));
    }

    /** 20021-SUMARIZA: motivo por el que un movimiento no entra a compensación, o vacío si entra. */
    public Optional<String> motivoRechazo(LogDetalle d) {
        if (!esValido(d.csiOrigen()) || !esValido(d.csiDestino())) return Optional.of("CSI/INVALIDO");
        if (!d.interregional())                                   return Optional.of("MOVTO. LOCAL");
        if (!d.estatus().compensable())                           return Optional.of("STA/INVALIDO");
        if (d.servicio() == null)                                 return Optional.of("NAT/INVALIDA");
        return Optional.empty();
    }
}
@Component
public class CuadreTrailer {

    /** 20025-BUSCA-DIFERENCIA. */
    public void valida(Resource log, Optional<LogTrailer> trailer, AcumuladorCifras contado) {
        if (trailer.isEmpty()) {
            throw new LogInvalidoException(log, "LOGCSI INCOMPLETO, SIN REG TRAILER");
        }
        // El fuente convierte cada acumulador a valor absoluto antes de comparar: el trailer no trae signo.
        CifrasControl op = contado.operado().abs(), ap = contado.aplicado().abs();
        LogTrailer t = trailer.get();
        if (!op.equals(t.operado()) || !ap.equals(t.aplicado())) {      // BigDecimal con la misma escala
            throw new LogInvalidoException(log, "DIFERENCIA DE TOTALES EN TRAILER",
                    Map.of("declarado", t, "contado", new LogTrailer(op, ap)));
        }
    }
}

@Component
@RequiredArgsConstructor
public class CompensacionWriter implements ItemWriter<LogDetalle> {

    private final CompensacionNacionalRepository repo;

    /**
     * 5010-PROCESA-SORT1 + 5050-ACTUALIZA-COMP-NAL. El SORT por llave y el corte de control
     * se reemplazan por un agrupamiento en memoria del chunk y un upsert por llave.
     */
    @Override
    @Transactional
    public void write(Chunk<? extends LogDetalle> chunk) {
        Map<LlaveCompensacion, Acumulado> porLlave = chunk.getItems().stream()
                .collect(Collectors.groupingBy(LlaveCompensacion::de,
                         Collectors.reducing(Acumulado.CERO, Acumulado::de, Acumulado::mas)));

        porLlave.forEach((llave, cifras) -> {
            CompensacionNacional reg = repo.findById(llave).orElseGet(() -> CompensacionNacional.nueva(llave));
            reg.suma(cifras);          // ver riesgo: el COBOL hace REWRITE con las cifras del grupo
            repo.save(reg);
        });
    }

Riesgos de migración
REWRITE reemplaza cifras en COMPENSACION

En 5050-ACTUALIZA-COMP-NAL (líneas 3108-3110) una llave existente se reescribe con las cifras del grupo actual. Si dos LOG generan la misma llave de compensación, las cifras del primero se pierden sin aviso.

Validaciones comentadas

La verificación de existencia de cada LOG (líneas 2364-2377 y 2856-2858) y el aborto por más de un LOG con diferencias (líneas 2333-2336) están comentados con marcas *ASM. Un LOG faltante deja al proceso esperando intervención del operador.

Cuadre por valor absoluto

20025-BUSCA-DIFERENCIA convierte los acumuladores a valor absoluto antes de compararlos con el trailer (líneas 2588-2603); un neto con signo invertido pasa la validación.

Consolidación de CSI compilada

Los CSI 9, 7, 1 y 6 se reasignan a 10 y 4 en dos párrafos duplicados (20023 y 4050), y los CSI 32 y 12 del servidor se tratan como 10 (línea 2095). Un cambio en la red de centros obliga a modificar el código en tres lugares.

Fechas de seis dígitos en llaves

FECHA-COMP y WS-RS1-FECHA son PIC 9(06) y reciben la fecha contable de ocho dígitos; el siglo se trunca y el orden de la llave depende de un pivote implícito.
