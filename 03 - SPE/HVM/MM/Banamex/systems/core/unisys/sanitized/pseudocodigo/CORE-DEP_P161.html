P161 · Preparación de Archivo de Movimientos Aplicados hacia S111 (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: P161.cbl (553 LOC) · Batch diario de retroalimentación CORE-DEP→S111 · BC-06

Convenciones: nombres traducidos (Unisys COBOL→legible); [P161 Lnnnn] = línea fuente; (BR: RN-CORE-DEP-...) = regla de negocio.

1. Resumen funcional

P161 (CORE-DEPP161) prepara el archivo de retroalimentación que el CORE-DEP envía al S111 con los movimientos que efectivamente aplicó: altas de cuentas, bloqueos, desbloqueos/cancelaciones y asignaciones TEF. Cierra el ciclo de conciliación iniciado por P176: el S111 solicita vía prealtas, el CORE-DEP aplica, y P161 confirma qué se aplicó. El programa barre los datasets DMSII B03CONTRATOS (contratos captación) y B04PTEF (transferencias electrónicas de fondos), filtra los registros cuya fecha de evento coincide con la fecha de lote (fecha-línea de B02CONTROL), y produce un archivo secuencial estructurado con header, registros de detalle (tipos 01–06) y trailer que el S111 consume para conciliar su cartera. Incorpora un flag de descomisionamiento (B02-USO-FUTURO-05) que permite desactivar el proceso sin modificar código. (BR: RN-CORE-DEP-521)

4.8 · Abrir_Archivo_S111

PROCEDIMIENTO Abrir_Archivo_S111():  // 10010600-ABRO-ARCH-S111 · [P161 L130100]
```
MOVER CEROS A fecha_en_etiqueta_archivo    // WKS-ETIQ-S111-FECHA

SI fecha_parametro > 20070830              // ⚠ [HARDCODE-SOSPECHOSO] corte histórico 2007-08-30
   SI fecha_parametro < fecha_proyectada
      // El parámetro es válido y previo al día hábil proyectado: usar el parámetro
      MOVER fecha_parametro A fecha_proyectada   // WKS-I01-FECH-PROYECTADA
   SINO
      // El parámetro excede la fecha proyectada: ERROR
      CONCATENAR "FECHA ERRONEA, ES MAYOR A LA FECHA LINEA "
                 " FECHA PARAM: " fecha_parametro
                 " FECHA LINEA: " fecha_linea
              EN texto_mensaje
      EJECUTAR 70000050-MENSAJE
      EJECUTAR 99000000-LLAMA-DMTERMINATE      // aborta
   FIN-SI
SINO
   // Parámetro menor o igual a 20070830: usar fecha-línea (sólo aviso)
   CONCATENAR "FECHA MENOR A 20070901, CONSIDERO FECHA LINEA"
              " FECHA PARAM: " fecha_parametro
              " FECHA LINEA: " fecha_linea
           EN texto_mensaje
   EJECUTAR 70000050-MENSAJE                   // aviso informativo, NO aborta
FIN-SI

MOVER fecha_proyectada A fecha_en_etiqueta_archivo  // construye nombre del archivo
                         fecha_lote                 // WKS-B02-FECHA-LOTE (actualiza)
MOVER csi_proceso      A csi_en_etiqueta_archivo    // WKS-ETIQ-S111-CSI

ABRIR ARCHIVO SALIDA I01-S111-APLICADOS
// nombre efectivo: "(CORE-DEP)CORE-DEP/FILE/S111/{CSI}/DEPINICIAL/{fecha}."
```
