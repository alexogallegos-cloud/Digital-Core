CORE-DEP · P109 a Java 21 Spring Boot

Lee el archivo de GBNP de la secuencia indicada en el archivo de control. Por cada detalle convierte la tasa de texto a número con seis decimales, bloquea el contrato en B03 y descarta clones, instrumentos inválidos, contratos cancelados o sin servicio GBNP. Si el contrato es válido y no tiene un cambio de producto que lo impida, graba fecha, tasa bruta y secuencia en B03. Cada contrato produce un renglón en GBNPRSLT con su código de resultado y, en la tercera secuencia, con la tasa y el rendimiento pagados; al final se ordena el resultado y se emiten reportes de tasas y mensajes.

public class AplicaTasaProcessor implements ItemProcessor<TasaGbnpRecord, ResultadoTasaRecord> {

    private final ValidadorContrato validador;       // 20000015-VALIDA-GENERAL
    private final ReporteMensajes mensajes;          // P02-REPMENSA
    @Value("#{jobExecutionContext['eventoContinua']}") private boolean eventoContinua;

    @Override
    public ResultadoTasaRecord process(TasaGbnpRecord r) {
        if (!r.esDetalle()) return null;             // 20000009-REW-ARCHCTRL: lo cubre el commit del chunk
        var res = eventoContinua ? validador.valida(r) : ResultadoContrato.error(r, 1003);
        if (res.esErrorReportable()) mensajes.error(res);   // WS-88-ERR-CODE-NOK (1001..1012)
        if (res.esClon()) return null;               // EXIT PERFORM: los clones no van al resultado
        return res.comoRegistro();                   // 20000018-MUEVE + 20000019-ESC-ARCHRSLT
    }

/** 20000015-VALIDA-TASA: reproduce los UNSTRING y el COMPUTE sin ROUNDED. */
public final class TasaGbnpParser {

    private static final BigDecimal TOPE = new BigDecimal("9999.999999");   // 9(04)V9(06)

    public static BigDecimal convierte(String tasa24) {
        // Primer UNSTRING por "-": solo decide si se convierte. COUNT = 0 solo si empieza con "-".
        if (tasa24.startsWith("-")) {
            return BigDecimal.ZERO.setScale(6);       // la tasa queda en cero
        }
        int sep = indexOfAny(tasa24, '.', '~');       // UNSTRING DELIMITED BY "." OR "~"
        String ent = sep < 0 ? tasa24 : tasa24.substring(0, sep);
        int desde = (sep < 0 ? tasa24.length() : sep) + 1;           // ADD 2 al COUNT (base 1)
        int fin = tasa24.indexOf('~', desde);
        String dec = desde >= tasa24.length() ? "" : tasa24.substring(desde, fin < 0 ? tasa24.length() : fin);

        // MOVE a 9(04) y 9(06): se pierden los dígitos de la izquierda que no caben.
        BigDecimal entero  = new BigDecimal(ultimos(digitos(ent), 4));
        BigDecimal decimal = new BigDecimal(ultimos(digitos(dec), 6));
        BigDecimal conv = entero.add(decimal.movePointLeft(dec.length()));   // 10 ** COUNT
        return conv.setScale(6, RoundingMode.DOWN).min(TOPE);              // sin ROUNDED: trunca
    }
}
@Component
@RequiredArgsConstructor
public class ValidadorContrato {

    private final ContratoCaptacionRepository b03;   // CORE-DEPBD01CAPTACION.B03CONTRATOS
    private final CatalogoB05 b05;                   // tabla de 30 instrumentos en memoria
    private final AsignadorTasa asignador;           // 20000036 + 20000041
    private final Estadisticos estadisticos;

    @Transactional
    public ResultadoContrato valida(TasaGbnpRecord r) {
        Optional<ContratoCaptacion> cto;
        try {
            cto = b03.findForUpdate(r.contrato());              // B03SXCTO-LOCK
        } catch (PessimisticLockingFailureException e) {
            return ResultadoContrato.error(r, 1006);            // deadlock
        } catch (DataAccessException e) {
            return ResultadoContrato.error(r, 1011);            // otro error de find
        }
        if (cto.isEmpty()) return ResultadoContrato.error(r, 1007);
        var c = cto.get();
        if (c.marcaClon() == 2 || c.marcaClon() == 3) {         // B03-MARCA-CLON
            if (c.marcaClon() == 3) estadisticos.suma(6);
            return ResultadoContrato.clon(r);                   // FREE: el lock se libera al salir
        }
        var instr = b05.instrumento(c.producto(), c.instrumento());   // 20000035-VAL-INSTRUME
        if (instr.error() > 0) return ResultadoContrato.error(r, instr.error());

        BigDecimal tasa = TasaGbnpParser.convierte(r.tasaTexto());      // 20000015-VALIDA-TASA
        int error = c.cancelado() ? 1002                               // 20000016-VALIDA-CTO
                  : c.gbnpServInd() == 0 ? 1010
                  : instr.noOperable() ? 1008 : 0;
        var res = asignador.obtieneTasaPaga(c, instr, error);          // solo en secuencia 3
        return res.ok() ? asignador.cambioProducto(c, instr, tasa, res) : res;
    }
}
@Component
@RequiredArgsConstructor
public class AsignadorTasa {

    private static final BigDecimal MILLON = BigDecimal.valueOf(1_000_000);
    private final HistoricoCorteRepository b06;                 // B06SXCTO
    @Value("#{jobExecutionContext['fechaProyectada']}") private LocalDate fechaProy;
    @Value("#{jobExecutionContext['secuencia']}")       private int secuencia;
    private LocalDate ultimoCorteLeido;                          // área B06 del último FIND (@StepScope)

    /** 20000036-OBT-TASAPAGA: solo se ejecuta en la secuencia 3 (WS-88-PROCE3). */
    ResultadoContrato obtieneTasaPaga(ContratoCaptacion c, Instrumento i, int error) {
        var res = ResultadoContrato.de(c, error);
        if (secuencia != 3) return res;
        switch (c.gbnpServInd()) {
            // Servicio 1: el fuente compara contra el B06 que quedó en memoria del último FIND,
            // no contra el del contrato. Aquí se conserva ese valor hasta que el SME decida.
            case 1 -> res.rendimiento(i.esDiario() ? c.rendiaIpab()
                    : fechaProy.equals(ultimoCorteLeido) ? c.intsCapit() : 0L);
            case 2 -> {
                var corte = b06.findByContrato(c.numero());
                if (corte.isEmpty()) return res.conError(1013);          // ERR FIND B06HISTORICO
                ultimoCorteLeido = corte.get().fecRealCorte();
                if (i.esDiario() || fechaProy.equals(corte.get().fecRealCorte())) {
                    res.fechaTasa(c.gbnpTasaFec()).pasoTasa(c.gbnpTasaSec())
                       .tasaAplicada(c.gbnpTasaBruta().multiply(MILLON).longValueExact())
                       .rendimiento(i.esDiario() ? c.rendiaIpab() : c.intsCapit());
                }
            }
            default -> { }                                               // otros valores: sin cambio
        }
        return res;
    }

Riesgos de migración
Validación de tasa desactivada

Las asignaciones de error 1005 (tasa cero) y 1012 (tasa mayor a 24) están comentadas en 20000015-VALIDA-TASA (líneas 3285-3293). Cualquier tasa que convierta a cero, incluida una que empiece con '-', se graba en B03-GBNP-TASA-BRUTA.

Truncamiento de la tasa

El COMPUTE de la línea 3277 no tiene ROUNDED y el destino es 9(04)V9(06): se truncan los decimales después del sexto. Además, si la parte decimal tiene más de seis dígitos, el MOVE a WS-TASA-DEC 9(06) pierde los de la izquierda y la división usa el conteo completo.

Errores 1013 y 1014 fuera del rango NOK

WS-88-ERR-CODE-NOK es 1001 THRU 1012 (línea 705). Con 1013 o 1014 no se ejecuta el FREE de B03 de la línea 3385 ni 20000042-ERR-REPMENSA.

Valor de B06 de otro contrato

En 20000036-OBT-TASAPAGA, rama de servicio GBNP 1, se usa B06-FECREAL-CORTE sin buscar B06 para el contrato actual (línea 3611).

Validación de CSI comentada

La verificación de CSI de la sucursal promotora con S080 (errores 1009 y 1015) está comentada en 20000013-GUA-ARCHRSLT (líneas 3125-3141); se aplican tasas de contratos de cualquier CSI.

Mensaje de instrumento inexistente sin datos

20000035-VAL-INSTRUME (líneas 3579-3591) arma el mensaje 'NO EXISTE PROD/INTS/MON' con campos de I02-R-ARCHRSLT, que 20000014-INICIALIZA-VARIABLES dejó en LOW-VALUES (línea 3233) y que se llenan después. El reporte no identifica el contrato. El mismo caso reusa el código 1011 de error de base.

Hardcodes

Hosts exentos de versión, indicador #ICACC#, el factor 1 000 000 y los códigos de error están compilados; se trasladan a application.yml o a constantes documentadas.
