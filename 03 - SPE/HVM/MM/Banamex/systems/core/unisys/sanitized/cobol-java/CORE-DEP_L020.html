CORE-DEP · L020 a Java 21 Spring Boot

CORE-DEPL020SDOS no consulta saldos. Declara los 20 procedimientos de la librería real con sufijo _C sobre una librería LIGACALL cuyo título se resuelve en ejecución con el catálogo de versiones CTLVER (identificador CORE-DEPL019SDOS), y exporta los mismos 20 nombres sin sufijo. Cada procedimiento exportado reenvía la llamada si el enlace está activo y devuelve 05 si está suspendido. Al levantarse valida su propia versión, resuelve el título de L019 e invoca LEVANTA_C; después se congela con FREEZE(CONTROL) y atiende los HI 1920 (suspender), 1950 (volver a ligar), 1 (estado) y 99 (ayuda) mientras tenga usuarios.

    // PROC_LEVANTA en start(); FREEZE(CONTROL, PROC_CONTROL) equivale a que el bean

}
    static final int REINTENTE_MAS_TARDE = 5;              // RESULT 05 del catálogo de L019

    private final AtomicReference<ConsultaSaldos> destino;  // LIGACALL; null = enlace suspendido

    ConsultaSaldosFachada(@Qualifier("core-depL019") ConsultaSaldos real) {
        this.destino = new AtomicReference<>(real);
    }

    /** CORE-DEPL020CONTRATO: los 20 procedimientos tienen exactamente esta forma. */
    @Override
    public int contrato(byte[] entrada, byte[] salida) {
        ConsultaSaldos d = destino.get();                     // IF B_LLAMAL020
        return (d != null) ? d.contrato(entrada, salida)       // CORE-DEPL020CONTRATO_C(...)
                           : REINTENTE_MAS_TARDE;
    }
    /** CORE-DEPL020FECCONT es PROCEDURE sin tipo: no puede devolver 05. */
    @Override
    public void fecCont(byte[] entrada) {
        ConsultaSaldos d = destino.get();
        if (d != null) {
            d.fecCont(entrada);
            return;
        }
        // El original no hace nada (ELSE comentado). Para no ocultarlo se lanza una excepción
        // que el cliente puede tratar como el 05 de los demás procedimientos.
        throw new EnlaceSuspendidoException("CORE-DEPL020FECCONT con enlace a L019 suspendido");
    }

@Component
@Endpoint(id = "enlacel019")
@RequiredArgsConstructor
class EnlaceSaldosEndpoint {

    private final ConsultaSaldosFachada fachada;
    private final ResolutorLibreria resolutor;

    @ReadOperation                                   // HI 1
    public String estado() {
        return fachada.enlaceActivo() ? "STATUS ACCESO A L019: CON" : "STATUS ACCESO A L019: SIN";
    }

    @WriteOperation                                  // HI 1920
    public String suspende() {
        ConsultaSaldos anterior = fachada.suspende(); // destino := null; desde aquí se responde 05
        // DELINKLIBRARY(LIGACALL): la instancia anterior se libera cuando terminen sus llamadas
        return "SE SUSPENDE LIGA A L019";
    }

    @WriteOperation                                  // HI 1950
    public String liga() {
        resolutor.resuelve().ifPresent(real -> {
            real.levanta();                          // LEVANTA_C
            fachada.conecta(real);                   // B_LLAMAL020 := TRUE
        });
        return "SE HACE LIGA A L019";
    }
}

Riesgos de migración
Fuente del inventario equivocado

El inventario asigna a CORE-DEP_L020 el archivo CORE-DEP_INC_L020.txt (fuente inferida), que es un copybook COBOL con llamadas a CORE-DEPL010CTRL y no contiene ningún punto de entrada CORE-DEPL020. El código real de esta fachada está en CORE-DEP_SOURCE_L019_SALDOS.txt (cabecera en las líneas 12-14: LIBRERIA DE CONTROL CORE-DEPL020SALDOS, CONTROLA LINKS DE LIBRERIA CORE-DEPL019SALDOS). Esta demostración cita ese archivo.

Ventana entre bandera y enlace

B_LLAMAL020 y LIGACALL se manejan por separado en el HI 1920 (líneas 517-519) y en el HI 1950 (líneas 520-523); una llamada concurrente puede ver la bandera activa con el enlace cerrado o con L019 todavía levantándose.

Llamada silenciosa en FECCONT

CORE-DEPL020FECCONT no informa nada cuando el enlace está suspendido (rama ELSE comentada en las líneas 355-356).

HI 4 no documentado

La condición del ciclo de control (línea 492) termina la librería con un HI 4, que no aparece en la lista de comandos del HI 99.

Hardcodes de ambiente

Los hosts ACYPBETA, CACYPBET, VDMBETA y CVDMBET, la versión 25MTP002, el MTP 002 de los mensajes y el título de LIBLJ están compilados.
