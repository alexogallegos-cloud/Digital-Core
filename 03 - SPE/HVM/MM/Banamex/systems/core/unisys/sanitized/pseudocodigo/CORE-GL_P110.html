1. Resumen funcional

P110 (PROGRAM-ID CORE-GL-P110, nombre de paso "MOVSBIT") genera el archivo de la BIT — la bitácora contable de movimientos del Libro Mayor (GL) — que alimenta al sistema CORE-DEP. Fue creado en enero 2006 por incremento de volumen de movimientos, para descargar del paso 108 la generación de este archivo y no entregar fuera de horario la información contable [P110 L10-16]. Lee el archivo de movimientos del día (LOG151) y su archivo de datos complementarios (LOG151-COMP), enriquece cada movimiento con su clave intercompany y con parámetros de catálogo (leyendas, esquemas contables, indicadores S250), aplica un filtro de selección (función, origen, coherencia línea/batch) y escribe el registro de 1900 bytes al archivo de salida MOVSCIG. Al cierre escribe el trailer, cierra archivos y dispara un WFL que transmite el archivo de la BIT [P110 L188-190]. El programa está diseñado para no abortar ante datos erróneos (aplica defaults y valida numéricos campo por campo).

⚠ Divergencia estructural fuente vs. catálogo: el diseño histórico documentado (y varias reglas del catálogo) describe la carga del archivo S016 clasificado en el paso 108 y la búsqueda de la clave intercompany en memoria o disco. En la fuente real actual todo ese camino está comentado/muerto [P110 L2508-2510, L2803-2815, L2920-2935]: la clave intercompany se resuelve hoy contra un catálogo de clientes en tabla cargado desde S080BD01CON (párrafos 12610-CARGA-CLIENTES / 21016-BUSCA-CLIENTE). Se refleja la FUENTE y se anota cada divergencia.

  • WKS-REG-MEM — tabla en memoria de hasta 4500 contratos S016 (WKS-S016-OCURRENCIAS OCCURS 4500) [P110 L344-352]. ⚠ Uso muerto.
  • WKS-TAB-CLIENTE / WKS-TAB-INBU / WKS-TAB-UNIN — tabla de clientes/intercompany cargada del catálogo (hasta 5000). Camino activo de resolución intercompany.
  • WKS-CORE-GLB01SISDIA — parámetros de control del día (fecha de proceso, nombres de archivos, niveles) obtenidos de la librería de control [P110 L391-415].
  • WKS-PARAMETROS (LINKAGE) — parámetros de entrada: WKS-SISTEMA-PARAMETRO, WKS-PROCESO-PARAMETRO (tipo de proceso línea/batch).
  • A00-BIT500-REGMOV — layout de salida de la BIT (registro tipo "5"), ~200 subcampos: función, sistema, producto, instrumento, sucursal promotora, contrato, hasta 5 grupos (CVETRAN, INDALFA, INDLEY, ESQCON, IMPORTE), fechas, autorizaciones, moneda, datos CORE-DEP (cheques, fraude FPC, TESOFE, EXTNET), leyendas, intercompany.
  • Acumuladores de control: WKS-TR500-TOT-REG, WKS-TR500-TOT-CVES, WKS-TR500-TOT-IMP (trailer WKS-TR500-CIG).
  • Banderas: W77-EOF, W77-ERROR-BIT, W77-BIT-SALIDA, W88-TIPO-LINEA/BATCH, W88-PROCESO-LINEA/BATCH, W88-ACCESA-MEMORIA/DISCO.

Librerías externas invocadas (CALL): SOPORTECOMS (CSIID del host), CTRLVERS/CTLVERS (DAME_TIT — resuelve títulos físicos de librerías por control de versiones), CORE-GLLIBCONTROL (CONSISDIA, CONSISMEN — datos de control del día), LIB-REGISTRA (CONTROLES — bitácora de control del proceso), LOCSUP (THECALENDAR — cálculo de fecha hábil anterior), S080BD01CON (L710_CONSUL_DETALLE — catálogos de parámetros/transacciones/clientes), LIB-DISP (LJ — despliegue de logs), WFL vía CALL SYSTEM (transmisión del archivo).

      CAMBIAR título de "CORE-GLLIBCONTROL" a titulo_resuelto

      CAMBIAR título de "S080BD01CON" a titulo_resuelto

PROCEDIMIENTO Cierra_Desc():                              // 111000-CIERRA-DESC · [P110 L2516]
   // Determina qué "función DEL" corresponde según cuál de las 10 fechas de archivo-movs
   // del control del día coincide con la fecha de proceso (mapa fecha→función 10..19)
   MOVER 0 A W77-DESC
   PARA cada nivel i EN 1..10:                             // [P110 L2519-2557]
      SI B01-fecarcmov(i) = fecha_proceso
         MOVER 1 A W77-DESC ; MOVER (9+i) A funcion_del    ⚠ [HARDCODE] funciones 10..19 por índice
   // Resolver título de la librería REGISTRA (control de bitácora del proceso)
   MOVER "CORE-GLL002R" A libid_nomb ; parametro_sistema A libid_sist
   SI W88-DESC (hubo coincidencia)
      LLAMAR "DAME_TIT IN CTRLVERS" ... GIVING status
      SI status < 0
         registrar log "ERROR EN CTLVERS, USO LIBRERIA REGISTRA SIN RELEASE NI MTP"
