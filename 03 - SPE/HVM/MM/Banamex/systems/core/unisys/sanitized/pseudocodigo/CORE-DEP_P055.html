P055 · Ejecutor de Procesos Especiales por Archivo Bandera (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: P055.cbl (1667 LOC) · Rol: orquestador online de procesos especiales bajo demanda · BC-12

Convenciones: nombres traducidos (Unisys→legible); [P055 Lnnnn] = origen en fuente; (BR: RN-CORE-DEP-...) = regla.

1. Resumen funcional

P055LIN es un servidor COMS de línea (online) que aguarda mensajes del bus COMS y, en cada heartbeat de 30 minutos, escanea hacia atrás desde la secuencia máxima (21) hasta encontrar un archivo bandera (ARCHBANDERA) residente en disco para el CSI local y la fecha contable en curso. Si encuentra uno, valida su cabecera y su registro de datos (tipo, CSI, fecha, hora programada de ejecución), y — cuando la hora del host ha superado la hora de proceso configurada — lanza el WFL correspondiente como proceso especial. Los tipos de lanzamiento son: WFL sin parámetro (tipo 01), WFL con parámetro (tipo 02), lote con parámetro (tipo 06) o remoción de archivo (tipo 90). Una vez aplicado, el archivo bandera es renombrado con el prefijo APLICADOP055/ para evitar reproceso. El programa corre en modo multiambiente (PROD/DESARROLLO/SIT/UAT) y adapta las rutas WFL y credenciales según el hostname del host Unisys.

4. Lógica por sección

4.1 §4.0 DECLARATIVES — Manejador de interrupción HI

PROCEDIMIENTO Manejador_Interrupcion_HI():            // INTERRUPT-BY-HI · [P055 L744]
  DISALLOW INTERRUPT
  SI ATTRIBUTE TASKVALUE OF MYSELF = 0
    SIGUIENTE SENTENCIA (no-op)
  SINO SI TASKVALUE = 4     // HI de operador: FIN NORMAL
    MOVER texto(03) "FIN NORMAL POR OPERADOR" → reporte-mensaje
    EJECUTAR 70001000-ESC-MENSAJES
    EJECUTAR 70000050-MENSAJE
    MOVER "DISABLE PROGRAM CORE-DEPP055" → WS-SOPCOM-COMANDO
    LLAMAR "SMCOMS OF SOPORTECOMS" CON WS-SOPCOM-COMANDO, WS-SOPCOM-TRABAJO
                                   RESULTADO WS-COMS-RESULT
    SI WS-COMS-RESULT = 1
      armar "NO HIZO DISABLE + EN FORMA NORMAL" → reporte
      EJECUTAR 70001000-ESC-MENSAJES · EJECUTAR 70000050-MENSAJE
  SINO                            // TASKVALUE desconocido
    MOVER TASKVALUE → WS-MSG-N-06
    armar "HI NO IMPLEMENTADO =" + WS-MSG-N-06 → reporte
    EJECUTAR 70001000-ESC-MENSAJES · EJECUTAR 70000050-MENSAJE
  SET MYSELF(TASKVALUE) TO ZERO
  ALLOW INTERRUPT

PROCEDIMIENTO Verificar_Versiones():            // 10000000-VERIFICA-VERSIONES · [P055 L824]

PROCEDIMIENTO Asignar_Taskfile():            // 10100000-ASIGNA-TASKFILE · [P055 L844]
  // Asigna nombre estándar al taskfile para recuperación ante fallo
  ACCEPT WKS-TASKFILE-FEC FROM DATE      // fecha YYMMDD

  MOVER ATTRIBUTE MIXNUMBER OF MYSELF → WKS-TASKFILE-MIX
  SET MYSELF(FILECARDS) TO WKS-TASKFILE-NOMBRE

PROCEDIMIENTO Inicializar_COMS():            // 10200000-INICIALIZA-COMS · [P055 L857]
  // Obtiene designadores COMS necesarios para operar en bus online
  EJECUTAR 0000-CALL-COMS-PROGRAM        // designador del programa COMS
  SI WS-COMS-RESULT ≠ 0
    armar error "PROBLEMAS AL DAR DE ALTA EL PROGRAMA EN COMS ERROR=" + resultado → reporte
    EJECUTAR ESC-MENSAJES · EJECUTAR MENSAJE
    CHANGE ATTRIBUTE STATUS OF MYSELF TO -1   // fuerza abort
  EJECUTAR 0000-CALL-COMS-NOAPL         // obtiene NOAPL (nombre de aplicación)
  SI WS-COMS-RESULT ≠ 0  → idem abort
  EJECUTAR 0000-CALL-COMS-OUTPUT        // designador "OUTPUT OF LINEA"
  SI WS-COMS-RESULT ≠ 0  → idem abort
  EJECUTAR 0000-CALL-COMS-STATION       // designador DEFAULTSTATION
  SI WS-COMS-RESULT ≠ 0  → idem abort
  // NOTA: el bloque TP_IDENTIFY XATMI fue comentado aquí [P055 L916] → se movió a 20000120-XATMI

PROCEDIMIENTO Validar_Version_CTLVERS():            // 10300000-P055-EN-CTLVERS · [P055 L931]
  MOVER WKS-ID-P055    // "CORE-DEPP055"
         → W77-S000-MY-ID
  MOVER WKS-ID-VERSION // "25MTP002"

4.6 §4.5 Loop de espera COMS y heartbeat

PROCEDIMIENTO Esperar_Mensaje_COMS():            // 50201000-OBTEN-MSG-DE-COMS · [P055 L1152]

         CON    WS-ESPERACOMS-TIEMPO  // 60 segundos timeout ⚠ [HARDCODE-SOSPECHOSO]
