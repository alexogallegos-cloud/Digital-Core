P606 · LEE-ARCHMOVYDES (CORE-GL — LegacyCore Unisys ClearPath MCP)

CORE-GLProgramaCOBOL

Fuente: COBOL_P606.cbl (2675 LOC)

Rol en batch: lector-reporteador de movimientos y datos adicionales del periodo anterior

BC-15 · Convenciones: nombres traducidos (Unisys→legible); [P606 Lnnnnnn] = línea fuente (cols 1-6); (BR: RN-CORE-GL-NNN) = regla de negocio.

1. Resumen funcional

P606 (nombre interno LEE-ARCHMOVYDES) lee secuencialmente el archivo de movimientos contables del periodo anterior (CORE-GLMOVANT, 450 bytes/registro) y genera un reporte CSV filtrado según nueve parámetros operativos: sistema, fecha, rango horario, sucursal, caja y clave de transacción. Antes de procesar cada registro, carga el catálogo paramétrico 523 de S080 para determinar las transacciones válidas para el sistema solicitado, calculando por cada transacción los atributos NAT028, IND250 y NATALFA que enriquecen el reporte. El programa abre también CORE-GLDESANT (datos adicionales, 540 bytes) pero en la versión presente no lee ni escribe sobre él — es código muerto residual. Una vez generado el reporte, lo envía a la cola Intelar vía ADMONXFERS.

2.2 Registros clave de CORE-GLMOVANT

A00-R00-HDR-MOV — Cabecera (primer registro):

  • HD(2): marcador de header
  • FCH(8): fecha del archivo
  • BANDES(2): número de bandas

A00-R01-REGMOV — Registro de movimiento (450 bytes) — (BR: RN-CORE-GL-561):

  • FUNCION(2 COMP): tipo de operación (1=movimiento normal)
  • FORMATO(2 COMP): variante de formato del registro
  • SISTEMA(4 COMP): sistema origen (500=Captación, 087=Inversión, 252=Factoraje, etc.)
  • PRODUCTO(4 COMP) / TIPOCREDITO / TIPO-PROD: producto o tipo de crédito (REDEFINES)
  • INSTRUMENTO(2 COMP) / PORTAFOLIO / FONDO: instrumento financiero (REDEFINES)
  • SERVICIO-ALERTA(4 COMP): servicio + tipo de operación
  • TIPO-MOVIMIENTO(2 COMP)
  • AGRUP-DESV-PROD(4 COMP) / PRODUCTO-S016: producto agrupador de desvíos
  • AGRUP-DESV-INST(4 COMP) / INSTRUMENTO-S016
  • SIRH-DESVIO(4 COMP)
  • LIBRO-CONTABLE(2 COMP) / IND-CONTA(2 COMP, REDEFINES): libro mayor que aplica — (BR: RN-CORE-GL-566)
  • CVEIMP-OC — OCCURS 5: hasta 5 conceptos contables simultáneos — (BR: RN-CORE-GL-562):
  • CVETRAN(i)(6 COMP): clave de transacción/concepto
  • INDLEY(i)(2 COMP): indicador de ley fiscal aplicable
  • ESQCON(i)(4 COMP) / TM(i) (REDEFINES): esquema contable / tipo movimiento alterno
  • IMPORTE(i)(16V2 COMP): importe del concepto (hasta 99 billones)
  • CVE-DESVIO(i)(4 COMP), GUIA-DESVIO(i)(4 COMP)
  • MONEDA(4 COMP)
  • ORIGEN(2 COMP): origen del movimiento
  • IND-EFEC(2 COMP), SOBREGIRO(2 COMP), IND-EDOCTA(2)
  • FECMOV(8 COMP): fecha de operación — (BR: RN-CORE-GL-563)
  • HORMOV(6 COMP): hora de operación
  • FECCONT(8 COMP): fecha contable — (BR: RN-CORE-GL-563)
  • FECVAL(8 COMP) / FECVAL-R(X(04) REDEFINES): fecha valor — (BR: RN-CORE-GL-563)

  • CAJA-INIC(4 COMP) / CAJA-S501 (REDEFINES): caja inicial
  • SUCOPER(4 COMP), CAJAOPER(4 COMP): sucursal/caja operadora
  • SUCTRAN(4 COMP), CAJATRAN(4 COMP): sucursal/caja transaccional
  • BCOS(10 COMP): banco origen+destino (BCO-ORI(5)+BCO-DES(5) REDEFINES)
  • CLIENTE(12 COMP), SECTOR(2 COMP), SUCPROM(4 COMP), CONTRATO(16 COMP)
  • CVEMDA(4 COMP), NUMMDA(20 COMP): código y número de moneda de la cuenta
  • MDA-SUC(4)+MDA-CTA(16) REDEFINES
  • CVEMDE(2 COMP): código de medio de entrega
  • INTERCOMPANY(6 COMP): código de filial intercompany — (BR: RN-CORE-GL-567)
  • FILIAL(X(05)) / GRUPO-SOC(4)+BIN-TAR(6) (REDEFINES) — (BR: RN-CORE-GL-567)
  • REFNUM(18 COMP): referencia numérica
  • AUTORIZA(18 COMP): autorización externa
  • AUT3ER(10 COMP): autorización de tercero
  • NIO(X(16)): número de identificación de operación
  • AUT-CORE-GL(8 COMP): autorización CORE-GL — (BR: RN-CORE-GL-568)
  • AUT-AELIM-CORE-GL(8 COMP) / AUT-AELIM-CORE-GL-R(X(04)): autorización eliminadora — (BR: RN-CORE-GL-568)
  • AUT-ANT-CORE-GL(8 COMP) / AUT-ANT-CORE-GL-R(X(04)): autorización anterior en cadena — (BR: RN-CORE-GL-568)
  • TIPO-PROC(2 COMP), VERIF-FIRMA(2 COMP)
  • NOMINA-OPE(14 COMP) / NOMINA-OPE-R(X(07))
  • STATUS(2 COMP): estado del movimiento
  • APUDES(8 COMP): apuntador descriptor
  • FILXAPL (165 bytes + REDEFINES polimórficos según SISTEMA) — (BR: RN-CORE-GL-564):
  • RED018: BCO-S018(4 COMP) en offset 96 (S018 — banco origen)
  • RED084: SUCEJE(4)+CTAEJE(12)+MENSUALIDAD(4)+ASESOR(2) (S084 — cuenta ejecutora)
  • REDS087: PZO(4)+EMISION(8)+PROD-S087(4)+INST-S016(2)+IMPINTRB(14V2)+SERV-S087(2)+SUCREEMB(4)+CTAREEMB(16)+SUCFOND(4)+CTAFOND(16)+OPBANEL(4)+GATN(S9(03)V99)+GATR(S9(03)V99)+FECGAT(8)+CTE-087(X(07))+TASAREF(6V2)+TASAREAL(4V4)+PM(2) (S087 — Inversión, garantías) — (BR: RN-CORE-GL-569)
  • REDC252: FEC-PARTIDA(8) en offset 96 (S252 — factoraje)

  • REDS701: datos de pago de servicios o impuestos (PAG-SERV / PAG-IMPT REDEFINES)
  • REDS702: CTE-S702+CTA-S702 (S702)
  • REDS703: 703-FLAGTX+703-FLAGTW+703-FECHAOPE+703-NOMBREBEN (S703)
  • REDS711: TRUI+MICR para cheques SPEI/CECOBAN: CSIREC+CSIOR+NUMOP+NUMTR+INSMN+CTABEN+NOMBEN+RFCBCO (S711)
  • REDS502: RFC-502+tabla de 12 conceptos de impuesto (CVECPTO+PDO+EJER+TIPPAG+IMP) (S502)
  • REDS203: hasta 7 conceptos de impuesto: CVE-IMPTOn+FORMA-PAGn+IMP-IMPTOn (S203)
  • REDS707: COP+IMP-ORIG+FORMA-COB+TIPO-CAMBIO+FEC-LIM-PAGO+VALOR-TARIFA+ESQUEMA-COBRO (S707 — cobranza)

2.3 Registro CORE-GLDESANT (A01-R01-DATOS, 540 bytes) — ⚠ [CODIGO-MUERTO] nunca leído en este programa

Incluye datos adicionales por sistema: AUTCORE-GLORI(8)+REF-LEGACYCORE(26)+NOMINA-FUN1/2(14×2)+SDO-FIN(S15V2)+REF-CLIENTE(16)+REFERENCIA1..4(35×4)+DATOS-2(LEY1..5 × 40 bytes + FILXAPL aplicativo 120 bytes)+TIPREG(2)+APUDES(8).

3. Mapa de control

000000-INIC-PROGRAMA
    ├─ EJECUTAR 00050-INICIO
    ├─ EJECUTAR 00100-CATALOGOS
    ├─ EJECUTAR 00200-PROC
    └─ EJECUTAR 00999-TERMINA

00050-INICIO
    ├─ inicializar etiquetas de archivos y variables
    ├─ LLAMAR CSIID (identificar CSI)
    ├─ LLAMAR DAME_TIT / CONSISDIA (obtener nombres de packs y fecha proceso)
    ├─ OPEN INPUT CORE-GLMOVANT CORE-GLDESANT  /  OPEN OUTPUT REPORTE
    ├─ EJECUTAR 01600-LEE-CORE-GLMOVANT  (leer cabecera — skip header)
    └─ SI no-EOF → EJECUTAR 01600-LEE-CORE-GLMOVANT  (primer registro de datos)

00100-CATALOGOS
    ├─ EJECUTAR 00110-CAT-CATALOGOS  (obtener metadata del catálogo 523)
    └─ SI catálogo-encontrado → EJECUTAR 00120-CAT-TRANS  (cargar entradas)

00110-CAT-CATALOGOS
    └─ EJECUTAR 00112-CARGA-CATALOGO-CAT HASTA W77-EOF > 0
           └─ (itera llamadas a L710_CONSUL_DETALLE hasta encontrar o agotar)

00120-CAT-TRANS
    └─ EJECUTAR 00122-CARGA-TRANSACCIONES HASTA W77-EOF > 0
           └─ (llena WKS-DATOS-CATRAN[W77-IND]: NAT028, IND250, NATALFA)

00200-PROC  [árbol de selección por combinación de parámetros]
    ├─ todos-cero         → EJECUTAR 01000-CON-X-DIA        HASTA fin
    ├─ solo-SUC           → EJECUTAR 01010-CON-X-SUC        HASTA fin
    ├─ SUC+CAJA           → EJECUTAR 01020-CON-X-SUCCAJ     HASTA fin
    ├─ FECINI+HRINI       → EJECUTAR 01100-CON-X-HR-INI     HASTA fin
    ├─ rango completo     → EJECUTAR 01200-CON-X-RANGO      HASTA fin
    ├─ rango+SUC          → EJECUTAR 01300-CON-X-SUC-HRINI  HASTA fin
    ├─ rango+SUC+CAJA     → EJECUTAR 01400-CON-X-SCAJ-HRINI HASTA fin
    ├─ rango-mov          → EJECUTAR 01450-CON-X-MOV-HRINI  HASTA fin
    ├─ rango+SUC+CAJA+tiempo → EJECUTAR 01500-CON-X-SCAJ-TIEMPO HASTA fin
    ├─ rango+SUC+tiempo   → EJECUTAR 01600-CON-X-SUC-TIEMPO HASTA fin
    ├─ CVETRAN solo       → EJECUTAR 01700-CON-X-AUT        HASTA fin
    ├─ CVETRAN+FECINI     → EJECUTAR 01800-CON-X-AUT-FEC    HASTA fin
    └─ ningún caso        → ESCRIBIR WKS-LINEA-ERROR
    └─ SI fin → CLOSE REPORTE + EJECUTAR 03000-ENVIA-INTELAR

Filtros de movimiento (01000..01800) → cada uno llama:
    EJECUTAR 01700-CONSULTA-MOVTOS  (o 01700-CONSULTA-MOVTOS2)
    EJECUTAR 01600-LEE-CORE-GLMOVANT

01700-CONSULTA-MOVTOS → itera slots CVETRAN (1..5)
    └─ EJECUTAR 02000-MUEVE-DATOS  (por cada slot con CVETRAN ≠ 0)

01700-CONSULTA-MOVTOS2 → itera slots CVETRAN (1..5) con filtro CVETRAN=WKS-PARAM-CVETRAN
    └─ EJECUTAR 02000-VAL-CVETRAN
           └─ SI coincide → EJECUTAR 02000-MUEVE-DATOS

03000-ENVIA-INTELAR
    └─ LLAMAR INTELARSND IN ADMONXFERS

00999-TERMINA
    └─ CLOSE CORE-GLMOVANT CORE-GLDESANT / STOP RUN

PROCEDIMIENTO Inicializar_Archivos_Y_Control():   // 00050-INICIO · [P606 L002023]
```
// Construir etiquetas dinámicas de archivos
MOVER parametro_fecha           A fecha_movs_etiqueta, fecha_des_etiqueta
    // WKS-PARAM-FECHA → WKS-CORE-GL-FEMOV, WKS-CORE-GL-FEDES
MOVER parametro_sistema         A num_sistema, num_sis_output, num_sis_b01,
                                   num_sis_movs_etiqueta, num_sis_des_etiqueta
    // WKS-PARAM-SIS → W77-NUMSIS, WKS-SIS, WKS-B01-SISTEMA, WKS-CORE-GL-MOVSIS, WKS-CORE-GL-DESSIS

// Obtener hora y fecha de máquina
ACEPTAR hora_maquina        DESDE TIME
MOVER horas, minutos, segundos  A WKS-HORA-MAQ
MOVER WKS-HORA-MAQ              A WKS-HHMMSS  // componente de título EXTMOV

ACEPTAR fecha_maquina       DESDE TODAYS-DATE
MOVER mes, dia, año         A WKS-MM-ARCH, WKS-DD-ARCH, WKS-AAAA-ARCH
MOVER WKS-FECHA-ARCH        A WKS-FECHA  // componente de título EXTMOV

// Activar librerías dinámicas vía BYFUNCTION
CAMBIAR ATRIBUTO LIBACCESS    DE "ADMONXFERS"  A BYFUNCTION   // transferencia Intelar
CAMBIAR ATRIBUTO FUNCTIONNAME DE "ADMONXFERS"  A "ADMONXFERS"
CAMBIAR ATRIBUTO LIBACCESS    DE "CTRLVERS"    A BYFUNCTION   // control de versiones
CAMBIAR ATRIBUTO FUNCTIONNAME DE "CTRLVERS"    A "CTLVERS"
CAMBIAR ATRIBUTO LIBACCESS    DE "SOPORTECOMS" A BYFUNCTION   // información CSI
CAMBIAR ATRIBUTO FUNCTIONNAME DE "SOPORTECOMS" A "SOPORTECOMS"
CAMBIAR ATRIBUTO TITLE        DE "LIB-DISP"   A
    "(S000)S000/UTILITY/DESPLIEGA/OBJ/LIB ON PACK"             // ⚠ [HARDCODE-SOSPECHOSO — ruta embebida]

// Obtener identificador del CSI (nodo de procesamiento)
LLAMAR "CSIID IN SOPORTECOMS" CON WKS-SOPCOMS
CANCELAR "SOPORTECOMS"
MOVER WKS-NUMCSI   A WKS-CSI, WKS-B01-CSI  // propaga número de CSI

// Resolver nombre real de la librería de control (versionada)
MOVER "CORE-GLL001CTL"   A WKS-LIBID
LLAMAR "DAME_TIT IN CTRLVERS" CON WKS-LIBID, WKS-NOMLIB  DANDO W77-ERR-CTLVER
SI W77-ERR-CTLVER = 0
    CAMBIAR ATRIBUTO TITLE DE "LIB-CONTROL" A WKS-NOMLIB
SINO
    CAMBIAR ATRIBUTO TITLE DE "LIB-CONTROL" A
        "(CORE-GL)CORE-GL/OBJECT/L001/CONTROL ON CMEMP"  // ⚠ [HARDCODE-SOSPECHOSO — fallback fijo]

// Consultar B01SISDIA: obtener nombre del pack de movimientos y fecha proceso
MOVER 1   A WKS-B01-FUNCION  // función 1 = consulta SISDIA
LLAMAR "CONSISDIA IN LIB-CONTROL" CON WKS-CORE-GLB01SISDIA  DANDO W77-RESULT-LIBCON
SI W77-RESULT-LIBCON = 0
    MOVER WKS-B01-NOMPACMOV  A WKS-CORE-GL-PKMOV, WKS-CORE-GL-PKDES  // nombre del pack activo

SI parametro_fecha = 0
    MOVER WKS-B01-FECPRO  A parametro_fecha  // tomar fecha proceso de B01SISDIA

SI parametro_hrfin > 0 Y parametro_fecfin = 0
    MOVER WKS-B01-FECPRO  A parametro_fecfin  // completar fecha fin con fecha proceso

// Asignar títulos dinámicos a los archivos (construye nombre completo)
CAMBIAR ATRIBUTO TITLE DE CORE-GLMOVANT A WKS-ETI-CORE-GL-MOVANT
    // ej: "CORE-GL/FILE/MOVCORE-DEP/AAMMDD ON packname."
CAMBIAR ATRIBUTO TITLE DE CORE-GLDESANT A WKS-ETI-CORE-GL-DESANT

// Resolver librería S080 (catálogos paramétricos)
MOVER "S080BD01CON"   A WKS-LIBID
LLAMAR "DAME_TIT IN CTRLVERS" CON WKS-LIBID, WKS-NOMLIB  DANDO W77-ERR-CTLVER
SI W77-ERR-CTLVER < 0
    MOVER "ERROR AL OBTENER NOMBRE LIB S080 "  A TEXTO-LJ
    MOVER 020901  A CODIGO-LJ  // ⚠ [HARDCODE] código de error fijo
    LLAMAR "LJ IN LIB-DISP" CON CONTADOR-LJ, MENSAJE-LJ
    CAMBIAR ATRIBUTO STATUS DE MYSELF A -1  // abortar programa
SINO
    CAMBIAR ATRIBUTO TITLE DE "S080BD01CON" A WKS-NOMLIB

// Abrir archivos
ABRIR LECTURA CORE-GLMOVANT, CORE-GLDESANT  // ⚠ CORE-GLDESANT abierto pero nunca leído
ABRIR ESCRITURA REPORTE

// Leer registro cabecera (skip header — primer registro = HDR-MOV)
EJECUTAR Leer_CORE-GLMOVANT()  // 01600-LEE-CORE-GLMOVANT: consume el header

SI indicador_fin = 0
    EJECUTAR Leer_CORE-GLMOVANT()  // primer registro de datos reales
```
