Valida en CORE-DEPB00CTRLPASO que la base sea salida de P170 y deja el paso en cero para que no se vuelva a correr si falla. Carga en memoria del dataset B17 las claves de cargo que generan comisión. Lee las tres copias de PLINEA (P105) y las tres de PBATCH (P130) del CSI y fecha de lote, exige que cada header traiga la fecha de lote y, de cada detalle con clave 2XXX o 4XXX marcada en B17, escribe en PTOTAL la clave de acumulación, el tipo de importe, el contrato y el importe. Ordena PTOTAL por contrato y clave, suma importe e IVA por grupo y los agrega al registro del contrato en la estructura mensual que corresponde al año y mes del lote, con commits cada 3,000 registros. Al terminar marca el paso 178 en B00.

/** REG-PUNTEOL1 (igual para las seis entradas): tipo 2 dígitos y tres vistas de la misma área. */
public sealed interface PunteoRecord permits PunteoRecord.Header, PunteoRecord.Detalle, PunteoRecord.Trailer {

    int tipoRegistro();                                      // WS-HEAL1-TREG PIC 9(02)

    record Header(int tipoRegistro, int sisOrigen, int sisDestino,
                  LocalDate fecha,                           // 9(08) AAAAMMDD: se compara con B02-FECHA-LOTE
                  int csiOrigen, LocalDate fecProceso, LocalTime horProceso,
                  int paso, int copia) implements PunteoRecord {}

    record Detalle(int tipoRegistro,
                   long autorizacion,
                   String contrato,                           // 9(12) COMP: String para no perder ceros
                   int producto, int instrumento, int moneda,
                   int cveTran,                               // 9(04) COMP
                   BigDecimal importe,                        // 9(10)V99 COMP -> escala 2
                   long referencia, long aut151,
                   LocalDate fecMaq, LocalTime horMaq,
                   int tipMov, int origen, int tipoProceso,
                   int bancos, int entrega) implements PunteoRecord {}

    record Trailer(int tipoRegistro, long numRegistros) implements PunteoRecord {}   // 99; NREG no se valida
}

/** El COBOL decide la vista por posición: primer registro = header, tipo 99 = trailer, resto = detalle. */
class PunteoLineMapper {
    static PunteoRecord mapea(byte[] reg, boolean primeroDelArchivo) {
        int tipo = Layouts.tipo(reg);
        if (primeroDelArchivo) return Layouts.header(reg);
        return (tipo == 99) ? Layouts.trailer(reg) : Layouts.detalle(reg);
    }
}

@Component
@RequiredArgsConstructor
public class ControlPasoTasklet implements Tasklet {

    private static final int PASO_PREVIO = 170, ESTE_PASO = 178;   // p178.paso-previo / p178.paso
    private final ControlPasoRepository control;                   // CORE-DEPB00CTRLPASO

    @Override
    @Transactional
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        ControlPaso b00 = control.findForUpdate()
                .orElseThrow(() -> new ProcesoAbortadoException("ERROR B00CTRLPASO VACIO"));
        // R4-COPIAS-2011: los tres campos de control deben venir de P170
        if (!b00.todosEn(PASO_PREVIO)) {
            throw new ProcesoAbortadoException("ERROR BASE NO ES SALIDA DEL P170");
        }
        b00.marcaTodos(0);        // impide un segundo intento automático si este paso falla
        return RepeatStatus.FINISHED;   // commit inmediato (END-TRANSACTION SYNC)
    }

    /** Step final: solo se alcanza si todo lo anterior terminó bien. */
    @Transactional
    public void marcaTerminado() {
        control.findForUpdate().orElseThrow().marcaTodos(ESTE_PASO);
    }
}
/** 20000800-LEO-B17 + 20000900-VAL-B17: tabla OCCURS 9999 indexada por clave a Map. */
@Component
@StepScope
@RequiredArgsConstructor
public class CatalogoComisiones {

    private final ClaveFuncionRepository b17;   // CORE-DEPB17CVESXFUN
    private Map<Integer, ReglaComision> porClave;

    public record ReglaComision(int claveAcumulacion, int tipoAcumulacion, int tipoMov) {}

    @PostConstruct
    void carga() {
        porClave = b17.findAll().stream()
                .filter(r -> r.claveTrans() > 0
                          && r.tipoMov() == 1                                 // cargo
                          && r.cveAcumComi() > 0
                          && r.tpoAcumComi() > 0 && r.tpoAcumComi() < 3)      // 1 comisión, 2 IVA
                .collect(Collectors.toMap(ClaveFuncion::claveTrans,
                        r -> new ReglaComision(r.cveAcumComi(), r.tpoAcumComi(), r.tipoMov()),
                        (previa, ultima) -> ultima));                         // MOVE: gana la última leída
    }

    public Optional<ReglaComision> regla(int cveTran) { return Optional.ofNullable(porClave.get(cveTran)); }
}

@Component
@StepScope
@RequiredArgsConstructor
public class PunteoProcessor implements ItemProcessor<PunteoRecord, PunteoTotal> {

    @Value("#{jobExecutionContext['fechaLote']}") private LocalDate fechaLote;
    private final CatalogoComisiones catalogo;

    @Override
    public PunteoTotal process(PunteoRecord r) {
        if (r instanceof PunteoRecord.Header h) {                   // 50001100-VAL-HEA
            if (!h.fecha().equals(fechaLote)) {
                throw new ProcesoAbortadoException("FECEXT.E INT ARC.PLINEA DIF");   // DMTERMINATE
            }
            return null;                                            // el header no va a PTOTAL
        }
        if (!(r instanceof PunteoRecord.Detalle d)) return null;    // trailer 99: se ignora
        if (!esCargo(d.cveTran())) return null;                     // 50001210-VAL-CVE
        return catalogo.regla(d.cveTran())                          // 50001230-CHECO-B17
                .map(g -> new PunteoTotal(g.claveAcumulacion(), d.contrato(), d.importe(),
                                          TipoImporte.de(g.tipoAcumulacion())))
                .orElse(null);                                      // sin comisión: se descarta
    }

    /** Solo las claves de cargo 2000-2999 y 4000-4999 (p178.rangos-cargo). */
    static boolean esCargo(int cve) {
        return (cve > 1999 && cve < 3000) || (cve > 3999 && cve < 5000);
    }
}

record LlaveComision(String contrato, int claveAcumulacion) {}

record GrupoComision(LlaveComision llave, BigDecimal comision, BigDecimal iva) {}

/** 50005200-ACT-EST: corte de control sobre PTOTAL ordenado. */
@RequiredArgsConstructor
public class AgrupadorComisionesReader implements ItemReader<GrupoComision> {

    private static final BigDecimal TOPE_8V2 = new BigDecimal("99999999.99");  // WS-SUM-*-COBRADO 9(08)V99
    private final SingleItemPeekableItemReader<PunteoTotal> ordenado;

    @Override
    public GrupoComision read() throws Exception {
        PunteoTotal p = ordenado.read();
        if (p == null) return null;
        var llave = new LlaveComision(p.contrato(), p.claveAcumulacion());
        BigDecimal comision = BigDecimal.ZERO.setScale(2), iva = BigDecimal.ZERO.setScale(2);
        do {
            if (p.tipo() == TipoImporte.COMISION) comision = tope(comision.add(p.importe()));
            else                                  iva      = tope(iva.add(p.importe()));
            PunteoTotal sig = ordenado.peek();
            p = (sig != null && llave.equals(new LlaveComision(sig.contrato(), sig.claveAcumulacion())))
                    ? ordenado.read() : null;
        } while (p != null);
        return new GrupoComision(llave, comision, iva);
    }

    /** ADD sin ON SIZE ERROR truncaría el dígito alto en silencio. */
    private static BigDecimal tope(BigDecimal v) {
        if (v.compareTo(TOPE_8V2) > 0) throw new DesbordamientoAcumuladorException(v);
        return v;
    }
}

/** 50005250-BUSCO + 50005500-ACT-B28. El step usa chunk(3000): END/BEGIN TRANSACTION cada 3,000. */
@Component
@StepScope
@RequiredArgsConstructor
public class AcumuladorComisionesWriter implements ItemWriter<GrupoComision> {

    private final ComisionCobradaRepository repo;
    @Value("#{jobExecutionContext['estructura']}") private int estructura;   // 50004000-LEO-EST

    @Override
    public void write(Chunk<? extends GrupoComision> grupos) {
        for (GrupoComision g : grupos) {
            var id = new ComisionCobradaId(estructura, g.llave().contrato(), g.llave().claveAcumulacion());
            ComisionCobrada b28 = repo.findByIdForUpdate(id)                   // LOCK B28SXCTOCVE
                    .orElseGet(() -> ComisionCobrada.nueva(estructura, g.llave()));   // CREATE
            b28.impCobrado = Importe.tope8v2(b28.impCobrado.add(g.comision()));    // ADD: acumula
            b28.ivaCobrado = Importe.tope8v2(b28.ivaCobrado.add(g.iva()));
            repo.save(b28);                                                    // STORE
        }
    }

Riesgos de migración
Posible arrastre de importes en altas nuevas

En 50005300-B28-LOCK (línea 1517) MOVE WS-COMICOB-AREA TO WS-BONI-AREA se ejecuta también cuando el contrato no existe; 50005400-CREATE-B28 solo asigna contrato y clave. Si el área no se limpia en la rutina del copybook CORE-DEP/INC/PRO/25MTP002, el nuevo registro arranca con los importes del contrato anterior.

Trailer sin validar

Los seis archivos traen un trailer 99 con el número de registros (WS-TRAL1-NREG y equivalentes) que no se compara en ningún punto. Un archivo incompleto pasa sin aviso.

Reproceso que duplica sumas

B28 se actualiza con ADD y commits cada 3,000 grupos. El candado de B00 impide un reinicio automático, pero un reinicio manual después de una falla vuelve a sumar lo ya confirmado.

Capacidades sin control

Importes de 9(10)V99 se suman en acumuladores y campos de B28 de 9(08)V99 sin ON SIZE ERROR, y la tabla de B17 de 9,999 posiciones se indexa directamente por la clave.

Escritura de PTOTAL sin control efectivo

El WRITE de 50001250-GRABO-ARC solo envía un mensaje si falla y continúa, por lo que se pueden perder comisiones sin abortar.

Hardcodes

Prefijos CORE-DEP/FILE/CORE-DEP/PLINEA, PBATCH y PTOTAL, copias 01 a 03, pasos 170 y 178, rangos de claves 2000-2999 y 4000-4999, y el lote de 3,000 transacciones. Se trasladan a application.yml.
