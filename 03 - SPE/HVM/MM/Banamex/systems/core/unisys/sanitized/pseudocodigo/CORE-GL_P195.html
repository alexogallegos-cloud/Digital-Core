P195 · Extractor de Configuración de Control a Archivos Secuenciales (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P195.cbl (1561 LOC) · paso 25MTP001 del WFL EXTRAECTL · sin BC asignado (programa técnico-operacional)

Convenciones: nombres traducidos (Unisys→legible); [P195 Lnnnnnn] = n.º de secuencia COBOL (cols 1-6 del fuente); (BR: RN-...) = regla de negocio del KB.

1. Resumen funcional

P195 es el extractor de configuración del sistema CORE-GL Contabilidad GL. A partir de la base de datos DMSII CORE-GLBD99CONTROL, genera seis archivos secuenciales planos — uno por cada dataset de control (B01SISDIA, B02ARCINTER, B03SISMEN, B04SISTEM, B05PROCESOS, B09CONXSIS) — que materializan la configuración operativa del sistema para respaldo o transferencia entre plataformas.

La fecha de proceso se obtiene en dos vías complementarias: vía librería (CONSISDIA, sistema 151) para la variable interna de control, y desde el primer registro de B01SISDIA (campo B01-SIS-FECPRO convertido de CCAAMMDD a AAMMDD mediante la rutina Cronos 2000) para rotular los archivos de salida. Si no existe ningún registro B01, todos los sufijos de fecha quedan en ceros.

En entornos de Alta Disponibilidad (clúster IBM, W77-VALUE = 1), el programa verifica primero si ya existe un registro B05PROCESOS para la fecha y número de proceso 195; si ya fue completado previamente (STAPGM ≠ 0), termina sin regenerar; de lo contrario genera todos los archivos y actualiza el estatus del B05 a 1 al terminar.

3. Mapa de control

Jerarquía de PERFORM — esqueleto del flujo principal:

00-0000-CONTROL
│
├─ [init] Inicializa variables de encabezado de reporte
│    ├─ CALL SOPORTECOMS/CSIID           → obtiene CSI del host
│    ├─ CALL GENERALSUPPORT/CURRENT_DATE → obtiene fecha/hora
│    ├─ CALL CTRLVERS/DAME_TIT           → obtiene nombre librería CORE-GL-L001
│    └─ CALL CORE-GL-L001/CONSISDIA         → obtiene WKS-FECHA-PROC
│
├─ PERFORM 000-050-CHECA-SALTO-HOJA2   (imprime encabezado reporte si >56 líneas)
│    └─ (write V00-REPORTE2 encabezados)
│
├─ PERFORM 01-00100-ABRE-ENTRADA       → OPEN INQUIRY CORE-GLBD99CONTROL
│
├─ [si W77-VALUE = 1] PERFORM 08-01000-VERIFICA-B05   (Alta Disponibilidad)
│    ├─ CALL B05PROCESOS func=01 (consulta B05 para P195 / fecha proceso)
│    ├─ SI encontrado y STAPGM ≠ 0 → PERFORM 08-02000-FINALIZA-PROGRAMA (STOP RUN)
│    └─ SI no encontrado → PERFORM 08-01100-CREA-B05 (func=19, alta B05)
│
├─ PERFORM 02-00100-GENERA-B01SISDIA
│    ├─ FIND FIRST CORE-GLB01SISDIA
│    ├─ [derivar fechas archivos, convertir CAMD→AMD]
│    ├─ OPEN OUTPUT A01-B01SISDIA
│    └─ PERFORM 02-00110-VACIA-B01SISDIA UNTIL EOF
│         └─ MOVE CORE-GLB01SISDIA → A01-R00-SISDIA; WRITE; FIND NEXT
│
├─ PERFORM 03-00100-GENERA-B02ARCINTER
│    └─ PERFORM 03-00110-VACIA-B02ARCINTER UNTIL EOF
│         └─ MOVE CORE-GLB02ARCINTER → A02-R00-ARCINTER; WRITE; FIND NEXT
│
├─ PERFORM 04-00100-GENERA-B03SISMEN
│    └─ PERFORM 04-00110-VACIA-B03SISMEN UNTIL EOF
│         ├─ copia campos fijos de CORE-GLB03SISMEN
│         ├─ PERFORM 04-00111-BASES-CICLO VARYING IND 1..min(5,NUMCICMES)
│         ├─ WRITE A03-R00-SISMEN
│         └─ PERFORM 04-00112-LIMPIA-VAR-BASES VARYING IND2 1..min(5,NUMCICMES)
│
├─ PERFORM 05-00100-GENERA-B04SISTEM
│    └─ PERFORM 05-00110-VACIA-B04SISTEM UNTIL EOF
│         └─ MOVE CORE-GLB04SISTEM → A04-R00-SISTEM; WRITE; FIND NEXT
│
├─ PERFORM 07-00100-GENERA-B05SISTEMA
│    └─ PERFORM 07-00110-VACIA-B05SISTEMA UNTIL EOF
│         └─ MOVE CORE-GLB05PROCESOS → A06-R00-PROCESOS; WRITE; FIND NEXT
│
├─ PERFORM 06-00100-GENERA-B09CONXSIS
│    └─ PERFORM 06-00110-VACIA-B09CONXSIS UNTIL EOF
│         └─ MOVE CORE-GLB09CONXSIS → A05-R00-CONXSIS; WRITE; FIND NEXT
│
├─ [si W77-VALUE = 1] PERFORM 08-01200-ACTUALIZA-B05  (actualiza STAPGM=1)
│
├─ PERFORM 01-00200-CIERRA-ENTRADA     → CLOSE CORE-GLBD99CONTROL
│
└─ [log "FIN NORMAL"] → CLOSE V00-REPORTE2 → STOP RUN

Subrutinas de error DMSII (invocadas por ON EXCEPTION en todos los FIND):
└─ PERFORM 900000-CHE-STA
     └─ STRING error → TEXTO-LJ → CALL LJ

Subrutinas Cronos 2000 (invocadas internamente por A2K-CONV-CAMD-TO-AMD):
└─ A2K-CONV-CAMD-TO-AMD
     └─ A2K-OBTAIN-CENTURY
          [determina siglo: AA < A2K-BASE-YEAR(50) → CC=20, else CC=19]

Orden real de generación en 00-0000-CONTROL: B01 → B02 → B03 → B04 → B05 → B09. Nótese que el número de párrafo del paso B09 es 06- y del B05 es 07-, lo que invierte el orden numérico de los párrafos respecto al orden de ejecución. [P195 L000857–L000862] ⚠ [HARDCODE-SOSPECHOSO: orden no correlativo]

4.1 Párrafos de inicialización y control principal

PROCEDIMIENTO Control_Principal():                           // 00-0000-CONTROL · [P195 L000738]

  // --- Hardcodes de identificación de tarea ---
  MOVER "151"  A  sistema_reporte          // WKS-SIS-BACK2, WLI-RB-E3-SISTEMA2 [P195 L000741]
  MOVER "P195" A  paso_reporte             // WKS-PASO-BACK2, WLI-RB-E1-PASO    [P195 L000743]
  MOVER "DIARIO" A tipo_proceso_reporte    // WLI-RB-E2-TIPO-PROC2               [P195 L000745]

  // --- Alta Disponibilidad: captura TASKVALUE del task actual ---
  MOVER ATTRIBUTE TASKVALUE OF MYSELF A valor_taskvalue   // W77-VALUE [P195 L000747]

  // --- Configurar acceso a librerías por BYFUNCTION ---
  CAMBIAR ATTRIBUTE LIBACCESS / FUNCTIONNAME DE "CTRLVERS" A "CTLVERS"   [P195 L000748–L000751]
  CAMBIAR ATTRIBUTE LIBACCESS / FUNCTIONNAME DE "SOPORTECOMS"            [P195 L000753–L000755]
  LLAMAR "CSIID IN SOPORTECOMS" USANDO bloque_datoshost
         → obtiene numero_csi, nombre_equipo, nombre_csi, linea_batch    [P195 L000756]
  MOVER numero_csi  A  csi_reporte                                       [P195 L000758]

  // --- Obtener fecha/hora actual del sistema ---
  CAMBIAR ATTRIBUTE LIBACCESS DE "GENERALSUPPORT" A BYFUNCTION           [P195 L000769]
  LLAMAR "CURRENT_DATE IN GENERALSUPPORT" USANDO arreglo_fecha           // WKS-DATE-ARRAY2 [P195 L000772]
  MOVER arreglo_fecha  A  estructura_fecha_hora                          // WKS-FECHA-HORA2
  MOVER fecha_6d       A  sufijo_fecha_reporte                           // WKS-FEMAQ6D2 → WKS-TR-FECHA-BACKUP2
  MOVER fecha_8d       A  fecha_proc_encabezado                          // WKS-FEMAQ8D2 → WLI-RB-E2-FECHA-PROC2

  MOVER ATTRIBUTE STACKNO OF MYSELF A mix_reporte                        // WKS-TR-MIX2 [P195 L000781]
  ESTABLECER V00-REPORTE2(USERBACKUPNAME) A TRUE                         [P195 L000782]
  CAMBIAR ATTRIBUTE TITLE DE V00-REPORTE2 A nombre_dinamico_reporte      // WKS-TIT-REPORTE2 [P195 L000783]

// Nota: bloque de compiletime / versión COMENTADO (código muerto) [P195 L000785–L000798] // ⚠ [DESCARTE-SILENCIOSO]: WKS-COMPILA2, WKS-VERSION2, WKS-FPRO-* nunca se calculan.

  MOVER 57 A contador_lineas_reporte        // ⚠ [HARDCODE-SOSPECHOSO]: umbral 57 hardcodeado [P195 L000800]
  MOVER fecha_6d A fecha_informacion_encabezado                         [P195 L000803]
  EJECUTAR Verificar_Salto_Hoja                                          [P195 L000808]

  // --- Obtener nombre dinámico de CORE-GL-L001 vía CTRLVERS ---
  CAMBIAR ATTRIBUTE TITLE DE "LIB-DISP" A "(S000)S000/UTILITY/DESPLIEGA/OBJ/LIB ON PACK"  [P195 L000812]
  MOVER "CORE-GLL001CTL" A id_libreria_control              // ⚠ [HARDCODE-SOSPECHOSO] [P195 L000816]
  LLAMAR "DAME_TIT IN CTRLVERS" USANDO id_libreria_control, nombre_libreria
         DANDO resultado_ctrlvers                                        [P195 L000817]
  SI resultado_ctrlvers = 0 ENTONCES
    CAMBIAR ATTRIBUTE TITLE DE "CORE-GL-L001" A nombre_libreria_dinamico    [P195 L000821]
  SINO
    CAMBIAR ATTRIBUTE TITLE DE "CORE-GL-L001" A "(CORE-GL)CORE-GL/OBJECT/L001/CONTROL ON CMEMP."
