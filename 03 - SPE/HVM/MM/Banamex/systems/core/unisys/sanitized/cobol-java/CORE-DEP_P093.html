CORE-DEP · P093 a Java 21 Spring Boot

P093 es una copia de P091 con tres diferencias de configuración: la versión de compilación (06.001.06000 contra 99.01.00), el identificador con el que pide a CTRLVERS el título de TIME_OUT (usercode.L093ASIN) y el prefijo del archivo de volcado (CORE-DEP/LIST/P093). El resto es idéntico: obtiene el CSI con SOPORTECOMS, activa las opciones de volcado, habilita COMS en modo ONLINE, desliga las librerías auxiliares y llama a ENVIA_CANCELACIONES con sus encabezados y eventos. La directiva $SET TADS aparece en la línea 2 pero está comentada.

Riesgos de migración
Código duplicado entre P091 y P093

Los dos programas difieren solo en literales. Cualquier corrección al arranque debe hacerse dos veces; en Java se recomienda un solo componente con dos perfiles de configuración.

Falla de control de versiones sin aborto

Si DAME_TIT regresa un valor negativo (línea 34), la tarea muestra un aviso y sigue con el título de TIME_OUT compilado, que puede no ser el de la instancia L093.

Directiva de depuración comentada

La línea 2 contiene %$ SET TADS: el signo % convierte la directiva en comentario, por lo que P093 no se compila con soporte TADS aunque la documentación del brain diga lo contrario.

Pendiente de revisión SME
  • El inventario no asigna reglas del brain a P093. RN-CORE-DEP-776 describe a P091 y P093 juntos y afirma que P093 activa $SET TADS; en el fuente la directiva está comentada (línea 2). Corregir la regla y asignarla también a P093.
  • Confirmar qué distingue operativamente a la instancia L093ASIN de L091ASIN (por ejemplo, otro conjunto de terminales o una ventana COMS distinta); el fuente no lo dice.
  • MY_ID vale 18MTP002 (línea 19) y no se usa; confirmar si debería validarse la versión del propio programa como en otros pasos de CORE-DEP.
