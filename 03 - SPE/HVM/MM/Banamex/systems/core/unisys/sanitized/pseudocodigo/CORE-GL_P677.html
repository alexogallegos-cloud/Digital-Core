P677 · Generador de Datasets de Control B01/B03/B04 (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P677.cbl (1,093 LOC) · Gate-keeper del ciclo batch diario · BC-18

Convenciones: nombres traducidos (Unisys→legible); [P677 Lnnnn] = origen; (BR: RN-CORE-GL-###) = regla.

1. Resumen funcional

P677 es el primer programa que se ejecuta en el ciclo batch diario de CORE-GL (LegacyCore GL Unisys MCP). Su función es leer, validar y actualizar los tres datasets de control interno del ciclo: B01SISDIA (fechas del sistema y archivo de movimientos), B03SISMEN (registro histórico de ciclos mensuales) y B04SISTEM (estado global del sistema). Recibe como parámetros el número de sistema (WKS-PARAM-SIS) y la fecha de proceso (WKS-PARAM-FECHA); si cualquier validación falla, termina con STATUS=-1 y bloquea el ciclo completo. Cuando B04SISTEM tiene ESTATUS=3 (transición de ciclo mensual), adicionalmente invoca la librería L002 para generar los archivos de control de cierre. Si P677 no termina normalmente, ningún otro programa CORE-GL puede ejecutarse ese día.

(BR: RN-CORE-GL-476)

2.5 Layouts de campos clave

WKS-CORE-GLB01SISDIA (estructura principal de B01SISDIA, layout resumido):

  • WKS-B01-CSI (9/02): Número de CSI
  • WKS-B01-SISTEMA (9/04): Sistema
  • WKS-B01-FECPRO (9/08): Fecha de proceso
  • WKS-B01-FECCON (9/08): Fecha de contabilización
  • WKS-B01-FECPRO151 (9/08): Fecha de proceso CORE-GL
  • WKS-B01-NUMARC (9/02): Número de día en ciclo semanal (1–5)
  • WKS-B01-CTL-DIA OCCURS 10 TIMES: Array de días del ciclo, campos por posición:
  • WKS-B01-FECARCMOV(i) (9/08): Fecha del archivo de movimientos del día i
  • WKS-B01-NIVARCMOV(i) (9/08): Nivel del archivo de movimientos
  • WKS-B01-NIVBDMOV(i) (9/08): Nivel de la BD de movimientos
  • WKS-B01-STAARCLOG(i) (9/02): Status del archivo log

WKS-CORE-GLB03SISMEN (ciclos mensuales):

  • WKS-B03-NUMCICDIA (9/04): Número de ciclos diarios vigentes
  • WKS-B03-CICLO OCCURS 99 TIMES: ciclos, cada uno con WKS-B03-AAMM(i) (AAMM del ciclo)
  • WKS-B03-STABDSAL (9/02): Status de la BD saldo (99=especial, otros→se fuerza a 1)

WKS-B04SISTEMA (estado del sistema):

  • WKS-B04-ESTATUS (9/02): Estado: 2=inicio, 3=generación archivos (cierre mensual), 4=fin

3. Mapa de control

Jerarquía de ejecución (sangría = llamado PERFORM):

00-0000-CONTROL                          [P677 L793]
├── 01-00050-LIBRERIAS                   [P677 L828]  — carga CTLVER/LOCSUP/LIB-DISP/LIBCTL
├── 01-00100-ABRE-ENTRADA                [P677 L853]  — gate: lee B01SISDIA F01; aborta si falla
├── 02-00100-GENERA-B01SISDIA            [P677 L908]  — construye fechas del ciclo en B01
│   ├── 02-00110-DAME-DIA                [P677 L950]  — valida día hábil + obtiene Nº de día
│   ├── 02-00130-FECHAS (loop)           [P677 L991]  — itera días hábiles hacia atrás
│   └── 02-00105-GRABA-BASE              [P677 L936]  — escribe B01SISDIA via MANTSISDIA F37
├── 02-00200-VERIFICA-B03SISMEN          [P677 L1030] — busca/actualiza ciclo AAMM en B03
│   ├── 02-00210-BUSCA-BASE (loop)       [P677 L1073] — ¿AAMM actual ya existe?
│   └── 02-00220-BUSCA-MENOR (loop)      [P677 L1078] — encuentra el ciclo más antiguo
├── 02-00300-VERIFICA-B04SISTEM          [P677 L1085] — lee ESTATUS del sistema en B04
├── 01-00300-CARGA-FECHAS                [P677 L869]  — si ESTATUS=3: carga LIB-L002 + función 25
└── 01-00400-CIERRA-ARCHIVOS (loop ×10) [P677 L902]  — si ESTATUS=3: ⚠ CALL comentado

Flujo lineal del párrafo principal 00-0000-CONTROL:

  1. Inicializar parámetros de log y cargar librerías
  2. Leer B01SISDIA (gate de entrada)
  3. Generar fechas del ciclo → grabar B01SISDIA
  4. Verificar / actualizar B03SISMEN
  5. Leer B04SISTEM
  6. Si ESTATUS=3: cargar LIB-L002 y llamar CONTROLES función 25
  7. Si ESTATUS=3: ejecutar loop de cierre de archivos (funciones 10–19 de LIB-L002) ⚠ CALL comentado
  8. Log "FIN NORMAL" → STOP RUN

4.2 §4.2 — 01-00050-LIBRERIAS (Inicialización de librerías) [P677 L828–L851]

PROCEDIMIENTO Cargar_Librerias():                  // 01-00050-LIBRERIAS · [P677 L828]

  // Configurar atributos de librerías dinámicas por nombre de función
  CAMBIAR ATRIBUTO LIBACCESS    DE "CTLVER"      A BYFUNCTION    // [P677 L831]
  CAMBIAR ATRIBUTO FUNCTIONNAME DE "CTLVER"      A "CTLVERS"     // [P677 L832]
  CAMBIAR ATRIBUTO LIBACCESS    DE "LOCSUP"      A BYFUNCTION    // [P677 L834]
  CAMBIAR ATRIBUTO FUNCTIONNAME DE "LOCSUP"      A "LOCSUP"      // [P677 L835]
  CAMBIAR ATRIBUTO LIBACCESS    DE "SOPORTECOMS" A BYFUNCTION    // [P677 L836]
  CAMBIAR ATRIBUTO FUNCTIONNAME DE "SOPORTECOMS" A "SOPORTECOMS" // [P677 L837-L838]
  CAMBIAR ATRIBUTO TITLE DE "LIB-DISP" A
          "(S000)S000/UTILITY/DESPLIEGA/OBJ/LIB ON PACK."        // ⚠ [HARDCODE: ruta física] [P677 L839-L840]

  // Resolver título dinámico de LIBCTL via CTLVERS
  MOVER "CORE-GLL001CTL"          A id_libreria                     // WKS-LIBID ⚠ [HARDCODE] [P677 L842]
  LLAMAR "DAME_TIT IN CTLVER" USANDO id_libreria, nombre_libreria
                               DANDO error_ctlver                // W77-ERR-CTLVER [P677 L843-L845]

  SI error_ctlver = 0 ENTONCES                                   // [P677 L846]
    CAMBIAR ATRIBUTO TITLE DE "LIBCTL" A nombre_libreria         // título resuelto vía CTLVERS [P677 L847]
  SINO
    CAMBIAR ATRIBUTO TITLE DE "LIBCTL" A
            "(CORE-GL)CORE-GL/OBJECT/L001/CONTROL/02MTP011 ON CMEMP"   // ⚠ [HARDCODE: fallback físico] [P677 L849-L850]
  FIN-SI

FIN PROCEDIMIENTO

4.3 §4.3 — 01-00100-ABRE-ENTRADA (Gate: lectura inicial de B01SISDIA) [P677 L853–L867]

PROCEDIMIENTO Abrir_Leer_B01SISDIA():              // 01-00100-ABRE-ENTRADA · [P677 L853]

  // Obtener CSI del entorno actual
  LLAMAR "CSIID OF SOPORTECOMS" USANDO datos_soportecoms         // [P677 L855]

FIN PROCEDIMIENTO

4.4 §4.4 — 01-00300-CARGA-FECHAS (Carga de fechas para cierre mensual) [P677 L869–L900]

PROCEDIMIENTO Cargar_Fechas_Si_Cierre():           // 01-00300-CARGA-FECHAS · [P677 L869]

  SI estatus_sistema ≠ 3 ENTONCES                               // WKS-B04-ESTATUS [P677 L871]
    SIGUIENTE SENTENCIA (no hacer nada)                         // [P677 L872]
  SINO
    // Resolver título dinámico de LIB-L002 via CTLVERS
    MOVER sistema_parametro    A sis_l002                        // WKS-PARAM-SIS → WKS-SIS-L002 [P677 L874]
    MOVER id_l002              A id_libreria                     // WKS-LIBID-L002 → WKS-LIBID [P677 L875]
    LLAMAR "DAME_TIT IN CTLVER" USANDO id_libreria, nombre_libreria
                               DANDO error_ctlver                // [P677 L876-L878]
    SI error_ctlver = 0 ENTONCES                                 // [P677 L879]
      CAMBIAR ATRIBUTO TITLE DE "LIB-L002" A nombre_libreria     // [P677 L880]
    SINO
      CAMBIAR ATRIBUTO TITLE DE "LIB-L002" A
              "(CORE-GL)CORE-GL/OBJECT/L002/REGISTRA ON CMEMP"         // ⚠ [HARDCODE: fallback L002] [P677 L882-L883]
    FIN-SI
  FIN-SI

  SI estatus_sistema = 3 ENTONCES                               // [P677 L885]
    MOVER 0025                 A funcion_l002                    // ⚠ [HARDCODE: CONTROLES F25=fechas] [P677 L886]
    LLAMAR "CONTROLES IN LIB-L002" USANDO datos_core-gl
                               DANDO resultado_core-gl           // WKS-CORE-GL-DATOS / WKS-CORE-GL-RESULT [P677 L887-L888]
  FIN-SI

  SI resultado_core-gl > 0 Y estatus_sistema = 3 ENTONCES          // error en CONTROLES [P677 L890]
    MOVER resultado_core-gl    A error_num                       // W77-ERROR [P677 L891]
    MOVER 051001               A codigo_log                      // ⚠ [HARDCODE: código error L002=051001] [P677 L892]
    MOVER "I"                  A tipo_log                        // [P677 L893]
    COMPONER texto_log = "ERROR # " + error_num + " EN LLAMADO A L002"  // [P677 L894-L897]
    LLAMAR "LJ IN LIB-DISP" USANDO contador_log, mensaje_log    // [P677 L898-L899]
    ABORTAR (CHANGE ATTRIBUTE STATUS OF MYSELF TO -1)            // [P677 L900]
  FIN-SI

FIN PROCEDIMIENTO

4.6 §4.6 — 02-00100-GENERA-B01SISDIA (Generar datos del ciclo en B01SISDIA) [P677 L908–L934]

PROCEDIMIENTO Generar_B01SISDIA():                 // 02-00100-GENERA-B01SISDIA · [P677 L908]

  // Igualar las tres fechas de proceso al parámetro de entrada
  MOVER fecha_proceso_param    A fecpro_b01                      // WKS-PARAM-FECHA → WKS-B01-FECPRO [P677 L910]
  MOVER fecha_proceso_param    A feccon_b01                      // → WKS-B01-FECCON [P677 L911]
  MOVER fecha_proceso_param    A fecpro151_b01                   // → WKS-B01-FECPRO151 [P677 L912]
  // ⚠ [HARDCODE-SEMÁNTICO: tres fechas conceptualmente distintas son siempre iguales al inicio del ciclo]

  // Obtener número de día en ciclo semanal (1=Lunes, 5=Viernes)
  EJECUTAR Obtener_Numero_Dia()                                  // 02-00110-DAME-DIA [P677 L913]

  // Poblar la posición del día actual en el array de días del ciclo
  MOVER fecha_proceso_param    A fecarcmov_b01(num_dia)          // WKS-B01-FECARCMOV(W77-NUMDIA) [P677 L914]
  MOVER fecha_proceso_param    A fecha_trabajo                   // WKS-FECHA [P677 L915]
  MOVER ZERO                   A nivarcmov_b01(num_dia)          // WKS-B01-NIVARCMOV(W77-NUMDIA) = 0 [P677 L916]
  MOVER ZERO                   A nivbdmov_b01(num_dia)           // WKS-B01-NIVBDMOV(W77-NUMDIA) = 0 [P677 L917]
  MOVER ZERO                   A staarclog_b01(num_dia)          // WKS-B01-STAARCLOG(W77-NUMDIA) = 0 [P677 L918]

  SI num_dia > 1 ENTONCES                                        // hay días anteriores en el ciclo [P677 L919]
    CALCULAR num_dia = num_dia + 1                               // [P677 L920]
    MOVER num_dia              A indice                          // W77-IND [P677 L921]
    // Primer tramo: desde (día+1) hasta 10
    MIENTRAS indice ≤ 10:
      EJECUTAR Poblar_Dia_Ciclo()                                // 02-00130-FECHAS [P677 L922-L923]
    FIN-MIENTRAS

    CALCULAR num_dia = num_dia - 2                               // [P677 L924]
    MOVER 1                    A indice                          // [P677 L925]
    // Segundo tramo: desde 1 hasta (día_original - 1)
    MIENTRAS indice ≤ num_dia:
      EJECUTAR Poblar_Dia_Ciclo()                                // 02-00130-FECHAS [P677 L926-L927]
    FIN-MIENTRAS
    EJECUTAR Grabar_Base_B01()                                   // 02-00105-GRABA-BASE [P677 L928]

  SINO  // num_dia = 1 → primer día hábil (Lunes)              // [P677 L929]
    CALCULAR num_dia = num_dia + 1                               // [P677 L930] = 2
    MOVER 2                    A indice                          // [P677 L931]
    // Poblar desde posición 2 hasta 10 (días anteriores del ciclo previo)
    MIENTRAS indice ≤ 10:
      EJECUTAR Poblar_Dia_Ciclo()                                // 02-00130-FECHAS [P677 L932-L933]
    FIN-MIENTRAS
    EJECUTAR Grabar_Base_B01()                                   // 02-00105-GRABA-BASE [P677 L934]
  FIN-SI

FIN PROCEDIMIENTO

4.7 §4.7 — 02-00105-GRABA-BASE (Escritura de B01SISDIA via MANTSISDIA F37) [P677 L936–L948]

PROCEDIMIENTO Grabar_Base_B01():                   // 02-00105-GRABA-BASE · [P677 L936]

PROCEDIMIENTO Poblar_Dia_Ciclo():                  // 02-00130-FECHAS · [P677 L991]

  MOVER 13                     A formato_calendar              // ⚠ [HARDCODE: formato AAAAMMDD] [P677 L996]

                                        fecha1_calendar,
                                        fecha2_calendar,
                                        formato_calendar        // [P677 L997-L1000]

  SI funcion_calendar = 0 ENTONCES                             // resta exitosa [P677 L1001]
    MOVER fecha1_calendar      A fecha_trabajo                 // WKS-FECHA = nuevo día anterior [P677 L1002]

    // === Verificar que el día retrocedido NO es sábado ni domingo (THECALENDAR F06) ===

    MOVER 13                   A formato_calendar              // [P677 L1005]

                  fecha2_calendar, formato_calendar             // [P677 L1006-L1010]

    LLAMAR "LJ IN LIB-DISP" USANDO contador_log, mensaje_log   // [P677 L1025-L1026]
    ABORTAR (CHANGE ATTRIBUTE STATUS OF MYSELF TO -1)           // [P677 L1027]
  FIN-SI

FIN PROCEDIMIENTO

4.10 §4.10 — 02-00200-VERIFICA-B03SISMEN (Verificar y actualizar ciclos mensuales en B03SISMEN) [P677 L1030–L1072]

PROCEDIMIENTO Verificar_B03SISMEN():               // 02-00200-VERIFICA-B03SISMEN · [P677 L1030]

  // === Leer B03SISMEN (ciclos mensuales del sistema) ===
  MOVER sistema_parametro      A sistema_b03                   // WKS-PARAM-SIS → WKS-B03-SISTEMA [P677 L1032]
  MOVER 1                      A funcion_b03                   // ⚠ [HARDCODE: F01=consulta] [P677 L1033]
  LLAMAR "CONSISMEN IN LIBCTL" USANDO datos_b03sismen
                               DANDO resultado_libcon          // [P677 L1034-L1035]

  SI resultado_libcon > 0 ENTONCES                             // error lectura B03 [P677 L1036]
    MOVER 020202               A codigo_log                    // ⚠ [HARDCODE: código error] [P677 L1037]
    MOVER "ERROR EN CONSISMEN  " A texto_log                   // [P677 L1038]
    LLAMAR "LJ IN LIB-DISP" USANDO contador_log, mensaje_log  // [P677 L1039-L1040]
    ABORTAR (CHANGE ATTRIBUTE STATUS OF MYSELF TO -1)          // [P677 L1041]
  FIN-SI

  // === Buscar si el AAMM actual ya existe en el array de ciclos ===

    SI encontrado = 1: salir del loop

  // === Forzar STABDSAL a 1 si no es 99 ===
  SI stabdsal_b03 = 99 ENTONCES                                // [P677 L1050]
    SIGUIENTE SENTENCIA  // preservar valor especial 99         // [P677 L1051]
  SINO
    MOVER 1                    A stabdsal_b03                  // ⚠ [HARDCODE: fuerza status=1] [P677 L1053]
  FIN-SI                                                       // ⚠ [DESCARTE-SILENCIOSO: cualquier valor ≠99 se sobreescribe con 1]

  // === Si no se encontró el AAMM y hay ciclos → reemplazar el más antiguo ===

    FIN-SI
  FIN-SI                                                       // (BR: RN-CORE-GL-483)

  // === Actualizar (commit) B03SISMEN via MANTSISMEN F37 ===
  MOVER sistema_parametro      A sistema_b03                   // [P677 L1063]
  MOVER 37                     A funcion_b03                   // ⚠ [HARDCODE: F37=cambio] [P677 L1064]
  LLAMAR "MANTSISMEN IN LIBCTL" USANDO datos_b03sismen
                               DANDO resultado_libcon          // [P677 L1065-L1066]

  SI resultado_libcon > 0 ENTONCES                             // [P677 L1067]
    MOVER 020202               A codigo_log                    // [P677 L1068]

    LLAMAR "LJ IN LIB-DISP" USANDO contador_log, mensaje_log  // [P677 L1070-L1071]
    ABORTAR (CHANGE ATTRIBUTE STATUS OF MYSELF TO -1)          // [P677 L1072]
  FIN-SI

FIN PROCEDIMIENTO
