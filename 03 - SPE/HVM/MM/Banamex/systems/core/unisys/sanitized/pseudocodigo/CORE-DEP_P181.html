CORE-DEPProgramaCOBOL

Fuente: P181.cbl (2047 LOC) · Paso nocturno de exportación analítica · BC-05

Convenciones: nombres traducidos (Unisys→legible); [P181 Lnnnn] = línea fuente; (BR: RN-CORE-DEP-NNN) = regla de negocio.

1. Resumen funcional

P181 (paso CORE-DEPP181) es el generador batch nocturno que construye el inventario de inversiones de captación y los archivos analíticos del sistema CORE-DEP LegacyCore. Lee secuencialmente la base DMSII CORE-DEPBD01CAPTACION (datasets B02-control, B03-contratos, B05-productos, B06-histórico y B50-tesofe), arma un archivo puente INVEPTE con un registro por contrato activo —excluyendo ahorros y contratos migrados al S111— y lo clasifica por nodo / sucursal / producto / instrumento / moneda / contrato. A partir del archivo ya ordenado genera cuatro archivos de salida: saldos de cheques (CHESDOS) y de cuenta maestra (CMASDOS) bajo la ruta INTS/50003S02, consumidos por S022-INTELAR (Genesis) y S006P940 (Datoteca), más sus archivos adicionales ADICIONALCHEQ y ADICIONALCMAE bajo la ruta S691, dirigidos a Teradata. El archivo INVEPTE queda disponible para el paso downstream P180, que lo usa como insumo para generar reportes de inventario. En la versión ABR/2019 se eliminó de P180 la generación de estos archivos analíticos, que se trasladó íntegramente a P181, y se reacomodó el formato de INVEPTE para dejar las llaves de sort contiguas al inicio del registro.
