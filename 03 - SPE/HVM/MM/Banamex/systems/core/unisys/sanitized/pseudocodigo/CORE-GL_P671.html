P671 · Generador de CSV INTELAR — Protección al Cobro / Alertas / Domiciliación (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P671.cbl (562 LOC) · Extracción post-proceso hacia INTELAR · BC-18

Convenciones: nombres traducidos (Unisys MCP → legible); [P671 Lnnnn] = línea en el fuente; (BR: RN-CORE-GL-###) = regla de negocio.

1. Resumen funcional

P671 (LEE-PROT-DOM-ALER) es el programa de interfaz entre CORE-GL e INTELAR creado en diciembre 2024 — el más reciente de la serie P600. Su propósito es extraer registros de protección al cobro, alertas de notificación o domiciliación bancaria desde la base de datos DMSII CORE-GLBD13BIFIN y generar un archivo CSV con columnas fijas para su consumo por INTELAR.

El programa recibe tres parámetros: un identificador de tipo de reporte (ID), una fecha en formato CCAAMMDD y un número de contrato opcional. Según el ID, selecciona el dataset DMSII (B07PROTCOB para IDs 1 y 2, B10DOMI para ID 3) y el índice de búsqueda correspondiente (B07SXFECHA o B10SXFECAUT151). La extracción soporta dos modos: por fecha sola (CASO=1) o por fecha + contrato específico (CASO=2), habilitando extracciones quirúrgicas o masivas.

El archivo de salida se nombra dinámicamente con el canal INTELAR hardcodeado 15110S01, el CSI de la máquina, el nombre del reporte, la fecha parametrizada y la hora de ejecución — garantizando unicidad por llamada. Ante error de apertura de BD, reintenta hasta 6 veces con pausa de 10 segundos; ante parámetro inválido o agotamiento de reintentos, termina con STATUS=-1 (terminación anormal que alerta al WFL caller).

4.3 · Capturar_Fecha_Hora_Inicio

PROCEDIMIENTO Capturar_Fecha_Hora_Inicio():              // 00050-INICIO · [P671 L276]
```
// Captura hora de la máquina (HH:MM:SS)
ACEPTAR hora_maquina DESDE TIME                             // WKS-HR-MAQUINA
MOVER WKS-HH-MAQUINA A WKS-MAQ-HH
MOVER WKS-MM-MAQUINA A WKS-MAQ-MM
MOVER WKS-SS-MAQUINA A WKS-MAQ-SS
MOVER WKS-HORA-MAQ   A marca_hora_ruta                     // WKS-HHMMSS → componente del título INTELAR

// Captura fecha de la máquina (MM/DD/AAAA)
ACEPTAR fecha_maquina DESDE TODAYS-DATE                     // WKS-FECHA-MAQUINA
MOVER WKS-FECMAQ-MM   A WKS-MM-ARCH
MOVER WKS-FECMAQ-DD   A WKS-DD-ARCH
MOVER WKS-FECMAQ-AAAA A WKS-AAAA-ARCH

// Fecha parametrizada → componente del título del archivo INTELAR
MOVER WKS-PARAM-FECHA A WKS-FECHA                           // ⚠ [HARDCODE] fecha viene del caller, no de máquina

// Obtener número de CSI (identificador de partición de máquina)
CHANGE ATTRIBUTE LIBACCESS    OF "SOPORTECOMS" TO BYFUNCTION
CHANGE ATTRIBUTE FUNCTIONNAME OF "SOPORTECOMS" TO "SOPORTECOMS"
CHANGE ATTRIBUTE TITLE OF "LIB-DISP" TO
  "(S000)S000/UTILITY/DESPLIEGA/OBJ/LIB ON PACK"
LLAMAR "CSIID IN SOPORTECOMS" CON WKS-SOPCOMS
CANCELAR "SOPORTECOMS"
MOVER WKS-NUMCSI A WKS-CSI                                  // CSI → componente del título INTELAR
```

4.8 · Validar_Parámetros

PROCEDIMIENTO Validar_Parámetros():                      // 00110-VAL-PARAM · [P671 L332]
```
// Paso 1: determinar WKS-CASO según fecha y contrato
SI fecha_aammdd > 0 Y contrato_param = 0 ENTONCES           // WKS-PA-FE-AAMMDD, WKS-PARAM-CTO
  MOVER 1 A caso_búsqueda                                   // CASO=1: extracción masiva por fecha
```
