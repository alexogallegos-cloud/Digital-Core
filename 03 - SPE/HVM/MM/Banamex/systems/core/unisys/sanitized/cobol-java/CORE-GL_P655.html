CORE-GL · P655 a Java 21 Spring Boot

Recibe un código de función y un número de sistema. Liga la librería de control LIBCTL resolviendo su versión en CTLVER, con una ruta fija de respaldo, y consulta los datasets de control diario (B01SISDIA) y mensual (B03SISMEN) para devolver al WFL los nombres de los packs de movimientos, descuentos, errores y saldos y el de la base de saldos. Si la función es 2 o 3 lee el registro del sistema en B04SISTEM y escribe ese mismo código como nuevo estatus. Los errores solo se informan al operador; el programa siempre termina normalmente.

ControlEstatusSistemaTasklet.java · ControlCORE-GLConfig.javaTasklet @StepScope · ExitStatus · DataSourceJava 21
@Component
@StepScope
@RequiredArgsConstructor
public class ControlEstatusSistemaTasklet implements Tasklet {   // PROGRAM-ID CALLLIBCTL

    private final ControlCORE-GLService control;   // reemplaza las entradas de LIBCTL
    @Value("#{jobParameters['funcion']}") private Integer funcion;
    @Value("#{jobParameters['sistema']}") private Integer sistema;

    @Override
    public RepeatStatus execute(StepContribution contribution, ChunkContext ctx) {
        var req = new ControlEstatusRequest(funcion, sistema);
        var dia = control.datosDia(req.sistema());          // 000310-CONSULTA-B01
        var mes = control.datosMes(req.sistema());          // 000320-CONSULTA-B03
        var estado = EstadoActualizacion.NO_APLICA;
        if (req.escribeEstatus()) {                          // IF W77-FUNCION = 2 OR 3
            estado = control.cambiaEstatus(req.sistema(), req.funcion());  // CONSULTA-B04 + CAMBIA-B04
        }
        var res = new ControlEstatusResult(dia.nomPacMov(), dia.nomPacDes(), dia.nomPacErr(),
                dia.nomPacSal(), mes.nomBdSal(), estado);
        ctx.getStepContext().getStepExecution().getJobExecution()
           .getExecutionContext().put("p655", res);

        if (estado == EstadoActualizacion.FALLO_ACTUALIZACION) {
            contribution.setExitStatus(new ExitStatus("ESTATUS_NO_ACTUALIZADO"));   // el WFL lo decide
        }
        return RepeatStatus.FINISHED;
    }
}

ControlCORE-GLService.javarepositorios JPA · @TransactionalJava 21
@Service
@RequiredArgsConstructor
public class ControlCORE-GLService {

    private final SistemaDiaRepository b01;    // CORE-GLB01SISDIA (entrada CONSISDIA)
    private final SistemaMesRepository b03;    // CORE-GLB03SISMEN (entrada CONSISMEN)
    private final SistemaCORE-GLRepository b04;

    /** 000310-CONSULTA-B01. Sin registro: se informa vacío, no el valor anterior. */
    public DatosDia datosDia(int sistema) {
        return b01.findBySistema(sistema)
                .map(d -> new DatosDia(d.nomPacMov(), d.nomPacDes(), d.nomPacErr(), d.nomPacSal()))
                .orElseGet(() -> {
                    log.warn("CONSISDIA sin datos para sistema {}", sistema);
                    return DatosDia.VACIO;
                });
    }

    /** 000320-CONSULTA-B03. */
    public DatosMes datosMes(int sistema) {
        return b03.findBySistema(sistema)
                .map(m -> new DatosMes(m.nomBdSal()))
                .orElseGet(() -> {
                    log.warn("CONSISMEN sin datos para sistema {}", sistema);
                    return DatosMes.VACIO;
                });
    }
}
    /** 000320-CONSULTA-B04 + 000320-CAMBIA-B04: el estatus nuevo es el código de función. */
    @Transactional
    public EstadoActualizacion cambiaEstatus(int sistema, int funcion) {
        List<SistemaCORE-GL> regs = b04.findByIdSistema(sistema);       // función 1
        if (regs.isEmpty()) {
            log.error("ERROR AL CONSULTAR B04 sistema={}", sistema);
            return EstadoActualizacion.FALLO_CONSULTA;               // el original seguía y escribía
        }
        if (regs.size() > 1) {
            throw new IllegalStateException(
                "B04 tiene " + regs.size() + " registros para el sistema " + sistema
                + "; P655 no envía producto ni instrumento");
        }
        try {
            regs.get(0).setEstatus(funcion);                         // MOVE W77-FUNCION TO WKS-B04-ESTATUS
            b04.flush();                                             // función 37 (MANTB04SISTEM)
            return EstadoActualizacion.ACTUALIZADO;
        } catch (OptimisticLockingFailureException e) {
            log.error("ERROR AL ACTUALIZAR B04 sistema={}", sistema, e);
            return EstadoActualizacion.FALLO_ACTUALIZACION;
        }
    }
Riesgos de migración
Fallo de actualización invisible para el WFL

Si MANTB04SISTEM devuelve error (líneas 764-769), P655 solo emite un mensaje informativo y termina con STOP RUN. La jornada sigue con el estatus anterior del sistema.

Escritura sin consulta válida

000300-PROCESO ejecuta CAMBIA-B04 aunque CONSULTA-B04 haya fallado (líneas 717-719 y 753-756). El registro enviado a MANTB04SISTEM contendría lo que hubiera en el área, no el registro del sistema.

Llave incompleta en B04

La librería documenta que la consulta de B04 es por sistema, producto e instrumento (líneas 350-357), pero P655 solo envía el sistema.

Consulta diaria sin CSI

La función 1 de B01SISDIA documenta como entrada requerida el número de CSI (línea 52); P655 limpia el área con LOW-VALUES y solo mueve función y sistema (líneas 723-725).

Respaldo silencioso de librería

Si CTLVER falla se liga (CORE-GL)CORE-GL/OBJECT/L001/CONTROL ON CMEMP sin dejar mensaje (líneas 704-708).

Datos de salida obsoletos

Si CONSISDIA o CONSISMEN fallan, los parámetros de salida conservan el valor que traían de la llamada (líneas 728-732 y 742-743).
