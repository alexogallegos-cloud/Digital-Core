CORE-DEP · P105 a Java 21 Spring Boot

P105 carga primero en memoria el catálogo de claves de movimiento (B17), los sectores por producto (B22) y las cifras acumuladas por producto (B09). Después recorre los movimientos del día y, por cada uno, enciende las banderas de comportamiento de su clave, acumula importes en una tabla de 31 productos según el origen local o foráneo, registra entradas y salidas de SBC a 6 días, cuenta aperturas y cancelaciones y llama a CORE-GLREGISTRA con la póliza del movimiento. Como salidas genera los archivos de cancelaciones, punteo, punteo S054 e incidentes, y al final vuelca la tabla de cifras en B09.

@Component
@StepScope
@RequiredArgsConstructor
public class AplicadorMovimientoProcessor implements ItemProcessor<MovimientoEnCurso, PolizaCORE-GL> {

    private final CatalogoClaves catalogo;          // B17 cargado en memoria
    private final AcumuladorB02 b02;
    private final TablaCifras cifras;               // WS-SAVECIFRAS
    private final ReglasCifras reglas;              // 51040000-ACT-CIFRAS
    private final ValidadorIva iva;
    private final ArchivoCancelaciones cancelaciones;

    /** 51000000-OPERO-MOV / 51000010-CONT-OPERO-MOV. */
    @Override
    public PolizaCORE-GL process(MovimientoEnCurso mov) {
        Optional<BanderasClave> ban = catalogo.banderas(mov.claveMovimiento());   // 51010000-LEO-FUN
        if (ban.isEmpty()) {
            return null;                            // W77-SIN-B17 = 1: incidente 79, el movimiento no se aplica
        }
        boolean entradaSbc6 = mov.claveMovimiento() == 1072 && mov.desdeB27();

        b02.acumula(mov, ban.get());                // 51020000-ACUM-B02
        if (!entradaSbc6) {
            cifras.ubica(mov);                      // 51030000-LEO-TABLA
        }
        PolizaCORE-GL poliza = reglas.aplica(mov, ban.get());   // 51040000-ACT-CIFRAS
        if (!entradaSbc6) {
            iva.valida(mov, ban.get());             // 51050000-VALIDO-IVA
        }
        cancelaciones.registraSiAplica(mov);        // 51060000-CANCEL
        return poliza;
    }
}

@Component

public class CORE-GLRegistraClient {

    private final CORE-GLRegistra libreria;          // adaptador de la librería CORE-GLREGISTRA (CARGAMOV1)
    private final IncidentesWriter incidentes;    // archivo I03 de incidentes
    private final P105Properties props;
    private int fallasDesarrollo;                 // W77-N-FALLA-CORE-GL

    /** 40000100-CALL-CORE-GL. */
    public void envia(PolizaCORE-GL p, MovimientoEnCurso m) {
        int status = libreria.cargaMovimiento(p);
        if (status == 0) return;

        String texto = "ERR CALL LIB/CORE-GLREG RS=%d, FUNCION %02d, FECHA %s"
                .formatted(status, p.funcion(), p.fechaContable());
        incidentes.registra(78, texto, m);                       // W77-PAR-RESULT = 78

        if (props.esDesarrollo()) {                              // 40000120-FALLA-CORE-GL-DES
            if (++fallasDesarrollo < 11) log.info(texto); else log.error(texto);
            log.error("SOLO EN DESARROLLO CONTINUA");
            return;
        }
        log.error(texto);                                        // 40000110-FALLA-CORE-GL-PROD
        if (status == 4) {
            throw new ProcesoAbortadoException(texto);           // CALL SYSTEM DMTERMINATE
        }
        // Cualquier otro estatus: el movimiento queda en incidentes y el paso continúa.
    }
}

Truncamiento del importe en el punteo S054

Rechazos de CORE-GL que no detienen el paso

En 40000110-FALLA-CORE-GL-PROD (líneas 3845-3848) solo el estatus 4 ejecuta DMTERMINATE. Otros rechazos quedan únicamente en el archivo de incidentes y en W77-PAR-RESULT = 78, lo que puede dejar movimientos del día sin registrar en contabilidad.

Aborts desactivados por comentario

Varios DMTERMINATE están comentados: falla de búsqueda en B17 con estatus 1 (línea 5113) y parámetro inválido de afectación S028 (línea 5796). El programa continúa con el movimiento omitido o sin afectar cifras.
