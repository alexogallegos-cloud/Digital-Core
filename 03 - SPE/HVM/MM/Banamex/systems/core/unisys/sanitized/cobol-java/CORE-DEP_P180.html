CORE-DEP · P180 a Java 21 Spring Boot

Une las tres copias del archivo de bloqueos de saldos pendientes y emite su listado. Barre dos veces los contratos de captación, primero CBII y Globaldirect y luego el resto, y envía cada saldo al CORE-GL por la librería CORE-GLREGISTRA, cerrando cada barrido con una señal de fin. Después recorre una sola vez el inventario INVE-PTE que P181 deja clasificado y produce los archivos SALDOSTB y SALDOSTBT para Tandem, el archivo CORE-GLSALDOS con los cambios de saldo materiales y los cortes por sucursal, y los listados de inventario de Ahorros y de saldo disponible. En corridas semanales agrega el reporte de comisiones por grupo TEF.

/** INVERSION-REG: un contrato del inventario clasificado por P181 (campos COMP = decimal empacado). */
public record InversionPte(
        int nodo,                     // 9(02)  llave de corte 1
        int sucursal,                 // 9(04)  llave de corte 2
        int producto,                 // 9(04)
        int instrumento,              // 9(04)
        int moneda,                   // 9(02)  1 = MN, 5 = DLL en las reglas del CORE-GL
        String contrato,              // 9(12)  String: conserva ceros a la izquierda
        String numCliente,            // 9(12)
        BigDecimal saldoAnterior,     // S9(13)V99: único par de importes con signo
        BigDecimal saldoActual,       // S9(13)V99
        BigDecimal saldoBloqueado,    // 9(12)V99
        BigDecimal saldoPendiente,    // 9(12)V99
        BigDecimal saldoPromedioMes,  // 9(12)V99
        BigDecimal autPendiente,      // 9(12)V99
        boolean medioTarjeta) {       // INV-BANTAR-S = 1: el contrato va al archivo de Tandem

    public boolean esAhorros()  { return producto == 500 && instrumento == 6; }
    public boolean esCtaMaestraTandem() {
        return producto == 66 || (producto == 500 && instrumento == 1);
    }
}

                             JobExecutionDecider esSemanal) {
        return new JobBuilder("CORE-DEPP180", repo)
                .start(validaAmbiente).next(fechaYAperturas).next(bloqueosPendientes)
                .next(enviaSaldosCORE-GLCbii).next(enviaSaldosCORE-GLResto)
                .next(generaSalidasInventario)
                .next(esSemanal).on("SEMANAL").to(reporteTefSemanal)
                .from(esSemanal).on("*").end()
                .end()
                .build();

@Component
@RequiredArgsConstructor
public class ValidaAmbienteTasklet implements Tasklet {

    private final P180Properties props;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        long sinS408 = (Long) ctx.getStepContext().getJobParameters().getOrDefault("sinS408", 0L);
        if (!props.permiteSinS408() && sinS408 != 0) {
            throw new ProcesoAbortadoException(
                    "VALUE ERRONEO PARA PRODUCCION, " + sinS408);   // CALL SYSTEM DMTERMINATE
        }
        return RepeatStatus.FINISHED;
    }
}

/** Al terminar el barrido: CLOSE ... WITH LOCK del archivo puente y función 82 u 83 al CORE-GL. */
@RequiredArgsConstructor
class FinEnvioListener implements StepExecutionListener {
    private final int funcionFin;
    private final String archivoPuente;
    @Autowired private CORE-GLRegistraClient core-gl;
    @Autowired private ArchivoPuente puentes;

    @Override
    public ExitStatus afterStep(StepExecution se) {
        if (se.getStatus() != BatchStatus.COMPLETED) return se.getExitStatus();
        puentes.cierra(archivoPuente);                          // señal para el CORE-GL
        core-gl.registra(SolicitudCORE-GL.fin(funcionFin, fechaProceso(se)));
        return ExitStatus.COMPLETED;
    }
}
@Bean
Step generaSalidasInventario(JobRepository repo, PlatformTransactionManager tx,
                             FlatFileItemReader<InversionPte> inventario,   // INVE-PTE de P181
                             InventarioProcessor procesador,
                             ClassifierCompositeItemWriter<SalidaP180> salidas,
                             TotalesListener totales) {
    return new StepBuilder("generaSalidasInventario", repo)
            .<InversionPte, List<SalidaP180>>chunk(180, tx)               // BLOCK CONTAINS 180
            .reader(inventario)
            .processor(procesador)
            .writer(new ListUnpackingItemWriter<>(salidas))
            .listener(totales)       // AT END: trailers de Tandem y CORE-GL, totales por sucursal, nodo y CSI
            .build();
}

@Component
@StepScope
@RequiredArgsConstructor
public class InventarioProcessor implements ItemProcessor<InversionPte, List<SalidaP180>> {

    private final InventarioAhorros ahorros;       // 53300000: listado JasperReports
    private final SalidasResto resto;              // 53410000 .. 53460000

    @Override
    public List<SalidaP180> process(InversionPte inv) {
        if (inv.esAhorros()) {
            ahorros.acumula(inv);                  // no escribe archivos de interfaz
            return List.of();
        }
        if (inv.cancelado() && inv.saldoActual().signum() == 0) return List.of();
        return resto.genera(inv);                  // Tandem, CORE-GL y renglón de disponible
    }
}

@Component
@RequiredArgsConstructor
public class CORE-GLRegistraWriter implements ItemWriter<SolicitudCORE-GL> {

    private final CORE-GLRegistraClient core-gl;      // CORE-GLREGISTRA, ahora API del CORE-GL
    private final P180Properties props;
    private int fallas;                          // WS-FALLA-CORE-GL

    @Override
    public void write(Chunk<? extends SolicitudCORE-GL> chunk) {
        for (SolicitudCORE-GL sol : chunk) {
            // 40000500-CALL-151SDO: los saldos de Ahorros en MN no se envían con función 81.
            if (sol.funcion() == 81 && sol.producto() == 500 && sol.instrumento() == 6 && sol.moneda() == 1) {
                continue;
            }
            int rs = core-gl.registra(sol);
            if (rs > 0) {
                fallas++;
                if (props.ambiente() != Ambiente.DESARROLLO) {
                    throw new ProcesoAbortadoException("ERROR CALL 151REGISTRA RS=%d FUNCION=%d CONTRATO=%s"
                            .formatted(rs, sol.funcion(), sol.contrato()));       // DMTERMINATE
                }
                if (fallas <= props.fallasCORE-GLToleradas()) log.warn("CORE-GL RS={} contrato={}", rs, sol.contrato());
            }
        }
    }
}

public class TandemMapper {

    private final TipoCambio tipoCambio;       // B02-TC-TCAMBIO, PIC 9(04)V9(04)
    private final RegistroControl control;     // B02-NUM-CSI -> WS-TBDE-CSI

    /** 53441000-GRABO-ARCHIVO. Solo contratos cuyo medio de acceso es tarjeta. */
    public Optional<TandemDetalle> mapea(InversionPte inv, Optional<BigDecimal> limiteS408) {
        if (!inv.medioTarjeta()) return Optional.empty();
        BigDecimal saldo = inv.saldoActual().abs();          // MOVE de S9(13)V99 a 9(12)V99: pierde el signo
        BigDecimal saldoMn, autMn, saldoDl, autDl;
        if (inv.moneda() == 1) {
            saldoMn = saldo; autMn = inv.autPendiente();
            saldoDl = BigDecimal.ZERO; autDl = BigDecimal.ZERO;
        } else {                                             // cualquier moneda distinta de 1
            saldoDl = saldo; autDl = inv.autPendiente();
            BigDecimal tc = tipoCambio.vigente();
            saldoMn = inv.saldoActual().multiply(tc).setScale(2, RoundingMode.HALF_UP).abs();  // ROUNDED
            autMn   = inv.autPendiente().multiply(tc).setScale(2, RoundingMode.HALF_UP);
        }
        // COMPUTE WS-S408-LIMITE = WS-S408-LIMITE / 1000 sin ROUNDED: trunca.
        int limiteMiles = limiteS408
                .map(l -> l.divide(BigDecimal.valueOf(1000), 0, RoundingMode.DOWN).intValueExact())
                .orElse(0);
        if (limiteMiles > 999) throw new CampoDesbordadoException("WS-TBDE-LIMCRE", limiteMiles);
        return Optional.of(new TandemDetalle(inv.contrato(), inv.producto(), inv.instrumento(),
                inv.moneda(), '+', saldoMn, limiteMiles, control.numCsi(), inv.sucursal(), autMn,
                inv.status(), saldoDl, autDl));
    }
}
@Component

public class CORE-GLSaldosMapper {

    private final P180Properties props;
    private final CortePorSucursal corte;      // WS-151-SUCANT y acumuladores por moneda

    /** 53450000-ARC151: corte por sucursal y detalle solo si el cambio de saldo es material. */
    public List<SalidaP180> mapea(InversionPte inv) {
        var salida = new ArrayList<SalidaP180>(corte.siCambiaSucursal(inv.sucursal()));  // clave 20
        corte.acumula(inv);                                          // 53450010-ACUM-MON

        if (inv.saldoActual().compareTo(inv.saldoAnterior()) == 0) return salida;
        // WS-SALDO-CORE-GL es PIC 9(14)V99 sin signo: guarda el valor absoluto de la diferencia.
        BigDecimal delta = inv.saldoActual().subtract(inv.saldoAnterior()).abs();
        BigDecimal umbral = props.umbralCORE-GL().get(inv.moneda());    // {1: 1000000.00, 5: 10000.00}
        if (umbral != null && delta.compareTo(umbral) < 0) return salida;

        salida.add(new CORE-GLDetalle(inv.producto(), inv.sucursal(), inv.moneda(),   // WS-D151-SIST <- producto
                Cuentas.sinDigito(inv.contrato()), Cuentas.digito(inv.contrato()),
                inv.instrumento(), inv.nombre(),
                inv.saldoAnterior().abs(), inv.saldoActual().abs(), null));
        return salida;
    }

Riesgos de migración
Signo del saldo perdido en las interfaces

INV-SDOACT-S es S9(13)V99, pero WS-TBDE-SDOMN (Tandem), WS-D151-SACT (CORE-GL) y los acumuladores por sucursal son sin signo; además WS-TBDE-SIGSDO se fija siempre en "+" (línea 4157). Un saldo deudor llega a Tandem y al CORE-GL como positivo, y los totales por sucursal se distorsionan. Coincide con el hallazgo de P420, que tampoco lee el signo.

Límite de crédito truncado

El límite del S408 se divide entre mil y se mueve a WS-TBDE-LIMCRE PIC 9(3) (líneas 4178-4179). Límites de un millón o más pierden el dígito alto sin aviso.

Umbral de materialidad compilado

Los umbrales de 1,000,000 MN y 10,000 DLL para el detalle al CORE-GL están en el código (líneas 4270-4271). Monedas distintas de 1 y 5 no tienen umbral.

Ambientes por nombre de servidor

VDMALFA, MONBETA, ACYPBETA y VDMBETA están compilados (líneas 1760-1765); cualquier otro servidor se trata como UAT. La regla de producción sobre el S408 depende de esa lista.

Desbordamiento en conversión de dólares

WS-IMP-CALSDO es S9(12)V99 y recibe INV-SDOACT-S (13 enteros) por el tipo de cambio con ROUNDED y sin ON SIZE ERROR; un saldo grande en dólares perdería dígitos altos en el importe MN enviado a Tandem.
