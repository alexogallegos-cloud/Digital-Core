Con 0 o 1 ejecuta FECHAS: calcula la fecha de hoy (la de ayer si es antes de mediodía), lee la fecha de la base y, con TASKVALUE 1, solo la devuelve en el TASKVALUE. Si hoy ya alcanzó la fecha de la base o llega un parámetro, avanza la fecha un día (o la fija con el parámetro), pone en cero los veinte contadores de arribo y la guarda en una transacción; si no, informa que la prelínea ya está hecha. Con 16 o 17 ejecuta PROX_SISTEMA, que recorre el catálogo de sistemas de L001 y devuelve en el TASKVALUE el siguiente sistema activo que corre en el CSI, o 9999.

/** El TASKVALUE de entrada es la operación y el de salida es el resultado para el WFL. */
public enum OperacionP000 {
    AVANZA_FECHA(0), CONSULTA_FECHA(1), SIGUIENTE_SISTEMA(16), SIGUIENTE_SISTEMA_ALT(17);
    final int taskValue;
    OperacionP000(int v) { taskValue = v; }
    static Optional<OperacionP000> de(int v) {
        return Arrays.stream(values()).filter(o -> o.taskValue == v).findFirst();
    }
}

@Configuration
public class ControlFechasJobConfig {

    @Bean
    Job controlFechas(JobRepository repo, Step resuelveControl, Step fechas, Step proxSistema) {
        JobExecutionDecider porOperacion = (job, step) -> new FlowExecutionStatus(
                OperacionP000.de(job.getJobParameters().getLong("taskValue", 0L).intValue())
                        .map(o -> o == OperacionP000.SIGUIENTE_SISTEMA
                                  || o == OperacionP000.SIGUIENTE_SISTEMA_ALT ? "SISTEMA" : "FECHAS")
                        .orElse("NADA"));                          // ELSE: vacío en el CASE
        return new JobBuilder("CORE-GLP000", repo)
                .start(resuelveControl)                            // VERSIONES
                .next(porOperacion).on("FECHAS").to(fechas)
                .from(porOperacion).on("SISTEMA").to(proxSistema)
                .from(porOperacion).on("NADA").end()
                .end().build();
    }

public final class PivoteY2k {
    private static final int ANIO_BASE = 50;              // a2k_base_year

    public static LocalDate deAammdd(int aammdd) {
        int aa = aammdd / 10_000;
        int siglo = (aa >= ANIO_BASE) ? 1900 : 2000;      // 50..99 -> 19xx, 00..49 -> 20xx

            .appendValueReduced(ChronoField.YEAR, 2, 2, 1950)
            .appendPattern("MMdd").toFormatter();
}

Riesgos de migración
Ciclo infinito de liga

En VERSIONES, WHILE LINKLIBRARY(SOPORTE) < 0 y WHILE DELINKLIBRARY(SOPORTE) < 0 (líneas 670 y 676) repiten la llamada sin espera ni límite; una caída de SOPORTECOMS bloquea la cadena de CORE-GL con consumo de procesador.

Un día por corrida
