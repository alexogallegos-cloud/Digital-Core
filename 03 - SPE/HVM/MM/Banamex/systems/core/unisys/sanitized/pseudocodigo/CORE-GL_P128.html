P128 · Reporte de Diferencias S264 (CORE-GL LegacyCore)

CORE-GLProgramaCOBOL

Fuente: COBOL_P128.cbl (2346 LOC) · Reporte comparativo diario de diferencias contables S264 · BC-11

Convenciones: nombres traducidos (Unisys→legible); [P128 Lnnnn] = línea en fuente merged; (BR: RN-...) = regla de negocio.

1. Resumen funcional

P128 genera el reporte de diferencias del sistema S264 comparando los movimientos contables enviados al sistema S028 contra los enviados al sistema S115. El programa lee el archivo de entrada CORE-GL/FILE/MOVS264/AAMMDD, ordena los movimientos por clave compuesta (moneda, sucursal inicial, referencia, clave de transacción), agrupa los registros por esa clave y contrasta los importes acumulados en cada destino contable. Cuando los totales no coinciden, registra las diferencias en el reporte de bitácora S264/LIST/P128/… con nombre lógico "001CORE-GLDIFS264".

Es un programa de control de integridad contable del ciclo diario del S264: no produce asientos ni modifica bases de datos, solo detecta y reporta desbalances entre los dos sistemas receptores.

        │                 └── (si > 55 líneas) EJECUTAR 41110-IMP-ENCAB

PROCEDIMIENTO Calcular_Espacio_Sort():            // 70000-CALCULA-ESPACIO · [P128 L1824]
// === Ajuste de MAXRECSIZE para arquitecturas ClearPath con FRAMESIZE=8 ===
// En MCP de 48 bits (framesize=48), se usa 8 como indicador de alineación de palabra
SI tamanio_frame = 8 ENTONCES             // W77-FRAMESIZE = 8 [P128 L1826]
  // Ajustar a múltiplos de 6 (6 bytes por palabra de 48 bits)
  CALCULAR calc_word = tamanio_max_registro / 6   // WS-CALC-WORD [P128 L1827]
  SI residuo_calc > CEROS ENTONCES        // WS-WORD-RES > 0 → hay fracción [P128 L1829]
    // Redondear hacia arriba
    CALCULAR tamanio_max_registro = parte_entera + 1  // WS-WORD-ENT + 1 [P128 L1830]
  SINO
    CALCULAR tamanio_max_registro = parte_entera      // WS-WORD-ENT [P128 L1832]

// === Fórmula de memoria para el SORT (palabras MCP) ===
// Memoria = (MAXRECSIZE + 3) * 2000 + 1500
CALCULAR memoria_sort REDONDEADA =         // W77-MEMORY-SIZE [P128 L1835]
  (tamanio_max_registro + 3) * 2000 + 1500
  // ⚠ [HARDCODE-SOSPECHOSO: factor 2000+1500 es constante ClearPath MCP]

// === Fórmula de disco para el SORT (palabras MCP) ===
// Disco = MAXRECSIZE * #registros * 3.5

  tamanio_max_registro * total_registros * 3.5
  // ⚠ [HARDCODE-SOSPECHOSO: factor 3.5 es constante ClearPath MCP]
