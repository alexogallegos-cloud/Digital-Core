P600 · Despliegue de Fechas Operacionales (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P600.cbl (903 LOC) · utilitario de diagnóstico batch · BC-18

Convenciones: nombres traducidos (Unisys→legible); [P600 Lnnn] = línea de archivo fuente; (BR: RN-CORE-GL-###) = regla de negocio del KB.

1. Resumen funcional

P600 (PROGRAM-ID CALLLIBCTL, path funcional DSPFECHAS) es un utilitario de diagnóstico batch de 903 LOC que consulta la biblioteca de control LIBCTL (CORE-GLL001CTL) para desplegar el estado de fechas operacionales de todos los sistemas activos registrados en el CORE-GL. Para cada sistema con estatus de activo (3 o 5) cuya CSI coincide con el host actual o que opera en modalidad global, el programa lee las fechas de consulta (LINEA), de proceso batch (BATCH) y de proceso CORE-GL desde el dataset de control B01SISDIA, y obtiene la fecha de recepción de la librería L002 (CORE-GLREGISTRA). Para el sistema especial CORE-DEP, adicionalmente interroga las librerías L009 y L012 para obtener fechas de envío y confirmación de movimientos. Toda la información se emite al log del operador mediante la librería de mensajes LIB-DISP (S000LIBLJ). El programa no modifica ningún dato: es de solo lectura.

2. Datos y archivos

2.1 No hay FILE-CONTROL ni FD

P600 no declara ningún archivo secuencial ni de disco propio. Todo acceso a datos se realiza mediante llamadas a funciones de la biblioteca LIBCTL.

3. Mapa de control

PROGRAMA P600 (DSPFECHAS)
│
├── 000100-INICIO                          [L700]  ← punto de entrada único
│   ├── 000200-LIBRERIAS                   [L722]  ← carga y configura librerías
│   ├── 000300-LLAMA-LIBCTL                [L747]  ← iteración principal sobre sistemas
│   │   └── 000310-CALL-L001              [L766]  ← LOOP: un sistema por iteración
│   │       └── 000400-LLAMA-L002         [L797]  ← condicional: sistema activo+CSI
│   │           ├── 000420-LLAMA-L009     [L825]  ← solo si sistema = 500
│   │           └── 000440-LLAMA-L012     [L848]  ← solo si sistema = 500
│   ├── 000500-DSP-FECHAS                  [L871]  ← LOOP: despliega 1 línea por sistema
│   └── 000500-DSP-LIBRERIAS              [L882]  ← despliega datos L009/L012 (CORE-DEP)
│
└── 800000-DISPLAY                         [L902]  ← subrutina: emite MENSAJE-LJ via LJ

Leyenda de control:

  • 000300-LLAMA-LIBCTL: hace primer B04SISTEM función 02 y luego entra al loop 000310-CALL-L001.
  • 000310-CALL-L001: itera via PERFORM ... UNTIL W77-FIN = 1; al final de cada iteración llama B04SISTEM función 02 nuevamente para avanzar al siguiente sistema; termina cuando el resultado es > 0 (fin del catálogo).
  • 000500-DSP-FECHAS: llamado con PERFORM VARYING W77-IND2 FROM 1 BY 1 UNTIL W77-IND2 > W77-IND.
  • 000500-DSP-LIBRERIAS: llamado una sola vez después del loop anterior.
  • 800000-DISPLAY: llamado desde DSP-FECHAS y desde DSP-LIBRERIAS; no es PERFORM directamente desde INICIO.
