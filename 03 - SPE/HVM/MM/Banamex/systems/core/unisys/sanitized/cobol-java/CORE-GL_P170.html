Recibe por parámetro el número de sistema y el identificador del paso que generó el archivo. Con la fecha de proceso arma el título del archivo de entrada CORE-GL/FILE/CORE-GL/{paso}/{fecha} y lo lee registro por registro. Cada registro trae 132 columnas de texto más dos campos de control: un registro INICI con BACK cierra el listado en curso y abre uno nuevo cuyo título es el propio texto del registro, PAGE provoca salto de página y un número indica cuántas líneas avanzar. Al terminar crea un archivo vacío en CORE-GL/FILE/I01 que sirve como marca de que el proceso corrió.

/** REG-IMPRESION: 132 de texto + FILLER + OPCION1 X(05) + FILLER + OPCION2 X(04) + FILLER X(07). */
public sealed interface RegistroImpresion
        permits RegistroImpresion.InicioBackup, RegistroImpresion.SaltoPagina,
                RegistroImpresion.Linea {

    String texto();                                   // LINEA-IMPRESION X(132)

    /** OPCION1 = "INICI" y OPCION2 = "BACK": el texto es el título del nuevo backup. */
    record InicioBackup(String texto) implements RegistroImpresion {}
    /** OPCION2 = "PAGE": WRITE ... AFTER PAGE. */
    record SaltoPagina(String texto) implements RegistroImpresion {}
    /** OPCION2 numérico (REDEFINES 9(04)): WRITE ... AFTER n líneas. */
    record Linea(String texto, int avance) implements RegistroImpresion {}

    static RegistroImpresion parse(String r) {
        String texto = r.substring(0, 132);
        String op1 = r.substring(133, 138);
        String op2 = r.substring(139, 143);
        if (op1.equals("INICI") && op2.equals("BACK")) return new InicioBackup(texto);
        if (op2.equals("PAGE")) return new SaltoPagina(texto);
        if (!op2.chars().allMatch(Character::isDigit)) {
            throw new RegistroInvalidoException("OPCION2 no numérica: '" + op2 + "'");
        }
        return new Linea(texto, Integer.parseInt(op2));
    }
}

/** A2K-OBTAIN-CENTURY: AA menor que 50 es 20xx, de lo contrario 19xx (A2K-BASE-YEAR). */
private static final int PIVOTE_Y2K = 50;

static LocalDate desdeAammdd(String aammdd) {
    int aa = Integer.parseInt(aammdd.substring(0, 2));
    int siglo = (aa < PIVOTE_Y2K) ? 2000 : 1900;
    return LocalDate.of(siglo + aa, Integer.parseInt(aammdd.substring(2, 4)),
                        Integer.parseInt(aammdd.substring(4, 6)));
}

// Parámetros del job: sistema (WKS-PARAM-SIS 9(03)) e idPaso (WKS-NOMBRE-IDPASO X(08)).
@Bean
@StepScope
FlatFileItemReader<RegistroImpresion> entrada(P170Properties props,
        @Value("#{jobExecutionContext['contexto']}") ContextoP170 ctx,
        @Value("#{jobParameters['sistema']}") Integer sistema,
        @Value("#{jobParameters['idPaso']}") String idPaso) {
    String titulo = props.resuelve(props.entrada(), sistema, idPaso,
                                   ctx.fechaProceso(), ctx.pack());
    return new FlatFileItemReaderBuilder<RegistroImpresion>()
            .name("archivoEnt")
            .resource(recursos.de(titulo))
            .lineMapper((linea, n) -> RegistroImpresion.parse(linea))
            .strict(true)          // OPEN INPUT falla si el archivo no existe
            .build();
}
/** 02-0150-IMPRIME-BACKUPS: cada INICI/BACK cierra el listado actual y abre otro. */
@Component
@StepScope
public class BackupRotatorioWriter implements ItemStreamWriter<RegistroImpresion> {

    private final SpoolImpresion spool;      // reemplaza PRINTER + USERBACKUPNAME
    private ListadoAbierto actual;           // W77-BACK-ABIERTO

    @Override
    public void write(Chunk<? extends RegistroImpresion> chunk) {
        for (RegistroImpresion r : chunk) {
            switch (r) {
                case RegistroImpresion.InicioBackup b -> {
                    if (actual != null) actual.cierraYGuarda();        // CLOSE MOVIMIENTOS WITH SAVE
                    actual = spool.abre(b.texto().trim());             // CHANGE ATTRIBUTE TITLE
                }
                case RegistroImpresion.SaltoPagina p -> listado().saltoDePagina(p.texto());
                case RegistroImpresion.Linea l       -> listado().avanza(l.avance(), l.texto());
            }
        }
    }

    private ListadoAbierto listado() {
        if (actual == null) {
            throw new ListadoNoAbiertoException("línea antes del primer INICI/BACK");
        }
        return actual;
    }
}
    @Override
    public void close() {
        if (actual != null) actual.cierraYGuarda();     // IF W88-BACK-ABIERTO CLOSE ... WITH SAVE
    }
}

Riesgos de migración
Fecha de proceso sin asignar

En 01-0110-LIBRERIAS el MOVE de WKS-B01-FECPRO a WKS-FECHA-PROCESO está comentado (línea 1058). Si la tarea no trae fecha en su atributo VALUE, el título del archivo de entrada se arma con una fecha sin inicializar.

Resultado de CONSISDIA no verificado

W77-RESULT-LIBCON recibe el resultado de la llamada a la librería de control (línea 1055) y ningún párrafo lo revisa; un error deja vacío el pack del archivo de entrada.

Archivo I01-MOVIMIENTOS sin contenido

El archivo de disco se abre y se guarda sin escribir registros. La regla RN-CORE-GL-895 dice que P170 reproduce el listado hacia ese archivo, lo que no coincide con el fuente.

Control de impresión sin validar

OPCION2 se usa como número de líneas sin comprobar que sea numérica y una línea que llegue antes del primer INICI/BACK se escribiría sobre un archivo de impresión cerrado.

Pendiente de revisión SME
  • Confirmar si la fecha de proceso debe tomarse de B01 cuando VALUE = 0; el fuente tiene esa asignación comentada y la versión Java la restituye.
  • RN-CORE-GL-895 indica que el listado se reproduce en el archivo de disco I01-MOVIMIENTOS; en el fuente ese archivo queda vacío. Revisar la redacción de la regla en el brain.
  • Confirmar quién consume el archivo de residencia CORE-GL/FILE/I01/CORE-GL/{paso}/{fecha} y si su sola existencia es la señal esperada.
  • Las rutinas CRONOS2K incluidas en el fuente usan pivote 50 (A2K-BASE-YEAR); confirmar que no se requiera otro pivote para fechas posteriores a 2049.
