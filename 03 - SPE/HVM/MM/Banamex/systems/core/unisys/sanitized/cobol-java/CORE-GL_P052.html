CORE-GL · P052 a Java 21 Spring Boot

P052 corre todo el día como tarea residente: en cada vuelta del ciclo principal acepta un evento de ESPERACOMS, revisa la hora de máquina y decide qué archivos de salida toca generar. Para la centralización recorre MOVCORE-DEP y MOVS264 desde la última autorización enviada y, por cada uno de los cinco importes del movimiento, decide si va al archivo de centralización según moneda, tipo de cambio, clave de transacción, importe en efectivo, entidad, rango de importes, caja virtual y días sin movimiento. Con la misma mecánica selecciona los movimientos cuyo CVETRAN está marcado en el catálogo de fraudes. Al terminar cada envío actualiza el archivo de control A02-CTL-ENVIO con la última autorización procesada por destino.

        int origen, int status, long fecUltMov, long autCORE-GL) {

    /** Elemento de A00-R01-ELE-CVEIMP. */
    public record Importe(int cveTran,          // 9(06) COMP
                          int indLey,
                          int esqCon,           // REDEFINES A00-R01-TM
                          BigDecimal importe,   // 9(16)V99 COMP -> escala 2
                          int cveDesvio,
                          int guiaDesvio) {}

    /** PERFORM ... VARYING W77-IND FROM 1 BY 1 UNTIL W77-IND > 5 OR A00-R01-CVETRAN(W77-IND) = 0 */
    public static List<Importe> vigentes(Importe[] ocurrencias) {
        return Arrays.stream(ocurrencias)
                .limit(5)

                .toList();

@Component
@RequiredArgsConstructor
public class AccivalScheduler {

    private final InicializacionService inicio;   // 020000-INICIO: catálogos, SIRH, tipo de cambio, cortes
    private final VentanaEnvioService ventanas;   // 030300-GENERA-ARCHIVO
    private final ImporteEfectivoStore umbral;    // 020310-ACT-ARCHIMP
    private final Clock clock;                    // ACCEPT ... FROM TODAYS-DATE / TIME

    @EventListener(ApplicationReadyEvent.class)
    void arranque() {
        inicio.cargar();                          // PERFORM 020000-INICIO
    }

    /**
     * 030100-PROCESO UNTIL W77-FIN = 1. ESPERACOMS con timeout se vuelve un disparo
     * periódico; el fin (CS-COMS-IN-STATUS-KEY = 99) es el apagado ordenado del servicio.
     */
    @Scheduled(fixedDelayString = "${accival.ciclo:PT15S}")
    void ciclo() {
        ventanas.despachar(LocalDateTime.now(clock));
    }

    @PreDestroy
    void fin() {
        umbral.persistir();                       // PERFORM 020310-ACT-ARCHIMP antes de STOP RUN
    }
}
@Service
@RequiredArgsConstructor
public class VentanaEnvioService {

    private final JobLauncher launcher;
    private final ControlEnvioRepository control;          // A02-CTL-ENVIO
    private final Map<Destino, Job> jobsPorDestino;        // CENTRAL, S408, S403, CONLI, FRAUD, S274, S501
    private final IntelarGateway intelar;                  // 030705-ENVIO-POR-INTELAR

    public void despachar(LocalDateTime ahora) {
        // 030302-VERIFICA-ENVIO: cada destino tiene su propia hora de siguiente envío
        EnumSet<Destino> vencidos = control.destinosVencidos(ahora);
        if (vencidos.isEmpty()) return;

        for (Destino d : List.of(Destino.S501, Destino.CENTRAL, Destino.S408, Destino.S403,
                                 Destino.CONLI, Destino.FRAUD)) {     // orden del fuente
            if (!vencidos.contains(d)) continue;
            JobExecution ex = launcher.run(jobsPorDestino.get(d), parametros(d, control.ultimaAutorizacion(d)));
            if (ex.getStatus() == BatchStatus.COMPLETED) {
                control.actualiza(d, ex);                // 030350-ACTUALIZA-CONTROL
                if (d.viajaPorIntelar()) {
                    intelar.enviar(d.titulo(ex));        // UNSTRING WKS-TITLE-... INTO WKS-INTE-ARCHIVO
                }
            }
        }
    }
}
@Component
@ManagedResource(objectName = "mx.legacycore.core-gl:name=AccivalUmbralEfectivo")
@RequiredArgsConstructor
public class ImporteEfectivoStore {

    private static final BigDecimal TOPE_9_05 = new BigDecimal("99999");
    private final ParametroRepository parametros;     // sustituye al archivo A08-IMPORTES
    private volatile BigDecimal umbral;

    @PostConstruct void cargar() { umbral = parametros.importeEfectivo1001(); }

    @ManagedOperation(description = "HI 30..35: suma o resta al umbral de CVETRAN 1001")
    public void ajustar(int delta) {                  // +1000, +5000, +10000, -1000, -5000, -10000
        fija(umbral.add(BigDecimal.valueOf(delta)));
    }

    @ManagedOperation(description = "HI 36: fija el umbral en formato 9(05)")
    public void fija(BigDecimal nuevo) {
        if (nuevo.signum() < 0 || nuevo.compareTo(TOPE_9_05) > 0) {
            // COMPUTE sobre PIC 9(05) sin signo pierde el signo y los dígitos altos
            throw new IllegalArgumentException("Umbral fuera de PIC 9(05): " + nuevo);
        }
        umbral = nuevo;
        parametros.guardaImporteEfectivo1001(nuevo);  // el fuente solo lo persiste al terminar
    }

    public BigDecimal actual() { return umbral; }
    public void persistir()    { parametros.guardaImporteEfectivo1001(umbral); }
}

    public record Rango(BigDecimal tipoCambio, BigDecimal menor, BigDecimal mayor) {}

    public Rango cargar() {
        var consulta = new ConsultaTarifa(151, 701, 21, /*prod*/ 33, /*ins*/ 5,
                                          /*cveTar*/ 60, /*mon*/ 5, /*persona*/ 1, /*plazo*/ 1);

                .filter(r -> r.resultado() == 0 || r.resultado() == 1)
                // 020710-CALCULA-VALOR: divide entre 10 tantas veces como DEC-VALOR(1)

                .orElse(props.tipoCambioRespaldo());       // MOVE 10 TO W77-TIPO-CAMBIO

        return new Rango(tc, menor, mayor);

public class CentralizacionClassifier {

    private static final BigDecimal USD_MINIMO = new BigDecimal("5.01");
    private static final Set<Integer> CVETRAN_SIEMPRE = Set.of(618, 619, 708, 720);

    private final TipoCambioService.Rango rango;
    private final ImporteEfectivoStore efectivo;
    private final Catalogos cat;            // WKS-TAB-NATCON-500/264, WKS-NUM-SIRH
    private final RuteoProperties props;

    public boolean centraliza(MovimientoContable m, MovimientoContable.Importe imp, int diasSinMov) {
        int nat = (m.sistema() == 500) ? cat.natcon500(imp.cveTran()) : cat.natcon264(imp.cveTran());
        boolean natCargoAbono = nat == 1 || nat == 2;

        BigDecimal importe = (m.moneda() == 5)
                ? imp.importe().multiply(rango.tipoCambio()).setScale(2, RoundingMode.DOWN)   // sin ROUNDED
                : imp.importe();

        if (m.moneda() == 5 && imp.importe().compareTo(USD_MINIMO) < 0 && natCargoAbono) return true;
        if (m.sistema() == 500 && imp.cveTran() == 1001
                && imp.importe().compareTo(efectivo.actual()) >= 0) return true;   // importe sin convertir
        if (CVETRAN_SIEMPRE.contains(imp.cveTran())) return true;
        if (cat.esEntidadEnvio(m) && natCargoAbono) return true;              // W88-ENTIDAD-ENVIO
        if (!natCargoAbono) return false;

        boolean fueraDeRango = importe.compareTo(rango.menor()) < 0 || importe.compareTo(rango.mayor()) > 0;
        int caja = RuteoProperties.cajaTruncada(m.cajaTran());
        return switch (m.sistema()) {
            case 500 -> fueraDeRango
                    || props.cajasVirtuales().core-dep().contains(caja)
                    || diasSinMov < cat.numDias();                             // W77-NUMDIAS
            case 264 -> fueraDeRango || cajaVirtualS264(m.sucTran(), caja);
            default  -> false;
        };
    }

    private boolean cajaVirtualS264(int suc, int caja) {
        var lista = props.cajasVirtuales().s264().get(String.valueOf(suc));
        return lista != null && lista.contains(caja);
    }
}

    public List<RegistroFraude> process(MovimientoContable m) {
        // El fuente escribe: SISTEMA = 500 AND TIPO-PROC = 40 OR 41 OR 42 OR 43.
        // COBOL evalúa AND antes que OR: (SISTEMA = 500 AND TIPO-PROC = 40) OR TIPO-PROC = 41 OR 42 OR 43.
        boolean excluido = (m.sistema() == 500 && m.tipoProc() == 40)
                || m.tipoProc() == 41 || m.tipoProc() == 42 || m.tipoProc() == 43;

Riesgos de migración
Tipo de cambio fijo cuando falla S080

En 020700-TIPO-CAMBIO (líneas 9930-9936) cualquier resultado distinto de 0 o 1 deja W77-TIPO-CAMBIO en 10 durante toda la vida de la tarea residente. No hay reintento ni alerta en bitácora; la conversión de USD y el rango normal de importes quedan calculados con ese valor.

Truncamiento de la caja en el chequeo de cajas virtuales

MOVE A00-R01-CAJATRAN (PIC 9(04)) TO W77-CVIRTUAL-CORE-DEP / W77-CVIRTUAL-S264 (PIC 9(02)) en la línea 10934 conserva solo los dos últimos dígitos. Cajas como 140 o 191 se evalúan como 40 y 91 y se tratan como virtuales.

Comparaciones con importe sin convertir

En 030344-MUEVE-IMPORTES el umbral de 5.01 y el umbral de efectivo de la clave 1001 se comparan con A00-R01-IMPORTE original (líneas 10950 y 10956-10957), mientras el rango normal usa el importe convertido a pesos (líneas 10969-10970).

Umbral de efectivo sin control de desbordamiento

W77-IMPORTE-EFECTIVO es PIC 9(05) sin signo y se ajusta con COMPUTE sin ON SIZE ERROR desde las interrupciones HI 30 a 35 (líneas 9051-9067). Un ajuste que salga de 0..99999 pierde signo o dígitos sin aviso.

Subíndice sin validar en la tabla de fraudes

WKS-TAB-FRAUD-500 tiene OCCURS 5000 (línea 7222) y se indexa con el CVETRAN, que puede valer hasta 999999. Un CVETRAN mayor a 5000 en CORE-DEP indexa fuera de la tabla, lo que en el MCP normalmente termina la tarea con INVALID INDEX.

Hardcodes de operación

CVETRAN privilegiados 618, 619, 708, 720; umbral de 5.01 USD; VALUE 49000; respaldo de tipo de cambio 10; NUMDIAS 180 por omisión; nombres de equipo y horas de cancelación de LIBL030 (líneas 10372-10385); cuentas fijas en WKS-TABLA-STA-CTA (líneas 7224-7234). Se trasladan a application.yml.
