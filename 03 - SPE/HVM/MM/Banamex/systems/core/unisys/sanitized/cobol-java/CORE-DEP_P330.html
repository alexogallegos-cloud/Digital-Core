CORE-DEP · P330 a Java 21 Spring Boot

Lee el control CORE-DEPB02CONTROL y, si el CSI de la corrida es 10, recorre los grupos CORE-DEPB37GRUPOCPE y sus cuentas CORE-DEPB39CTASCPE. Para cada cuenta calcula el rendimiento del saldo promedio con la tasa real bruta sobre base 360, la retención de ISR con el factor de la tarifa 254 del catálogo S080 sobre base 365 o 366, descontando la parte exenta de cinco UMA anuales para personas físicas, y la comisión por cheques girados con el IVA de la sucursal. Graba los importes en B39 y los acumulados del grupo en B37, escribe un archivo de paso de transacciones que después se ordena para generar las cintas de cuenta-producto de Valle de México y Monterrey, e imprime tres listados de control.

    private final P330Properties props;   // p330.bisiesto.excepciones: hosts y años a forzar en 365

    /** 10010-CHECA-BISIESTO: divisor anual del ISR (36500 o 36600, días por cien). */
    public BigDecimal divisorAnualIsr(LocalDate fechaProceso, String host) {
        boolean bisiesto = Year.isLeap(fechaProceso.getYear());   // regla 4/100/400 del fuente
        boolean excepcion = props.bisiesto().hosts().contains(host.trim())
                && props.bisiesto().anios().contains(fechaProceso.getYear());   // hoy: 2016
        int dias = (!bisiesto || excepcion) ? 365 : 366;
        return BigDecimal.valueOf(dias * 100L);            // WS-DIAS-ANUAL-EDIT
    }
}

                        .producto(9991).instrumento(2).tarifa(252)

                .map(r -> r.valorMaximo(0))                 // REP080-TAR-CODVALMAX(01)
                .orElseGet(() -> {
                    log.warn("Tarifa 252 no disponible; se usa UMA de respaldo {}", params.umaAnualRespaldo());
                    return params.umaAnualRespaldo();       // comportamiento actual, ahora con aviso
                });
        // COMPUTE WS-SMGX5 = WS-SMGX5-UMA * 5  (producto exacto, escala 4)
        return umaAnual.multiply(BigDecimal.valueOf(params.vecesUma())).setScale(4, RoundingMode.DOWN);

                .end()
                .build();
    }

class CsiBancoDecider implements JobExecutionDecider {
    private final ControlCaptacionRepository control;           // CORE-DEPB02CONTROL
    private final P330Properties props;                          // p330.csi-banco: 10

    @Override
    public FlowExecutionStatus decide(JobExecution job, StepExecution step) {
        return control.numCsi() == props.csiBanco()
                ? new FlowExecutionStatus("BANCO") : new FlowExecutionStatus("OTRO_CSI");
    }

@Component
@StepScope
@RequiredArgsConstructor
public class GrupoCpeReader implements ItemReader<GrupoCpe> {

    private final GrupoCpeRepository grupos;      // CORE-DEPB37GRUPOCPE
    private final Iterator<String> gruposDeCuentas; // grupos en el orden de B39SXGPOSBGMDA

    /** 20000-PROCESO-CALCULOS: un grupo por iteración, con su lista de cuentas B39. */
    @Override
    public GrupoCpe read() {
        while (gruposDeCuentas.hasNext()) {
            String numGrupo = gruposDeCuentas.next();          // WS39-GRUPO
            GrupoCpe g = grupos.findById(numGrupo)
                    .orElseThrow(() -> new ProcesoAbortadoException(
                            "ERROR FATAL NO HAY GRUPO " + numGrupo));   // STATUS OF MYSELF TO -1
            if (g.opcion() == 0) {
                log.warn("Grupo {} con opción 0: se omite", numGrupo);  // en COBOL: NEXT SENTENCE
                continue;                                     // el iterador sí avanza
            }
            return g;
        }
        return null;                                          // WS-EOF-BD = 1
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class CalculoCuentaCpeProcessor implements ItemProcessor<CuentaCpe, CuentaCpe> {

    private static final BigDecimal BASE_360 = new BigDecimal("36000");
    private final CalculadoraIsr isr;
    private final P330Properties props;   // umbrales 0.050 y 0.61 en p330.isr.umbral-*

    @Override
    public CuentaCpe process(CuentaCpe c) {
        TipoPersona tp = c.tipoPersona();
        // Exención de personas físicas 1 y 7: saldo promedio contra UMA exenta de la cuenta (B39)
        boolean exento = tp.esFisicaConExencionUma()
                && c.saldoPromedio().subtract(c.umaExenta()).signum() < 0;

        BigDecimal rendimiento = c.saldoPromedio().multiply(c.tasaRealBruta())
                .divide(BASE_360, 20, RoundingMode.DOWN)
                .multiply(BigDecimal.valueOf(c.diasCiclo()))
                .setScale(2, RoundingMode.DOWN);                 // COMPUTE sin ROUNDED

        BigDecimal retencion = BigDecimal.ZERO.setScale(2);
        if (rendimiento.signum() > 0 && !(tp == TipoPersona.EXENTO_4 || exento)) {
            if (c.grupo().opcionPago().pagaPorCuenta() && tp.esMoralOExtranjeroSobretasa()) {
                retencion = isr.sobretasa(c);                    // 20142 (personas 2, 9, 12, 14)
            } else if (tp.esExtranjero() && c.tasaRealBruta().compareTo(props.umbralExtranjero()) < 0) {
                retencion = isr.tasaMenor(c);                    // 20158, umbral 0.050
            } else if (c.tasaRealBruta().compareTo(props.umbralGeneral()) < 0) {
                retencion = isr.tasaMenor(c);                    // 20158, umbral 0.61
            } else {
                retencion = isr.general(c);                      // 20140
                if (c.grupo().opcionPago().pagaPorCuenta() && c.tasaPagada().signum() > 0) {
                    retencion = BigDecimal.ZERO.setScale(2);
                }
            }
        }
        // INI-L3CORE-DEP-CPE: el ISR nunca excede al rendimiento
        if (rendimiento.compareTo(retencion) < 0) {
            return c.conResultado(BigDecimal.ZERO.setScale(2), rendimiento);
        }
        return c.conResultado(rendimiento.subtract(retencion), retencion);
    }
}
@Service
@RequiredArgsConstructor
public class CalculadoraIsr {

    private static final BigDecimal BASE_360 = new BigDecimal("36000");
    private final ParametrosIsr p;            // factorIsr (tarifa 254), factorIsrExtranjero (259),
                                              // divisorAnual (36500/36600), exencionAnual (5 UMA)

    /** 20140-CALCULA-IMPUESTO. Todos los COMPUTE truncan (sin ROUNDED). */
    public BigDecimal general(CuentaCpe c) {
        BigDecimal saldo = c.saldoPromedio();
        BigDecimal dias = BigDecimal.valueOf(c.diasCiclo());
        if (c.grupo().opcionPago().pagaPorCuenta() && c.tasaPagada().signum() > 0) {
            return cero();                                        // NEXT SENTENCE: WS-ISR queda en 0
        }
        return switch (c.tipoPersona().categoriaIsr()) {
            case EXENTA -> cero();                                // persona 4
            case MORAL -> proporcional(saldo, dias);              // 2, 9, 14, 3, 16 (US-81, 2022)
            case EXTRANJERA -> {                                  // 11, 12, 15
                BigDecimal bruto = saldo.multiply(c.tasaRealBruta())
                        .divide(BASE_360, 20, RoundingMode.DOWN).multiply(dias);
                yield trunca(bruto.multiply(p.factorIsrExtranjero()));
            }
            case FISICA_UMA -> proporcional(                      // 1, 7: 50008460, exención por cuenta
                    saldo.subtract(c.umaExenta()).max(BigDecimal.ZERO), dias);
            case OTRA -> proporcional(                            // resto: exención global de 5 UMA
                    saldo.subtract(p.exencionAnual()).max(BigDecimal.ZERO), dias);
        };
    }

    /** ((base * WS-ISR-0) / WS-DIAS-ANUAL-EDIT) * WS-DIAS-CTE */
    private BigDecimal proporcional(BigDecimal base, BigDecimal dias) {
        return trunca(base.multiply(p.factorIsr())
                .divide(p.divisorAnual(), 20, RoundingMode.DOWN).multiply(dias));
    }

    private static BigDecimal trunca(BigDecimal v) { return v.setScale(2, RoundingMode.DOWN); }
    private static BigDecimal cero() { return BigDecimal.ZERO.setScale(2); }
}
    /** 20158-TASA-MEN-ISR: la tasa real no alcanza al factor de retención. */
    public BigDecimal tasaMenor(CuentaCpe c) {
        if (c.grupo().opcionPago().pagaPorCuenta() && c.tasaPagadaBruta().signum() > 0) {
            return cero();                                        // marca WS-MEN-85 = 1 para el reporte
        }
        BigDecimal saldo = c.saldoPromedio();
        BigDecimal dias = BigDecimal.valueOf(c.diasCiclo());
        BigDecimal tasa = c.tasaRealBruta();
        if (c.tipoPersona().esExtranjero()) {
            if (tasa.compareTo(p.factorIsrExtranjero()) > 0) {
                return cero();                                    // NEXT SENTENCE: no toca WS-ISR
            }
            // Base 365/366 para el ISR, a diferencia del rendimiento que usa 360
            return trunca(saldo.multiply(tasa).divide(p.divisorAnual(), 20, RoundingMode.DOWN).multiply(dias));
        }
        if (tasa.compareTo(p.factorIsr()) > 0) {
            return cero();
        }
        // "Todos los intereses (WS-PRODUCTOS) van a impuestos (WS-ISR)"
        return trunca(saldo.multiply(tasa).divide(BASE_360, 20, RoundingMode.DOWN).multiply(dias));
    }
@Service
public class CalculadoraComision {

    /** Comisión según clase de cálculo (WS-CONTCLACAL) y tarifa normal o PLUS del grupo. */
    public BigDecimal comision(CuentaCpe c, TarifaComision t) {
        long cobrables = c.chequesGirados() - c.chequesDevueltos();     // devoluciones topadas a cargos
        BigDecimal base = BigDecimal.valueOf(cobrables)
                .multiply(c.grupo().tasaPactada() == 0 ? t.comisionProd() : t.comisionPlus());
        BigDecimal comision = switch (c.claseCalculo()) {
            case 2 -> base.multiply(t.tasaComisionCap());                 // porcentaje / 100
            case 0 -> base;
            default -> BigDecimal.ZERO;
        };
        if (t.importeComisionCap().signum() > 0) {                        // importe fijo por cheque gana
            comision = BigDecimal.valueOf(cobrables).multiply(t.importeComisionCap());
        }
        return comision.setScale(2, RoundingMode.DOWN);                   // 9(13)V99, sin ROUNDED
    }

    /** IVA con ROUNDED: HALF_UP. Solo la parte entera de la tasa de la sucursal. */
    public BigDecimal iva(BigDecimal comision, TasaIvaSucursal tasa) {
        if (comision.signum() <= 0) return BigDecimal.ZERO.setScale(2);
        BigDecimal enteros = BigDecimal.valueOf(tasa.enteros());          // WS-TABIVA-ENTEROS
        return comision.multiply(enteros)
                .divide(BigDecimal.valueOf(100), 2, RoundingMode.HALF_UP);
    }
}

Riesgos de migración
Bucle sin avance con grupos de opción 0

En 20000-PROCESO-CALCULOS (líneas 5409-5420) un grupo con WS37-OPCION = 0 termina en NEXT SENTENCE sin ejecutar 20100-PROCESA-GRUPO, que es donde se avanza sobre las cuentas B39. Como el ciclo principal solo termina con WS-EOF-BD = 1, un grupo así dejaría el programa repitiendo el mismo FIND. No se encontró otra ruta que mueva el cursor en ese caso.

Truncamiento en ISR y rendimientos

Todos los COMPUTE de rendimiento e ISR (20140, 20142, 20158 y 50008460) carecen de ROUNDED y se asignan a PIC 9(8)V99 o 9(13)V99: los centavos se truncan. La versión Java usa RoundingMode.DOWN para reproducirlo; cambiarlo a redondeo alteraría la retención contra lo declarado históricamente.

Bases de días distintas para rendimiento e ISR

El rendimiento se calcula sobre 36000 (año de 360 días en porcentaje) y la retención sobre WS-DIAS-ANUAL-EDIT, que vale 36500 o 36600. Es una convención fiscal plausible, pero debe confirmarse con Fiscal porque altera el importe retenido.

Excepción de año bisiesto por nombre de host

En 10010-CHECA-BISIESTO (líneas 4601-4609) el año 2016 se trata como de 365 días solo en los hosts ACYPBETA, MONALFA, ACYPGAMA, VDMKAPPA y ACYPOMEGA. El resultado del cálculo depende de la máquina donde corre.

UMA de respaldo compilada

WS-SMGX5-UMA tiene VALUE 137694.0000 (línea 230, fechado 18/01/2017). Si la consulta a la tarifa 252 del catálogo S080 falla, la exención de ISR se calcula con ese valor fijo multiplicado por cinco, sin aviso.

IVA con solo la parte entera de la tasa

El IVA de la comisión se calcula con WS-TABIVA-ENTEROS (líneas 5771-5773), la parte entera de la tasa por sucursal; los decimales se guardan aparte solo para el reporte. Una tasa con decimales se aplicaría truncada.

Grabación en DMSII sin transacción explícita

En 20902-MUEVE-A-B39 y 20902-MUEVE-A-B37 las llamadas a BEGIN-TRANSACTION y END-TRANSACTION están comentadas (líneas 6284, 6297, 6300 y 6312). La unidad de recuperación ante una caída a mitad del proceso no está clara.
