CORE-DEP · L081 a Java 21 Spring Boot

L081 exporta seis entry points: un handshake obligatorio, consulta y actualización de atributos de contrato (dataset CORE-DEPB01CONTRATOS), consulta y actualización del registro de control (CORE-DEPB02CONTROL) y un canal para recibir HIs por API. Cuando el cliente entrega una tarjeta en lugar del contrato, la traduce con la librería S016L458. La actualización recibe una cadena de hasta diez agrupadores; solo el agrupador bA, indicador de cuenta ordenante, tiene validaciones de fecha, hora y antigüedad frente a lo guardado. Cada llamada se registra en archivos MONITOR o PROBLEM que se transmiten a INTELAR, y la librería permanece residente atendiendo HIs de operación hasta que no quedan usuarios.

@Component
@RequiredArgsConstructor
class ResolutorMedioAcceso {
    private final S016MedioAccesoClient s016;           // S016L458.S016_L458_BUSCA_MDA
    private final AtomicBoolean llamadaHabilitada = new AtomicBoolean(true);   // B_LLAMA_S016 (HI 4195)

    /** LLAMA_S016: medio de acceso de 16 dígitos a contrato y CSI. */
    ResultadoResolucion resuelve(String medioAcceso16) {
        if (!llamadaHabilitada.get()) return ResultadoResolucion.error(ResultadoL081.S016_DESACTIVADO);
        try {
            RespuestaS016 r = s016.buscaMda(medioAcceso16);
            if (r.dmsError() > 0) {
                log.warn("ERROR CALL S016: {}", r.dmsError());
                return ResultadoResolucion.error(ResultadoL081.S016_INCORRECTO);   // 18
            }
            return ResultadoResolucion.ok(r.contrato(), r.csi());
        } catch (ServicioNoDisponibleException e) {
            return ResultadoResolucion.error(ResultadoL081.S016_DESACTIVADO);      // 17: no se pudo ligar
        }
    }
}

ResultadoL081 validaEntrada(ActualizaContratoRequest rq, int sistemaLlamador) {
    if (!Set.of(0, 1, 2).contains(rq.tipoMda()))        return ResultadoL081.TIPO_MDA_INVALIDO;   // 2
    if (rq.medioAcceso().signum() <= 0)                 return ResultadoL081.MDA_INVALIDO;        // 3
    if (rq.tipoMda() == 0 && !props.csiValidos().contains(rq.csiContrato())) {
        return ResultadoL081.CSI_INVALIDO;                                                        // 6
    }
    if (!Set.of(0, 1, 2).contains(rq.origen()))         return ResultadoL081.ORIGEN_INVALIDO;     // 7
    if (sistemaLlamador != props.sistemaPropio()
            && !calendario.esFechaValida(rq.fechaProceso())) {                                    // LOCSUP
        return ResultadoL081.FECHA_PROCESO_INVALIDA;                                              // 20
    }
    return ResultadoL081.OK;
}
/** Grupo 1 ("bA"): indicador de cuenta ordenante con fecha y hora de alta o actualización. */
ResultadoL081 validaCuentaOrdenante(AtributoNumerico a, AtributosContrato actual, int sistemaLlamador) {
    if (a.dato() != 0 && a.dato() != 1) return ResultadoL081.IND_CUENTA_ORDENANTE_INVALIDO;    // 9
    if (sistemaLlamador == props.sistemaPropio()) return ResultadoL081.OK;      // CORE-DEP no se valida
    if (!calendario.esFechaValida(a.fecha()))  return ResultadoL081.FECHA_CTA_ORDENANTE_INVALIDA;  // 21
    if (!esHoraValida(a.hora()))               return ResultadoL081.HORA_CTA_ORDENANTE_INVALIDA;   // 22

    // VALIDA_FECHOR_REC: lo enviado debe ser posterior a los dos sellos guardados del grupo 1.
    boolean posteriorAlta = posterior(a.fecha(), a.hora(), actual.grupo1().fecMaq(), actual.grupo1().hora());
    boolean posteriorBaja = posterior(a.fecha(), a.hora(), actual.grupo1().fecMaq2(), actual.grupo1().hora2());
    return (posteriorAlta && posteriorBaja) ? ResultadoL081.OK
                                            : ResultadoL081.FECHA_HORA_BD_MAS_RECIENTE;          // 23
}

private static boolean posterior(int fecha, int hora, int fechaBd, int horaBd) {
    return fecha > fechaBd || (fecha == fechaBd && hora > horaBd);   // AAAAMMDD y HHMMSSnn como enteros
}

@Transactional
public ResultadoL081 actualizaContrato(ActualizaContratoRequest rq) {
    var inicio = validaInicio();                                  if (inicio.isPresent()) return inicio.get();
    var entrada = validaEntrada(rq, contexto.sistema());         if (entrada != ResultadoL081.OK) return entrada;

    ContratoCsi cc = (rq.tipoMda() == 0)
            ? new ContratoCsi(rq.medioAcceso(), rq.csiContrato())
            : resolutor.resuelve(rq.medioAcceso()).orElseThrowResultado();     // LLAMA_S016

    AtributosContrato atr = repo.findByContratoForUpdate(cc.contrato())         // LOCK B01SXCTO
            .orElseGet(() -> AtributosContrato.nuevo(cc.contrato(), cc.csi(),
                                                     rq.fechaProceso(), reloj.fecha(), reloj.hora()));
    var agrup = aplicaAgrupadores(rq.agrupadores(), atr);       // VALIDA_AGRUPADOR (hasta 10)
    if (agrup != ResultadoL081.OK) return agrup;                 // la transacción se revierte y libera el bloqueo

    atr.marcaActualizacion(rq.fechaProceso(), reloj.fecha(), reloj.hora());
    atr.setCsiContrato(cc.csi());
    repo.save(atr);                                              // PUT + STORE; error -> excepción -> rollback
    return ResultadoL081.OK;
}

Riesgos de migración
Estado global compartido sin protección

Con SHAREDBYRUNUNIT (línea 32), las matrices de trabajo, R_DMERR e I_RESULT son globales (líneas 39-161) y no existe PROCURE ni LIBERATE; invocaciones solapadas en la misma run unit pueden cruzar datos de contratos.

Número de tarjeta en claro en la bitácora

Con la traza encendida por el HI 4196 se despliegan el medio de acceso y el contrato completos (líneas 714, 1682, 2128). Debe enmascararse por PCI-DSS.

Registro bloqueado tras un rechazo

El LOCK de VALIDA_B01CTO (línea 1686) no tiene FREE en ninguna ruta; si el agrupador es inválido la actualización termina sin liberar el registro.

Transacción sin aborto ni verificación de cierre

ACT_CREA_CTO abre con NOAUDIT y cierra con AUDIT (líneas 2004 y 2112) aunque CREATE o STORE hayan fallado, y no revisa el resultado de ENDTRANSACTION.

Validación parcial de agrupadores

Los grupos 2 a 10 del CASE de VALIDA_AGRUPADOR_INFO (líneas 1764-1773) están vacíos; cualquier dato en esos agrupadores se guarda sin control.

Hardcodes

CSI válidos 10 y 4, sistema 500 exento de validación, rutas (CORE-DEP)CORE-DEP/FILE/INTS/50004S01 y títulos ON CAPTACION, versión 002. Se trasladan a configuración.
