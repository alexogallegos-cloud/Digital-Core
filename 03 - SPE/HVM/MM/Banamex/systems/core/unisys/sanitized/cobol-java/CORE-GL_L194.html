    @Override
    public int remueveArchivos(String dir, int fechaCorteJuliana) {
        var raizDir = directorioValido(dir);
        if (raizDir.isEmpty()) return -2;

        // GETSTATUS tipo directorio devuelve los nombres por bloques; el bit 47 de GSA[0]
        // indica que hay más entradas. DirectoryStream entrega la lista completa de una vez.
        try (DirectoryStream<Path> entradas = Files.newDirectoryStream(raizDir.get())) {
            for (Path archivo : entradas) {
                procesa(archivo, fechaCorteJuliana);
            }
        } catch (IOException e) {
            log.warn("Error en GetStatus {}", dir, e);   // el DISPLAY está comentado en ALGOL
            return -1;
        }
        return 0;                                        // en ALGOL no se asigna en la ruta exitosa
    }
    private void procesa(Path archivo, int fechaCorteJuliana) throws IOException {
        var attrs = Files.readAttributes(archivo, BasicFileAttributes.class);
        if (attrs.isDirectory()) return;                     // nuevo: L194 no lo verifica

        // ACC_DATE := 1900000 + fecha de acceso de GETSTATUS: se interpreta como AAAADDD juliano.
        LocalDate acceso = LocalDate.ofInstant(attrs.lastAccessTime().toInstant(), zona);
        int accesoJuliano = acceso.getYear() * 1000 + acceso.getDayOfYear();
        if (accesoJuliano >= fechaCorteJuliana) return;      // IF ACC_DATE < FECHA

        if (enUso(archivo)) return;                          // SUBVALUE3F = 1: archivo en uso
        if (props.mueveArchivos()) mueveARespaldo(archivo);
    }

    private boolean enUso(Path archivo) {
        try (var ch = FileChannel.open(archivo, StandardOpenOption.WRITE);
             var lock = ch.tryLock()) {
            return lock == null;
        } catch (IOException | OverlappingFileLockException e) {
            return true;
        }
    }
    /** OPEN(F) con el título original, cambio de TITLE a RESPALDO/<nombre> y CLOSE(F, LOCK). */
    private void mueveARespaldo(Path archivo) throws IOException {
        Path destino = raiz.resolve(props.prefijoRespaldo())
                           .resolve(raiz.relativize(archivo));
        Files.createDirectories(destino.getParent());
        Files.move(archivo, destino, StandardCopyOption.ATOMIC_MOVE);   // conserva el contenido
        log.info("Archivado {} -> {}", archivo, destino);
    }

Riesgos de migración
Nombre engañoso

REMUEVE_ARCHIVOS no borra: retitula los archivos bajo RESPALDO/ (líneas 87-96). Quien lo invoque esperando liberar espacio en el pack no lo logra.

Directorios no excluidos

SUBVALUE2F (líneas 36-39) se define pero no se evalúa; solo se excluyen los archivos en uso (línea 83).

Resultado indefinido en éxito y sin bitácora

La ruta exitosa no asigna REMUEVE_ARCHIVOS y todos los DISPLAY están comentados (líneas 50-51 y 63-64); no queda evidencia de qué archivos se movieron.

Switches de tarea sin efecto

B_REMUEVE y B_DESPLIEGA se leen de SW1 y SW2 y se sobrescriben con TRUE en las líneas 44-45.

Pendiente de revisión SME
  • El inventario no asocia reglas del brain a L194; no se usaron IDs de regla.
  • Confirmar el formato de la fecha que recibe L194 y el de la fecha de acceso de GETSTATUS; la suma 1900000 de la línea 81 sugiere juliano AAAADDD con año relativo a 1900, pero no se documenta en el fuente.
  • Confirmar qué programas invocan L194 y con qué directorios, para dimensionar el árbol RESPALDO.
  • Confirmar qué hace CLOSE(F, LOCK) cuando ya existe un archivo con el título de respaldo.
