P117 · DIFERENCIAS (CORE-GL · Compensación Contable Nacional · LegacyCore)

CORE-GLProgramaCOBOL

Fuente: COBOL_P117.cbl (~3394 LOC) · Programa batch de reporteo de diferencias · BC-11

Convenciones: nombres traducidos (Unisys→legible); [P117 Lnnnn] = origen; (BR: RN-...) = regla de negocio.

Dialecto: COBOL85 Unisys ClearPath MCP con extensiones (ATTRIBUTE, CHANGE ATTRIBUTE, LIBACCESS BYFUNCTION, REPORT SECTION, SORT con OUTPUT PROCEDURE).

1. Resumen funcional

P117 (CORE-GL-P117-DIFERENCIAS) produce reportes con las diferencias detectadas entre lo OPERADO y lo APLICADO/CONFIRMADO en las transacciones de los archivos LOG de cada C.S.I. (Centro de Servicio de Información), para control de la Compensadora Nacional [P117 L31-33]. Lee el LOG general de movimientos de compensación (LOG-GRAL), agrupa los movimientos por clave de autorización, empareja y cancela pares operado↔aplicado que cuadran (mismo importe, misma cuenta, mismo tipo cargo/abono), y lo que no cuadra se considera diferencia. Los movimientos con diferencia se ordenan (SORT) y se emiten en cuatro reportes de impresión (R/151-117/001-DIFERENCIAS, /002-DUPLICADOS, /003-DIFSUCURSAL, /004-DIFNOCONTABLE) con totales de punteo multinivel (sistema→fecha→moneda→CSI→general), y se alimenta un archivo histórico de diferencias (HISTDIF) por CSI (BR: RN-CORE-GL-786, RN-CORE-GL-789).

Como segunda función, arma un enlace al sistema S028 (archivo S028MANIOBRA / MOVSXTERM): las diferencias se transforman en registros de maniobra contable (cargos/abonos invertidos según operado/aplicado) que se ordenan y re-reportan por sucursal para su registro. Es un job de detección y conciliación contable (flag CNBV/Interno), sin escritura a DMSII: opera sobre archivos secuenciales de disco y reportes de impresora.

2. Datos y archivos

Archivos (FILE-CONTROL) [P117 L45-59]:

  • LOG-GRAL (DISK, entrada) — LOG general con todas las transacciones en línea aceptadas para compensación; registro 160 bytes; título físico dinámico en NOMBRE-LOG-GRAL = CORE-GL/FILE/LOGGRAL/AAMMDD. (BR: RN-CORE-GL-790) [P117 L90-96, L598-605].
  • TEMPFILE (DISK, temporal) — movimientos con diferencia (no cancelados), 160 bytes; se purga al final [P117 L99-104].
  • SORT-LOG (SORT DISK) — sort de diferencias por SLOG-LLAVE (CSI-ORI, moneda, fecha-con, apl-ori, CSI-des, apl-des, cuenta-des, cve-mov, importe, status) [P117 L154-168].
  • S028MANIOBRA (DISK) + SORT-S028 — registros de maniobra para enlace S028 (204 bytes) [P117 L114-119, L171-174].
  • MOVSXTERM (DISK) — archivo de salida S028 por CSI; título CORE-GL/FILE/MOVSXTERM/{CSI}/AAMMDD. [P117 L107-112, L540-546].
  • HISTDIF (DISK) — archivo histórico de diferencias en oper/apli por CSI, 204 bytes, título fijo CORE-GL/FILE/HISTDIF [P117 L147-152].
  • A01-CONTROL (DISK SEQUENTIAL) — archivo de control de fechas (CORE-GL)CORE-GL/FILE/CONTROL/CORP.; de aquí se lee la fecha de proceso [P117 L74-78].
  • REPORTE (PRINTER, REP-DIFERENCIA) — reporte 001-DIFERENCIAS.
  • LISTADO (PRINTER) — reporte 002-DUPLICADOS.
  • INICSUC (PRINTER, REP-INICSUC) — reporte 003-DIFSUCURSAL.
  • DIFNOCON (PRINTER, LDNC) — reporte 004-DIFNOCONTABLE.
  • V00-REPORTE2 (PRINTER) — bitácora de mensajes del proceso (copy CPBAS).
  • FILE1 — pseudo-archivo usado solo para leer atributos de compilación (CREATIONDATE/CREATIONTIME) vía truco COBOL74.

Layouts de registro clave (WORKING-STORAGE):

  • WS-REG-DET-INFOICA (160 bytes) — registro de detalle de movimiento leído del LOG [P117 L398-445]: CSI-ORI (88 RDI-CSI-ORI-VAL = {2,4,10}, BR: RN-CORE-GL-788), CSI-DES, nombre-estación (tipo-disp/suc/caja), fecha/hora-gen, APL-ORI, APL-DES, STA-TRN (88: 1=ENVIADO, 2=APLICADO, 3=OPERADO, 4=DENEGADO, 5=PENDIENTE), COD-SER (88: 10=CARGO, 11=ELIMCARGO, 20=ABONO, 21=ELIMABONO — BR: RN-CORE-GL-787), SUB-SER, CTA-DES, IMP-TRN S9(16)V99, MON-TRN, FEC-CON, CVE-AUT, NUM-TRN, CTA-ACC, REF-OPE.
  • WS-TABLA-VERIF-MSG — tabla en memoria de hasta 100 registros de LOG (WS-TVM-OCC OCCURS 100) con mismos campos redefinidos, usada para el emparejamiento operado/aplicado dentro de una misma clave de autorización [P117 L751-786]. ⚠ [HARDCODE-SOSPECHOSO] límite fijo 100 movimientos por clave de autorización.
  • WS-REG-HIST-DIF — registro histórico: fecha, moneda, sistema, CSI, y matriz WS-RHD-APLI-CONF OCCURS 2 × WS-RHD-CARABO-ELIM OCCURS 4 (num+importe por operado/aplicado × cargo/abono/elimcargo/elimabono) [P117 L488-496].
  • WS-REG-SORT-S028 — llave de maniobra (CSI, SUC, TREP, MON, FEC-CON, APL, SUCOPE, CAJOPE, NUMAUT) + resto [P117 L379-390].
  • TABLA-CCRS — tabla de 20 CSI con abreviatura/nombre/CCR; solo CSI 02, 04, 10 tienen datos reales, el resto "-DESCONOCIDO-" ⚠ [HARDCODE-SOSPECHOSO] [P117 L647-695].
  • TABLA-SISTEMAS — 5 sistemas emisores (CHS001/CHEQUES, CMS001/CTA MAESTRA, LBS001/LINEA LEGACYCORE, OAS001/ORDENES ABONO, BCS001/BCO EN SU CASA) [P117 L728-748].
  • TAB-MENSAJES — 4 textos de diferencia: "CONF NO APLICADO", "APLICADO NO CONF", "ELIM CONF NO APL", "ELIM APL NO CONF" [P117 L700-706].
  • TAB-DIFNOCON (TAB-DNC OCCURS 21) — etiquetas cargo/abono/elim (" CR","ECR"," DR","EDR") indexadas por COD-SER [P117 L715-726].
  • APUNTADORES-WS: PTER-CSIOK = {2,4,10,32}, WS-CSI-TANDEM=02 ⚠ [HARDCODE-SOSPECHOSO] [P117 L1193-1207].
  • WKS-DATOS-HOST — CSI/nombre-equipo/nombre-CSI/línea-batch obtenidos del host vía CSIID OF SOPORTECOMS [P117 L1230-1234].

REPORT SECTION [P117 L1856-2113]: define los report-groups REP-DIFERENCIA (grupos DET-MONEDA, DET-FECHA, DET-SISTEMA, DET-DIFER, DET-DIF-VACIO, TOT-SISTEMA/FEC/MON/CSI/GRAL, SALDO) y REP-INICSUC (grupos ...-1: DET-MONEDA-1, DET-DIFER-1, TOT-...-1, SALDO-1) emitidos con GENERATE desde §4.

4.1 Arranque y utilidades de fecha

PROCEDIMIENTO Carga_Tiempos_Compilacion():            // FNC-CARGA-TIEMPOS · [P117 L2119]
   // Truco COBOL74/MCP: usa el propio objeto como "archivo" FILE1 para leer sus atributos.
   MOVER atributo NAME de MI_MISMO   A nombre_codigo          // CODE-FILE
   CAMBIAR atributo TITLE de FILE1   A nombre_codigo
   SI atributo PRESENT de FILE1 = VERDADERO
      EJECUTAR Carga_Times()                                  // 100-CARGATIMES
   SINO
      MOVER 999999 A fecha_compila_mmddaa                     // valores centinela
      MOVER 99999999999 A hora_compila
      MOVER 99999 A fecha_compila_ddaa
   ACEPTAR reloj FROM TIMER
   CALCULAR reloj = ((reloj * 2.4) / 1000000) * 60            // sexagésimos → unidades
PROCEDIMIENTO Carga_Times():                          // 100-CARGATIMES · [P117 L2132]
   MOVER atributo CREATIONTIME de FILE1 A hora_compila
   CALCULAR hora_compila = hora_compila / 2.4
   MOVER atributo CREATIONDATE de FILE1 A fecha_compila_ddaa  // formato juliano DDDAA
   descomponer en JUL-YY (año) y JUL-DDD (día del año)
   SI año_juliano < 80  ENTONCES año4 = año + 2000            // ⚠ pivote Y2K hardcode
   SINO                       año4 = año + 1900
   SI (año4 MOD 4 = 0)                                        // año bisiesto
      EJECUTAR Suma_Uno VARIANDO apunt_mes DESDE 1 HASTA JUL-DDD < M-DAY(mes)+1  // tabla bisiesto
      MOVER apunt_mes A mes; día = JUL-DDD - M-DAY(mes-1)
   SINO
      igual con tabla no-bisiesto D-DAY(...)
   MOVER fecha_MMDDYY A fecha_compila_mmddaa
PROCEDIMIENTO Suma_Uno(): EXIT.                       // 200-SUMAUNO · [P117 L2167]
   // Cuerpo vacío. Sólo sirve de blanco para el PERFORM ... VARYING que localiza el mes.

4.2 Driver principal — 000-RUTINA-PRINCIPAL [P117 L2170-2331]

PROCEDIMIENTO Rutina_Principal():                     // 000-RUTINA-PRINCIPAL · [P117 L2170]
   // 1) Enlaces a librerías del sistema (MCP)
   CAMBIAR TITLE de "LIB-DISP" A "(S000)S000/UTILITY/DESPLIEGA/OBJ/LIB ON PACK."
   habilitar librería "CTLVER"  BYFUNCTION -> "CTLVERS"
   habilitar librería "SOPORTECOMS" BYFUNCTION -> "SOPORTECOMS"
   LLAMAR "CSIID OF SOPORTECOMS" USING datos_host          // obtiene CSI/nombre/línea batch del host
   MOVER num_csi_host A titulo_backup_csi

   // 2) Identificación del paso y encabezados de bitácora
   MOVER "CORE-GL" A sistema_bitacora; "P117" A paso; "001" A mtp; "DIARIO" A tipo_proceso
   MOVER "151" A sistema_num
   MOVER CEROS A INDICES, WS-FECHAS, WS-NUM-AUT, CONTADORES

   EJECUTAR Obtiene_Fecha_Control()                        // 11500  → fecha de proceso
   EJECUTAR Vacia_Fechas()                                 // 12500  → formatea/valida CSI

   // Bitácora: INICIO DE PROCESO (código 020101)
   registrar_mensaje("I", 020101, "INICIO DE PROCESO")     // 000-030-IMPRIME-MENSAJE
   ACEPTAR hora_actual FROM TIME

   // 3) Prepara constantes de enlace S028 (cabecera/movimiento/trailer)
   MOVER LOW-VALUES A registros_S028 (ctl, tra, mov)
   MOVER "HR" A tipo_cabecera_S028; "TR" A tipo_trailer_S028
   MOVER "CORE-GL" A cve_sistema_S028; "COMP. NACIONAL" A nombre_sistema_S028
   MOVER fecha_proceso(AMD) A nombre_log, nombre_reporte(AAMMDD), hist_fec_ctl, nombre_S028_fec
   MOVER partes fecha/hora A títulos de los 4 reportes (TIT-*)

   // 4) Abre HISTDIF y graba su registro de control
   ABRIR SALIDA HISTDIF
   ESCRIBIR REG-HIST-DIF DESDE registro_control_historico
      INVALID KEY:
         registrar_mensaje("I", 010105, "NO SE PUEDE GRABAR REG DE CTRL HISTORICO")
         SET MI_MISMO(STATUS) = -1                          // aborta job con status de error

   // 5) Pre-arma títulos de MOVSXTERM por cada CCR/CSI de la tabla (1..20)
   EJECUTAR Crea_Movsxterm VARIANDO IND-CSI DESDE 1 HASTA IND-CSI > LIM-CCRS(=20)   // 1000

   // 6) Abre LOG-GRAL con título dinámico + los 4 reportes de impresión
   CAMBIAR TITLE de LOG-GRAL A NOMBRE-LOG-GRAL              // (BR: RN-CORE-GL-790)
   MOVER MIXNUMBER de MI_MISMO A nombre_reporte.mix; nodo=10; subnodo=0; tipo="R"
   nombre_reporte(seq=001,desc="DIFERENCIA") ; ABRIR SALIDA REPORTE
   nombre_reporte(seq=002,desc="DUPLICADOS") ; ABRIR SALIDA LISTADO
   nombre_reporte(seq=003,desc="DIFSUCUR")   ; ABRIR SALIDA INICSUC
   nombre_reporte(seq=004,desc="DIFNOCONT")  ; ABRIR SALIDA DIFNOCON
   INITIATE REP-DIFERENCIA, REP-INICSUC

   EJECUTAR Proceso()                                       // 2000-PROCESO (núcleo)

   TERMINATE REP-DIFERENCIA, REP-INICSUC
   CERRAR HISTDIF WITH LOCK
   CERRAR REPORTE, LISTADO, INICSUC, DIFNOCON
   registrar_mensaje("I", 020201, "FIN NORMAL DEL PROCESO")
   STOP RUN

PROCEDIMIENTO Analiza_Movtos():                       // 2510-ANALIZA-MOVTOS · [P117 L2522]
   // Procesa un GRUPO de movimientos que comparten la misma CLAVE DE AUTORIZACION.
   MOVER SPACES A tabla_verif(100) ; MOVER 0 A ind_tab
   MOVER cve_autorizacion_actual A WS-NUM-AUT
