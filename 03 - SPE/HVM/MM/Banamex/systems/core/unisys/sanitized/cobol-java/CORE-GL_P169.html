CORE-GL · P169 a Java 21 Spring Boot

Lee el archivo de saldos de entrada (registro de 390 bytes) y exige que su header traiga la fecha de proceso. Por cada registro tipo 81 arma un registro de interfaz con sucursal, divisa, estatus y los saldos actual (concepto 2) y disponible (concepto 354), lo enriquece con nombre, domicilio, idioma y número de responsabilidad consultando la librería S016 L422, y lo escribe a un temporal de CITD si el indicador de envío CITD es 2 o 3, y a un temporal de BNE si el indicador BNE es 1 y el host está en la lista autorizada. En una segunda pasada completa cada saldo con la consulta SALDOSXCTO de la librería S408, escribe el archivo definitivo y un archivo monitor, y finalmente dispara la copia de ambos archivos por WFL.

/** A22-R00-SALDOS: el tipo de registro decide la vista (00 header, 81 saldo). */
public sealed interface SaldoEntrada permits SaldoEntrada.Header, SaldoContrato, SaldoEntrada.Otro {
    record Header(int sistema, int producto, LocalDate fecha) implements SaldoEntrada {}
    record Otro(int tipoReg) implements SaldoEntrada {}      // P169 solo procesa el tipo 81
}

/** A22-R01-REG-SAL (vista CORE-DEP de A22-R01-FILXAPL). Campos COMP: decodifica el lector binario. */
public record SaldoContrato(
        int sistema, int producto, int instrumento,
        int sucursalPromotora,              // A22-R01-SUCPRO 9(04)
        String contrato,                    // A22-R01-CNT 9(16): String para conservar ceros
        int estadoCuenta,
        LocalDate fecProceso, LocalDate fecInicio, LocalDate fecFin, LocalDate fecUltMov,  // 9(08) AAAAMMDD
        int status,
        List<ConceptoSaldo> conceptos,      // OCCURS 30 TIMES
        int moneda,                         // A22-R01-MONEDA: 5 = dólares
        int indEnvioBne,                    // primer dígito de A22-R01-INDENVCTD
        int indEnvioCitd                    // segundo dígito de A22-R01-INDENVCTD
) implements SaldoEntrada {

    /** A22-R01-IMPT PIC S9(13)V99: importe con signo, escala 2. */
    public record ConceptoSaldo(int clave, BigDecimal importe) {}

    public Optional<BigDecimal> importe(int clave) {
        return conceptos.stream().filter(c -> c.clave() == clave)
                        .map(ConceptoSaldo::importe).reduce((a, b) -> b);   // gana la última ocurrencia
    }
}
/** R04-SDOSCITD-T: 385 bytes de interfaz ACC más 18 de control interno (contrato). */
public record AcciRecord(
        String recordType,              // X(03) "ACI"
        int branch,                     // 9(03)
        String genCust,                 // 9(12)
        int ccyCode,                    // 9(03)
        String acctNbr1, String acctNbr2,   // 9(12) + 9(23)
        String liaNbr,                  // 9(11)
        String swiftCcy,                // X(04)
        String shortName,               // X(32)
        char statInd,                   // X(01): ' ', 'B', 'C'
        int catCode,                    // 9(07)
        String lastTxnDate,             // 9(07): formato pendiente de confirmar
        SignedAmount acctBal,           // 9(15)V99 + X(01)
        SignedAmount lcyAcctBal,
        SignedAmount dispValBal,
        String bankNonBank, String mail, char mailToCollect, String mailRuleOff,
        int languageCode,
        String customerName, String addr1, String addr2, String addr3, String addr4,
        String contrato                 // ACCI-CONTRATO-T 9(16): no viaja al corresponsal
) {
    /** El layout guarda magnitud y signo por separado: el valor nunca es negativo. */
    public record SignedAmount(BigDecimal magnitud, char signo) {
        public SignedAmount {
            if (magnitud.signum() < 0) throw new IllegalArgumentException("magnitud negativa");
            magnitud = magnitud.setScale(2, RoundingMode.UNNECESSARY);
        }
        public static SignedAmount of(BigDecimal v) {
            return new SignedAmount(v.abs(), v.signum() < 0 ? '-' : '+');
        }
        public BigDecimal valor() { return signo == '-' ? magnitud.negate() : magnitud; }
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class HeaderSaldosValidator implements StepExecutionListener {

    @Value("#{jobParameters['fechaProceso']}") private LocalDate fechaProceso;
    private final SaldosEntradaReader reader;

    /** 150-007-VALIDA-HEADER: header "HD" con la fecha de proceso o el step no arranca. */
    @Override
    public void beforeStep(StepExecution stepExecution) {
        Optional<HeaderSdoEnt> header = reader.leeHeader();
        if (header.isEmpty()) {
            // Comportamiento actual: mensaje y fin normal con archivos vacíos.
            log.warn("ERROR: ARCHIVO VACIO");
            return;
        }
        HeaderSdoEnt h = header.get();
        if (!"HD".equals(h.tipoReg()) || !h.fecha().equals(fechaProceso)) {
            // En MCP el STOP detiene el programa hasta que el operador copie el archivo correcto.
            throw new HeaderInvalidoException(
                "FECHA EN HEADER ERRONEA = %s FECHA CORRECTA = %s".formatted(h.fecha(), fechaProceso));
        }
    }
}

@Component
@RequiredArgsConstructor
public class RuteoCorresponsalProcessor implements ItemProcessor<SaldoContrato, RuteoSaldo> {

    private final P169Properties props;
    private final ClientesService clientes;          // S016_L422 (B01SXCTE, B38COSMOS, CTAMEDIO)
    private final MapeoAcci mapeo;                   // 200-MUEVE-INFORMACION-SDOS
    private final HostInfo host;                     // CSIID IN SOPORTECOMS

    @Override
    public RuteoSaldo process(SaldoContrato s) {
        boolean citd = props.citdIndicadores().contains(s.indEnvioCitd());
        boolean bne  = s.indEnvioBne() == props.bneIndicador()
                       && props.hostsBne().contains(host.nombreEquipo());
        if (!citd && !bne) return null;              // ni CITD ni BNE: no se escribe

        AcciRecord base = clientes.completa(mapeo.desde(s), s);   // una sola consulta por contrato
        return new RuteoSaldo(citd ? base : null, bne ? base : null);
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class CompletaSaldoS408Processor implements ItemProcessor<AcciRecord, AcciRecord> {

    private final SaldosS408Client s408;             // SALDOSXCTO IN CONL022S408, función 02
    private final RetryTemplate esperaS408;          // 96 = ocupado: WAIT(300) y reintento
    @Value("#{jobParameters['fechaProceso']}") private LocalDate fechaProceso;

    @Override
    public AcciRecord process(AcciRecord r) {
        S408Respuesta resp = esperaS408.execute(ctx -> {
            S408Respuesta x = s408.saldosPorContrato(r.contrato(), fechaProceso);
            if (x.resultado() == 96) throw new S408OcupadoException();
            return x;
        });
        if (resp.resultado() != 0) {
            log.error("ERROR AL CONSULTAR S408 CON CTO. : {} RESULT : {}", r.contrato(), resp.resultado());
            return r;                                // se envía con los saldos del batch
        }
        // Aritmética con signo; el fuente opera sobre magnitudes sin signo (ver riesgo).
        BigDecimal disponible = r.dispValBal().valor().add(resp.disponible());
        AcciRecord.Builder b = r.toBuilder().dispValBal(SignedAmount.of(disponible));
        if (resp.saldo().signum() > 0) {
            BigDecimal actual = r.acctBal().valor().subtract(resp.saldo());
            b.acctBal(SignedAmount.of(actual)).lcyAcctBal(SignedAmount.of(actual))
             .lastTxnDate(Fechas.siete(fechaProceso));
        }
        return b.build();
    }
}

@Bean
RetryTemplate esperaS408() {
    return RetryTemplate.builder()
            .retryOn(S408OcupadoException.class)
            .fixedBackoff(Duration.ofSeconds(300))   // WAIT(300)
            .infiniteRetry()                         // PERFORM ... UNTIL W88-S408-OK
            .build();
}
    /**
     * 310-LLAMA-S408: idéntica a 300 salvo por el manejo de errores.
     *  - 96: espera 300 s una sola vez y NO reintenta; el contrato sale con saldos del batch.
     *  - 99: se ignora sin bitácora.
     * Se mantiene el comportamiento actual detrás de una propiedad.
     */
    private S408Respuesta consultaSiguiente(AcciRecord r) {
        S408Respuesta x = s408.saldosPorContrato(r.contrato(), fechaProceso);
        if (x.resultado() == 96) {
            if (props.reintentarTodos()) {               // p169.s408.reintentar-todos: false
                return esperaS408.execute(ctx -> reconsulta(r));
            }
            esperaFija(Duration.ofSeconds(300));         // WAIT(300) sin nueva consulta
        } else if (x.resultado() != 0 && x.resultado() != 99) {
            log.error("ERROR AL CONSULTAR S408 CON CTO. : {} RESULT : {}", r.contrato(), x.resultado());
        }
        return x;
    }

Riesgos de migración
Signo del disponible perdido

En 300-LLAMA-S408, 310-LLAMA-S408 y sus versiones BNE (líneas 7294, 7354, 7778 y 7849) la condición ACCI-DISP-VAL-BAL-AMT-T < 0 se evalúa sobre un campo PIC 9(15)V99 sin signo, por lo que siempre resulta falsa y el signo del disponible se fija en +. Un disponible en sobregiro llega al corresponsal como positivo, contrario a lo que describe RN-CORE-GL-763.

Aritmética sobre magnitudes

El ADD del disponible de S408 y el COMPUTE del saldo actual (líneas 7261 y 7265) operan sobre la magnitud sin signo del registro. Para saldos deudores el ajuste se aplica en sentido contrario, y un resultado igual a cero recibe signo - porque la condición es > 0.

Reintento solo para el primer contrato

Solo 300-LLAMA-S408 se repite ante el resultado 96. 310-LLAMA-S408, que atiende al resto del archivo, espera 300 segundos y continúa sin repetir la consulta; esos contratos salen sin el complemento de S408.

Archivo de entrada vacío con fin normal

150-007-VALIDA-HEADER y 150-010-LEE-PRIMER-REGISTRO solo imprimen ERROR: ARCHIVO VACIO; el programa genera interfaces vacías, las envía si corre en el CSI 04 y termina con FIN NORMAL DE PROCESO.

Hardcodes

Sucursal 999, divisa 126 para dólares, lista de ocho nombres de equipo para BNE, CSI 04 como único emisor (con el CSI 32 convertido a 04) y títulos de librería por omisión en CHANGE ATTRIBUTE TITLE. Se trasladan a application.yml.
