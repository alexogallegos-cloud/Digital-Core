P144 · Reconciliación B01/B03 y generación de activación masiva "Marca Ordenante" (CORE-DEP)

CORE-DEPProgramaCOBOL

Fuente: P144.cbl (~14497 LOC; PROCEDURE L13872–14497) · Batch nocturno CORE-DEP (Captación LegacyCore, Unisys ClearPath MCP / COBOL85) · BC-06

Convenciones: nombres traducidos (Unisys→legible); [P144 Lnnnn] = origen; (BR: RN-CORE-DEP-...) = regla. Original entre comentario la 1ª vez.

1. Resumen funcional

P144 (PROGRAM-ID: P144, JUNIO/2021) es un programa batch de reconciliación que valida la consistencia del indicador de "marca ordenante" entre dos bases DMSII de captación: B01CONTRATOS (dataset de atributos, sobre CORE-DEPBD07ATRIBUCTA) y B03CONTRATOS (dataset de captación, sobre CORE-DEPBD01CAPTACION). Recorre el universo COMPLETO de contratos de B01 y, para cada contrato cuyo CSI coincide con el CSI local y cuyo indicador de marca ordenante DIFIERE entre B01 y B03, emite un registro de activación masiva (CLAVE-TRANS 0935, "MARCA MASIVA ORDENANTE") en el archivo de salida BIT-ACTBANDERA (BR: RN-CORE-DEP-138). Los contratos locales sin correspondencia en B03 se reportan como huérfanos en el archivo PROBLEMAS (BR: RN-CORE-DEP-141); los contratos cross-CSI ausentes se ignoran en silencio (BR: RN-CORE-DEP-140).

Ambas bases se abren en modo INQUIRY (solo lectura): P144 nunca modifica producción; la sincronización real se delega al procesador aguas abajo que consume BIT-ACTBANDERA (BR: RN-CORE-DEP-148). El programa es read-only + output file. Comparte con P020/P142 la tabla de 8 pares de host de failover cross-CSI e instrumentación de auditoría MAPLI (S038L035) alrededor de cada llamada a librería (BR: RN-CORE-DEP-151, RN-CORE-DEP-152).

2. Datos y archivos

2.1 Archivos secuenciales (FILE-CONTROL / FD) — [P144 L40-70]

  • SELECT BIT-ACTBANDERA ASSIGN TO DISK · FD: BLOCK 45 RECORDS, RECORD 240 CHARS, TITLE = WS-ETIQ-ACTBAND, SECURITYTYPE PUBLIC. Registro: REG-ARCH-SINC-B03 PIC X(240) — archivo de salida con activaciones de marca ordenante (header + detalle + trailer).
  • SELECT F02-PROBLEMAS ASSIGN TO DISK · FD: BLOCK 45 RECORDS, RECORD 80 CHARS, PROTECTION PROTECTED, SAVEFACTOR 99. Registro: F02-REG PIC X(080) — bitácora de problemas/excepciones con marca de tiempo.

2.2 Bases de datos DMSII (DATA-BASE SECTION) — abiertas OPEN INQUIRY

  • CORE-DEPBD01CAPTACION → dataset CORE-DEPB03CONTRATOS (B03) + índice secundario B03SXCTO (acceso por número de contrato) (BR: RN-CORE-DEP-150).
  • CORE-DEPBD07ATRIBUCTA → datasets CORE-DEPB01CONTRATOS (B01, universo a barrer) y CORE-DEPB02CONTROL (B02, fechas de proceso/lote).

2.3 Layout del registro de sincronización B03 — WS-ARCHSINCB03-REG PIC X(240) [P144 L13808]

Redefine en tres vistas (240 bytes):

  • Cabecera (WS-ARCHSINCB03-HDR, TIPREG=01) [L13810]: TIPREG 9(01), NODORI 9(02), FECPRO 9(06), SISCTE 9(12), NUMARC 9(04), DESCTE X(36), filler, FINREG X(01), filler2.
  • Detalle (...-DET, TIPREG=02) [L13833]: TIPO-REG 9(01), NUM-SEC 9(08), SUC 9(04), CAJA 9(02), NUMTRAN 9(08), CLAVE-TRANS 9(04), TIPO-MOV 9(01), TIPMEDACC 9(02), grupo{ SUC-PROM 9(04), CTO 9(12) }, IMPORTE 9(14)V99, MONEDA 9(03), REFERENCIA 9(12), MOV-FORZADO 9(01), grupo C935{ IND-MARORD-A 9(02), FEC-MARORD-A 9(08) }.
  • Trailer (WS-ARCHSINCB03-TRL, TIPREG=09) [L13821]: TRL-TIPREG 9(01), TRL-NUMABO 9(08), TRL-IMPABO 9(16)V99, TRL-NUMCAR 9(08), TRL-IMPCAR 9(16)V99, TRL-NUMNCO 9(08), fillers.

2.4 Variables de control clave (WORKING-STORAGE)

  • WKS-CSIL — CSI local (Centro de Servicio Integral): 10=Valle de México (VDM), 04=Monterrey/ACYP; derivado del hostname [L14000].
  • WKS-CONTRATO-B01 / WKS-CONTRATO-B03 — número de contrato leído de cada base para comparar.
  • WKS-DATO-MATCH (= B01-NUM-DATO(1), indicador marca ordenante en B01) · WKS-DATO-FECACT (= B01-NUM-FECPROACT(1), fecha proceso/actualización).
  • WKS-SUC-PROMOTORA — sucursal promotora derivada del CSI (0432 VDM / 0366 MTY) (BR: RN-CORE-DEP-143).
  • WKS-FIN-B01 (fin de barrido), WKS-CONTADOR (registros de activación escritos), WS-CONT (secuencial detalle), WS-STATUS-BASE (status DMSII).
  • WKS-TSK-FECH (override de fecha vía ATTRIBUTE TASKVALUE), WKS-FEC-BASE/WKS-FEC-PROX/WKS-FEC-LINEA (fechas de proceso), WKS-ES-MENSUAL (flag cierre mensual).
