1. Resumen funcional

P184-INVCPE es un programa batch de generación de reporte para el sistema de captación bancaria CORE-DEP (LegacyCore, Unisys ClearPath MCP/DMSII), versión MTP 25MTP004. Su función es producir el Inventario de Cuentas Productivas Especiales (INVENTACPE) recorriendo los datasets DMSII B37GRUPOCPE (grupos corporativos CPE) y B39CTASCPE (cuentas subordinadas), emitiendo mediante Report Writer una ficha de identificación por grupo corporativo seguida del desglose de sus cuentas activas. El reporte imprime dos niveles jerárquicos: corporativo (B37) → cuentas miembro (B39); al final totaliza grupos y cuentas encontrados. El programa solo ejecuta el reporte si el CSI activo es 10 (B02-NUM-CSI = 10, correspondiente a C.S.I. México / Valle de México); en cualquier otro CSI cierra la base y termina sin generar impresión. Es un documento de control regulatorio exigible ante revisión CNBV del portafolio CPE.

PROCEDIMIENTO Reportar_Grupos():                     // 200-REPORTA-GRUPOS · [P184 L141600]
  // Ejecutado en bucle HASTA FIN-B37-GRUPOS
  // Precondición: B37GRUPOCPE ya posicionado en el grupo actual (por FINDN previo)

  // Descomponer MDA de pago del grupo en sucursal + cuenta
  MOVER cuenta_mda_grupo    A numero_mda             // B37-MDA-PAGO → WKS-MDA-PAG
  // WKS-MDA-PAG se redefine como WKS-MDA-SUCU(4d) + WKS-MDA-CUEN(8d)

  // Línea 1 (blank)
  // Línea 2: B37-GRUPO(col4) · B37-NOMBRE(col16) · B37-CIUDAD(col58)
  //          · B37-COD-POSTAL(col92) · B37-REPRES(col99)
  // Línea 3: WKS-MDA-SUCU(col1) + "/" + WKS-MDA-CUEN(col6) · B37-DOMICILIO(col16)
  //          · B37-TPO-PERS(col59) · B37-OPCION(col65)-B37-RANGO(col68)
  //          · B37-CSI-CTO-PAGO(col74) · SPACES(col78)  [B37-STATUS DESHABILITADO ⚠]
  //          · B37-SUC-CTO-PAGO(col82) + "-" + B37-CTO-PAGO(col87)
  //          · B37-FECH-VIG(col102) · B37-FECH-ULACT(col112)
  // Línea 4 (blank)

  // ⚠ [CAMPO-COMENTADO]: B37-STATUS en columna 078 está comentado con ***
  //    y reemplazado por SPACES — estatus del grupo suprimido en impresión.

  SUMAR 1 A total_grupos                             // WS-TOTGPO

  MOVER numero_grupo        A grupo_activo           // B37-GRUPO → WS-GRUPO (para filtro en B39)

  // Procesar cuentas asociadas a este grupo
  EJECUTAR Buscar_Primera_Cuenta_Grupo()             // 200-10-15-FINDFG-B39-CTAS

PROCEDIMIENTO Reportar_Cuentas():                    // 200-10-20-REPORTA-CUENTAS · [P184 L147300]

  // Precondición: B39CTASCPE posicionado en cuenta actual del grupo
