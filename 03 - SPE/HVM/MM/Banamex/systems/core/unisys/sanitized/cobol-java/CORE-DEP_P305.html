P305 toma la fecha de lote de CORE-DEPB02CONTROL, proyecta un año y treinta días hacia atrás y, en producción o en cierre de mes, exige que B00CTRLPASO indique que la base es salida de P127. Carga en memoria las cifras de B09 por producto, instrumento y moneda. Recorre B03 con bloqueo y elige los contratos con estatus 3 o 4, o migrados de S111 hace más de treinta días, que no estén marcados como clon y no tengan registros en B25; según el producto exige saldos en cero y borra el contrato, sus movimientos B04, el histórico B06 y otras estructuras asociadas, sumando la depuración en la tabla de cifras. Cada contrato borrado se escribe en el archivo DEPURA con header y trailer, que al final se envía con P197 opción I1.

@Bean
@StepScope
FlatFileItemWriter<ContratoDepurado> depuraWriter(P305Properties p,
        @Value("#{jobExecutionContext['csi']}") int csi,
        @Value("#{jobExecutionContext['fechaProceso']}") LocalDate fecha) {
    return new FlatFileItemWriterBuilder<ContratoDepurado>()
            .name("depura")
            .resource(new FileSystemResource(p.archivoDepura()
                    .replace("{csi}", "%02d".formatted(csi))
                    .replace("{aammdd}", fecha.format(DateTimeFormatter.ofPattern("yyMMdd")))))
            .headerCallback(w -> w.write(DepuraLayout.header("0000CORE-DEP", "0000S016")))   // tipo 01
            .lineAggregator(DepuraLayout::detalle)                                          // tipo 2
            .footerCallback(w -> w.write(DepuraLayout.trailer(contador.total())))            // tipo 99
            .build();
}

@Component
@StepScope
@RequiredArgsConstructor
public class CriterioDepuracion implements ItemProcessor<Contrato, Contrato> {

    private final PagosPendientesRepository b25;          // CORE-DEPB25PGOSPENDPE
    @Value("#{jobExecutionContext['fechaMesAnterior']}") private LocalDate hace30Dias;
    @Value("#{jobParameters['modo'] ?: 0}")              private long modo;

    @Override
    public Contrato process(Contrato b03) {
        boolean masivo = modo == 5;
        boolean migradoAntiguo = !masivo && b03.migradoS111() == 1
                && b03.fechaMigra().isBefore(hace30Dias);      // W77-MIGRADO-SINSDO
        boolean candidato = b03.status() == 3 || b03.status() == 4 || migradoAntiguo;
        if (!candidato) return null;

        if (masivo) {
            return b03.marcaClon() == 2 ? b03 : null;          // solo clones
        }
        if (b03.marcaClon() == 2) return null;                 // los clones no se tocan en modo normal
        if (b25.existsByContrato(b03.numContrato())) return null;   // 53000500-VALIDA-B25
        return b03;
    }
}
/** 53100000-BORRO-MOV: qué saldos deben estar en cero según producto e instrumento. */
public enum TipoDepuracion { AHORRO, RESTO, NINGUNA }

public static TipoDepuracion clasifica(Contrato b03) {
    int prd = b03.numProducto(), ins = b03.numInstrum();
    boolean sinActualNiBloqueo = b03.sdoActual().signum() == 0 && b03.sdoProtBloq().signum() == 0;

    if (prd == 500 && ins == 6) {
        return TipoDepuracion.AHORRO;                     // inversión de ahorro: no se revisa saldo
    }
    if (prd == 66 && ins == 90) {
        return sinActualNiBloqueo ? TipoDepuracion.RESTO : TipoDepuracion.NINGUNA;
    }
    return (sinActualNiBloqueo && b03.sdoFinCorte().signum() == 0)
            ? TipoDepuracion.RESTO : TipoDepuracion.NINGUNA;
}

    }

@Service
@RequiredArgsConstructor
public class BorradoContratoService {

    private final ContratoRepository b03;
    private final MovimientoRepository b04;
    private final HistoricoRepository b06;
    private final CifrasDepuracion cifras;
    private final DepuraWriter depura;

    /**
     * 53200000-CHECO-INVAHO. En el fuente cada DELETE es una transacción DMSII propia;
     * aquí se agrupa el contrato y sus dependientes en una sola para que el borrado sea atómico.
     */
    @Transactional
    public void borraAhorro(Contrato c) {
        cifras.suma(c);
        b04.deleteByContrato(c.numContrato());     // 53250000-MOV + 53251000-NEXT: todos los B04
        b06.deleteByContrato(c.numContrato());     // 53260000-HIS
        b03.delete(c);                             // WS-BAN-B03
        depura.escribe(c);                         // 20000500-MOVE-WRITE-DEPURA
    }
}
/** 53410000-DELETE: una bandera por dataset. En Java cada repositorio borra lo suyo. */
private void borra(Set<Estructura> marcadas, Contrato c) {
    for (Estructura e : marcadas) {
        try {
            switch (e) {
                case B03 -> b03.delete(c);
                case B04 -> b04.deleteActual(c);
                case B06 -> b06.deleteActual(c);
                case B12 -> b12.deleteByContrato(c.numContrato());
                case B20 -> b20.deleteByContrato(c.numContrato());
                case B25 -> b25.deleteByContrato(c.numContrato());
                case B26 -> b26.deleteByContrato(c.numContrato());
                case B39 -> b39.deleteByContrato(c.numContrato());
                case B48 -> b48.deleteByContrato(c.numContrato());
                case B49 -> b49.deleteByContrato(c.numContrato());
                case B50 -> b50.deleteByContrato(c.numContrato());
                case B00, B09 -> { /* STORE, no DELETE: se graban al cierre */ }
            }
        } catch (DataAccessException ex) {
            throw new ProcesoAbortadoException("ERROR AL BORRAR " + e, ex);   // DMTERMINATE
        }
    }
}

Riesgos de migración
Borrado no atómico por contrato

Cada DELETE de 53410000-DELETE abre y cierra su propia transacción, y el contrato B03 se borra antes que sus movimientos e histórico. Un DMTERMINATE intermedio deja registros dependientes sin contrato.

Contratos de ahorro sin revisión de saldo

53100000-BORRO-MOV borra la inversión de ahorro 500-6 sin revisar saldos, y un contrato migrado de S111 hace más de treinta días entra como candidato aunque su estatus no sea 3 ni 4.

Reejecución bloqueada

20000400-VAL-PASO pone en cero los indicadores 127 de B00CTRLPASO antes de depurar; una falla posterior impide reejecutar sin corregir la base a mano.

Posible índice fuera de rango

La búsqueda de 53210000-ACUM-DEPU evalúa WS-PRD(31) en la condición UNTIL antes de detenerse.

Hardcodes

Sistemas 0000CORE-DEP y 0000S016 del header, ruta S016/FILE/CORE-DEP, opción I1 de P197, productos 500-6, 66-90 y 66-11, ventanas de 30 y 365 días y el límite de 30 productos. Se trasladan a application.yml.

Pendiente de revisión SME
  • El inventario no trae reglas del brain para P305; ningún segmento cita reglas.
  • Confirmar si B03-MIGR-S111 = 1 implica que el contrato no recibió saldo, como dice el comentario de las líneas 790-794, o solo que fue migrado.
