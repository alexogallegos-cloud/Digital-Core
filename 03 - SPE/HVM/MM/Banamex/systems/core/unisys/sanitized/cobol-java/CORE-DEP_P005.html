Según el TASKVALUE con que se invoca, P005 fija la actividad y el número de copia del monitor MAPLI, valida la versión, enlaza las librerías LOCSUP, CORE-DEPL010CTRL y L040, y ejecuta una sola fase llamando a la librería de control L010; cualquier valor no previsto termina con estado -1. Con el monitor activo registra inicio, avance y fin en el grupo 06 BATCH DIARIO de MAPLI. La rama de depuración toma la fecha de línea de CORE-DEPB02CONTROL, proyecta una fecha límite 90 días hábiles atrás, recorre el catálogo CORE-DEPB10PDEPURA validando el patrón del nombre de cada archivo y su fecha de última depuración, borra del catálogo los registros marcados para eliminar y emite comandos REMOVE a través de WFL, dejando un reporte que se envía por INTELAR.

@Component

public class MonitorBatchListener implements JobExecutionListener {

    private final MonitorMapliClient mapli;   // S038L035 / 70000950-INI-PGM-MAPLI
    private final MonitorProperties props;    // grupo: 6, nombre: "BATCH DIARIO"

    @Override
    public void beforeJob(JobExecution job) {
        var fase = fase(job);
        if (!fase.monitor) return;                                   // W77-SI-MONITOR
        mapli.iniciaPrograma(props.grupo(), props.nombre(), fase.copiaMapli, fase.inicioGrupo);
        mapli.iniciaActividad(1, "PROCESO UNICO ");
    }

    @Override
    public void afterJob(JobExecution job) {
        if (!fase(job).monitor) return;
        mapli.registraAvance(1, job.getStepExecutions().stream()
                .mapToLong(StepExecution::getWriteCount).sum());      // 70000950-ACT-REGPROC
        mapli.finActividad(1);
        mapli.finPrograma();
    }
}

@Bean
Job despachadorCaptacion(JobRepository repo, Step validaVersion, DespachadorFasesDecider decider,
                         Map<String, Step> fases, MonitorBatchListener monitor) {
    var flow = new FlowBuilder<SimpleFlow>("fases").start(decider);
    fases.forEach((nombre, paso) -> flow.from(decider).on(nombre).to(paso));
    return new JobBuilder("CORE-DEPP005", repo)
            .listener(monitor)
            .start(validaVersion)                 // 20000100-CHECAME-VERSION
            .next(flow.build()).end()
            .build();

final class ErroresL010 {
    private static final List<String> CAUSAS = cargaCatalogo();   // X(40) OCCURS 28

    static Optional<String> causa(int resultado) {
        int i = resultado - 10;                      // se calcula ANTES de validar el rango
        return (i >= 1 && i <= CAUSAS.size()) ? Optional.of(CAUSAS.get(i - 1)) : Optional.empty();
    }

@Component
@RequiredArgsConstructor
public class FechasDepuracionTasklet implements Tasklet {

    private final ControlCaptacionRepository control;   // CORE-DEPB02CONTROL, OPEN INQUIRY
    private final CalendarioBancario calendario;         // 90021000-PROYECTA-FECHA-HAB2K
    private final DepuracionProperties props;            // dias-habiles-retencion: 90

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        LocalDate proceso = control.findFechaLinea()
                .orElseThrow(() -> new ProcesoAbortadoException(
                        "Sin registro CORE-DEPB02CONTROL: no se depura con la fecha del sistema"));
        LocalDate limite = calendario.sumaHabiles(proceso, -props.diasHabilesRetencion());
        var ec = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        ec.put("fechaProceso", proceso);
        ec.put("fechaLimite", limite);
        return RepeatStatus.FINISHED;
    }
}
public enum MarcaDepuracion { CONSERVAR, DEPURAR, ELIMINAR_REGISTRO }   // WS-REG-DEPURABLE 0, 1, 2

@Component
@RequiredArgsConstructor
public class ElegibilidadDepuracion {

    private final DepuracionProperties props;   // ides-validos: [1, 3]
    private final PatronNombreArchivo patron;

    MarcaDepuracion evalua(ArchivoDepuracion r, LocalDate fechaProceso, BitacoraDepuracion bitacora) {
        if (r.fechaUltimaDepuracion() != null
                && !r.fechaUltimaDepuracion().isBefore(fechaProceso)) {
            return MarcaDepuracion.CONSERVAR;                 // ya se procesó hoy
        }
        if (!props.idesValidos().contains(r.ideDepuracion())) {
            bitacora.problema(4, r.nombre());                 // ID no válido para depuración
            return MarcaDepuracion.CONSERVAR;
        }
        var marca = patron.valida(r.nombre());                // 40000-VALIDA-FECHA-SECUENCIAL
        if (marca == MarcaDepuracion.DEPURAR && r.fechaUltimaDepuracion() == null) {
            marca = patron.validaNombre(r.nombre());          // 90000-VALIDA-NOMBREDEP
        }
        if (marca != MarcaDepuracion.DEPURAR) {
            bitacora.problema(10, r.nombre());
        }
        return marca;
    }
}

/** El nombre es un patrón: '#' fecha de 6 u 8, '?' secuencial de 2 a 6, '%' copia de 2. */
@Component
class PatronNombreArchivo {
    private static final Pattern VALIDO = Pattern.compile(
            "^[^#?%]*(#{6}|#{8})?[^#?%]*(\\?{2,6})?[^#?%]*(%{2})?[^#?%]*$");
    MarcaDepuracion valida(String nombre) {
        return VALIDO.matcher(nombre.strip()).matches()
                ? MarcaDepuracion.DEPURAR : MarcaDepuracion.ELIMINAR_REGISTRO;
    }
}
@Service

public class CatalogoDepuracionService {

    private final ArchivoDepuracionRepository repo;   // CORE-DEPB10PDEPURA en CORE-DEPBD04TARJETAS
    private final BitacoraDepuracion bitacora;

    /** 50000-DEPURA-REGISTRO: LOCK y DELETE dentro de una transacción; el error se reporta y se sigue. */
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void eliminaRegistro(ArchivoDepuracionId id, String nombre) {
        try {
            repo.findByIdForUpdate(id).ifPresent(repo::delete);   // LOCK + DELETE
        } catch (DataAccessException e) {
            bitacora.problema(1, e.getMessage());
            bitacora.problema(7, nombre);
            throw e;   // revierte solo esta transacción; el recorrido continúa
        }
    }
}

    private final AlmacenArchivos almacen;
    private final ReporteDepurados reporte;    // FILE-DEPTEM y FILE-DEPURADOS

    @Override
    public void write(Chunk<? extends ArchivoAEliminar> chunk) {   // chunk = lote-maximo
        var nombres = new ArrayList<String>();
        for (var a : chunk) {
            if (almacen.enUso(a.nombre())) {          // WS-ABORT-DEP: no se borra
                reporte.noDepurado(a.nombre());
                continue;
            }
            nombres.add(a.nombre());                  // sin truncar: el nombre completo de 75
        }
        almacen.elimina(nombres);                     // CALL SYSTEM WFL USING WFL-DEPURA
        nombres.forEach(reporte::depurado);           // 90000-ESCRIBE-DEPURADOSTEM
    }
}

Riesgos de migración
Depuración con fecha del sistema mal formada

Sin registro en CORE-DEPB02CONTROL se usa ACCEPT FROM DATE (línea 1082) sobre un campo de 8 dígitos; la fecha resultante no es AAAAMMDD y los criterios de retención y la fecha límite se calculan sobre ella.

Índice de error evaluado antes de calcularse

6000-DESPLIEGA-ERROR (líneas 799-802) valida WS-IND-ERROR antes de asignarlo, por lo que la causa mostrada puede ser de otra llamada o indexar fuera de la tabla de 28 textos.

Borrado de archivos sin confirmar resultado

Los CALL SYSTEM WFL de las líneas 1534, 1759 y 1851 no revisan resultado; el reporte de depurados puede listar archivos que siguen en disco.

Esperas fijas

20000-PROCESO-VALIDACIONPDIR espera 600 segundos fijos (línea 1199) a que un WFL externo genere los archivos PDIR, sin verificar que hayan terminado.

Hardcodes

Grupo MAPLI 06 y nombre BATCH DIARIO, tabla de actividades por librería, 90 días hábiles de retención, identificadores de depuración 1 y 3, lote de 750 y rutas CORE-DEP/FILE/DEPTEM, (CORE-DEP)CORE-DEP/FILE/INTS/50004S01 y CORE-DEP/FILE/PDIR están compilados.
