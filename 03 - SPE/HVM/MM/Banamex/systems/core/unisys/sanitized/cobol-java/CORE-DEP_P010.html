CORE-DEP · P010 a Java 21 Spring Boot

P010 recibe cada transacción por COMS, decide de dónde vino y a qué CSI pertenece, valida la seguridad del operador con la librería S041 y, según el resultado, la procesa localmente o la reenvía a otro CORE-DEP. Las transacciones locales pasan por validaciones de recepción del contrato (migración, cuentas móviles, restricciones) y se despachan por tipo de movimiento a abonos, cargos, eliminaciones o no contables. El operador ajusta el comportamiento en caliente con interrupciones HI identificadas por TASKVALUE. Al final responde al diálogo, graba la bitácora y persiste en las bases DMSII ORIGINAL, CORE-DEPBD02AUXILIAR y CORE-DEPBD03MSGAAPLI.

public enum ModoProceso {

    private final int codigo;
    ModoProceso(int codigo) { this.codigo = codigo; }

    public static ModoProceso of(int codigo) {
        return Arrays.stream(values()).filter(m -> m.codigo == codigo).findFirst()
                .orElseThrow(() -> new IllegalStateException("WS-NUMERO-PROCESO fuera de 0..2: " + codigo));
    }
}

@Component
@RequiredArgsConstructor
public class TransaccionRouter {

    private final ValidaRecepcion valida;           // 51080500-VALIDA-RECIBE-MOVTOS
    private final Abonos abonos; private final Cargos cargos;
    private final Eliminaciones eliminaciones; private final NoContables noContables;
    private final CuentaMovil cuentaMovil;
    private final GatewayProperties props;

    /** 51000000-PROCESA-TRANSACCION. */
    public void procesa(Transaccion tx) {
        if (tx.compensacionObanco()) return;          // WS-88-COMPENSACION-OBANC: NEXT SENTENCE
        valida.recepcion(tx);
        if (tx.contrato().pimPerfilesDolares()) perfilesDolares.aplica(tx);
        if (!tx.contrato().productoSoriana()) observacion.checa(tx);   // 00000000-CHECA-CTA-ENOBS
        if (tx.conError()) return;

        if (tx.cuentaMovil()) {
            if (tx.tipoMov() == TipoMov.ABONO || tx.tipoMov() == TipoMov.CARGO) cuentaMovil.cargoAbono(tx);
            else cuentaMovil.eliminacion(tx);
            return;
        }
        switch (tx.tipoMov()) {                         // WS17-88-TIPMOV-*
            case ABONO   -> abonos.procesa(tx);
            case ELIM    -> eliminaciones.procesa(tx);
            case CARGO   -> cargos.procesa(tx);
            case NOCONT  -> { if (tx.clave() != props.claveNoContableExcluida()) noContables.procesa(tx); }  // 0544
        }
    }
    private final PerfilesDolares perfilesDolares; private final CuentaEnObservacion observacion;
}

            if (contable || tx.chequeSalvoBuenCobro()) return Optional.of(QuienVa.FORANEO_APLI);
            if (tx.ica() && tx.sistemaOrigen() == 16 && tx.noContable()) return rechazo(tx);
            return tx.noContable() ? Optional.of(QuienVa.NOCONT_APLI) : rechazo(tx);
        }
        if (local) {
            if (tx.soloValidaCsi()) return Optional.empty();   // NEXT SENTENCE: no marca proceso
            tx.marcaProcesaLocal(); return Optional.of(QuienVa.LOCAL_TERM);
        }
        if (contable) return Optional.of(QuienVa.FORANEO_TERM);
        return tx.noContableForaneoTerminal() ? Optional.of(QuienVa.NOCONT_FOR_TERM) : rechazo(tx);
    }

    private static Optional<QuienVa> rechazo(Transaccion tx) {
        tx.rechaza(250);   // TRANSACCION NO PERMITIDA PARA DIALOGO FORANEO
        return Optional.empty();
    }
}

Riesgos de migración
Semántica de errores S041 distinta a la del brain

La tabla WS-TABLA-ERRORES (líneas 956-983 y 1602-1603) da textos que no corresponden con los que RN-CORE-DEP-204 asigna: -2 lleva a 0154 NIVEL INSUFICIENTE DE FACULTADES, -4 a 0477 firma mancomunada, -6 a 0157 problemas con la librería, -7 a 0155 terminal no firmada y -9 a 0166 seguridad levantándose.

Validación Teletón 2014 activa por omisión

WS-88-VALIDA-TELETON es VALUE 0 (línea 4018), así que el bloque de las líneas 18677-18691 se evalúa en cada transacción con un contrato y un rango de fechas de 2014 fijos. No tiene efecto hoy, pero es lógica muerta en el camino crítico.

Stand-in de migración comentado

En las líneas 18729-18748 solo el MOVE 0847 está activo: todo contrato con WS03-MIGR-S111 igual a 1 o 4 rechaza cualquier movimiento, sin las excepciones que el código comentado preveía.

Rama HI 1016 duplicada

El valor 1016 se evalúa dos veces en la cadena de interrupciones (líneas 5593 y 5599); la segunda rama es inalcanzable.

Tipo de movimiento sin rama

En 51000000-PROCESA-TRANSACCION una clave que no sea abono, eliminación, cargo ni no contable no produce error; la transacción sigue hacia la respuesta.

Hardcodes

Contrato 9014946817, sistemas origen 0015, 0501, 0618 y 0016, claves 4009, 2442 y 0544 y la sucursal 511 de las interrupciones 1017 y 1018 están compilados. Se trasladan a application.yml.
