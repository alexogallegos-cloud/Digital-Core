@Component
@RequiredArgsConstructor
public class GeneraReorganizadorTasklet implements Tasklet {

    private final ObjetosReorg objetos;
    private final ReorgPlanGenerator generador;      // sustituto de *SYSTEM/BUILDREORG
    private final ReorgCaptacionProperties p;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        // En el WFL se borran S1 y S2 ANTES de generar; si la generación falla,
        // el P691 vigente ya no existe. Aquí se genera primero y se publica al final.
        ReorgPlan plan = generador.genera(objetos.generado(), p.estructuras());   // DATA CARD
        ctx.getStepContext().getStepExecution().getJobExecution()
           .getExecutionContext().put("planReorg", plan);
        return RepeatStatus.FINISHED;
    }
}

/** En la base destino, GENERATE ... ORDER BY equivale a reescribir la tabla en el orden del índice. */
@Component
class ReorgPlanGenerator {
    ReorgPlan genera(String id, List<EstructuraReorg> estructuras) {
        var pasos = estructuras.stream()
                .map(e -> new PasoReorg(e.nombre(),
                        // PostgreSQL: CLUSTER core-dep_contratos USING b03sxcto; o pg_repack --order-by
                        "CLUSTER %s USING %s".formatted(Tablas.de(e.nombre()), Indices.de(e.ordenarPor()))))
                .toList();
        return new ReorgPlan(id, pasos);
    }
}
/** GLOBAL USEREORGDB + REORGDBTITLE + AUTOSWAP=TRUE: reorganizar en sombra y conmutar. */
@Component
@RequiredArgsConstructor
class EstrategiaSwap {

    private final JdbcTemplate jdbc;
    private final ReorgCaptacionProperties p;

    void conmuta(PasoReorg paso) {
        if (!p.autoswap()) {
            throw new IllegalStateException("Swap manual requerido para " + paso.tabla());
        }
        // Copia reorganizada en el esquema de trabajo (familia REORG -> esquema core-dep_reorg);
        // el intercambio es un rename atómico dentro de una transacción.
        jdbc.execute("""
            BEGIN;
              ALTER TABLE core-dep.%1$s RENAME TO %1$s_old;
              ALTER TABLE core-dep_reorg.%1$s SET SCHEMA core-dep;
            COMMIT;
            """.formatted(paso.tabla()));
    }
}

PublicaReorganizadorTasklet.javaFlow con transición condicional · sondeo con límiteJava 21
@Component
@RequiredArgsConstructor
public class PublicaReorganizadorTasklet implements Tasklet {

    private final ObjetosReorg objetos;
    private final ArtifactRepository artefactos;
    private final ReorgCaptacionProperties p;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) throws InterruptedException {
        Instant limite = Instant.now().plus(p.tiempoMaximo());       // el WFL no tiene límite
        while (!objetos.existePublicado()) {                         // UNTIL GARBAGE IS RESIDENT
            if (Instant.now().isAfter(limite)) {
                throw new IllegalStateException("No se publicó " + objetos.publicado());
            }
            Thread.sleep(p.intervaloSondeo().toMillis());            // WAIT(15)
            if (objetos.existeGenerado()) {
                artefactos.renombra(objetos.generado(), objetos.publicado());   // CHANGE #S1 TO #S2
            }
        }
        return RepeatStatus.FINISHED;
    }
}

Riesgos de migración
Borrado del P691 antes de generar el nuevo

La línea 20 elimina el objeto publicado antes de correr BUILDREORG. Una generación fallida deja la base de captación sin programa de reorganización.

Falla de compilación sin aviso

El IF T1 IS COMPILEDOK de la línea 41 no tiene ELSE; el job termina normalmente aunque BUILDREORG haya fallado.

Ciclo de espera sin límite

El DO ... UNTIL GARBAGE IS RESIDENT de las líneas 42-48 no tiene contador ni tiempo máximo.

Cambio automático embebido

AUTOSWAP=TRUE (línea 39) queda dentro del P691 generado, que sustituye las estructuras de producción al ejecutarse.

Todo literal

Base, versiones, familias CAPTACION y REORG y la lista de estructuras están en el fuente; el job no recibe parámetros.
