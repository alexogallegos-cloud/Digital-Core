P103 · Control de Fechas y Período Corporativo (CORE-GL)

CORE-GLProgramaCOBOL

Fuente: COBOL_P103.cbl (562 LOC) · Primer y último paso del lote batch CORE-GL · BC-14

Convenciones: nombres traducidos (Unisys→legible); [P103 Lnnnn] = secuencia fuente; (BR: RN-CORE-GL-nnn) = regla de negocio.

1. Resumen funcional

P103 es el gestor de fechas y períodos del lote batch CORE-GL (Administración de Saldos y Movimientos, LegacyCore). Opera en modo dual controlado por el parámetro de entrada W77-PARAMETRO: en modo CONSULTA (parámetro=01), lee la fecha de proceso activa del archivo corporativo CORE-GL/FILE/CONTROL/CORP y la publica en el directorio de tareas Unisys (CHANGE ATTRIBUTE VALUE OF MYSELF) para que los programas subsecuentes del lote conozcan la fecha contable del día. En modo PROYECTA (parámetro=02), calcula la próxima fecha hábil bancaria invocando el servicio externo THECALENDAR de la librería LOCSUP (sistema S006), genera un reporte impreso con el estatus de procesamiento de los 5 sistemas dependientes (S084, S087, S408, CORE-DEP, S701), y actualiza el archivo corporativo con la nueva fecha de proceso. P103 es invocado dos veces desde WFL_LOTE: al inicio del lote (modo 01) y al cierre (modo 02). Cualquier error en THECALENDAR o en la escritura del archivo corporativo causa aborto del proceso (SET MYSELF(STATUS) TO -1).

2.2 Layouts de registro clave (A01-CONTROL, PIC X(90))

  WKS-HD-CSI      PIC 9(02)   — Identificador CSI corporativo

  WKS-DET-SIST    PIC 9(03)   — Número del sistema (S084=084, …, S701=701; 999=sentinel fin)
  WKS-DET-FECPRO  PIC 9(08)   — Fecha de proceso del sistema (AAAAMMDD)

2.4 Datasets DMSII

P103 no accede a bases DMSII directamente. Opera únicamente sobre el archivo secuencial CORP y genera salidas a impresora. La fecha que proyecta en CHANGE ATTRIBUTE VALUE OF MYSELF es consumida por otros programas del lote (L001, P021, P120, etc.) que sí acceden a BD99CONTROL y BD02ADSALDO.

PROCEDIMIENTO Inicializar_Display():            // 000050-DISPLAY · [P103 L331]
> Este procedimiento es invocado tanto desde `000050-CONSULTA` como desde `000080-PROYECTA`.
> Su cuerpo fue originado por COPY `CORE-GL/FORMATO/PROCEDURE/DISPLAY` (expandido en L334-408).

```
PROCEDIMIENTO Inicializar_Display():            // 000050-DISPLAY · [P103 L331]

  // Configurar librería GENERALSUPPORT para obtener fecha/hora de la máquina
  CAMBIAR ATRIBUTO LIBACCESS de "GENERALSUPPORT" A BYFUNCTION

  // Obtener fecha y hora actuales del sistema Unisys
  LLAMAR "CURRENT_DATE OF GENERALSUPPORT"
    USANDO fecha_hora_array  // WKS-DATE-ARRAY2 — PIC X(21), fecha+hora máquina

  // Distribuir componentes de fecha/hora a campos de encabezado
  MOVER fecha_hora_array  A  fecha_hora_completa   // WKS-FECHA-HORA2
  MOVER componente_fecha_6d  A  fecha_backup2      // WKS-FEMAQ6D2 → WKS-TR-FECHA-BACKUP2
  // Fecha 6 dígitos se usa en el nombre dinámico del backup V00-REPORTE2

  MOVER fecha_8d_maquina  A  fecha_proc_encab2     // WKS-FEMAQ8D2 → WLI-RB-E2-FECHA-PROC2
  MOVER hora_hh  A  hora_titulo_hh                 // WKS-HMS-MAQ2-HH → WLI-RB-E2-HORA-TIT2-HH
  MOVER hora_mm  A  hora_titulo_mm                 // WKS-HMS-MAQ2-MM → WLI-RB-E2-HORA-TIT2-MM
  MOVER hora_ss  A  hora_titulo_ss                 // WKS-HMS-MAQ2-SS → WLI-RB-E2-HORA-TIT2-SS

PROCEDIMIENTO Control_Salto_Hoja():            // 000-050-CHECA-SALTO-HOJA2 · [P103 L376]
> Controla el salto de página automático en el archivo de log V00-REPORTE2.
> Es llamado desde `Inicializar_Display` y desde `Imprimir_Mensaje`.

```
PROCEDIMIENTO Control_Salto_Hoja():            // 000-050-CHECA-SALTO-HOJA2 · [P103 L376]

  // Ajustar año del encabezado para visualización 4 dígitos (siglo)
  MOVER  fecha_inf_encab2  A  fecha_inf_wks2    // WLI-RB-E1-FECHA-INF2 → WKS-RB-E1-FECHA-INF2
  SI  anio_2d_encab < 50                        // WKS-RB-E1-FECHA-INF2-A2 < 50
      MOVER 20  A  siglo_encab                  // WKS-RB-E1-FECHA-INF2-A1 = 20 (año >= 2000)
  SINO
      MOVER 19  A  siglo_encab                  // WKS-RB-E1-FECHA-INF2-A1 = 19 (año <= 1999)
  // ⚠ Pivote de siglo hardcoded en 50: años 00-49 → 2000-2049; 50-99 → 1950-1999
  // ⚠ [HARDCODE-SOSPECHOSO] Regla de siglo sin configuración externa

  // Formatear fecha completa en encabezado 1
  MOVER siglo_encab         A  WLI-RB-E1-ANIO41
  MOVER anio_2d_encab       A  WLI-RB-E1-ANIO42
  MOVER "/"                 A  separador1        // WKS-SLASH1
  MOVER mes_encab2          A  WLI-RB-E1-MES
  MOVER "/"                 A  separador2        // WKS-SLASH2
  MOVER dia_encab2          A  WLI-RB-E1-DIA

4.5 · Modo_Consulta

PROCEDIMIENTO Modo_Consulta():            // 000050-CONSULTA · [P103 L410]
> Modo de operación 1 (W77-PARAMETRO = 01).
> Lee la fecha de proceso actual del archivo CORP y la publica en el directorio de tareas Unisys.
> Usado por los programas del lote al inicio para conocer la FECPRO activa.

```
PROCEDIMIENTO Modo_Consulta():            // 000050-CONSULTA · [P103 L410]

  // --- Leer archivo corporativo de control ---
  ABRIR ENTRADA A01-CONTROL                     // archivo secuencial CORE-GL/FILE/CONTROL/CORP
  LEER A01-CONTROL  HACIA  registro_header      // WKS-REG-HD-CONTROL: CSI(2) + FECPRO(8) + FILLER(80)
  // Solo se lee el primer registro (header) — no se procesan registros de detalle en modo CONSULTA

  // --- Distribuir campos del header ---
  MOVER  csi_header         A  csi_reporte2     // WKS-HD-CSI → WKS-TR-CSI2 (encabezado del log)
  MOVER  fecha_proc_header  A  fecha_proceso     // WKS-HD-FECPRO → W77-FECHA-PROCESO (var de trabajo)
                               fecha_inf_encab2  // WKS-HD-FECPRO → WLI-RB-E1-FECHA-INF2 (encabezado log)

  // --- Inicializar identificadores en estructuras de mensaje ---
  MOVER "CORE-GL"  A  sistema_lj                  // SISTEMA-LJ (mensaje LJ)
                   sistema_back2               // WKS-SIS-BACK2 (título backup)
                   sistema_encab3              // WLI-RB-E3-SISTEMA2 (encabezado log 2)
  MOVER "P103"  A  paso_lj                     // PASO-LJ (mensaje LJ)
                   paso_back2                  // WKS-PASO-BACK2 (título backup)
                   paso_encab1                 // WLI-RB-E1-PASO (encabezado log 1)
  MOVER "DIARIO"  A  tipo_proceso2             // WLI-RB-E2-TIPO-PROC2 (encabezado log 2)

  // --- Abrir log de mensajes y emitir mensaje de inicio ---
  EJECUTAR Inicializar_Display()               // 000050-DISPLAY: obtiene fecha/hora, abre V00-REPORTE2

  // Preparar y emitir mensaje de inicio de consulta
  MOVER "001"     A  mtp_lj                    // MTP-LJ = módulo/paso 001
  LIMPIAR  linea_encab52, texto_lj             // WLI-ENCAB-52, TEXTO-LJ = SPACES
  MOVER "I"       A  tipo_lj, tipo_lj_display  // TIPO-LJ = "I" (Informativo); WLI-TIPO-LJ = "I"
  MOVER 020101    A  codigo_lj                 // CODIGO-LJ = 020101 ⚠ [HARDCODE]
  CONCATENAR "INICIO PROCESO PARA CONSULTA DE FECHA DE PROCESO : "
             + fecha_proceso                   // W77-FECHA-PROCESO
    DELIMITADO POR TAMAÑO  HACIA  texto_lj     // STRING INTO TEXTO-LJ
  MOVER texto_lj  A  texto_lj_display          // TEXTO-LJ → WLI-TEXTO-LJ
  EJECUTAR Imprimir_Mensaje()                  // 000-030-IMPRIME-MENSAJE

  // NOTA: la llamada "LJ IN LIB-DISP" está comentada en el fuente (L440)
  // ⚠ [CÓDIGO MUERTO] CALL "LJ IN LIB-DISP" está comentado — el log LJ no se envía en este programa

  // --- Publicar fecha de proceso en el atributo del proceso Unisys ---
  MOVER  fecha_proc_header  A  fecha_8d         // WKS-HD-FECPRO → WKS-FECHA8D
  CAMBIAR ATRIBUTO VALOR DE MYSELF  A  componente_6d  // WKS-FEC-6D (6 dígitos: AAMMDD)
  // Este mecanismo Unisys publica la FECPRO en el directorio de tareas para
  // que otros programas del lote (L001, P021, P120, etc.) la lean sin acceder al archivo CORP.
  // En el target Java: equivale a escribir en Redis/BD-config/variable compartida.

  // --- Cerrar archivo con persistencia garantizada ---
  CERRAR A01-CONTROL CON SAVE               // Unisys garantiza flush a disco antes de continuar

  « [P103 L410-444] · BR: RN-CORE-GL-201, RN-CORE-GL-202 »
```

4.6 · Modo_Proyecta

PROCEDIMIENTO Modo_Proyecta():            // 000080-PROYECTA · [P103 L446]
> Modo de operación 2 (W77-PARAMETRO = 02).
> Calcula la próxima fecha hábil bancaria, genera el reporte de estatus de sistemas,
> y actualiza el archivo corporativo con la nueva fecha de proceso.

```
PROCEDIMIENTO Modo_Proyecta():            // 000080-PROYECTA · [P103 L446]

  // ===== BLOQUE A: LECTURA DEL ARCHIVO CORPORATIVO Y PREPARACIÓN =====

  ABRIR ENTRADA A01-CONTROL
  LEER A01-CONTROL  HACIA  registro_header   // WKS-REG-HD-CONTROL: CSI(2) + FECPRO(8) + FILLER(80)

  // Distribuir campos del header
  MOVER  csi_header         A  csi_reporte2  // WKS-HD-CSI → WKS-TR-CSI2
  MOVER  fecha_proc_header  A  fecha_proceso // WKS-HD-FECPRO → W77-FECHA-PROCESO
                               fecha_inf_encab2  // → WLI-RB-E1-FECHA-INF2

  // Inicializar identificadores de sistema y paso
  MOVER "CORE-GL"  A  sistema_lj               // SISTEMA-LJ, WKS-SIS-BACK2, WLI-RB-E3-SISTEMA2
                   sistema_back2
                   sistema_encab3
  MOVER "P103"  A  paso_lj                  // PASO-LJ, WKS-PASO-BACK2, WLI-RB-E1-PASO
                   paso_back2
                   paso_encab1
  MOVER "DIARIO"  A  tipo_proceso2          // WLI-RB-E2-TIPO-PROC2

  // Abrir log de mensajes y emitir mensaje de inicio de proyección
  EJECUTAR Inicializar_Display()            // 000050-DISPLAY

  MOVER "001"     A  mtp_lj
  LIMPIAR  linea_encab52, texto_lj
  MOVER "I"       A  tipo_lj, tipo_lj_display
  MOVER 020101    A  codigo_lj             // ⚠ [HARDCODE] código de mensaje inicio
  CONCATENAR "INICIO PROCESO PARA PROYECCION DE FECHAS FECHA: "
             + fecha_proceso
    DELIMITADO POR TAMAÑO  HACIA  texto_lj
  MOVER texto_lj  A  texto_lj_display
  EJECUTAR Imprimir_Mensaje()              // 000-030-IMPRIME-MENSAJE
  // NOTA: CALL "LJ IN LIB-DISP" comentado en L476 — log LJ no se envía aquí

  « [P103 L446-477] »

  // ===== BLOQUE B: CÁLCULO DE PRÓXIMA FECHA HÁBIL (THECALENDAR) =====

  MOVER  fecha_proc_header  A  fecha_entrada_cal, fecha_backup  // WKS-HD-FECPRO → WKS-FECHA1, WKS-FECBACK
  MOVER 12              A  formato_calendario   // W77-FORMATO = 12 ⚠ [HARDCODE] (formato AAAAMMDD)
  MOVER 13              A  funcion_calendario   // W77-FUNCION = 13 ⚠ [HARDCODE] (función: +1 día hábil)
  MOVER "00000001"      A  incremento_cal       // WKS-FECHA2 = "00000001" ⚠ [HARDCODE] (delta +1)

  // Invocar servicio de calendario bancario del sistema S006
  LLAMAR "THECALENDAR IN LOCSUP"
    USANDO  funcion_calendario,   // W77-FUNCION: entrada=13, salida=0 si OK / >0 si error
            fecha_entrada_cal,    // WKS-FECHA1: entrada=FECPRO actual, salida=próxima fecha hábil
            incremento_cal,       // WKS-FECHA2: delta de días
            formato_calendario    // W77-FORMATO: formato de fecha (12=AAAAMMDD)
  // THECALENDAR calcula la próxima fecha hábil bancaria mexicana saltando fines de semana y feriados.
  // El resultado se devuelve en WKS-FECHA1 (entrada/salida). W77-FUNCION pasa a >0 si hubo error.

  SI  funcion_calendario > 0   // W77-FUNCION > 0 → error en THECALENDAR

4.7 · Verificar_Status_Sistema

PROCEDIMIENTO Verificar_Status_Sistema():            // 000100-CHECA-STATUS · [P103 L547]
> Itera sobre los registros de detalle del archivo CORP para verificar si cada
> sistema dependiente procesó correctamente el día. Es invocado en loop desde
> `Modo_Proyecta()` hasta que `flag_fin = 1`.

```

  LEER A01-CONTROL  HACIA  registro_detalle    // WKS-REG-DET-CONTROL: SIST(3) + FECPRO(8)

  SI  numero_sistema = 999   // WKS-DET-SIST == 999
      MOVER 1  A  flag_fin   // W77-FIN = 1 — terminar el loop

      // El archivo CORP debe contener 999 después del último sistema activo.
      // Si se omite por error, el loop termina solo al EOF — puede incluir basura.
  SINO
      // Preparar línea del reporte para este sistema
      MOVER  numero_sistema    A  sistema_reporte     // WKS-DET-SIST → WLI-SIS-NUM (PIC X(03))
      MOVER  fecha_proc_sist   A  fecha_sistema_rep   // WKS-DET-FECPRO → WLI-SIS-FEC (PIC 9999/99/99)

          // ⚠ Texto hardcoded con espacios de relleno para justificar a 30 caracteres
      SINO
          MOVER "NO HA SIDO PROCESADO DESDE   "  A  mensaje_sistema  // WLI-SIS-MSG (30 chars)
