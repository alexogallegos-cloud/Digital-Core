Recibe en un buffer empacado el sistema que llama, el tipo de llave, el tipo y número de medio de acceso, y opcionalmente producto e instrumento. Valida la entrada, busca el medio en CORE-DEPB12PCLONNING con una llave que depende del tipo de medio y, si lo encuentra, devuelve sucursal, producto, instrumento, moneda, centro de cómputo, cliente, estatus y fecha de alta. Para el sistema 127 rechaza los medios con estatus 1. Devuelve un código numérico de resultado entre 0 y 10.

/** VALIDA_ENTRADA: el orden de las validaciones define qué código ve el llamador. */
private Optional<CodigoClonacion> validaEntrada(ConsultaClonacion in) {
    if (in.tipoMedio() != 0 && in.tipoMedio() != 1) {
        return Optional.of(CodigoClonacion.TIPO_MEDIO_INVALIDO);                 // 3
    }
    if (new BigInteger(in.medioAcceso()).signum() <= 0) {
        return Optional.of(CodigoClonacion.MEDIO_EN_CERO);                       // 4
    }
    if (in.tipoMedio() == 0) {                                                   // la llave incluye producto
        if (in.producto() <= 0)    return Optional.of(CodigoClonacion.PRODUCTO_EN_CERO);     // 5
        if (in.instrumento() <= 0) return Optional.of(CodigoClonacion.INSTRUMENTO_EN_CERO);  // 6
    }
    return Optional.empty();
}
public interface ClonacionRepository extends Repository<MedioClonadoEntity, Long> {

    /** FIND B12PCSXMDACTO con tipo de medio 0: medio + producto + instrumento. */
    Optional<MedioClonadoEntity> findFirstByMedAccesoAndContCuentAndProductoAndInstrumento(
            int medAcceso, String contCuent, int producto, int instrumento);

    /** FIND B12PCSXMDACTO con tipo de medio 1: solo el medio. */
    Optional<MedioClonadoEntity> findFirstByMedAccesoAndContCuent(int medAcceso, String contCuent);
}

/** BUSCA_B12. */
@Transactional(readOnly = true)                 // OPEN INQUIRY
Either<CodigoClonacion, MedioClonadoEntity> buscaB12(ConsultaClonacion in) {
    try {
        Optional<MedioClonadoEntity> r = (in.tipoMedio() == 0)
                ? b12p.findFirstByMedAccesoAndContCuentAndProductoAndInstrumento(
                        0, in.medioAcceso(), in.producto(), in.instrumento())
                : b12p.findFirstByMedAccesoAndContCuent(in.tipoMedio(), in.medioAcceso());
        return r.<Either<CodigoClonacion, MedioClonadoEntity>>map(Either::right)
                .orElse(Either.left(CodigoClonacion.NO_EXISTE));                // NOTFOUND -> 1
    } catch (DataAccessException e) {
        log.error("CORE-DEP/L070/002: ERROR DMSII en B12PCSXMDACTO", e);          // hoy no se registra
        return Either.left(CodigoClonacion.ERROR_BASE);                        // 10
    }
}
private final ClonacionProperties props;   // sistema-bloqueo-estatus: 127

/** CONSULTA_CLONING: VALIDA_ENTRADA, BUSCA_B12, VALIDA_STATUS y MUEVE_B12, cada paso solo si va en 0. */
private ResultadoClonacion consulta(ConsultaClonacion in) {
    Optional<CodigoClonacion> invalida = validaEntrada(in);
    if (invalida.isPresent()) return ResultadoClonacion.error(invalida.get());

    var b12 = buscaB12(in);
    if (b12.isLeft()) return ResultadoClonacion.error(b12.getLeft());
    MedioClonadoEntity e = b12.get();

    // VALIDA_STATUS: solo el sistema 127 rechaza medios con estatus 1.
    if (in.sistema() == props.sistemaConValidacionEstatus() && e.getStatus() == 1) {
        return ResultadoClonacion.error(CodigoClonacion.BLOQUEADO_SISTEMA_127);   // 7
    }
    return new ResultadoClonacion(CodigoClonacion.OK, Optional.of(MedioClonado.de(in, e)));   // MUEVE_B12
}

Riesgos de migración
Salida sin limpiar en errores

La copia a EA_O_VACLON solo ocurre con resultado 0 (líneas 328-334). Con cualquier otro código el buffer del llamador queda con su contenido previo; un llamador que no revise el código usaría datos ajenos.

Errores de base sin bitácora

BUSCA_B12 convierte cualquier error DMSII distinto de NOTFOUND en el código 10 sin invocar DF_ERRORDB (líneas 250-254). Solo la apertura de la base registra el detalle.

Validación de estatus solo para el sistema 127

VALIDA_STATUS (líneas 273-274) es la única regla sobre el registro encontrado y está compilada para el sistema 127; los demás sistemas reciben medios con estatus 1 como válidos.

Contrato binario implícito

La interfaz depende de desplazamientos en dígitos de 4 bits (líneas 98-126) y de que el buffer del llamador mida al menos 42 bytes. Cualquier llamador que se migre por separado necesita el adaptador de nibbles.

Pendiente de revisión SME
  • Confirmar con SME qué representan los tipos de medio 0 y 1 (por ejemplo contrato y tarjeta o cuenta) y el significado de los estatus de CORE-DEPB12PCLONNING.
  • Confirmar el formato de B12P-FEC-ALTA (8 dígitos: AAAAMMDD o DDMMAAAA) para convertirlo a LocalDate.
  • Identificar qué programas llaman a CORE-DEPL070_VALIDA_CLONING y si alguno usa el buffer de salida sin revisar el código de resultado.
  • El fuente solo acepta el tipo de llave 1; confirmar si el campo tipo de llave quedó reservado para usos futuros.
