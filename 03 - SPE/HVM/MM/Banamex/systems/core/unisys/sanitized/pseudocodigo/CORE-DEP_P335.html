P335 · Estado de Cuenta CPE (CORE-DEP Captación LegacyCore)

CORE-DEPProgramaCOBOL

Fuente: P335.cbl (1036 LOC) · Batch nocturno — generación y clasificación del estado de cuenta de Cuenta Productiva Especial · BC-21

Convenciones: nombres traducidos (Unisys→legible); [P335 Lnnnn] = origen; (BR: RN-CORE-DEP-...) = regla.

1. Resumen funcional

P335-EDOCTA genera el estado de cuenta mensual de la Cuenta Productiva Especial (CPE) del sistema de captación LegacyCore CORE-DEP. Opera en modo exclusivo para el centro de servicio CSI=10 (Banca Corporativa), leyendo la base DMSII CORE-DEPBD01CAPTACION en modo INQUIRY y barriendo el dataset B39CTASCPE en orden de grupo-subgrupo para acumular saldos, rendimientos, comisiones e ISR retenido en tres niveles: cuenta individual (B39), subgrupo/cliente (B38) y grupo corporativo (B37). El programa produce primero un archivo intermedio ARCHED1 (CORE-DEP/FILE/S051) con registros tipados jerárquicamente, y luego lo ordena por grupo-cliente-tipo para generar el archivo final ARCHEDO (CORE-DEP/FILE/S050) que se entrega al cliente corporativo como extracto. Si CSI ≠ 10, el programa cierra la base y termina sin generar ningún archivo. Toda la lógica fiscal de ISR y las dos tasas de IVA sobre comisiones (10%/15%) derivan de campos directamente del dataset B37/B39 del periodo.

4.4 Apertura de base de datos — 120-ABRE-BASE

PROCEDIMIENTO Abre_Base():                      // 120-ABRE-BASE · [P335 L138000]

  MOVER 0  A  estado_base                       // WS-STATUS-BASE = 0
  ABRIR INQUIRY  CORE-DEPBD01CAPTACION
  EN EXCEPCIÓN
    SI error_DMSII_tipo_open  // DMSTATUS(OPENERROR)
    ENTONCES
      SI tipo_error = 39      // DMSTATUS(DMERRORTYPE) = 39 — base temporalmente bloqueada
      ENTONCES
        MOVER 39  A  estado_base
        ESPERAR 60 segundos   // WAIT(60) — retry automático
      SINO
        MOVER tipo_error  A  estado_base
        MOVER "ERROR AL OPEN DE LA BD; ST BASE: " + estado_base  A  texto_mensaje
        EJECUTAR 70000050-MENSAJE               // [COPY PRO]
        LLAMAR SYSTEM DMTERMINATE              // terminación inmediata del job
      FIN-SI
    SINO
      // Error de categoría DMSII (no open error)
      MOVER categoría_error  A  estado_base    // DMSTATUS(DMCATEGORY)
      MOVER "ERROR AL OPEN DE LA BD; ST BASE: " + estado_base  A  texto_mensaje
      EJECUTAR 70000050-MENSAJE
      LLAMAR SYSTEM DMTERMINATE
    FIN-SI
  FIN-EXCEPCIÓN

4.5 Obtención de control B02 y cálculo de fechas — 122-OBTEN-B02CONTROL

PROCEDIMIENTO Obtiene_Control_B02():            // 122-OBTEN-B02CONTROL · [P335 L140700]

  EJECUTAR 90000002-B02CONTROL-FIND            // [COPY PRO] — FIND en B02CONTROL

  SI estado_base > 0  // error en el FIND
  ENTONCES
    MOVER "ERR LOCK B00CTRLPASO " + estado_base  A  texto_mensaje
    EJECUTAR 70000050-MENSAJE
    LLAMAR SYSTEM DMTERMINATE
  FIN-SI

  // Cálculo del mes de proceso (mes anterior al mes de la fecha de línea en B02)
  SI centro_servicio = 10  // B02-NUM-CSI = 10
  ENTONCES
    MOVER fecha_linea_b02  A  fecha_proceso     // WS-FECHA-PROCER ← B02-FECHA-LINEA (AAAAMMDD)
    SI mes_proceso = 01                         // enero → retroceder al año anterior

      MOVER 12  A  mes_proceso                  // WS-FEC-PROCE-MM = 12
      MOVER dias_del_mes(12)  A  dia_proceso    // WS-NUM-DIAS(12) → WS-FEC-PROCE-DD

      CALCULAR mes_proceso  = mes_proceso - 1   // WS-FEC-PROCE-MM - 1
      MOVER dias_del_mes(mes_proceso)  A  dia_proceso
    FIN-SI

4.6 Establecimiento de fechas del ciclo — 132-ESTABLECE-FECHAS

PROCEDIMIENTO Establece_Fechas():               // 132-ESTABLECE-FECHAS · [P335 L142500]

  // Fecha de inicio: día 1 del mes calculado
  MOVER 1  A  dia_inicio                        // WS-FEC-INI-DD = 1

  // Fecha de fin: último día del mes (de la tabla WS-MESES de 12 entradas)
  MOVER dias_del_mes(mes_inicio)  A  dia_fin    // WS-NUM-DIAS(WS-FEC-INI-MM) → WS-FEC-FIN-DD

  // Ajuste de año bisiesto: si el año es divisible entre 4 y el mes es febrero, +1 día
  DIVIDIR año_inicio / 4
  GUARDANDO  cociente_division  RESTO  residuo
  SI residuo = 0
  ENTONCES
    SI mes_inicio = 02
    ENTONCES
      SUMAR 1  A  dia_fin                       // febrero bisiesto → 29 días
    FIN-SI
  FIN-SI

« [P335 L142500-143500] » Nota: el ajuste bisiesto usa únicamente divisibilidad entre 4, sin las excepciones de los años centenarios (divisibles por 100 pero no por 400). Esto puede generar fechas incorrectas para años 2100/2200 aunque no tiene impacto operativo inmediato. ⚠ [HARDCODE-IMPLÍCITO]

4.9 Loop principal de generación — 200-GENERA-EDOCTA

PROCEDIMIENTO Genera_Estado_Cuenta():           // 200-GENERA-EDOCTA · [P335 L148100]
// Ejecutado HASTA que EOF-B39 sea verdadero. Procesa un registro B39 por iteración.

  // --- Primera vez: captura grupo y subgrupo iniciales ---
  SI es_primera_vez  // PRIM-VEZ (WB-PRIM-VEZ = 0)
  ENTONCES
    MOVER 1  A  bandera_primera_vez             // WB-PRIM-VEZ = 1
    MOVER grupo_b39  A  grupo_anterior, grupo_corriente    // B39-GRUPO → WS-GPO-ANT, WS-GRUPO
    MOVER subgrupo_b39  A  subgrupo_anterior, subgrupo_corriente  // B39-SUB-GPO → WS-SGP-ANT, WS-SUBGPO
    // INC00318628663 — captura tipo persona de pago para selección de tasa
    MOVER tipo_persona_b39  A  tipo_persona_pago  // B39-TPO-PERS → WS-TIPO-PERSONA-PAGO
  FIN-SI

  // --- Detección de cambio de grupo (procesamiento del grupo anterior) ---
  SI NO fin_dataset_B39
  ENTONCES
    SI grupo_b39  ≠  grupo_anterior              // B39-GRUPO ≠ WS-GPO-ANT → cambio de grupo
    ENTONCES
      SI cuentas_ok_grupo > 0                   // WS-CTAS-STAT-OKGP > 0 — hay cuentas válidas en el grupo
      ENTONCES
        MOVER ZEROS  A  cuentas_ok_grupo, cuentas_ok_subgrupo  // WS-CTAS-STAT-OKGP=0, WS-CTAS-STAT-OKSG=0
        EJECUTAR Cambio_Grupo()                 // PERFORM 205-CAMBIO-GRUPO — vuelca registros del grupo anterior
      SINO
        SIGUIENTE SENTENCIA                     // NEXT SENTENCE — sin cuentas válidas, no graba nada del grupo
      FIN-SI
    SINO
      // Mismo grupo — verifica cambio de subgrupo
      SI subgrupo_b39  ≠  subgrupo_anterior     // B39-SUB-GPO ≠ WS-SGP-ANT
      ENTONCES
        SI cuentas_ok_subgrupo > 0             // WS-CTAS-STAT-OKSG > 0
