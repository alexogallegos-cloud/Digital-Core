1. Resumen funcional

P164 es un proceso batch multi-función del dominio de Captación (S500, Unisys ClearPath MCP). Su misión principal es exportar estructuras DMSII de BD01CAPTACION a Teradata para análisis de control de retiros y pagos. Soporta cinco modos de ejecución gobernados por el campo WKS-TSK-PROCESO del TASKVALUE: (1) extraer el archivo B52 de límites depósito/retiro (CTRLDEPRET), (2) extraer pagos activos ISI (ISILOANS), (3) ejecutar el proceso de réplica inter-host entre coberturas MCP (F04-REPLICA-LOC ↔ F05-REPLICA-FOR), (4) extraer pagos pendientes B25 (PGOSPENDPE), y (5) extraer contratos dormidos B03 (RDORMANT). Cuando el TASKVALUE es cero o ausente, corre los modos 1, 2, 3 y 4 secuencialmente. El proceso de réplica (modo 3) sincroniza acumulados de depósito/retiro diario y mensual entre las dos coberturas del sistema MCP mediante transferencia de archivos vía la librería ADMONXFERS.
