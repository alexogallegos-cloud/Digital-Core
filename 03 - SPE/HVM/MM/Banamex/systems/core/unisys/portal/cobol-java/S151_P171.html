Recibe en su parámetro el sistema y la fecha de proceso, con los que arma los títulos de AHR, ACC y de la bandera. Carga el archivo ACC en un archivo indexado temporal ACC2 por número de cuenta. Recorre AHR, que trae los movimientos agrupados por cuenta con el saldo de mayor posterior a cada uno, y en cada cambio de cuenta compara el último saldo de la cuenta anterior contra ACC2; las diferencias y las cuentas inexistentes en ACC se graban en un archivo indexado de cuentas descuadradas. Después imprime, por cada cuenta descuadrada, la diferencia de saldos y el detalle de sus movimientos, escribe el registro BANDE-171 y borra el archivo temporal.

public record MovimientoAhr(
        String tipoRegistro,          // AHRST-RECORD-TYPE X(03)
        int sucursal,                 // AHRST-BRCH-NBR 9(03)

    static boolean esTrailer(String linea) { return linea.startsWith("END OF FILE"); }

    static BigDecimal conSigno(String digitos17, char signo) {
        BigDecimal v = new BigDecimal(new BigInteger(digitos17), 2);
        return signo == '-' ? v.negate() : v;
    }

@Bean
Step cargaAcc(JobRepository repo, PlatformTransactionManager tx,
              FlatFileItemReader<String> accReader, SaldoAccRepository saldos,
              @Value("#{stepExecution.jobExecutionId}") Long ejecucion) {
    return new StepBuilder("cargaAcc", repo)
            .<String, SaldoAcc>chunk(1000, tx)
            .reader(accReader)                                   // BLOCK CONTAINS 5 RECORDS
            .processor(linea -> {
                if (linea.startsWith("END OF FILE")) return null;  // ACCI-ENDOFFILE
                var acc = AccRecord.parse(linea);
                return new SaldoAcc(ejecucion, acc.cuenta(),       // ACCI-ACCT-NBR2 completo
                        MovimientoAhr.conSigno(acc.saldoDigitos(), acc.signo()));
            })
            .writer(chunk -> {
                for (SaldoAcc s : chunk) {
                    if (saldos.existsById(s.id())) {
                        log.error("ERROR AL GRABAR ARCH-ACC2 cuenta {}", s.id().cuenta()); // INVALID KEY
                        continue;                                  // se conserva el primero, como en MCP
                    }
                    saldos.save(s);
                }
            })
            .build();
}
/** 20100-LEE-ARCH-AHR como corte de control explícito sobre AHR ordenado por cuenta. */
@Component
@StepScope
@RequiredArgsConstructor
public class PunteoProcessor implements ItemProcessor<MovimientoAhr, CuentaDescuadrada> {

    private final SaldoAccRepository acc;
    private final P171Properties props;     // p171.comparar-signo: false (comportamiento actual)
    private String cuentaActual;            // WKS-CUENTA-ANT
    private BigDecimal ultimoSaldo;         // WKS-SALDO-T + WKS-SSDO-T: saldo tras el último movimiento

    @Override
    public CuentaDescuadrada process(MovimientoAhr m) {
        CuentaDescuadrada resultado = null;
        if (cuentaActual != null && !m.cuenta().equals(cuentaActual)) {
            resultado = compara(cuentaActual, ultimoSaldo);    // se compara la cuenta que TERMINA
        }
        cuentaActual = m.cuenta();
        ultimoSaldo = m.saldoMayor();
        return resultado;                                       // null = cuadrada o misma cuenta
    }

    /** Se invoca desde afterStep: el COBOL omite la última cuenta del archivo. */
    public Optional<CuentaDescuadrada> cierraUltima() {
        return cuentaActual == null ? Optional.empty() : Optional.ofNullable(compara(cuentaActual, ultimoSaldo));
    }

    private CuentaDescuadrada compara(String cuenta, BigDecimal saldoAhr) {
        return acc.findById(new LlaveEjecucionCuenta(ejecucion(), cuenta))
                .map(a -> cuadra(saldoAhr, a.saldo()) ? null
                        : CuentaDescuadrada.de(cuenta, saldoAhr, a.saldo(), true))
                .orElseGet(() -> CuentaDescuadrada.de(cuenta, saldoAhr, BigDecimal.ZERO, false)); // "+" y 0
    }

    /** La comparación de signo está comentada en el fuente (línea 1503). */
    private boolean cuadra(BigDecimal ahr, BigDecimal accSaldo) {
        return props.compararSigno() ? ahr.compareTo(accSaldo) == 0
                                     : ahr.abs().compareTo(accSaldo.abs()) == 0;
    }
}

/** 30300-GRABA-DET1: diferencia entre saldo AHR y ACC según sus signos. */
public final class DiferenciaSaldos {

    /**
     * Mismo signo: mayor menos menor. Signo distinto: suma de ambos importes.
     * Equivale a |saldoAhr - saldoAcc| con los saldos ya firmados.
     */
    public static BigDecimal de(BigDecimal saldoAhr, BigDecimal saldoAcc) {
        return saldoAhr.subtract(saldoAcc).abs();   // escala 2, exacto
    }

        if (lista.isEmpty()) {

Riesgos de migración
Descuadre atribuido a la cuenta siguiente

En 20100-LEE-ARCH-AHR, al detectar el cambio de cuenta se lee ACC2 con la cuenta anterior (línea 1498), pero en la línea 1499 se mueve la cuenta nueva a WKS-CUENTA-T antes de usarla. Las ramas de descuadre (líneas 1510 y 1522) graban WKS-CTA-AHR con la cuenta nueva y los saldos de la anterior. El reporte de auditoría mostraría la diferencia y los movimientos bajo una cuenta que no es la descuadrada.

La última cuenta de AHR no se audita

La comparación solo ocurre al cambiar de cuenta. Cuando READ ARCH-AHR llega a fin de archivo (línea 1533) el ciclo termina y 20000-LEE-AHR cierra los archivos sin comparar el saldo acumulado de la última cuenta.

Signo del saldo no comparado

La condición WKS-SSDO-T = ACC-SSDO está comentada (línea 1503): dos saldos de igual importe y signo contrario se consideran cuadrados.

Truncamiento de cuentas e importes

El número de cuenta de 23 dígitos (AHRST-ACCT-NBR2, ACCI-ACCT-NBR2) se reduce a sus últimos 11 en ACC-CUENTA y WKS-AHR-ACCT-NBR; dos cuentas que coincidan en esos dígitos colisionan. El saldo 9(15)V99 se guarda en WKS-SALDO-T 9(14)V99, ACC-SALDO 9(14)V99 y WKS-SDO-AHR 9(12)V99, perdiendo dígitos altos en silencio.

Datos personales en el archivo de entrada

El layout AHR incluye RFC, nombre y cuenta de ordenante y beneficiario y sello digital (Anexo 20 del SAT, líneas 87-117). P171 no los usa, pero la versión Java no debe cargarlos en memoria ni en bitácoras.
