Con el parámetro 1 recorre el índice B52SXCSIFECH desde los registros con CSI cero y con el parámetro 2 el dataset S500B52CTRLDEPRET completo. Por cada registro consulta al cliente en S016 y, si el CSI alterno, el tipo de persona o la ubicación difieren, actualiza el B52 dentro de una transacción con hasta dos intentos ante deadlock; se detiene si cambia la fecha de máquina o el operador envía HI 4. Al cierre graba el trailer del monitor, lo copia con un WFL compilado y lo envía por ADMONXFERS. Por último reúne los archivos de error de L050 de los últimos días y el del propio P280, los ordena y emite el reporte 001ERRORES por plaza.

/** F01-REG-ARCH (320 bytes): llave de 32 posiciones y texto con tres interpretaciones. */
public record ErrorConsolidado(int pieza,              // F01-NUM-PIEZA: 1 = L050, 2 = P280
                               LocalDate fechaArchivo,  // F01-FECHA-ARCH 9(08)
                               int copia,               // F01-NUM-C
                               int tipoRenglon,         // F01-TR: 1 acciones, 2 errores de BD
                               int id,                  // F01-ID
                               LocalDate fecha, LocalTime hora,   // F01-HORA HHMMSS + 2 de relleno
                               Texto texto) implements Comparable<ErrorConsolidado> {

    public sealed interface Texto permits TextoL050, TextoS016, TextoP280 {}
    public record TextoL050(String det1, String det2, String det3) implements Texto {}  // 91 / 97 / 100
    public record TextoS016(String det1, String det2) implements Texto {}               // 110 / 102
    public record TextoP280(String det1) implements Texto {}                            // 100

    /** SD-ARCERR: siete llaves ascendentes. */
    static final Comparator<ErrorConsolidado> ORDEN = Comparator
            .comparingInt(ErrorConsolidado::pieza)
            .thenComparing(ErrorConsolidado::fechaArchivo)
            .thenComparingInt(ErrorConsolidado::copia)
            .thenComparingInt(ErrorConsolidado::tipoRenglon)
            .thenComparingInt(ErrorConsolidado::id)
            .thenComparing(ErrorConsolidado::fecha)
            .thenComparing(ErrorConsolidado::hora);

    @Override public int compareTo(ErrorConsolidado o) { return ORDEN.compare(this, o); }
}

/** El MIX (STACKNO) identificaba la instancia; aquí es el id de ejecución del job. */
static String tituloReporte(String plantilla, int csi, LocalDate fecha, long jobExecutionId) {
    return plantilla.replace("{csi}", "%02d".formatted(csi))
                    .replace("{fecha:yyMMdd}", fecha.format(DateTimeFormatter.ofPattern("yyMMdd")))
                    .replace("{instancia}", "%07d".formatted(jobExecutionId));
}
@Component
@RequiredArgsConstructor
public class PublicaMonitorTasklet implements Tasklet {

    private final CopiaMonitor copia;
    private final TransferenciaArchivos admonXfers;   // reemplaza INTELARSND IN ADMONXFERS
    private final AvisoOperador avisos;
    private final TitulosMonitor titulos;

    /** 40006000-COPIA-PROB + 40006000-INTELAR-PROB. */
    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        String ints = titulos.problemasInts();    // WS-TITLE-PROB-INTS sin el punto final
        String local = titulos.problemas();       // WS-TITLE-PROB
        copia.copia(ints, local);                 // WAIT(03) previo: ya no es necesario, la llamada es síncrona
        int resultado = admonXfers.envia(ints);
        if (resultado != 0) {
            avisos.mensaje("ERROR INTELARSND %011d".formatted(resultado));   // sin aborto, como el original
        }
        return RepeatStatus.FINISHED;
    }
}

/** PGM-INTERRUPT-BY-HI: el operador enviaba HI 1, 2 o 4 a la tarea. */
@RestController
@RequestMapping("/admin/p280")
@PreAuthorize("hasRole('OPERADOR_S500')")
@RequiredArgsConstructor
class P280OperadorController {
    private final ControlEjecucion control;

    @PostMapping("/hi/{valor}")
    void hi(@PathVariable int valor) {
        switch (valor) {
            case 4 -> control.solicitaFin("TERMINO PROCESO POR HI 4");   // WS-HI = 4
            case 2 -> control.rotaMonitor();                             // 300000-CIERRA-MON
            case 1 -> control.publicaContadores();                       // 300000-MUESTRA-DISP
            default -> { }
        }
    }
}

@Bean
Job p280(JobRepository repo, Step validaVersionYParametro, Step barridoB52,
         Step cierraMonitor, Step publicaMonitor, Step consolidaErrores, Step reporteErrores,
         ParametroValidoDecider parametro) {
    return new JobBuilder("S500P280", repo)
            .start(validaVersionYParametro)           // 100000-INICIO-PGM, TASKVALUE 1 o 2
            .next(barridoB52)                         // PERFORM 200000-PROCESO-PGM UNTIL WS-EOJ
            .next(parametro).on("VALIDO").to(cierraMonitor)
                .next(publicaMonitor).next(consolidaErrores).next(reporteErrores)
            .from(parametro).on("*").end()
            .end().build();
}
@Component
@StepScope
@RequiredArgsConstructor
public class ActualizaB52Processor implements ItemProcessor<ControlDepRet, ControlDepRet> {

    private final ClienteS016 s016;
    private final ControlEjecucion control;
    private final Clock reloj;
    private final Contadores contadores;              // WKS-CONTADOR-LEI / ACT / NO-ACT / ERR
    @Value("#{stepExecution.startTime.toLocalDate()}") private LocalDate fechaMaquinaInicio;

    /** 200200-PROC-CSI. */
    @Override
    public ControlDepRet process(ControlDepRet b52) {
        contadores.leido();
        ControlDepRet resultado = s016.consulta(b52.numCliente())
                .flatMap(cte -> difiere(cte, b52) ? Optional.of(b52.conDatosDe(cte)) : Optional.empty())
                .orElse(null);                         // null: no se escribe

        // 200800-VALIDA-FEC: si cambió el día, se detiene el barrido después de este registro.
        if (!LocalDate.now(reloj).equals(fechaMaquinaInicio)) {
            control.registraMonitor("ERROR TIEMPO DE EJEUCION EXCEDIDO");  // texto original, con su errata
            control.solicitaFin("FIN DE DIA");
        }
        return resultado;
    }
}

/** S016_L422_B01SXCTE IN S016L422, opción 01. */
@Component
@RequiredArgsConstructor
class ClienteS016 {
    private final ClientesApi s016;          // servicio que reemplaza a la librería S016L422
    private final MonitorP280 monitor;
    private final Contadores contadores;

    Optional<DatosCliente> consulta(String numCliente) {
        RespuestaCliente r = s016.buscaPorNumero(numCliente, 1);
        if (r.error() == 0 && numCliente.equals(r.numCliente())) {
            return Optional.of(r.datos());
        }
        contadores.error();
        monitor.errorS016(r, numCliente);    // 200211-GRABA-ERR-S016, id 4
        return Optional.empty();
    }
}

/** 200220-VALIDA-DATOS: se actualiza si cualquiera de los tres datos difiere. */
boolean difiere(DatosCliente cte, ControlDepRet b52) {
    boolean igual = cte.csiAlterno() == b52.csi()
                 && cte.tipoPersona() == b52.tipoPersona()
                 && cte.ubicacionGeo() == b52.ubicacionGeo();
    if (igual) contadores.noActualizado();
    return !igual;
}
@Component
@RequiredArgsConstructor
class ActualizadorB52 {

    private final ControlDepRetRepository repo;   // S500B52CTRLDEPRET
    private final Contadores contadores;
    private final MonitorP280 monitor;

    /** 200230-ACTUALIZA-BD52 + 300233-MUEVE-DATOS-BD52. */
    @Retryable(retryFor = PessimisticLockingFailureException.class,
               maxAttempts = 2, backoff = @Backoff(delay = 2_000))     // WKS-INT-LOOK = 2, WAIT (2)
    @Transactional
    public void actualiza(ControlDepRet b52, DatosCliente cte, LocalDate fechaProceso) {
        ControlDepRet bloqueado = repo.findWithLockById(b52.id()).orElseThrow();  // LOCK
        bloqueado.setFecUpdate(fechaProceso);                // B52-FEC-UPDATE
        bloqueado.setCsi(cte.csiAlterno());                  // B52-CSI
        bloqueado.setTipoPersona(cte.tipoPersona());         // B52-TIP-PER
        bloqueado.setUbicacionGeo(cte.ubicacionGeo());       // B52-UBI-GEO
        contadores.actualizado();                            // STORE + END-TRANSACTION
    }

    /** Dos deadlocks seguidos: se registra y se sigue con el siguiente registro. */
    @Recover
    public void deadlockPersistente(PessimisticLockingFailureException e, ControlDepRet b52,
                                    DatosCliente cte, LocalDate fecha) {
        contadores.error();
        monitor.deadlock(b52.numCliente());                  // 300232-DEADLOCK-BASE, id 20
    }
}

        for (int cop = 1; cop <= 14; cop++) {

    var lector = new MultiResourceItemReader<ErrorConsolidado>();

    lector.setComparator((a, b) -> 0);               // conservar el orden de descubrimiento
    lector.setDelegate(new FlatFileItemReaderBuilder<ErrorConsolidado>()

Riesgos de migración
Actualización de la llave del índice que se recorre

En modo 1 el barrido usa B52SXCSIFECH desde B52-CSI = 0 (línea 999) y 300234-MUEVE-DATOS cambia B52-CSI (línea 1185). Según cómo reposicione DMSII el cursor, podrían saltarse o repetirse registros.

Deadlock persistente sin reintento posterior

Tras dos deadlocks (líneas 1113-1117) el registro se reporta en el monitor y el barrido continúa; ese cliente queda sin actualizar hasta otra corrida.

Copia WFL sin verificación

CALL SYSTEM WFL USING WS-WFL-COPY (línea 1249) no revisa el resultado, y el pack CAPTACION está fijo en la tarjeta WFL de DATA DIVISION (líneas 379-388).

Huecos en la secuencia de archivos L050

La búsqueda de archivos L050 se detiene en la primera secuencia que no existe (línea 1343); los archivos posteriores de esa copia no entran al reporte.

Hardcodes

Versión 25MTP004, prefijo 50004S01, CSI 04 y 10 con sus nombres de plaza, 14 copias, 9999 secuencias, 6 días de retroceso y 55 líneas por página están compilados. Se trasladan a configuración. No se encontraron credenciales en el fuente.
