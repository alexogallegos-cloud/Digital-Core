Recibe por CARGAMOV1, o por ENLACE_6D en la instancia del S408, un registro de movimiento en el formato anterior y lo convierte al vigente. Lo valida contra el catálogo de claves de transacción del S080, le asigna como autorización el siguiente número de registro del archivo MOV del día contable correspondiente entre diez canales abiertos y lo escribe, junto con sus datos adicionales. Tras cada operación lanza, si hace falta, los procesos P015, P016 y P025, sincroniza niveles con L001/CONTROL y, al fin de movimientos del S408, reenvía el cierre a la instancia del S500.

        long total = 0;

                total += TIEMPO.toSeconds();

                }
            }
        } catch (InterruptedException ie) {
            Thread.currentThread().interrupt();
            throw new LockNoDisponibleException(total);
        }

    /** Hasta 10 días contables abiertos a la vez: el movimiento va al canal de su fecha contable. */
    private int resuelveCanal(MovimientoGl mov, int resultadoPrevio) {
        while (cambiaFecha.isLocked()) esperaCorta();             // WHILE LOCKSTATUS(CAMBIA_FECHA) ... WAIT((.3))

        if (mov.sistema() != props.sistema()) return -Resultado.SISTEMA_NO_VALIDO;   // RESULT := 1
        if (resultadoPrevio != 0) return -resultadoPrevio;

        OptionalInt canal = IntStream.rangeClosed(0, 9)
                .filter(i -> mov.fechaContable().equals(canales.fechaDia(i)))   // FEC_DIA[I_I]
                .findFirst();
        if (canal.isPresent()) return canal.getAsInt();               // NUMDIAC1
        if (mov.funcion() == 96) return CANAL_NO_REQUERIDO;           // fin de S500 no necesita canal
        return -Resultado.FECHA_NO_ABIERTA;                           // RESULT := 4
    }
    private int despacha(MovimientoGl mov, int canal) {
        return switch (mov.funcion()) {
            case 1      -> cargaMemory(mov, canal);          // alta de movimiento
            case 2      -> elimina(mov, canal);              // baja lógica
            case 11     -> inicia(mov, canal);
            case 12     -> termina(mov, canal);
            case 21     -> eliminaPorProceso(mov, canal);
            case 22     -> eliminaPorAutorizacion(mov, canal);
            case 31, 32 -> cambiaModoEscritura(mov, canal);  // REBLOCKADE
            case 96     -> { if (props.sistema() == 408) { finS500 = true; fechaP150 = mov.fechaContable(); } yield 0; }
            case 97     -> preFinal(mov);
            case 98     -> finDeMovimientos(mov);
            default     -> Resultado.FUNCION_NO_VALIDA;      // ELSE: RESULT := 2
        };
    }

    /** FUNCION 98: cierra los diez canales y, en la instancia S408, reenvía el cierre a la del S500. */
    private int finDeMovimientos(MovimientoGl mov) {
        canales.cierraTodos();                               // CIERRALOG(0..9)
        if (props.sistema() == 408) {
            finS408 = true;
            ha.marcaTestigo("FINS408", fechaS151);           // archivo testigo de alta disponibilidad
            fechaP150 = mov.fechaContable();
            int r = registroS500.enlace8d(MovimientoGl.cierre(96, 1, 500, fechaP150));   // ENLACE_8D
            if (r != 0) throw new ReenvioCierreS500Exception(r);   // nuevo: en ALGOL el resultado se ignora
        }
        return finalYSincroniza();                           // FINAL
    }
@Component

public class ValidadorMovimiento {

    private final CatalogoClavesS080 claves;   // ACLAVES, cargado por CARGACVES

    /** DFVALIDA: devuelve el código de rechazo o 0. */
    public int valida(MovimientoGl m) {
        if (m.clave(1) == 0) return 3;                                   // sin primera clave
        for (int i = 1; i <= 5 && m.clave(i) > 0; i++) {
            if (claves.columna(m.clave(i)) <= 0) return 3;                // clave no catalogada
        }
        int r = 0;
        for (int i = 1; i <= 5 && m.importe(i).signum() > 0; i++) {
            int ind = claves.indicador(m.clave(i));
            if ((ind == 2 || ind == 3) && m.sucursalPromotora() <= 0) r = 5;
            if ((ind == 1 || ind == 3) && m.sucursalInicial() <= 0)   r = 6;
        }
        if (r != 0) return r;                                            // ALGOL conserva el último código
        if (m.origen() < 1 || m.origen() > 3) return 10;
        if (m.moneda() <= 0) return 14;
        return 0;
    }
}
    /** GRABALOG: header en el registro 0 y autorización = NIVLOG + 1 (posición física en el archivo MOV). */
    private int cargaMemory(MovimientoGl mov, int canal) {
        if (mov.funcion() == 1) {
            int r = validador.valida(mov);
            if (r != 0) return r;
        }
        CanalDia c = canales.canal(canal);
        if (c.nivelLog() == 0) {
            c.escribeHeader("HD", c.fecha());                   // "HD" + FECDIA 8 dígitos + ceros
        }
        long autorizacion = c.nivelLog() + 1;                   // DFAUT y DFAUTFAN
        mov.asignaAutorizacion(autorizacion);
        c.escribe(autorizacion, mov);                           // resto de GRABALOG: bloque MOV y, si hay, DES

        // CARGAMEMORY: si quedan menos de 300 registros libres, el archivo crece 20 000 (MOV) o 5 000 (DES).
        c.ampliaSiHaceFalta(300, props.ampliacionMov(), props.ampliacionDes());
        return 0;
    }

Riesgos de migración
Lock global retenido durante esperas

CARGAMOV1 toma E1 y, dentro, ejecuta WAIT((3)) antes de lanzar P015 o P016 (líneas 2659, 2667 y 2675). ACQUIREL espera sin límite (líneas 1204-1225). Un consumidor lento congela el registro contable de todos los sistemas.

Reenvío de cierre al S500 sin verificación

RESULT_L002_S500 no se evalúa tras LINKLIBRARY, ENLACE_8D ni DELINKLIBRARY (líneas 2579-2588).

Comportamiento dependiente del nombre del objeto

SIST_LIB se toma de MYSELF.NAME (líneas 4069-4070). Renombrar el objeto cambia qué sistema atiende la instancia.

Desfase de niveles tras una caída

Las altas y bajas sincronizan niveles con L001/CONTROL cada 1 000 movimientos (línea 2693); tras una caída puede haber hasta 999 asientos sin reflejar en el control.

Carga del catálogo de claves posiblemente incompleta

En CARGACVES el ciclo WHILE RESULTADO < 2 (línea 3580) termina cuando la consulta a L710 devuelve 0, porque la línea 3696 lo convierte en 3. Si L710 usa 0 para indicar que hay registro y 1 para indicar que hay más, se cargaría una sola clave por arranque. Depende de la semántica de L710, que no viene en el fuente.

Sin validación de cuadre contable

DFVALIDA (líneas 1236-1295) valida claves, sucursales, origen y moneda, pero no que cargos y abonos cuadren.

Pendiente de revisión SME
  • El inventario no asocia reglas del brain a L002R2; el pseudocódigo cita RN-S151-633 a RN-S151-689, pero no se usaron porque no están en reglas_brain. Revisar la vinculación en brain.db.
  • Confirmar los códigos de retorno de L710_CONSUL_DETALLE para saber si la línea 3696 limita la carga del catálogo a una sola clave.
  • La conversión de formato MAPEO (líneas 2052-2203), CARGASALDOS y la consola CONTROLES no se incluyeron en esta demostración y requieren su propio análisis.
  • El tope de espera del lock y la verificación del reenvío al S500 son cambios de comportamiento propuestos; deben aprobarse con el SME antes de implementarse.
  • Definir si en la arquitectura destino la autorización seguirá siendo el número de registro físico o una secuencia por fecha contable; los sistemas satélite dependen de ese valor.
