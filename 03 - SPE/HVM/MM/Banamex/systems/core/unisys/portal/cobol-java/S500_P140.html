Recibe por USING un número de 13 dígitos que trae el tipo de reporte, el USER de la CSI y la fecha. Consulta a la librería MAPLI de forma jerárquica: agrupadores por USER (de 10 en 10), programas por agrupador (de 15 en 15) y actividades por programa (de 5 en 5), con continuaciones cuando hay más. Cada actividad, o el programa solo si no tiene actividades, se graba en el archivo de paso FILE-PROGRAMAS de 360 bytes; después se ordena por agrupador, programa, tipo, copia y actividad, y se imprime el reporte FILE-MONI filtrando agrupadores menores a 6 (monitoreo normal) o mayores a 5 (monitoreo batch). Si MAPLI responde 99 espera, reintenta y pide decisión al operador.

/** WS-USER-FEC PIC 9(13) RECEIVED BY CONTENT, interpretado con WS-PARAM-USERFEC y WS-PARAM-CUF. */
public record ParametroMonitoreo(TipoReporte tipo,   // WS-PARAM-DECI  9(01)
                                 int user,           // WS-PARAM-USER  9(04)
                                 int sistema,        // WS-PARAM-U     9(03): últimos 3 dígitos del USER
                                 LocalDate fecha) {  // WS-PARAM-FEC   9(08) AAAAMMDD

    public enum TipoReporte { MONITOREO, MONIBATCH }

    public static ParametroMonitoreo parse(String p13) {
        if (p13 == null || !p13.matches("\\d{13}")) {
            throw new IllegalArgumentException("Parámetro de 13 dígitos inválido: " + p13);
        }
        TipoReporte tipo = p13.charAt(0) == '1' ? TipoReporte.MONITOREO : TipoReporte.MONIBATCH;
        int user = Integer.parseInt(p13.substring(1, 5));
        int sistema = Integer.parseInt(p13.substring(2, 5));    // vista CUF: D(1) C(1) U(3) F(8)
        LocalDate fecha = LocalDate.parse(p13.substring(5), DateTimeFormatter.BASIC_ISO_DATE);
        return new ParametroMonitoreo(tipo, user, sistema, fecha);
    }
}

/** Cliente del servicio que sustituye a MAPLI (S038L035). */
@Component
@RequiredArgsConstructor
public class MapliClient {

    private final RestClient mapli;

    /** S038L035_31_AGRUPXUSER: agrupadores del USER, de 10 en 10 a partir de 'desde'. */
    @Retryable(retryFor = MapliNoDisponibleException.class,
               maxAttempts = 2, backoff = @Backoff(delayExpression = "${p140.espera-ms:300000}"))
    public List<Agrupador> agrupadores(int user, int desde) {
        var r = mapli.get().uri("/users/{u}/agrupadores?desde={d}&max=10", user, desde)
                     .retrieve().toEntity(RespuestaMapli.class).getBody();
        return switch (r.resultado()) {
            case 0  -> r.agrupadores();
            case 99 -> throw new MapliNoDisponibleException();          // WS-BAN99
            default -> throw new MapliErrorException("ERR.AL ACCESAR AGRUXUSER", r.resultado());
        };
    }
}
/** Sustituye ACCEPT WS-DECIDE ("C" cancelar, "R" reintentar) por una política sin operador. */
@Component
@RequiredArgsConstructor
public class ConsultaProgramas {

    private final MapliClient mapli;
    private final MonitoreoAlertas alertas;

    public List<Programa> programasDe(int user, Agrupador a) {
        try {
            return mapli.programas(user, a.numero(), 0);    // 50013100-CALLPGRS (+ un reintento)
        } catch (MapliNoDisponibleException e) {
            // En MCP aquí se detenía la tarea esperando la decisión del operador.
            alertas.mapliNoDisponible(user, a);              // aviso a operación (correo, Teams, PagerDuty)
            return List.of();                                // equivale a responder "C": se corta el agrupador
        } catch (MapliErrorException e) {
            log.error("Error de MAPLI en agrupador {}: {}", a.numero(), e.getMessage());
            throw new CorteDeConsultaException(e);           // MOVE 11 TO WS-IND: deja de leer agrupadores
        }
    }
}

/** 50018100-MUEDAT-ACT + 50018110-STAACT */
public TareaMonitoreada fila(Agrupador a, Programa p, ActividadMapli act) {
    TareaMonitoreada.Actividad actividad = (act == null) ? null      // WS-SACT = 1: programa sin actividades
        : new TareaMonitoreada.Actividad(act.num(), act.tipo(), act.nombre(), act.pctAvance(),
              act.etAnterior(), act.etActual(), act.tiempoEsperado(), act.textoAdicional(),
              act.numLlamadas(), act.transXSeg().setScale(2, RoundingMode.DOWN),
              act.tiempoPromResp().setScale(6, RoundingMode.DOWN),
              act.seEncuentraEn(), estado(act.status()));
    return new TareaMonitoreada(a.numero(), a.nombre(), p.tipo(), p.numero(), p.copia(), p.nombre(),
              p.fecIni(), p.hraIni(), p.fecFin(), p.hraFin(), p.etAnterior(), p.etActual(),
              p.pctAvance(), p.tiempoEsperado(), p.tipoDespliegue(), actividad);
}

static TareaMonitoreada.Estado estado(int sta) {
    return switch (sta) {
        case 1  -> TareaMonitoreada.Estado.EN_PROCESO;    // " EN PROCESO"
        case 2  -> TareaMonitoreada.Estado.TERMINADA;     // "  TERMINADA"
        case 3  -> TareaMonitoreada.Estado.NO_INICIADA;   // "NO INICIADA"
        default -> TareaMonitoreada.Estado.SIN_ESTADO;    // queda en SPACES
    };
}
/** SORT PRO-SORT ON ASCENDING KEY ... USING FILE-PROGRAMAS GIVING FILE-PROGRAMAS */
public static final Comparator<TareaMonitoreada> ORDEN_REPORTE =
        Comparator.comparingInt(TareaMonitoreada::numAgrupador)
                  .thenComparingInt(TareaMonitoreada::numProg)
                  .thenComparingInt(TareaMonitoreada::tipoProg)
                  .thenComparingInt(TareaMonitoreada::numCopia)
                  .thenComparingInt(t -> t.actividad() == null ? 0 : t.actividad().tipo())
                  .thenComparingInt(t -> t.actividad() == null ? 0 : t.actividad().num());

        return switch (parametro.tipo()) {
            case MONITOREO -> esBatch ? null : t;       // IF MON-NUM-AGRUP < 6
            case MONIBATCH -> esBatch ? t : null;       // IF MON-NUM-AGRUP > 5
        };
    }

Riesgos de migración
Espera interactiva en un proceso batch

50010150-TOMO-DEC hace ACCEPT WS-DECIDE y repite el mensaje hasta que el operador teclee C o la llamada responda; si nadie atiende la consola, la tarea queda detenida indefinidamente.

Errores de MAPLI sin abortar

No hay CALL SYSTEM DMTERMINATE en el programa. Un error distinto de 99 solo se informa (40000100 a 40000400) y en varios niveles corta la consulta del resto (MOVE 11 TO WS-IND); el reporte sale incompleto sin aviso en el listado.

Contador de continuación equivocado

50019100-CALLACTC (línea 1960) pone en cero WS-S038L035-32-CUANTOS-E, que pertenece a la consulta de programas, en lugar del campo de la consulta de actividades (33). La continuación de actividades viaja con el contador que haya quedado de la llamada anterior.

Hardcodes

Umbral de agrupador 6, prefijos S500/FILE/S038/ y /LIST/P140/, nombre MONITOREOS, versión 25MTP004 y WAIT ((300)) están compilados.

Pendiente de revisión SME
  • Confirmar la unidad de WAIT ((300)) en MCP; el pseudocódigo la describe como 300 ms, pero P015 usa WAIT (20) con el texto de 20 segundos.
  • Confirmar si la línea 1960 (MOVE 0 TO WS-S038L035-32-CUANTOS-E dentro de 50019100-CALLACTC) es un error de copia y debería ser el campo 33.
  • Definir con operación la política que reemplaza la decisión C o R del operador: número de reintentos, tiempo de espera y canal de alerta.
  • Confirmar el uso de la vista WS-PARAM-CUF: WS-MONI-SIS toma 3 dígitos (WS-PARAM-U) mientras el resto del programa usa el USER de 4 dígitos.
