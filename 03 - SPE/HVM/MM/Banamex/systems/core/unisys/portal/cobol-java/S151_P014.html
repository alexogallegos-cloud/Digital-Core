Al arrancar carga del catálogo 6 de S080 (librería S080L710) qué claves de transacción generan alerta de servicio 1, de servicio 2 o de ambos, calcula la ventana de servicio del día con LOCSUP y B05PROCESOS y fija los límites de envío. En cada ciclo lee del archivo de control A02-CTL-PC el último registro procesado de A01-MOVS500, se posiciona en el siguiente con SEEK y recorre los movimientos hasta fin de archivo, un registro de función 99, una cancelación o el límite de envíos. Por cada ocurrencia de clave de transacción con marca en el catálogo crea un registro en S151B07PROTCOB y, si está dentro de la ventana y no es duplicado, arma y envía el mensaje; fuera de la ventana el registro queda pendiente con estatus 0. Al terminar el recorrido guarda el nuevo apuntador en A02-CTL-PC y espera eventos COMS o comandos HI del operador.

public class ProteccionCobrosRunner implements SmartLifecycle {

    private final CatalogoProteccionCobros catalogo;   // 020700-CATALOGO (S080 catálogo 6)

    @Override
    public void start() {
        catalogo.cargar();             // falla explícita; en el fuente el W77-FIN = 1 del catálogo se pierde
        ventana.recalcular(LocalDate.now());
        limites.cargar();              // con piso de 80 envíos y 40 pendientes
        activo = true;
    }

    /** PERFORM 030100-PROCESO UNTIL W77-FIN = 1, con la espera de ESPERACOMS entre ciclos. */
    @Scheduled(fixedDelayString = "${p014.espera-entre-ciclos:PT2S}")
    void cicloProgramado() {
        if (activo) ciclo.ejecutar();
    }

    /** HI 4 / HI 6 o fin de COMS: equivale a 999999-FIN y al registro B05 función 22. */
    @Override public void stop()       { activo = false; }
    @Override public boolean isRunning() { return activo; }
}

public class CicloAlertas {

    private final LectorMovs500 lector;           // 030300-PROCESA-MOVS500
    private final ComsReceptor coms;              // 080500-ACEPTA-MENSAGE
    private final VentanaServicio ventana;
    private final P014Properties props;

        lector.procesarPendientes();
        coms.drenarEventos();

        // 030150-CHECA-FIN no se invoca en el fuente: el programa no se detiene al cerrar
        // la ventana, solo deja de enviar. Se conserva así y se deja activable.

            throw new FinDeVentanaException();   // detiene el scheduler de forma controlada
        }
    }

@Component
@RequiredArgsConstructor
public class VentanaServicio {

    private final CalendarioBancario calendario;   // THECALENDAR IN LOCSUP, función 18
    private final ProcesosB05Client b05;           // B05PROCESOS IN S151-L001
    private final P014Properties.Ventana cfg;
    private volatile Rango hoy;

    public record Rango(boolean diaHabil, LocalTime inicio, LocalTime fin) {
        /** WKS-HR-INI-FUN < seg-maquina AND WKS-HR-FIN-FUN > seg-maquina (extremos abiertos). */
        boolean abierta(LocalTime t) { return inicio.isBefore(t) && fin.isAfter(t); }
    }

    public void recalcular(LocalDate fecha) {
        boolean habil = calendario.esHabil(fecha);
        if (!habil) {
            log.info("DIA INHABIL PARA PROTECCION DE COB");
            hoy = new Rango(false, cfg.inhabilInicio(), cfg.inhabilFin());
            return;
        }
        hoy = b05.horario(151, 14)
                .map(h -> new Rango(true, h.inicio(), h.fin()))
                .orElseGet(() -> new Rango(true, cfg.habilInicioPorOmision(), cfg.habilFinPorOmision()));
    }

    public boolean abierta(LocalTime t) { return hoy.abierta(t); }
    public boolean cerrada(LocalTime t) { return !hoy.fin().isAfter(t); }
    public boolean diaHabil()          { return hoy.diaHabil(); }
}

/** Límites vivos: se ajustan en caliente con los HI 14, 15, 16, 80 y 90 (ver Actuator abajo). */
@Component
@RequiredArgsConstructor
public class LimitesEnvio {

    private final ParametrosEnvioRepository repo;   // B05 proceso 1, fecha 17 (registro de límites)
    private final P014Properties.Limites cfg;
    private final AtomicInteger envios = new AtomicInteger(500);       // VALUE 500
    private final AtomicInteger pendientes = new AtomicInteger(300);   // VALUE 300
    private volatile boolean alertasClienteNoContratado;              // W77-ENVIO-ALER-CLINOCON

    public void cargar() {
        repo.findParametros().ifPresentOrElse(p -> {
            envios.set(p.limiteEnvios());
            pendientes.set(p.limitePendientes());
            alertasClienteNoContratado = p.alertasClienteNoContratado();
        }, () -> repo.guardar(envios.get(), pendientes.get(), alertasClienteNoContratado));
        envios.updateAndGet(v -> Math.max(v, cfg.enviosMinimo()));
        pendientes.updateAndGet(v -> Math.max(v, cfg.pendientesMinimo()));
    }

    public int envios() { return envios.get(); }
}

Riesgos de migración
Error de catálogo sobrescrito al arrancar

020700-CATALOGO marca W77-FIN = 1 cuando el catálogo 6 no trae claves PC o la librería S080L710 falla (líneas 2927 y 2938), pero 020000-INICIO hace MOVE 1 TO W77-FIN y 700100-ABRE-BD lo regresa a 0 (líneas 2663-2664 y 3663). El programa entra al ciclo principal aunque el catálogo no se haya cargado.

El programa no se detiene por horario

030150-CHECA-FIN (líneas 3100-3107) es el único párrafo que pone W77-FIN en 1 al pasar la hora de fin, pero ningún PERFORM lo invoca. P014 solo termina por estatus 99 de COMS (línea 3941) o por HI 4 o 6.

Truncamiento en claves excluidas

W77-CLAVES-EXCLUIDAS es PIC 9(04) (línea 2383) y recibe claves PIC 9(06) en 030500-ALTA-SERV2 y 303680-CICLO-NUM-OCR. Claves de cinco o seis dígitos cuyas últimas cuatro cifras coincidan con la lista quedan excluidas.

Apuntador de control sin manejo de error

030350-ACTUALIZA-CONTROL hace REWRITE con INVALID KEY NEXT SENTENCE (líneas 3409-3410). Un fallo no se reporta y el siguiente ciclo reprocesa movimientos; solo la detección de duplicados del STORE evita alertas repetidas.

Campos de B05 con doble significado

WKS-B05-HORAINI, WKS-B05-HORAFIN y WKS-B05-STAPGM se usan como horario de servicio en 020800-CALCULA-ESPERA y como límite de envíos, límite de pendientes y marca de clientes no contratados en 000-BUSCAR-LIM-ENV-PEND. Un error de orden entre llamadas mezclaría ambos valores.

Hardcodes operativos

Horarios 06:00, 22:00, 08:00 y 19:30; pisos de 80 envíos y 40 pendientes; límites iniciales 500 y 300; HI 16 que restablece a 150; dieciséis claves excluidas, la exclusión de clave 1015 en sucursal 342 y caja 68; y la tabla de equipos para CSI destino 23 y 24. Todo se traslada a application.yml.

Siglo fijo en la bitácora

060700-DISPLAY toma la fecha con ACCEPT FROM DATE (seis dígitos) y le antepone el siglo 20 con MOVE 20 TO WKS-DIS-FECHA-S (línea 3584). En Java se usa LocalDate completo.

Catálogo indexado por número de clave

CVETRAN-PC OCCURS 10000 (línea 1120) se indexa con la clave de transacción; una clave fuera de 1 a 10000 provoca un subíndice inválido.
