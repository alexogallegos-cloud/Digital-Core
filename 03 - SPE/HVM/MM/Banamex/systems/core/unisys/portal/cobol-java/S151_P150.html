Lee los movimientos contables del día, los filtra por indicadores del catálogo de transacciones y calcula un saldo corrido por contrato a partir del saldo de inicio de día que entrega la librería de saldos de S500. Con el archivo intermedio ARCH-CITI arma en una sola pasada tres registros posicionales: ALR para movimientos de S151, AHR para S151 y S408 con el saldo, y OCM para cobranza de cheques. En la plaza 10 concentra los archivos de ambas plazas, renumera la secuencia por llave, emite un reporte de cifras de control y lanza el WFL P940 que transmite cada archivo a CITI.

@Component
@RequiredArgsConstructor
public class SaldoInicialClient {

    private final SaldosCaptacionService s500;        // reemplaza "S500L020SDOINIDIA IN S500L020SDOS"
    private final ArchivoErrorWriter archivoError;      // REG-ARCH-ERROR
    private final Bitacora lj;                          // "LJ IN LIB-DISP"

    /** 35200-CALL-S500: saldo neto = saldo captación (500) menos su reflejo en 408. */
    @Retryable(retryFor = LibreriaOcupadaException.class,       // RESULT 5 o 17
               maxAttempts = 8, backoff = @Backoff(delay = 30_000))  // WAIT(30)
    public BigDecimal saldoInicial(String contrato, LocalDate fechaProceso) {
        var r = s500.saldoInicioDia(contrato, fechaProceso);
        BigDecimal saldo;
        switch (r.resultado()) {
            case 0 -> saldo = r.saldo500().subtract(r.saldo408());   // COMPUTE exacto, escala 2
            case 5, 17 -> throw new LibreriaOcupadaException(r.resultado());
            case 12 -> {
                // COBOL avisa (tipo O) pero no prende W77-BAN-S500: el PERFORM UNTIL vuelve a llamar sin espera.
                archivoError.write(RegistroErrorSaldo.de(fechaProceso, contrato, r));
                throw new ErrorTablaS500Exception(contrato, r.resultado());   // aquí se detiene el step
            }
            default -> {
                // <21: error tipo E; >=21: informativo tipo I. En ambos se sigue con saldo cero.
                lj.registra(r.resultado() < 21 ? 'E' : 'I', " ERROR : " + r.resultado());
                saldo = BigDecimal.ZERO.setScale(2);
            }
        }
        archivoError.write(RegistroErrorSaldo.de(fechaProceso, contrato, r));   // se escribe siempre, aun con RESULT 0
        return saldo;
    }

    @Recover   // al octavo intento: aviso "NO CONTESTA LIBRERIA S500L020 FAVOR DE VERIFICAR"
    BigDecimal noContesta(LibreriaOcupadaException e, String contrato, LocalDate fecha) {
        lj.registra('O', " ERROR : " + e.resultado() + " NO CONTESTA LIBRERIA S500L020 FAVOR DE VERIFICAR ");
        throw e;   // P150 vuelve a empezar el ciclo de 8 intentos sin límite; aquí se escala
    }
}
@Component
@RequiredArgsConstructor
public class InclusionCitiPolicy {

    private final CatalogoTransacciones cat;          // WKS-PT-* cargados de S080BD01CON (cat. 6)
    private final P150Properties props;               // listas de CVETRAN excluidas / forzadas

    /** 35500-GRABA-ARCHIVO: decide si la clave contable va a CITI y ajusta el saldo corrido. */
    public Decision evalua(Movimiento m, int cvetran, BigDecimal importe, BigDecimal saldo) {
        boolean envia = false;
        int ind408 = cat.ind408(cvetran);

        // Precedencia COBOL: A AND B OR C se evalúa como (A AND B) OR C.
        if ((m.indSis() == 2 && ind408 == 1) || ind408 == 2) {
            envia = true;
            saldo = saldo.subtract(importe);
        } else if (props.cvetranExcluidas().contains(cvetran)) {          // 15,16,1009,1072,2111,2115
            envia = false;
        } else if (cat.indCiti(cvetran) == 1 || cat.indCiti(cvetran) == 2) {
            envia = true;
            switch (Naturaleza.de(cat.afectacion(cvetran), cat.natCont(cvetran))) {
                case CARGO -> saldo = saldo.subtract(importe);
                case ABONO -> saldo = saldo.add(importe);
                case SIN_NATURALEZA -> envia = false;
            }
        }
        if (cvetran > 730 && cvetran < 747) envia = true;                // transferencias 731-746
        if (cvetran == 1009) envia = false;
        boolean graba = envia || (m.indSis() == 1 && cvetran == 1072);
        return new Decision(graba, saldo);                                 // saldo viaja en RMC-SALDO
    }
}

    public Optional<AlrRecord> map(RegistroCiti rmc, Cuentas c, long contador) {
        if (rmc.indSis() != 1) return Optional.empty();

            textos.set(2, rmc.leyendaR2());

        } else if (rmc.cvetran() > 730 && rmc.cvetran() < 747) {

@Component
public class ValidacionesCampoCiti {

    private final CatalogoTransacciones cat;

    /** 41210-VALIDA-MON1-ALR: código numérico de moneda CITI. */
    public String ccyNbr(int mon) {
        return switch (mon) {
            case 1 -> "000";                         // MXN
            case 5 -> "126";                         // USD
            default -> throw new MonedaNoMapeadaException(mon);   // COBOL no mueve nada: queda el valor previo
        };
    }

    /** 41210-VALIDA-NATURALEZA-ALR: afectación primero, naturaleza contable después; 731-746 siempre cargo. */
    public char drCr(int cvetran) {
        if (cvetran > 730 && cvetran < 747) return 'D';
        return switch (Naturaleza.de(cat.afectacion(cvetran), cat.natCont(cvetran))) {
            case CARGO -> 'D';
            case ABONO -> 'C';
            case SIN_NATURALEZA -> throw new NaturalezaIndefinidaException(cvetran);
        };
    }

    /** 41210-VALIDA-IMPORTE-ALR: signo separado; cero se informa positivo. */
    public char signo(BigDecimal importe) {
        return importe.signum() < 0 ? '-' : '+';
    }
}

public Optional<OcmRecord> mapOcm(RegistroCiti rmc, Cuentas c) {

            && cat.indCiti(rmc.cvetran()) == 2
            && rmc.instrumento() > 10 && rmc.instrumento() < 16          // instrumentos 11-15

            .dateInput(FechaCiti.ceroMasSeis(rmc.fecOper()))

            .amountChecks(rmc.importe()).checksSign('+')
            .evBranch(filial)
            .txnCode(cat807.codigoCiti(rmc.cvetran()))
            .build());

@Bean
Step concentraAlr(JobRepository repo, PlatformTransactionManager tx, P150Properties props) {
    // 78200 / 78500: VDM y MTY se leen hasta el trailer "END OF FILE" y se acumulan cifras CBII.
    var lector = new MultiResourceItemReaderBuilder<AlrRecord>()
            .name("movsAlrPlazas")
            .resources(props.movsAlr().vdm(), props.movsAlr().mty())
            .delegate(new HastaTrailerReader<>(alrLineReader(), AlrRecord::esTrailerEof))
            .build();
    return new StepBuilder("concentraAlr", repo)
            .<AlrRecord, AlrRecord>chunk(100, tx)                 // BLOCK CONTAINS 100 RECORDS
            .reader(lector)
            .processor(cifrasCbii())                              // WKS-NUM/IMP-CARCBIIT y ABOCBIIT por D/C
            .writer(new SortingItemWriter<>(                      // SORT SD-ALR ON DESCENDING KEY SD-ALR-LLAVE
                    Comparator.comparing(AlrRecord::llaveOrden).reversed(),
                    renumeraPorLlave(alrUniWriter())))
            .build();
}

/** 78610-GENERA-ARCHIVO: CURRENT-NO reinicia en 1 cada vez que cambia la llave. */
ItemWriter<AlrRecord> renumeraPorLlave(ItemWriter<AlrRecord> destino) {
    return chunk -> {
        String anterior = null; int secuencial = 0;
        var salida = new ArrayList<AlrRecord>();
        for (AlrRecord r : chunk) {
            secuencial = r.llaveOrden().equals(anterior) ? secuencial + 1 : 1;
            salida.add(r.conCurrentNo(secuencial));
            anterior = r.llaveOrden();
        }
        destino.write(new Chunk<>(salida));   // al cerrar se agrega AlrRecord.trailer()
    };
}

Riesgos de migración
Precedencia AND/OR en la regla de inclusión

En 35500-GRABA-ARCHIVO (líneas 10852-10857) la condición se evalúa como (IND-SIS = 2 AND IND408 = 1) OR IND408 = 2. Un movimiento de S151 con IND408 = 2 se envía a CITI y resta del saldo sin pasar por las exclusiones ni por la naturaleza contable.

Campos heredados del registro anterior

Las validaciones de moneda y naturaleza (líneas 11312-11359) no tienen rama por defecto. Una moneda distinta de 1 y 5, o una clave sin afectación ni naturaleza, deja en el ALR el valor del movimiento escrito antes.

Ciclo sin fin ante librería S500L020 ocupada

35200-CALL-S500 se repite hasta que W77-BAN-S500 = 1. Los resultados 5 y 17 reinician el contador al octavo intento y siguen esperando 30 segundos (líneas 10772-10784), y el resultado 12 no prende la bandera, por lo que la llamada se repite sin espera (líneas 10786-10793). En ambos casos el paso puede no terminar.

OCM siempre positivo

OCMIN-VALUE-SIGN y OCMIN-CHECKS-SIGN se fijan en '+' (líneas 11185 y 11189) sin considerar el signo de RMC-IMPORTE.

Envío a CITI sin confirmación

CALL SYSTEM WFL lanza el P940 y el programa sigue; el reporte de totales no refleja si la transmisión fue exitosa.

Hardcodes regulatorios

La filial CITI 484 aparece en al menos cinco MOVE del párrafo 41000, el pivote de siglo A2K-BASE-YEAR VALUE 50 en la línea 1603, la ruta (S006)S006/WFL/P940/01MTP001 ON XFER en el driver y las listas de CVETRAN en 35500 y 41000. Se trasladan a application.yml.
