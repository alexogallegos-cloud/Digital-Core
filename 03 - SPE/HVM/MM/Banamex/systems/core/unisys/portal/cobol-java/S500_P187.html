Lee la fecha de línea de B02CONTROL y recorre secuencialmente el dataset B08PCTRARRIBO de S500BD04TARJETAS, donde cada registro es un archivo de captación con su letra de estatus y sus contadores de registros. Según el estatus y la fecha de aplicación escribe el archivo en uno de tres archivos de staging (PROCESADOS, PENDIENTES, RECHAZADOS) con su leyenda, y para los archivos con B07P-LISTADOS entre 1 y 4 y B08P-ENVIO-INTE = 1 crea un archivo de control y lanza P188 por WFL, apagando después la marca de envío. Ordena los tres archivos de staging, genera con Report Writer los reportes por sistema-cliente con totales de registros, OK, rechazados, foráneos y no procesados, y al final espera a que terminen todas las copias de P188 vigilando un horario máximo.

/** WKS-ESTATUS PIC X(01) con sus tres niveles 88 (IBM-CHARITY-2002). */
public enum Categoria { PROCESADO, RECHAZADO, PENDIENTE, SIN_CATEGORIA }

public final class EstatusArchivo {

    private static final Map<Character, Categoria> CATEGORIA = new HashMap<>();
    static {
        for (char c : "DTH".toCharArray())           CATEGORIA.put(c, Categoria.PROCESADO);
        for (char c : "GIJKLMNOPQRSU".toCharArray()) CATEGORIA.put(c, Categoria.RECHAZADO);
        for (char c : "ABCEFVW".toCharArray())       CATEGORIA.put(c, Categoria.PENDIENTE);
    }

    /** Cualquier letra fuera de las tres listas no cae en ningún reporte (comportamiento actual). */
    public static Categoria de(char estatus) {
        return CATEGORIA.getOrDefault(estatus, Categoria.SIN_CATEGORIA);
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class ClasificaArchivosProcessor implements ItemProcessor<ArriboArchivoB08, ArchivoClasificado> {

    @Value("#{jobExecutionContext['fechaLinea']}") private LocalDate fechaOk;   // W88-FEC-OK
    private final ParametroArchivoRepository b07;                              // B07PSXSISCTESEC

    @Override
    public ArchivoClasificado process(ArriboArchivoB08 a) {
        Categoria cat = EstatusArchivo.de(a.estatus());
        boolean delDia = a.fecApl().equals(fechaOk);
        boolean entra = (delDia && (cat == Categoria.PROCESADO || cat == Categoria.RECHAZADO))
                || cat == Categoria.PENDIENTE;               // los pendientes entran sin importar la fecha
        if (!entra) return null;
        return b07.findBySistCteAndSecuencial(a.sistCte(), a.secuencial())
                .map(p -> new ArchivoClasificado(a, p, cat,
                        p.listados() >= 1 && p.listados() <= 4 && a.envioInte() == 1))
                .orElse(null);                                // sin B07: se omite en silencio
    }
}
@Bean
ClassifierCompositeItemWriter<ArchivoClasificado> stagingWriter(
        FlatFileItemWriter<ArchivoClasificado> procesados,    // S500/FILE/P187/PROCESADOS
        FlatFileItemWriter<ArchivoClasificado> pendientes,    // S500/FILE/P187/PENDIENTES
        FlatFileItemWriter<ArchivoClasificado> rechazados) {  // S500/FILE/P187/RECHAZADOS
    var w = new ClassifierCompositeItemWriter<ArchivoClasificado>();
    w.setClassifier(a -> switch (a.categoria()) {
        case PROCESADO -> procesados;
        case PENDIENTE -> pendientes;
        case RECHAZADO -> rechazados;
        case SIN_CATEGORIA -> throw new IllegalStateException("filtrado en el processor");
    });
    return w;
}

/** Totales por archivo, por sistema-cliente y del reporte. Contadores PIC 9(10). */
public record Cuadre(long archivos, long totReg, long procesados, long ok,
                     long rechazados, long foraneos, long noProcesados) {

    static Cuadre de(ArchivoProcesado a) {
        long noProc = a.totReg() - a.regProc();               // COMPUTE WS-REG-NPROCESADOS
        if (noProc < 0) {
            throw new CuadreInvalidoException(a, "REG-PROC mayor que TOT-REG");
        }
        return new Cuadre(1, a.totReg(), a.regProc(), a.regOk(), a.regRech(), a.regFor(), noProc);
    }

    Cuadre mas(Cuadre o) {
        return new Cuadre(archivos + o.archivos, totReg + o.totReg, procesados + o.procesados,
                ok + o.ok, rechazados + o.rechazados, foraneos + o.foraneos,
                noProcesados + o.noProcesados);
    }
}

/** Equivale a BEGIN JOB ...; START <lote>("ESPECIAL P188/<mtp> <param>"); END JOB. */
@Component
@RequiredArgsConstructor
public class LanzadorDetalleP188 {

    private final JobLauncher asyncLauncher;     // START: P187 no espera a P188
    private final Job detalleCaptacionP188;
    private final P187Properties props;

    public JobExecution lanza(ParametrosP188 p) throws Exception {
        return asyncLauncher.run(detalleCaptacionP188, new JobParametersBuilder()
                .addLong("sistCte", props.detalle().sistCteComodin())   // WKS-WFL-SISCTE 9(12)
                .addLong("nodo", (long) p.nodo())                      // WKS-WFL-NODO 9(02)
                .addLong("sec", 0L)                                     // WKS-WFL-SEC
                .addLocalDate("fecha", p.fecha())                      // WKS-WFL-FEC 9(08)
                .addLong("registroControl", (long) p.registro())       // WKS-WFL-REG 9(04)
                .toJobParameters());
    }
}
/** 50000100-REPORTE-DETALLE: un registro de control por archivo y un P188 por registro. */
@Component
@RequiredArgsConstructor
class DetalleP188Writer implements ItemWriter<ArchivoClasificado> {

    private final SolicitudDetalleRepository solicitudes;   // reemplaza A04-PROCDET .../IMPDET/.../ssss
    private final LanzadorDetalleP188 lanzador;
    private final ArriboArchivoB08Repository b08;

    @Override
    public void write(Chunk<? extends ArchivoClasificado> chunk) throws Exception {
        for (ArchivoClasificado a : chunk) {
            if (!a.requiereDetalle() || a.categoria() == Categoria.PENDIENTE) continue;
            // La secuencia ssss (1..9999) servía para encontrar un título libre en disco;
            // con una tabla, la llave es un id generado y no hay tope de 9999.
            SolicitudDetalle s = solicitudes.save(SolicitudDetalle.de(a));   // WRITE REG-ARCHDET
            lanzador.lanza(new ParametrosP188(a.nodo(), a.fechaLinea(), s.id()));
            b08.apagaEnvioInterfaz(a.id());       // 202002-ACTUALIZA-B08: B08P-ENVIO-INTE := 0
        }
    }
}

@Component
@RequiredArgsConstructor
public class EsperaDetallesTasklet implements Tasklet {

    private final SolicitudDetalleRepository solicitudes;
    private final P187Properties props;
    private final Clock reloj;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) throws InterruptedException {
        LocalDateTime inicio = (LocalDateTime) ctx.getStepContext().getJobExecutionContext().get("inicio");
        // 10000050-HORA-INI: si arrancó después de las 19:00 el límite es el día siguiente.
        LocalDate diaLimite = inicio.toLocalTime().isAfter(props.horario().corteDiaSiguiente())
                ? inicio.toLocalDate().plusDays(1) : inicio.toLocalDate();
        LocalDateTime limite = diaLimite.atTime(props.horario().maximo());

        while (solicitudes.countPendientes(ctx) > 0) {          // 60000000-VALIDA-ARCHIVOS
            if (LocalDateTime.now(reloj).isAfter(limite)) {   // comparación por instante, no por fecha igual
                throw new HorarioExcedidoException(
                        "HORARIO MAX DEL P187 SUPERADO LAS COPIAS DEL P188 SE DARAN DE BAJA");
            }
            Thread.sleep(props.horario().sondeo().toMillis());
        }
        return RepeatStatus.FINISHED;
    }
}

Riesgos de migración
Credencial en el fuente

Las líneas 499-502 contienen, comentado, un bloque de la plantilla WFL que asigna ACCESSCODE con usuario y contraseña en claro. No se copió al portal (sustituido por ****). Se recomienda retirarlo del repositorio y rotar la credencial.

Espera sin límite de P188

60000000-VAL-FINXHORARIO solo detiene el programa si la fecha de máquina es igual a WKS-FEC-TERMINO; si la espera pasa a otro día, P187 sigue sondeando cada 10 segundos indefinidamente. Al superar el horario no cancela las copias de P188 aunque el mensaje lo diga.

Errores DMSII tratados como fin de datos

El recorrido de B08 termina con cualquier WS-STATUS-BASE > 0, y 202002-ACTUALIZA-B08 pone el status en cero aunque el LOCK haya fallado. Un error de base puede truncar los reportes o dejar la marca de envío encendida sin aviso.

Estatus sin categoría

Cualquier letra fuera de las listas, incluido un estatus nuevo que agregue el pipeline, no pertenece a ninguna de las tres listas de niveles 88 y no aparecen en ningún reporte, lo que rompe el cuadre del universo de archivos.

Hardcodes de horario y rutas

Horas 19:00 y 10:00, sistema-cliente comodín 999999999999, familia CAPTACION, prefijos S500/FILE/P187 y leyendas de estatus están compilados. Se trasladan a application.yml.
