P060 · Servidor ECO Transit (S500)

S500ProgramaCOBOL

Fuente: P060.cbl (382 LOC · 17 párrafos propios + 12 COPY-PRO) · Rol: servidor XATMI/TransIT de larga vida · MTP: 25MTP002 · BC-16

Convenciones: nombres traducidos (Unisys→legible); [P060 Lnnnnnn] = número de secuencia COBOL cols 1-6; (BR: RN-S500-xxx) = regla de negocio. Párrafos COPY-PRO marcados con [COPY-PRO: S500/INC/PRO/25MTP002] — lógica inferida de la interfaz visible en fuente; no se expande el copybook.

1. Resumen funcional

P060 (PROGRAM-ID: S500P060, escrito diciembre 2019) es el servidor ECO Transit del sistema S500 — captación bancaria Banamex. Es un proceso de larga vida (servidor XATMI/TransIT) que expone dos servicios de consulta en línea: S500_Con_Cto_{M|V} (datos de contrato de captación) y S500_SdoParNac_{M|V} (saldo para nación), donde el sufijo geográfico se determina en arranque leyendo el hostname del equipo (MTY=_M, VDM=_V). Al iniciarse, establece conexión con SOPORTECOMS, resuelve los títulos dinámicos de las librerías via CTLVERS, registra los dos service designators en el bus TransIT y entra en un bucle permanente esperando mensajes con timeout fijo de 60 segundos. Por cada mensaje válido: valida que el buffer sea de tipo X_OCTET, despacha a la librería S500L020CONTRATO o S500L020SDOPARNAC según el designador recibido, y responde vía TP_Return con hasta 2000 bytes. La terminación es ordenada: TP_SvcStart devuelve código 14 (señal de shutdown del administrador TransIT), se activa EOJ y el programa ejecuta STOP RUN sin interrumpir el mensaje en curso. (BR: RN-S500-241, RN-S500-242, RN-S500-243, RN-S500-244, RN-S500-245, RN-S500-246)

4. Lógica por sección

4.1 DECLARATIVAS — Manejador de interrupción HI

PROCEDIMIENTO Manejador_Interrupcion_HI():             // HI-INTERRUPT · [P060 L110800]

  DISALLOW INTERRUPT                                   // bloquea re-entrancia durante manejo
  MOVER ATTRIBUTE TASKVALUE OF MYSELF → contador_hi   // WS-HI — valor enviado por el operador

  SI contador_hi = 1 ENTONCES                         // ⚠ [HARDCODE-SOSPECHOSO: valor 1 fijo]
    LIMPIAR buffer_mensaje_lj                          // TEXTO-LJ
    CONCATENAR
      "ENVIE SERV: "    + ya_envie_serv               // WS-YA-ENVIE-SERV
      ", PROCESE SERV: " + ya_procese_serv             // WS-YA-PROCESE-SERV
      DELIMITED BY SIZE → buffer_mensaje_lj
    EJECUTAR 00000000-DISPLAY                          // imprime estadísticas operativas
  FIN SI

  CHANGE ATTRIBUTE TASKVALUE OF MYSELF → 0            // consume el evento (reset)
  ALLOW INTERRUPT                                      // reactiva interrupción
