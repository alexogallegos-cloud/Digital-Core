P179 · Consolidación de Movimientos Aplicados MTY+VDM para S111 (S500)

S500ProgramaCOBOL

Fuente: P179.cbl (489 LOC) · Batch nocturno post-aplicación · BC-06

Convenciones: nombres traducidos (Unisys→legible); [P179 Lnnnn] = línea fuente (cols 1-6); (BR: RN-S500-NNN) = regla de negocio.

COPY compartidos: WS de S500/INC/WOR/25MTP004 (vars comunes), procedimientos de S500/INC/PRO/25MTP005 (versiones, LOCSUP, mensajes).

1. Resumen funcional

P179 (PROGRAM-ID: S500P179) es el programa de consolidación que une los archivos de movimientos aplicados generados de forma independiente en dos centros geográficos — Monterrey (MTY, CSI 04) y Valle de México (VDM, CSI 10) — en un único archivo de respuesta hacia el sistema S111. Opera como el punto de convergencia del ciclo de retroalimentación distribuida: cada CSI aplica sus movimientos y P179 los concatena en una sola confirmación para que S111 reconcilie contrato por contrato. Antes de procesar, verifica la bandera de decomiso WS-B02-DECOM-S111 consultando el dataset DMSII S500B02CONTROL; si la bandera es activa (≠ 0), el programa termina sin abrir ningún archivo. Los registros de entrada y salida tienen longitud fija de 40 caracteres, y el archivo de salida incluye header (tipo 00), detalle (tipos distintos de 00 y 99) y trailer (tipo 99) con conteo de registros leídos.

2.1 Archivos FILE-CONTROL

Nombre lógicoAsignaciónDirecciónDescripción

Todos los archivos comparten los mismos atributos físicos MCP:

  • BLOCK CONTAINS 360 RECORDS
  • RECORD CONTAINS 40 CHARACTERS (PIC X(040)) — contrato de interfaz inter-sistema
  • VALUE OF AREAS 1000 / AREASIZE 720
  • SECURITYTYPE PUBLIC / PROTECTION PROTECTED

2.2 Etiquetas de archivo (títulos MCP — hardcodes)

VariableValor prefijoSufijo dinámico

2.3 Layout de registro de trabajo WKS-REG-S111-ENVIO (40 bytes total)

02 WKS-S111-TIP-REG       PIC 9(002)          -- tipo: 00=header, 99=trailer, else=detalle
02 WKS-S111-HEADER         (38 bytes, REDEFINES con DETALLE y TRAILER)
   03 WKS-S111-HDR-FECHA   PIC 9(008)          -- fecha del proceso AAAAMMDD
   03 WKS-S111-HDR-SIS-ORI PIC X(004)          -- sistema origen (hardcode "S500")
   03 WKS-S111-HDR-SIS-DES PIC X(004)          -- sistema destino (hardcode "S111")
   03 WKS-S111-HDR-CSI-ORI PIC 9(002)          -- CSI origen (hardcode "10" en header de salida)
   03 FILLER               PIC X(020)
02 WKS-S111-DETALLE REDEFINES WKS-S111-HEADER
   03 WKS-S111-DET-TARJETA  PIC 9(016)         -- número de tarjeta
   03 WKS-S111-DET-CONTRATO PIC 9(012)         -- número de contrato
   03 WKS-S111-DET-SUC-PROM PIC 9(004)         -- sucursal promotora
   03 FILLER               PIC X(006)
02 WKS-S111-TRAILER REDEFINES WKS-S111-HEADER
   03 WKS-S111-TRL-NUM-REG  PIC 9(008)         -- número de registros detalle
   03 FILLER               PIC X(030)
