Fuente: p160.cbl (2106 LOC) · Batch diario conciliación · BC-11

Convenciones: nombres traducidos (Unisys→legible); [P160 Lnnnnnn] = origen en cols 1-6 del fuente; (BR: RN-S500-xxx) = regla de negocio.

1. Resumen funcional

P160 (PROGRAM-ID: COMPARATIVO, versión JUN/2006) es el reconciliador de saldos del ciclo batch nocturno de Captación S500. Recorre el dataset de Inversiones (B03CONTRATOS) contrato por contrato, recalcula el saldo esperado del Histórico sumando el saldo de fin de corte más hasta 31 días de depósitos menos retiros (B06HISTORICO), y lo contrasta contra el saldo actual del contrato. Los contratos que no cuadran se graban en un archivo intermedio (FILE-SALDOS), que se sortea por producto y se imprime en dos listados: uno de diferencias contrato a contrato (FILE-COMPARA · "S500-P160-CHECASAL") y otro de posición consolidada por producto (FILE-POSICION · "S500-P160-CHECAPOS"). En paralelo, para los contratos de copia 1, genera el archivo Motor (E01-MOTOR) con la fecha de último movimiento por cliente, insumo obligatorio del siguiente paso P189. El programa corre en hasta 3 copias simultáneas; cada copia procesa la partición de productos que B05INSTRUMEN le asigna mediante el campo B05-PROCESA-COPIA. La adición ESS/STEF del 2020-05-27 incorporó un cuarto archivo de incidentes (I03-ARCH-INCIDENTE) que registra diferencias entre B09 vs B03 vs B05 para auditoría de paso.

PROCEDIMIENTO Abrir_BD_y_Determinar_Copia():                    // 20000010-OBT-COPIA · [P160 L498050]
  ABRIR DMSII S500BD01CAPTACION MODO UPDATE
  SI excepción AL ABRIR
    MENSAJE "ERROR AL ABRIR LA BASE"
    ABORTAR con DMTERMINATE

  POSICIONAR S500B00CTRLPASO AL INICIO
  EJECUTAR LOCK B00CTRLPASO
  SI WS-STATUS-BASE > 0
    SI = 1 → MENSAJE "ERROR B00CTRLPASO VACIO" · ABORTAR
    SINO   → MENSAJE "ERROR AL HACER LOCK A B00CTRLPASO {status}" · ABORTAR

  // Leer parámetros de Motor y tasa desde B00
  MOVER B00-CARGA-MOTOR  A indicador_gen_motor      // WKS-IND-GEN-MOTOR
  MOVER B00-FECH-ART61   A fecha_art61              // WKS-FEC-ART61
  MOVER B00-TASA-FIX     A tasa_fix_decimal         // WKS-TASA-FIXDEC

  // Determinar número de copia (1, 2 ó 3) según estado de pasos
  SI B00-NUM-PASO-01=155 Y B00-NUM-PASO-02=155 Y B00-NUM-PASO-03=155
    MOVER 1 A número_copia      // WS-COPIAP160
    MOVER 0 A B00-NUM-PASO-01
  SINO SI (B00-NUM-PASO-01=0 ó 160) Y B00-NUM-PASO-02=155 Y B00-NUM-PASO-03=155
    MOVER 2 A número_copia
    MOVER 0 A B00-NUM-PASO-02
  SINO SI (B00-NUM-PASO-01=0 ó 160) Y (B00-NUM-PASO-02=0 ó 160) Y B00-NUM-PASO-03=155
    MOVER 3 A número_copia
    MOVER 0 A B00-NUM-PASO-03
  SINO
    MENSAJE "ERROR SECUENCIA DE PROCESOS, PASO-01={x}, PASO-02={x}, PASO-03={x}"
    ABORTAR con DMTERMINATE
  ⚠ [HARDCODE-SOSPECHOSO] Valores 155 y 160 codificados; 155 = paso previo P155 completado.

  // Grabar B00 con la copia asignada (quitar bandera 155 del paso propio)
  EJECUTAR BEGIN-TRANSACTION
  EJECUTAR STORE B00CTRLPASO
  EJECUTAR END-TRANSACTION SYNC
