S500 · P117 a Java 21 Spring Boot

P117 recibe un parámetro de 12 posiciones con la estructura a tratar, la opción y, para las opciones 2 y 3, una fecha. Obtiene la fecha de proceso de S500B02CONTROL proyectándola con LOCSUP, salvo que la fecha venga en el parámetro. Para la estructura 17 borra las alertas de S500B17PCTLALERTA en estatus 2 de la fecha proyectada; para la 56 vacía toda la bitácora S500B56MAKERCHEK a un archivo temporal, lo ordena por sucursal y estatus y emite el listado maker-checker con cortes por SIRH. Con las opciones 1 y 3 genera además el archivo SDOSBNE y lo envía por INTELAR; como la invocación del tratamiento de S500B18PENVIOSDOS está comentada, hoy ese archivo solo lleva header y trailer.

/** WS-PARAM-VALUE X(12): estructura 9(02), opción 9(02), fecha 9(08). */
public record P117Parametros(Estructura estructura, int opcion, Optional<LocalDate> fecha) {

    public enum Estructura { B17, B18, B56, AMBAS }          // 88 WS-88-P-VAL-EST-OK 17,18,56,99

    public boolean generaReporte() { return opcion == 1 || opcion == 3; }   // WS-88-P-VAL-REPS
    public boolean depura()        { return opcion == 1 || opcion == 2; }   // WS-88-P-VAL-DEPU
    public boolean fechaExterna()  { return opcion == 2 || opcion == 3; }   // WS-88-P-VAL-CONF

    public static P117Parametros parse(String raw) {          // JobParameter "param", 12 caracteres
        Estructura est = switch (raw.substring(0, 2)) {
            case "17" -> Estructura.B17;
            case "18" -> Estructura.B18;
            case "56" -> Estructura.B56;
            case "99" -> Estructura.AMBAS;
            default   -> throw new ParametroInvalidoException("ESTRUCTURA NO VALIDA = " + raw.substring(0, 2));
        };
        int opc = Integer.parseInt(raw.substring(2, 4));
        if (opc < 1 || opc > 3) {
            throw new ParametroInvalidoException("OPCION NO VALIDA = " + raw.substring(2, 4));
        }
        long fec = Long.parseLong(raw.substring(4, 12));
        if (opc != 1 && fec == 0) {
            throw new ParametroInvalidoException("FECHA ES REQUERIDA = " + raw.substring(4, 12));
        }
        Optional<LocalDate> f = (fec == 0) ? Optional.empty()
                : Optional.of(LocalDate.parse(raw.substring(4, 12), DateTimeFormatter.BASIC_ISO_DATE));
        return new P117Parametros(est, opc, f);
    }
}
@Component
@StepScope
@RequiredArgsConstructor
public class FechaProyectadaTasklet implements Tasklet {

    private final ControlCaptacionRepository control;   // S500B02CONTROL
    private final CalendarioBancario calendario;         // reemplaza LOCSUP
    @Value("#{jobParameters['param']}") private String param;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        var b02 = control.findControl().orElseThrow(() ->
                new ProcesoAbortadoException("ERR FIND B02CONTROL"));            // CALL SYSTEM DMTERMINATE
        var p = P117Parametros.parse(param);
        // LOCSUP función 15, formato 13, desplazamiento 2 (comentario: "PROYECTA T-2").
        LocalDate proyectada = p.fechaExterna()
                ? p.fecha().orElseThrow()                                         // MOVE WS-PARAM-VALUE-FEC
                : calendario.retrocede(b02.fechaLinea(), 2)
                        .orElseThrow(() -> new ProcesoAbortadoException("ERR CALL LOCSUP"));
        var exec = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        exec.put("fechaProyectada", proyectada);
        exec.put("csi", b02.numCsi());              // WS02-NUM-CSI: entra en el título de los archivos
        exec.put("fechaLote", b02.fechaLote());     // WS02-FECHA-LOTEA
        return RepeatStatus.FINISHED;
    }
}
@Bean
Job depuracionP117(JobRepository repo, Step fechaProyectada, Step drenaMakerChecker,
                   Step reporteMakerChecker, Step depuraAlertasB17, Step cierraYEnviaSdosbne,
                   JobExecutionDecider porEstructura) {
    // cierraYEnviaSdosbne siempre cierra el job; solo envía si la opción es 1 o 3, porque
    // 10000007-OPEN-ARCH abre SDOSBNE con WS-88-P-VAL-REPS sin importar la estructura.
    return new JobBuilder("S500P117", repo)
            .start(fechaProyectada)
            .next(porEstructura)
                .on("B56").to(drenaMakerChecker).next(reporteMakerChecker).next(cierraYEnviaSdosbne)
            .from(porEstructura)
                .on("AMBAS").to(drenaMakerChecker).next(reporteMakerChecker)
                            .next(depuraAlertasB17).next(cierraYEnviaSdosbne)
            .from(porEstructura)
                .on("B17").to(depuraAlertasB17).next(cierraYEnviaSdosbne)
            .from(porEstructura)
                .on("B18").to(cierraYEnviaSdosbne)   // 20000100-PROCESO-B18 está comentado en el fuente
            .end()
            .build();
}

@Component
@StepScope
@RequiredArgsConstructor
public class DepuraAlertasProcessor implements ItemProcessor<AlertaB17, AlertaB17> {

    private final AlertaB17Repository alertas;               // S500BD04TARJETAS.S500B17PCTLALERTA
    private final TotalesDepuracion totales;                  // WS-TOTAL-DEP OCCURS 30
    @Value("#{jobExecutionContext['fechaProyectada']}") private LocalDate fechaProyectada;

    @Override
    @Transactional(propagation = Propagation.REQUIRES_NEW)    // BEGIN/END-TRANSAC-NOAUD por registro
    public AlertaB17 process(AlertaB17 a) {
        if (a.estatus() == 2 && a.fechaMaquina().equals(fechaProyectada)) {
            totales.leido(a.fechaMaquina());                   // 20000011-REGISTRA-TOTAL-B17
            alertas.delete(a);
            totales.depurado(a.fechaMaquina());
        }
        return null;                                           // no hay salida a archivo
    }
}

// Al terminar el step (ON NOTFOUND): 20000012-IMPRIME-MSJ-B17
@AfterStep
ExitStatus mensaje(StepExecution se) {
    log.info(totales.depurados() == 0
            ? "NO EXISTEN REGISTROS PARA LA FECHA : " + fechaProyectada
            : "REGISTROS DEPURADOS EN S500B17PCTLALERTA: " + totales.depurados());
    return se.getExitStatus();
}

public class EnviosSaldosProcessor implements ItemProcessor<EnvioSaldoB18, RegistroTemporal> {

    private final EnvioSaldoB18Repository envios;
    @Value("#{jobExecutionContext['fechaProyectada']}") private LocalDate fechaProyectada;

    @Override
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public RegistroTemporal process(EnvioSaldoB18 e) {
        sdosbneWriter.detalle(e);                              // 20000098-GENERA-DET-ARCHSDOS
        if (e.estatusEnvio() == 2 && !e.fechaTransaccion().isAfter(fechaProyectada)) {
            envios.delete(e);                                  // ya enviado: se totaliza y se borra
            return RegistroTemporal.depurado(e);               // MUEVE-TEMP-1, tipo 1
        }
        if (e.estatusEnvio() == 1) {
            return RegistroTemporal.pendiente(e);              // MUEVE-TEMP-3, tipo 3: se conserva
        }
        return null;
    }
}

Riesgos de migración
Depuración de S500B18PENVIOSDOS desactivada

En 20000000-PROCESO (líneas 1032-1033) el PERFORM 20000100-PROCESO-B18 está comentado. Con las opciones 1 y 3 el programa abre el archivo SDOSBNE (y con la estructura 18 también el listado 001REPSALDOS), escribe header y trailer en ceros y lo envía por INTELAR, sin leer ni depurar la B18. Las reglas RN-S500-372 y RN-S500-373 describen código que hoy no corre.

La bitácora maker-checker se borra con cualquier opción

20000100-PROCESO-B56 (líneas 1257-1264) no consulta la opción del parámetro: con la opción 3, que en S500B17 y S500B18 significa solo reporte, también elimina todos los registros de S500B56MAKERCHEK. Tampoco filtra por fecha.

Evidencia de auditoría dependiente de un archivo temporal

Cada registro de la B56 se borra y se escribe al temporal TEMP02 dentro de la misma transacción DMSII, pero el archivo no es transaccional. Si el paso cae después de cerrar transacciones y antes del CLOSE WITH SAVE de la línea 1263, la bitácora de quién capturó y quién autorizó se pierde.

Contador del trailer con subíndice del registro anterior

En 20000098-GENERA-DET-ARCHSDOS (líneas 1319-1322) se suma 1 a WS-TOTAL-ARCHSDOS(I02-DET-EST-ENVIO) antes de mover el estatus del registro actual. El subíndice proviene del contenido previo del área del registro (en el primer detalle, del header), y la tabla solo tiene 2 ocurrencias. Hoy no se ejecuta porque la B18 está comentada; reactivarla expondría el error.

Estatus de renglón heredado en el listado

20000123-CONT-STATUS-MOVS solo asigna FINALIZADO (2) o EN PROCESO (1). Un registro con otro estatus conserva en WS-DT-STATUS el texto del renglón anterior, porque la limpieza de la línea 1860 es sobre P01-R-ARCMAKRCHECK y no sobre la línea de detalle.

Envío INTELAR sin abortar y tabla de fechas acotada

Si INTELARSND falla tres veces solo se emite un mensaje para envío manual. Los totales por fecha de depuración usan WS-TOTAL-DEP OCCURS 30 sin guarda de desborde.
