1. Resumen funcional

PROYFECHA (PROGRAM-ID lógico "P001", paso "008" del ecosistema S151) es un utilitario de proyección de fechas del proceso diario contable (PD) del libro mayor (GL) de Banamex sobre Unisys ClearPath MCP. Recibe por LINKAGE un número de función (W77-FUN-PROY) y un número de sistema (WKS-SISTEMA) y, según la función, avanza / retrocede las fechas de proceso y consulta del sistema en la base de control S151BD99CONTROL (vía librería LIB-CONTROL), recalcula el arreglo circular de 10 niveles de archivos de movimientos, purga niveles y totales por clave de trayectoria obsoletos, y genera los archivos de salida vacíos dimensionados (L01-MOVTOS, L02-DESCRIP, L03-CBII, L04-CTDR) que consumirán los pasos posteriores del WFL LOTE (BD10MOVDIA151). Se apoya en la librería de calendario bancario THECALENDAR IN LOCSUP (S006) para toda aritmética de días hábiles/naturales.

Es un componente "diseño genérico" (HEUR/DEC S151): una sola pieza de código que se instancia por sistema; lee WKS-SISTEMA para saber a qué sistema atiende (500, 264, 403, 404, 711, 335, 151, 999, …). Incluye lógica de Alta Disponibilidad (B05, modificación 15MTP001 / IBM 20-ENE-2015) y un bloque de conversión de fechas Y2K CRONOS 2000 (copybooks CPBAS WS/PD).

```
MOVER WKS-SISTEMA → num_sistema (W77-NUMSIS), copias back-up y de reporte

EJECUTAR Procedure_Display()                        // abre reporte de bitácora
MOVER 1 → indicador_archivo ; imprimir "INICIO PROCESO S<sistema> FECHA <fecpro> FN <funcion>"

SI num_sistema > 0:
   SI num_sistema = 999:  seguir              // 999 = "todos los sistemas", caso especial

      EJECUTAR Dame_Esquema()                       // 01-0112: valida esquema contable del sistema

MOVER fecha_proceso_control → fecha_hoy

SI num_sistema = 999:                               // ── rama sistema-global ──
   SI funcion = 2:
      MOVER fecpro → fecha_actual, fecha_busca, fecha_hoy, fecha1
      EJECUTAR Proyecta_Fecha()                      // 01-0130
   SINO: imprimir "FUNCION INVALIDA PARA EL SISTEMA <num>" (051001)
SINO SI funcion = 0 O 2:                             // ── proyección normal ──

   MOVER fecpro_B05_aux → fecpro_B05

SINO SI funcion = 5: EJECUTAR Liga_L002(); MOVER 0023 → func_del; EJECUTAR Llama_L002()  // (func 23)

SINO:                                                // función inválida
   imprimir "NUMERO DE FUNCION INVALIDA" (cod 05100) ; LLAMAR "LJ IN LIB-DISP" ; ABORTAR

CANCEL "CTLVER" ; CERRAR reporte ; STOP RUN.
```
