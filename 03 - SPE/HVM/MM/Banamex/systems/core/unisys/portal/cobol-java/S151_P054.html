Se registra en COMS y espera eventos, mensajes, timeout o interrupciones del operador; a los mensajes solo responde CONSULTA NO DISPONIBLE. En cada vuelta retoma desde el último registro procesado de A01-MOVS500, guardado en el archivo de control A03-CTL-ENVIO, y clasifica cada movimiento: los de función 1 que S500 marca para Red Extendida generan un detalle en el archivo de pesos o de dólares y una autorización en A05-AUTORIZACIONES; los de función 2, 21 y 22 cancelan autorizaciones previas. Cuando la hora alcanza el corte vigente escribe los trailers con cargos, abonos y no contabilizados, envía ambos archivos por INTELARSND y limpia los totales del control. Al llegar al corte 9999 termina.

@Component
@RequiredArgsConstructor
class CorteScheduler {

    private final GeneradorRedExtendida generador;   // 030300-GENERA-ARCHIVO
    private final Clock clock;
    private LocalDate fechaAnterior;                 // WKS-FECHA-MAQ-ANT-8D

    /** Reemplaza el despertar de ESPERACOMS: cada vuelta intenta generar, haya o no mensaje. */
    @Scheduled(fixedDelayString = "${p054.ciclo.espera:PT60S}")
    void despierta() {
        LocalDate hoy = LocalDate.now(clock);
        if (!hoy.equals(fechaAnterior)) {
            fechaAnterior = hoy;
            // El fuente calcula W77-HABIL con THECALENDAR FUN 18, pero ningún párrafo lo consulta.
            // No se traduce como condición para no introducir un comportamiento que P054 no tiene.
        }
        generador.generaYEnviaSiCorresponde(hoy);
    }
}
@Service
@RequiredArgsConstructor
class CortesEnvio {

    private final CatalogoCortes catalogo1822;   // WKS-HORA-CORTE OCCURS 1000, HHMM
    private int indiceVigente;                    // W77-IND-ENV, persistido en A03-CTL-ENVIO

    /** 030302-VERIFICA-ENVIO. */
    Decision evalua(LocalTime ahora, boolean envioPendiente) {
        Optional<LocalTime> corte = catalogo1822.corte(indiceVigente);   // vacío = 9999
        if (corte.isEmpty()) {
            return Decision.TERMINA_DIA;          // MOVE 1 TO WKS-ARCH-GEN y 999999-FIN
        }
        boolean alcanzado = !ahora.truncatedTo(ChronoUnit.MINUTES).isBefore(corte.get());
        return (alcanzado || envioPendiente) ? Decision.GENERA_Y_ENVIA : Decision.SOLO_GENERA;
    }
}
@MessagingGateway
interface IntelarGateway {
    @Gateway(requestChannel = "intelarSalida")
    void envia(Path archivo);                        // INTELARSND IN ADMONXFERS
}

@Service
@RequiredArgsConstructor
class EnvioRedExtendida {

    private final IntelarGateway intelar;
    private final ControlEnvioRepository control;     // A03-CTL-ENVIO

    @Transactional
    void envia(ArchivosCorte archivos) {
        intelar.envia(archivos.pesos());
        intelar.envia(archivos.dolares());
        // Solo si ambos envíos terminaron se limpian trailer y totales (400021-LIMPIA-*).
        // En el fuente un error de INTELAR se registra en LJ y la limpieza ocurre igual.
        control.limpiaTotalesYAvanzaCorte();
    }
}

Riesgos de migración
Día hábil calculado y nunca usado

W77-HABIL se asigna en las líneas 2327-2329 y 2881-2883 pero ningún IF lo consulta. P054 genera y transmite archivos de Red Extendida sin importar si el día es hábil.

Envío fallido sin reintento

Un error de INTELARSND solo se registra en LJ (líneas 3179-3186). Después el programa limpia trailer y totales y avanza al siguiente corte.

Truncamiento del importe del detalle

El importe del movimiento es PIC 9(16)V99 COMP y el del detalle EXTNET PIC 9(14)V99; el MOVE de la línea 3728 trunca los dígitos altos sin aviso.

Lógica de eliminación comentada

En 400040-MUEVE-DATOS-ELIM-EXTNET (líneas 3427-3452) la obtención de naturaleza y la transformación de claves están comentadas; toda eliminación sale con clave 534 y naturaleza 9.

Índices sin validar en el catálogo 1823

WKS-CAT1823-* tiene OCCURS 5000 y se indexa con la clave de transacción sin validar el rango (líneas 3394-3408 y 3432).

Hardcodes

Sucursal 4000, caja 01 para CSI 32 y 10, clave 1009 como abono, clave 534 con naturaleza 9 para eliminaciones, monedas 1 y 5 y el centinela de corte 9999. Se trasladan a application.yml.
