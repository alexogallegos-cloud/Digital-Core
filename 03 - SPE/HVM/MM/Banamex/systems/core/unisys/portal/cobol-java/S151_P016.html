Recibe como parámetro fecha y sistema, consulta en L001/CONTROL el pack del LOG del día y carga desde CPPS el catálogo de claves y naturalezas contables, los límites de alarma y la tabla de CPAE por sucursal. Abre dos veces el mismo LOG (bloques de 145 y de 2 registros), recupera los totales que ya existían en S151B01TOTPROD y lee el archivo por llave relativa hasta la función 99. Cada movimiento con función 1 suma sus hasta cinco slots a una tabla en memoria de 3,000 combinaciones; la función 2 revierte el movimiento original. Cada 100 transacciones escribe la tabla en BIFIN, y cada slot cuyo importe excede el límite configurado genera un registro en S151B03ALARMAS.

@Component
@RequiredArgsConstructor
public class VentanaOperativa {

    private final AcumuladorProperties props;
    private final Clock clock;

    /** Si ya pasó la hora límite, el proceso termina con mensaje y no hace nada. */
    void validaHoraLimite() {
        LocalTime ahora = LocalTime.now(clock);
        if (ahora.isAfter(props.horaLimite())) {
            throw new FueraDeVentanaException("ESTE PROCESO NO PUEDE CORRER DESPUES DE LAS "
                    + props.horaLimite().format(DateTimeFormatter.ofPattern("HHmm")) + " HRS.");
        }
    }

    /** 000020-VALIDA-INICIO: WAIT(20) hasta pasar la hora de inicio; se reemplaza por una espera programada. */
    void esperaHoraInicio(BooleanSupplier terminar) throws InterruptedException {
        while (!LocalTime.now(clock).isAfter(props.horaInicio()) && !terminar.getAsBoolean()) {
            Thread.sleep(Duration.ofSeconds(20));
        }
    }
}

/**
 * ItemReader que sigue un archivo que otro proceso sigue escribiendo (L002 REGISTRAS).
 * L01-DATOS (bloque de 145) recorre lo acumulado; L02-DATOS (bloque de 2) lee la cola
 * reciente sin datos viejos en buffer. Aquí basta un acceso por posición con relectura.
 */
@Component
@StepScope
@RequiredArgsConstructor
public class LogTailItemReader implements ItemStreamReader<MovimientoLog151> {

    private final LogDiarioRepository log;     // LOG del día; en el to-be, tabla o tópico Kafka
    private final VentanaOperativa ventana;
    private final AcumuladorProperties props;
    private long llave;                        // W77-LLAVE: número de registro relativo

    @Override
    public MovimientoLog151 read() throws InterruptedException {
        while (true) {
            if (ventana.pasoHoraLimite() || senales.terminar()) return null;   // W77-SW-FIN = 9 / HI4
            Optional<MovimientoLog151> m = log.leePorPosicion(llave + 1);
            if (m.isPresent() && m.get().funcion() != 99) { llave++; return m.get(); }
            Thread.sleep(props.esperaSinDatos());          // WAIT UNTIL W77-TIME
            // Cada 24 esperas el fuente cierra y reabre los dos archivos para ver el crecimiento.
        }
    }

    @Override public void update(ExecutionContext ctx) { ctx.putLong("llave", llave); }   // reinicio
    @Override public void open(ExecutionContext ctx)   { llave = ctx.getLong("llave", nivelEnBifin()); }
}
@Component
@StepScope
@RequiredArgsConstructor
public class FiltroMovimientos implements ItemProcessor<MovimientoLog151, MovimientoLog151> {

    private final AcumuladorProperties props;   // exclusiones: [{sistema: 500, tipos-proceso: [40, 41, 42, 43]}]

    @Override
    public MovimientoLog151 process(MovimientoLog151 m) {
        if (props.excluido(m.sistema(), m.tipoProceso())) return null;   // filtro Teletón (sistema 500)
        return switch (m.funcion()) {
            case 1 -> m.origen() == 1 || m.origen() == 2 ? m : null;     // alta: solo orígenes 1 y 2
            case 2 -> m;                                                  // eliminación: se revierte
            default -> null;                                              // cualquier otra función
        };
    }
}

public enum Naturaleza { CARGO, ABONO, NINGUNA;

    static Naturaleza de(SlotContable s, int formatoCatalogo, CatalogoClaves cat) {
        int clave = s.claveTransaccion();
        int nat = (formatoCatalogo == 3 && (s.esquemaContable() == 1 || s.esquemaContable() == 2)
                   && cat.tipoMovimiento(clave) != 1)
                ? cat.naturaleza2(clave)        // WKS-CAT-NATCON2
                : cat.naturaleza(clave);        // WKS-CAT-NATCON

    }

                    switch (Naturaleza.de(s, formatoCatalogo, catalogo)) {

                        case ABONO -> { t.numAbonos--; t.impAbonos = restaNoNegativa(t.impAbonos, s.importe()); }
                        case NINGUNA -> { }
                    }
                }
            }

    }

    private static BigDecimal restaNoNegativa(BigDecimal a, BigDecimal b) {
        BigDecimal r = a.subtract(b);
        if (r.signum() < 0) throw new TotalNegativoException(a, b);
        return r;

    void evalua(MovimientoLog151 m, SlotContable s, Naturaleza nat, LlaveAlarma llave) {
        LimitesAlarma lim = limites.get(llave);
        if (lim == null || nat == Naturaleza.NINGUNA) return;
        boolean excede = switch (nat) {
            case ABONO -> s.importe().compareTo(lim.limiteAbono()) > 0;
            case CARGO -> s.importe().compareTo(lim.limiteCargo()) > 0;
            default -> false;
        };
        if (excede) {
            alarmas.save(Alarma.de(m, s, nat == Naturaleza.ABONO ? 2 : 1));   // CVE-ALARM 2 abono, 1 cargo
        }
    }

Riesgos de migración
Pérdida de importes al dar de alta una combinación

En 001800-MVE-TABLA cada slot pone en cero el lado contrario de la misma entrada nueva. Si el primer movimiento de una combinación trae cargo y abono, solo sobrevive el último slot.

Reversa asimétrica

La suma usa NATCON o NATCON2 según formato y tipo de movimiento; la resta de 001720 usa siempre NATCON. Si las columnas difieren, una eliminación descuadra cargos y abonos.

Acumuladores sin signo y sin control de capacidad

Los totales 9(14)V99 COMP y los contadores 9(06) COMP no tienen signo ni ON SIZE ERROR, y la tabla de 3,000 entradas no valida su límite.

Frecuencia de escritura distinta a la documentada

El encabezado dice cada 10 minutos; el código escribe cada 100 transacciones. Entre escrituras, las consultas en línea a BIFIN ven totales atrasados.
