L020 · S151LIB020 — Librería de Movimientos y Saldos (S151)

S151LibreríaCOBOL

Fuente: COBOL_L020.cbl (2712 LOC) · librería SHAREDBYRUNUNIT · BC-L020

Convenciones: nombres traducidos (Unisys→legible); [L020 Lnnnn] = línea absoluta del archivo fuente; (BR: RN-S151-NNN) = regla de negocio.

1. Resumen funcional

S151LIB020 es la librería central de escritura de movimientos y actualización de saldos del sistema S151 (Banamex — Cuenta de Cheques / Ahorro). Opera como librería MCP de tipo SHAREDBYRUNUNIT TEMPORARY: se carga una sola vez por unidad de ejecución y es compartida por todos los tasks de esa run-unit, optimizando el acceso a las bases DMSII de movimientos (MOVDB) y saldos (SDODB).

La interfaz es un único punto de entrada con un registro de 540 bytes (WKS-MOV-DATOS) que describe el movimiento a registrar. El campo WKS-MOV-FUNCION controla el modo de operación: función 0 = inicialización (apertura de bases, carga de tabla de claves de transacción), funciones 1 y 2 = alta o baja de movimiento con actualización inmediata de saldos diarios y mensuales por contrato (datasets B20/B21) y posición por CSI (datasets B70/B71), cualquier otra función = grabación de nivel en metadata de la base.

La librería da soporte a múltiples sistemas llamadores (S500, S555, S087, S084, S403, S404, S701, S702, S252, S264, etc.) mediante redefiniciones polimórficas del área de datos adicionales.

2.3 Estructura de interfaz WKS-MOV-DATOS (540 bytes, WITH LOWER-BOUNDS) (BR: RN-S151-1064)

Campos clave:

  • WKS-MOV-FUNCION PIC 9(02): función (0=init, 1=alta, 2=baja, otros=graba-nivel)
  • WKS-MOV-SISTEMA PIC 9(04): sistema llamador
  • WKS-MOV-PRODUCTO / WKS-MOV-INSTRUMENTO: clasificación del producto financiero
  • WKS-MOV-CONTRATO PIC 9(16): clave de contrato
  • WKS-MOV-SUCPROM PIC 9(04): sucursal promotora
  • WKS-TAB-CVEIMP OCCURS 5: 5 slots de transacción contable (CVETRAN+INDLEY+ESQCON+IMPORTE) (BR: RN-S151-1065)
  • WKS-MOV-FECCONT PIC 9(08): fecha de contabilidad (AAMM en redefinición)
  • WKS-MOV-AUT-S151 PIC 9(08): número de autorización S151 (last read level)
  • WKS-MOV-REFNUM PIC 9(20): referencia numérica — redefinido por sistema llamador (BR: RN-S151-1066)
  • WKS-MOV-FIL-FUTURO PIC X(07): extensión sistema-específica (BR: RN-S151-1067)
  • WKS-MOV-DATOS-ADIC PIC X(354): datos adicionales por aplicación (BR: RN-S151-1068)
  • WKS-MOV-IND-CONTA, WKS-MOV-IND-EDOCTA, WKS-MOV-IND-DATOS-ADIC: indicadores de estado (BR: RN-S151-1069)

2.4 Variables de control de estado (WORKING-STORAGE)

  • W77-OPEN-SDO / W77-OPEN-MOV: indicador de base abierta (0=cerrada, 1=abierta, 2=error/vacía)
  • W77-ACT-SDO / W77-ACT-MOV: indicador de acción requerida (0=ninguna, 1=actualizar, 2=solo nivel)
  • W77-NIV-MOVOK/MOVIN/MOVER: contadores de nivel (OK/INFO/ERROR) del archivo MOVDB
  • W77-D: índice del día dentro del ciclo diario de archivos
  • W77-TAB-APUNCVES OCCURS 9999: tabla de apuntadores CVE→posición en tabla de afectaciones
  • WKS-TAB-AFECSDOS OCCURS 5000×6: tabla de afectaciones por clave de transacción

2.5 Estructura de mensaje de log (MENSAJE-LJ)

Formato: {SISTEMA-LJ}/{PASO-LJ}/{MTP-LJ}:{TIPO-LJ}>{CODIGO-LJ}<{TEXTO-LJ} — enviado mediante CALL "LJ IN LIB-DISP". Inicializado en 999999-DISPLAY-INICIO: SISTEMA-LJ="S151", PASO-LJ="L020", MTP-LJ="002".

```
// Inicializa la librería: obtiene títulos de control de versiones, consulta
// config sistema B03, abre SDODB y MOVDB, carga tabla de claves de transacción,
// obtiene datos del host CSI.

// --- Versión de librería ESTRUCTURA ---
CAMBIAR ATRIBUTO LIBACCESS DE "CTLVER" A BYFUNCTION
CAMBIAR ATRIBUTO FUNCTIONNAME DE "CTLVER" A "CTLVERS"
MOVER "S080BD01CON" A identificador_libreria  // WKS-LIBID  ⚠ [HARDCODE: S080BD01CON]
LLAMAR "DAME_TIT IN CTLVER" USANDO id_lib, nombre_lib DANDO resultado_ctlver  // W77-ERR-CTLVER
SI resultado_ctlver = 0
   CAMBIAR ATRIBUTO TITLE DE "ESTRUCTURA" A nombre_lib

// --- Versión de librería LIB-CONTROL ---
MOVER 0 A resultado_ctlver
MOVER "S151L001CTL" A identificador_libreria  // ⚠ [HARDCODE: S151L001CTL]
LLAMAR "DAME_TIT IN CTLVER" USANDO id_lib, nombre_lib DANDO resultado_ctlver
SI resultado_ctlver = 0
   CAMBIAR ATRIBUTO TITLE DE "LIB-CONTROL" A nombre_lib
SINO
   codigo_log = 020901; mensaje = "ERROR EN CTLVERS, NO ENCONTRO ID DE LIB-CONTROL "
   EJECUTAR 999999-DESPLIEGA
   SET MYSELF(STATUS) TO -1  // Aborta la run-unit
FIN-SI

// --- Consultar configuración del sistema (B03SISMEN) ---
MOVER sistema_movimiento A config_b03_sistema  // WKS-B03-SISTEMA
MOVER 1 A config_b03_funcion                   // WKS-B03-FUNCION = 1 (consulta)
LLAMAR "CONSISMEN IN LIB-CONTROL" USANDO config_b03 DANDO estado
SI estado > 0
   codigo_log = 020901; mensaje = "ERROR AL CONSULTAR B03 LIB-CONTROL : " + estado
   EJECUTAR 999999-DESPLIEGA
   SET MYSELF(STATUS) TO -1
FIN-SI

// --- Abrir base de SALDOS ---
MOVER "BASE DE SALDOS " A nombre_base_error_dmsii
SI nombre_bd_saldos = ESPACIOS  // WKS-B03-NOMBDSAL
   mensaje = "NO EXISTE BD DE SALDOS SISTEMA " + sistema_movimiento
   EJECUTAR 999999-DESPLIEGA
SINO
   MOVER 1 A indicador_sdo_abierta  // W77-OPEN-SDO
   MOVER nombre_bd_saldos A nombre_sdo_bd  // WKS-NOM-SDOBD → título dinámico

      EN EXCEPCION → EJECUTAR 900000-CHECA-STATUS

SI base_saldos_abierta = 1

      EN EXCEPCION → EJECUTAR 900000-CHECA-STATUS

      EN EXCEPCION → EJECUTAR 900000-CHECA-STATUS

// --- Sincronizar W77-ULT-LEC y WKS-MOV-AUT-S151 desde LECARCDIA ---
// Día de contabilidad: W77-D ← WKS-MOV-FECCONT-DD (día del mes)
SI sistema = 500 O 555

      SI B00-SDO-LECARCDIA(dia) = B00-MOV-LECARCDIA(dia)
       Y B00-SDO-MOVCICDIA(dia) = B00-MOV-MOVCICDIA(dia)

         MOVER B00-MOV-LECARCDIA(dia) A aut_s151
```

PROCEDIMIENTO Carga_ClavesTransaccion():     // 230100-CARGA-CVES · [L020 L001325]
```
// Llama a L710 del S080 para obtener tabla de afectaciones por clave de transacción.
// (BR: RN-S151-1062, RN-S151-1063) — Cada llamada recupera hasta 1 entrada.

LLAMAR "L710_CONSUL_DETALLE IN ESTRUCTURA"
   USANDO sistema_l710, programa_l710, parametros_entrada_l710, parametros_salida_l710
   DANDO resultado_l710  // W77-L710-RESULT

SI resultado_l710 = 0 O 1   // 0=último, 1=hay más
   // Actualizar llaves para siguiente iteración
   MOVER dato_salida_1 A llave1_l710
   MOVER dato_salida_2 A llave2_l710
   MOVER dato_salida_3 A llave3_l710
   MOVER nivel_ini_sal A nivel_ini_l710
   MOVER fec_ini_sal   A fec_ini_l710

   // Registrar la clave si pertenece al sistema actual
```
