P017 · Receptor de Respuestas de Protección de Cobros (S151)

S151ProgramaCOBOL

Fuente: COBOL_P017.cbl (1936 LOC) · Servidor COMS online · BC-06

Convenciones: nombres traducidos (Unisys→legible); [P017 Lnnnn] = nº de línea en el fuente; (BR: RN-...) = regla registrada en KB.

1. Resumen funcional

P017 (PROGRAM-ID S151-P017, compilado desde 21MTP002) es un servidor COMS (online) del sistema S151 que escucha permanentemente el canal de mensajes COMS-IN esperando respuestas de confirmación provenientes del sistema S702 (CBII — CIMS Bancario Interbancario). Su función exclusiva es recibir el resultado de un movimiento de protección de cobros por domiciliación que P016 u otro paso previo envió a S702 y actualizar el registro correspondiente en la base de datos DMSII S151BD13BIFIN.

El programa soporta tres subtipos de mensaje (discriminados por WKS-SA0-TRN-DSCOD): 001 — confirmación de cargo por fecha/contrato en dataset B07PROTCOB; 002 — confirmación de cargo por cliente en B07PROTCOB; 003 — confirmación de cargo domiciliado en dataset B10DOMI. Para cada subtipo bloquea el registro correspondiente (LOCK), lo actualiza con el nuevo estado (B07-STATUS / B10-STATUS = dirección de la respuesta) y el número de error recibido, y confirma la transacción DMSII. El ciclo se repite hasta recibir señal HI de terminación o DISABLE externo.

El programa también gestiona rotación del archivo de despliegue (L01-DISPLAY) a 6 500 registros, encendido/apagado de monitor (L02-MONITOR) vía HI, y validación de cambio de día contable en timeouts del COMS.

2.4 Layouts de mensaje (WORKING-STORAGE)

WKS-REG-MSG (534 bytes) — mensaje COMS expandido:

  • WKS-HDR-MSG — cabecera de mensaje (prefijo, aplicación destino/origen, CSI, LSN, station, CCR, facultad, WKS-HDR-RSLTDO PIC 9(02) con 88s: TERM=11/12, APLI=02/04, REDFOR=12, MAS=3, TER=1, ERR=31/32/33)
  • WKS-SA0 — área de servicios A0: TRN-DEST (sistema+código+subcódigo), TRN-ORIG (sistema+código+subcódigo), DIRECCION (88: ALTA=1, RESP=2, BAJA=3, RES-BAJA=4), LONG, TIEMPO-ESPERA, RESPUESTA

  • WKS-AREA-MSG-OBL-SERV1 (DSCOD=001): CONTRATO(16) + CVEMDA(4) + MDA-SUC(4) + MDA-CTA(16) + AUTORIZA(8) + REFNUM(12) + AUT-S151(8) + FECMOV(6) + CVETRAN(4) + OCCUR(2) + IMPORTE(14V2) + ERROR(4) + FILLER(309)

       └─ 000A-BEGIN-INTERRUPT           ← captura HI; despacha según tipo

000000-PRINCIPAL SECTION

       ├─ PERFORM 100000-INICIO
       ├─ PERFORM 200000-PROCESO  UNTIL W77-FIN = 1
       ├─ PERFORM 800010-CIERRA-BD

100000-INICIO
  ├─ 020200-TASKFILE              ← fecha máquina + taskfile
  ├─ 020500-COMS                  ← inicializa canal COMS, DCILIBRARY, agenda salida, CSI
  ├─ 020400-LIBRERIAS             ← liga CTRLVERS, LOCSUP, LIB-DISP; obtiene fecha proceso S500
  ├─ 020650-OPN-TSKFILE           ← configura OPTION=1926 y FILECARDS del taskfile
  ├─ 020600-DISPLAY               ← abre L01-DISPLAY (EXTEND si existe, OUTPUT si no)
  ├─ 100400-CHECA-VERS            ← valida versión 21MTP002 vs librería CTLVERS
  └─ 700100-ABRE-BD UNTIL ok o > 6 intentos   ← OPEN UPDATE S151BD13BIFIN

200000-PROCESO  (loop principal)
  ├─ 200600-COMS-RECEIVE          ← ESPERACOMS(20s); RECEIVE COMS-IN; routing por tipo evento
  │    ├─ timeout  → 202000-VALIDA-FEC-ACTUAL
  │    ├─ HI-4/6  → 060700-DISPLAY + 999999-FIN
  │    └─ msg/evento → RECEIVE + 060950-ESCRIBE-MONITOR
  └─ 201000-PROCESA-MSG-PC        ← routing por DSCOD
       ├─ DSCOD=001 → 700300-BUSCA-REG-B07SXFECHA
       │                └─ si encontrado: 060960-BEGIN-TRANS + 030203-ACTUALIZA-B07-RES + 060970-END-TRANS
       ├─ DSCOD=002 → 700300-BUSCA-REG-B07SXCTE
       │                └─ si encontrado: 060960-BEGIN-TRANS + 030203-ACTUALIZA-B07-RES + 060970-END-TRANS
       └─ DSCOD=003 → 700300-BUSCA-B10SXFECAUT151
                        └─ 700301-PROCESA-DOMI
                             └─ si encontrado: 060960-BEGIN-TRANS + 030203-ACTUALIZA-B10-RES + 060970-END-TRANS

030203-ACTUALIZA-B07-RES
  └─ 700200-ALMACENA-REG          ← STORE S151B07PROTCOB

030203-ACTUALIZA-B10-RES
  └─ 700200-ALMACENA-REG-B10      ← STORE S151B10DOMI

8000000-DMTERMINATE
  └─ 060700-DISPLAY + log LJ + 8500000-ERROR-FATAL
       └─ SYSTEMERROR / OPENERROR / CLOSEERROR / AUDITERROR / VERSIONERROR → 700020-DS

Utilidades:
  060700-DISPLAY   ← escribe línea en L01-DISPLAY (rota cada 6500 registros)  ⚠ [HARDCODE-SOSPECHOSO]
  060900-APAGA-MONITOR ← cierra L02-MONITOR
  060800-ENCIENDE-MONITOR ← abre L02-MONITOR (OUTPUT)
  800100-HI-SALIDA ← log LJ "terminación normal/emergencia" antes de 999999-FIN
  999999-FIN       ← DISABLE PROGRAM via SMCOMS OF SOPORTECOMS
  800010-CIERRA-BD ← CLOSE S151BD13BIFIN + L01-DISPLAY + apaga monitor
  020700-CLOSE-DISPLAY ← rota L01-DISPLAY (cierra con SAVE, reabre OUTPUT)
  010300-IMP-DISPLAY ← genera mensaje "MSG RECIBIDO REG NO LOCALIZADO" condicional
  700020-DS        ← CHANGE ATTRIBUTE STATUS OF MYSELF TO -1 (abort)
  900000-FIN-MAL   ← error COMS crítico → log LJ + 999999-FIN
