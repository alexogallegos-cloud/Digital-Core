Recibe el sistema en WKS-SISTE-PARAM, obtiene la fecha de proceso con CONSISDIA y, en modo de alta disponibilidad, consulta B05PROCESOS para no repetir una corrida ya terminada. Carga del catálogo paramétrico S080 la naturaleza contable de cada clave de transacción (catálogo 1059 para los sistemas CFR y 523 para el resto) y, solo para el sistema 18, la tabla de CPAE por sucursal operadora. Lee el log por llave relativa y, para cada movimiento con función 1, estatus 1 y origen 1 o 2, suma número e importe de cargos y abonos por llave producto, instrumento, moneda y CPAE. Al encontrar la función 99 vuelca la tabla a S151B05BATCH en una transacción no auditada, actualizando o creando un registro por llave.

/** W77-RPIMC: producto 9(04) + instrumento 9(02) + moneda 9(02) + CPAE 9(04) = PIC 9(12). */
public record ClavePimc(int producto, int instrumento, int moneda, int cpae) {

    public ClavePimc {
        // MOVE A00-R01-MONEDA (9(04)) TO W77-MONEDA (9(02)) conserva solo los dos dígitos bajos
        moneda = moneda % 100;
    }

    public String texto() { return "%04d%02d%02d%04d".formatted(producto, instrumento, moneda, cpae); }
}

/** WKS-TOT-PRDINST + WKS-TOT-ABO + WKS-TOT-CGO: tres OCCURS 3000 indexados en paralelo. */
public final class TotalesPimc {
    private static final BigDecimal TOPE_14V2 = new BigDecimal("99999999999999.99");
    private long numCargos, numAbonos;                                  // 9(06) COMP
    private BigDecimal impCargos = BigDecimal.ZERO.setScale(2),         // 9(14)V99 COMP
                       impAbonos = BigDecimal.ZERO.setScale(2);

    void cargo(BigDecimal imp)  { numCargos++; impCargos = tope(impCargos.add(imp)); }
    void abono(BigDecimal imp)  { numAbonos++; impAbonos = tope(impAbonos.add(imp)); }

    boolean tieneMovimiento() {                                         // 002010-BUSCA-TAB-TOT
        return numCargos > 0 || numAbonos > 0 || impCargos.signum() > 0 || impAbonos.signum() > 0;
    }

    /** ADD sin ON SIZE ERROR perdería los dígitos altos; aquí se falla. */
    private static BigDecimal tope(BigDecimal v) {
        if (v.compareTo(TOPE_14V2) > 0) throw new DesbordamientoAcumuladorException(v);
        return v;
    }
    // getters
}

@Configuration
public class AcumuladorJobConfig {

    /** 000000-INICIO-PROCESO. El sistema llega como parámetro del job (WKS-SISTE-PARAM). */
    @Bean
    Job acumuladorPimc(JobRepository repo, Step fechaProceso, JobExecutionDecider yaProcesado,
                       Step cargaCatalogos, Step acumulaLog, Step marcaTerminado) {
        return new JobBuilder("S151P152", repo)
                .start(fechaProceso)                          // 000040: CONSISDIA, pack del log
                .next(yaProcesado)                            // 010000-VERIFICA-B05
                    .on("TERMINADO").end()                    // STAPGM <> 0: STOP RUN sin procesar
                .from(yaProcesado).on("*").to(cargaCatalogos) // 000180-PROCESA-CATALOGOS
                .next(acumulaLog)                             // 001300-PROC-LOGS hasta función 99
                .next(marcaTerminado)                         // 010200-ACTUALIZA-B05, STAPGM = 1 (solo sin fecha forzada)
                .end()
                .build();
    }

    /** Solo cuando la tarea no trae fecha forzada (TASKVALUE = 0) se consulta B05PROCESOS. */
    @Bean
    JobExecutionDecider yaProcesado(LibreriaControl libCtl) {
        return (job, step) -> {
            var p = job.getJobParameters();
            if (p.getLocalDate("fechaForzada") != null) return new FlowExecutionStatus("PROCESAR");
            var r = libCtl.b05Procesos(1, p.getLong("sistema").intValue(), 152, fechaProceso151(job));
            if (r.ok() && r.estatusPrograma() != 0) return new FlowExecutionStatus("TERMINADO");
            if (!r.ok()) libCtl.b05Procesos(19, ...);         // 010100-CREA-B05: alta del control
            return new FlowExecutionStatus("PROCESAR");
        };
    }
}

/** 000200-CARGA-CATALOGO + 000245-INIC-VAR-CAT2: cabecera y formato del catálogo. */
@Component
@RequiredArgsConstructor
public class CatalogoNaturalezas {

    private final ParametricoS080Client s080;   // L710_CONSUL_DETALLE IN S080BD01CON
    private final P152Properties props;

    public FormatoCatalogo resuelve(int sistema) {
        var cfg = props.catalogos();
        var consulta = cfg.sistemasCfr().contains(sistema)
                ? ConsultaS080.alfanumerica(cfg.cfr(), "S" + "%03d".formatted(sistema))
                : ConsultaS080.numerica(cfg.general(), sistema);
        var cabecera = s080.consulta(consulta.llave2(1).ordenBusqueda(2));
        if (!cabecera.exitosa()) {
            throw new CatalogoS080Exception(consulta.catalogo(), sistema, cabecera.resultado());
        }
        int numCat = cabecera.dato(1, 4), formato = cabecera.dato(1, 5);
        return switch (formato) {
            case 1 -> new FormatoCatalogo(numCat, 1, 2, ConsultaS080.llave2(sistema));
            case 2 -> new FormatoCatalogo(numCat, 2, 1, ConsultaS080.llave1(sistema));
            case 3 -> new FormatoCatalogo(numCat, 3, 1, ConsultaS080.sinLlave());
            case 4 -> new FormatoCatalogo(numCat, 4, 2, ConsultaS080.sinLlave());
            default -> throw new CatalogoS080Exception(               // STATUS OF MYSELF = -1
                    "NUMERO DE FORMATO NO VALIDO EN CAT. DE CAT. S%03d FORMATO %d".formatted(sistema, formato));
        };
    }
}
/** 000450-PREG-TRANS: cada formato guarda clave y naturaleza en columnas distintas. */
public record Naturaleza(int cveTran, int tipMov, int natcon, int tipMov2, int natcon2) {

    static Optional<Naturaleza> de(int formato, RenglonS080 r, Naturaleza previa) {
        return switch (formato) {
            case 1 -> valida(r.col(11)) ? Optional.of(new Naturaleza(r.col(1), 0, r.col(11), 0, 0)) : Optional.empty();
            case 2 -> valida(r.col(11)) ? Optional.of(new Naturaleza(r.col(2), 0, r.col(11), 0, 0)) : Optional.empty();
            case 3 -> {
                if (!valida(r.col(6))) yield Optional.empty();
                // Formato 3: TIP-MOV = 1 es la naturaleza primaria; cualquier otro, la secundaria.
                // La otra mitad se conserva del renglón previo de la misma clave (no se limpia).
                yield Optional.of(r.col(2) == 1
                        ? new Naturaleza(r.col(1), r.col(2), r.col(6), previa.tipMov2(), previa.natcon2())
                        : new Naturaleza(r.col(1), previa.tipMov(), previa.natcon(), r.col(2), r.col(6)));
            }
            case 4 -> valida(r.col(4)) ? Optional.of(new Naturaleza(r.col(1), 0, r.col(4), 0, 0)) : Optional.empty();
            default -> Optional.empty();
        };
    }

    private static boolean valida(int nat) { return nat == 1 || nat == 2; }   // 1 cargo, 2 abono
}

/** 000800-CARGA-CPAE + 045500-TRAE-CEPAE: sucursal operadora a CPAE, catálogo 231. */
@Component
@JobScope
@RequiredArgsConstructor
public class CatalogoCpae {

    private final ParametricoS080Client s080;
    private final P152Properties props;
    @Value("#{jobParameters['sistema']}") private int sistema;
    private Map<Integer, Integer> cpaePorSucursal = Map.of();

    @PostConstruct
    void carga() {
        if (sistema == 18) {                                     // p152.cpae.sistemas: [18]
            cpaePorSucursal = s080.leeTodo(props.catalogos().cpae()).stream()
                    .collect(Collectors.toMap(RenglonS080::sucursalOperadora, RenglonS080::cpae,
                                              (primero, otro) -> primero));   // SEARCH toma el primero
        }
    }

    /** Para cualquier otro sistema, o si la sucursal no está, el CPAE es 0. */
    public int cpae(int sucursalOperadora) {
        return cpaePorSucursal.getOrDefault(sucursalOperadora, 0);
    }
}

/** 001300-PROC-LOGS: lee por ACTUAL KEY desde la llave 2; la 1 se lee y no se procesa. */
@Component
@StepScope
@RequiredArgsConstructor
public class LogMovimientosReader implements ItemReader<MovimientoLog> {

    private final LogRelativo log;          // L01-DATOS: SEQUENTIAL, ACCESS RANDOM, ACTUAL KEY
    private final P152Properties props;
    private long llave = 1;                 // W77-LLAVE
    private long fallasConsecutivas;

    @Override
    public MovimientoLog read() {
        while (true) {
            llave++;
            Optional<MovimientoLog> m = log.lee(llave);
            if (m.isEmpty()) {                                    // INVALID KEY: se informa y se salta
                log.warn("ERROR AL LEER LOG DEL S151 CON LA LLAVE : {}", llave);
                if (++fallasConsecutivas > props.maxFallasLectura()) {
                    throw new FinDeLogNoEncontradoException(llave);   // el COBOL seguiría para siempre
                }
                continue;
            }
            fallasConsecutivas = 0;
            if (m.get().funcion() == 99) return null;            // fin de proceso: dispara el volcado
            return m.get();
        }
    }
}

/** Solo el movimiento real efectivo se acumula (RN-S151-856). */
static boolean esEfectivo(MovimientoLog m) {
    return m.funcion() == 1 && m.status() == 1 && (m.origen() == 1 || m.origen() == 2);
}
/** 001710-ACUMULA-CVES: decide cargo o abono para una imputación. */
static Optional<Sentido> sentido(int formato, Naturaleza n, int esquemaContable) {
    if (n == null) return Optional.empty();
    int nat;
    if (formato == 3 && (esquemaContable == 1 || esquemaContable == 2)) {
        if (n.tipMov() == esquemaContable)       nat = n.natcon();    // naturaleza primaria
        else if (n.tipMov2() == esquemaContable) nat = n.natcon2();   // naturaleza secundaria
        else                                     return Optional.empty();
    } else {
        nat = n.natcon();
    }
    return switch (nat) {
        case 1 -> Optional.of(Sentido.CARGO);
        case 2 -> Optional.of(Sentido.ABONO);
        default -> Optional.empty();
    };
}

/** Recorre las hasta cinco imputaciones y suma en la llave del movimiento. */
void acumula(MovimientoLog m, TotalesPimc t) {
    for (var imp : m.vigentes()) {                                 // hasta CVETRAN = 0
        sentido(formato, naturalezas.get(imp.cveTran()), imp.esquemaContable())
            .ifPresent(s -> { if (s == Sentido.CARGO) t.cargo(imp.importe()); else t.abono(imp.importe()); });
    }
}
/** 001500-GUARDA-TABLA + 001600 + 001800: un Map sustituye la búsqueda lineal. */
@Component
@StepScope
@RequiredArgsConstructor
public class AcumuladorPimcWriter implements ItemWriter<MovimientoLog> {

    private final Map<ClavePimc, TotalesPimc> tabla = new LinkedHashMap<>();   // orden de alta
    private final CatalogoCpae cpae;
    private final P152Properties props;

    @Override
    public void write(Chunk<? extends MovimientoLog> chunk) {
        for (MovimientoLog m : chunk) {
            if (!esEfectivo(m)) continue;
            var clave = new ClavePimc(m.producto(), m.instrumento(), m.moneda(), cpae.cpae(m.sucursalOperadora()));
            var t = tabla.get(clave);
            if (t == null) {
                var nuevo = new TotalesPimc();
                acumula(m, nuevo);
                // 001860-INCR-INDICE: la llave solo se da de alta si alguna imputación sumó
                if (nuevo.tieneMovimiento()) {
                    if (tabla.size() >= props.maxLlaves()) throw new CapacidadPimcExcedidaException(props.maxLlaves());
                    tabla.put(clave, nuevo);
                }
            } else {
                acumula(m, t);
            }
        }
    }
}

Riesgos de migración
Errores de STORE ignorados

En 031000-STORE-B05 la rama ON EXCEPTION asigna 0 a W77-NO-ERROR, el mismo valor que indica éxito. Los totales de una llave pueden no persistirse sin ningún aviso.

Ciclo sin fin si falta la función 99

001300-PROC-LOGS solo termina con W77-END-LOGS = 1, que se enciende con la función 99. Una lectura fallida solo se informa y se pasa a la llave siguiente, por lo que un log sin ese registro deja al paso leyendo indefinidamente.

Subíndices y capacidades sin validar

La tabla de totales tiene 3,000 posiciones y la de naturalezas 10,000, sin comparación contra el índice. W77-INDICE es PIC 9(04) y trunca claves de catálogo de 5 o más dígitos.

Truncamientos en la llave y en importes

La moneda del log (9(04)) se mueve a un campo 9(02) de la llave y los importes 9(16)V99 se suman en acumuladores 9(14)V99 sin ON SIZE ERROR.

Volcado sin auditoría

El volcado se hace con BEGIN-TRANSACTION NO-AUDIT: si el paso se interrumpe a la mitad, la recuperación depende del reinicio y no hay pista de auditoría DMSII de los registros modificados.

Hardcodes

Sistemas CFR 203, 404, 707 y 804, catálogos 1059, 523 y 231, sistema 18 para CPAE, pack LOGS por defecto, título (S151)S151/FILE/MOVS y librería de control (S151)S151/OBJECT/L001/CONTROL ON CMEMP. Se trasladan a application.yml.
