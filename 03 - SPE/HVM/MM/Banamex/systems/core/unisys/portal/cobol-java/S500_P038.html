Al arrancar identifica su host para saber su CSI y el del nodo par, carga las librerías de control de versiones, seguridad y soporte COMS, y se queda esperando mensajes. Cada consulta de terminal se valida contra la librería de seguridad S041 y se despacha según una clave de cinco caracteres; si apunta al otro nodo se reenvía por COMS y la respuesta vuelve a la terminal de origen. El operador puede encender un monitor que imprime los mensajes, activar o desactivar la seguridad y dar de baja el programa mediante interrupciones HI. No accede directamente a DMSII; toda la información viene de la librería MAPLI.

@ConfigurationProperties("mapli")
public record MapliProperties(Map<String, Nodo> nodos, Set<String> ambientesPrueba,
                              String cveTranConsulta) {

    /** Una fila de RD-WKS-TABLA-NODOHOST: NODO-ORI 9(02), HOST-ORI X(10), NODO-FOR 9(02), HOST-FOR X(10). */
    public record Nodo(int csi, String par, int csiPar) {
        /** Respuesta de la consulta 140N1: los 24 bytes tal como los devolvía P038. */
        public String comoRespuesta(String host) {
            return "%02d%-10s%02d%-10s".formatted(csi, host, csiPar, par);
        }
    }
}
@Component
@RequiredArgsConstructor
public class NodoActual {

    private final MapliProperties props;
    private final Environment env;

    @Getter private String host;
    @Getter private int csi, csiForaneo;
    @Getter private boolean pruebasInternas;

    @PostConstruct
    void identifica() {
        host = env.getRequiredProperty("mapli.host");             // ATTRIBUTE HOSTNAME OF MYSELF
        var nodo = props.nodos().get(host);
        if (nodo == null) {
            // NO PUEDO RECONOCER EL HOST: P038 se da de baja; aquí falla el arranque del contexto
            throw new IllegalStateException("NO PUEDO RECONOCER EL HOST " + host);
        }
        csi = nodo.csi();
        csiForaneo = nodo.csiPar();
        pruebasInternas = props.ambientesPrueba().contains(host);  // ACYPBETA, VDMBETA, SITBETA
    }
}

@Configuration
@RequiredArgsConstructor
public class MonitorMapliFlowConfig {

    /** 000000-CONTROL-PROGRAMA: INICIO, ciclo de mensajes hasta STATUS 99 y FIN. */
    @Bean
    IntegrationFlow consultasMapli(MessageChannel entradaComs,      // COMS-IN, agenda ONLINE
                                   ConsultaMapliRouter router,
                                   MonitorMensajes monitor) {
        return IntegrationFlow.from(entradaComs)
                .wireTap(monitor.recepcion())                  // 901000-MONITOR-RCV si el monitor está activo
                .filter(DialogoMapli.class, d -> !d.esFinDePrograma(),
                        f -> f.discardChannel("apagadoChannel"))  // COMS-IN-STATUS-KEY = 99
                .route(router)                                 // 300000-RECIBE-MENSAJES
                .get();
    }

    @Bean
    IntegrationFlow apagado(ApplicationContext ctx) {          // 990000-FIN / STOP RUN
        return IntegrationFlow.from("apagadoChannel")
                .handle(m -> SpringApplication.exit(ctx, () -> 0))
                .get();
    }
}
@Component
@RequiredArgsConstructor
public class SincronizadorOperativo {

    private final SeguridadS041 seguridad;
    private final MonitorMensajes monitor;
    private final EstadoOperativo estado;   // banderas que antes cambiaba el HI

    /**
     * 200400-ESPERA-SOPCOMS, primera parte: antes de cada espera P038 alinea el estado real
     * de SEGURIDAD y del monitor con lo pedido por el operador. Con eventos ya no hace falta
     * esperar al siguiente mensaje: se reacciona al cambio.
     */
    @EventListener
    public void onCambioOperativo(CambioOperativo ev) {
        if (seguridad.activa() != estado.seguridadDeseada()) {
            if (estado.seguridadDeseada()) seguridad.carga(); else seguridad.descarga();
        }
        if (monitor.abierto() != estado.monitorActivo()) {
            if (estado.monitorActivo()) monitor.abre(); else monitor.cierra();
        }
    }
}
// ESPERACOMS con timeout de 60 s, eventos 2, 3 y 4 sin acción y "EVENTO NO CONOCIDO" en otro caso:
// lo absorbe el adaptador de entrada; un timeout ya no despierta al servidor.
@Component
@RequiredArgsConstructor
public class ConsultaMapliRouter extends AbstractMessageRouter {

    private final SeguridadS041 seguridad;
    private final Clock reloj;
    private LocalDate fechaCargaSeguridad;                       // WKS-FECMAQ-AMD-S041

    @Override
    protected Collection<MessageChannel> determineTargetChannels(Message<?> m) {
        recargaSeguridadSiCambioElDia();
        var d = (DialogoMapli) m.getPayload();
        return List.of(switch (d.origen()) {
            case TERMINAL -> canal("deTerminal");                // 301000-DE-TERMINAL
            case APLICACION -> d.esConsultaForanea()             // 140S2, 140A2, 140P2, 140L2 y STPRFOR
                    ? canal("deTerminalForanea")                 // W77-ES-FORANEO = 1, resultado 12
                    : canal("errorDialogo");                     // 302000-DE-APLICACION
            case ERROR_APLICACION -> canal("errorAplicacion");   // cve = resultado - 20; invierte CSI
            default -> canal("errorDialogo");
        });
    }

    /** Si cambió la fecha de máquina y ya pasaron las 16:00, se recarga la librería de seguridad. */
    private void recargaSeguridadSiCambioElDia() {
        var ahora = LocalDateTime.now(reloj);
        if (!ahora.toLocalDate().equals(fechaCargaSeguridad) && ahora.toLocalTime().isAfter(LocalTime.of(16, 0))) {
            seguridad.descarga();
            seguridad.carga();
            fechaCargaSeguridad = ahora.toLocalDate();
        }
    }
}
@Component
@RequiredArgsConstructor
public class ConsultaMapliHandler {

    private final ValidadorFacultades s041;
    private final MapliClient mapli;            // S038L035: USERXCSI, AGRUPXUSER, PROGSXAGRUP, ACTIXPROG
    private final NodoActual nodo;

    /** 301000-DE-TERMINAL + 301500-SIGUE-CONSULTA. */
    @ServiceActivator(inputChannel = "deTerminal")
    public DialogoMapli atiende(DialogoMapli d) {
        if (!d.foraneo()) {
            int err = s041.valida(d);                         // 60700000-VALIDA-SEGURIDAD
            if (err > 0) return d.conError(err);              // 301050-MANDA-ERROR
        }
        return switch (d.idClave()) {
            case "140N1"          -> d.responde(nodo.respuestaNodo());          // 400000-NODO-X-HOST
            case "140S1", "140S2" -> consulta(d, mapli::usuariosPorCsi);        // 401000
            case "140A1", "140A2" -> consulta(d, mapli::agrupadoresPorUsuario); // 402000
            case "140P1", "140P2" -> consulta(d, mapli::programasPorAgrupador); // 403000
            case "140L1", "140L2" -> consulta(d, mapli::actividadesPorPrograma);// 404000
            default               -> d.conError(3);           // CLAVE SOLICITUD INVALIDA
        };
    }

    @ServiceActivator(inputChannel = "deTerminalForanea")
    public DialogoMapli atiendeForanea(DialogoMapli d) {
        return atiende(d.marcadoForaneo());                  // sin validación S041: se confía en el nodo origen
    }
}

    private final MessageChannel salidaComs;     // agenda "OUTPUT OF LINEA." + DEFAULTSTATION

    public void enviaForaneo(DialogoMapli d) {
        int destino = nodo.csiForaneo();
        if ("VDMBETA".equals(nodo.getHost()) && estado.rutaAlterna1032()) destino = 32;   // HI 61
        envia(d.conHeader(2, nodo.getCsi(), destino));
    }

    /** 200260-RESPUESTA-TERMINAL: resultado 1 e intercambio de origen y destino. */
    public void respondeTerminal(DialogoMapli d) {
        var r = d.conHeader(1, d.csiDestino(), d.csiOrigen());
        if (r.idCveN1() == 2) r = r.conIdCveN1(1);         // la respuesta foránea viaja como local
        envia(r);
    }

                .build());                                  // SEND COMS-OUT FROM WKS-MENSAJE-DIALOGO
    }

    private final MapliProperties props;

    /** 60700000-VALIDA-SEGURIDAD: 0 si procede; si no, el código de la tabla general (32-41 o 45). */
    public int valida(DialogoMapli d) {
        if (!s041.activa()) return 0;                          // WS-88-S041-SEGURIDAD-ON
        var r = s041.validaFacultad(new SolicitudFacultad(
                "Q0", d.pantalla(), props.cveTranConsulta(),   // "CONSMAPLI"
                1, BigDecimal.ZERO,                            // moneda 1, importe 0
                d.lsnOrigen(), d.estacion(), "S500"));
        int res = r.resultado();
        if (res == 0 || res == 1) return 0;                    // 60702000-S041-NOMINAS
        if (res <= -2 && res >= -11) return 30 - res;          // -2 -> 32 ... -11 -> 41
        log.warn("ERR-S041 ERROR DESCONOCIDO DE SEGURIDAD {}", res);
        return 45;
    }
}

Riesgos de migración
Seguridad desactivable sin control

El HI 10 (líneas 1423-1429) pone en cero la seguridad deseada y, en el siguiente ciclo, se descarga la librería S041. No hay verificación de quién envía el HI y fuera de pruebas internas no se emite mensaje.

Consultas foráneas sin validación local

301000-DE-TERMINAL solo valida facultades cuando W77-ES-FORANEO = 0 (líneas 1896-1903); lo que llega del nodo par se atiende sin consultar S041.

Facultades del día anterior hasta las 16:00

La librería de seguridad solo se recarga cuando cambió la fecha y la hora es mayor a 16:00 (líneas 1833-1839).

Topología compilada en el programa

Los nombres de host y sus CSI están en la tabla WKS-TABLA-NODOHOST (líneas 598-616) y repetidos en 100000-INICIO (líneas 1520-1532). Un servidor nuevo exige recompilar.

Código sin efecto

El bloque posterior al ciclo principal (líneas 1492-1496) es inalcanzable y el estado 97 de 200300-ENVIA-COMS se asigna después del SEND (líneas 1760-1761).

Pendiente de revisión SME
  • El inventario clasifica P038 como A5 Orquestador, pero el fuente es un servidor COMS de consultas en línea sin pasos batch; se tradujo como flujo de Spring Integration. Confirmar el arquetipo con el SME.
  • El inventario no asocia reglas del brain a P038 y el pseudocódigo lo describe como infraestructura sin reglas de negocio; no se usaron IDs de regla.
  • Confirmar el motivo de la hora de corte de las 16:00 para recargar la librería de seguridad.
  • La clave STPRFOR se acepta como consulta foránea (línea 1872) pero no tiene rama de atención; confirmar si es una consulta retirada.
  • Los párrafos de reporte del monitor (900000 a 903050) y los wrappers de MAPLI (2000038-*) no se incluyeron en esta demostración.
