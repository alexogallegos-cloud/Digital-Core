S500 · admwin a Java 21 Spring Boot

admwin declara un par de mensajes COMS, uno vivo y uno de retención, y tres párrafos que el anfitrión ejecuta: al iniciar fija el CSI del nodo según el nombre del equipo; después de cada RECEIVE, si el mensaje viene del paso servidor 70, extrae el mensaje real de la carga; antes de cada SEND, si se cumplen las marcas de línea y el código de resultado, guarda la respuesta y la envuelve en una cabecera nueva dirigida al paso 70. No accede a archivos ni a DMSII y no contiene reglas de negocio; es transporte de mensajes con una treintena de literales de configuración.

/** COMS-MENSAJE: cabecera de 125 posiciones + carga X(2875). Se modela una sola vez. */
public record SobreComs(
        HeaderComs hdr,          // PRE, APLDES, CSIDES, LSN1, LSNSUB, LSN2, STATIP..SEGURIDAD
        DireccionAmp amp,        // DES0, DESSIS, DESPAS, ORI0, ORISIS, ORIPAS
        TransporteSa0 sa0,       // DESAPL..CODRES, incluye LONG y TIMEOUT
        ContextoSa2 sa2,         // ID..VERDAT: sucursal, caja, autorización, fecha, operador
        byte[] datos) {          // COMS-APL-DATOS X(2875)

    public static final int LONG_CABECERA = 125;      // el ADD 125 del SEND
    public static final int LONG_DATOS = 2875;

    public SobreComs {
        if (datos.length > LONG_DATOS) {
            throw new IllegalArgumentException("Carga mayor a " + LONG_DATOS + ": " + datos.length);
        }
        datos = datos.clone();
    }
}

public record DireccionAmp(int destino0, int sistemaDestino, int pasoDestino,
                           int origen0, int sistemaOrigen, int pasoOrigen) {}

    /** 000-ADMWIN-INICIO: cualquier host no listado cae en el CSI por defecto. */
    public int csiDelNodo(String nombreEquipo) {

@Component
@RequiredArgsConstructor
public class AdmwinEnvelope {
    private final AdmwinProperties props;
    private final SobreComsCodec codec;          // parse/format posicional de 3000 posiciones

    /**
     * 000-ADMWIN-RECEIVE. Si el sobre viene del paso servidor (70), el mensaje real viaja
     * en la carga y se promueve; si no, el mensaje se procesa tal cual.
     */
    public SobreComs alRecibir(SobreComs recibido) {
        if (recibido.amp().pasoOrigen() != props.pasoServidor()) {
            return recibido;                                    // no hay ELSE en el fuente
        }
        // MOVE COMS-APL-DATOS(2) TO COMS-MENSAJE(1): las primeras 125 posiciones de la carga
        // son la cabecera del mensaje anidado; las 125 finales del buffer quedan en espacios.
        byte[] interno = Arrays.copyOf(recibido.datos(), SobreComs.LONG_CABECERA + SobreComs.LONG_DATOS);
        Arrays.fill(interno, recibido.datos().length, interno.length, (byte) 0x40);  // espacio EBCDIC
        return codec.parse(interno);
    }
}

/**
 * Condición de 000-ADMWIN-SEND tal como la evalúa COBOL:
 *   (LSN1 = F0 AND LSN2 = 0F AND RESULT = 01) OR RESULT = 03 OR RESULT = 07
 * La indentación sugiere que LSN1/LSN2 aplican a los tres códigos; no es así.
 */
static boolean debeReencapsular(SobreComs m, boolean corregirPrecedencia) {
    HeaderComs h = m.hdr();
    boolean marcasLsn = h.lsn1() == (byte) 0xF0 && h.lsn2() == (byte) 0x0F;
    int r = h.resultado();
    if (corregirPrecedencia) {
        return marcasLsn && (r == 1 || r == 3 || r == 7);      // intención aparente
    }
    return (marcasLsn && r == 1) || r == 3 || r == 7;           // comportamiento actual (AS-IS)
}
// s500.admwin.corregir-precedencia: false hasta que el SME confirme la intención.
    /** 000-ADMWIN-SEND, primera mitad: HDR y AMP del sobre externo. */
    public SobreComs alEnviar(SobreComs respuesta, int csiNodo, int pasoActivo, int longTexto) {
        if (!debeReencapsular(respuesta, props.corregirPrecedencia())) return respuesta;

        HeaderComs r = respuesta.hdr();
        HeaderComs hdr = HeaderComs.builder()
                .pre('F').aplDestino('0')
                .csiDestino(r.csiOrigen())                 // la respuesta regresa al CSI que la originó
                .lsn1((byte) 0xF0).lsnSub(r.lsnSub()).lsn2((byte) 0x0F)
                .estacion(r.tipoEstacion(), r.sucursal(), r.prioridad(), r.caja())   // se arrastra la estación
                .csiOrigen(csiNodo)                        // el 10 o 32 de 000-ADMWIN-INICIO
                .comunicadorOrigen("10").nivelSeguridad("00").aplOrigen('0')
                .resultado(2).pantalla("00000").seguridad("000000")
                .build();
        DireccionAmp amp = new DireccionAmp(0, props.sistema(), props.pasoServidor(),   // 500 -> paso 70
                                            0, props.sistema(), pasoActivo);           // desde el paso 10/20/80
        return envuelve(hdr, amp, respuesta, longTexto);
    }
    private SobreComs envuelve(HeaderComs hdr, DireccionAmp amp, SobreComs respuesta, int longTexto) {
        // ADD 125 TO COMS-OUT-TEXT-LENGTH: acumula sobre lo que dejó el anfitrión. Aquí se calcula.
        int longitud = longTexto + SobreComs.LONG_CABECERA;
        var sa0 = new TransporteSa0(500, 1, 2, 500, 1, 2, /*direccion*/ 2, longitud,
                                    /*timeout*/ 90, /*codRes*/ 0);
        var r = respuesta.hdr();
        var sa2 = new ContextoSa2(0, 'B', 0, 1, 1,
                Integer.parseInt(r.sucursal()), r.prioridad(), r.caja(),
                1L,                       // autorización fija 00000001
                null, null,               // fecha y hora en ceros en el fuente: sin dato real
                1, "0000000000", 'B');    // operador en ceros
        byte[] carga = codec.format(respuesta);                       // 3000 posiciones
        if (carga.length > SobreComs.LONG_DATOS && !esRelleno(carga, SobreComs.LONG_DATOS)) {
            throw new MensajeTruncadoException(carga.length);           // el fuente corta en silencio
        }
        return new SobreComs(hdr, amp, sa0, sa2, Arrays.copyOf(carga, SobreComs.LONG_DATOS));
    }
Riesgos de migración
Precedencia AND/OR en la condición del SEND

IF ... AND ... AND COMS-HDR-RESULT(1) = 01 OR 03 OR 07 (líneas 74-75) se evalúa como (marcas LSN y 01) OR 03 OR 07: con 03 o 07 se re-encapsula sin validar las marcas de línea.

Truncamiento silencioso de la respuesta

MOVE COMS-MENSAJE(2) TO COMS-APL-DATOS(1) (línea 126) copia unas 3000 posiciones en 2875 y descarta las últimas 125.

Longitud acumulativa

ADD 125 TO COMS-OUT-TEXT-LENGTH (línea 108) depende de que el anfitrión reasigne la longitud antes de cada envío; el copybook no lo verifica.

Trazabilidad perdida en el sobre

Fecha, hora y operador del bloque SA2 se envían en ceros y la autorización fija en 1 (líneas 120-124).

Clon divergente en P080

P080 no usa el COPY y replica los párrafos inline; su INICIO solo reconoce VDMBETA (P080 línea 8449) y su SEND mueve CSIDES(2) en lugar de CSIORI(2) a CSIDES(1) (P080 línea 8467).

Hardcodes de infraestructura

Nombres de equipo, CSI 10 y 32, paso servidor 70, sistema 500, comunicador 10, códigos SA0 01 y 002, timeout 90 y versión B. Se trasladan a configuración.

Pendiente de revisión SME
  • Confirmar con el SME si la condición del SEND debía exigir las marcas LSN para los tres códigos de resultado; hasta entonces se conserva el comportamiento actual.
  • Identificar qué componente es el paso servidor 70 de ADMWIN (no hay un P070 en el corpus) para definir el destino equivalente en el broker.
  • Determinar el tamaño en caracteres de los campos 9(02) COMP de la cabecera; la aritmética de 125 posiciones supone uno por campo.
  • Decidir cuál de las dos variantes (copybook o clon de P080) es la vigente para el ruteo de la respuesta antes de consolidarlas en un solo componente Java.
  • MYSELF-USERCODE (líneas 2-4) se declara y, según el pseudocódigo, no se usa en ningún programa; confirmar antes de descartarlo.
