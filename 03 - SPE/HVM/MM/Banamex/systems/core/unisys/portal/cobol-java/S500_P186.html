S500 · P186 a Java 21 Spring Boot

P186 construye un archivo puente con los archivos de traspaso esperados de S500 (tres copias), S084, S087, S264, S111 y el archivo de reactivaciones, proyectando día hábil a día hábil desde la última fecha aplicada hasta la fecha del batch. Ordena esa cola por prioridad y fecha y solo aplica un archivo si su fecha es la consecutiva esperada para su origen. Cada archivo de 140 bytes se valida por header y trailer y sus registros se clasifican por tipo: 3 traspaso a Cuenta Global, 4 reactivación, 5 beneficencia, 7 cambio de estatus y 9 trailer. Los traspasos aceptados actualizan el histórico S500B05PHISCTAGLB y generan un abono de 240 bytes en E02-DISP-S274 con una clave de transacción que depende del sistema origen; las reactivaciones van a un archivo separado, E02-DISP-REAC-S274. Al final emite cifras de control, rechazos, incidentes, el histórico de ligas y actualiza las fechas de control en S500B01PCONTROL.

                        .next(reportaArchivos)

public record ArchivoPendiente(int prioridad, String sistema, LocalDate fecha, String titulo) {}

@Component
@RequiredArgsConstructor
public class ColaArchivosTasklet implements Tasklet {

    private final P186Properties props;
    private final CalendarioBancario calendario;      // LOCSUP formato 12, función 13 u 8
    private final ControlFechasRepository control;    // S500B01PCONTROL: última fecha por origen
    private final ColaPendientesRepository cola;      // reemplaza I03-ARCH-XAPL

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        LocalDate fechaBatch = control.fechaBatch();
        for (var o : props.origenes()) {
            LocalDate f = control.siguienteFecha(o.prioridad());
            if (f == null || f.isAfter(fechaBatch) || o.apagado()) continue;
            // Un registro por día pendiente: incluye la fecha batch y se detiene después de ella.
            while (!f.isAfter(fechaBatch)) {
                cola.save(new ArchivoPendiente(o.prioridad(), o.sistema(), f, o.titulo(f)));
                f = calendario.siguiente(f, o.calendario());
            }
            control.siguienteFecha(o.prioridad(), f);
        }
        return RepeatStatus.FINISHED;
    }
}
/** 50000200-VE-RESIDENCIA: decide qué hacer con cada archivo de la cola, ya ordenada. */
@Component
@RequiredArgsConstructor
public class ResidenciaDecider {

    public enum Decision { APLICAR, SALTADO, RECHAZAR_NO_RESIDENTE, BRINCAR, IGNORAR }

    private final ArchivoStore store;              // RESIDENT OF I01-TRP-CTAGLB
    private final ControlFechasRepository control; // WKS-FEC-xxx-V: fecha consecutiva esperada
    private final DiasNoResidente diasNoResidente;  // 40901150: tolerancia W77-NUM-DIA-BRINCO

    public Decision decide(ArchivoPendiente a) {
        boolean reactivacion = a.titulo().contains("REACTASGLB");
        if (store.existe(a.titulo())) {
            if (a.fecha().equals(control.fechaEsperada(a.prioridad()))) return Decision.APLICAR;
            return reactivacion ? Decision.IGNORAR : Decision.SALTADO;   // no aplica fechas saltadas
        }
        if (reactivacion) return Decision.IGNORAR;    // la reactivación faltante no se reporta
        return diasNoResidente.excedeTolerancia(a)
                ? Decision.BRINCAR                     // 999905000-BRINCA-ARCH
                : Decision.RECHAZAR_NO_RESIDENTE;      // 50000182-RECH-ARCHIVO
    }
}

/** WKS-I01-R03-DATOS (tipo 3) y WKS-I01-R04-DATOS (tipo 4) comparten el mismo layout de 140 bytes. */
public record TraspasoRecord(
        int tipoRegistro,          // 9(01): 3 traspaso, 4 reactivación
        int producto,              // 9(04)
        int instrumento,           // 9(04)
        int moneda,                // 9(02): 1 MN, 5 dólares, 26 euros
        int instOpera,             // 9(02)
        int numInversion,          // 9(06)
        String contratoTarjeta,    // 9(18) como String: conserva ceros
        String numCliente,         // 9(12)
        int sucursalPromotora,     // 9(04)
        LocalDate fechaTraspaso,   // 9(08) AAAAMMDD; 0 = sin fecha
        BigDecimal importeOriginal,// 9(14)V99 escala 2
        BigDecimal importeMn,      // 9(14)V99 escala 2
        BigDecimal tipoCambio,     // 9(04)V9(04) escala 4
        String nombre) {           // X(36)

    static TraspasoRecord parse(String r) {
        return new TraspasoRecord(Fixed.entero(r, 0, 1), Fixed.entero(r, 1, 4),
                Fixed.entero(r, 5, 4), Fixed.entero(r, 9, 2), Fixed.entero(r, 11, 2),
                Fixed.entero(r, 13, 6), r.substring(19, 37), r.substring(37, 49),
                Fixed.entero(r, 49, 4), Fixed.fechaAmdOpcional(r, 53),
                Fixed.decimal(r, 61, 16, 2), Fixed.decimal(r, 77, 16, 2),
                Fixed.decimal(r, 93, 8, 4), r.substring(101, 137));
    }
}
public enum EstadoArchivo { SIN_HEADER_SIN_TRAILER, SOLO_HEADER, SOLO_TRAILER, COMPLETO }   // ARCH-OK 0..3

@Component
@RequiredArgsConstructor
public class ValidadorArchivoTraspaso {

    private final BitacoraIncidentes incidentes;   // I06-ARCH-INCIDENTE

    /** El header se lee en el registro 1 y el trailer en el último; luego se recorre del 2 en adelante. */
    public EstadoArchivo valida(RandomAccessRecords f, ArchivoPendiente a) {
        long ultimo = f.lastRecord() + 1;                  // LASTRECORD + 1: clave relativa del trailer
        int ok = 0;
        var h = f.read(1).map(HeaderTraspaso::parse);
        if (h.isPresent() && h.get().tipo() == 1
                && h.get().sistemaOrigen().equals(a.sistema())
                && "S500".equals(h.get().sistemaDestino())
                && h.get().fecha6().equals(Fixed.aammdd(a.fecha()))) {
            ok += 1;
        }
        if (f.read(ultimo).filter(t -> t.charAt(0) == '9').isPresent()) {
            ok += 2;
        }
        var estado = EstadoArchivo.values()[ok];
        if (estado != EstadoArchivo.COMPLETO) {
            incidentes.registra(a, switch (estado) {
                case SIN_HEADER_SIN_TRAILER -> "ERR HEADER Y SIN TRAILER";
                case SOLO_TRAILER           -> "ERR HEADER Y CON TRAILER";
                default                     -> "ERROR SIN TRAILER";
            });
        }
        return estado;
    }
}
@Bean
ClassifierCompositeItemProcessor<RegistroTraspaso, Salida> procesadorPorTipo(
        TraspasoCuentaGlobalProcessor traspaso,      // 50000550-TRP-A-CTAGLB
        ReactivacionProcessor reactivacion,          // 50000590-REAC-CTA-GLB
        BeneficenciaProcessor beneficencia,          // 50000570-TRP-A-BENEF
        CambioEstatusProcessor cambioEstatus,        // 50000580-MODIF-STATUS
        TrailerProcessor trailer,                    // 50000598-VAL-TRAILER
        RechazoProcessor rechazo) {                  // 50000590-RECHAZO

    var p = new ClassifierCompositeItemProcessor<RegistroTraspaso, Salida>();
    p.setClassifier(reg -> switch (reg.tipo()) {
        case '3' -> traspaso;
        case '4' -> reactivacion;
        case '5' -> beneficencia;
        case '7' -> cambioEstatus;
        case '9' -> trailer;          // el reader termina después del trailer (W77-EOF-I01 = 1)
        default  -> rechazo;          // tipo desconocido: rechazo con W77-ERR-REG = 0
    });
    return p;
}

@Component
@StepScope
@RequiredArgsConstructor
public class TraspasoCuentaGlobalProcessor implements ItemProcessor<RegistroTraspaso, Salida> {

    private final ValidadorTraspaso validador;          // 50000700 y 50000750
    private final HistoricoCuentaGlobalRepository b05p; // S500B05PHISCTAGLB (JPA)
    private final ClienteS016 s016;                     // 50000800-VAL-S016 (L422)
    private final AltaCuentaGlobal alta;                // 50000900 / 50000901-CREA-NUEVO
    private final CifrasControl cifras;                 // 50002400-SUMA-TOTALES
    private final DispersionS274 dispersion;            // 50002200-REG-S274

    @Override
    @Transactional                                      // 50125000-STORE-BASE confirma al final
    public Salida process(RegistroTraspaso reg) {
        var t = TraspasoRecord.parse(reg.raw());
        Optional<Rechazo> r = validador.registro(t).or(() -> validador.sucursal(t));
        if (r.isPresent()) return Salida.rechazo(reg, r.get());

        var hist = b05p.findByOrigen(t);
        r = Reincidencia.evalua(hist);                  // estatus 6: candidato a reincidencia
        if (r.isPresent()) return Salida.rechazo(reg, r.get());

        var contratoS016 = s016.valida(t);
        var cuenta = alta.obtieneOCrea(t, hist, contratoS016);   // producto 66, instr. 90, moneda 1
        cifras.suma(t);
        return Salida.de(
                RegistroS016.de(cuenta),
                dispersion.abono(t, cuenta));            // E02-DISP-S274
    }
}

public class ReactivacionProcessor implements ItemProcessor<RegistroTraspaso, Salida> {

    private final HistoricoCuentaGlobalRepository b05p;
    private final DispersionS274 dispersion;
    private final CifrasControl cifras;

    @Override
    @Transactional
    public Salida process(RegistroTraspaso reg) {
        var t = TraspasoRecord.parse(reg.raw());              // tipo 4, mismo layout que el 3
        var hist = b05p.findByOrigenForUpdate(t)               // B05PXORIG-LOCK
                .orElse(null);
        if (hist == null) return Salida.rechazo(reg, Rechazo.of(13));
        if (hist.estatusBenef() != 3 && hist.estatusBenef() != 5) {
            return Salida.rechazo(reg, Rechazo.of(17));        // solo se reactiva liga pendiente o cancelada
        }
        hist.reactiva();          // estatus 2, fecha e importe de beneficencia en cero
        cifras.suma(t, LlaveTotales.de(t.producto(), t.instrumento(), t.moneda(), 0));
        return Salida.de(
                RegistroS016.reactivacion(hist),
                dispersion.reactivacion(t, hist));             // E02-DISP-REAC-S274, clave 1300
    }
}

Riesgos de migración
Barrido de ligas fuera del IF por un punto

En 00000000-CONTROL-PROGRAMA (líneas 1508-1512) el punto después de MOVE 0 TO W77-EOF-B05P termina el IF WKS-TSK-OPCION = 0. El barrido de S500B05PHISCTAGLB y la escritura de ARCH-HLIG se ejecutan también en la opción 1, en la que ARCH-HLIG no se abre.

Moneda heredada en totales de reactivación

50000590-REAC-CTA-GLB (líneas 3274-3279) no asigna WKS-REG-MONE; la llave de totales usa la moneda del registro procesado antes. Afecta el reporte de cifras de control por producto, no el abono.

Aplicación de archivos con header inválido

50000210-ABRE-ARCHIVO aplica un archivo con estado 2 (header inválido, trailer presente) cuando WKS-ERR-LAST-R es menor que 3. Queda registrado como incidente, pero se aplica.

Hardcodes regulatorios y de ruteo

Claves S274 1181, 1183 a 1186 y 1300, tipo de cuenta 7, prefijos de contrato 9999 y 9998, producto 66 instrumento 90, la chequera de beneficencia WKS-CHEQUERA-BENEF (línea 424) y los nombres de archivo por origen están compilados. Se trasladan a application.yml.

Beneficencia sin abono a S274

La rama de 50002200-REG-S274 para tipo 5 (clave 1182) está comentada. Los traspasos a beneficencia no generan abono en E02-DISP-S274.
