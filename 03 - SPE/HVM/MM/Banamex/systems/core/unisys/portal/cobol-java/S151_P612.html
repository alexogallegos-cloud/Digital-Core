S151 · P612 a Java 21 Spring Boot

P612 recorre los títulos S151/FILE/EJECUCIONWFL/NN. con NN de 01 a 99. Para cada archivo residente lo abre en I-O y lee registros de 60 bytes con opción, nombre de WFL, estatus y parámetro. En el primer registro cuya opción coincide con la recibida y cuyo estatus es 0, arma un comando START (S151) sobre el pack CMEMP, con o sin parámetro entre comillas, lo envía con CALL SYSTEM WFL, marca el estatus en 1 y deja de leer ese archivo. No usa librerías externas ni verifica el resultado del arranque.

/** WKS-START-WFL y WKS-START-WFL2 se reemplazan por una petición de lanzamiento tipada. */
public record LanzamientoWfl(String usercode, String nombre, String pack, Optional<String> parametro) {

    /** Solo para trazabilidad: el texto que el MCP habría recibido. */
    String comandoMcp() {
        return "START (" + usercode + ") " + nombre.strip() + " ON " + pack
               + parametro.map(p -> "(\"" + p.strip() + "\")").orElse("");
    }
}

DispatcherWflService.java@Service · @TransactionalJava 21
@Service
@RequiredArgsConstructor
public class DispatcherWflService {

    private final EjecucionWflRepository repo;
    private final LanzadorWfl lanzador;

    /** 00-0000-CONTROL: PERFORM 00-0050-BUSCA-FILE UNTIL WKS-NFILE = 99. */
    public List<LanzamientoWfl> despacha(String opcion) {
        var lanzados = new ArrayList<LanzamientoWfl>();
        for (int grupo : repo.gruposExistentesOrdenados()) {   // 01..99
            despachaGrupo(grupo, opcion).ifPresent(lanzados::add);
        }
        return lanzados;    // puede haber uno por grupo, no solo uno en total
    }
}
/** 00-0050-BUSCA-FILE: un archivo (grupo) por iteración. */
@Transactional
Optional<LanzamientoWfl> despachaGrupo(int grupo, String opcion) {
    // IF ATTRIBUTE RESIDENT OF A04-WFLS = 0: EXIT PERFORM.
    // Con la tabla, un grupo sin filas simplemente no aparece en gruposExistentesOrdenados().
    return repo.primerPendiente(grupo, opcion, "0")             // 00-0100-LEEARCHIVO
            .map(e -> {
                LanzamientoWfl l = new LanzamientoWfl(props.usercode(), e.nombre, props.pack(),
                        e.parametro == null || e.parametro.isBlank()
                                ? Optional.empty() : Optional.of(e.parametro));
                lanzador.lanza(l);
                e.status = "1";                                // MOVE 1 TO WKS-WFL-STATUS
                return l;                                      // commit = CLOSE A04-WFLS WITH SAVE
            });
}
private final P612Properties props;

public interface EjecucionWflRepository extends JpaRepository<EjecucionWfl, Long> {

    /** IF WKS-WFL-OPCION = WKS-PARAMETRO AND WKS-WFL-STATUS = 0, en orden de lectura. */
    @Lock(LockModeType.PESSIMISTIC_WRITE)
    @Query("""
           select e from EjecucionWfl e
            where e.grupo = :grupo and e.opcion = :opcion and e.status = :status
            order by e.orden
           """)
    List<EjecucionWfl> pendientes(int grupo, String opcion, String status, Pageable una);

    default Optional<EjecucionWfl> primerPendiente(int grupo, String opcion, String status) {
        return pendientes(grupo, opcion, status, PageRequest.of(0, 1)).stream().findFirst();
    }
}
@Component
@RequiredArgsConstructor
class LanzadorWfl {

    private final TaskLauncher launcher;   // Spring Cloud Data Flow

    /** CALL SYSTEM WFL USING WKS-START-WFL / WKS-START-WFL2. */
    void lanza(LanzamientoWfl l) {
        var args = l.parametro().map(List::of).orElse(List.of());
        String id = launcher.launch(new AppDeploymentRequest(
                new AppDefinition(l.nombre().strip(), Map.of("pack", l.pack())),
                recurso(l.nombre()), Map.of(), args));
        if (id == null || id.isBlank()) {
            // El COBOL no revisa el resultado y marca STATUS = 1 de todos modos.
            throw new LanzamientoFallidoException(l);   // rollback: el registro sigue pendiente
        }
        log.info("WFL {} lanzado: {}", l.comandoMcp(), id);
    }
}

RN-S151-467P612 incrementa WKS-NFILE de 1 a 99 y construye el título `S151/FILE/EJECUCIONWFL/{NN}.`. Si `ATTRIBUTE RESIDENT OF A04-WFLS = 0` (archivo no existe) → EXIT PERFORM (termina el scan). La lista es escasa (sparse): el primer archivo ausente detiene el scan, aunque existan archivos con números mayores.Título del archivo con número de 01 a 99 · Archivo ausente y apertura en I-O
RN-S151-468Dentro de cada archivo EJECUCIONWFL, P612 lee registros buscando el primero donde WKS-WFL-OPCION = WKS-PARAMETRO AND WKS-WFL-STATUS = 0. STATUS=0 significa "pendiente de ejecución"; STATUS=1 significa "ya ejecutado". Solo los registros pendientes y con la OPCION correcta activan el lanzamiento del WFL.Registro de 60 bytes de EJECUCIONWFL · Primer pendiente de la opción sin parámetro
RN-S151-469Si WKS-WFL-PARAM = SPACES (parámetro vacío) → lanza el WFL con `CALL SYSTEM WFL USING WKS-START-WFL`. WKS-START-WFL contiene la cadena completa: `START (S151){NOMBRE} ON CMEMP`. El WFL se ejecuta en el pack CMEMP sin argumentos.Comandos START con y sin parámetro · Primer pendiente de la opción sin parámetro
RN-S151-470Si WKS-WFL-PARAM ≠ SPACES → lanza el WFL con `CALL SYSTEM WFL USING WKS-START-WFL2`. WKS-START-WFL2 contiene: `START (S151){nombre} ON CMEMP("{param}")`. El parámetro va entre comillas dobles dentro del comando de inicio del WFL. El WFL receptor lo recibe como argumento de línea de comando.Comandos START con y sin parámetro · Variante con parámetro y arranque sin verificación
RN-S151-471Inmediatamente después del CALL SYSTEM WFL (con o sin parámetro), P612 hace MOVE 1 TO WKS-WFL-STATUS + WRITE R01-REG-WFL. Esto marca el registro como "ya lanzado" (STATUS=1) en el archivo I-O. Si P612 es llamado de nuevo con la misma OPCION, el registro ya tiene STATUS=1 y no volverá a coincidir con el filtro `AND WKS-WFL-STATUS = 0`.Primer pendiente de la opción sin parámetro · Variante con parámetro y arranque sin verificación
RN-S151-472Después de lanzar el WFL, P612 hace `MOVE 1 TO W77-EOF`. Esto detiene el loop de lectura del archivo actual. Solo UN registro por archivo EJECUCIONWFL es procesado por llamada a P612. Si hay múltiples registros con la misma OPCION en diferentes archivos, solo el primero encontrado (en el archivo de menor número) es procesado.Ciclo principal hasta el archivo 99 · Primer pendiente de la opción sin parámetro

Riesgos de migración
Arranque sin verificación

Después de CALL SYSTEM WFL (líneas 73 y 80) el estatus se marca en 1 sin revisar si el WFL arrancó.

Varios WFL por llamada

Lanzar un WFL solo termina la lectura del archivo actual (MOVE 1 TO W77-EOF); el ciclo de 00-0000-CONTROL continúa con los siguientes números hasta el 99.

WRITE en lugar de REWRITE

El registro leído se actualiza con WRITE R01-REG-WFL (líneas 75 y 83) sobre un archivo abierto en I-O; la forma estándar es REWRITE.

Sin control de concurrencia

Dos ejecuciones simultáneas con la misma opción pueden leer el mismo registro pendiente y lanzar el WFL dos veces.

Hardcodes

Usercode S151, pack CMEMP, prefijo S151/FILE/EJECUCIONWFL/ y el límite 99 están compilados.

Pendiente de revisión SME
  • RN-S151-467 dice que el primer archivo ausente detiene el recorrido; confirmar con el compilador MCP si EXIT PERFORM dentro de un párrafo ejecutado con PERFORM ... UNTIL termina el ciclo completo o solo la iteración.
  • RN-S151-472 dice que solo se procesa el primer registro encontrado en el archivo de menor número; en el fuente el ciclo externo no se detiene al lanzar (línea 49), por lo que puede haber un lanzamiento por archivo. Revisar la regla.
  • Confirmar el efecto de WRITE sobre un archivo secuencial abierto en I-O en MCP (líneas 75 y 83): si actualiza el registro leído o escribe en otra posición.
  • El programa no tiene PROGRAM-ID (línea 4 vacía); confirmar el nombre de objeto con el que lo invoca el WFL.
  • Definir con SME si la versión Java debe conservar los archivos EJECUCIONWFL o si la tabla los sustituye para todos los productores.
