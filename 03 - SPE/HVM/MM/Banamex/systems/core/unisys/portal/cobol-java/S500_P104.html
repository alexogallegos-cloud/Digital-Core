Recibe en el TASKVALUE la fecha de proceso, el CSI (04 Monterrey o 10 Valle de México) y la opción de proceso: 01 a 04 miden data sets de las bases BD01 a BD04, 50 mide archivos de disco y 90 emite los reportes. Para cada archivo obtiene LASTRECORD y AREASIZE si está residente y, para cada data set, el número de registros que reporta la librería MAPLI. Con esos datos actualiza en S500BD04TARJETAS un registro de control por archivo con los registros por día, los máximos por mes, por año (cinco años) e históricos, y la capacidad máxima. Al final calcula el porcentaje de uso y avisa cuántos archivos cruzaron el 80 por ciento ese día.

/** WS-TASKVALUE PIC 9(12) = AAAAMMDD + CSI(2) + OPCION(2). */
public record MonitorCapacidadParams(LocalDate fechaProceso, Plaza plaza, Opcion opcion) {

    public enum Plaza {
        MTY(4), VDM(10);                                   // W88-ES-MTY, W88-ES-VDM
        final int csi;
        Plaza(int csi) { this.csi = csi; }
    }

    public enum Opcion {
        BD01(1), BD02(2), BD03(3), BD04(4), ARCHIVOS(50), REPORTES(90);
        final int valor;
        Opcion(int valor) { this.valor = valor; }
        boolean actualizaBase() { return this != REPORTES; }  // W88-PROC-ACTBASE
    }

    /** Lectura de JobParameters: se publican por separado en lugar de un numérico de 12 dígitos. */
    static MonitorCapacidadParams de(JobParameters p) {
        return new MonitorCapacidadParams(
                p.getLocalDate("fechaProceso"),
                Plaza.valueOf(p.getString("plaza")),
                Opcion.valueOf(p.getString("opcion")));
    }
}
@Component
@RequiredArgsConstructor
public class TaskValueValidator implements JobParametersValidator {

    private final Clock reloj;   // fecha de máquina (90000000-DAME-FEC-MAQUINA)

    @Override
    public void validate(JobParameters p) throws JobParametersInvalidException {
        List<String> errores = new ArrayList<>();
        int anioMaq = LocalDate.now(reloj).getYear();
        LocalDate f;
        try {
            f = p.getLocalDate("fechaProceso");                 // MES 01-12, DIA 01-31 y dentro del mes
        } catch (DateTimeException e) {
            throw new JobParametersInvalidException("TASK VALUE ERRONEO=" + p);
        }
        if (f.getYear() < anioMaq - 1 || f.getYear() > anioMaq + 1) {
            errores.add("AÑO DE FECHA ERRONEO=%d, DEBE SER DEL %d AL %d"
                    .formatted(f.getYear(), anioMaq - 1, anioMaq + 1));
        }
        // Opción y CSI fuera de catálogo fallan al convertir a enum (01,02,03,04,50,90 / 04,10).
        if (!errores.isEmpty()) {
            throw new JobParametersInvalidException(String.join("; ", errores));   // STATUS -1
        }
    }
}

@Configuration

public class MonitorCapacidadJobConfig {

    /** 00000000-CTRLPGM: inicio, actividad 1 (preparación), principal, actividad 8 (cierre). */
    @Bean
    Job monitorCapacidad(JobRepository repo, TaskValueValidator validador,
                         MapliJobListener mapli, Step preparacion, Flow principal, Step termina) {
        return new JobBuilder("S500P104", repo)
                .validator(validador)                 // 10000100 / 10000190
                .listener(mapli)                      // 10000107-INI-PGM-MAPLI / 70000950-FIN-PGM-MAPLI
                .start(preparacion)                   // encabezados, reportes, fecha CSI, abre base
                .on("*").to(principal)                // 40050000-PRINCIPAL
                .from(principal).on("*").to(termina)  // 80000000-TERMINA
                .end()
                .build();
    }
}

@Bean
Flow principal(OpcionDecider decider, Step midePorBase, Step mideArchivos, Step mideBd04, Step reportes) {
    // Orden del lote (comentarios del fuente): BD03 antes de RS500RESTA24H, BD01 antes de
    // RS500FINBATCH, BD02 antes de RINICIALIZAAUX, ARCHIVOS antes de RESPBASEBD04TAR,
    // BD04 después de ARCHIVOS y REPORTES antes de FINWFLLOTE. Lo fija el orquestador, no este job.
    return new FlowBuilder<Flow>("principal")
            .start(decider)
            .on("BD01").to(midePorBase).from(decider)
            .on("BD02").to(midePorBase).from(decider)
            .on("BD03").to(midePorBase).from(decider)
            .on("ARCHIVOS").to(mideArchivos).from(decider)
            .on("BD04").to(mideBd04).from(decider)
            .on("REPORTES").to(reportes)
            .end();
}

@Component
@RequiredArgsConstructor
public class MedicionArchivoProcessor implements ItemProcessor<ArchivoMonitoreado, Medicion> {

    private final AlmacenArchivos almacen;      // reemplaza ATTRIBUTE RESIDENT / LASTRECORD / AREASIZE
    private final P104Properties props;

    /** 50009910-VALIDO-ARCH + 50009912-SACA-ATRIBUTOS. */
    @Override
    public Medicion process(ArchivoMonitoreado a) {
        return almacen.atributos(a.etiqueta())
                .map(at -> new Medicion(a.llave(), a.nombre(),
                        Math.max(at.ultimoRegistro(), 2),                       // IF < 3 MOVE 2
                        at.tamanoArea() * props.factorCapacidadPorArea(), true))
                .orElseGet(() -> new Medicion(a.llave(), a.nombre(), 0, 0, false)); // NO RESIDENTE
    }
}

@Service
public class ControlArchivoService {

    /** 40000650-ACT-DATASET: no repite el día por reinicios o reprocesos sin rollback. */
    @Transactional
    public void aplica(ControlArchivo c, Medicion m, LocalDate hoy) {
        LocalDate inicioMes = c.fechaActual().withDayOfMonth(1);
        boolean reprocesoMesActual = hoy.isBefore(c.fechaActual()) && !hoy.isBefore(inicioMes);
        if (!reprocesoMesActual && hoy.equals(c.fechaActual())) return;   // ya actualizado hoy
        if (hoy.isBefore(inicioMes)) return;                               // fecha de otro mes: se ignora

        if (hoy.isAfter(c.fechaActual())) c.rotaPeriodos(hoy);              // 40000652 / 40000653
        long regs = m.registros();
        c.registrosPorDia()[hoy.getDayOfMonth()] = regs;
        c.maximos().actualizaMes(hoy, regs);
        c.maximos().actualizaAnio(hoy, regs);
        if (regs > c.maxHistorico()) { c.maxHistorico(regs); c.fechaMaxHistorico(hoy); }
        if (m.capacidad() > 0 && m.capacidad() != c.capacidadMaxima()) {
            if (m.capacidad() > c.capacidadMaxima()) c.porcentajeUso(BigDecimal.ZERO.setScale(1));
            c.capacidadMaxima(m.capacidad());
        }
    }
}
@Embeddable
public class MaximosAnuales {
    static final int ANIOS = 5;
    private long[] maxMesActual = new long[13];   private LocalDate[] fecMesActual = new LocalDate[13];
    private long[] maxMesAnterior = new long[13];
    private long[] maxAnual = new long[ANIOS + 1]; private LocalDate[] fecMaxAnual = new LocalDate[ANIOS + 1];

    /** 40000670-CAMBIA-ANH: (4)->(5), (3)->(4), (2)->(3), (1)->(2); (1) en cero; se pierde el (5). */
    void cambiaAnio() {
        System.arraycopy(maxAnual, 1, maxAnual, 2, ANIOS - 1);
        System.arraycopy(fecMaxAnual, 1, fecMaxAnual, 2, ANIOS - 1);
        maxAnual[1] = 0;
        fecMaxAnual[1] = null;
        maxMesAnterior = maxMesActual.clone();      // B06P-XMES-ANHACT -> B06P-XMES-ANHANT
        Arrays.fill(maxMesActual, 0);
        Arrays.fill(fecMesActual, null);
    }
}

// En ControlArchivo
void rotaPeriodos(LocalDate hoy) {
    if (hoy.getYear() != fechaActual.getYear()) maximos.cambiaAnio();
    if (hoy.getYear() != fechaActual.getYear() || hoy.getMonthValue() != fechaActual.getMonthValue()) {
        Arrays.fill(registrosPorDia, 0);            // 40000654-LIMPIA-DIA 31 TIMES
    }
}
@Component
@StepScope
@RequiredArgsConstructor
public class SaturacionTasklet implements Tasklet {

    private final ControlArchivoRepository controles;
    private final P104Properties props;            // umbral-alto: 79.9, umbral-bajo: 79.8
    private final AvisoOperacion aviso;

    /** 50040800-MARCA-NOACT + 40000710-SI-ACTHOY + aviso de 80000000-TERMINA. */
    @Override
    @Transactional
    public RepeatStatus execute(StepContribution sc, ChunkContext ctx) {
        LocalDate fecha = /* fechaProceso del job */ null;
        int saturados = 0;
        for (ControlArchivo c : controles.findAll()) {
            boolean actualizadoHoy = c.fechaActual() != null && !c.fechaActual().isBefore(fecha);
            c.sinActualizarHoy(!actualizadoHoy);
            if (!actualizadoHoy) continue;
            if (c.capacidadMaxima() == 0) continue;     // el COBOL arrastraba el % del registro anterior
            BigDecimal uso = BigDecimal.valueOf(c.maxHistorico())
                    .multiply(BigDecimal.valueOf(100))
                    .divide(BigDecimal.valueOf(c.capacidadMaxima()), 1, RoundingMode.HALF_UP); // ROUNDED
            if (uso.compareTo(props.umbralAlto()) > 0 && c.porcentajeUso().compareTo(props.umbralBajo()) < 0) {
                saturados++;                              // cruza el 80% hoy
            }
            c.porcentajeUso(uso);                         // en COBOL se graba siempre (punto en 2075)
        }
        if (saturados > 0) {
            aviso.operador(" %d ARCHIVOS > AL 80%% DE USO HOY, AVISAR A ING.SISTEMAS".formatted(saturados));
        }
        return RepeatStatus.FINISHED;
    }
}
@Service

public class ControlArchivoWriter {

    private final ControlArchivoRepository repo;

    /**
     * 40000800-STORE-B06P: BEGIN/END TRANSACTION NO AUDITADA. Son datos de control operativo,
     * no contables: se graban en una transacción propia, separada de cualquier otra unidad de trabajo.
     */
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void graba(ControlArchivo c) {
        try {
            repo.saveAndFlush(c);
        } catch (DataAccessException e) {
            // "STORE DATAB06P, LLAVE ..." con W77-FIN-ERRBASE = 1 -> CALL SYSTEM DMTERMINATE
            throw new ProcesoAbortadoException("STORE DATAB06P, LLAVE " + c.llave(), e);
        }
    }
}

Riesgos de migración
Porcentaje de uso se graba siempre

En 40000710-SI-ACTHOY (líneas 2074-2078) el IF que compara B06P-PORC-USO con el nuevo porcentaje termina con un punto en la línea 2075; el MOVE del porcentaje y el STORE quedan fuera del IF y se ejecutan para todos los registros, aunque el porcentaje haya bajado. La indentación sugiere lo contrario.

Marca de no actualizado sin grabar

40000705-NO-ACTHOY (líneas 2056-2057) pone B06P-NO-ACT = 1 pero no hace STORE; con LOCKN el cambio se pierde al pasar al siguiente registro. La marca de archivos no actualizados hoy no llega a la base, salvo que otra rutina la grabe.

Porcentaje arrastrado del registro anterior

Si B06P-MAXIMA-CAP es 0, el COMPUTE de la línea 2067 no se ejecuta y W77-PORC-USO conserva el valor del archivo procesado antes; ese valor se graba en el registro actual y puede contarlo como saturado.

Capacidades compiladas

La capacidad de cada data set es una constante por párrafo (30000000, 3000000, 1500000, 300000, entre otras) y la de los archivos se estima como AREASIZE por 15000 (línea 3269). El SORT de I02 fija 300000 de disco y 400000 de memoria (líneas 3066-3067). Ninguno se recalcula si cambia el tamaño real.

Año bisiesto simplificado

00000100-VALIDA-HOST (líneas 1348-1352) considera bisiesto todo año divisible entre 4; es correcto entre 1901 y 2099, pero no aplica la regla de 100 y 400.

Host desconocido se asume UAT

Si el nombre del equipo no corresponde a pruebas, UAT ni producción, el programa sigue como UAT (líneas 1372-1377); el abort está comentado en la línea 1378.

Pendiente de revisión SME
  • RN-S500-730 habla de archivos históricos del bloque B06 de tarjetas; en el fuente S500B06PCTRLARCH es un data set de control de capacidad dentro de S500BD04TARJETAS que guarda un registro por archivo o data set monitoreado, no un histórico de tarjetas.
  • RN-S500-732 describe la ventana año anterior y año posterior como acotamiento de la búsqueda histórica de tarjetas; en el fuente (líneas 1565-1600) solo valida que el año del TASKVALUE esté en ese rango. Revisar la redacción en el brain.
  • Confirmar el significado de W77-TIPO-DISP = 'O' antes del aviso de saturación (línea 4236); podría ser un mensaje que espera respuesta del operador, pero el párrafo que lo usa viene de un copybook no incluido.
  • Confirmar el origen de las capacidades por data set (por ejemplo 30000000 para S500B03CONTRATOS de DB01) y si siguen vigentes.
