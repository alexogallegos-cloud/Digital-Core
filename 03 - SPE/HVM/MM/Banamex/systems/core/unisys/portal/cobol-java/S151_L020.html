S151 · L020 a Java 21 Spring Boot

L020 recibe WKS-MOV-DATOS (el movimiento de 540 bytes con hasta cinco claves de transacción e importes) y un código de función. Con función 0 inicializa: abre las bases y carga del catálogo S080 qué saldos afecta cada clave de transacción y con qué signo. Con función 1 (alta) o 2 (baja) decide, comparando niveles de lectura, si toca actualizar movimientos, saldos o ambos; graba el movimiento detallado solo para producto 1 instrumento 3 y, para los saldos, suma o resta el importe en el saldo mensual por contrato (B20) y en la posición diaria por CSI, fecha, moneda, producto e instrumento (B70). Cualquier otra función solo graba los niveles de avance y regresa 98.

/**
 * S151LIB020. $SHARING = SHAREDBYRUNUNIT TEMPORARY: una instancia por unidad de ejecución.
 * En Spring el equivalente más cercano es un bean con alcance de job o de request,
 * con su propio estado de niveles (W77-NIV-*, W77-ULT-LEC).
 */
@Service
@Scope(value = "job", proxyMode = ScopedProxyMode.TARGET_CLASS)
@RequiredArgsConstructor
public class Lib020Service {

    public static final int RES_SOLO_NIVELES = 98;

    private final InicioLib020 inicio;          // 200000-INICIO
    private final ProcesoSdoMov proceso;        // 300000-PROCESO-SDOMOV
    private final NivelesLib020 niveles;        // 100100-GRABA-NIVEL-SDOMOV

    /** PROCEDURE DIVISION USING WKS-MOV-DATOS, W77-RES-FIL, W77-RES-LIB. */
    public Resultado ejecuta(MovimientoDatos mov) {
        return switch (mov.funcion()) {
            case 0    -> inicio.inicia(mov);
            case 1, 2 -> proceso.procesa(mov);
            default   -> {
                niveles.grabaNiveles();
                yield Resultado.mov(RES_SOLO_NIVELES);   // MOVE 98 TO W77-RES-MOV
            }
        };
    }

    public record Resultado(int resMov, int resLib) {
        static Resultado mov(int r) { return new Resultado(r, 0); }
    }
}

@Service
@RequiredArgsConstructor
class ProcesoSdoMov {

    private final ControlNivelRepository nivelSdo;    // B00 en SDODB
    private final ControlNivelRepository nivelMov;    // B00 en MOVDB
    private final MovimientosService movimientos;     // 310000-PROCESA-MOVTOS
    private final SaldosService saldos;               // 510000-PROCESA-SDOS
    private final NivelesLib020 niveles;

    @Transactional   // LOCK SDODB + LOCK MOVDB: una sola transacción para ambas bases
    Lib020Service.Resultado procesa(MovimientoDatos mov) {
        long lecSdo = nivelSdo.lecArcDia(), lecMov = nivelMov.lecArcDia();
        boolean actMov, actSdo;
        if (mov.sistema() == 500 || mov.sistema() == 555) {
            actSdo = lecSdo <= lecMov;    // = actualiza ambas; < solo saldos
            actMov = lecSdo >= lecMov;    // > solo movimientos (la base atrasada se pone al corriente)
        } else {
            actSdo = true;
            actMov = false;
        }
        if (actMov) {
            boolean detalla = !(mov.sistema() == 84 && mov.instrumento() != 15 && mov.instrumento() != 17);
            if (detalla) movimientos.procesa(mov);
            niveles.grabaNivMovs(mov);
        }
        if (actSdo) {
            saldos.procesa(mov);
            niveles.grabaNivSdos(mov);
        }
        // W77-ACT-SDO = 2 (solo grabar nivel de saldos) nunca se asigna en el fuente: rama omitida.
        return niveles.ultimaLecturaResultado(mov, actMov, actSdo);   // W77-ULT-LEC
    }
}
@Component
@RequiredArgsConstructor
class NivelesLib020 {

    private final ControlNivelRepository nivelMov;
    private final ControlNivelRepository nivelSdo;
    private long nivMovOk, nivMovInf, nivMovErr;       // W77-NIV-MOVOK / MOVIN / MOVER

    /** 300100-GRABA-NIVMOVS: los tres niveles del día suben juntos a la autorización del movimiento. */
    void grabaNivMovs(MovimientoDatos mov) {
        ControlNivel b00 = nivelMov.delDia();
        b00.setSecuencias(nivMovOk, nivMovInf, nivMovErr);
        if (mov.autS151() > b00.getLecArcDia() || mov.autS151() > b00.getMovCicDia()
                || mov.autS151() > b00.getSdoCicDia()) {
            b00.setNiveles(mov.autS151());             // LECARCDIA = MOVCICDIA = SDOCICDIA
        }
        nivelMov.save(b00);                            // STORE MOVDB (siempre)
    }

    /** 300200-GRABA-NIVSDOS: a diferencia de MOVDB, solo hace STORE si el nivel cambió. */
    void grabaNivSdos(MovimientoDatos mov) {
        ControlNivel b00 = nivelSdo.delDia();
        if (mov.autS151() > b00.getLecArcDia() || mov.autS151() > b00.getMovCicDia()
                || mov.autS151() > b00.getSdoCicDia()) {
            b00.setNiveles(mov.autS151());
            nivelSdo.save(b00);
        }
    }
}
@Component
@RequiredArgsConstructor
class DmsErrorHandler {

    private final AlertaOperacion alertas;

    /**
     * 900000-CHECA-STATUS. El fuente registra categoría, tipo y estructura del error,
     * los niveles de lectura y ejecuta STOP "DAR OK PARA CONT": la tarea queda detenida
     * hasta que un operador responde OK, y luego CONTINÚA con la siguiente instrucción.
     */
    void checa(DataAccessException e, String base, Niveles niv) {
        log.error("BASE DATOS {} ERROR EN BD {} lecSdo={} lecMov={} ultLec={}",
                  base, e.getMostSpecificCause().getMessage(),
                  niv.lecSdo(), niv.lecMov(), niv.ultLec());
        alertas.publica("S151LIB020 error de base de datos en " + base);
        // En lugar de esperar al operador y continuar, se revierte la transacción:
        throw new Lib020DatosException(base, e);       // W77-RES-MOV = categoría DMSII
    }
}

    public record Afecta(int tipoSaldo, Afectacion afectacion) {}   // WKS-TIP-CVE 9(03)

    private final CatalogoS080Client s080;          // L710_CONSUL_DETALLE IN ESTRUCTURA
    private Map<Integer, List<Afecta>> porClave = Map.of();

    void carga(int sistema) {
        Map<Integer, List<Afecta>> m = new HashMap<>();
        for (var r : s080.detalle(/* catálogo del sistema */)) {   // RESULT 1 = hay más páginas, 0 = última, 20 = sin datos
            if (r.dato(1) != sistema) continue;
            var lista = m.computeIfAbsent((int) r.dato(2), k -> new ArrayList<>());
            if (lista.size() < 6) {                // 230110-BUSCA-SPC: primer hueco libre de 6

                        r.dato(4) == 1 ? Afectacion.CARGO : Afectacion.ABONO));
            }
        }
        if (m.isEmpty()) {
            throw new IllegalStateException("Sin claves de afectación para " + sistema);  // W77-RES-MOV 999
        }
        porClave = Map.copyOf(m);
    }

    public List<Afecta> de(int cveTran) { return porClave.getOrDefault(cveTran, List.of()); }

Riesgos de migración
STOP en una librería compartida

900000-CHECA-STATUS termina con STOP "DAR OK PARA CONT" (línea 2699). Cualquier excepción de DMSII detiene a la tarea llamadora hasta que el operador responde, y después continúa sin reintentar la operación fallida.

En S087 instrumentos 3 y 5 los plazos 368 y 369 no caen en ningún tramo y se agrupan en 720 (líneas 1940-1946). Plazos menores a 90 en esos instrumentos también van a 720.

Rama muerta

IF W77-ACT-SDO = 2 (línea 1419) nunca es verdadero: W77-ACT-SDO solo recibe 0 o 1 (líneas 1384, 1395, 1398 y 1402).

Claves sin catálogo sin rastro

La llamada a 531000-GRABA-ERROR-CVETRA para claves sin afectación está comentada (líneas 2122-2123).

Pausa interactiva para depuración

Si W77-DISP es distinto de cero, 510000-PROCESA-SDOS hace ACCEPT W77-DISP (línea 1984) dentro de la librería, lo que detiene la tarea llamadora. En operación normal W77-DISP vale cero (VALUE ZEROS, línea 422).

Hardcodes

Sistemas 500, 555, 84 y 87; producto 1 instrumento 3 como único caso con movimiento detallado y saldo mensual; clave 18 de producto 84 instrumento 15; límites de tramos de plazo; código de resultado 98 y 999. Se trasladan a configuración.
