El parámetro del data set decide si la corrida es diaria o semanal. Mientras haya archivos pendientes según las fechas de B02, P400 procesa primero el del S111 y luego el de ECMS: valida que el header traiga la fecha de proceso y el sistema emisor esperado, lee cada detalle, mapea la clave de transacción, obtiene el contrato y la sucursal promotora con las librerías S500 L040 y S016 L422 y, con la sucursal, el CSI vía S080. Cada movimiento se escribe en el archivo de su CSI con header y trailer propios. Al final compara el trailer de entrada contra lo leído; si no cuadra, salvo en una ventana de fechas de diciembre de 2011, pregunta al operador si se procesa de todos modos y le pide el SOEID de quien autoriza, o purga las salidas. Después actualiza B02 y lanza el WFL P197 para enviar los archivos a Monterrey.

public enum Ciclo { DIARIO, SEMANAL;
    /** WS-TAR-DS: "TARJETADIA" es diario; "TARJETASEM" semanal; cualquier otro no procesa. */
    static Optional<Ciclo> de(String dataSet) {
        return switch (dataSet) {
            case "TARJETADIA" -> Optional.of(DIARIO);
            case "TARJETASEM" -> Optional.of(SEMANAL);
            default           -> Optional.empty();
        };
    }
}

public class ArchivosPendientesDecider implements JobExecutionDecider {

    private final ControlCaptacionRepository b02;

    @Override
    public FlowExecutionStatus decide(JobExecution job, StepExecution step) {
        var c = b02.findControl().orElseThrow();
        boolean pendS111 = c.fechaProS111().isBefore(c.fechaMaquina()) && !c.decomisoS111();   // WS-B02-DECOM-S111
        boolean pendEcms = c.fechaProEas().isBefore(c.fechaLinea()) && !c.omitirEcms();

        if (pendS111) return new FlowExecutionStatus("S111");   // WS-INT-CONTROL: 88 ARCH-S111 = 1
        if (pendEcms) return new FlowExecutionStatus("ECMS");   // 88 ARCH-ECMS = 2
        return new FlowExecutionStatus("NINGUNO");              // WS-FIN-PROCESOS = 1
    }
}

    private final TbinterRepository entrada;                 // TARJETA, acceso RANDOM
    private final RutasArchivo rutas;                        // ERRTBINTER/ y APLTBINTER/

    @Override
    public void beforeStep(StepExecution s) {

        var h = entrada.leeRegistro(1)                       // MOVE 1 TO W-LLAVE-TARJETA
                .orElseThrow(() -> new ProcesoAbortadoException("ERROR AL LEER HEAD. ARC DIARIO"));
        List<String> errores = new ArrayList<>();
        if (!h.fecha().equals(fechaPro)) errores.add("FEC INT. DIF. PROC. ARC DIARIO");  // DDMMAA
        if (!"S111".equals(h.idSistema())) errores.add("SIS. INT. DIFERENTE DE S111");
        if (!errores.isEmpty()) {
            rutas.marcaErroneo(h);                           // 31310110-CHANGETIT-ARCH-ERR
            // El fuente espera en consola a que se inyecte un archivo correcto y vuelve a leer.
            // En Java el step falla; el reintento lo decide el orquestador tras reemplazar el archivo.
            throw new HeaderInvalidoException("ARCH CON HEADER ERRONEO " + errores);
        }
    }

@Component
@StepScope
@RequiredArgsConstructor
public class ResolucionCsiProcessor implements ItemProcessor<MovimientoTarjeta, MovimientoTarjeta> {

    private final P400Properties props;
    private final ContratoTarjetaResolver contratos;   // S500 L040 y S016 L422
    private final SucursalCsiCatalogo s080;            // 40000450-CSI-SUCPTE

    @Override
    public MovimientoTarjeta process(MovimientoTarjeta m) {
        int sucursal = m.sucursal();
        int csi = s080.csiDe(sucursal);
        if (!(m.contrato() > 0 && m.esEcms()) && m.tarjeta().length() == 16) {   // TB-TARJETA > 999999999999999
            var cto = contratos.porTarjeta(m.tarjeta());
            if (cto.isPresent()) {
                sucursal = cto.get().sucursalPromotora();
                csi = s080.csiDe(sucursal);
            }
        }
        if (!props.csiValidos().contains(csi)) {
            log.warn("WS-NUMCSI = CERO tarjeta={} contrato={} origen={}",
                     Pan.enmascara(m.tarjeta()), m.contrato(), m.origen());
            csi = props.csiPorOmision();
            sucursal = props.sucursalPorOmision();
        }
        char autoriza = (m.importePosteo().signum() > 0 && m.importeAutorizado().signum() == 0) ? 'C'
                      : (m.importePosteo().signum() == 0 && m.importeAutorizado().signum() > 0) ? 'V'
                      : (m.importePosteo().signum() > 0 && m.importeAutorizado().signum() > 0) ? 'P' : ' ';
        return m.conCsi(csi, sucursal).conClaveAutoriza(autoriza);
    }
}
@Bean
@StepScope
ClassifierCompositeItemWriter<MovimientoTarjeta> movsPorCsi(
        @Value("#{jobExecutionContext['origen']}") String origen,        // S111 o ECMS
        Map<String, FlatFileItemWriter<MovimientoTarjeta>> salidas) {     // MOVSTBINTER[EAS] 04 y 10
    var w = new ClassifierCompositeItemWriter<MovimientoTarjeta>();
    w.setClassifier(m -> switch (m.csi()) {
        case 4  -> salidas.get(origen + "-04");     // TBINTERMON / TBINTERMON-EAS
        case 10 -> salidas.get(origen + "-10");     // TBINTERVDM / TBINTERVDM-EAS
        default -> throw new IllegalStateException("CSI sin archivo: " + m.csi());
    });
    return w;
}

@Component
public class TrailerValidator implements StepExecutionListener {

    @Override
    public ExitStatus afterStep(StepExecution s) {
        var ctx = s.getExecutionContext();
        TrailerEntrada t = (TrailerEntrada) ctx.get("trailerEntrada");   // 50002455-POSICIONO-TRAILER
        long leidos = ctx.getLong("regLeidos");
        BigDecimal sumaBruto = (BigDecimal) ctx.get("sumTotBruto");      // escala 2, 9(12)V99
        String titulo = ctx.getString("ciclo").equals("DIARIO") ? "DIARIO S111" : "SEMANAL S111";

        boolean cuadra = t.numRegistros() == leidos && t.importeBruto().compareTo(sumaBruto) == 0;
        if (cuadra) return s.getExitStatus();
        log.error(" DETALLE Y TRAI. DIF ARC. {}, REG-LEIDOS {}, TRAIL-NUMREG {}, SUM-BRUTO {}, TRAIL-IMPBRUTO {}",
                  titulo, leidos, t.numRegistros(), sumaBruto, t.importeBruto());
        return new ExitStatus("TRAILER_DESCUADRADO");                    // WS-ERROR-TRAILER = 1
    }
}

@Service
@RequiredArgsConstructor
public class AutorizacionDescuadreService {

    private final P400Properties props;
    private final AprobacionesClient aprobaciones;   // reemplaza ACCEPT WS-SINO / WS-SOEID-VOBO-TRAILER
    private final SalidasMovs salidas;

    public Decision resuelve(LocalDate fechaPro, Descuadre d) {
        if (props.trailer().enVentanaSinValidar(fechaPro)) return Decision.CONTINUAR;   // sin aviso en el fuente

        Optional<Aprobacion> ap = aprobaciones.solicita(
                "DESEA PROCESAR SIN VALIDAR TRAILER (SI/NO)?", d, Duration.ofHours(2));
        if (ap.filter(Aprobacion::aprobada).isPresent()) {
            log.warn("EL SOEID DE QUIEN AUTORIZO PROCESAR SIN VALIDAR EL TRAILER ES: {}", ap.get().soeid());
            return Decision.CONTINUAR;
        }
        salidas.marcaEntradaErronea();               // 31310110-CHANGETIT-ARCH-ERR: prefijo ERRTBINTER/
        salidas.purgaMovs();                         // 50002456-PURGE-MOVS: CLOSE ... WITH PURGE
        return Decision.NO_PROCESAR;                 // WS-NOPROC-ERR-TRAI = 1
    }
}

RN-S500-527Antes de procesar un archivo de entrada (S111 diario o semanal), el programa valida el trailer comparando el número de registros leídos contra el número declarado en el trailer y la suma de importes brutos acumulada contra el importe bruto del trailer. Cualquier diferencia marca error de trailer y detona el mensaje de descuadre. Es el control de integridad que impide procesar un archivo truncado o corrupto hacia estados de cuenta.Registros e importe bruto contra el trailer del S111
RN-S500-528Cuando el trailer no cuadra (RN-S500-527), el programa evalúa la fecha de proceso: si cae dentro de la ventana codificada `20111201 < WS-FECHA-PRO < 20111207` omite silenciosamente el error de trailer y continúa el proceso sin pedir autorización. Es un parche histórico embebido que sigue vivo en el código y representa un riesgo latente: cualquier corrida con fecha de proceso manipulada a ese rango salta el control de integridad de estados de cuenta.Ventana de diciembre de 2011 y autorización con SOEID
RN-S500-529Fuera de la ventana hardcodeada, ante un trailer descuadrado el operador puede autorizar el procesamiento respondiendo `SI` a la pregunta interactiva y capturando el SOEID de quien autoriza; el SOEID queda registrado en bitácora. Si responde distinto de `SI`, el proceso se detiene. Es un control de segregación de funciones que permite procesar datos no cuadrados bajo responsabilidad nominal, pero depende de intervención humana en batch.Ventana de diciembre de 2011 y autorización con SOEID

Riesgos de migración
Control de trailer desactivable

La ventana de fechas de diciembre de 2011 (líneas 3885-3887) omite la validación sin mensaje, y fuera de ella basta con responder SI y teclear cualquier SOEID para procesar un archivo descuadrado hacia estados de cuenta.

CSI por omisión

Los movimientos sin CSI válido se envían a Valle de México con sucursal 105 (líneas 3356-3367) en lugar de rechazarse; quedan mezclados con los movimientos correctos.

Espera indefinida en header erróneo

50002115-OPEN-VALHEADER se repite hasta que el header sea correcto, con un mensaje a consola para reinyectar el archivo; sin intervención el paso no termina.

Número de tarjeta en bitácora

Los mensajes de las líneas 3357-3358 escriben la tarjeta completa. Debe enmascararse en la versión Java y revisarse la retención de las bitácoras actuales.

Código muerto extenso

Los drivers STEFANINI EAS (50000000, 60000000) y el flujo combinado con SORT siguen en el fuente comentados o sin invocar; no se transpilan.
