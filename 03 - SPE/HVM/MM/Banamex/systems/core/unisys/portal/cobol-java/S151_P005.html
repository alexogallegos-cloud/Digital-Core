S151 · P005 a Java 21 Spring Boot

Abre S151BD02ADSALDO en actualización, toma del registro de control el CSI, la fecha y hasta 20 sistemas, y calcula con LOCSUP el día de la semana y la próxima corrida. Por cada sistema arma la etiqueta del archivo SALDOS, lee su header y, según el formato (1, 2 o 3), recorre los registros de cliente (10), sucursal (20), global (30) y trailer (90): los graba en los conjuntos B03, B02 y B01 de la base con una transacción por registro, los copia a SDOS-SAL y, en el formato 1, escribe los globales en TESORERIA. Valida el conteo del trailer contra lo leído, marca el sistema como arribado en el control y emite un reporte de cifras por archivo.

/** W-REG-SALDOS: registro de 90 bytes con cinco vistas REDEFINES, discriminadas por la clave (CVES). */
public sealed interface RegistroSaldos
        permits RegistroSaldos.Header, RegistroSaldos.Cliente, RegistroSaldos.Sucursal,
                RegistroSaldos.Global, RegistroSaldos.Trailer, RegistroSaldos.Otro {

    /** El header no tiene clave propia: es el primer registro del archivo. */
    record Header(int csiOrigen, int sistema,
                  LocalDate fechaProceso, LocalDate fechaCreacion,   // 9(06) AAMMDD, pivote Y2K explícito
                  String horaCreacion, int formato) implements RegistroSaldos {}

    /** CVES = 10. Cuenta 9(20) COMP como String para conservar ceros. */
    record Cliente(int sistema, int sucursal, int moneda, String cuenta, int instrumento,
                   int sucursalExpedidora, String nombre,
                   BigDecimal saldoAnterior, BigDecimal saldoActual,      // 9(18)V99 COMP -> escala 2, sin signo
                   LocalDate fecha) implements RegistroSaldos {}
    /** CVES = 20. */
    record Sucursal(int sistema, int sucursal, int moneda,
                    BigDecimal saldoAnterior, BigDecimal saldoActual, LocalDate fecha) implements RegistroSaldos {}
    /** CVES = 30. */
    record Global(int sistema, int moneda,
                  BigDecimal saldoAnterior, BigDecimal saldoActual, LocalDate fecha) implements RegistroSaldos {}
    /** CVES = 90: número de registros de cliente del archivo. */
    record Trailer(int sistema, long registros) implements RegistroSaldos {}
    /** Cualquier otra clave: P005 la ignora sin aviso. */
    record Otro(byte[] raw) implements RegistroSaldos {}
}

final class FechaAammdd {
    static final int PIVOTE = 50;   // CRONOS 2000: confirmar el pivote real de A2K-OBTAIN-CENTURY
    static LocalDate de(int aammdd) {
        int aa = aammdd / 10000, siglo = aa < PIVOTE ? 2000 : 1900;
        return LocalDate.of(siglo + aa, (aammdd / 100) % 100, aammdd % 100);
    }
}
/** W-REG-GLOBALES-TESORERIA: 2 + 4 + 2 + 20 + 20 + 8 = 56 posiciones, todo numérico DISPLAY. */
public record RegistroTesoreria(int csi, int sistema, int moneda,
                                BigDecimal saldoAnterior, BigDecimal saldoActual, LocalDate fecha) {

    String formatea() {
        return "%02d%04d%02d%s%s%s".formatted(csi, sistema, moneda,
                implicito(saldoAnterior), implicito(saldoActual),
                fecha.format(DateTimeFormatter.BASIC_ISO_DATE));      // 9(08) AAAAMMDD tras CRONOS 2000
    }

    /** 9(18)V99: 20 dígitos con punto decimal implícito, sin signo; un negativo sería un error de datos. */
    private static String implicito(BigDecimal v) {
        if (v.signum() < 0) throw new IllegalArgumentException("TESORERIA no admite saldos negativos: " + v);
        return "%020d".formatted(v.setScale(2, RoundingMode.UNNECESSARY).unscaledValue());
    }
}

@Configuration
public class ExtractorJobConfig {

    @Bean
    Job extractorSaldos(JobRepository repo, CalendarioDecider calendario,
                        Step abreControl, Step integraSistemas, Step reporteCifras, Step cierra) {
        return new JobBuilder("S151P005", repo)
                .start(abreControl)                          // 1000-ABRE: OPEN UPDATE + FIND del control
                .next(calendario)                            // 1010-CARGA-LOCSUP
                    .on("FIN_DE_SEMANA").to(cierra)          // no integra ni emite REPORTE
                .from(calendario)
                    .on("HABIL").to(integraSistemas)         // 2000-PROCESO
                    .next(reporteCifras)                     // 4000-REPORTE
                    .next(cierra)
                .end().build();
    }
}

@Component
@RequiredArgsConstructor
public class IntegraSistemaTasklet implements Tasklet {

    private final ArchivoSaldosReader lector;
    private final ProcesadorPorFormato procesador;     // 400-GRABA-REG-SDOS
    private final CifrasPorArchivo cifras;              // FPRO/DCRE/HCRE/RLEI/RGRA/RLEY-TAB

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        for (int sistema : control.sistemasRegistrados()) {         // TAB-SIST(1..20) > 0
            if (props.excluyeSar(sistema, control.csi())) continue;  // 151 en CSI 4 o 6
            Path archivo = props.etiquetaSaldos(sistema, control.fechaBase());
            try (var in = lector.abre(archivo)) {
                Optional<RegistroSaldos.Header> header = in.header();
                if (header.isEmpty()) {
                    cifras.leyenda(sistema, "ARCHIVO SIN INFORMACION");
                    continue;
                }
                var h = header.get();
                // Orden corregido: el fuente procesa (línea 1881) y valida después (líneas 1920-1990).
                Optional<String> rechazo = valida(h, control.fechaBase());
                if (rechazo.isPresent()) {
                    cifras.leyenda(sistema, rechazo.get());
                    if (props.validarAntesDeIntegrar()) continue;     // false = comportamiento actual
                }
                procesador.procesa(sistema, h, in);
            }
        }
        return RepeatStatus.FINISHED;
    }
}
    /** Validaciones de 2200-ARMA-ETIQUETAS; devuelven la leyenda del reporte o vacío. */
    Optional<String> valida(RegistroSaldos.Header h, LocalDate fechaBase) {
        if (!h.fechaProceso().equals(fechaBase)) {
            return Optional.of("FECHAS FUERA DE PROCESO");
        }
        if (!props.csiValidos().contains(h.csiOrigen())) {          // [1, 4, 6, 7, 9, 10]
            return Optional.of("C.S.I. FUERA DE RANGO");
        }
        if (!Set.of(1, 2, 3).contains(h.formato())) {
            avisos.lj("FORMATO : %d NO SE PROCESA : %s NOTIFICAR A INGENIERIA DE SISTEMAS"
                    .formatted(h.formato(), h.sistema()));
            return Optional.of("FORMATO NO SOPORTADO");
        }
        return Optional.empty();
    }
@Component

public class ProcesadorPorFormato {

    private final SaldosDmsiiWriter base;
    private final FlatFileItemWriter<RegistroTesoreria> tesoreria;
    private final MessageChannel intelarOut;     // Spring Integration: SFTP outbound adapter (ADMONXFERS)

    @Transactional
    public void procesa(int sistema, RegistroSaldos.Header h, ArchivoSaldos in) {
        switch (h.formato()) {
            case 3 -> in.registrosNuevoFormato().forEach(base::integra);     // 6000-BARRE-SALDOS-NVO
            case 2 -> in.registros().forEach(base::integra);                 // 2300-BARRE-SALDOS
            default -> {                                                     // formato 1 y cualquier otro
                tesoreria.open(new ExecutionContext());
                in.registrosFormatoAnterior().forEach(r -> base.integraConTesoreria(r, tesoreria));
                tesoreria.close();
                if (sistema == props.sistemaCuentaMaestra()) {               // 500 -> SALCTAM / S500
                    transferencias.preparaSalctam(control.fechaBase());
                }
            }
        }
        intelarOut.send(MessageBuilder.withPayload(props.etiquetaSdosInt(sistema)).build()); // 300-DATOS-ENVI-INTELAR
    }

    void integra(RegistroSaldos.Cliente c) {
        sdosSal.escribe(c);                                           // 2405-GRABA-SALDOS-CTE
        var id = new SaldoClienteId(c.moneda(), c.sucursal(), c.sistema(),
                                    c.cuenta().substring(0, 10), c.cuenta().substring(10));   // LLAVE-CTE1/2
        SaldoCliente e = clientes.findByIdForUpdate(id)                // LOCK ... AT
                .orElseGet(() -> SaldoCliente.nuevo(id));             // NOTFOUND -> CREATE
        e.actualiza(c);                                                // 2410-CLIENTES
        clientes.save(e);                                              // STORE S151B03SDOCTE
        // Cualquier otra excepción DMSII: 8000-BD-ERROR + DMTERMINATE -> la excepción aborta el step.
    }
}

                g.saldoAnterior(), g.saldoActual(), g.fecha())));
    }

Riesgos de migración
Validaciones después de integrar

En 2200-ARMA-ETIQUETAS la línea 1881 ejecuta 400-GRABA-REG-SDOS, que integra todo el archivo en la base, y las validaciones de fecha, CSI y formato (líneas 1920 a 1990) corren después. Solo producen leyendas en el reporte.

Factor del nuevo peso siempre igual a 1

El nivel 88 WS-DIAPBAS-NVOPSO conserva fechas de seis dígitos de 1992 y 1993 sobre un campo de ocho dígitos; la condición es siempre falsa y las divisiones entre WS-FACTOR-NVOPSO no tienen efecto.

Lógica comentada en el despacho

El ruteo por formato dentro de 2100-CHECA-ETIQUETAS (líneas 1719 a 1758) está comentado y se trasladó a 400-GRABA-REG-SDOS. También están comentados la validación de arribo previo (2250-CHECA-ARRIBO, líneas 1824 y 1825) y la mayoría de las llamadas a LJ.

Saldos sin signo

Los saldos de SALDOS, SDOS-SAL y TESORERIA son PIC 9(18)V99 sin signo; un saldo negativo no se puede representar.

Hardcodes

CSI válidos 1, 4, 6, 7, 9 y 10; exclusión del sistema 151 en CSI 4 y 6; posiciones fijas de los sistemas 66 y 500; servidor S500 y archivo SALCTAM; ruta de la librería (S000)S000/UTILITY/DESPLIEGA/OBJ/LIB ON PACK. Pasan a application.yml.
