S151 · P122 a Java 21 Spring Boot

P122 resuelve el título del archivo de entrada según el sistema recibido: los sistemas C/S e IBM (402, 600 y 804) llegan en ARCHC402 con registro de 720 posiciones y los de Tandem (707 y 203) en ARCHS707 con registro de 1261. Exige un header HD y, solo para el 804, un trailer TR cuyos totales de registros e importe cuadren con lo calculado; si no, pide al operador cambiar el archivo y vuelve a validar. Después transforma cada movimiento al área de llamado de L002, forzando el tipo de proceso a 1, lo envía, escribe el punteo y al terminar manda el centinela de función 98. Para los sistemas 203 y 804 controla la reejecución con un registro de proceso en B05.

/** Registro de ARCHC402 (720 bytes). Las tres vistas comparten el buffer; el discriminador son las 2 primeras posiciones. */
public sealed interface RegistroC402 permits RegistroC402.Header, RegistroC402.Movimiento, RegistroC402.Trailer {

    record Header(String sistema, LocalDate fecha) implements RegistroC402 {}        // "HD" 9(04) 9(08)

    record Movimiento(int funcion,                     // 9(02): 01, 11, 21 o 98
                      String sistema, String producto, String instrumento,
                      String sucursalPromotora,
                      String contrato,                 // 9(16) como String: conserva ceros
                      List<Concepto> conceptos,        // OCCURS 5
                      int tipoProceso                  // R01-MOV-TIPO-PROC: P122 lo ignora (ver s7)
                      /* ... fechas, autorizaciones, referencias, indicadores ... */) implements RegistroC402 {}

    record Concepto(int claveTransaccion, int indLeyenda, int esquemaContable,
                    BigDecimal importe) {}             // 9(14)V99 -> escala 2

    record Trailer(long totalRegistros, long totalClaves,
                   BigDecimal totalImporte) implements RegistroC402 {}   // 9(10) 9(10) 9(16)V99

    static RegistroC402 parse(String r) {
        return switch (r.substring(0, 2)) {
            case "HD" -> new Header(r.substring(2, 6), Fixed.fechaAmd(r, 6));
            case "TR" -> new Trailer(Fixed.entero(r, 2, 10), Fixed.entero(r, 12, 10), Fixed.decimal(r, 22, 18, 2));
            default   -> Fixed.movimientoC402(r);   // R01-MOV-FN-ALFA no numérico se detecta al validar la función
        };
    }
}

@ConfigurationProperties("p122")
public record P122Properties(String pack, Map<String, String> entradas, String formatoFecha) {

    public String tituloEntrada(SistemaOrigen s, LocalDate fechaProceso) {
        String plantilla = entradas.getOrDefault(String.valueOf(s.numero()), entradas.get("default"));
        return plantilla.replace("{prefijo}", s.prefijo())
                        .replace("{sistema}", "%03d".formatted(s.numero()))
                        .replace("{fecha}", fechaProceso.format(DateTimeFormatter.ofPattern(formatoFecha)))
               + " ON " + pack;
    }
}
/** Sistemas originadores conocidos; el fuente manda cualquier otro valor al formato Tandem. */
public enum SistemaOrigen {
    C402(402, "C", Formato.C402), C600(600, "C", Formato.C402), S804(804, "S", Formato.C402),
    S707(707, "S", Formato.S707), S203(203, "S", Formato.S707);

    public enum Formato { C402, S707 }      // 720 y 1261 posiciones
    private final int numero; private final String prefijo; private final Formato formato;
    SistemaOrigen(int n, String p, Formato f) { numero = n; prefijo = p; formato = f; }
    public int numero() { return numero; }
    public String prefijo() { return prefijo; }
    public Formato formato() { return formato; }

    public static SistemaOrigen de(int parametro) {
        return Arrays.stream(values()).filter(s -> s.numero == parametro).findFirst()
                .orElseThrow(() -> new IllegalArgumentException(
                        "Sistema no soportado por P122: " + parametro));   // el fuente lo trataría como Tandem
    }
}

@Bean

            .get();
}

@Component
@RequiredArgsConstructor
public class ValidadorArchivoMovimientos {

    /** 050-VALIDA-ARCHIVO. */
    public void valida(SistemaOrigen sistema, List<RegistroC402> archivo) {
        if (archivo.isEmpty() || !(archivo.get(0) instanceof RegistroC402.Header)) {
            throw new ArchivoRechazadoException("SE RECHAZA ARCHIVO SIN HEADER");
        }
        // Los sistemas 707 y 203 tienen la validación de trailer comentada en el fuente.
        if (sistema == SistemaOrigen.S804) {
            validaTrailer(archivo);                          // 082-VALIDA-TR-402
        }
    }
}

// En el MCP el rechazo pide al operador cambiar el archivo y vuelve a validar (PERFORM ... UNTIL).
// En Java el step termina en FAILED y el reintento lo decide el orquestador al recibir un archivo nuevo.
    /** 082-VALIDA-TR-402 + 084-ACUMULA. */
    void validaTrailer(List<RegistroC402> archivo) {
        long registros = 0, claves = 0;
        BigDecimal importe = BigDecimal.ZERO.setScale(2);
        RegistroC402.Trailer tr = null;

        for (RegistroC402 r : archivo.subList(1, archivo.size())) {
            registros++;
            if (r instanceof RegistroC402.Trailer t) { tr = t; registros--; break; }
            if (r instanceof RegistroC402.Movimiento m && m.funcion() == 1) {   // solo función 01 suma
                for (var c : m.conceptos()) {
                    if (c.claveTransaccion() > 0) { claves++; importe = importe.add(c.importe()); }
                }
            }
            // funciones 11, 21, 98 y registros con función no catalogada que no son TR: se cuentan y se siguen leyendo
        }
        if (tr == null) {
            throw new ArchivoRechazadoException("ARCHIVO SIN TRAILER SE RECHAZA ARCHIVO");
        }
        boolean cuadra = tr.totalRegistros() == registros
                && tr.totalImporte().compareTo(importe) == 0;
        // R01-MOV-TRA-TOTCLAVES se calcula y se muestra pero la comparación está comentada.
        if (!cuadra) {
            throw new ArchivoRechazadoException("ARCHIVO CON TRAILER ERRONEO TOT REG CALC. %d VS %d IMP. CALC. %s VS %s"
                    .formatted(registros, tr.totalRegistros(), importe, tr.totalImporte()));
        }
    }

public class ControlReejecucion implements JobExecutionDecider {

    private static final int NUM_PROCESO = 122;      // WKS-B05-NUMPRO
    private final ControlS151 libControl;            // L001 B05PROCESOS

    /** 1000-VERIFICA-B05: solo para 203 y 804 y solo cuando la tarea no recibió fecha (VALUE = 0). */
    @Override
    public FlowExecutionStatus decide(JobExecution je, StepExecution se) {
        var p = Parametros.de(je);
        if (!(p.sistema() == SistemaOrigen.S203 || p.sistema() == SistemaOrigen.S804) || p.fechaExplicita()) {
            return FlowExecutionStatus.COMPLETED;
        }
        var clave = ProcesoDto.consulta(p.sistema().numero(), p.fechaProceso151(), NUM_PROCESO);
        ResultadoControl r = libControl.b05Procesos(clave);                       // función 01
        if (r == ResultadoControl.OK) {
            return clave.statusPrograma() == 0 ? FlowExecutionStatus.COMPLETED
                                               : new FlowExecutionStatus("YA_TERMINADO");   // STOP RUN
        }
        if (r == ResultadoControl.NO_EXISTE) {
            libControl.b05Procesos(clave.comoAlta());                                // función 19
            return FlowExecutionStatus.COMPLETED;
        }
        throw new ControlException(r);   // el fuente intenta el alta ante cualquier resultado distinto de 0
    }

    /** 1200-ACTUALIZA-B05: función 37 con STAPGM = 01 al terminar la carga. */
    public void marcaTerminado(Parametros p) {
        libControl.b05Procesos(ProcesoDto.consulta(p.sistema().numero(), p.fechaProceso151(), NUM_PROCESO)
                                         .comoCambio(1));
    }
}

    @Override

            contador++;

        }
    }
}

            @Override
            public ExitStatus afterStep(StepExecution se) {

                var fin = MovimientoL002.builder()
                        .funcion(98)                                 // fin de proceso
                        .sistema(String.valueOf(p.sistema().numero()))
                        .fechaContable(p.fechaProceso())            // WKS-TIT-FECHAPRO
                        .build();

                if (r > 0) {
                    return ExitStatus.FAILED.addExitDescription("Fin de movimientos rechazado por L002: " + r);
                }
                return se.getExitStatus();
            }
        };

Riesgos de migración
Doble envío del fin de movimientos

400-ENVIA-FIN-MOVTOS se ejecuta al detectar una función no válida en la lectura (líneas 1988 y 2019) y nuevamente en la rutina principal (línea 1677). L002 recibe dos registros de función 98 por ejecución; debe confirmarse que la librería tolera el segundo.

Validación de totales parcial

Solo el sistema 804 valida trailer (líneas 1701-1705) y la comparación del total de claves está comentada (línea 1831). Para 707 y 203 incluso la llamada a la validación está comentada (líneas 1697-1698).

Rechazos de L002 sin efecto

Un resultado mayor que 0 de CARGAMOV1 solo genera un mensaje de consola (líneas 1970-1980 y 2001-2011); la carga continúa y el programa termina normalmente.

Dependencia del operador

Un archivo sin header o con trailer erróneo provoca un ciclo de CLOSE, mensaje al operador y OPEN hasta que se entregue un archivo válido (PERFORM 050-VALIDA-ARCHIVO UNTIL, línea 1653). La aceptación manual está comentada (líneas 1871-1875).

Detención silenciosa por B05

Cuando el proceso ya está marcado como terminado en B05 el programa hace STOP RUN (línea 2161) sin mensaje ni código de resultado; el WFL no puede distinguirlo de una carga exitosa.

Valores fijos

Títulos de archivo con el pack CMEMP, ruta especial del sistema 600, número de proceso 122 en B05, título por defecto de L002 y el título de LIBLJ están compilados. Se trasladan a application.yml.

Pendiente de revisión SME
  • RN-S151-855 interpreta ATTRIBUTE VALUE OF MYSELF = 0 como ejecución en el host primario. En el fuente ese mismo valor decide si la fecha de proceso se toma de B01 o del valor de la tarea (líneas 1604-1610). Confirmar con SME el significado operativo del valor de la tarea en el WFL que lanza P122.
  • RN-S151-852 dice que la lectura termina al primer registro con función no catalogada; en la validación del trailer del 804 esos registros se cuentan y se siguen leyendo (líneas 1853-1854). Confirmar si pueden llegar registros intermedios con funciones no catalogadas.
  • Confirmar si L002 es idempotente ante el segundo registro de función 98.
  • El layout de WKS-REG-NVO y WKS-MSG-NVO (formato Tandem de 1261 posiciones) se mueve con MOVE CORRESPONDING; no se transpiló en este borrador y requiere un mapeo campo a campo validado.
