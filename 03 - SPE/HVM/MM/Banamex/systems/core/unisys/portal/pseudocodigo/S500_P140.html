P140 · Motor de Monitoreo de Tareas Batch (S500)

S500ProgramaCOBOL

Fuente: P140.cbl (2427 LOC) · Paso batch S038-P140 · Version 25MTP004

Convenciones: nombres traducidos (Unisys→legible); [P140 Lnnnn] = línea fuente (cols 1-6); (BR: RN-S500-...) = regla; ⚠ = hallazgo.

1. Resumen funcional

P140 (PROGRAM-ID S500BATCH) es el motor de monitoreo operativo del sistema S500. Consulta la librería MAPLI (S038L035) para obtener, en tiempo de ejecución, la lista de programas batch activos agrupados por usuario (USER) y sub-agrupador (tipo de proceso). Graba los datos de cada programa y actividad en un archivo de control temporal (FILE-PROGRAMAS), los ordena, y genera el reporte impreso de monitoreo de tareas (FILE-MONI). Es infraestructura transversal: no pertenece a ningún dominio de negocio específico sino que observa y reporta el estado de toda la cadena batch S500. El parámetro de entrada es un campo de 13 dígitos que codifica el USER de la CSI y la fecha de proceso. Tiene manejo interactivo de operador cuando MAPLI no está disponible (error 99). « [P140 L001009-L001010] (BR: RN-S500-749) »
