Abre S500BD01CAPTACION en INQUIRY, toma de B02CONTROL el CSI y la fecha de línea, y con LOCSUP obtiene la fecha de lote anterior. Carga en memoria los instrumentos de B05 (máximo 30) con su indicador de envío a S084 y escribe el header con sistema origen 0500 y destino 0084. Recorre B06HISTORICO y, para cada contrato cuya fecha real de corte es la fecha de lote anterior, busca el contrato en B03 y su instrumento en la tabla; si el instrumento tiene el indicador en 1, escribe el saldo promedio del ciclo 12 con contrato, producto, instrumento y moneda. Al final escribe un trailer con número de registros y suma de saldos.

/** Registros de 24 bytes con campos COMP (binarios): se escriben con un codec, no como texto. */
public sealed interface PromedioS084Record
        permits PromedioS084Record.Header, PromedioS084Record.Datos, PromedioS084Record.Trailer {

    /** TPOREG 01. */
    record Header(int sistemaOrigen, int sistemaDestino, int csiOrigen,
                  LocalDate fechaMovto) implements PromedioS084Record {}

    /** TPOREG 02. */
    record Datos(String contrato,            // 9(12) COMP
                 int producto, int instrumento, int moneda,
                 BigDecimal saldoPromedio)    // 9(12)V99 COMP -> escala 2
            implements PromedioS084Record {}

    /** TPOREG 09. */
    record Trailer(long totalRegistros,       // 9(08) COMP
                   BigDecimal totalSaldos)    // 9(14)V99 COMP
            implements PromedioS084Record {}
}

@Component
@RequiredArgsConstructor
public class ControlPromediosTasklet implements Tasklet {

    private final ControlCaptacionRepository b02;   // OPEN INQUIRY
    private final CalendarioBancario calendario;    // LOCSUP

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        ControlCaptacion control = b02.findControl()
                .orElseThrow(() -> new ProcesoAbortadoException("ERR FIND B02CONTROL"));
        LocalDate fechaLinea = control.fechaLinea();
        // LOCSUP función 15, formato 12, desplazamiento 1: fecha de lote anterior
        LocalDate fechaLoteAnt = calendario.retrocede(fechaLinea, 1)
                .orElseThrow(() -> new ProcesoAbortadoException("ERR CALL LOCSUP"));

        var jc = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        jc.put("csi", control.numCsi());
        jc.put("fechaLinea", fechaLinea);         // header y nombre del archivo
        jc.put("fechaLoteAnt", fechaLoteAnt);     // filtro de corte sobre B06
        return RepeatStatus.FINISHED;
    }
}
/** WKS-TABLA-B05: instrumentos y su indicador de envío a S084. */
@Component
@StepScope
@RequiredArgsConstructor
public class CatalogoInstrumentosS084 {

    private static final int CAPACIDAD_ORIGEN = 30;     // OCCURS 30 TIMES
    private final InstrumentoRepository b05;
    private Map<ClaveInstrumento, Boolean> enviaS084;

    @PostConstruct
    void carga() {
        List<Instrumento> todos = b05.findAll();
        if (todos.size() > CAPACIDAD_ORIGEN) {
            // Mismo comportamiento que el fuente: con más de 30 instrumentos el paso se detiene.
            throw new ProcesoAbortadoException(
                "MAS DE 30 INSTRUMENTOS EN LA BASE; IND-INSTRUM: " + (CAPACIDAD_ORIGEN + 1));
        }
        enviaS084 = todos.stream().collect(Collectors.toMap(
                i -> new ClaveInstrumento(i.producto(), i.instrumento(), i.moneda()),
                i -> i.envSdopS084() == 1));
    }

    public Optional<Boolean> enviaSaldo(int producto, int instrumento, int moneda) {
        return Optional.ofNullable(enviaS084.get(new ClaveInstrumento(producto, instrumento, moneda)));
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class PromedioProcessor implements ItemProcessor<Historico, PromedioS084Record.Datos> {

    private final ContratoRepository b03;
    private final CatalogoInstrumentosS084 b05;

    @Override
    public PromedioS084Record.Datos process(Historico h) {
        Contrato c = b03.findByNumContrato(h.numContrato())          // 90000003-B03SXCTO-FIND
                .orElseThrow(() -> new ProcesoAbortadoException(
                        "NO EXISTE CTO EN B03 " + h.numContrato()));
        boolean envia = b05.enviaSaldo(c.producto(), c.instrumento(), c.moneda())
                .orElseThrow(() -> new ProcesoAbortadoException(
                        "NO HAY INSTR EN B05 %d-%d-%d".formatted(c.producto(), c.instrumento(), c.moneda())));
        if (!envia) {
            return null;                                            // WKS-TB05-SDO-S084 <> 1
        }
        return new PromedioS084Record.Datos(
                "%012d".formatted(c.numContrato()), c.producto(), c.instrumento(), c.moneda(),
                h.promCiclo(12).setScale(2, RoundingMode.DOWN));   // B06-PROM-CICLO(12)
    }
}
/** 50001500-GEN-ARCHIVO + 20000700-GEN-TRAILER */
@Component
@StepScope
@RequiredArgsConstructor
public class PromediosWriter implements ItemStreamWriter<PromedioS084Record.Datos>, StepExecutionListener {

    private static final BigDecimal TOPE_9_14_V99 = new BigDecimal("99999999999999.99");
    private final S084BinaryCodec codec;                           // header escrito en open()
    private long totalRegistros;                                   // WKS-E04-R09-TOTREGS
    private BigDecimal totalSaldos = BigDecimal.ZERO.setScale(2);  // WKS-E04-R09-TOTDSOS

    @Override
    public void write(Chunk<? extends PromedioS084Record.Datos> chunk) {
        for (var d : chunk) {
            totalRegistros++;
            totalSaldos = totalSaldos.add(d.saldoPromedio());
            if (totalSaldos.compareTo(TOPE_9_14_V99) > 0) {
                throw new DesbordamientoAcumuladorException(totalSaldos);   // COBOL truncaría
            }
            codec.escribe(d);
        }
    }

    @Override
    public void close() {
        codec.escribe(new PromedioS084Record.Trailer(totalRegistros, totalSaldos));
        codec.cierra();                                            // CLOSE ... WITH SAVE
    }
}
@Override
public ExitStatus afterStep(StepExecution step) {
    // 80000000-TERMINA: CLOSE S500BD01CAPTACION, GEN-TRAILER, CLOSE E04 WITH SAVE.
    // El trailer depende solo de los acumuladores en memoria, no de la base.
    step.getExecutionContext().putLong("totalRegistros", totalRegistros);
    step.getExecutionContext().put("totalSaldos", totalSaldos);
    return step.getExitStatus();
}

Riesgos de migración
Abortos por un solo registro inconsistente

50001100-DAME-B03 y 50001200-DAME-B05 terminan con DMTERMINATE si un contrato del histórico no existe en B03 o si su instrumento no está en la tabla de B05 (líneas 318-329 y 350-359).

Límite estructural de 30 instrumentos

20000155-B05-A-MEMORIA aborta al cargar el instrumento 31 (líneas 262-268), aunque no sea de envío a S084.

Fecha del archivo distinta a la de los cortes

El header y el título llevan B02-FECHA-LINEA (líneas 201-203) y la selección usa la fecha de lote anterior calculada con LOCSUP (líneas 218-225).

Saldos y acumulados sin signo ni protección

WKS-E04-R02-SDOPROM y WKS-E04-R09-TOTDSOS no tienen signo y el ADD de la línea 372 no tiene ON SIZE ERROR.

Mensajes de error que citan otro dataset

Los errores de B05 y B06 dicen "ERR FIND A B07" (líneas 252 y 304), lo que confunde el diagnóstico en operación.

Pendiente de revisión SME
  • Confirmar que B06-PROM-CICLO(12) es el ciclo más reciente y que no debe tomarse otra posición según la fecha de corte.
  • Confirmar con S084 la representación binaria (COMP) de los registros de 24 bytes en la plataforma destino.
  • Confirmar si B06-PROM-CICLO puede ser negativo (contratos con sobregiro) y cómo debe viajar.
  • Validar si LOCSUP función 15 con formato 12 retrocede un día hábil o natural; el encabezado del fuente habla de contratos que cortaron hoy en fecha hábil.
