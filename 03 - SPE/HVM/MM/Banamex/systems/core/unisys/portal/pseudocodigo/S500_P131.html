S500ProgramaCOBOL

Fuente: p131.cbl (3394 LOC · PROGRAM-ID S500P131 · versión 26MTP001) · rol en batch: BC-12 (Financial Servicing / comisiones de tarjetas) · Unisys ClearPath MCP COBOL85.

Convenciones: nombres traducidos (Unisys→legible); [p131 Lnnnn] = línea física del fuente; (BR: RN-S500-...) = regla de negocio del catálogo. Sin COPY (fuente expandido, autocontenido).

1. Resumen funcional

P131 es el motor de cálculo de comisiones y rewards del paquete de incentivos (EPP) de tarjetas de S500 (Banamex). Lee el archivo de transacciones que Teradata deja en disco (EVCOMIS), y para cada cuenta evaluada aplica las reglas parametrizadas cargadas en la base DMSII S500BD04TARJETAS —tabla B13 de comisiones y tabla B14 de rewards— para determinar el importe de comisión a cobrar, el importe exentado (waiver) y el reward (bonificación) por movimientos en canales. Produce tres salidas: (1) el archivo de respuesta a Teradata RESEVAL/RCOMIS con el resultado por cuenta; (2) el archivo de posteo contable para el procesamiento del propio S500 (cargos, abonos y movimientos no contables); y (3) un listado impreso EPPCOMISREW con totales por esquema/producto (BR: RN-S500-738).

El programa opera en dos modos de disparo mutuamente excluyentes según el parámetro de tarea (TASKVALUE): OPCON (ejecución agendada por el scheduler: sondea cíclicamente hasta encontrar los archivos de T-1/T-2/T-3 en días hábiles, respetando ventana horaria) y CORRESOLO (ejecución manual de re-proceso para una fecha entregada como parámetro). El proceso valida versión de librería, hostname/nodo, residencia del archivo y control de reprocesos contra la base de arribos S500B08PCTRARRIBO (B08) antes de calcular (BR: RN-S500-739, RN-S500-740, RN-S500-741, RN-S500-742).

Rol en la cadena: EVCOMIS (Teradata) → P131 → RESEVAL (respuesta Teradata, enviada vía INTELARSND) + archivo de POSTEO (contable S500) + listado impreso (impreso vía WFL SYSTEM/FORZA).
