L006 · Librería de Conciliación Cruzada Interbancaria de Tesorería (S151)

S151LibreríaALGOL

Fuente: ALGOL_L006.alg (2.029 LOC) · Librería ALGOL residente (FREEZE) · Carpeta TESORERIA · S151

Convenciones: nombres traducidos (Unisys ALGOL → legible); [L006 Lnnn] = línea física del fuente; (BR: RN-S151-###) = regla de negocio.

Compilación: $SET ERRORLIMIT=50, $SET SHARING=SHAREDBYALL, $SET LIST, $SET OPTIMIZE. Target: %$TARGET ALL.

1. Resumen funcional

L006 es la librería ALGOL de conciliación cruzada interbancaria del módulo de Tesorería del sistema S151 (Banamex). Su función central es acumular, persistir y consultar los saldos y movimientos derivados de operaciones cruzadas entre Banamex (banco origen/destino código 2, sistema S151) y contrapartes (sistema S500 u otros), clasificados por par banco-origen/banco-destino y moneda.

La librería expone tres entry points exportados: SALDOS (gestión completa de saldos en el dataset S151B14CONOPECRUZ), MOVIMIENTOS (consulta de movimientos en S151B15MOVOPECRUZ) y BASE (apertura/cierre controlada de la base DMSII S151BD02ADSALDO). Opera como proceso residente que se congela (FREEZE) con un controlador de eventos (PROC_CONTROL) que coordina de forma asíncrona el procesamiento del archivo de movimientos (LOG1), el análisis de funciones de eliminación y la actualización de totales.

El procesamiento de movimientos distingue claves de transacción 1078 (liquidación OTR→BNX) y 2129 (liquidación BNX→OTR), así como la naturaleza débito/crédito por banco (columna NAT=1/2 del catálogo S080), acumulando subtotales tridimensionales [banco_origen, banco_destino, moneda] en arrays de hasta 12×12×5.

« divergencia KB: RN-S151-1151 » El stub del KB describe L006 como "librería genérica de acceso a datos". La fuente evidencia un propósito específico: conciliación cruzada de operaciones interbancarias de Tesorería, con lógica de acumulación, reinicio y borrado sectorial. La estrategia RETAIN+ENCAPSULATE del stub es aplicable, pero el contrato de datos es mucho más rico de lo inferido.

2.8 FREEZE y ciclo de vida

FREEZE(CONTROL, PROC_CONTROL);   % Congela L006 como daemon residente

La librería se mantiene residente mientras tenga usuarios (MYSELF.LIBRARYUSERS > 0). PROC_CONTROL gestiona el ciclo de vida mediante WAITANDRESET((30), MYSELF.EXCEPTIONEVENT).

  SI FORMATO = 2 ENTONCES
    REEMPLAZAR PTR_HEX CON 200101 (6 dígitos)    // ⚠ [HARDCODE]: clave de formato 2
    REEMPLAZAR PTR_EBC CON "         " + 500 + "            "

    LOG "ERROR L006, CATALOGO S080 NUMERO DE FORMATO NO VALIDO"

PROCEDIMIENTO Acumular_Registro_Cruzado():
  % Subrutina interna GRABAMOVTO (DEFINE, no PROCEDURE):
  SUBRUTINA Grabar_Movimiento_Cruzado():   // GRABAMOVTO · [L006 L682-L721]
    ERROR_BASE := 0
    LOCK S151B15MOVOPECRUZ POR LLAVE
          (CSI=CSI_LIB, FCHCON=IDFFECCONT(ALOG), SISTEMA=IDFSISTEMA(ALOG),
           MONEDA=IDFMONEDA(ALOG), BCOORI=IDFBCOORI(ALOG),
           BCODES=IDFBCODES(ALOG), HHMMSS=IDFHORAOPE(ALOG),
           FCHMAQ=IDFFECOPE(ALOG)) : DMERR
    SI error ENTONCES
      SI DMERR.DMERROR = NOTFOUND ENTONCES
        CREATE S151B15MOVOPECRUZ : DMERR
        SI error ENTONCES ERRORDB  // pone ERROR_BASE=5
      SINO
        ERRORDB
    FIN_SI
    SI ERROR_BASE = 0 ENTONCES
      PUT S151B15MOVOPECRUZ (todos los campos de llave + CVETRA:=CLAVE, IMPMOV:=IMPMOV)
      BEGINTRANSACTION NOAUDIT S151B91REINICIO : DMERR
      STORE S151B15MOVOPECRUZ : DMERR
      SI error ENTONCES ERRORDB
      ENDTRANSACTION AUDIT S151B91REINICIO : DMERR
    FIN_SI
  FIN_SUBRUTINA

  VARIABLES LOCALES: I, ORI, DES, CVEMON

  ORI    := IDFBCOORI(ALOG)   // banco origen
  DES    := IDFBCODES(ALOG)   // banco destino
  CVEMON := IDFMONEDA(ALOG)   // clave moneda
