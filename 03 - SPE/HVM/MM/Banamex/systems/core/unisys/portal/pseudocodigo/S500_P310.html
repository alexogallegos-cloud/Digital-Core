P310 · Carga Rendimientos Cuenta Productiva Especial (S500)

S500ProgramaCOBOL

Fuente: P310.cbl (1103 LOC)

Rol en batch: proceso mensual de cierre CPE — genera archivo SAT + actualiza B39CTASCPE + B37GRUPOCPE

Versión: 25MTP004 · Release: CPE 2022R09M (MTDP-2466/2467 Stefanini incluidos)

Convenciones: nombres traducidos (Unisys→legible); [P310 Lnnnn] = línea fuente; (BR: RN-S500-###) = regla.

1. Resumen funcional

P310-CARGA es el proceso batch mensual que cierra el ciclo de rendimientos de Cuentas Productivas Especiales (CPE) en el sistema de captación S500 de Banamex. Lee la tabla B39CTASCPE (cuentas CPE ordenadas por grupo/subgrupo/modalidad) e imputa tasa ISR, saldo promedio del ciclo, rendimiento pagado, ISR retenido y tasa bruta provenientes de B03CONTRATOS y B06HISTORICO (datos del ciclo mensual). Consolida acumulados de grupo en B37GRUPOCPE y genera el archivo mensual de constancias de retención para el SAT. El programa ejecuta procesamiento completo únicamente en el CSI-10 (VDM — Valle de México); para cuentas del CSI-04 (MTY — Monterrey) consume un archivo índice pre-calculado (ARCHIMTY) que el centro regional ya generó, evitando acceso DMSII directo a esos contratos.

PROCEDIMIENTO Manejador_Interrupcion_HI():           // INTERRUPT-BY-HI · [P310 L117708]

    DESACTIVAR interrupción (DISALLOW INTERRUPT)
    MOVER "I" A tipo_display                         // W77-TIPO-DISP: estado "Interrupt"
    MOVER TASKVALUE DE MYSELF A numero_hi            // W77-HI-NUMHI: número de señal HI recibida

    SI numero_hi = 10:
        SI donde_estoy = 0:                          // W77-DONDE-ESTOY: fase actual del programa
            mensaje = "NO HE INICIADO"
        SINO SI donde_estoy = 1:
            mensaje = "VALIDA Y GENERA ARCH INDEX MTY"

    MOVER "E" A tipo_display                         // W77-TIPO-DISP: estado "Ejecutando"
