S500 · P100 a Java 21 Spring Boot

P100 recibe un parámetro de dos dígitos: el primero es la opción y el segundo los días de retroceso. Lee el registro de control de Captación (S500B02CONTROL) o, para la opción 3 sin días, el de Tarjetas (S500B01PCONTROL), y según la opción proyecta la fecha de línea uno, dos o N días hacia atrás con LOCSUP, calcula el primer día del mes o el último del mes anterior, pide una fecha al operador, o devuelve el nodo activo o el indicador de Teletón. El resultado sale en el atributo TASKVALUE como ocho dígitos de fecha y dos de nodo. Fuera del servidor de desarrollo valida antes su versión.

    /** 20002010-FECHA-BD01: primera mitad de la tabla de opciones. */
    private RespuestaFecha desdeCaptacion(SolicitudFecha s) {
        ControlCaptacion b02 = control.find()
                .orElseThrow(() -> new ProcesoAbortadoException("ERROR REG. DE CONTROL VACIO"));   // DMTERMINATE
        int op = s.opcion(), d = s.diasAtras();

        if (op == 3 && d == 1) {                                  // opción "31": solo el nodo activo
            return RespuestaFecha.soloNodo(b02.usoFuturo05());
        }
        if (op > 0 && d > 0) {                                    // inválida: fecha de línea sin proyectar
            return RespuestaFecha.de(b02.fechaLinea(), b02.numCsi());
            // la condición (op == 3 && d > 1) del fuente ya está contenida en esta
        }
        if (op == 0 && d > 0) {                                   // "01".."09": d días hacia atrás
            return proyecta(b02, s);
        }
        return segundaMitad(b02, s);                              // opciones 9, 5, 6, 7, 8, 1, 2, 4 y 0
    }
    /** Segunda mitad de 20002010-FECHA-BD01. */
    private RespuestaFecha segundaMitad(ControlCaptacion b02, SolicitudFecha s) {
        return switch (s.opcion()) {
            case 9 -> new RespuestaFecha(b02.actTeleton(), b02.numCsi());   // indicador Teletón en el campo de fecha
            case 5 -> {
                LocalDate tecleada = consola.pideFechaValida();             // 20002100-PIDO-FECHA UNTIL WS-1VEZ = 1
                proyecta(b02, s);                                           // el fuente llama a LOCSUP aunque descarte el resultado
                yield RespuestaFecha.de(tecleada, b02.numCsi());
            }
            case 6 -> RespuestaFecha.de(ultimoDiaMesAnterior(b02.fechaLinea()), b02.numCsi());
            case 7 -> RespuestaFecha.de(b02.fechaLinea().withDayOfMonth(1), b02.numCsi());
            case 8 -> RespuestaFecha.de(b02.fechaLinea(), b02.numCsi());
            case 1, 2, 4 -> proyecta(b02, s);
            default -> proyecta(b02, s);                                    // opción 0 sin días
        };
    }
    /** 20002200-PROY-FEC + 40000000-CALL-FECPRO. */
    private RespuestaFecha proyecta(ControlCaptacion b02, SolicitudFecha s) {
        int dias = (s.diasAtras() > 0) ? s.diasAtras()
                 : (s.opcion() == 1)   ? 1
                 : 2;                                               // opciones 0, 2, 4 y 5
        LocalDate fecha = calendario.retrocede(b02.fechaLinea(), dias)   // LOCSUP función 15, formato 12
                .orElseThrow(() -> new ProcesoAbortadoException("ERROR AL ACCESAR LOCSUP"));
        return RespuestaFecha.de(fecha, b02.numCsi());
    }
    /** 20002300-FEC-ULTDIAMES, con la regla de bisiesto del fuente. */
    static LocalDate ultimoDiaMesAnterior(LocalDate fechaLinea) {
        int anio = fechaLinea.getYear(), mes = fechaLinea.getMonthValue();
        if (mes == 1) { mes = 12; anio -= 1; } else { mes -= 1; }
        int dia = DIAS_POR_MES[mes - 1];
        if (mes == 2 && anio % 4 == 0) {
            dia = 29;                       // el fuente no aplica la excepción de 100 y 400
        }
        return LocalDate.of(anio, mes, dia);
        // Equivalente gregoriano exacto: fechaLinea.withDayOfMonth(1).minusDays(1).
        // Coinciden en todos los años de 1901 a 2099; difieren en 2100.
    }

Riesgos de migración
Bisiesto incompleto

20002300-FEC-ULTDIAMES (líneas 472-476) considera bisiesto todo año divisible entre 4. En 2100 devolvería 29 de febrero.

Validación de fecha tecleada por campo

Los niveles 88 de las líneas 130-134 validan año, mes y día de forma independiente; se aceptan fechas imposibles como el 31 de febrero.

Condición redundante

En la línea 353, (WKS-VAL-OPCI = 3 AND WKS-VAL-DANT > 1) ya está contenida en (WKS-VAL-OPCI > 0 AND WKS-VAL-DANT > 0) de la línea 352.

Parámetros inválidos sin error

Cualquier combinación de opción y días distintos de cero, salvo 31, devuelve la fecha de línea sin aviso; el WFL no distingue un error de captura de una petición válida.

Opciones equivalentes y llamada descartada

Las opciones 0, 2 y 4 producen el mismo resultado. La opción 5 invoca LOCSUP y descarta su resultado, pero una falla de LOCSUP la aborta igual.

Hardcodes de ambiente

El host de desarrollo "ACYPBETA. " (línea 195) y la versión 25MTP007 (línea 190) están compilados. Se trasladan a configuración.
