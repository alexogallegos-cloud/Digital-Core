Este componente se documenta solo con el pseudocódigo extraído, porque el fuente L035.alg no está cargado en source/. Según ese pseudocódigo, L035 exporta once puntos de entrada con los nombres S038L035_nn y cada uno delega en el procedimiento S038L035_nn_C de MAPLICALL si la liga está activa, o devuelve 99 si no lo está. Resuelve en ejecución, con CTLVER, el título del objeto L036 y fuerza su carga con un punto de entrada vacío. El único envoltorio con lógica propia es el conteo de registros de una estructura, que adapta la firma y traslada los códigos de error al rango 71 a 76. Un hilo de control atiende comandos del operador por TASKVALUE para suspender, rehacer o consultar la liga.

public class MapliFachada implements MapliApi {

    private final ObjectProvider<MapliApi> implementacion;   // MAPLICALL = S500_L036 (MapliService)
    private final AtomicBoolean ligaActiva = new AtomicBoolean(false);   // B_LLAMAL036, global (SHAREDBYALL)

    public ResultadoMapli inicioPrograma(LlavePrograma llave, InicioPrograma in, Consumer<Integer> idSalida) {
        return delega(api -> api.inicioPrograma(llave, in, idSalida));
    }

    private ResultadoMapli delega(Function<MapliApi, ResultadoMapli> llamada) {
        if (!ligaActiva.get()) {
            return ResultadoMapli.LIBRERIA_NO_DISPONIBLE;   // 99: el programa de negocio sigue corriendo
        }
        return llamada.apply(implementacion.getObject());
    }
}

    public ResultadoConteo numeroRegistros(byte[] entrada) {
        if (!ligaActiva.get()) return ResultadoConteo.error(LIBRERIA_NO_DISPONIBLE);
        String estructura = Ebcdic.texto(entrada, 0, 17);
        String tituloBase = Ebcdic.texto(entrada, 17, 56).stripTrailing();   // L036 busca el fin en un blanco

        }
        return ResultadoConteo.ok(r.poblacion());   // long tipado; el adaptador COBOL decide el formato
    }

Riesgos de migración
Interruptor global del monitoreo

Según el pseudocódigo, la librería es SHAREDBYALL y B_LLAMAL036 es un solo indicador para todo el sistema: el comando de operador 1 deja sin monitoreo a todos los programas de S500 simultáneamente y no hay reintento automático.

Falla silenciosa al resolver la versión

Si DAME_TIT de CTLVER falla, solo se despliega ERROR CALL CTLVER; la liga sigue activa con el título anterior.

Salida binaria en un buffer EBCDIC

S038L035_06_NUM_REGS devuelve la población como palabra binaria sobre el arreglo de salida, a diferencia de las demás salidas que usan dígitos. El adaptador Java hacia COBOL debe respetar ese formato.

Apagado sin mensaje y autoextinción

El comando 4 no tiene rama en el CASE y termina el ciclo sin aviso; además, la librería se retira sola cuando LIBRARYUSERS llega a cero.
