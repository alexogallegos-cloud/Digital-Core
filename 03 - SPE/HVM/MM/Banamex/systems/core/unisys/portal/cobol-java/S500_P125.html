Lee el archivo de devoluciones de 180 bytes, asigna a cada detalle el nodo de impresión de su sucursal promotora y lo ordena por nodo, sucursal, moneda y contrato. Las devoluciones de cámara (clave 2002) van al reporte por sucursal promotora y, si el importe no excede el saldo disponible, también al consolidado; las demás claves van al reporte de ventanilla. Después lee el archivo de intentos de pago, valida su header contra el CSI y la fecha base, y emite un resumen por situación del cheque, nivel de seguridad lógica, código CHVV y causa CHECKBOLT, más un detalle de los intentos con error CHVV. Para cada nodo sin devoluciones genera reportes vacíos.

        int tipoRegistro,
        int sucursalPromotora,
        String contrato,               // 9(12) como String: conserva ceros
        String chequera,               // 9(16): prefijo 9(04) + 5 de relleno + cuenta 9(07)

@Component
@StepScope
@RequiredArgsConstructor
class AsignadorNodo implements ItemProcessor<Devolucion, Devolucion> {

    private final CatalogoSucursales s080;     // 42000080-DATOS-S080 (S080 catálogo de sucursales)
    private final P125Properties props;
    @Value("#{jobExecutionContext['csi']}") private int miCsi;

    @Override
    public Devolucion process(Devolucion d) {
        if (d.tipoRegistro() == 1 || d.tipoRegistro() == 9) {
            return d;                          // header y trailer pasan sin nodo
        }
        int nodo = s080.nodoImpresion(d.sucursalPromotora());   // cacheado por sucursal
        var regla = props.nodosPara(miCsi == 4 ? 4 : 10);
        return d.conNodo(regla.validos().contains(nodo) ? nodo : regla.porDefecto());
    }
}

public enum ReporteDevolucion { DEVASUC, DEVCONSDO, DEVVENT }

@Component
@RequiredArgsConstructor
class ClasificadorDevolucion implements ItemProcessor<Devolucion, Devolucion> {

    private final P125Properties props;   // clave-camara: 2002

    /** 50001200-PRIMER-DETALLE: cámara va a sucursal promotora (y consolidado si alcanza el saldo). */
    @Override
    public Devolucion process(Devolucion d) {
        if (d.claveMovimiento() == props.claveCamara()) {
            d.agregaDestino(ReporteDevolucion.DEVASUC);
            if (d.importe().compareTo(d.saldoDisponible()) <= 0) {
                d.agregaDestino(ReporteDevolucion.DEVCONSDO);   // la devolución pudo cubrirse con saldo
            }
        } else {
            d.agregaDestino(ReporteDevolucion.DEVVENT);         // cualquier otra clave: ventanilla
        }
        return d;
    }
}

/** Totales del reporte consolidado: por sucursal y por nodo separados en MN y DL. */
public final class TotalesConsolidado {
    private long numSucursal;  private BigDecimal impSucursal = BigDecimal.ZERO.setScale(2);
    private long numMn;        private BigDecimal impMn       = BigDecimal.ZERO.setScale(2);
    private long numDl;        private BigDecimal impDl       = BigDecimal.ZERO.setScale(2);

    void suma(Devolucion d) {
        numSucursal++;
        impSucursal = impSucursal.add(d.importe());          // ADD ... TO WKS-TOTS-R03-IMP
        if (d.moneda() == 1) {
            numMn++;  impMn = impMn.add(d.importe());
        } else {
            numDl++;  impDl = impDl.add(d.importe());        // toda moneda distinta de 1
        }
    }
}

/** 50007200-VALIDA-INTPAG: si el header no corresponde, el archivo no se procesa. */
Optional<String> validaHeader(Optional<HeaderIntentos> h, int miCsi, LocalDate fechaBase,
                              String titulo) {
    if (h.isEmpty() || h.get().tipo() != 1) {
        return Optional.of("ARCHIVO %s SIN HEADER, (NO SE PROCESA)".formatted(titulo));
    }
    if (h.get().csi() != miCsi || !h.get().fechaBase().equals(fechaBase)) {
        return Optional.of("ARCHIVO %s ERRONEO, HEADER %s (NO SE PROCESA)"
                .formatted(titulo, h.get()));
    }
    return Optional.empty();   // header correcto: se procesan los detalles
}

/** 50013300 / 50013350: solo los intentos con CHVV 1, 2 o 3; corte y total por moneda. */
void detalleChvv(Stream<IntentoPago> porMonedaYChequera, ReporteChvv r05) {
    porMonedaYChequera
        .filter(IntentoPago::conErrorChvv)
        .collect(Collectors.groupingBy(IntentoPago::moneda, TreeMap::new, Collectors.toList()))
        .forEach((moneda, lista) -> {
            r05.encabezado(moneda);
            lista.forEach(i -> r05.renglon(i.sucursalOpera(), i.cajaOpera(), i.nominaOperador(),
                    i.sucursalPromotora(), i.contrato(), i.prefijo(), i.cuenta(),
                    i.numeroCheque(), i.importe(), ErrorChvv.de(i.codigoChvv()).leyenda));
            r05.total(lista.size(), lista.stream().map(IntentoPago::importe)
                    .reduce(BigDecimal.ZERO, BigDecimal::add));
        });
}

Riesgos de migración
El detalle CHVV no respeta la validación de header

50007200-VALIDA-INTPAG descarta un archivo con header erróneo para el resumen 004, pero 50013250-LEEHEADER-INTPAG (línea 2096) solo lee el header y el reporte 005 procesa los detalles de todos modos.

Nodos y claves compilados

Los nodos válidos por CSI (líneas 2416-2425), las listas de nodos para reportes vacíos (líneas 961-967), la clave de cámara 2002 y el prefijo S500/LIST/P125/ están en el fuente. Se trasladan a application.yml.

Reportes vacíos para el nodo 00

WKS-NODOS-VDM vale 1009000000, es decir nodos 10, 09, 00, 00 y 00. 70006200-GENERA-VACIO usa la posición del reporte como índice de nodo, de modo que en Valle de México puede generar reportes vacíos para el nodo 00.

Moneda binaria

Los acumuladores separan moneda 1 contra cualquier otra; una moneda distinta de pesos y dólares se sumaría como dólares.

Archivo ordenado sobre sí mismo

Los SORT de devoluciones e intentos usan GIVING sobre el mismo archivo de entrada con SAVE, por lo que el orden original se pierde y un reinicio a mitad del paso trabaja sobre el archivo ya ordenado.
