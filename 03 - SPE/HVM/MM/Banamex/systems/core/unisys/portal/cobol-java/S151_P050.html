Después entra a un ciclo de espera COMS: cada mensaje se despacha en 240-MANEJA-MSG por el código de función del texto hacia consultas de saldos globales, por sucursal y por cliente, conceptos de caja, depósitos S333, SAR y sincronización entre hosts, y siempre termina en 800-RESPONDE. En días hábiles y por horario arma la cápsula ACCIVAL a partir del log LOG1S151, filtrando por función, origen, una lista fija de cuentas y la naturaleza contable de cada clave de transacción.

@Service
@RequiredArgsConstructor
class ContextoNodoService {

    private final NodoProperties props;
    private final ControlS151Client control;   // CONSISDIA IN S151LIBCONTROL

    ContextoNodo resuelve(int csi, LocalDate fechaMaquina) {
        SistemaDia sis500 = control.consisdia(csi, 500, 1)
                .orElseThrow(() -> new ArranqueFallidoException(
                        "ERROR AL CONSULTAR S151LIBCONTROL PARA OBTENER NOMBRE DE LA BASE DIARIA"));

        // IF WKS-NUMCSI = 4 OR 10 AND FECCON < MAQUINA se evalúa como
        // (CSI = 4) OR (CSI = 10 AND FECCON < MAQUINA): AND precede a OR.
        LocalDate feccon = sis500.fecCon();
        if (csi == 4 || (csi == 10 && feccon.isBefore(fechaMaquina))) {
            feccon = fechaMaquina;
        }
        return new ContextoNodo(csi, props.csiEnvio(csi),
                sis500.nombreBaseSemanal(), sis500.packMovimientos(),
                feccon,            // WKS-LOG1-FECHA y WKS-S500-FECHA
                fechaMaquina);     // W77-FCH-S500: el fuente la sobrescribe con la fecha máquina
    }
}

/** Cada PERFORM del IF anidado se vuelve una implementación registrada por código. */
public interface FuncionSaldos {
    int codigo();
    void atiende(MensajeComs msg, Respuesta resp);
}

@Service
@RequiredArgsConstructor
class AdSaldoMessageHandler {

    private static final Set<Integer> SIN_ACCION = Set.of(25, 72, 73);   // NEXT SENTENCE en el fuente
    private final List<FuncionSaldos> funciones;   // 300-GLOBALES, 400-SUCURSAL, ... 22000-BUSCA-MOVS
    private final LogSaldosWriter logSaldos;       // 245-GRABA-LOGSALDOS
    private final ConcentracionTotales concentra;  // 205-VERIFICA-SAR + 210-VERIFICA-DIALOGO
    private Map<Integer, FuncionSaldos> porCodigo;

    @PostConstruct
    void indexa() {
        porCodigo = funciones.stream()
                .collect(Collectors.toUnmodifiableMap(FuncionSaldos::codigo, f -> f));
    }

    Respuesta maneja(MensajeComs msg) {
        if (msg.hdrRes() == 2) logSaldos.graba(msg);
        var resp = Respuesta.nueva();                  // WS-ERROR = 0, WS-FORMATOS = SPACES
        int fun = msg.funcion();                       // WS-TXT-FUN
        if (fun == 1 && msg.hdrRes() == 2) {
            concentra.verificaSarYDialogo();           // función 1 como respuesta: concentra
        } else if (!SIN_ACCION.contains(fun)) {
            Optional.ofNullable(porCodigo.get(fun))
                    .ifPresentOrElse(f -> f.atiende(msg, resp),
                                     () -> resp.error(1));   // MOVE 1 TO WS-ERROR
        }
        return resp;                                   // PERFORM 800-RESPONDE
    }
}

@Component
@RequiredArgsConstructor
class CapsulaAccivalProcessor implements ItemProcessor<MovimientoLog, List<RegistroAccival>> {

    private final CapsulaProperties props;

    @Override
    public List<RegistroAccival> process(MovimientoLog m) {
        boolean entra = m.funcion() == 1
                && props.origenes().contains(m.origen())
                && props.cuentas().contains(new CuentaMadre(m.mdaSuc(), m.mdaCta()));
        if (!entra) return null;                       // se filtra; la llave del log avanza igual
        var base = RegistroAccival.desde(m);           // 9977-MUEVE-INF-ACCIVAL
        return m.claves().stream()                     // hasta 5 CVETRAN, termina en la primera en 0
                .takeWhile(c -> c.cvetran() != 0)
                .limit(5)
                .map(c -> clasifica(base, c))
                .flatMap(Optional::stream)
                .toList();
    }
    private final NaturalezaContable naturalezas;   // WKS-TAB-NATCON, cargada desde catálogo S080

    /** 9979-MUEVE-IMP-ACCIVAL + 9992-GRABA-ACCIVAL. */
    private Optional<RegistroAccival> clasifica(RegistroAccival base, ClaveImporte c) {
        int clave = c.cvetran();
        if (clave == 1009) return Optional.empty();                      // excluida sin aviso
        OptionalInt nat = naturalezas.de(clave);                          // 1 = cargo, 2 = abono
        if (nat.isPresent() && (nat.getAsInt() == 1 || nat.getAsInt() == 2)) {
            return Optional.of(base.con(clave, nat.getAsInt(), c.importe()));
        }
        if (clave > 730 && clave < 747) {
            // abono forzado: el importe viaja como leyenda y el campo importe va en cero
            return Optional.of(base.conLeyenda(clave, 2, c.importe()));
        }
        return Optional.empty();
    }
}

Riesgos de migración
Filtros SECORE distintos a los documentados

En 9966-ARMA-SIG (líneas 15557-15566) el origen aceptado es 1 o 3, no 1 o 2, y en 9979-MUEVE-IMP-ACCIVAL (líneas 15615-15617) se graban naturalezas 1 y 2. Ninguno de los dos coincide con MRA 031 y MRA 032 ni con RN-S151-289 y RN-S151-290. La selección además depende de ocho cuentas compiladas.

Ventana de envío declarada y no usada

WS-HORA-INI-ENV (08000000) y WS-HORA-TER-ENV (14050000), en las líneas 9010-9011, no se referencian en la PROCEDURE DIVISION. La ventana efectiva sale de WS-HORA-NEXT, que arranca en 07300000 (línea 9555), WS-HORA-PARARENVIO con VALUE 14000000 (línea 6380) y WKS-CORTE-X-HORA con VALUE 14550000 (línea 5587).

Truncamiento y pérdida de signo en saldos globales

340-RESTO-CAMPOS divide entre 1000 sin ROUNDED hacia un PIC S9(10) entero y mueve el resultado a campos editados sin signo (ZZZZ,ZZZ,ZZZ). Los centavos se pierden y un saldo negativo se presenta como positivo; solo la variación lleva signo.

Sistema no encontrado toma la posición 20

330-ASIGNA-SISTEMA asigna WS-IND-SIS = 20 cuando el sistema pedido no aparece en las 20 posiciones, y 340-RESTO-CAMPOS presenta los saldos de esa posición si son mayores a cero.

Precedencia de AND sobre OR en la corrección de FECCON

La condición de la línea 9427 se evalúa como CSI = 4 OR (CSI = 10 AND FECCON < fecha máquina). En Monterrey la fecha se reemplaza siempre.

Punto final desplazado por la renovación CRONOS 2000

En 200-ACEPTA-MSG (líneas 9989-9996) el IF solo controla el PERFORM A2K-ACCEPT-TODAYS-DATE; el resto del bloque se ejecuta siempre con la última fecha leída.

Hardcodes de títulos, nodos y catálogos

Títulos de librería de respaldo (L006, L001, LIBEST), sustituciones de CSI 10 a 04 y 32 a 12, el factor 1000, los 180 días por defecto y la lista de cuentas de la cápsula están compilados. Se trasladan a application.yml.
