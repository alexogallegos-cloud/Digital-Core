S500 · P179 a Java 21 Spring Boot

Lee la bandera de decomiso de S111 en S500B02CONTROL; si vale 0, abre (S500)S500/FILE/S111/04/DEPINICIAL/aammdd y (S500)S500/FILE/S111/10/DEPINICIAL/aammdd y crea (S500)S500/FILE/S111/DEPINICIAL/aammdd. Escribe un header propio con la fecha, S500 como origen, S111 como destino y CSI 10, y copia los detalles del archivo de Monterrey y luego los del de Valle. En cada archivo de entrada valida que el header traiga la fecha del parámetro y el CSI esperado (04 o 10), y que el trailer cuadre con los detalles leídos; cualquier diferencia o la falta de trailer termina el paso con estado -1. Al final escribe un trailer con el total de detalles de ambos archivos.

/** WKS-REG-S111-ENVIO: 40 bytes; el tipo 9(02) distingue 00 header, 99 trailer y cualquier otro detalle. */
public sealed interface RegistroS111 permits RegistroS111.Header, RegistroS111.Detalle,
                                            RegistroS111.Trailer {
    String raw();

    record Header(LocalDate fecha,          // 9(08) AAAAMMDD
                  String sistemaOrigen,     // X(04)
                  String sistemaDestino,    // X(04)
                  int csiOrigen,            // 9(02): 04 MTY, 10 VDM
                  String raw) implements RegistroS111 {}

    record Detalle(String tarjeta,          // 9(16): texto, conserva ceros
                   String contrato,         // 9(12)
                   int sucursalPromotora,   // 9(04)
                   String raw) implements RegistroS111 {}

    record Trailer(long numRegistros, String raw) implements RegistroS111 {}   // 9(08)

    static RegistroS111 parse(String r) {
        return switch (r.substring(0, 2)) {
            case "00" -> new Header(LocalDate.parse(r.substring(2, 10), BASIC_ISO_DATE),
                    r.substring(10, 14), r.substring(14, 18), Integer.parseInt(r.substring(18, 20)), r);
            case "99" -> new Trailer(Long.parseLong(r.substring(2, 10)), r);
            default   -> new Detalle(r.substring(2, 18), r.substring(18, 30),
                    Integer.parseInt(r.substring(30, 34)), r);   // P179 copia el detalle sin interpretarlo
        };
    }
}

@Component

public class DecomisoS111Decider implements JobExecutionDecider {

    private final ControlCaptacionRepository b02;   // S500B02CONTROL, OPEN INQUIRY

    @Override
    public FlowExecutionStatus decide(JobExecution job, StepExecution step) {
        var control = b02.findFirst()
                .orElseThrow(() -> new ProcesoAbortadoException(
                        "NO EXISTE B02CONTROL EN S500BD01CAPTACION"));   // el COBOL solo avisa y sigue
        int decomiso = control.usoFuturo05();          // B02-USO-FUTURO-05
        return (decomiso == 0)
                ? new FlowExecutionStatus("GENERA")
                : new FlowExecutionStatus("S111_DECOMISIONADO");      // termina sin abrir archivos
    }

@Bean
Step concentraDepInicial(JobRepository repo, PlatformTransactionManager tx,
                         P179Properties props, ResourceLoader rl,
                         @Value("#{jobParameters['fechaProceso']}") LocalDate fecha,
                         ValidadorArchivoS111 validador, DepInicialWriter salida) {

    Resource[] entradas = props.entradas().stream()
            .map(e -> rl.getResource(props.resuelve(e.ruta(), fecha)))
            .toArray(Resource[]::new);

    var lector = new MultiResourceItemReaderBuilder<RegistroS111>()
            .name("depInicialMtyVdm")
            .resources(entradas)
            .comparator((a, b) -> 0)          // no reordenar: MTY (archivo 1) antes que VDM (archivo 2)
            .delegate(lineaS111Reader())      // FlatFileItemReader de 40 bytes -> RegistroS111.parse
            .build();

    return new StepBuilder("concentraDepInicial", repo)
            .<RegistroS111, RegistroS111>chunk(360, tx)   // BLOCK CONTAINS 360 RECORDS
            .reader(lector)
            .processor(validador)             // valida header/trailer y deja pasar solo detalles
            .writer(salida)                   // header propio al abrir, trailer total al cerrar
            .build();
}
@Component
@StepScope
@RequiredArgsConstructor
public class DepInicialWriter extends FlatFileItemWriter<RegistroS111> {

    private final P179Properties props;
    @Value("#{jobParameters['fechaProceso']}") private LocalDate fecha;
    private long detalles;                                   // WKS-I01-NUM-REG

    @PostConstruct
    void configura() {
        setLineAggregator(RegistroS111::raw);
        setHeaderCallback(w -> w.write(Fixed.headerS111(     // 20101000-GENERA-HEADER, tipo 00
                fecha, props.header().sistemaOrigen(),
                props.header().sistemaDestino(), props.header().csiOrigen())));
        setFooterCallback(w -> w.write(Fixed.trailerS111(detalles)));   // tipo 99 con el total
    }

    @Override
    public void write(Chunk<? extends RegistroS111> chunk) throws Exception {
        detalles += chunk.size();
        super.write(chunk);
    }
}
@Component
@StepScope
@RequiredArgsConstructor
public class ValidadorArchivoS111 implements ItemProcessor<RegistroS111, RegistroS111> {

    private final P179Properties props;
    @Value("#{jobParameters['fechaProceso']}") private LocalDate fecha;
    private int archivo = 1;                 // WKS-E01-NUM-ARCHIVO
    private long detallesArchivo;            // WKS-E01-REG-DETALLE
    private boolean trailerVisto;

    @Override
    public RegistroS111 process(RegistroS111 r) {
        return switch (r) {
            case RegistroS111.Header h  -> { validaHeader(h); yield null; }   // no se copia
            case RegistroS111.Trailer t -> { validaTrailer(t); yield null; }
            case RegistroS111.Detalle d -> { detallesArchivo++; yield d; }    // 20101030-MUEVE-DETALLE
        };
    }

    private void validaHeader(RegistroS111.Header h) {
        int csiEsperado = props.entradas().get(archivo - 1).csi();   // 04 para MTY, 10 para VDM
        if (!h.fecha().equals(fecha) || h.csiOrigen() != csiEsperado) {
            throw new ArchivoS111InvalidoException("ERROR EN HEADER DEL ARCHIVO: %d FECHA: %s CSI: %d"
                    .formatted(archivo, h.fecha(), h.csiOrigen()));   // STATUS OF MYSELF := -1
        }
    }
}
    /** 20101020-VALIDA-TRAILER: cierra el archivo actual y exige que el conteo cuadre. */
    private void validaTrailer(RegistroS111.Trailer t) {
        if (t.numRegistros() != detallesArchivo) {
            throw new ArchivoS111InvalidoException(
                    "TERMINO <CON ERROR> ARCHIVO: %d REGISTROS EN TRL: %d REGISTROS LEIDOS: %d"
                            .formatted(archivo, t.numRegistros(), detallesArchivo));
        }
        log.info("TERMINO <SIN ERROR> ARCHIVO: {} REGISTROS: {}", archivo, t.numRegistros());
        archivo++;                    // MOVE ZEROS TO WKS-E01-REG-DETALLE y siguiente archivo
        detallesArchivo = 0;
        trailerVisto = true;
    }

    @AfterStep
    ExitStatus verificaTrailers(StepExecution se) {
        if (archivo != 3) {           // los dos archivos deben haber cerrado con trailer
            throw new ArchivoS111InvalidoException("ERROR ARCHIVO SIN TRAILER: " + archivo);
        }
        return se.getExitStatus();
    }
}
Riesgos de migración
Generación sin poder consultar el decomiso

Si falla el FIND de S500B02CONTROL (líneas 221-231) el programa avisa y continúa con la bandera en 0, generando el archivo para S111 aunque el sistema pudiera estar decomisionado.

Header de entrada opcional

20101000-PROCESA-DETALLE (líneas 343-349) valida el header solo si aparece un registro tipo 00; un archivo sin header se copia sin validar fecha ni plaza.

Tipos de registro no reconocidos

Todo registro con tipo distinto de 00 y 99 se trata como detalle y se copia a la salida.

CSI fijo en el header de salida

El header que recibe S111 lleva siempre CSI 10 (línea 323), aunque el archivo combine movimientos de Monterrey y Valle de México.

Código sin uso

70000100-LLAMA-FECHAS (líneas 441-457) y WKS-AUX-FECH-PROYECTADA (línea 157) no se invocan ni se leen en este fuente; LOCSUP se enlaza en 10000010-LIBRERIAS pero no se llama (el copybook S500/INC/PRO/25MTP005 no viene en el fuente).

Hardcodes

Usuario (S500), nodos 04 y 10, nombre DEPINICIAL, literales S500, S111 y CSI 10 están compilados; se trasladan a application.yml.

Pendiente de revisión SME
  • Confirmar con el SME el significado y los valores posibles de B02-USO-FUTURO-05 como bandera de decomiso de S111.
  • Confirmar si S111 necesita saber la plaza de origen de cada movimiento, dado que el header de salida siempre dice CSI 10.
  • Validar si un archivo de entrada sin header debe rechazarse; el fuente lo acepta.
  • Confirmar el formato del TASKVALUE con que el WFL invoca P179: el programa lo trata como fecha AAAAMMDD de 8 dígitos.
