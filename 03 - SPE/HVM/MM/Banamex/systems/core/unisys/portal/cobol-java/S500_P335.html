S500 · P335 a Java 21 Spring Boot

P335 abre S500BD01CAPTACION en modo de consulta y, si el CSI de control es 10, recorre B39CTASCPE en orden de grupo y subgrupo. Por cada cuenta vigente (estatus 0 o 1) escribe un detalle con saldo promedio, tasas, cheques, productos, comisión más IVA e ISR, y acumula esos importes por subgrupo, grupo y total general. En cada corte de grupo escribe los registros de datos de sucursal, datos del cliente, resumen CPE, encabezados y totales con comisiones e IVA a 10 y 15 por ciento tomados de B37. El archivo intermedio ARCHED1 se ordena por grupo, cliente y tipo de registro y se depura a los tipos válidos para producir ARCHEDO.

    static BigDecimal campo8v2(BigDecimal v) {
        BigDecimal abs = v.abs().setScale(2, RoundingMode.DOWN);

@Component
@StepScope
public class CorteGrupoProcessor implements ItemProcessor<CuentaCpe, List<SobreEdoCta>> {

    private Long grupoAnt;                    // WS-GPO-ANT
    private Integer subgrupoAnt;              // WS-SGP-ANT
    private int cuentasOkGrupo, cuentasOkSubgrupo;   // WS-CTAS-STAT-OKGP / OKSG
    private final Acumuladores acum = new Acumuladores();   // WKS-ACUM-ARCHED1

    /** 200-GENERA-EDOCTA: lectura de B39 por el set B39SXGPOSBGMDA (grupo, subgrupo, modalidad). */
    @Override
    public List<SobreEdoCta> process(CuentaCpe c) {
        List<SobreEdoCta> salida = new ArrayList<>();
        if (grupoAnt == null) { grupoAnt = c.grupo(); subgrupoAnt = c.subgrupo(); }

        if (c.grupo() != grupoAnt) {
            if (cuentasOkGrupo > 0) {                         // un grupo sin cuentas vigentes no se reporta
                cuentasOkGrupo = cuentasOkSubgrupo = 0;
                salida.addAll(cierraGrupo(grupoAnt, subgrupoAnt));   // 205-CAMBIO-GRUPO
            }
        } else if (c.subgrupo() != subgrupoAnt && cuentasOkSubgrupo > 0) {
            cuentasOkSubgrupo = 0;
            salida.addAll(cierraSubgrupo(grupoAnt, subgrupoAnt));    // 207-CAMBIO-SUBGPO
        }
        grupoAnt = c.grupo();
        subgrupoAnt = c.subgrupo();
        if (c.status() == 0 || c.status() == 1) {             // solo cuentas vigentes
            cuentasOkGrupo++; cuentasOkSubgrupo++;
            salida.add(detalle(c));                           // 250-GRABA-POR-CTA
        }
        return salida;
    }
    // 300-TERMINA: un StepExecutionListener.afterStep cierra el último grupo y escribe el trailer.
}

Riesgos de migración
Fuente intercambiado en el inventario

El archivo registrado para P335 (S500_SOURCE_P335.txt) contiene el programa S500P400, y S500_SOURCE_P400.txt contiene P335-EDOCTA (PROGRAM-ID en la línea 14). Este borrador cita líneas de S500_SOURCE_P400.txt, que es la ruta que ahora registra el inventario para S500_P335.

Truncamiento de totales

Los acumuladores WKS-*-X-GPO son 9(12)V99 (líneas 136-142) y se mueven a campos 9(08)V99 de los registros 701190 y 709000 (líneas 272-280 y 288-296). Grupos con productos, comisiones o producto neto de 100 millones o más se reportarían sin los dígitos altos.

Pérdida de signo en tasa adicional

RDC-TASA-ADIC (línea 244) es 9(02)V99 sin signo y recibe la resta B39-TASA-NTA-500 menos B39-TASA-NTA-152 (líneas 822-823). Una diferencia negativa se reporta como positiva.

Tope de memoria del SORT con un dígito menos

En 400-CLASIFIC-EDOCT (líneas 990-991) el límite superior se compara contra 258435000 pero se asigna 25843500. Si el archivo crece, el SORT recibe diez veces menos memoria de la prevista.

Errores de escritura no detienen el paso

350-GRABA-ARCHED1 y 420-GENERA-ARCHEDO solo ponen el estatus de la tarea en -1 ante un error de WRITE (líneas 972 y 1033); el programa sigue escribiendo y el estado de cuenta podría quedar incompleto.

Valores fijos

CSI 10, nodos 12/12 de las rutas S050 y S051 y el domicilio de Banca Corporativa (líneas 648-653) están compilados. Se trasladan a application.yml.
