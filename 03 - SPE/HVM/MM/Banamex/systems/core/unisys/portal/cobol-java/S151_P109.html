Lee el archivo LOG151 del sistema indicado, valida su header y selecciona los movimientos de alta autorizados o eliminados. Los autorizados con origen 1 o 3 se desglosan en hasta cinco claves de transacción, se ordenan y acumulan por una clave de 11 dimensiones y se traducen en partidas de cargo y abono mediante la cadena de catálogos INDS250, CAT7 y ESQCON. Con esas partidas genera MOVCONTABLES, la bitácora, el punteo hacia el sistema origen, el cuadre contable por cuenta y, según el tipo de base, la posición diaria en S151B72POSCONTA.

/** LOG151: el fin lógico es el registro FUNCION = 99, no el fin físico del archivo. */
public class Log151ItemReader implements ItemReader<RegistroLog151> {
    private final ItemReader<RegistroLog151> delegado;
    private boolean fin;

    @Override
    public RegistroLog151 read() throws Exception {
        if (fin) return null;
        RegistroLog151 r = delegado.read();               // READ LOG151 ... AT END
        if (r == null || r.funcion() == 99) {             // centinela: nunca se procesa como asiento
            fin = true;
            return null;
        }
        return r;
    }
}

Riesgos de migración
Header de LOG151 inválido no detiene el proceso

En 20000-PROCESA-MOVIMIENTOS (líneas 9992-10018) los errores de tipo de registro y de fecha solo imprimen un mensaje; el SET MYSELF(STATUS) TO -1 está comentado. Un LOG151 de otra fecha se contabiliza.

Condición abreviada siempre verdadera en RECHAZOS

La línea 7848 (IF W77-SISTEMA-PARAMETRO NOT = 702 OR 502) se expande en COBOL-85 a NOT = 702 OR NOT = 502, que se cumple para cualquier sistema. Contradice RN-S151-050.

Lectura de ESQCON fallida continúa con datos previos

En 21121-MUEVE-CUENTAS-CONTABLES (líneas 10905-10913) el INVALID KEY solo envía un mensaje; el IF siguiente evalúa WKS-EQ-NAT-MOV del último registro leído.

Truncamiento de importes

IMPORTE1..5 de LOG151 son 9(16)V99 y se mueven a RMS-IMPORTE 9(14)V99; W77-IMP-SORT 9(16)V99 se mueve a RMC-IMPORTE 9(14)V99. En ambos casos COBOL descarta los dígitos altos sin aviso.

Validación de índices comentada

El rango de W77-IND (1 a 200) y W77-IND2 (1 a 150) no se valida (líneas 10839-10842) antes de usar las tablas en memoria.

Hardcodes

CSI 12 mapeado a 10 (líneas 8012-8013), cuentas 1503 y 150399000000, grupo 5 por defecto, producto 087, sectores 31 y 32 para C408 y la lista de sistemas en las condiciones de ruteo. Se proponen como parámetros en application.yml o en tabla.
