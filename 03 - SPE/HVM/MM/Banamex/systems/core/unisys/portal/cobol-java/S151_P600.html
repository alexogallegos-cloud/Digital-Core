S151 · P600 a Java 21 Spring Boot

Resuelve por CTLVERS el título de la librería de control L001 y recorre con B04SISTEM todos los sistemas registrados. Para cada sistema consulta CONSISMEN y CONSISDIA (función 01) y, si el sistema está en estatus 3 o 5 y reside en el CSI de la máquina o no tiene modo de residencia, guarda sus fechas en una tabla de 50 posiciones y pide a su librería L002 (función 5 de CONTROLES) la fecha de línea y el nivel de registros recibidos. Para el sistema 500 consulta además L009 y L012. Al final despliega un renglón por sistema y otro por cada librería de envío. Su WORKING-STORAGE incluye el copy LIBCONTROL que documenta las diez funciones de CONSISDIA, aunque el programa sólo usa la consulta.

/** WKS-S151B01SISDIA: estado del día de un sistema en un CSI. */
public record SistemaDia(
        int sistema, int csi,
        LocalDate fechaProceso,        // FECPRO    9(08) AAAAMMDD
        LocalDate fechaConsulta,       // FECCON
        LocalDate fechaProcesoS151,    // FECPRO151
        int estatusRegistro,           // STAREG
        ArchivoMcp salida, ArchivoMcp movimientos, ArchivoMcp descriptores, ArchivoMcp errores,
        String baseSemanal,            // NOMBDSEM X(17)
        int estatusBaseSemanal,        // STABDSEM
        int numArchivo, int tercerNivel,
        List<ControlDia> dias) {       // CTL-DIA OCCURS 10

    /** Nombre de archivo (X(34)) más pack (X(17)), como los arma MCP. */
    public record ArchivoMcp(String nombre, String pack) {}

    public record ControlDia(LocalDate fechaArchivoMovs,   // FECARCMOV
                             long nivelArchivoMovs,        // NIVARCMOV 9(08)
                             long nivelBaseMovs,           // NIVBDMOV  9(08)
                             int statusLog) {}             // STAARCLOG 9(02)

    public SistemaDia {
        if (dias.size() != 10) throw new IllegalArgumentException("CTL-DIA OCCURS 10 TIMES");
        dias = List.copyOf(dias);
    }
}

    private final SoporteComsClient coms;         // CSIID OF SOPORTECOMS

                .orElse(props.libControlDefault());              // título compilado de respaldo

@Component
@StepScope
@RequiredArgsConstructor
public class SistemasActivosReader implements ItemReader<SistemaDia> {

    private static final Set<Integer> ESTATUS_ACTIVOS = Set.of(3, 5);   // WKS-B04-ESTATUS
    private final LibControlClient libControl;
    private final LibreriasResolver libs;
    private Iterator<SistemaB04> sistemas;

    @Override
    public SistemaDia read() {
        if (sistemas == null) sistemas = libControl.recorreB04().iterator();   // B04SISTEM función 02
        int csi = libs.csiEfectivo();
        while (sistemas.hasNext()) {
            SistemaB04 s = sistemas.next();
            var men = libControl.consisMen(s.numero());          // CONSISMEN función 01
            if (men.isEmpty()) continue;
            var dia = libControl.consulta(s.numero(), 0);        // CONSISDIA F01; WKS-B01-CSI nunca se asigna
            boolean resideAqui = men.get().csiResidencia() == csi || men.get().modo() == 0;
            if (dia != null && ESTATUS_ACTIVOS.contains(s.estatus()) && resideAqui) {
                return dia;                                      // ADD 1 TO W77-IND
            }
        }
        return null;                                             // W77-FIN = 1
    }
}

@Component
@RequiredArgsConstructor
public class NivelesL002Processor implements ItemProcessor<SistemaDia, RenglonFechas> {

    private final RegistroContableResolver l002;   // "S151L002R" + sistema 9(03)
    private final ConsolaOperador consola;

    @Override
    public RenglonFechas process(SistemaDia d) {
        RegistroContable lib = l002.para(d.sistema());               // CTLVERS o título por defecto
        var r = lib.controles(DatosControles.funcion(5));            // fecha de proceso + nivel del canal
        LocalDate fecLinea = r.ok() ? r.fechaLinea() : null;
        Long recibidos = r.ok() ? r.recibidos() : null;
        if (d.sistema() == 500) {
            lib.controles(DatosControles.funcion(1));                // L002 despliega sus niveles en consola
        }
        return new RenglonFechas(d.sistema(), d.fechaConsulta(), d.fechaProceso(),
                                 d.fechaProcesoS151(), fecLinea, recibidos);
    }
}
@Component
@RequiredArgsConstructor
public class Librerias500Tasklet implements Tasklet {

    private final EnvioConfirmacionClient l009;    // FUNCIONES IN LIB-L009
    private final EnvioConfirmacionClient l012;    // FUNCIONL12 IN LIB-L012
    private final P600Properties props;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        var ec = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        l009.consulta(5).ifPresent(r -> ec.put("L009", r));        // fecha, enviados, confirmados
        l012.consulta(5).ifPresent(r -> ec.put("L012", r));
        // El fuente llama también FUNCIONL12 con función 1 (líneas 864-868); la misma llamada
        // a L009 está comentada (841-845). Se deja configurable hasta conocer su efecto.
        if (props.l012().invocaFuncion1()) {
            l012.invoca(1);
        }
        return RepeatStatus.FINISHED;
    }
}
@Component
@RequiredArgsConstructor
public class DespliegueWriter implements ItemWriter<RenglonFechas> {

    private final ConsolaOperador consola;       // LJ IN LIB-DISP

    @Override
    public void write(Chunk<? extends RenglonFechas> chunk) {
        for (RenglonFechas r : chunk) {
            consola.informa("S%03d Linea %s Batch %s S151 %s L002 %s REG. %08d".formatted(
                    r.sistema(), aaaammdd(r.fechaConsulta()), aaaammdd(r.fechaProceso()),
                    aaaammdd(r.fechaS151()), aaaammdd(r.fechaLinea()),
                    Objects.requireNonNullElse(r.recibidos(), 0L)));
        }
    }

    /** 000500-DSP-LIBRERIAS se ejecuta una vez, aun cuando no hubo sistema 500. */
    public void librerias(EnvioConfirmacion l009, EnvioConfirmacion l012) {
        consola.informa("L009 FEC %s ENV %08d CONF %08d".formatted(l009.fecha(), l009.enviados(), l009.confirmados()));
        consola.informa("L012 FEC %s ENV %08d CONF %08d".formatted(l012.fecha(), l012.enviados(), l012.confirmados()));
    }

    private static String aaaammdd(LocalDate f) {
        return f == null ? "00000000" : f.format(DateTimeFormatter.BASIC_ISO_DATE);
    }
}

Riesgos de migración
Tabla de sistemas sin control de límite

WKS-TAB-FECHAS tiene 50 posiciones (línea 626) y el índice W77-IND (PIC 9(02)) no se compara contra ese límite en 000310-CALL-L001. Además WKS-TAB-SISTEMA es PIC 9(03) y recibe WKS-B01-SISTEMA de 4 dígitos.

CONSISDIA sin CSI asignado

El copy exige sistema y CSI para la función 1, pero 000310-CALL-L001 sólo mueve el sistema a WKS-B01-SISTEMA; WKS-B01-CSI nunca se asigna. Las líneas 712-713 llenan WKS-CON-FUNCION y WKS-CON-CSI, que pertenecen a otra estructura no usada en ninguna llamada.

Parámetro de fecha sin efecto

La fecha recibida por VALUE de la tarea se mueve a WKS-PARAM-FECHA (línea 704) y no se usa en ningún párrafo.

Llamada activa con función 1 a L012

En 000440-LLAMA-L012 (líneas 864-868) se invoca FUNCIONL12 con función 1 después de la consulta, mientras que la llamada equivalente a L009 está comentada. En un programa de despliegue esa llamada podría tener efectos que no se conocen.

Valores compilados

CSI 32 tratado como 10, títulos por defecto de L001 y L002, prefijo S151L002R y el sistema 500 como único con L009 y L012 están escritos en el código.

Pendiente de revisión SME
  • El inventario clasifica P600 como A5 Orquestador; el fuente es un programa de consulta y despliegue que se declara programa ejemplo de llamado a la librería de control. Se tradujo como un job corto de Spring Batch con un decider, pero conviene confirmar el arquetipo.
  • Confirmar con qué CSI responde CONSISDIA cuando WKS-B01-CSI no se asigna antes de la llamada (línea 775).
  • Confirmar qué hace la función 1 de FUNCIONL12 en la librería L012, cuyo fuente no está disponible.
  • Confirmar si la función 5 de CONSISDIA es HABILITA FECHA, como dice el comentario del copy (línea 28), o el control de STAREG que describe RN-S151-1137.
  • Las reglas RN-S151-1134 a RN-S151-1138 describen funciones de CONSISDIA que P600 documenta pero no ejecuta; su semántica exacta (por ejemplo los valores de STAREG y STABDSEM) no se puede verificar en este fuente.
  • Se asumió que la librería S151L002R{sistema} es la misma REGISTRAS de ALGOL_L002R3; confirmar que todos los sistemas usan esa versión.
