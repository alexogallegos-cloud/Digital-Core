Para terminar solo envía HI 4. Para depurar borra los directorios de control, bitácora y CON de STSTOTALES en las familias CMEMP y LOGS mediante la utilería P805 de S288. Un parámetro inválido solo produce un mensaje en consola.

public enum Accion { INICIA, TERMINA, DEPURA }
public enum Paso { P810, ALL, NADA }               // PARAM2 OPTIONAL DEFAULT = "NADA"

@ConfigurationProperties("s151-splunk")
public record SplunkProperties(String pasoP810, String familiaDir, String familiaLogs,
                               String taskString, Duration esperaTrasDetener) {}

/** BEGIN JOB S151/WFL/SPLUNK/25MTP006(STRING PARAM1, STRING PARAM2 ...). */
@Bean
Job s151Splunk(JobRepository repo, SplunkDecider decider,
               Step detieneP810, Step iniciaP810, Step depuraArchivos, Step parametroInvalido) {
    return new JobBuilder("S151SPLUNK", repo)
            .incrementer(new RunIdIncrementer())      // ON RESTART, GO INICIO: reinicia desde el principio
            .start(decider)
                .on("INICIA").to(detieneP810).next(iniciaP810)
            .from(decider).on("TERMINA").to(detieneP810)
            .from(decider).on("DEPURA").to(depuraArchivos)
            .from(decider).on("INVALIDO").to(parametroInvalido)
            .end().build();
}
/** TASKCOMM: (S288)S288/OBJECT/P804/TCMD envía un comando de operador a las tareas que coinciden. */
@Service
@RequiredArgsConstructor
public class ComandoTareaService {

    private final JobOperator jobOperator;
    private final JobExplorer explorer;

    /** HI 4 a todas las ejecuciones vivas de P810: se traduce en una petición de paro ordenado. */
    public void detiene(String nombreJob, Duration espera) throws Exception {
        for (JobExecution e : explorer.findRunningJobExecutions(nombreJob)) {
            jobOperator.stop(e.getId());          // P810 debe tratar el stop como trataba HI 4
        }
        Thread.sleep(espera.toMillis());          // WAIT(5)
    }
}

/** REMFILES: (S288)S288/OBJECT/P805/REMF borra los archivos de un directorio en una familia. */
@Service
public class DepuraArchivosService {
    public long borra(Path directorio) throws IOException {
        if (!Files.isDirectory(directorio)) return 0;
        try (Stream<Path> s = Files.list(directorio)) {
            return s.filter(Files::isRegularFile).peek(DepuraArchivosService::borraSilencioso).count();
        }
    }
}

@Component
public class SplunkDecider implements JobExecutionDecider {

    /** CASE PARAM1 OF ... CASE PARAM2 OF ... */
    @Override
    public FlowExecutionStatus decide(JobExecution job, StepExecution last) {
        JobParameters p = job.getJobParameters();
        Optional<Accion> accion = Enums.parse(Accion.class, p.getString("param1"));
        Paso paso = Enums.parse(Paso.class, p.getString("param2", "NADA")).orElse(Paso.NADA);
        if (accion.isEmpty()) {
            return new FlowExecutionStatus("INVALIDO");     // "SOLO ACEPTO: INICIA, TERMINA O DEPURA"
        }
        return switch (accion.get()) {
            case INICIA, TERMINA -> (paso == Paso.P810 || paso == Paso.ALL)
                    ? new FlowExecutionStatus(accion.get().name())
                    : new FlowExecutionStatus("INVALIDO");  // "SOLO ACEPTO: P810 U ALL"
            case DEPURA -> new FlowExecutionStatus("DEPURA"); // PARAM2 no se usa
        };
    }
}

@Bean
Step parametroInvalido(JobRepository repo, PlatformTransactionManager tx) {
    return new StepBuilder("parametroInvalido", repo).tasklet((c, ctx) -> {
        // La WFL solo hace DISPLAY y termina bien; aquí el job termina en FAILED para que
        // el planificador detecte la llamada mal formada.
        throw new ParametroInvalidoException(ctx.getStepContext().getJobParameters());
    }, tx).build();
}
@Bean
Step iniciaP810(JobRepository repo, PlatformTransactionManager tx, JobLauncher launcher,
                @Qualifier("p810StsTotales") Job p810, SplunkProperties props) {
    return new StepBuilder("iniciaP810", repo).tasklet((c, ctx) -> {
        String paso = (String) ctx.getStepContext().getJobParameters().get("param2");
        JobParameters params = new JobParametersBuilder()
                .addString("taskString", props.taskString())     // COMPANY=BANAMEX;USER=S151;...
                .addLong("ts", System.currentTimeMillis())
                .toJobParameters();
        JobExecution e = launcher.run(p810, params);             // RUN #PASO810[T1]
        if ("P810".equals(paso)) {
            Awaitility.await().until(() -> !e.isRunning());      // WAIT(T1 IS COMPLETED)
            if (e.getStatus() != BatchStatus.COMPLETED) {
                throw new PasoFallidoException("P810", e.getExitStatus());
            }
        }
        return RepeatStatus.FINISHED;
    }, tx).build();
}

// detieneP810 corre antes: ComandoTareaService.detiene("p810StsTotales", props.esperaTrasDetener()).
// En la rama P810 un fallo al detener se ignora (ON TASKFAULT, GO REINP810); en ALL no hay manejo.
@Bean
Step detieneP810(JobRepository repo, PlatformTransactionManager tx,
                 ComandoTareaService comandos, SplunkProperties props) {
    return new StepBuilder("detieneP810", repo).tasklet((c, ctx) -> {
        // "%S151/OBJECT/P810/STSTOTALES%": TAKE(PASO810, LENGTH(PASO810) - 9) quita "/25MTP006"
        String patron = props.pasoP810().substring(0, props.pasoP810().lastIndexOf('/'));
        try {
            comandos.detiene(JobNames.de(patron), props.esperaTrasDetener());
        } catch (Exception e) {
            boolean desdeInicia = "INICIA".equals(ctx.getStepContext().getJobParameters().get("param1"));
            if (!desdeInicia) throw e;
            log.warn("No se pudo detener P810 antes de reiniciar: {}", e.getMessage());  // ON TASKFAULT
        }
        return RepeatStatus.FINISHED;
    }, tx).build();
}

Riesgos de migración
Parámetros inválidos terminan con éxito

Las ramas ELSE (líneas 60-64, 77-81 y 90-94) solo ejecutan DISPLAY; la WFL termina normalmente y el planificador no distingue una llamada mal formada de una exitosa.

Posible doble instancia de P810

INICIA espera cinco segundos fijos después del HI 4 (línea 18) y lanza un nuevo P810 sin comprobar que el anterior terminó.

Depuración con P810 activo

DEPURA (líneas 83-89) borra archivos de control y bitácora de STSTOTALES sin detener P810.

Dependencia de utilerías externas

P804 y P805 de S288 se ejecutan desde el pack SPLUNK (líneas 16 y 26); su comportamiento no está en el fuente y hay que reemplazarlos por servicios equivalentes en la plataforma destino.

Hardcodes

Versión 25MTP006 del programa, familias CMEMP y LOGS, la cadena TASKSTRING y las rutas de depuración están en el job; se trasladan a application.yml.

  • Confirmar qué hace P810 al recibir HI 4 (cierre ordenado o terminación inmediata) para mapearlo a JobOperator.stop() o a una señal propia.
