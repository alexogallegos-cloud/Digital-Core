S151ProgramaCOBOL

Fuente: COBOL_P025.cbl (3142 LOC) · Rol en batch: actualizador batch del cierre diario/semanal del GL S151 · BC-13

Convenciones: nombres traducidos (Unisys→legible); [P025 Lnnnn] = línea origen en la fuente; (BR: RN-...) = regla de negocio del catálogo.

⚠ Nota de trazabilidad KB: el miembro fuente analizado tiene PROGRAM-ID CARSDOMOV y función ACTBDSDOMOV (Actualiza Base de Datos de Saldos de Movimientos). El bloque P025 del catálogo (rules-s151-movimientos.md, RN-S151-1040..1049) describe un P025 de "proyección de fechas sobre MOVDIA" con archivos L01-MOVTOS/L02-DESCRIP/L03-CBII/L04-CTDR, que NO corresponden a este miembro. Se marcan como « divergencia KB » las reglas que no aplican y se reflejan sólo las verificables contra esta fuente.

1. Resumen funcional

P025 (CARSDOMOV, alias funcional ACTBDSDOMOV) es un programa batch del subsistema contable S151 (Libro Mayor / General Ledger) de Banamex sobre Unisys ClearPath MCP. Su cometido es recorrer secuencialmente el archivo LOG de movimientos contables del día (A01-S151MOV) y, por cada movimiento contabilizable, invocar la librería S151LIB020 (LIB-L020) para actualizar la base de datos de saldos del sistema. Es, en esencia, el poster de saldos: convierte los movimientos ya autorizados del LOG en actualizaciones de saldo persistentes.

El programa recibe como único parámetro el número de sistema (WKS-PARAMETRO, 3 dígitos) [P025 L2199-L2201], valida contra la librería de control LIB-CONTROL que la fecha contable y la fecha de proceso del S151 sean coherentes y que el proceso previo (P197) haya corrido, y sólo entonces abre los archivos y procesa. Por cada registro con FUNCION=1, STATUS=1 e indicador de estado de cuenta IND-EDOCTA=1, arma la estructura canónica WKS-MOV-DATOS (180 bytes de datos generales + 354 de datos adicionales) y hace CALL "S151LIB020 IN LIB-L020", que aplica el saldo. Al terminar marca el estatus de la base de saldos (STABDSAL) vía CONSISMEN y hace STOP RUN.

Incorpora un mecanismo de recuperación/reanudación (W77-BD-SDOS): si la base de saldos quedó parcialmente actualizada (estatus 99), el programa hace un CALL inicial a L020 para obtener la última autorización aplicada y reposiciona la lectura del LOG a partir de ese punto, evitando doble contabilización [P025 L2422-L2447]. Es un programa MCP nativo: usa DECLARATIVES con procedimiento de interrupción de operador HI (Handle Interrupt), CHANGE ATTRIBUTE, CALL ... IN LIB, SET MYSELF(STATUS) y despliegue de mensajes al operador vía la librería DESPLIEGA.

Toda la manipulación de fechas se hace con la librería embebida CRONOS2K (copybooks CPY/WS y CPY/PD), que convierte entre formatos de 6 y 8 dígitos usando un pivote de siglo A2K-BASE-YEAR = 50 (BR: RN-S151-954).

2.2 Layouts de registro clave

  • A00-R01-REGMOV — registro canónico de movimiento (450 bytes) [P025 L76-L631]. Campos de cabecera: FUNCION, FORMATO, SISTEMA, PRODUCTO, INSTRUMENTO, TIPO-MOVIMIENTO (todos COMP). Contiene una tabla A00-R01-CVEIMP con OCCURS 5 de tuplas (CVETRAN 9(06), INDLEY 9(02), ESQCON 9(04), IMPORTE 9(16)V99, CVE-DESVIO, GUIA-DESVIO) — hasta 5 esquemas de contabilización por movimiento [P025 L111-L118]. Zona A00-R01-FILXAPL PIC X(165) [P025 L242] con decenas de REDEFINES por sistema origen (S016, S018, S084, S087, S203, S252, S264, S402, S403, S404, S408, S500, S501, S502, S701, S702, S703, S707, S711...). Campos de control: A00-R01-APUDES (apuntador al archivo de descripciones), A00-R01-STATUS, A00-R01-AUT-S151, A00-R01-IND-EDOCTA [P025 L163-L167, L215, L629-L630].
  • A00-R00-HDR-MOV — encabezado del archivo LOG: HDR-HD X(2), HDR-FCH 9(8) (fecha del archivo), HDR-BANDES [P025 L69-L74].
  • A01-R01-DATOS — registro del archivo de datos adicionales A02: autorización origen, referencias Banamex (REF-BANAMEX/CVECON-YREFLOC), nómina maker/checker, saldo financiero SDO-FIN-S500, 5 leyendas LEY1..LEY5 X(40), FILXAPL X(120) [P025 L646-L689].

2.3 Estructuras de trabajo relevantes

  • WKS-MOV-DATOS (WITH LOWER-BOUNDS, 540 bytes = 180 generales + 360 adicionales) [P025 L1236-L1474] — estructura canónica de interfaz hacia la librería S151LIB020. Contiene la cabecera del movimiento, la tabla WKS-TAB-CVEIMP OCCURS 5 (CVETRAN, INDLEY, ESQCON, IMPORTE), fechas (FECMOV, FECCONT, FECVAL), autorizaciones (AUT-S151, AUT-AELIM-S151, AUT-ANT-S151), indicadores (IND-EDOCTA, IND-CONTA, SOBREGIRO, TIPO-PROC) y la zona WKS-MOV-DATOS-ADIC X(354) con REDEFINES por sistema.
  • A2K-WKS-MOV-DATOS (WITH LOWER-BOUNDS) [P025 L1031-L1163] — espejo COMP de WKS-MOV-DATOS que usa la librería L020; las rutinas A2K-1-... y A2K-2-... copian campo a campo entre ambas y convierten las fechas AAMMDD↔CCAAMMDD.
  • CRONOS2K — banco de variables de fecha en todos los formatos (A2K-FEC-MDCA/CAMD/DMCA/AMD/MDA/DMA/CAM/AM), pivote A2K-BASE-YEAR PIC 9(02) VALUE 50 [P025 L1166].
  • Interfaz LIB-CONTROL — múltiples estructuras USING: WKS-S151B01SISDIA (dataset control de día: fechas proceso/consulta/151, nombres de archivos MOV/DES/ERR, estatus de bases) [P025 L1613-L1637]; WKS-S151B03SISMEN (estatus base de saldos STABDSAL, ciclos de bases) [P025 L1987-L2009]; y familias de funciones -F02..-F22.
  • Manejo de errores DMSII — WKS-TAB-ERRDMSII: tabla de 21 categorías de error (NOTFOUND=01 … INTLIBERROR=21) [P025 L1536-L1582]. ⚠ « divergencia KB: RN-S151-1043 » enumera 17 categorías bajo el nombre WKS-CATEGORIAS; la fuente real tiene 21 categorías en WKS-TAB-ERRDMSII.
  • MENSAJE-LJ — buffer de mensaje a operador con formato canónico SISTEMA-LJ/PASO-LJ/MTP-LJ:TIPO-LJ>CODIGO-LJ<TEXTO-LJ(250) [P025 L1204-L1215] (BR: RN-S151-955).

4.1 DECLARATIVES — manejo de interrupción de operador

PROCEDIMIENTO Manejar_Interrupcion_HI():                 // HI-INTERRUPT / INTERRUP-BY-HI · [P025 L2224-L2243]
    // Procedimiento de interrupción MCP (USE AS INTERRUPT). El operador puede
    // enviar un "HI" (Handle Interrupt) a la tarea; su valor determina la acción.
    DESHABILITAR interrupciones                          // DISALLOW INTERRUPT
    SI (atributo TASKVALUE de MI_TAREA) = 4 ENTONCES
        MOVER "I" A tipo_mensaje                          // TIPO-LJ
        ARMAR texto " TERMINACION ANORMAL P025/ASINSDOMOV POR HI 4 "

        ARMAR texto "NIVEL DE ACTUALIZACION " + ultimo_reg_leido   // W77-ULT-REG-LEIDO
        EJECUTAR 999999-DESPLIEGA                         // informa avance sin abortar
    SINO
        ARMAR texto " HI NO IMPLEMENTADO "
        EJECUTAR 999999-DESPLIEGA
    HABILITAR interrupciones                              // ALLOW INTERRUPT
