S500 · lib010 a Java 21 Spring Boot

Declara en WORKING-STORAGE los formatos de entrada y salida de unos cuarenta entry points de S500L010CTRL y, en la parte de procedimiento, un párrafo envoltorio por cada uno. Los envoltorios copian paso, copia y mix del programa anfitrión, registran la medición en MAPLI y en la librería L030 cuando están habilitadas, hacen el CALL y devuelven el resultado en WS-L010-RESULT. Algunos contienen reglas propias: el armado del registro de log con sus zonas superpuestas, la lectura del log en recuperación con re-solicitud del contrato y la asignación del paso en el aviso de baja.

/** Resultado común de todos los entry points (GIVING WS-L010-RESULT). */
public record ResultadoL010<T>(int codigo, T salida) {

    public static final int OK = 0;
    public static final int CONTRATO_OCUPADO = 8;          // dispara 00000000-TIEMPOS-CTOOCUP

    public boolean ok()              { return codigo == OK; }
    public boolean contratoOcupado() { return codigo == CONTRATO_OCUPADO; }

    /** WS-L010-RESULT es PIC 9(02): el adaptador valida el rango en lugar de truncar. */
    static int deLibreria(long valorNativo) {
        if (valorNativo < 0 || valorNativo > 99) {
            throw new ResultadoFueraDeRangoException(valorNativo);
        }
        return (int) valorNativo;
    }
}

@Service
@RequiredArgsConstructor
public class ControlCaptacionService implements ControlCaptacion {

    private final S500L010Gateway gateway;     // la librería nativa, un servicio remoto o su reimplementación
    private final ObservationRegistry observaciones;

    /** 0000-CALL-S500L010SOLCTO. La medición MAPLI (actividad 13) y la de L030 son un aspecto. */
    @Override
    @Observed(name = "s500.l010", contextualName = "L010SOLCTO",
              lowCardinalityKeyValues = {"actividad", "13", "proceso", "13"})
    public ResultadoL010<SolCtoOut> solicitaContrato(SolCtoIn in) {
        var r = gateway.solCto(in);
        if (r.contratoOcupado()) {
            // 00000000-TIEMPOS-CTOOCUP: proceso 32 y actividad 23 "CONTRATO OCUPADO"
            observaciones.getCurrentObservation().event(Observation.Event.of("contrato.ocupado"));
        }
        return r;
    }
}

    Resultado resultado =
            m.causaDevolucion() > 0 ? new Devolucion(m.causaDevolucion(), m.subcausa(), m.difVsSaldo())
          : m.rechazadoUtil()       ? new Rechazo(m.codigoErrorRechazo())
          :                           new Normal();

    long llaveDialogo = m.bancoDestinoEsBanamex() ? m.seqDialogo() : m.seqDialogoOtroBanco();
    String contrato   = m.usaSubcuenta() ? m.contratoSubcuenta() : m.contrato();

    DatoClave dato = props.clavesConTipoCambio().contains(m.claveTrans())   // RDISPEFECAJDL, RNEGAFILDL,
            ? new TipoCambio(m.tipoCambio())                                // DDISPNOEFECDL
            : new Nomina(m.nomina());

    DatoTarjeta tarjeta = m.claveTrans() == props.claveEvolucion()          // 1153
            ? new AutPendienteEvolucion(m.autPendiente())
            : new Tarjeta(tokenizador.token(m.tarjeta()));

    return new RegistroLogIn(funcion, ctx.copia(), m.ultimoRegLog(), ctx.base(), ctx.copia(),
            m.statusRegLog(), m.folioFm(), m.fechaMaquina(), m.horaMovto(), resultado,
            llaveDialogo, contrato, m.claveTransHost(), dato, m.autorizacion(),
            // Solo el caso normal llena la línea de servicio; en devolución y rechazo el COBOL
            // no la asigna (queda el valor previo) o pone la tasa en cero. Aquí se envía cero.
            resultado instanceof Normal ? m.lineaServicioAut() : 0L,
            resultado instanceof Normal ? m.lineaServicioTasa() : BigDecimal.ZERO,
            m.tipoRespuestaS054(), tarjeta, m.mensajeDialogo());
}
/** 0000-CALL-S500L010LEELOG: reprocesa el log tras una caída. */
public Optional<RegistroRecuperado> siguienteDeLog(ContextoPaso ctx, EstadoRecuperacion estado) {
    var r = gateway.leeLog(new LeeLogIn(ctx.copia(), ctx.mix()));
    LeeLogOut out = r.salida();

    if (out.fin() != LeeLogOut.FinRecuperacion.NINGUNO) {      // parcial o total: termina recuperación
        estado.terminar();
        sincronizaTransaccion();                               // 00000000-TRANS-SYNC
        estado.controlB01(controlB01.obtiene());               // 00000000-OBTEN-B01CONTROL
        return Optional.empty();
    }
    estado.ultimoRegistro(out.registroLog());
    var mov = MovimientoS500.desdeLog(out.registro()).conForzado(true);   // WS-GEN-MOV-FORZADO = 1

    if (out.contratoBloqueado()) {
        // En recuperación la librería ya bloqueó el contrato al leer el registro.
        estado.contratoBloqueado(out.aplicaSaldoPendiente());
    } else if (!mov.contrato().equals("000000000000")) {
        solicitaContrato(new SolCtoIn(ctx.paso(), ctx.copia(), mov.contrato(), false, ctx.mix()));
    }
    return Optional.of(new RegistroRecuperado(out.registroLog(), mov));
}
/** 20230125-AVISO-BAJA: copias 1 a 7 reportan el paso 10; copias 8 a 14, el paso 16. */
public ResultadoL010<Void> confirmaBaja(int copia) {
    int paso = switch (copia) {
        case 1, 2, 3, 4, 5, 6, 7       -> props.pasoBajaGrupo1();    // 10
        case 8, 9, 10, 11, 12, 13, 14  -> props.pasoBajaGrupo2();    // 16
        default -> throw new IllegalArgumentException(
                "Copia fuera de los rangos de baja: " + copia);       // el COBOL deja el paso anterior
    };
    return gateway.confirmaBaja(new ConfirmaBajaIn(paso, copia));
}
Riesgos de migración
Número de tarjeta en el log

WS-I-GL-TARJ-CRCHQRA (PIC 9(16)) se graba en el log de movimientos por GRABALOG y se restaura en LEELOG. Es información de alcance PCI-DSS; la versión Java debe guardar un token.

Zonas REDEFINES sin discriminador validado

Diferencia contra saldo y código de rechazo, nómina y tipo de cambio, y tarjeta e importe de evolución comparten memoria. Si el indicador de devolución o la clave de transacción no coinciden con lo grabado, se lee un dato con otro significado.

Dependencia del estado del programa anfitrión

Los envoltorios leen variables globales del anfitrión (WS-PASO-N, WS-NUMERO-COPIA, WS-NUMERO-MIX, banderas MAPLI y L030) y el armado normal del log no asigna la función de grabación. Un programa que incluya el copybook sin inicializar esas variables envía datos de una llamada previa.

Resultados sin verificar

GRABALOG, COMPAUT, INTPAG, COMMPOST, ARCHCTRL, LOGPC, GET_TIME y CTR_TIME_FM se llaman sin GIVING; el copybook no puede saber si fallaron.

Código de resultado sin signo

WS-L010-RESULT es PIC 9(02) (línea 653); un código negativo o mayor que 99 se recibiría alterado.
