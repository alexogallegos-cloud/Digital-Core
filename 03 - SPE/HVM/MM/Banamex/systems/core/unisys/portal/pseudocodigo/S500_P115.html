P115 · Informe de Saldos GCE y Generador de Archivos I10/I10PS/I10PS2 (S500)

S500ProgramaCOBOL

Fuente: P115.cbl (2334 LOC) · Batch nocturno de captación · BC-05

Convenciones: nombres traducidos (Unisys COBOL→legible); [P115 Lnnnn] = línea origen; (BR: RN-S500-xxx) = regla de negocio.

Módulos COPY compartidos referenciados por nombre; no se re-inlinean: S500/INC/WOR/25MTP002, S500/INC/WOR/DAS/25MTP003, S500/INC/PRO/25MTP002.

1. Resumen funcional

P115 es un programa batch multimodal de S500 (Banamex, Unisys ClearPath MCP) que sirve dos propósitos relacionados: (a) generar y/o consolidar los archivos de saldos de fin de día para la interfaz GCE (Global Cash Engine) —archivos I7, I10, I10PS e I10PS2— diferenciando entre los dos nodos de la instalación (VDM=CSI 10, MTY=otro CSI), y (b) imprimir reportes de auditoría que listan los archivos enviados, las cuentas marcadas en B48CTOSGCE y el saldo disponible final después de rendimientos y comisiones. El modo de operación se selecciona vía WKS-FUNCION (parámetro TASKVALUE): funciones 0 = informe, 1/4/7 = generación por nodo, 2/5/8 = consolidación VDM+MTY, 3/6/9 = solo VDM. Las tres familias de archivos (I10, I10PS, I10PS2) representan tres cortes de saldo: al cierre de día, después de balanceo, y después de rendimientos y comisiones respectivamente.

2.2 Layouts de registro clave

WKS-REG-I7 (1416 bytes): registro del archivo I7 SWIFT Forward/Back (solo func. 1 en VDM).

  • Tipos: HDR (header), TLR (trailer). El header lleva: pais MX, sucursal MX1, referencia 0000606, formato 0000153, fecha máquina, hora, fecha proceso. El trailer lleva num-reg=2. ⚠ [HARDCODE-SOSPECHOSO]: referencia=0000606, formato=0000153, numreg=2.

WKS-REG-I10 (113 bytes): registro de archivo de saldos I10/I10PS/I10PS2.

  • Tipos de registro: *** (header), 485 (detalle), --- (trailer).
  • Detalle (485): cuenta_cheques (11 dig., SUC 4+CTA 7), signo_saldo_disponible, saldo_disponible_entero (15 dig.), punto, decimales_milésimas (3 dig.), saldo_valor_día, saldo_libro_banco, saldo_lineas_credito_y_bloqueos, fechas_último_débito/crédito, moneda_SWIFT (3 chars).
  • Header/trailer: sucursal=485 ⚠ [HARDCODE-SOSPECHOSO], num_interface=10, versión=01, fecha.

4. Lógica por sección

4.1 SECCIÓN: DECLARATIVES — INTERRUPT-BY-HI

PROCEDIMIENTO Manejador_Interrupcion_HI():            // INTERRUPT-BY-HI · [P115 L067600]
  DESACTIVAR interrupciones
  MOVER "I" A tipo_visualizacion  // W77-TIPO-DISP

  SI TASKVALUE del programa = 0
    ENTONCES
      MOVER TASKVALUE           A numero_hi            // WKS-HI-NUMHI
      MOVER funcion             A hi_funcion            // WKS-HI-FUNC
      MOVER num_cuentas         A hi_reg_leidos         // WKS-HI-REG-LEI
      MOVER total_reg           A hi_total_reg          // WKS-HI-TOT-REG
      MOVER llamadas_s408       A hi_calls_s408         // WKS-HI-CALLS408
      MOVER stores_b03          A hi_stores_b03         // WKS-HI-STOREB03
      MOVER texto_estadisticas  A mensaje               // WKS-HI-TEXTO → WS-0101-TEXT-MSG
      EJECUTAR 70000050-MENSAJE                         // → COPY PRO
    SINO
      CONSTRUIR "NUM HI ERRONEO " + numero_hi A mensaje
      EJECUTAR 70000050-MENSAJE

  PONER TASKVALUE DEL PROGRAMA A CERO                  // [P115 L069300]
  MOVER "E" A tipo_visualizacion
  ACTIVAR interrupciones
