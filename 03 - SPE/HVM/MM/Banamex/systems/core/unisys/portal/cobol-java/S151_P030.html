S151 · P030 a Java 21 Spring Boot

Se registra en COMS y espera mensajes con ESPERACOMS. Cada mensaje trae un encabezado de 36 bytes con la estación del cajero y un texto que se interpreta como consulta de pantalla (funciones 502 a 506) o como mensaje SA2 (prefijos y subcódigo de servicio). Valida los campos, determina el CSI de residencia de la sucursal y, si es local, consulta por librería y arma la respuesta; si no, reenvía el mensaje al CSI correcto. Los operadores lo controlan con interrupciones HI para monitoreo, bloqueo de consultas y terminación.

/** Encabezado de 36 bytes común a WS-HEADER-COMS y WS-HEADER. */
public record AdmovHeader(char prefijo, char aplDestino, int csiDestino,      // CCR-DES 99
                          int lstOrigen,                                   // LST-ORG 9999 o 9(08) COMP
                          Estacion estacion,                               // 8 bytes
                          int csiOrigen, int csiOrigenCopia, int fac,      // CCR-ORG, COP-ORG, FAC
                          char aplOrigen, int resultado,                   // RES 99
                          String mascara, String password) {

    /** WS-HDR-STATION: TIPO(1) + SUC(4) + PRIV(1) + CAJ(2). */
    public record Estacion(char tipo, String sucursal, char privilegio, String caja) {}

    public boolean esDeAplicacion() { return resultado == 2 || resultado == 4; }    // MSG-DE-APLICACION
    public boolean esDeRed()        { return resultado == 11 || resultado == 12; }  // MSG-DE-RED
    public boolean esDeErrores()    { return resultado >= 31 && resultado <= 33; }  // MSG-DE-ERRORES
}

/** WS-MSG (1920) = encabezado + WS-TEXTO (1884), con tres lecturas del texto. */
public sealed interface AdmovTexto permits AdmovTexto.Pantalla, AdmovTexto.Sa2 {

    /** WS-TEXTO-R2: mensaje de pantalla, función 502..506 en posiciones 4-6. */
    record Pantalla(String f, int funcion, String fs, String cuerpo) implements AdmovTexto {}

    /** WS-TEXTO-SA2: ampliación de encabezado y segmento de infraestructura SA2. */
    record Sa2(int prefijoDestino, int prefijoOrigen,                  // 9(06) cada uno
               int destinoSistema, int destinoCodServ, int destinoSubCodServ,
               int origenSistema, int origenCodServ, int origenSubCodServ,
               int direccion, int longMsg, int tiempoEspera, int resultIca,
               int formatoId, int formatoRecon, char formatoVersion,
               int mensajeClase, int mensajeResult, String cuerpo) implements AdmovTexto {}
}

@ConfigurationProperties("admov.taskfile")
public record TaskfileProperties(String titulo, int subnodo, boolean respaldo) {

    /** 00001-INICIO: WKS-TSK-NODO = WKS-NUMCSI, fecha AAMMDD, MIXNUMBER de la tarea. */
    public String resuelve(int nodo, LocalDate hoy, long instancia) {
        return titulo.replace("{nodo}", "%02d".formatted(nodo))
                     .replace("{subnodo}", "%02d".formatted(subnodo))
                     .replace("{fecha}", hoy.format(DateTimeFormatter.ofPattern("yyMMdd")))
                     .replace("{mix}", "%07d".formatted(instancia % 10_000_000));
    }
}

@Component
@RequiredArgsConstructor
public class AdmovEndpoint {

    private final AdmovParser parser;
    private final AdmovDispatcher dispatcher;
    private final MonitorAdmov monitor;            // WS-MON / archivo MONITOREO

    /** 10100-ACEPTA-MSG + 10000-PROCESO: un mensaje por invocación, sin bucle GO TO. */
    @ServiceActivator(inputChannel = "admovEntrada", outputChannel = "admovSalida")
    public Message<byte[]> recibe(Message<byte[]> entrada) {
        AdmovMensaje msg = parser.parse(entrada.getPayload());   // 1926 -> encabezado + texto

        // Solo se aceptan resultados 2/4 (aplicación), 11/12 (red) y 31-33 (errores).
        if (!(msg.header().esDeRed() || msg.header().esDeAplicacion() || msg.header().esDeErrores())) {
            log.warn("RESULT DEL HEADER NO TRATADO {}", msg.raw());
            return null;                                  // MOVE 1 TO WS-CONTROL: se descarta
        }
        monitor.entrada(msg);                             // "* ENTRADA:" si WS-MON = 1
        return dispatcher.procesa(msg);                   // 20000-PROCESA-MENSAJE
    }
}
// ESPERACOMS con timeout de 60 s, ACCEPT de operador y HI se sustituyen por el contenedor
// del canal (Kafka/JMS) y por endpoints de Actuator; el STATUS-KEY 99 (STOP RUN) es el apagado.
@Component
@Endpoint(id = "admov")
@RequiredArgsConstructor
public class AdmovOperadorEndpoint {

    private final MonitorAdmov monitor;
    private final ApplicationContext ctx;

    /** INTERRUPT-BY-HI: MOVE ATTRIBUTE TASKVALUE OF MYSELF TO WS-HI-INTERRUPT. */
    @WriteOperation
    public String hi(int valor) {
        return switch (valor) {
            case 2  -> monitor.enciende() ? "PRENDE MONITOR" : "MONITOR YA ENCENDIDO";
            case 3  -> monitor.apaga()    ? "APAGA MONITOR"  : "MONITOR NO ENCENDIDO";
            case 4  -> termina("FIN NORMAL POR OPERADOR");           // WS-FIN = 1
            case 6  -> termina("TERMINACION DE EMERGENCIA");         // mismo efecto que HI4
            case 7  -> "DUMP no aplica; usar heap dump de Actuator";  // CALL SYSTEM DUMP
            case 13 -> monitor.estadoConsultas();                    // WS-HI-STACONS
            case 14 -> monitor.alternaBloqueoConsultas();            // WS-HI-DESBLOCON
            case 19 -> "Fecha de consulta: usar parámetro admov.fecha-consulta";
            case 25 -> monitor.alternaLibreriaCheques();             // W77-CHQS-ANT
            case 32 -> monitor.recargaFechasL001();                  // 09000 + 90000-FECHAS-L001
            case 46 -> monitor.habilitaConsultasPantalla(true);      // WS-CONXPAN = 0
            case 47 -> monitor.habilitaConsultasPantalla(false);     // WS-CONXPAN = 1
            default -> monitor.ayuda();                              // lista de HI disponibles
        };
    }

    private String termina(String texto) {
        log.info(texto);
        SpringApplication.exit(ctx, () -> 0);
        return texto;
    }
}

@Service
@RequiredArgsConstructor
public class AdmovDispatcher {

    private final AdmovRouter router;          // 20200-TRANSACCIONES
    private final AdmovRespuestas respuestas;  // 30000-RESPONDE-MAL + 40000-SENDCOMS
    private final AtomicLong consultas = new AtomicLong();   // WS-NUM-CON (HI13)

    @Transactional(readOnly = true)            // P030 solo consulta: ADMOV, L001, L011, L120
    public Message<byte[]> procesa(AdmovMensaje msg) {
        consultas.incrementAndGet();
        var ctx = AdmovContexto.limpio(msg);   // 20001-LIMPIA-CAMPOS / 20002-LIMPI-TABLA

        // En el fuente WS-STATUS se pone en cero justo antes de evaluarlo, así que
        // "IF WS-STATUS = 0 OR WS-OPE-PRI" siempre es verdadero y la rama de error 12/1
        // nunca se ejecuta. Se traduce sin la rama muerta.
        ctx.textoSinEspacios(Texto.compacta(msg, 60));   // 20100-QUITA-ESPACIOS
        router.despacha(ctx);

        // La respuesta de error se omite cuando el destino es 040310.
        if (ctx.prefijoDestino() != 40310 && ctx.error() > 0) {
            respuestas.armaError(ctx);
        }
        return respuestas.envia(ctx);
    }
}
@Component
@RequiredArgsConstructor
public class AdmovRouter {

    private final Map<Integer, ConsultaAdmov> porSubCodServ;   // 1 totales, 2 movtos, 3 productos, 4, 5
    private final Map<Integer, ConsultaAdmov> porFuncion;      // 502 cuenta, 503/504 caja, 505, 506
    private final AdmovSwitches switches;                      // WS-CONXPAN, operado por HI46/HI47

    private static final Map<Integer, Integer> ERROR_PANTALLA_DESHABILITADA =
            Map.of(502, 20, 503, 21, 504, 22, 505, 23, 506, 25);

    void despacha(AdmovContexto ctx) {
        if (ctx.texto() instanceof AdmovTexto.Sa2 sa2
                && sa2.prefijoDestino() == 15130 && sa2.prefijoOrigen() == 40310) {
            ejecuta(Set.of(1, 2), sa2.destinoSubCodServ(), ctx);     // solo totales y movimientos
        } else if (ctx.header().aplOrigen() == 'G' && ctx.texto() instanceof AdmovTexto.Sa2 sa2) {
            ejecuta(Set.of(1, 2, 3, 4, 5), sa2.destinoSubCodServ(), ctx);
        } else if (ctx.texto() instanceof AdmovTexto.Pantalla p) {
            if (switches.consultasPantallaHabilitadas()) {
                var c = porFuncion.get(p.funcion());
                if (c == null) ctx.error(2); else c.ejecuta(ctx);      // TRANSACCION NO IMPLEMENTADA
            } else {
                ctx.error(ERROR_PANTALLA_DESHABILITADA.getOrDefault(p.funcion(), 2));
            }
        }
    }

    private void ejecuta(Set<Integer> permitidos, int subCodServ, AdmovContexto ctx) {
        if (permitidos.contains(subCodServ)) porSubCodServ.get(subCodServ).ejecuta(ctx);
        // else 29000-RESPONDE-ERROR: en el fuente es un párrafo vacío; no asigna error.
    }
}
@Component("consulta502")
@RequiredArgsConstructor
public class ConsultaPorCuenta implements ConsultaAdmov {

    private final ResidenciaSucursales residencias;   // WKS-CSIRES-SUC(10000), cargada por L120
    private final MovimientosCuentaClient lib502;     // 20211-CARGA-LIB-502

    @Override
    public void ejecuta(AdmovContexto ctx) {
        String[] c = ctx.campos("[\\x1C@]");          // UNSTRING ... DELIMITED BY WS-FS OR "@"
        String suc = c[0], cuenta = c[1], sistema = c[2], control = c[3];

        if (!esNumero(suc) || Integer.parseInt(suc) < 1) ctx.error(4);       // SUCURSAL INVALIDA
        if (ctx.error() == 0 && !esNumero(cuenta))      ctx.error(8);       // CUENTA NO NUMERICA
        if (!esNumero(sistema))                         ctx.error(13);      // pisa el error previo
        int sis = esNumero(sistema) && Integer.parseInt(sistema) != 0 ? Integer.parseInt(sistema) : 1;
        if (ctx.error() == 0 && !control.isBlank() && !esNumero(control)) ctx.error(6);
        if (ctx.error() != 0) return;

        int csiSucursal = residencias.csiDe(Integer.parseInt(suc), ctx);    // 50000-LIBEST
        if (csiSucursal == ctx.header().csiDestino() || ctx.header().csiDestino() > 30) {
            lib502.consulta(suc, cuenta, sis, control, ctx);                // y 20212-ARMA-RESPUESTA
        } else {
            ctx.reenviaA(csiSucursal);       // CCR-DES = CSI de la sucursal, RES = 2, DIRECCIONA = 1
        }
    }
}

@Component
public class AdmovRespuestas {

    /**
     * 29000-RESPONDE-ERROR no contiene instrucciones: un PERFORM sobre él no hace nada,
     * así que un subcódigo SA2 desconocido responde sin texto de error.
     * Se conserva ese comportamiento y se registra el caso.
     */
    void subCodigoNoSoportado(AdmovContexto ctx) {
        log.warn("SUBCODSERV no soportado {}; el fuente responde sin error", ctx.subCodServ());
    }

    /** 30000-RESPONDE-MAL: tres formatos de pantalla según el error. */
    void armaError(AdmovContexto ctx) {
        AdmovError e = AdmovError.de(ctx.error());
        String cuerpo = switch (ctx.error()) {
            case 19        -> Pantalla.DESPROTEGE + Pantalla.pos(5, 60) + ctx.monedaFija()
                              + Pantalla.PROTEGE + Pantalla.HOME + Pantalla.POS + "     " + e.texto();
            case 7, 11, 12 -> Pantalla.HOME + Pantalla.POS + e.texto();
            default        -> Pantalla.HOME + Pantalla.POS + "ERROR: " + e.texto();
        };
        ctx.respuesta(cuerpo + " ".repeat(20) + Pantalla.ETX);   // WITH POINTER WS-LONG-MSG
    }
}
    /** 40000-SENDCOMS: responde a la terminal o reenvía el mensaje completo a otro CSI. */
    Message<byte[]> envia(AdmovContexto ctx) {
        var h = ctx.header();
        if (ctx.dialogo()) {
            h = h.conResultado(2);                                 // W77-DIALOGO = 1
        } else if (!ctx.reenvio()) {                               // WS-DIRECCIONA = 0
            int destino = h.csiOrigenCopia() > 0 ? h.csiOrigenCopia() : h.csiOrigen();
            h = h.conDestino(destino, h.aplOrigen()).conAplOrigen('0').conResultado(1);
        } else {
            h = h.conResultado(6);                                 // reenvío: longitud 1852
        }
        byte[] payload;
        if (!ctx.reenvio()) {
            payload = AdmovSerializer.comoMsg(h, ctx);             // SEND ... FROM WS-MSG (1920)
        } else if (h.aplDestino() == '0') {
            payload = AdmovSerializer.comoComs(h, ctx);            // WS-HEADER y WS-TEXTO a WS-MSG-COMS
        } else {
            payload = ctx.comsOriginal();                          // WS-MSG-COMS tal como llegó
        }
        monitor.salida(payload);
        return MessageBuilder.withPayload(payload)
                .setHeader("longitud", ctx.longitud() + 48)        // ADD 48 TO WS-LONG-MSG
                .build();
        // STATUS-KEY distinto de 0 o 96: el fuente solo hace DISPLAY; aquí lo maneja el canal.
    }
}

// 50000-LIBEST
@Component
@RequiredArgsConstructor
public class ResidenciaSucursales {
    private final int[] csiPorSucursal = new int[10_000];          // OCCURS 10000, cargada por 00200-CARGA-SUC (L120)
    private final AdmovProperties props;

    int csiDe(int sucursal, AdmovContexto ctx) {
        int csi = csiPorSucursal[sucursal - 1];                    // índice COBOL base 1
        if (csi == 0 || ctx.header().resultado() == 2) {
            return ctx.header().csiDestino();                      // MOVE WS-HDR-CCR-DES TO WKS-SAL-CSI
        }
        // El IF no tiene ELSE: WKS-SAL-CSI conserva el 0 de 20001-LIMPIA-CAMPOS.
        // admov.residencia-literal=true reproduce eso; false usa el CSI de la tabla.
        return props.residenciaLiteral() ? 0 : csi;
    }

Riesgos de migración
Condición siempre verdadera en el despacho

En 20000-PROCESA-MENSAJE (líneas 3082-3096) WS-STATUS se pone en cero y se evalúa de inmediato con IF WS-STATUS = 0 OR WS-OPE-PRI. La rama que responde CONSULTA BLOQUEADA (error 12) o error 1 es inalcanzable desde aquí.

Párrafo de error vacío

29000-RESPONDE-ERROR (línea 5547) no tiene instrucciones. Los subcódigos SA2 no soportados (líneas 3165 y 3183) responden sin error, y el sistema origen no puede distinguir una consulta rechazada de una vacía.

Truncamiento del texto COMS

10100-ACEPTA-MSG (línea 3054) mueve 1890 bytes a un campo de 1884; los últimos seis bytes del mensaje entrante se pierden. La alternativa que movía WS-TEXTO-COMS está comentada.

Orden de validaciones en consulta por cuenta

La validación de sistema (líneas 3265-3266) sobrescribe un error previo de sucursal o cuenta, por lo que el mensaje al cajero puede no ser el primero detectado.

Interrupciones anunciadas sin implementación

El menú de ayuda (líneas 2399-2423) ofrece HI8, HI11, HI12, HI15, HI16, HI17 y HI18, pero ninguna rama del despachador los atiende: caen en la misma ayuda. HI8 sí termina el servidor desde 10100-ACEPTA-MSG.

Consultas de pantalla deshabilitadas al arranque

WS-CONXPAN inicia en 1 (línea 1284). Tras cada reinicio las funciones 502 a 506 responden con redirección a pantallas Q0151xx hasta que un operador envíe HI46.

Residencia de sucursal sin rama ELSE

50000-LIBEST (líneas 5664-5674) solo asigna WKS-SAL-CSI cuando la sucursal no tiene residencia o el mensaje ya fue reenviado. En el caso restante WKS-SAL-CSI conserva el cero de 20001-LIMPIA-CAMPOS (línea 3116), y 20210-CONSULTA-POR-CUENTA lo usaría como CSI destino del reenvío (línea 3285). El bloque está marcado *RGV, lo que sugiere una modificación posterior.

Hardcodes de topología

Prefijos SA2 015130 y 040310, la aplicación 'G', el umbral de CSI mayor a 30, los CSI 04 y 32 para la librería L011 y el título de LIB-DISP están compilados; se trasladan a configuración.

Pendiente de revisión SME
  • El inventario clasifica P030 como A2 Validador-Actualizador, pero el fuente es un servidor COMS en línea que solo consulta (librerías L001, L011, L120 y ADMOV). Confirmar con el SME el arquetipo y si el destino debe ser un servicio síncrono (REST o mensajería petición-respuesta) en lugar de batch.
  • RN-S151-961 atribuye la diferencia de seis bytes al encabezado de protocolo; en el fuente ambos encabezados miden 36 bytes y los seis bytes son WS-TRANCODE-COMS al inicio del texto (líneas 285-288). Revisar la redacción de la regla.
  • RN-S151-960 describe el título como {NODO}/{FECHA}/{MXNB}; el fuente agrega un subnodo 00 pegado al nodo, el literal /R000/ y la fecha en seis dígitos (líneas 212-226).
  • RN-S151-966 menciona TRANNUM, FECMOV y HORA en el encabezado SA2; esos campos no aparecen en WS-TEXTO-SA2 entre las líneas 326-345. Ubicar el resto del layout SA2 antes de cerrar el parser.
  • RN-S151-969 menciona distribución a P013, P014, P016, P055 y P054 mediante taskfiles; en las secciones revisadas P030 responde o reenvía a otro CSI por COMS y no se encontró ese reparto. Validar con SME.
  • Confirmar con trazas de producción qué ocurre en 50000-LIBEST cuando la sucursal tiene residencia en otro CSI: el fuente dejaría WKS-SAL-CSI en cero y reencaminaría al CSI 00. Puede existir un comportamiento de COMS con destino 00 que no se ve en el fuente.
  • Confirmar el valor real de WS-FS (separador de campos del UNSTRING) para el parser de Java.
  • Confirmar si los mensajes con resultado 31 a 33 (MSG-DE-ERRORES) deben procesarse o descartarse; hoy se procesan.
