Recorre las cifras de control de S500B09CIFRAS y, para cada producto, instrumento y moneda, consulta los totales recibidos por el S408 a través de la librería LINCRED y los del S151 a través de TOTXCVE. Calcula las diferencias de importe y número de movimientos, imprime los reportes de cifras, posición y estadísticas, y cuadra clave por clave el archivo TOTCVE ordenado. Si una consulta falla, el operador decide por consola si continúa o reintenta. Al final marca el paso 170 en S500B00CTRLPASO y el estado de disponibilidad en S500B02CONTROL.

@Service
@RequiredArgsConstructor
public class LineaCreditoClient {

    private static final int NO_DISPONIBLE = 96;
    private final LincredGateway gateway;
    private final DecisionOperador operador;
    private final P170Properties props;

    @Retryable(retryFor = S408NoDisponibleException.class,
               maxAttemptsExpression = "#{@p170Properties.s408().intentos()}",          // 4
               backoff = @Backoff(delayExpression = "#{@p170Properties.s408().esperaMs()}")) // WAIT(30)
    public TotalesS408 totales(ConsultaTotalesRequest req) {
        var resp = gateway.consulta(req);
        if (resp.status() == 0) return resp.totales();
        if (resp.status() == NO_DISPONIBLE) throw new S408NoDisponibleException(resp.status());
        // Productos sin línea de crédito: se simula que no tienen movimientos en S408.
        if (props.productosSinLinea().contains(req.llaveProducto())) {     // 88 PIM-PROD-A-SOR / PIM-PREPAGADA
            return TotalesS408.CERO;
        }
        return operador.decide(req, resp);                                  // 50005254-DECIDO
    }

    @Recover
    TotalesS408 agotado(S408NoDisponibleException e, ConsultaTotalesRequest req) {
        // En el fuente, tras más de 4 intentos se ejecuta 70000055-STOP-PGM y el ciclo vuelve a empezar.
        throw new ProcesoDetenidoException(
            "ERR CALL S408 RS=%d INTENTOS=%d (OK CUANDO ESTE DISPONIBLE S408L011LCRD)"
                .formatted(e.status(), props.s408().intentos() + 1));
    }
}
@Component
@RequiredArgsConstructor
public class DecisionOperador {

    public enum Decision { CONTINUAR, REINTENTAR }

    private final ConsolaOperacion consola;    // ACCEPT WS-DECIDE1 -> tarea humana / ticket
    private final LincredGateway gateway;

    public TotalesS408 decide(ConsultaTotalesRequest req, RespuestaS408 fallida) {
        while (true) {
            String r = consola.pregunta("CONSULTA S408 FALLIDA %s, C=CONTINUAR R=REINTENTAR"
                                        .formatted(fallida.status()));
            switch (r) {
                case "C" -> {
                    log.warn("Operador continúa sin totales del S408 para {}", req);
                    return TotalesS408.SIN_DATO;          // explícito, no basura del área de comunicación
                }
                case "R" -> {
                    gateway.recarga();                    // CANCEL "LINCRED" + WAIT(2) + nuevo enlace
                    return reintenta(req);
                }
                default -> consola.avisa("DECISION INVALIDA " + r);
            }
        }
    }
}
@Service

public class ConsultaTotalesS151 {

    private final TotalesContablesClient s151;      // librería TOTXCVETRAS500, función 06
    private final P170Properties props;

    public TotalesS151 consulta(CifraControl b09, LocalDate fechaProceso) {
        TotalesS151 tot = s151.totalesPorClave(fechaProceso, b09.llave(), b09.bancos());
        // Hardcode del fuente: 66-15 en moneda 5 se consulta otra vez en moneda 1 y se suma.
        if (props.consultaAdicionalMn().contains(b09.llave())) {          // 66-15-5

        }
        return tot;
    }

/** Diferencias de cargos y abonos. En COBOL los campos -DIF son 9(16)V99 y 9(08) sin signo. */
public record DiferenciaCifras(BigDecimal importeCargos, long numCargos,
                               BigDecimal importeAbonos, long numAbonos) {

    public static DiferenciaCifras s500MenosOtro(Totales s500, Totales otro) {
        return new DiferenciaCifras(
                s500.impCargos().subtract(otro.impCargos()),     // SUBTRACT ... GIVING WS-IMP-TCAR-DIF
                s500.numCargos() - otro.numCargos(),
                s500.impAbonos().subtract(otro.impAbonos()),
                s500.numAbonos() - otro.numAbonos());
    }

    public boolean cuadra() {
        return importeCargos.signum() == 0 && numCargos == 0
            && importeAbonos.signum() == 0 && numAbonos == 0;
    }

    /** Compatibilidad con el reporte actual, que imprime el valor absoluto. */
    public DiferenciaCifras comoReporteLegado() {
        return new DiferenciaCifras(importeCargos.abs(), Math.abs(numCargos),
                                    importeAbonos.abs(), Math.abs(numAbonos));
    }
}
@Component
@StepScope
public class CuadrePorClaveProcessor implements ItemProcessor<TotCve, List<RenglonClave>> {

    private TotCve pendiente;        // WS-xxxPASO1; WS-12VEZ = 1 cuando hay uno guardado

    /** TOTCVE viene ordenado por clave; cada clave debería traer un registro de cada origen. */
    @Override
    public List<RenglonClave> process(TotCve actual) {
        if (pendiente == null) {
            pendiente = actual;
            return List.of();
        }
        var anterior = pendiente;
        if (anterior.clave().equals(actual.clave()) && !anterior.identificador().equals(actual.identificador())) {
            pendiente = null;                                     // par completo: se consumen ambos
            long dNum = actual.numero() - anterior.numero();      // NUMTEM1 - NUMTEM2
            BigDecimal dImp = actual.importe().subtract(anterior.importe());
            return List.of(RenglonClave.par(anterior, actual, dNum, dImp));   // + 50007435-GENERA-DET-INC
        }
        pendiente = actual;                                       // el anterior queda sin pareja
        return List.of(RenglonClave.solo(anterior));              // LIMPIO-CVE + IMP-CVE
    }
}

Riesgos de migración
Diferencias sin signo

Los campos de diferencia WS-IMP-TCAR-DIF, WS-IMP-TABO-DIF, WS-IMP-NCON-DIF y sus contadores (líneas 375-384) y WS-TCVE-NDIF y WS-TCVE-IDIF (líneas 197-198) no tienen signo. Los reportes de cuadre muestran el valor absoluto y no permiten saber qué sistema tiene de más.

Batch detenido esperando al operador

Las consultas al S408 (50005254-DECIDO) y al S151 (50005302-DECIDE) se resuelven con ACCEPT por consola. Con la opción C el cuadre continúa con datos incompletos de ese producto sin marcarlo en el reporte.

Combinaciones de producto compiladas

La segunda consulta al S151 para producto 66, instrumento 15 y moneda 5 (líneas 2147-2161) y los productos sin línea de crédito (condiciones 88 PIM-PROD-A-SOR y PIM-PREPAGADA) están escritos en el código.

Reintento manual tras un aborto

Los contadores de paso se ponen en cero al inicio (línea 1624) y sólo se restauran a 170 al final; un aborto intermedio deja la base sin el valor 160 que exige el reintento.

Pendiente de revisión SME
  • Los párrafos 70000055-STOP-PGM, 10000100-VERSIONES, 20000151-TOTXCVES, 20000408-LINCRED y 90000000-B00CTRLPASO-LOCK no están en el fuente extraído (vienen de copybooks); su comportamiento se infirió por el nombre y el contexto.
  • Confirmar la razón de la segunda consulta al S151 con moneda 1 para el producto 66-15 en moneda 5.
  • Confirmar la definición de las condiciones 88 WS03-88-PIM-PROD-A-SOR y WS03-88-PIM-PREPAGADA, que no están en el fuente extraído.
  • Confirmar si el reporte de cifras se usa hoy para decidir el sentido del descuadre; si es así, la versión con signo cambia la lectura del reporte y debe acordarse con Operación.
