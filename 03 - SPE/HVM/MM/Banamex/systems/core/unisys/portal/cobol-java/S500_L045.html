Mantiene en memoria compartida cuatro ranuras de autorización, una por copia del proceso, protegidas por un evento usado como semáforo. VALIDAAUT registra una autorización en la ranura del llamador solo si no está ya en ninguna de las cuatro; LIBERAAUT pone la ranura en cero. FILEINUSE envía a la consola el comando PD sobre la bitácora S500/FILE/LOG/P045 y responde si el archivo aparece en uso. No accede a bases de datos ni persiste nada.

/**
 * Estado de L045. SHARING = SHAREDBYALL: una sola instancia para todos los programas
 * de la línea Teletón, por eso el estado es un singleton con acceso sincronizado.
 */
@Component
class RanurasAutorizacion {

    static final int RANURAS = 4;                         // AUTORIZACION[0:4], se usan 1..4

    private final long[] autorizacion = new long[RANURAS + 1];   // DOUBLE -> long: valores enteros
    private final ReentrantLock usoAut = new ReentrantLock(true);  // EVENT E_USO_AUT (PROCURE/LIBERATE)

    ReentrantLock candado()             { return usoAut; }
    long valor(int ranura)              { return autorizacion[ranura]; }
    void asigna(int ranura, long valor) { autorizacion[ranura] = valor; }
}

@Override
public int validaAut(int copia, long autorizacion) {
    int error = 0;                                        // ALGOL inicializa INTEGER en 0
    if (copia <= 0 || copia >= 5) {
        return 2;                                         // sin tomar el candado (ver riesgo)
    }
    ReentrantLock candado = ranuras.candado();
    candado.lock();                                       // PROCURE(E_USO_AUT)
    try {
        error = registraSiNoDuplicada(copia, autorizacion);   // s5
    } finally {
        candado.unlock();                                 // EPILOG LIBERA: una sola liberación
    }
    return error;                                         // VALIDAAUT := ERROR
}
/** Busca la autorización en las 4 ranuras; si no está, la registra en la ranura del llamador. */
private int registraSiNoDuplicada(int copia, long autorizacion) {
    for (int i = 1; i <= RanurasAutorizacion.RANURAS; i++) {
        if (ranuras.valor(i) == autorizacion) {
            return 1;                      // CONTADOR := 10 -> sale con 11 -> ERROR := 1
        }
    }
    ranuras.asigna(copia, autorizacion);   // AUTORIZACION[COPIA] := AUTORIZ
    return 0;
}
@Override
public int liberaAut(int copia) {
    if (copia <= 0 || copia >= 5) {
        return 2;
    }
    ReentrantLock candado = ranuras.candado();
    candado.lock();                 // el original escribe sin PROCURE; aquí se protege igual que VALIDAAUT
    try {
        ranuras.asigna(copia, 0L);  // AUTORIZACION[COPIA] := 0
        return 0;
    } finally {
        candado.unlock();
    }
}
Riesgos de migración
Doble liberación del semáforo

El EPILOG LIBERA (líneas 32-33) libera E_USO_AUT al salir de VALIDAAUT además del LIBERATE de la línea 44, y lo hace también cuando la ranura es inválida y no hubo PROCURE. Puede dejar sin protección la sección crítica de otro proceso.

Escritura sin candado en LIBERAAUT

LIBERAAUT (líneas 51-60) escribe en el arreglo compartido sin tomar el evento, en carrera con VALIDAAUT.

Detección de archivo en uso por texto de consola

FILEINUSE depende de que la respuesta de PD traiga IN USE exactamente en la posición 55 (línea 20). Un cambio de formato da falsos libres sin error.

Estado volátil

Con FREEZE(TEMPORARY) las ranuras se pierden si la librería se descarga por quedarse sin usuarios. Ruta de bitácora y número de ranuras están compilados; no hay credenciales en el fuente.

Pendiente de revisión SME
  • Confirmar con el SME qué programas consumen L045 además de P045 y cómo asignan la ranura (COPIA) a cada copia del proceso.
  • Confirmar si DCKEYIN requiere privilegios de consola para el usercode que ejecuta la línea Teletón; la versión Java elimina esa dependencia.
  • Confirmar si la aplicación destino correrá en una sola instancia; si no, el candado en memoria debe moverse a un almacén compartido.
  • El inventario no asigna reglas del brain a este componente; el pseudocódigo cita RN-S500-881, que no se usa aquí.
