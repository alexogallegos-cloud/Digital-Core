S151 · P020 a Java 21 Spring Boot

Al iniciar obtiene los designadores de COMS para la agenda de salida OUTPUT OF LINEA y la estación DEFAULTSTATION, y fija el CCR destino según el CSI o el nombre del equipo. Después espera eventos con ESPERACOMS en ciclos de 20 segundos; cada mensaje dirigido al sistema 0151 se recibe en un buffer de 864 bytes con encabezado de enrutamiento, ACA, SA0 y SA2 y un área de usuario de 739 bytes. Si el subcódigo destino es 264, resuelve con CTRLVERS el título vigente de LIB-REGISTRA, convierte los campos DISPLAY del mensaje al formato empaquetado de S151 y llama a CARGAMOV1. La respuesta invierte origen y destino, marca dirección 2 y regresa el código de resultado junto con los datos.

/** WKS-REG-MSG: 864 bytes = encabezado 36 + ACA 12 + SA0 30 + SA2 47 + área de usuario 739. */
public record MensajeL002(Encabezado hdr, Aca aca, Sa0 sa0, Sa2 sa2, byte[] areaUsuario) {

    public record Encabezado(char prefijo, char aplDestino, int ccrDestino,
                             byte[] lsnOrigen,            // 9(004) o 9(08) COMP según la red: se conserva crudo
                             Estacion estacion, int ccrOrigen, int copOrigen,
                             String facultad, char aplOrigen, int resultado,
                             String mascara, String password) {
        boolean esEco() { return resultado == 31 || resultado == 32 || resultado == 33; }   // W88-MSGRES-ERR
    }
    /** STATION X(8): tipo, sucursal, privilegio y caja. */
    public record Estacion(char tipo, int sucursal, char privilegio, int caja) {}
    public record Aca(int destino, int origen) {}

    /** SA0: transacción destino 9(09) = sistema 9(04) + código 9(02) + subcódigo 9(03). */
    public record Sa0(int sistemaDestino, int codigoDestino, int subcodigoDestino,
                      int sistemaOrigen, int codigoOrigen, int subcodigoOrigen,
                      Direccion direccion, int longitud, int tiempoEspera, int respuesta) {}

    public enum Direccion { ALTA, RESP, BAJA, RES_BAJA;                 // 1, 2, 3, 4
        static Direccion de(int v) { return values()[v - 1]; }
        int codigo() { return ordinal() + 1; }
    }

    static MensajeL002 decodifica(byte[] buf) { return MensajeL002Codec.decode(buf, Charset.forName("Cp1047")); }
}
/** WKS-DATOS-S151: el movimiento que manda S264, todo en DISPLAY (dígitos EBCDIC). */
public record MovimientoS264(
        int funcion, int sistema, int producto, int instrumento, int sucursalPromotora,
        String contrato,                        // 9(16): sucursal 9(04) + número 9(08) en las últimas 12 posiciones
        List<SlotS264> slots,                   // 5 grupos CVETRANn / IND-LEYEn / ESQ-CONTn / IMPORTEn
        /* ... fechas, autorizaciones, sucursales, cajas, moneda ... */
        int bancoS264, int bancoOrigen, int bancoDestino,
        List<String> leyendas) {}               // 5 x 40 posiciones

/** CVETRAN 9(04) e IMPORTE 9(14)V99 en DISPLAY: punto decimal implícito, sin signo. */
public record SlotS264(int claveTransaccion, int indicadorLey, int esquemaContable, BigDecimal importe) {
    static SlotS264 de(String campos) {
        return new SlotS264(Integer.parseInt(campos.substring(0, 4)),
                            Integer.parseInt(campos.substring(4, 6)),
                            Integer.parseInt(campos.substring(6, 10)),
                            new BigDecimal(new BigInteger(campos.substring(10, 26)), 2));
    }
}
/** 700000-S264-A-6DIG-COMP: copia campo por campo de WKS-DATOS-S151 a WKS-MOV-DATOS. */
@Component
public class MovimientoMapper {

    public MovimientoLog151 aS151(MovimientoS264 m) {
        var slots = m.slots().stream()
                .map(s -> new SlotContable(
                        s.claveTransaccion(),          // 9(04) DISPLAY -> 9(06) COMP: se amplía sin perder valor
                        s.indicadorLey(),
                        s.esquemaContable(),
                        s.importe(),                   // 9(14)V99 DISPLAY -> 9(14)V99 COMP, misma escala
                        0, 0))
                .toList();
        return MovimientoLog151.builder()
                .funcion(m.funcion()).sistema(m.sistema()).producto(m.producto())
                .instrumento(m.instrumento()).sucursalPromotora(m.sucursalPromotora())
                .contrato(m.contrato()).slots(slots)
                .bancoS264(m.bancoS264()).bancoOrigenS264(m.bancoOrigen()).bancoDestinoS264(m.bancoDestino())
                .leyendas(m.leyendas())
                .build();                              // empaquetado COMP lo resuelve el codec de salida
    }
}

Riesgos de migración
Respuesta de éxito sin registrar

Cuando CTRLVERS no devuelve la librería, 201000-PROCESA-MSG solo muestra el error y conserva W77-151-RESULT en 0; la respuesta lleva resultado 0 y una autorización S151 del mensaje previo.

Longitud de envío fija

La respuesta se envía con TEXT-LENGTH 737 desde un buffer de 864 bytes con 125 de encabezado. Validar con el emisor qué parte del área de usuario recibe.

Enlace de librería por mensaje

DAME_TIT y CANCEL LIB-REGISTRA se ejecutan en cada mensaje, con costo de búsqueda y enlace por transacción. La llamada equivalente previa está comentada en las líneas 1916 a 1922.

Hardcodes de equipos y CCR

Nombres de equipo VDMBETA, ACYPGAMA, MONALFA, ACYPOMEGA y VDMKAPPA, CCR 23 y 24, CSI 10 y 4, subcódigo 264, agenda OUTPUT OF LINEA y estación DEFAULTSTATION. Pasan a configuración.

060950-ESCRIBE-MONITOR copia el buffer completo, incluido WKS-HDR-PASSWORD, al archivo L02-MONITOR cuando el monitor está encendido.
