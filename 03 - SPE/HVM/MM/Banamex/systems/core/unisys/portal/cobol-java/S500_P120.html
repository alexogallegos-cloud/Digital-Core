P120 vuelca las devoluciones del dataset B08DEVOLUCION a un archivo plano, lo ordena por contrato y medio de acceso y, para cada devolución, decide si procede el cobro según el estado del contrato, la causa y la clave del movimiento, dejando un estatus de dos dígitos. Calcula la comisión con IVA contra el disponible del contrato, cobra parcial si no alcanza y registra lo pendiente en B12. Después aplica el archivo COMIPREV de S127 día por día y los cortes de estado de cuenta que entrega la librería S050/L191. Cada cargo genera movimientos para S151, un renglón en el punteo que continúa el de P102 y actualizaciones en B03, B06, B12 y B20, y al cierre consolida cifras en B09 y B14 y sella el control de paso.

@Component
@StepScope
@RequiredArgsConstructor
public class DevolucionProcessor implements ItemProcessor<Devolucion, Devolucion> {

    private final ContratoService contratos;          // 50003100-VERIFICA-CTO (LOCK B03SXCTO)
    private final TarifaDevolucion tarifas;           // 50003600-DAME-TARIFA
    private final CobroComision cobro;                // 50004000-COBRA-COMISION

    @Override
    public Devolucion process(Devolucion d) {
        Optional<ContratoVista> cto = contratos.verifica(d.contrato());
        if (cto.isEmpty()) return d.conEstatus(EstatusDevolucion.NO_EXISTE_CONTRATO);   // vía MODIF-ARCHIVO

        ContratoVista c = cto.get();
        if (d.estatus() == EstatusDevolucion.ELIMINADO) return d;
        if (c.tipoBloqueo() == 66 && c.restricciones() == 17) {
            return d.conEstatus(EstatusDevolucion.SIN_COBRO_POR_BLOQUEO);
        }
        if (c.esTesofe()) return d.conEstatus(EstatusDevolucion.DEVOLUCION);  // no se cobra; ver riesgo
        if (d.causaDevolucion() != 1) return d.conEstatus(EstatusDevolucion.CAUSA_NO_FONDOS);

        ResultadoTarifa t = tarifas.resuelve(d, c);
        return t.cobrable() ? cobro.cobra(d, c, t) : d.conEstatus(t.estatusNoCobro());
    }
}
// La ruptura por contrato y medio de acceso (W77-FIN-CTO, WKS-IGUAL-MDA) pasa a un
// ItemWriter que agrupa por contrato: el archivo ya viene ordenado por SORT S01-SORTDEVOL.
@Component
class TarifaDevolucion {

    /** 50003610-TARIFA-DEVOL. Índice de clave B05: 17 para la 2001, 18 para la 2002. */
    ResultadoTarifa resuelve(Devolucion d, ContratoVista c) {
        Integer indiceClave = switch (d.claveMovimiento()) {
            case 2001 -> 17;
            case 2002 -> 18;
            default -> null;              // 2113 incluida: el fuente la manda a COBRA-INSTR = 8
        };
        if (indiceClave == null) return ResultadoTarifa.noCobra(EstatusDevolucion.ERROR_CLAVE);

        Instrumento inst = c.instrumento();
        if (inst.claveComision(indiceClave) <= 0) {
            return ResultadoTarifa.noCobra(EstatusDevolucion.NO_COBRA_PRODUCTO);
        }
        BigDecimal tope = inst.comisionDevolucionMayor(c.tipoPersona(), c.indiceEsquema());  // 9(8)V99
        // Se cobra el menor entre el tope del tarifario y la diferencia de saldo de B08.
        BigDecimal tarifa = d.diferenciaSaldo().compareTo(tope) > 0 ? tope : d.diferenciaSaldo();
        return ResultadoTarifa.cobra(tarifa.setScale(2, RoundingMode.DOWN));  // MOVE a 9(8)V99 trunca
    }
}
@Component
@RequiredArgsConstructor
class CobroComision {

    /** WKS-TASA-IVA es 9(4)V9(4): factor 1 + tasa (p. ej. 1.1600). */
    CargoComision calcula(BigDecimal tarifa, BigDecimal factorIva, boolean llevaIva, BigDecimal disponible) {
        BigDecimal conIva, sinIva, iva;
        if (llevaIva) {
            conIva = tarifa.multiply(factorIva).setScale(2, RoundingMode.DOWN);   // COMPUTE sin ROUNDED
            sinIva = tarifa;
            iva    = conIva.subtract(sinIva);
        } else {
            conIva = sinIva = tarifa;
            iva    = BigDecimal.ZERO.setScale(2);
        }
        BigDecimal ivaTotal = iva, difCom = BigDecimal.ZERO.setScale(2), difIva = difCom;

        if (disponible.compareTo(conIva) < 0) {                // cobro parcial hasta el disponible
            conIva = disponible;
            if (llevaIva) {
                sinIva = conIva.divide(factorIva, 2, RoundingMode.HALF_UP);   // COMPUTE ... ROUNDED
                iva    = conIva.subtract(sinIva);
                difCom = tarifa.subtract(sinIva);
                difIva = ivaTotal.subtract(iva);
            } else {
                sinIva = disponible;
                iva    = BigDecimal.ZERO.setScale(2);
                difCom = tarifa.subtract(sinIva);
            }
        }
        return new CargoComision(conIva, sinIva, iva, difCom, difIva);
    }

    /** 50004200-CALCULA-DISPONIBLE: el saldo pendiente se integra al actual antes de calcular. */
    static BigDecimal disponible(Contrato c) {
        if (c.getSaldoPendiente().signum() > 0) {
            c.setSaldoActual(c.getSaldoActual().add(c.getSaldoPendiente()));
            c.setSaldoPendiente(BigDecimal.ZERO);
            if (c.getIndLineaCredito() > 0) c.setIndPendienteLc(1);
        }
        return c.getSaldoActual().compareTo(c.getAutPendiente()) > 0
                ? c.getSaldoActual().subtract(c.getAutPendiente()) : BigDecimal.ZERO;
    }
}

Riesgos de migración
Clave 2113 nunca se cobra

50003610-TARIFA-DEVOL (líneas 2952-2984) solo tiene ramas para 2001 y 2002; la 2113 cae en COBRA-INSTR = 8 y queda con estatus 08, aunque el catálogo (línea 710) y DAME-CVES-COMIS (línea 3290) la tratan como válida.

Estatus heredado del registro anterior

WKS-COBRA-INSTR solo se inicializa con VALUE 1 (línea 447) y no se reinicia por devolución. En cuentas TESOFE, que no pasan por la tarifa, el estatus final depende del registro procesado antes.

Comisión no cobrada sin rastro

Si la clave no tiene indicador de comisión pendiente, la diferencia entre tarifa y lo cobrado se pone en cero (líneas 3338-3343).

Truncamiento del IVA

El importe con IVA se calcula sin ROUNDED (línea 3301) y el despeje en cobro parcial sí redondea (línea 3313); la combinación puede dejar diferencias de un centavo entre IVA cobrado e IVA pendiente.

Contratos exentos compilados

Nueve números de contrato están escritos en 50200500-LEE-ARCH-PREVEN (líneas 3990-3998) y quedan fuera del cobro de prevenciones. No se reproducen en este documento.

Atomicidad entre S151, punteo y DMSII

Los movimientos al mayor y el punteo se emiten antes de la transacción que actualiza B03, B06 y B12; un aborto intermedio deja inconsistencias que hoy se resuelven con reproceso manual.

Hardcodes operativos

Claves excluidas 0688, 0690 y 0692, sucursales 3667 y 3084 por nodo, banco 002 o 007, límites de 30 instrumentos, 30 movimientos por mensaje y 100 claves acumuladas. Se trasladan a configuración.
