P610 · Dispatcher Multi-Función de Control de Ciclo Batch (S151)

S151ProgramaCOBOL

Fuente: COBOL_P610.cbl (1,767 LOC) · Dispatcher de control batch · BC-18

Convenciones: nombres traducidos (Unisys→legible); [P610 Lnnnn] = número de línea en fuente; (BR: RN-S151-NNN) = regla de negocio del KB.

PROGRAM-ID implícito: CALLLIBCTL · MTP: 25MTP001 · PASO-LJ: "P610"

1. Resumen funcional

P610 (PROGRAM-ID CALLLIBCTL, 1,767 LOC) es el dispatcher multi-función de la librería de control de ciclo del sistema S151 (General Ledger Banamex, Unisys ClearPath MCP). No contiene lógica de negocio propia: recibe tres parámetros — función (1–9), sistema y dato_genérico — y enruta la ejecución al procedimiento correspondiente dentro de la biblioteca LIBCTL. Las nueve funciones cubren las operaciones de inicio, cierre y transición del ciclo batch diario/mensual del GL: registrar tamaño de ciclo (F01), activar/desactivar bases de datos (F02, F04, F05), enviar señal de fin de día al motor de posting (F03), actualizar estado del sistema (F06), crear archivo E01 de intercambio (F07), actualizar fechas en archivo CONTROL/CORP (F08) y generar el archivo TANDEM para ICA/Banxico (F09). Cualquier función fuera del rango 1–9 causa terminación anormal del task MCP con STATUS=-1. (BR: RN-S151-451)

PROCEDIMIENTO Inicializar_Bibliotecas():                       // 000200-LIBRERIAS · [P610 L1481]
```
// Configurar modo de acceso por función para las bibliotecas auxiliares
CAMBIAR atributo LIBACCESS de "CTLVER" a BYFUNCTION, nombre función = "CTLVERS"
CAMBIAR atributo LIBACCESS de "SOPORTECOMS" a BYFUNCTION, nombre función = "SOPORTECOMS"
CAMBIAR atributo TITLE de "LIB-DISP" a "(S000)S000/UTILITY/DESPLIEGA/OBJ/LIB ON PACK."

// Obtener identificador de CSI del nodo actual
LLAMAR CSIID IN SOPORTECOMS USANDO nodo_host  // WKS-HOST [P610 L1490]
    // Retorna número de CSI (Centro de Sistemas de Información) del nodo MCP actual
CANCELAR "SOPORTECOMS"                         // libera segmento de memoria [P610 L1491]

// Resolver ruta de LIBCTL via CTLVERS (registro de versiones de S151)
MOVER "S151L001CTL" A identificador_biblioteca  // WKS-LIBID [P610 L1492]
LLAMAR DAME_TIT IN CTLVER                       // [P610 L1493]
    USANDO identificador_biblioteca, ruta_resuelta  // WKS-LIBID, WKS-NOMLIB
    RETORNANDO codigo_error_ctlver              // W77-ERR-CTLVER

SI codigo_error_ctlver = 0 ENTONCES            // resolución exitosa
    CAMBIAR atributo TITLE de "LIBCTL" a ruta_resuelta   // ruta dinámica del registro [P610 L1496]
SINO                                           // CTLVERS falló
    CAMBIAR atributo TITLE de "LIBCTL" a                 // ⚠ [HARDCODE-SOSPECHOSO]
        "(S151)S151/OBJECT/L001/CONTROL/02MTP009 ON CMEMP"  // fallback fijo [P610 L1498-1499]
FIN-SI

CANCELAR "SOPORTECOMS"                         // segunda liberación [P610 L1501]
CANCELAR "CTLVER"                              // libera resolvedor de versiones [P610 L1502]
```

```
// Paso 1: leer registro actual de B03SISMEN
MOVER 1 A funcion_b03                          // WKS-B03-FUNCION = 1 (consulta) [P610 L1546]

// Paso 2: determinar STABDSAL a establecer según función llamante
SI funcion = 2 ENTONCES                        // desactivación total del ciclo
    MOVER 99 A estado_base_salida              // WKS-B03-STABDSAL = 99 [P610 L1551]
    // STABDSAL=99 → base desactivada completamente (cycle_status = 'CLOSED')

    MOVER 1 A funcion_consisdia               // WKS-B01-FUNCION = 1 [P610 L1553]

        USANDO paquete_consisdia               // WKS-S151B01SISDIA

    SI resultado_libcon = 0 ENTONCES
        MOVER fecpro_b01 A fecha_completa      // WKS-B01-FECPRO → WKS-FECHA-8D [P610 L1558]

        // STABDSAL=1 → ciclo activo/iniciado para el período AAMM actual
    FIN-SI
FIN-SI

// Paso 3: actualizar B03SISMEN con el nuevo STABDSAL

MOVER sistema A sistema_b03                    // WKS-B03-SISTEMA
```
