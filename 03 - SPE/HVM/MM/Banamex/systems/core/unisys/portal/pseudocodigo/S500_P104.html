P104 · Monitor de Capacidad y Saturación de Archivos/Data Sets (S500 Captación)

S500ProgramaCOBOL

Fuente: P104.cbl (~4515 LOC) · COBOL85 Unisys ClearPath MCP · batch nocturno de captación (S500) · BC-02

Convenciones: nombres traducidos (Unisys→legible); [P104 Lnnnn] = nº de línea en cols 1-6 del fuente; (BR: RN-S500-...) = regla de negocio del catálogo.

COPY compartidos referenciados por nombre (no expandidos aquí): S500/INC/WOR/25MTP002, S500/INC/MAPLI/WOR/15MTP001, S500/INC/PRO/25MTP002, S500/INC/MAPLI/PRO/15MTP001, y los $SET de accesos DMSII BD4B00/BD4B06 (BEGIN/END-TRANSAC, LOCK/CREATE/STORE del data set B06P).

1. Resumen funcional

P104 es el monitor de ocupación de archivos en disco y de data sets DMSII del sistema de captación S500 (Banamex). En cada corrida (parametrizada por un TASKVALUE con fecha, CSI y opción de proceso) recorre un catálogo de decenas de archivos residentes (S500/FILE/...) y de data sets de las bases S500BD01CAPTACION, BD02AUXILIAR, BD03MSGAAPLI y S500BD04TARJETAS, obtiene su número de registros y su capacidad máxima (POPULATION), y persiste esos máximos históricos en el data set de control S500B06PCTRLARCH (bloque B06 de la base de tarjetas). Con esa información calcula el porcentaje de uso, detecta archivos saturados al 80% y emite dos reportes impresos (R01 = archivos, R02 = estadístico con máximos por día/mes/año). Su rol en el batch es de vigilancia de capacidad: alerta a Ingeniería de Sistemas cuando un archivo o data set supera el umbral de uso, para prevenir desbordes antes de las ventanas de REORG/GARBAGE. El programa se ejecuta en varias fases del lote (una por base + una de archivos + una de reportes), seleccionadas por la opción del TASKVALUE.

2.2 Bases / data sets DMSII (DATA-BASE SECTION)

  • S500BD04TARJETAS — base de tarjetas de débito (abierta UPDATE o INQUIRY según opción).
  • S500B06PCTRLARCH (data set B06P) — control de máximos históricos por archivo/data set. Campos clave: B06P-LLAVE-ARCH, B06P-NOMBRE, B06P-FECH-ACT/B06P-FECH-ANT, B06P-REGXDIA(31), B06P-MAXMES-AACT(12)/-AANT(12) con sus fechas B06P-FECMXM-*, B06P-MAX-ANUAL(5)/B06P-FEC-MAXANH(5), B06P-REGMAXHIST/B06P-FECHMAXHIST, B06P-MAXIMA-CAP, B06P-PORC-USO, B06P-NO-ACT.
  • S500B91PREINICIO — declarado (reinicio), sin uso activo detectado. ⚠ [CÓDIGO-MUERTO-APARENTE]

2.3 Working-Storage relevante

  • Contadores de saturación/dimensionamiento: W77-NUM-ARCH-SAT, W77-PORC-USO 9(3)V9, W77-CAPACIDAD, W77-AREASIZE, W77-TOT-DISKSIZE, W77-TOT-MEMSIZE, W77-REG-TOTAL.
  • Ventana temporal: WKS-AAAA-MAQ (año de fecha de máquina), W77-ANH-ANT/W77-ANH-POS (año-1/año+1).
  • TASKVALUE (WS-TASKVALUE 9(12)): WS-TASK-FECH (AAAAMMDD), WS-TASK-CSI (04=Monterrey, 10=VDM/México), WS-TASK-OPC (01=BD01, 02=BD02, 03=BD03, 04=BD04, 50=archivos, 90=reportes).
  • Registro de trabajo por archivo: WS-CAMPOS-ACT (WS-ACT-LLAVE, WS-ACT-REG, WS-ACT-CAPACIDAD, WS-ACT-FECHA, WS-ACT-NOMBRE).
  • Tablas fijas: WS-TBDIAS (días por mes "312831…"), WS-TBMESES ("ENEFEB…DIC").
  • Hardcodes de negocio: sucursal 3084 (encabezado L04), banda de saturación 79.8/79.9, capacidad de trabajo AREASIZE × 15000, sort DISK 300000 / MEMORY 400000 WORDS, y las POPULATION hardcodeadas por cada data set (ver §4, bloques DB01-DB04).

4.1 Control y arranque

PROCEDIMIENTO Control_Programa():                         // 00000000-CTRLPGM · [P104 L225500]
    EJECUTAR Valida_Host()
    EJECUTAR Enlaza_Librerias()
    EJECUTAR Valida_TaskValue()
    EJECUTAR Registra_Inicio_MAPLI()                      // copia MAPLI según opción de proceso
    EJECUTAR Inicia_Actividad_01()
    EJECUTAR Valida_Fecha_Value()                         // valida fecha + calcula fechas hábiles
    EJECUTAR Arma_Encabezados()
    EJECUTAR Abre_Reportes()
    EJECUTAR Compone_Nombres_Archivos()                   // pon fecha/CSI en nombres
    EJECUTAR Abre_Base()                                  // UPDATE o INQUIRY según opción
    EJECUTAR Fin_Actividad_MAPLI()
    EJECUTAR Proceso_Principal()                          // dispatcher por opción
    // Última actividad: terminar
    MOVER 8 A id_actividad; MOVER "TERMINA PROGRAMA" A nombre_actividad
    EJECUTAR Inicia_Actividad_General()
    EJECUTAR Termina()
    EJECUTAR Fin_Actividad_MAPLI()
    EJECUTAR Fin_Programa_MAPLI()
    SI resultado_MAPLI (WS-S038L035-RESULT) > 0 ENTONCES  Error_MAPLI("FIN PASO P104")
    SINO  registrar "FIN PASO EN MAPLI ... OK"
    ABORTAR/RETORNAR (STOP RUN)                            // [P104 L230900]

PROCEDIMIENTO Valida_Host():                              // 00000100-VALIDA-HOST · [P104 L231300]
    EJECUTAR Dame_Fecha_Maquina()                         // copybook compartido
    ACEPTAR hora_maquina DESDE TIME
    MOVER atributo TASKVALUE de MISMO A WS-TASKVALUE       // parámetros de ejecución
    MOVER atributo MIXNUMBER de MISMO A num_mix
    EJECUTAR Change_Sopcoms() ; EJECUTAR Call_Hostname()
    // Detección de año bisiesto:
    DIVIDIR WKS-AAAA-MAQ ENTRE 4 → resto W77-R-REMANENTE
    SI resto = 0 (W88-ES-BISIESTO) ENTONCES MOVER 29 A dias_de_febrero (WS-TBDIA-F(02))
    MOVER identidad "S500P104" / versión "25MTP005" / código 050505 a variables de log
    // Clasifica entorno por hostname:
    SI host es PBA        ENTONCES entorno = 1 (DESARROLLO)
    SINO SI host es UAT   ENTONCES entorno = 2 (UAT)
    SINO SI host es PROD  ENTONCES entorno = 0 (PRODUCCION)
    SINO  entorno = 2 (UAT) ; registrar "NAME-HOST DESCONOCIDO ... ASUMO COMO UAT"   ⚠ [FALLBACK-SILENCIOSO]
    registrar "PROCESO EN HOST <equipo>"

PROCEDIMIENTO Enlaza_Librerias():                         // 10000000-LIBRERIAS · [P104 L236000]
    EJECUTAR Versiones()                                  // librería de versiones
    SI entorno = DESARROLLO ENTONCES  (no valida versión)
    SINO  EJECUTAR Checa_Version()                        // 10000105-CHECAME
    EJECUTAR LOCSUP()                                     // librería de fechas/días hábiles (S006)
    EJECUTAR S038L035()                                   // librería MAPLI (registro de módulos activos)

PROCEDIMIENTO Checa_Version():                            // 10000105-CHECAME · [P104 L238700]
    EJECUTAR Checa_Version_Detalle()
    SI cve_error < 0 ENTONCES registrar "ERROR DE VERSION" ; CAMBIAR STATUS DE MISMO A -1  // aborta task

PROCEDIMIENTO Registra_Inicio_MAPLI():                    // 10000107-INI-PGM-MAPLI · [P104 L239500]
    // Nº de copia MAPLI según opción (BD03=1, BD01=2, BD02=3, ARCHIVOS=4, BD04=5, REPORTES=6)
    SEGUN opción → asignar num_copia_MAPLI
    registrar "INICIO PGM EN MAPLI COPIA n"
    MOVER "BATCH DIARIO" A nombre_lib ; grupo=06
    EJECUTAR Inicia_Pgm_MAPLI()                           // copybook MAPLI
    SI resultado_MAPLI > 0 ENTONCES Error_MAPLI("INICIO PASO P104")  SINO registrar "... OK"

PROCEDIMIENTO Valida_TaskValue():                         // 10000100-VAL-TASKVALUE · [P104 L243000]
    SI opción NO ES 01/02/03/04/50/90 ENTONCES registrar "TIPO PROCESO ERRONEO"; err_task=1

4.2 Cálculo de fechas (ventana temporal)

PROCEDIMIENTO Valida_Fecha_Value():                       // 10000190-VAL-FECHA-VALUE · [P104 L244700]
    EJECUTAR Valida_Fecha()
    SI err_task = 1 ENTONCES registrar "TASK VALUE ERRONEO"; CAMBIAR STATUS DE MISMO A -1  // aborta
    registrar "RECIBO TASKVALUE<...>"
    EJECUTAR Fecha_Anterior()
    EJECUTAR Fecha_Siguiente()

PROCEDIMIENTO Valida_Fecha():                             // 10000130-VALIDA-FECHA · [P104 L252400]
    CALCULAR año_anterior  (W77-ANH-ANT) = WKS-AAAA-MAQ - 1     // « [P104 L252600] · BR: RN-S500-732 »
    CALCULAR año_posterior (W77-ANH-POS) = WKS-AAAA-MAQ + 1     // « [P104 L252700] · BR: RN-S500-732 »
    SI año_task ∈ {año_máquina, año_anterior, año_posterior} ENTONCES
        SI mes_task ∈ 01..12 ENTONCES
            SI día_task ∈ 01..31 ENTONCES
                SI día_task NO > dias_del_mes(mes_task) ENTONCES ok
                SINO registrar "DIA NO CORRESPONDE AL MES"; err_task=1
            SINO registrar "DIAS DE FECHA ERRONEO"; err_task=1
        SINO registrar "MES DE FECHA ERRONEO"; err_task=1
    SINO registrar "AÑO DE FECHA ERRONEO, DEBE SER DEL {año-1} AL {año+1}"; err_task=1
    // La ventana de años válida es SIEMPRE [año_máquina-1, año_máquina+1] (BR: RN-S500-732)

PROCEDIMIENTO Fecha_Anterior():                           // 10000192-FECH-ANTERIOR · [P104 L246300]
    LLAMAR LOCSUP(fecha_task, función=15, formato=12)      // día hábil anterior
    MOVER resultado A fecha_dia_anterior ; extraer día → W77-DIA-ANT
    registrar "FECHA HABIL ANTERIOR = ..."
    EJECUTAR Fechas_5Dias_Anteriores()
    registrar "FECHAS P/TBINTER DESDE {task-5d} HASTA {task}"

PROCEDIMIENTO Fechas_5Dias_Anteriores():                  // 10000193-FECHAS-5DIAS-ANT · [P104 L249300]
    MOVER fecha_task A dia_00
    REPETIR 5 veces: EJECUTAR Resta_1Dia() ; guardar en dia_01..dia_05   // 5 días NATURALES atrás
    restaurar fecha_pte = fecha_task

PROCEDIMIENTO Resta_1Dia():                               // 10000194-RESTA-1DIA · [P104 L251400]
    LLAMAR LOCSUP(fecha_pte, función=10, formato=12) → fecha_pte           // fecha - 1 día natural

PROCEDIMIENTO Fecha_Siguiente():                          // 10000195-FECH-SGTE · [P104 L252135]
    LLAMAR LOCSUP(fecha_task, función=13, formato=12) → fecha_proxima      // día siguiente

PROCEDIMIENTO Call_LOCSUP():                              // 40000000-CALL-LOCSUP · [P104 L276300]
    EJECUTAR LOCSUP()  // rutina real en copybook
    SI función > 0 (error) ENTONCES registrar "ERR CALL LOCSUP..."; CAMBIAR STATUS DE MISMO A -1

4.4 Núcleo: actualización de máximos en el data set B06P

PROCEDIMIENTO Actualiza_NumReg():                         // 40000600-ACT-NUMREG · [P104 L278100]
    MOVER llave_actual A WS-LLAVE
    EJECUTAR Lock_SETB06P()                               // 90400006-SETB06P-LOCK (copybook DMSII)
    SI status_base = 0 ENTONCES                           // ya existe registro para este archivo
        SI archivo_residente (W77-NO-RESIDENTE=0) ENTONCES EJECUTAR Actualiza_DataSet()
        SINO  (no residente, no hace nada)
    SINO SI status_base = 1 ENTONCES                      // no existe → crear
        EJECUTAR Crea_DataSet()
        SI NO residente ENTONCES  B06P-PORC-USO=0 ; EJECUTAR Store_B06P()   // crea solo con llave y nombre
        SINO  EJECUTAR Actualiza_DataSet()
    SINO  registrar "LOCK X SET B06P, LLAVE ..."; EJECUTAR Disp_Err_Base()  // aborta (fin=1)

PROCEDIMIENTO Crea_DataSet():                             // 40000610-CREA-DATASET · [P104 L280900]
    EJECUTAR Create_DATAB06P()                            // 90400006-DATAB06P-CREATE
    SI status_base > 0 ENTONCES registrar "CREATE DATAB06P..."; Disp_Err_Base() (aborta)
    MOVER llave_actual A B06P-LLAVE-ARCH ; MOVER nombre_actual A B06P-NOMBRE

PROCEDIMIENTO Actualiza_DataSet():                        // 40000650-ACT-DATASET · [P104 L282100]
    // arma inicio de mes de la última actualización
    MOVER B06P-FECH-ACT A inicio_mes_act ; día=1
    // Evita re-actualizar si ya se actualizó HOY (reinicios/reprocesos sin rollback):
    SI fecha_actual < B06P-FECH-ACT ENTONCES
        SI fecha_actual < inicio_mes_act ENTONCES  (nada)
        SINO EJECUTAR Sigue_Actualizacion()
    SINO SI B06P-FECH-ACT ≠ fecha_actual ENTONCES EJECUTAR Sigue_Actualizacion()

PROCEDIMIENTO Sigue_Actualizacion():                      // 40000651-SIGUE-ACT · [P104 L282900]
    SI fecha_actual > B06P-FECH-ACT ENTONCES EJECUTAR Valida_Cambio_Mes()
    SI usa_dia_anterior=1 ENTONCES MOVER B06P-REGXDIA(día_anterior) A registros_actuales
    SI fecha_actual > B06P-FECH-ACT ENTONCES                       // avanza fechas
        MOVER B06P-FECH-ACT A B06P-FECH-ANT ; MOVER fecha_actual A B06P-FECH-ACT ; B06P-NO-ACT=0
    SI nombre_actual ≠ " " ENTONCES MOVER nombre_actual A B06P-NOMBRE
    MOVER registros_actuales A B06P-REGXDIA(día_de_fecha_actual)   // registros del día
    SI B06P-MAXMES-AACT(mes) < registros_actuales ENTONCES         // máximo del mes (año actual)
        actualizar B06P-MAXMES-AACT(mes) y B06P-FECMXM-AACT(mes)
    SI B06P-MAX-ANUAL(01) < registros_actuales ENTONCES            // máximo del año actual
        actualizar B06P-MAX-ANUAL(01) y B06P-FEC-MAXANH(01)
    SI registros_actuales > B06P-REGMAXHIST ENTONCES               // máximo histórico
        actualizar B06P-REGMAXHIST y B06P-FECHMAXHIST
    SI capacidad_actual > 0 ENTONCES                               // capacidad máxima (POPULATION)
        SI capacidad_actual = B06P-MAXIMA-CAP ENTONCES (nada)
        SINO SI capacidad_actual > B06P-MAXIMA-CAP ENTONCES  B06P-MAXIMA-CAP=capacidad ; B06P-PORC-USO=0
        SINO  B06P-MAXIMA-CAP=capacidad                            // capacidad menor: la registra igual
    EJECUTAR Store_B06P()

PROCEDIMIENTO Valida_Cambio_Mes():                        // 40000652-VAL-CAMBIO-MES · [P104 L286500]
    MOVER B06P-FECH-ACT (actualización previa) A fecha_ant ; EJECUTAR Cambio_Mes()

PROCEDIMIENTO Cambio_Mes():                               // 40000653-CAMBIO-MES · [P104 L288900]
    SI año_actual ≠ año_anterior ENTONCES
        EJECUTAR Valida_Cambio_Anio() ; limpiar 31 días  (Limpia_Dia ×31)
    SINO SI mes_actual ≠ mes_anterior ENTONCES limpiar 31 días (Limpia_Dia ×31)

PROCEDIMIENTO Limpia_Dia():                               // 40000654-LIMPIA-DIA · [P104 L290600]
    índice_día += 1 ; MOVER 0 A B06P-REGXDIA(índice_día)

PROCEDIMIENTO Valida_Cambio_Anio():                       // 40000660-VAL-CAMB-ANH · [P104 L291500]
    EJECUTAR Cambia_Anio()
    MOVER meses_año_actual A meses_año_anterior (B06P-XMES-ANHACT → B06P-XMES-ANHANT)  // conserva 12 meses
    limpiar 12 meses del año actual (Limpia_Mes ×12)

PROCEDIMIENTO Limpia_Mes():                               // 40000664-LIMPIA-MES · [P104 L292800]
    índice_mes += 1 ; MOVER 0 A B06P-MAXMES-AACT(índice_mes) y B06P-FECMXM-AACT(índice_mes)

PROCEDIMIENTO Cambia_Anio():                              // 40000670-CAMBIA-ANH · [P104 L293400]
    // corrimiento de máximos anuales: occ04→05, 03→04, 02→03, 01→02 ; occ01=0 ; se pierde occ05
    desplazar B06P-MAX-ANUAL(1..5) y B06P-FEC-MAXANH(1..5) ; poner occurrence 01 en ceros

PROCEDIMIENTO Ve_Actualizado_Hoy():                       // 40000700-VE-ACTHOY · [P104 L295400]
    EJECUTAR Lock_DATAB06P()                              // 90400006-DATAB06P-LOCKN (recorre data set)
    SI status_base = 0 ENTONCES
        SI B06P-FECH-ACT > 0 ENTONCES
            SI B06P-FECH-ACT >= fecha_task ENTONCES EJECUTAR Si_Actualizado_Hoy()
