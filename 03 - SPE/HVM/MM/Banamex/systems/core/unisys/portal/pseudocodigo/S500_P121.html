P121 · Planchado de Autorizaciones Pendientes en Captación (S500)

S500ProgramaCOBOL

Fuente: p121.cbl (468 LOC) · programa de reconciliación batch · BC-05

Convenciones: nombres traducidos (Unisys COBOL→legible); [p121 Lnnnn] = número de línea en fuente (cols 1-6); (BR: RN-S500-###) = regla de negocio del catálogo.

PROGRAM-ID real: ACTB03. El nombre P121 corresponde al paso WFL del job batch.

1. Resumen funcional

P121 (ACTB03) es el programa de "planchado" de autorizaciones pendientes del sistema de captación S500 (Banamex). Su función es reconciliar, contrato por contrato en la estructura DMSII B03CONTRATOS, el saldo de autorizaciones pendientes acumuladas durante el ciclo online frente al indicador de control centralizado en B02CONTROL. El programa calcula el monto neto pendiente real (FILLER1 − FILLER2) y lo consolida en el campo B03-AUT-PENDIENTE, limpiando los acumuladores temporales. Opera en modo UPDATE sobre toda la base S500BD01CAPTACION, con bloqueo exclusivo por registro. Solo se ejecuta cuando el parámetro de entrada (WS-PARAM-121) vale 1 y en un nodo reconocido (CSI 10 = VDM o CSI 04 = MTY). Al finalizar emite totales de contratos leídos, bloqueados y actualizados.

4.14 · Actualizar_Contrato

PROCEDIMIENTO Actualizar_Contrato():                // 50110000-ACTUALIZACION · [p121 L136260]
```
// --- Paso 1: bloquear registro exclusivamente ---
EJECUTAR Bloquear_Contrato_B03()                       // 90000003-B03CONTRATOS-LOCK
SI estado_base > 0                                     // WS-STATUS-BASE
   CONCATENAR "ERR LOCK B03CONTRATOS CTO=" + mensaje_contrato → texto_mensaje
   EJECUTAR Emitir_Mensaje()
   LLAMAR SYSTEM DMTERMINATE                           // ⚠ Termina ante error de lock

SUMAR 1 → total_contratos_bloqueados                   // W77-TOT-B03-CTOS-LOCK
MOVER 0 → bandera_modificado                           // WKS-SI-B03 ← reset por contrato

// --- Paso 2: determinar si el contrato está "planchado" ---
// Un contrato está NO planchado cuando hay doble discrepancia de indicadores (BR: RN-S500-420)
SI indicador_autorizaciones ≠ control_autorizaciones_contrato       // W77-B02-IND-AUTPEND ≠ B03-CTR-AUTSPEND
   SI indicador_secundario_autorizaciones ≠ control_autorizaciones_contrato  // W77-B02-CTR-AUTSPENDEAS ≠ B03-CTR-AUTSPEND
      // ** CONTRATO NO PLANCHADO — doble discrepancia; aplica neteo **
      // Neteo de autorizaciones pendientes (BR: RN-S500-416)
      SI (autorización_pendiente > 0)                  // B03-AUT-PENDIENTE
         O (acumulador_cargos > 0)                     // B03-FILLER1
         O (acumulador_cancelaciones > 0)              // B03-FILLER2
         SI acumulador_cargos > acumulador_cancelaciones  // B03-FILLER1 > B03-FILLER2
            // Quedan autorizaciones netas pendientes
            CALCULAR autorización_pendiente = acumulador_cargos - acumulador_cancelaciones
            //                               B03-AUT-PENDIENTE = B03-FILLER1 - B03-FILLER2
            MOVER indicador_autorizaciones → control_autorizaciones_contrato
            //     W77-B02-IND-AUTPEND     → B03-CTR-AUTSPEND
            MOVER CERO → acumulador_cargos             // B03-FILLER1
            MOVER CERO → acumulador_cancelaciones      // B03-FILLER2
            MOVER 1    → bandera_modificado            // WKS-SI-B03
         SINO
            // Todas las autorizaciones fueron canceladas — saldo neto = cero
            // Comentario fuente: "NO REALIZARON COMPRAS O CANCELARON TODAS LAS COMPRAS"
            MOVER CERO → autorización_pendiente        // B03-AUT-PENDIENTE
            MOVER CERO → acumulador_cargos             // B03-FILLER1
            MOVER CERO → acumulador_cancelaciones      // B03-FILLER2
            MOVER indicador_autorizaciones → control_autorizaciones_contrato
            MOVER 1 → bandera_modificado               // WKS-SI-B03
      SINO
         // Sin movimientos pendientes de ningún tipo
         NEXT SENTENCE                                 // no modifica el contrato
   SINO
      // ** CONTRATO PLANCHADO por control secundario (W77-B02-CTR-AUTSPENDEAS coincide) **
      // Igual sincroniza el indicador primario
      MOVER indicador_autorizaciones → control_autorizaciones_contrato
      //     W77-B02-IND-AUTPEND     → B03-CTR-AUTSPEND
      MOVER 1 → bandera_modificado                    // WKS-SI-B03
      SI (acumulador_cargos > 0) O (acumulador_cancelaciones > 0)   // B03-FILLER1/FILLER2
         MOVER CERO → acumulador_cargos               // B03-FILLER1
         MOVER CERO → acumulador_cancelaciones        // B03-FILLER2
         // ⚠ Línea L136960 comentada: "***MOVE 1 TO WKS-SI-B03" — bandera ya está en 1
SINO
   // ** CONTRATO PLANCHADO por indicador primario (W77-B02-IND-AUTPEND ya coincide) **
   // Solo limpia FILLERs si quedaron sucios
   SI (acumulador_cargos > 0) O (acumulador_cancelaciones > 0)     // B03-FILLER1/FILLER2
      MOVER CERO → acumulador_cargos                 // B03-FILLER1
      MOVER CERO → acumulador_cancelaciones          // B03-FILLER2
      MOVER 1    → bandera_modificado                // WKS-SI-B03

// --- Paso 3: persistir si hubo cambio ---
SI bandera_modificado = 1                             // WKS-SI-B03
   EJECUTAR Persistir_Contrato_B03()                 // 00000000-ACT-B03

FREE S500B03CONTRATOS                                 // libera bloqueo del registro
```
