Al iniciar se liga a COMSSUPPORT y SOPORTECOMS, obtiene el CSI del equipo, habilita la entrada ONLINE y resuelve con CTLVER el título de la librería S151L012. Después espera eventos: por cada mensaje recibido revisa tipo, longitud y nodo de origen (15, 16, 21 o 22). Los mensajes tipo 02 traen un resultado de 1 a 3 (confirmado, no enviado o duplicado) y una secuencia; los tipo 32 traen solo una secuencia. En ambos casos actualiza contadores y llama a ENVIA_CD de S151L012. Los tipos 11 y 12 son consultas y reciben como respuesta un resumen de contadores. Por TASKVALUE el operador puede cambiar el bloque o el tiempo de espera de la dispersión, activar el modo de prueba, deshabilitar el programa o volver a ligar la librería.

public record MensajeTandem(String nodoDestino,  // E_MSG[02], 2
                            String nodoOrigen,   // E_MSG[16], 2
                            String tipo,         // E_MSG[23], 2
                            String tcDestino,    // E_MSG[36]
                            String tcOrigen,     // E_MSG[42]
                            byte[] crudo, int longitud) {

    static final int OFS_RESULTADO = 83;          // TXT_RESULT
    static final int OFS_SECUENCIA = 92;          // TXT_SEQ
    static final int OFS_SECUENCIA_32 = 71;       // E_MSG[71] en tipo 32

    static MensajeTandem de(byte[] e, int longitud) {
        return new MensajeTandem(Ebcdic.texto(e, 2, 2), Ebcdic.texto(e, 16, 2), Ebcdic.texto(e, 23, 2),
                Ebcdic.texto(e, 36, 6), Ebcdic.texto(e, 42, 6), e, longitud);
    }
}

    private final DispersionClientRefresher refresher;
    private final ReceptorEstado estado;                  // testing, habilitado
    private final IntegrationFlowContext flujos;

    @WriteOperation
    public String comando(int taskValue) {
        if (taskValue > 2400) {                            // cambio de bloque de dispersión
            return "CONFIG_DISPERSION=" + dispersion.configura(taskValue % 100, 0);
        }
        if (taskValue > 2300) {                            // cambio de tiempo de espera
            return "CONFIG_DISPERSION=" + dispersion.configura(0, taskValue % 20);
        }
        switch (taskValue) {
            case 2 -> estado.testing(true);
            case 3 -> estado.testing(false);
            case 4, 5, 6 -> flujos.getRegistrationById("receptorTandem").stop();   // DISABLE PROGRAM
            case 11 -> refresher.religa();                 // CAMBIA_L012
            default -> { }
        }
        return "OK";
    }
}
@Component
@RequiredArgsConstructor
public class DispersionClientRefresher {

    private final CtlVerClient ctlver;                       // CTLVERS / DAME_TIT
    private final ObjectProvider<DispersionClient> proveedor;
    private final RetryTemplate reintento;                   // reemplaza WHILE LINKLIBRARY < 0 + ERROR_LIGA
    private volatile DispersionClient actual;

    /** REFRESCA: obtiene la versión vigente de S151L012 y la liga. */
    public void liga() {
        String version = ctlver.titulo("S151L012")
                .orElseThrow(() -> new IllegalStateException("CTLVER sin título para S151L012"));
        actual = reintento.execute(ctx -> proveedor.getObject(version));   // con tope y alerta
    }

    /** CAMBIA_L012: DELINKLIBRARY, espera 3 segundos y vuelve a ligar. */
    public void religa() {
        DispersionClient anterior = actual;
        liga();
        if (anterior instanceof AutoCloseable c) {
            try { c.close(); } catch (Exception e) { log.warn("cierre de cliente anterior", e); }
        }
    }
}

@Service
@RequiredArgsConstructor
public class ProcesadorMensajes {

    private final ContadoresReceptor cont;
    private final RespuestaConsulta respuesta;
    private final DispersionClientRefresher dispersion;
    private final ReceptorEstado estado;    // TESTING
    private final P012Properties props;     // p012.nodos-origen: [15, 16, 21, 22]

    public void procesa(MensajeTandem m) {
        switch (m.tipo()) {
            case "11", "12" -> respuesta.informa(m);                       // CONSULTA
            case "02", "32" -> {
                if (m.longitud() < 42 || !props.nodosOrigen().contains(m.nodoOrigen())) {
                    cont.invalidos.increment();                            // ERRORES := * + 1
                    return;
                }
                if (m.tipo().equals("02")) procesaTipo02(m); else procesaTipo32(m);
            }
            default -> cont.invalidos.increment();
        }
    }
}
    /** Tipo 02: más de 123 posiciones; resultado de 1 dígito y secuencia de 8. */
    private void procesaTipo02(MensajeTandem m) {
        if (m.longitud() <= 123) { cont.invalidos.increment(); return; }
        String bloque = Ebcdic.texto(m.crudo(), MensajeTandem.OFS_RESULTADO, 7);
        String secTxt = Ebcdic.texto(m.crudo(), MensajeTandem.OFS_SECUENCIA, 8);
        int resultado = Character.digit(bloque.charAt(0), 10);
        if (!bloque.chars().allMatch(Character::isDigit) || resultado < 1 || resultado > 3
                || !secTxt.chars().allMatch(Character::isDigit)) {     // la secuencia se valida aquí
            cont.invalidos.increment();
            return;
        }
        int seq = Integer.parseInt(secTxt);
        switch (resultado) {
            case 1 -> { cont.confirmados.increment(); cont.ultConfirmado.set(seq); }
            case 2 -> { cont.noEnviados.increment();  cont.ultNoEnvio.set(seq); }
            case 3 -> { cont.duplicados.increment();  cont.ultDuplicado.set(seq); }   // el 4 no llega
        }
        if (estado.testing()) log.info("020801 01 RECIBI 02: RSLT={}, SEQ={}", resultado, seq);
        dispersion.actual().enviaCd(resultado, seq);                   // ENVIA_CD IN S151L012
    }
    /** Tipo 32: más de 77 posiciones; secuencia de 6 dígitos en la posición 71; resultado fijo 2. */
    private void procesaTipo32(MensajeTandem m) {
        if (m.longitud() <= 77) { cont.invalidos.increment(); return; }
        String secTxt = Ebcdic.texto(m.crudo(), MensajeTandem.OFS_SECUENCIA_32, 6);
        if (!secTxt.chars().allMatch(Character::isDigit)) { cont.invalidos.increment(); return; }
        int seq = Integer.parseInt(secTxt);
        cont.tipo32.increment();
        cont.ult32.set(seq);
        if (estado.testing()) log.info("020801 01 RECIBI 32: RSLT=2, SEQ={}", seq);
        dispersion.actual().enviaCd(2, seq);           // se informa a la dispersión como resultado 2
    }

Riesgos de migración
Secuencia sin validar

En los mensajes tipo 02 se valida que las siete posiciones desde TXT_RESULT (E_MSG[83]) sean dígitos, pero la secuencia se lee de TXT_SEQ (E_MSG[92]) con INTEGER(TXT_SEQ,8) sin validar (líneas 180-185). Una secuencia con caracteres no numéricos llega a ENVIA_CD con un valor imprevisible.

Caso de resultado inalcanzable

La validación rechaza resultados fuera de 1 a 3 (línea 181), pero el CASE trata 3 y 4 como duplicado (línea 190). El valor 4 nunca llega; si TANDEM lo usa, hoy se cuenta como inválido.

Reintento indefinido de liga con intervención del operador

REFRESCA repite LINKLIBRARY(S151L012) mientras falle (líneas 89-90) y ERROR_LIGA suspende el programa con STATUS 3 esperando OK del operador. Si CTLVER o DAME_TIT fallan, no se asigna el título y no hay aviso; la siguiente llamada a ENVIA_CD intentaría la liga con el título previo.

Mensaje completo en la bitácora de la tarea

Ante el resultado 93 de RECEIVE el programa escribe el mensaje completo en TASKFILE (línea 230). El contenido de mensajes CitiDirect puede incluir datos de clientes; además el texto de aviso al operador nombra a una persona (línea 229).

Nodos y códigos compilados

Los nodos de origen válidos 15, 16, 21 y 22, los tipos de mensaje y los umbrales de TASKVALUE 2300 y 2400 están en el código (líneas 171-174 y 234-240).

  • Confirmar qué hace ENVIA_CD y CONFIG_DISPERSION en S151L012; el fuente de esa librería no se revisó para este componente.
  • Confirmar el significado de MYSELF.STATUS := 3 en ERROR_LIGA (línea 73) y si el operador responde con OK para reintentar.
  • Verificar los desplazamientos del encabezado COMS (HDR_NODODEST en E_MSG[02], HDR_TIPO en E_MSG[23], TXT_RESULT en E_MSG[83], TXT_SEQ en E_MSG[92]) contra la especificación de la interfaz TANDEM.
  • El inventario no asigna reglas del brain a P012; los segmentos quedan sin regla.
