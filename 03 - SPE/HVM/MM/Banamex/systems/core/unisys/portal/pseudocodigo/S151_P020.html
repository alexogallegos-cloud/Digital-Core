P020 · Receptor de Mensajes L002 COMS (S151)

S151ProgramaCOBOL

Fuente: COBOL_P020.cbl (2139 LOC) · Modo ONLINE (tarea COMS LINEA) · BC-06

Convenciones: nombres traducidos (Unisys→legible); [P020 Lnnnn] = línea fuente; (BR: RN-S151-NNNN) = regla de negocio.

1. Resumen funcional

P020 (PROGRAM-ID S151-P020, autor Christian Dueñas, feb-2018) es la tarea COMS que opera como receptor online de mensajes del protocolo L002 dentro del modo LINEA del sistema GL Banamex S151. Su función es escuchar mensajes entrantes via COMS (infraestructura MCP de comunicación inter-procesos), filtrar únicamente los dirigidos al sub-código 264 (sistema S264 — compensación interbancaria), convertir el payload del formato nativo SA0/SA2 de 739 bytes al formato comprimido WKS-MOV-DATOS (6DIG-COMP), e invocar CARGAMOV1 de la librería S151REGISTRA para registrar el movimiento en la base GL. Devuelve el resultado (código de retorno + datos actualizados) al sistema origen en un mensaje de respuesta COMS. También mantiene archivos de display (L01-DISPLAY) y monitor (L02-MONITOR) para auditoría operacional, y responde a interrupciones HI2 del sistema operativo para encender/apagar el monitor o terminar de forma controlada.

2.3 Layouts de registro clave

WKS-REG-MSG — Buffer principal de mensaje L002 · 864 bytes · WITH LOWER-BOUNDS [P020 L56] (BR: RN-S151-1090)

WKS-REG-MSG (864 bytes):
  WKS-HDR-MSG (36 bytes):
    WKS-HDR-PREFIJO    X(1)    — prefijo de mensaje
    WKS-HDR-APLDEST    X(1)    — aplicación destino
    WKS-HDR-CCRDEST    9(2)    — CCR destino (hardcode: 23=MTY, 24=VDM)
    WKS-HDR-LSNORGN    9(4)    — LSN origen (DISPLAY)
      REDEFINES → COMP 9(8)    — LSN origen en binario  (BR: RN-S151-1099)
    WKS-HDR-STATION    X(8)    — estación física
      REDEFINES (TIPO(1)+SUC(4)+PRIV(1)+CAJA(2))        (BR: RN-S151-1094)
    WKS-HDR-CCRORGN    9(2)    — CCR origen
    WKS-HDR-COPORGN    9(2)    — COP origen
    WKS-HDR-FACULTAD   X(2)    — facultad operador
    WKS-HDR-APLORIG    X(1)    — aplicación origen
    WKS-HDR-RSLTDO     9(2)    — resultado/clasificación SA2   (BR: RN-S151-1092)
      88 W88-HDR-VINO-TERM  VALUE 11, 12
      88 W88-HDR-VINO-APLI  VALUE 02, 04
      88 W88-MSGRES-REDFOR  VALUE 12
      88 W88-MSGRES-MAS     VALUE 3
      88 W88-MSGRES-TER     VALUE 1
      88 W88-MSGRES-ERR     VALUE 31, 32, 33
    WKS-HDR-MASCARA    X(5)    — máscara de pantalla  ⚠ [SEGURIDAD]
    WKS-HDR-PASSWORD   X(6)    — password en claro    ⚠ [SEGURIDAD — PASSWORD expuesto en buffer]
  WKS-MSG-TEXTO (828 bytes):
    WKS-ACA (12 bytes):
      WKS-ACA-DESTINO  9(6)    — dirección ACA destino
      WKS-ACA-ORIGEN   9(6)    — dirección ACA origen
    WKS-SA0 (25 bytes):
      WKS-SA0-TRN-DEST  9(9):   SA0-TRN-DSIS(4)+SA0-TRN-DCOD(2)+SA0-TRN-DSCOD(3)
        88 W88-SA0-TRN-DSIS-S151 VALUE 0151  — filtro: solo mensajes a S151
      WKS-SA0-TRN-ORIG  9(9):   SA0-TRN-OSIS(4)+SA0-TRN-OCOD(2)+SA0-TRN-OSCOD(3)
      WKS-SA0-DIRECCION 9(1):
        88 W88-SA0-ALTA    VALUE 1  — crear sesión/registro
        88 W88-SA0-RESP    VALUE 2  — respuesta              (BR: RN-S151-1093)
        88 W88-SA0-BAJA    VALUE 3  — eliminar/cerrar
        88 W88-SA0-RES-BAJA VALUE 4 — respuesta a baja
      WKS-SA0-LONG      9(4)    — longitud del mensaje (respuesta: 737)
      WKS-SA0-TIEMPO-ESPERA 9(5) — timeout
      WKS-SA0-RESPUESTA 9(2)    — código de respuesta
    WKS-SA2 (35 bytes):
      ID-FMT, VERSION, CLASE, RESULTADO, MODO
      IDENTIFICACION: SUCURSAL(4)+IDEN-CAJA(3)+TRN-NUM(8)+FEC-HR(12)
      MODALIDAD(2), IEFE-NOPE(10): INDEFECTIVO(1)+FILLER(1)+OPERADOR(8)
      VER-OPC(1)
    WKS-AREA-USUARIO (739 bytes) — área de datos del usuario
      → redefine como WKS-DATOS-S151 para acceso a campos de movimiento

WKS-DATOS-S151 — Payload de movimiento S151 / 739 bytes [P020 L141] Contiene: FUNCION(2)+SISTEMA(4)+PRODUCTO(4)+INSTRUMENTO(2)+SUCPROM(4)+CONTRATO(16)+5×CVEIMP(CVETRAN4+IND-LEYE2+ESQ-CONT4+IMPORTE16V2)+FECMOV+HORAMOV+FECCONT+FECVAL+AUT(8)+AUT-3ERNIV(8)+REFEREN(20)+CVEMDA(2)+MDA-SUC(4)+MDA-CTA(16)+CVEMDE(2)+sucursales+cajas+nóminas+banderas+leyendas(5×40) (BR: RN-S151-1095, RN-S151-1096, RN-S151-1097)

MSG-SAL — Mensaje de salida · PIC X(739) [P020 L246] Redefine como WKS-AREA-MSG-OBL-RES-L002: RESULT-L002(2)+MENSAJE(737).

WS-ERRORES — Tabla de mensajes de error [P020 L251] 9 mensajes de 31 chars: ER01–ER09 (sistema no habilitado, función inválida, transacción no catalogada, fecha contable inválida, falta suc. promotora, falta suc. operadora, importe=0, falta ref-eliminar, movimiento no existe). ⚠ [NO-DETERMINADO] no se observa referencia directa en PROCEDURE DIVISION; posiblemente usados internamente por CARGAMOV1.

TASKFILE — Título dinámico [P020 L394] "FILE TASKFILE (USERBACKUPNAME=TRUE,TITLE=S151/TASKFILE/P020/{NODO}{00}/R000/{FECHA}/{MXNB}/001TASKFILE );" ⚠ [HARDCODE-SOSPECHOSO] WKS-TSK-SUBN hardcodeado en 00.

3. Mapa de control

INTERRUPT-BY-HI2 (DECLARATIVES):
  000A-BEGIN-INTERRUPT
    SI HI=4 o HI=6 → HI-SALIDA → 999999-FIN
    SI HI=3        → apaga-monitor → 060700-DISPLAY + 060900-APAGA-MONITOR
    SI HI=2        → enciende-monitor → 060700-DISPLAY + 060800-ENCIENDE-MONITOR

000000-PROCESO-GLOBAL (main):
  INICIO (una vez)
    101000-TASKFILE
    102000-COMS
    103000-VALIDA-CSI
    104000-LIBRERIAS
    105000-OPN-TSKFILE
    106000-DISPLAY
    107000-CHECA-VERS
    ATTACH INTERRUPT-BY-HI2
  PROCESO (UNTIL W77-FIN=1)
    200600-COMS-RECEIVE
      SI TIMEOUT → 202000-VALIDA-FEC-ACTUAL
                     SI cambio de fecha → 020700-CLOSE-DISPLAY + 060900-APAGA-MONITOR
      SI MSG+S151+RECIBI=1 → 201000-PROCESA-MSG
        201010-EXTRAE-L002  (resuelve LIB-REGISTRA)
          SI W77-ERROR=1  → log error → fin de procesa-msg
          SINO SI TRN-DSCOD=264
            → 700000-S264-A-6DIG-COMP  (conversión de formato)
            → CARGAMOV1 IN LIB-REGISTRA
            → CANCEL LIB-REGISTRA
          SINO  (código de sistema inválido)
            → log "SIST. INVALIDO" + W77-151-RESULT=99
        201040-ARMA-MSG-SAL
          → 201050-ENVIA-COMS
    060950-ESCRIBE-MONITOR
  FIN (normal)
    300000-FIN → STOP RUN

Terminación anormal:
  900000-FIN-MAL → log error COMS → 999999-FIN
  999999-FIN     → SMCOMS "DISABLE [NOW] PROGRAM" → (task se desregistra de COMS)

4.1 DECLARATIVAS

PROCEDIMIENTO Interrupt_HI2():            // 000A-BEGIN-INTERRUPT · [P020 L1515]
DESHABILITAR interrupciones
MOVER "I" → tipo_mensaje_log  // TIPO-LJ
MOVER 050104 → codigo_log     // CODIGO-LJ
MOVER TASKVALUE(MYSELF) → nivel_HI  // W77-HI: 2=enciende-monitor, 3=apaga-monitor, 4/6=terminar
MOVER SPACES → texto_display  // WKS-DIS-TEXTO

    MOVER SPACES → texto_log

SINO SI nivel_HI = 3  // W88-HI-3
    MOVER "  SE APAGA MONITOR " → texto_log, texto_display
    LLAMAR LJ(log_jobs)  ⚠ [HARDCODE-SOSPECHOSO] prefijo "S151/P020>:" implícito

    EJECUTAR Apaga_Monitor       // 060900-APAGA-MONITOR
SINO SI nivel_HI = 2  // W88-HI-2
    MOVER "  SE ENCIENDE MONITOR " → texto_log, texto_display
    LLAMAR LJ(log_jobs)
    EJECUTAR Escribe_Display     // 060700-DISPLAY
    EJECUTAR Enciende_Monitor    // 060800-ENCIENDE-MONITOR
