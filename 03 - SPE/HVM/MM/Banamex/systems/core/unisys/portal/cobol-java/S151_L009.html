Un proceso de control espera cada 15 segundos (o un HI de operador) y, dentro de la ventana horaria tomada de B05, lee los movimientos nuevos del archivo MOVS_CBII en bloques de hasta NUM_REGISTROS. Por cada ocurrencia de importe con clave marcada para Citi arma el mensaje 942 convirtiendo la cuenta Banamex al formato interno Citi, le antepone un header de infraestructura y lo envía con A_OTRO_CSINEW. Cada envío exitoso se registra en el archivo de control ENVIOS con estatus 1; ENVIA_L009 recibe el resultado de Tandem y lo marca como aceptado o duplicado (3) o rechazado (2). Cada 20 ciclos, o cuando hay rechazos, recorre ENVIOS y reenvía lo que sigue en estatus 1 o 2.

/** A_OTRO_CSINEW IN TCPCARRIER: puerto de salida hacia el CSI destino. */
public interface TcpCarrierGateway {
    /** Devuelve el resultado del carrier: 0 ok; 10 y 33 obligan a desligar y reintentar. */
    int enviaAOtroCsi(byte[] mensajeEbcdic);
}

@Component
@RequiredArgsConstructor
class TcpCarrierAdapter implements TcpCarrierGateway {
    private final MessageChannel salidaTandem;      // Spring Integration TCP outbound adapter

    @Override
    public int enviaAOtroCsi(byte[] msg) {
        try {
            return salidaTandem.send(MessageBuilder.withPayload(msg).build(), 60_000) ? 0 : 33;
        } catch (MessagingException e) {
            return 10;
        }
    }
}
@Service
@RequiredArgsConstructor
public class L009Service {

    private final EstadoEnvio estado;
    private final CambioDiaCoordinator cambioDia;

    /** FUNCIONES(DATOS): los dos primeros dígitos de DATOS son la función. */
    public FuncionResultado funciones(int funcion) {
        return switch (funcion) {
            case 1  -> FuncionResultado.ok();                         // sin efecto
            case 4  -> { estado.solicitaBajaSiSinUsuarios(); yield FuncionResultado.ok(); }
            case 5  -> FuncionResultado.totales(estado.fechaProceso(),
                                                estado.totEnviados(), estado.totIbm());
            case 25 -> { cambioDia.ejecuta(Duration.ofSeconds(60)); yield FuncionResultado.ok(); }
            case 50 -> { estado.liberaSbcSiPendiente(); yield FuncionResultado.ok(); }
            case 98 -> { estado.cierraArchivos(); yield FuncionResultado.ok(); }
            default -> FuncionResultado.ok();                         // ELSE : ;
        };
    }
}

@Component
class CambioDiaCoordinator {
    /** Función 25: espera hasta 60 s a que el ciclo de envío suelte el archivo. */
    void ejecuta(Duration espera) {
        if (!envioEnCurso.tryLock(espera.toSeconds(), TimeUnit.SECONDS)) {
            alertas.critica("L009> S500 NO SE REALIZO CAMBIO DE DIA");   // ACCEPT: pide respuesta al operador
            return;
        }
        try { estado.reiniciaDia(); } finally { envioEnCurso.unlock(); }
    }
}
@Component
@RequiredArgsConstructor
class EnvioCb2Scheduler {

    private final EnvioCb2Properties props;   // espera 15 s, ventana de B05 (por omisión 0600-2300)
    private final EnvioMovimientos envio;     // BUSCA_MOVTOS
    private final ControlEnvios control;      // archivo ENVIOS -> tabla cb2_control_envio
    private final EstadoEnvio estado;
    private int ciclos;

    /** WAITANDRESET((TIEMPO_ESPERA), EXCEPTIONEVENT, LIBERA_SBC): rama del tiempo vencido. */
    @Scheduled(fixedDelayString = "${l009.espera:PT15S}")
    void ciclo() {
        if (!estado.hi11()) estado.ligaTcp();
        LocalTime ahora = LocalTime.now(props.zona());
        if (ahora.isAfter(props.ventana().inicio()) && ahora.isBefore(props.ventana().fin())) {
            estado.abreEnvio();               // en el fuente nunca se vuelve a cerrar hasta INICIA
        }
        if (!estado.envioAbierto()) return;

        envio.enviaPendientes();
        if (estado.tcpDesligado()) return;

        if (++ciclos == 20) estado.marcaRechazos();
        if (estado.hayRechazos()) {
            esperaFija(Duration.ofSeconds(20));                    // WAIT((20))
            ciclos = 0;
            estado.limpiaRechazos();
            control.pendientesDeConfirmar()                        // estatus 1 o 2
                   .takeWhile(r -> !estado.cambioDiaSolicitado())
                   .forEach(envio::reenvia);
        }
    }
}

/** ENVIA_MOVIMIENTOS: hasta 5 ocurrencias de importe por movimiento, se detiene en la clave 0. */
List<Mensaje942> mensajes(MovimientoCb2 mov, boolean reenvio, int desdeOcurrencia) {
    if (mov.tipoProceso() >= 20 || mov.funcion() != 1) return List.of();
    List<Mensaje942> salida = new ArrayList<>();
    for (int i = reenvio ? desdeOcurrencia : 1; i <= 5 && mov.clave(i) > 0; i++) {
        ClaveBnx clave = claves.de(mov.clave(i));
        if (clave.indCiti() != 1 && clave.indCiti() != 2) continue;
        if (!claves.valida(clave)) continue;                         // VALIDA_CVE
        boolean cargo = clave.afectacionContable() == 1
                || props.clavesCargoForzado().contains(clave.numero());
        Importe imp = props.esImporteEditado(clave.numero())
                ? Importe.soloLeyenda(mov.importe(i))                // va en :86:, el :61: lleva cero
                : Importe.de(mov.entero(i), mov.decimal(i));
        builder.detalle(mov, clave, cargo, imp, i).ifPresent(salida::add);
        if (reenvio) break;                                          // INDICE := 6
    }

Riesgos de migración
Ventana horaria que no se cierra

ABRE_ENVIO se enciende dentro de la ventana HORA_INICIO a HORA_FIN (línea 3061) y solo se apaga en INICIA (línea 1371), es decir en el cambio de día. Pasada la hora fin, la librería sigue enviando.

Reenvíos de mensajes en espera de confirmación

El barrido cada 20 ciclos reenvía registros en estatus 1, que incluye mensajes enviados cuya respuesta aún no llega. La integridad depende de que Tandem detecte duplicados (resultado 3).

Mensajes que no quedan en el control

Un resultado de TCP Carrier distinto de 0, 10 y 33 no registra el mensaje en ENVIOS ni lo desliga (líneas 2572-2615); ese movimiento no entra a ningún reenvío.

Cuenta truncada o en ceros

El tag 25 emite el formato interno de 11 dígitos con FOR 10 DIGITS, y si S016 L422 falla la cuenta viaja en ceros sin marcarse como error.

Hardcodes de enrutamiento

Códigos de aplicación 13704 y 15107, sistema host 0137, prefijo 484, ventana por omisión 0600-2300, exclusión de caja 86 en sucursales 870 y 519, claves 2005-2007, 2229 y 731-746, y CSI destino 15, 21 o 22 por HI. Se trasladan a application.yml.
