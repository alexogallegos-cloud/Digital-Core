Lee el log diario de movimientos LOG151 y selecciona los que pertenecen a 45 cuentas y contratos compilados en el programa, clasificando su naturaleza con el catálogo de transacciones S080 de los sistemas 500 y 408. En la misma pasada envía al archivo A03-MOV-GCE los movimientos en moneda 5 de doce claves de transacción. Ordena lo seleccionado, toma de SALDOS151 el saldo de cierre (concepto 0002) y de la librería S500L020 el saldo de inicio del día, y escribe por cuenta un encabezado con saldos y los detalles en archivos E01 de 197 bytes. En el CSI 10 concatena los parciales en E02-INTELLI-UNI y los transmite a IntelliMatch mediante ADMONXFERS.

public sealed interface IntelliMatchRecord permits IntelliMatchRecord.Encabezado, IntelliMatchRecord.Detalle {

    String toFixed();   // registro posicional tal como lo espera IntelliMatch

    /** A00-R00-HDR-INTE: saldo de apertura y cierre por cuenta. */
    record Encabezado(String numCta,                  // X(34)
                      LocalDate fecApertura, LocalDate fecCierre,   // 9(06) AAMMDD
                      char natApertura, BigDecimal sdoApertura,     // 9(14)V99 sin signo
                      char natCierre, BigDecimal sdoCierre) implements IntelliMatchRecord {
        public String toFixed() {
            return "HS" + Fixed.x(numCta, 34) + "S" + "0".repeat(9)
                 + Fixed.aammdd(fecApertura) + Fixed.aammdd(fecCierre)
                 + natApertura + Fixed.importe(sdoApertura, 14, 2) + "F"
                 + natCierre  + Fixed.importe(sdoCierre, 14, 2)  + "F"
                 + " ".repeat(103);
        }
    }

    /** A00-R01-INTE-REGMOV: un movimiento. */
    record Detalle(String numCta, LocalDate fecConta, LocalDate fecValor, String tipo,
                   char naturaleza, BigDecimal importe, String referen, String surefer,
                   String otraref, String detalle, int sistema, int clave) implements IntelliMatchRecord {
        public String toFixed() {
            return "D" + Fixed.x(numCta, 35) + Fixed.aammdd(fecConta) + Fixed.aammdd(fecValor)
                 + Fixed.x(tipo, 2) + naturaleza + Fixed.importe(importe, 14, 2)
                 + Fixed.x(referen, 16) + Fixed.x(surefer, 16) + Fixed.x(otraref, 16)
                 + Fixed.x(detalle, 40) + " ".repeat(34) + Fixed.n(sistema, 4) + Fixed.n(clave, 4);
        }
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class SeleccionMovimientos500 implements ItemProcessor<MovimientoLog, List<MovimientoTrabajo>> {

    private static final Set<Integer> ORIGENES = Set.of(1, 3);
    private final P172Properties props;        // p172.tipos-proceso-excluidos: [40, 41, 42, 43] (Teletón)
    private final GeneradorGce gce;
    private final SelectorCuentas selector;

    /** 03-301-10-ELIGE-MOVS-500. La función 99 marca el fin lógico del LOG151. */
    @Override
    public List<MovimientoTrabajo> process(MovimientoLog m) {
        if (m.funcion() == 99) {
            throw new FinDeLogException();          // el reader corta aquí (W77-FIN = 1)
        }
        if (!ORIGENES.contains(m.origen())
                || props.tiposProcesoExcluidos().contains(m.tipoProceso())) {
            return null;
        }
        m.claves().stream()                         // hasta 5 claves; la primera en 0 corta
                .takeWhile(c -> c.cveTran() != 0)
                .forEach(c -> gce.evalua(m, c));   // 03-302-10-VALIDA-CLAVE
        return selector.revisa(m, 500);             // 03-303-11-REVISA-MOVTO con W77-IND = 1
    }
}
/** 03-301-22-GRABA-REGISTRO: naturaleza del movimiento hacia IntelliMatch. */
static char naturalezaIntelliMatch(int sistemaLog, ParametroTransaccion p) {
    if (sistemaLog != 500) {
        return 'D';                                // cualquier otro sistema: cargo
    }
    if (p.natAlfa() == 1) return 'D';
    if (p.natAlfa() == 2) return 'C';
    return (p.natS028() == 1) ? 'D' : 'C';         // ALFA sin definir: decide S028
}

static MovimientoTrabajo aTrabajo(MovimientoLog m, ClaveImporte c, ParametroTransaccion p) {
    // A00-R01-IMPORTE es 9(16)V99 y A02-MOV-IMPORTE 9(14)V99: el MOVE pierde los dos dígitos altos.
    BigDecimal importe = Fixed.cabeEn(c.importe(), 14, 2);   // falla en vez de truncar
    return new MovimientoTrabajo(m.sucursal(), m.cuenta(), m.fecMov(), m.horMov(),
            m.fecCont(), m.fecVal(), naturalezaIntelliMatch(m.sistema(), p), importe,
            m.autoriza(), m.referencia());
}
@Component

    private final CatalogoTransacciones catalogo;
    private final ItemWriter<IntelliMatchRecord.Detalle> movGceWriter;   // A03-MOV-GCE

    /** 03-302-10-VALIDA-CLAVE. */
    public void evalua(MovimientoLog m, ClaveImporte c) {
        ParametroTransaccion p = catalogo.de500(c.cveTran());
        boolean esGce = p.gce() == 3
                && m.moneda() == props.gce().moneda()                  // 5
                && (p.natAlfa() == 1 || p.natAlfa() == 2)
                && (p.natS028() == 1 || p.natS028() == 2)
                && props.gce().claves().contains(c.cveTran());
        if (esGce) {
            movGceWriter.write(Chunk.of(registroGce(m, c, p)));      // 03-301-30-GRABA-REG-GCE

                naturalezaGce(m.sistema(), p), c.importe(), m.cuentaIntelli(),
                m.motivoDevolucion(), "", "", m.sistema(), c.cveTran());
    }

            .filter(c -> c.clave() == SaldoContrato.SALDO_ACTUAL)

            .findFirst();                                   // sin concepto 0002: cero

/** 03-304-10-LEE-MOV: corte de control por archivo y cuenta sobre A02-MOVS151 ordenado. */
@Component
@StepScope
@RequiredArgsConstructor
public class GeneradorIntelliMatchProcessor implements ItemProcessor<MovimientoTrabajo, List<IntelliMatchRecord>> {

    private final Map<String, EstadoCuenta172> estado;   // por cuenta IntelliMatch
    private LlaveCuenta anterior;                          // WKS-LLAVE-ANT
    private BigDecimal saldo = BigDecimal.ZERO.setScale(2); // W77-SALDO S9(14)V99

    @Override
    public List<IntelliMatchRecord> process(MovimientoTrabajo m) {
        if (m.llave().equals(anterior)) {
            anterior = m.llave();
            return List.of(detalle(m));           // misma cuenta: solo detalle
        }
        anterior = m.llave();
        saldo = BigDecimal.ZERO.setScale(2);
        return iniciaCuenta(m);                   // encabezado HS + primer detalle (03-304-18)
    }

    /** 03-304-12-CALCULA-SALDO: cargo resta, abono suma; otro valor no mueve el saldo. */
    private IntelliMatchRecord.Detalle detalle(MovimientoTrabajo m) {
        saldo = switch (m.naturaleza()) {
            case 'D' -> saldo.subtract(m.importe());
            case 'C' -> saldo.add(m.importe());
            default  -> saldo;
        };
        estado.get(m.cuenta()).sdoCalculado = saldo;   // WKS-SDO-CALCULADO
        return Detalles.de(m);                           // 03-304-14-ESCRIBE-REG-DETALLE
    }
}

Riesgos de migración
Reintento infinito contra S500L020

En 03-303-20-TRAE-SDO-INICIO (líneas 2905-2918) los resultados 5 y 17 esperan 30 segundos y reintentan; al octavo intento se avisa al operador y el contador vuelve a cero, por lo que el paso puede quedar girando sin fin si la librería no responde.

Cuenta 45 con detalle incompleto

La condición W77-IND-CTA > 0 AND W77-IND-CTA < 45 (línea 2987) deja fuera los movimientos posteriores al primero de la última cuenta de la tabla.

Truncamiento de importe y contrato

A00-R01-IMPORTE 9(16)V99 se mueve a A02-MOV-IMPORTE 9(14)V99 y A00-R01-CONTRATO 9(16) a W77-INTEL-CONTRATO 9(11). Los dígitos altos se pierden sin aviso; en el caso del contrato, dos contratos distintos podrían coincidir en sus 11 dígitos bajos.

Fallo de envío silencioso

Si INTELARSND devuelve error (líneas 3196-3207), solo se envía un mensaje al operador; el job no falla y IntelliMatch puede quedarse sin archivo.

Hardcodes de negocio

45 cuentas y contratos repetidos en tres listas, doce claves de transacción GCE, moneda 5, cuenta GCE 158224, sistemas 500 y 408, CSI concentrador 10 y tipos de proceso 40 a 43 están compilados. Se trasladan a configuración.

Naturaleza de cierre heredada en encabezados

03-304-20-BUSCA-SALDO-INICIO (líneas 3089-3106) llena el saldo de cierre del encabezado pero no recalcula A00-R00-INTE-NAT-CIERRE; el campo conserva el valor que dejó el último contrato procesado en 03-303-14-BUSCA-SDOFIN o en 03-304-25-SIN-MOVTOS. Una cuenta con movimientos puede salir con la naturaleza de cierre de otra. Requiere validación del SME.

Saldo inicial no reiniciado ante error

Con resultado 21 o mayor de S500L020 se pone en cero W77-SALDO pero no WKS-SDO-INI-DIA (líneas 2945-2952), así que la cuenta conserva el saldo de inicio que tuviera la tabla.
