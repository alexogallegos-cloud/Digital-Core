S151 · P151 a Java 21 Spring Boot

Recibe por parámetro el sistema (500 o 701) y obtiene del host el centro de cómputo. Para el sistema 500 en CSI 10 carga los catálogos paramétricos por clave de transacción, selecciona y ordena los movimientos, obtiene el saldo de inicio de día de cada contrato con la librería S500L020 y genera los archivos ALR, AHR y OCM, además del archivo de saldos ACC y los listados de control diario. Cada movimiento se reparte entre CitiDirect y la ruta BNE según un indicador de dos dígitos. Los archivos no se transmiten desde P151: el programa arma el comando de la WFL P940 y la lanza.

/**

@Component
@RequiredArgsConstructor
public class RutaP151Decider implements JobExecutionDecider {

    private final P151Properties props;   // numCsi (WKS-NUMCSI) se obtiene del host

    /** 000000-INICIO-PROGRAMA: decide la ruta por (W77-SISTEMA-PARAMETRO, WKS-NUMCSI). */
    @Override
    public FlowExecutionStatus decide(JobExecution job, StepExecution last) {
        int sistema = job.getJobParameters().getLong("sistema").intValue();
        int csi = props.numCsi();
        return switch (sistema) {
            case 500 -> switch (csi) {
                case 10 -> new FlowExecutionStatus("CITI_COMPLETO");     // catálogos, saldos, ALR/AHR/OCM, ACC, P171
                case 4  -> new FlowExecutionStatus("ENVIO_REGIONAL");    // copias L030 de OCM, AHR y ALR
                default -> new FlowExecutionStatus("SIN_ARCHIVOS");
            };
            case 701 -> csi == 10 ? new FlowExecutionStatus("OCM_701")   // 50000 / 60000 / 70000
                                  : new FlowExecutionStatus("SIN_ARCHIVOS");
            default  -> new FlowExecutionStatus("SIN_ARCHIVOS");         // el COBOL termina con STOP RUN sin aviso
        };
    }
}

// Sistema de movimientos: con parámetro 500 los movimientos y descripciones se leen del 408.
static int sistemaMovimientos(int sistemaParametro) {
    return sistemaParametro == 500 ? 408 : sistemaParametro;    // WS-MOV-SISTEMA / WS-DES-SISTEMA
}

@Bean
Job p151(JobRepository repo, Step inicio, RutaP151Decider ruta,
         Flow citiCompleto, Flow envioRegional, Flow ocm701, Step sinArchivos) {
    return new JobBuilder("S151P151", repo)
            .start(inicio)                                      // 10000-INICIO-PROGRAMA
            .next(ruta)
                .on("CITI_COMPLETO").to(citiCompleto)
            .from(ruta).on("ENVIO_REGIONAL").to(envioRegional)
            .from(ruta).on("OCM_701").to(ocm701)
            .from(ruta).on("SIN_ARCHIVOS").to(sinArchivos)      // registra WARN: hoy es silencioso
            .end().build();
}

@Component
@RequiredArgsConstructor
public class TransferenciaCitiTasklet implements Tasklet {

    private final CitiDirectGateway citi;      // Spring Integration SFTP hacia /CO/ de CitiDirect
    private final P151Properties props;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        var p = ctx.getStepContext().getJobParameters();
        // WKS-TIT-WFL: START <prog> ("S" sistema archivo "C", fecha, csi)
        String archivo = "S%03d%sC".formatted((Long) p.get("sistema"), "ALR");
        ResultadoEnvio r = citi.enviar(archivo, (String) p.get("fechaProceso"), props.numCsi());
        if (!r.exitoso()) {
            // CALL SYSTEM WFL no espera ni revisa el resultado de P940; aquí sí se falla el step.
            throw new TransferenciaCitiException(archivo, r.detalle());
        }
        return RepeatStatus.FINISHED;
    }
}
@Service
@RequiredArgsConstructor
public class SaldoInicioDiaService {

    private static final int MAX_INTENTOS = 8;                       // W77-REINTENTO = 8
    private static final Duration ESPERA = Duration.ofSeconds(30);   // WAIT(30)
    private static final Set<Integer> NO_DISPONIBLE = Set.of(5, 17);

    private final SaldosClient s500;            // reemplaza S500L020SDOINIDIA IN S500L020SDOS
    private final SaldoCacheRepository cache;   // ARCH-SAL (VML), JPA
    private final LlamadaSaldoRepository bitacora;  // ARCHIVO-ERROR: el COBOL escribe un renglón por llamada

    /** 35200-CALL-S500. Saldo real = inicio de día del 500 menos inicio de día del 408. */
    @Transactional
    public BigDecimal saldoReal(String contrato, LocalDate fechaProceso) {
        for (int intento = 1; ; intento++) {
            RespuestaSaldo r = s500.saldoInicioDia(contrato, fechaProceso);
            bitacora.save(LlamadaSaldo.de(fechaProceso, contrato, r));   // WRITE REG-ARCH-ERROR, incluso con éxito
            switch (r.resultado()) {
                case 0 -> {
                    BigDecimal saldo = r.saldo500().subtract(r.saldo408());   // COMPUTE, resta exacta
                    cache.save(new SaldoCache(contrato, fechaProceso, r.saldo500(), r.saldo408(), saldo));
                    return saldo;
                }
                case 5, 17 -> {
                    if (intento < MAX_INTENTOS) { pausa(ESPERA); continue; }
                    // COBOL: registra el error, regresa el contador a 0 y el PERFORM UNTIL sigue sin límite.
                    throw new LibreriaSaldosNoDisponibleException(contrato, r.resultado());
                }
                case 12 -> // COBOL: registra el error sin encender W77-BAN-S500 y vuelve a llamar sin espera.
                    throw new LibreriaSaldosException(contrato, r.resultado());
                default -> {
                    log.info("S500L020 devolvió {} para {}: se continúa con saldo 0", r.resultado(), contrato);
                    return BigDecimal.ZERO.setScale(2);                // MOVE ZEROS TO W77-SALDO
                }
            }
        }
    }
}

/** 41210-VALIDA-NATURALEZA-ALR: afectación del catálogo, luego naturaleza contable, luego excepción 731-746. */
static char drCr(int cveTran, CatalogoTransacciones cat) {
    if (cveTran > 730 && cveTran < 747) return 'C';           // se evalúa al final y siempre gana
    return switch (cat.afectacion(cveTran)) {                 // WKS-PT-AFECTACION: 1 cargo, 2 abono
        case 1 -> 'D';
        case 2 -> 'C';
        default -> switch (cat.naturalezaContable(cveTran)) { // WKS-PT-NATCONT
            case 1 -> 'D';
            case 2 -> 'C';
            default -> ' ';    // ninguna rama asigna: el campo conserva lo que traía el buffer
        };
    };
}

Riesgos de migración
Signo del importe que nunca es negativo

RMC-IMPORTE es PIC 9(14)V99 COMP sin signo (línea 483). Las validaciones de signo de ALR, AHR y OCM (líneas 14436, 14779 y 14956) comparan contra cero y siempre producen '+'. Solo el saldo RMC-SALDO, que sí es S9(15)V99, puede llegar con '-' al AHR.

Ciclo sin fin si S500L020 no contesta

En 35200-CALL-S500, al llegar a ocho intentos con resultado 5 o 17 el programa reinicia el contador sin encender W77-BAN-S500, y el resultado 12 tampoco lo enciende. El PERFORM UNTIL W77-BAN-S500 = 1 de la línea 13976 sigue llamando a la librería sin límite (con espera de 30 segundos en el caso 5 o 17 y sin espera en el caso 12), y cada llamada agrega un renglón a ARCHIVO-ERROR.

ARCHIVO-ERROR no distingue errores de éxitos

El WRITE REG-ARCH-ERROR de las líneas 14060-14067 está fuera del IF anidado y se ejecuta en cada llamada a S500L020, incluidas las exitosas y cada reintento. Quien consuma ese archivo debe filtrar por REG-RESULT.

Importe en cero para las claves 731 a 746

Las líneas 14250-14253 mueven el importe a un campo de texto y lo ponen en cero antes de armar ALR, AHR y OCM; además 14773-14774 fuerzan naturaleza de abono. Citi recibe esos movimientos sin monto numérico.

Desbordamiento del consecutivo ALR

W77-CONTADOR-ALR y W77-CONTADOR-OCM son PIC 9(05) (líneas 11783-11784) y se incrementan sin ON SIZE ERROR; por arriba de 99,999 registros en una corrida el consecutivo se repite.

Transferencia sin verificación

CALL SYSTEM WFL lanza la WFL P940 (líneas 12605-12612, 12653-12660 y 12709-12716) sin revisar su resultado; un fallo de FTP hacia CitiDirect no detiene ni marca a P151.

Valores fijos compilados

Sucursal, país y agente 485, tipo de producto "DE ", archivo origen "LQ", la lista de hosts BNE y la ruta (S006)S006/WFL/P940/01MTP001 ON XFER están en el código. Se trasladan a application.yml.
