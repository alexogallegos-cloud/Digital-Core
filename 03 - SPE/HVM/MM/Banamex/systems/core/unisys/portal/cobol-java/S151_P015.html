S151 · P015 a Java 21 Spring Boot

Recibe un parámetro con la fecha de proceso, el día de la semana y el sistema origen. Obtiene de la librería de control el nombre de la base semanal y del LOG, y retoma desde el último nivel aplicado. Lee el LOG por llave relativa y aplica cada registro según su función: 01 alta, 02 baja específica, 21 borrado por proceso, 22 borrado a partir de una autorización y 98 cierre; la 99 indica que no hay más registros y el programa espera 5 segundos antes de volver a leer. Cada aplicación y el avance del nivel forman una sola transacción, y en las altas se acumulan número e importe de cargos y abonos por renglón en los registros de cuadre de sucursal y caja.

/** A00-R01-REGMOV: registro de 450 bytes del LOG151 (campos COMP de Unisys = decimal empacado sin signo). */
public record MovimientoLog(
        int funcion,                     // 9(02) COMP: 01 alta, 02 baja, 21, 22, 98, 99
        int formato,
        int sistema,                     // 9(04) COMP
        List<ClaveImporte> claves,       // A00-R01-ELE-CVEIMP OCCURS 5 TIMES
        int moneda,                      // 9(04) COMP
        int origen,                      // 9(02) COMP
        long autS151,                    // 9(08) COMP: folio de autorización S151
        int tipoProceso,                 // 9(02) COMP: alimenta W77-LINEA / W77-TELETON
        LocalDate fechaContable) {       // 9(08) COMP, formato CCAAMMDD

    /** Una ocurrencia de A00-R01-ELE-CVEIMP. La vista CVEIMP-DE (CVETRAN1..5) es la misma memoria. */
    public record ClaveImporte(int cveTran,          // 9(06) COMP
                               int indLey,           // 9(02) COMP
                               int esqCon,           // 9(04) COMP; REDEFINES A00-R01-TM
                               BigDecimal importe,   // 9(16)V99 COMP -> escala 2
                               int cveDesvio, int guiaDesvio) {
        public boolean vacia() { return cveTran == 0; }   // UNTIL WKS-TAB-CVE(W77-IND1) = 0
    }

    /** Equivale a los cinco MOVE A00-R01-CVETRANn / IMPORTEn a WKS-TAB-CVE/WKS-TAB-IMP. */
    public List<ClaveImporte> clavesActivas() {
        return claves.stream().takeWhile(c -> !c.vacia()).toList();
    }
}

/** WKS-PARAMETRO PIC 9(13) = FECHA(8) + DIA(2) + SISTEMA(3), recibido en PROCEDURE DIVISION USING. */
public record ParametroP015(LocalDate fechaProceso, int entrada, int sistema) {

    public static ParametroP015 parse(String p13) {          // "2026093001500" por ejemplo
        if (p13.length() != 13) throw new IllegalArgumentException("WKS-PARAMETRO debe tener 13 dígitos");
        return new ParametroP015(
                LocalDate.parse(p13.substring(0, 8), DateTimeFormatter.BASIC_ISO_DATE), // CCAAMMDD
                Integer.parseInt(p13.substring(8, 10)),
                Integer.parseInt(p13.substring(10, 13)));
    }
}

@Component
@RequiredArgsConstructor
public class ArranqueAsincronoTasklet implements Tasklet {

    private final LibreriaControlClient control;      // CONSISDIA IN S151LIBCONTROL
    private final GlobalesSemanaRepository globales;  // dataset de globales B00 de MOVDB

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        var p = ctx.getStepContext().getJobParameters();
        ParametroP015 param = ParametroP015.parse((String) p.get("parametro"));

        // CONSISDIA función 01: nombre de la base semanal y del LOG del sistema.
        BaseDiaria base = control.consultaSistemaDia(param.sistema())
                .orElseThrow(() -> new ProcesoAbortadoException(
                        "ERROR AL CONSULTAR S151LIBCONTROL PARA OBTENER NOMBRE DE LA BASE DIARIA"));

        // 000100-CHECA-FECHA: entradas 1..5 y 6..10 apuntan al mismo día (1/6 lunes ... 5/10 viernes).
        DayOfWeek dia = DayOfWeek.of(((param.entrada() - 1) % 5) + 1);

        // B00-GLOB-NIV-BASE(día) = último registro del LOG ya aplicado; 0 si la base está vacía.
        long nivel = globales.nivelBase(base.nombre(), dia).orElse(0L);

        var ec = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        ec.put("base", base);
        ec.put("dia", dia);
        ec.put("nivelInicial", nivel);
        return RepeatStatus.FINISHED;
    }
}
@Component
@StepScope
@RequiredArgsConstructor
public class AplicaMovimientoProcessor implements ItemProcessor<MovimientoLog, ResultadoAplicacion> {

    private final P015Properties props;
    private final AltaMovimientoService altas;        // 001500-ACT-BASE
    private final BajaMovimientoService bajas;        // 010000 / 020000 / 030000
    @Value("#{jobParameters['sistema']}") private int sistema;

    /** Árbol de IF anidados de 001300-LEE-BLOCK1. El nivel se avanza en el writer, en la misma transacción. */
    @Override
    public ResultadoAplicacion process(MovimientoLog m) {
        MovimientoLog mov = normalizaBancos(m);
        boolean aplica = props.tipoProceso().linea().contiene(mov.tipoProceso())
                || (sistema == 500 && props.tipoProceso().teleton().contiene(mov.tipoProceso()));

        return switch (mov.funcion()) {
            case 1  -> aplica ? altas.alta(mov)                : ResultadoAplicacion.soloNivel(mov);
            case 2  -> aplica ? bajas.bajaEspecifica(mov)      : ResultadoAplicacion.soloNivel(mov);
            case 21 -> aplica ? bajas.borraPorProceso(mov)     : ResultadoAplicacion.soloNivel(mov);
            case 22 -> aplica ? bajas.borraAPartirDeAut(mov)   : ResultadoAplicacion.soloNivel(mov);
            case 98 -> ResultadoAplicacion.cierre(mov);         // W77-FUN-98: fin del día, avanza nivel
            case 99 -> ResultadoAplicacion.finDeLog();          // no hay más registros: no avanza nivel
            default -> ResultadoAplicacion.soloNivel(mov);      // función desconocida: se salta en silencio
        };
    }

    /** Sistema 264 sin bancos informados: se asume Banamex (02) en origen y destino. */
    private MovimientoLog normalizaBancos(MovimientoLog m) {
        return (sistema == 264 && m.bancoOrigen() == 0 && m.bancoDestino() == 0)
                ? m.conBancos(props.bancoDefault(), props.bancoDefault()) : m;
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class NivelBaseWriter implements ItemWriter<ResultadoAplicacion> {

    private final GlobalesSemanaRepository globales;
    private final LibreriaControlClient control;
    private final AtomicLong nivel;                         // W77-NIV-BASE
    private int desdeUltimoReporte;                         // W77-C2-CONT

    /** 001600-ACT-NIV-BASE: misma transacción que la alta o baja; un fallo revierte ambas. */
    @Override
    public void write(Chunk<? extends ResultadoAplicacion> chunk) {
        for (ResultadoAplicacion r : chunk) {
            if (!r.avanzaNivel()) continue;                 // función 99
            globales.incrementaNivel(r.dia());              // LOCK MOVDB, ADD 1, STORE MOVDB
            long n = nivel.incrementAndGet();
            if (++desdeUltimoReporte > 500) {               // cada 500 registros: CONSISDIA función 09
                desdeUltimoReporte = 0;
                control.reportaNivel(r.sistema(), r.fecha(), n);
            }
        }
    }
}
@Component
@RequiredArgsConstructor
public class MonitorInactividadLog {

    private final P015Properties props;
    private final AlertaOperativa alertas;     // VPSTORE IN VPOLLIB (SightLine)
    private final JobLauncherClient lote;      // CALL SYSTEM WFL USING WKS-WFL-NOM-INICIA
    private final Clock reloj;
    private int ciclosSinMovimientos;          // WKS-TIME: ciclos que terminaron en función 99

    public void movimientoAplicado() { ciclosSinMovimientos = 0; }   // MOVE ZEROS TO WKS-TIME

    /** 001700-VALIDAR-FUN99: solo se vigila a los sistemas 500 y 701. */
    public void finDeLogAlcanzado(int sistema) {
        if (sistema != 500 && sistema != 701) return;
        ciclosSinMovimientos++;
        LocalTime ahora = LocalTime.now(reloj);
        var m = props.monitorInactividad();
        boolean disparo = (m.ventanaLinea().contiene(ahora) && ciclosSinMovimientos > m.ventanaLinea().ciclosMax())
                       || (m.ventanaBatch().contiene(ahora) && ciclosSinMovimientos > m.ventanaBatch().ciclosMax());
        if (disparo) {
            ciclosSinMovimientos = 0;
            alertas.publica(8, 99);                         // WKS-SEND-ITEM-NUM 08, VALUE 99
            lote.arranca(props.wflLote(), sistema);         // nombre resuelto por CTRLVERS al inicio
        }
    }
}

    @ElementCollection @OrderColumn(name = "posicion")

    /** 042300-SUMA-IMP-LUNES: 40 sentencias ADD, cada una a B03 y B04 a la vez. */
    public void suma(MatrizCuadre.Seccion s) {
        for (int pos = 0; pos < 10; pos++) {
            Renglon r = renglones.get(pos);
            r.numAbonos   += s.numAbonos(pos);
            r.impAbonos    = r.impAbonos.add(s.impAbonos(pos));     // escala 2, suma exacta
            r.numCargos   += s.numCargos(pos);
            r.impCargos    = r.impCargos.add(s.impCargos(pos));
        }
    }
}

    void sumaAbono(int sec, int pos, BigDecimal imp) {

        secciones[sec - 1].setImpAbonos(pos - 1, v);
    }

Riesgos de migración
Credencial de desarrollo en el fuente

La línea 2044 conserva comentada una cadena ACCESSCODE=**** con usuario y clave del ambiente de desarrollo. Aunque está comentada, viaja en el fuente y en los listados de compilación; debe retirarse y rotarse.

Pérdida silenciosa de movimientos

Los errores de CREATE de movimiento y de registro de cuadre solo se escriben en bitácora; el nivel avanza igual (001600-ACT-NIV-BASE), así que el registro del LOG no se vuelve a intentar y la base semanal queda incompleta sin que el proceso termine con error.

Nivel de reinicio no garantizado

Si el LOCK o el STORE de los globales falla (líneas 3140-3167) el programa sigue; el nivel en memoria avanza pero el de la base no. Tras un reinicio se volverían a aplicar movimientos ya aplicados.

Truncamiento en el cuadre

El importe del movimiento es PIC 9(16)V99 y el acumulador WKS-SUC-IMP-ABO/CAR es PIC 9(14)V99, sin ON SIZE ERROR. Un importe que exceda la capacidad pierde los dígitos altos en silencio.

Descarte sin bitácora por tipo de proceso

Altas y bajas con tipo de proceso fuera de 00-15 (o Teletón 40-43 en un sistema distinto del 500) solo avanzan el nivel. No hay contador ni mensaje de esos descartes.

Lógica quintuplicada por día de la semana

Cada alta, baja, borrado y cuadre existe cinco veces (lunes a viernes) con datasets distintos. Una corrección aplicada a un día y no a los otros produciría diferencias entre días; la versión Java los unifica con una columna de día.

Hardcodes de sistemas, bancos y rutas

Sistemas 500, 264, 501, 87, 084, 711 y 701, bancos 0000200002, el título de respaldo (S151)S151/OBJECT/L001/CONTROL ON CMEMP y el del WFL de lote están compilados. Se trasladan a application.yml.
