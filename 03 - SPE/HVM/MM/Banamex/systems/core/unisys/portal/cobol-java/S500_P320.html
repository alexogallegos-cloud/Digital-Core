S500 · P320 a Java 21 Spring Boot

Por cada registro de B20 suma las devoluciones de los dos meses guardados y, si el total es mayor a 2, toma los datos del contrato en B03 y los promedios de saldo en B06 para escribir un archivo intermedio de 90 bytes con nodo, sucursal, contrato, medio de acceso, devoluciones y promedios mensual y anual. Ordena ese archivo por nodo, sucursal, contrato y medio, e imprime el listado 001DEVOLBIM con cortes por sucursal y por nodo, generando un listado vacío para los nodos del CSI que no tuvieron casos. Después recorre B12 y, para cada contrato con comisiones acumuladas, imprime en 002COMIPEND las comisiones de manejo de cuenta, renta, cheques girados, cheques devueltos, otras y el total.

@Component
@StepScope
@RequiredArgsConstructor
class DevolucionesProcessor implements ItemProcessor<B20DevMensual, ContratoDevoluciones> {

    private final P320Properties props;
    private final ContratoRepository b03;        // S500B03CONTRATOS
    private final HistoricoRepository b06;       // S500B06HISTORICO
    private Contrato ultimo;                     // B03 se reutiliza si el contrato se repite
    private Historico ultimoHist;

    @Override
    public ContratoDevoluciones process(B20DevMensual b20) {
        int total = b20.devMesAnt() + b20.devMesAntAnt();          // COMPUTE ... DEVMES-TOT
        if (total <= props.umbralDevoluciones() || b20.contrato().equals("000000000000")) {
            return null;                                           // W77-SW-NOHAY = 1
        }
        if (ultimo == null || !ultimo.numero().equals(b20.contrato())) {
            Optional<Contrato> c = b03.findById(b20.contrato());
            if (c.isEmpty()) return null;                          // contrato inexistente: se omite
            ultimo = c.get();
            ultimoHist = b06.findById(b20.contrato())
                    .orElseThrow(() -> new ProcesoAbortadoException(
                            "ERR FIND B06SXCTO " + b20.contrato()));   // CALL SYSTEM DMTERMINATE
        }
        return armaRenglon(b20, ultimo, ultimoHist, total);
    }
}
/** 50003250-ESCRIBE-ARCHIVO y 50003260-SUMA-PROM-ANUAL. */
private ContratoDevoluciones armaRenglon(B20DevMensual b20, Contrato c, Historico h, int total) {
    BigDecimal promedioMes = h.promedioCiclo(12);                 // B06-PROM-CICLO(12)

    // Promedio anual: solo cuentan los meses con promedio mayor a cero.
    List<BigDecimal> conSaldo = IntStream.rangeClosed(1, 12)
            .mapToObj(h::promedioCiclo)
            .filter(p -> p.signum() > 0)
            .toList();
    BigDecimal promedioAnual = conSaldo.isEmpty()
            ? BigDecimal.ZERO.setScale(2)
            : conSaldo.stream().reduce(BigDecimal.ZERO, BigDecimal::add)
                      .divide(BigDecimal.valueOf(conSaldo.size()), 2, RoundingMode.DOWN);  // COMPUTE sin ROUNDED

    String nombre = c.nombre().replace('/', ' ').replace(',', ' ');
    return new ContratoDevoluciones(0, c.sucursalPromotora(), c.numero(), b20.medioAcceso(),
            b20.devMesAnt(), b20.devMesAntAnt(), total, promedioMes, promedioAnual,
            c.producto(), c.instrumento(), c.moneda(), 0, nombre);   // el nodo se calcula después
}

@Component
@RequiredArgsConstructor
class ReporteNodoFactory {
    private final ReportStorage almacen;                 // reemplaza USERBACKUPNAME / TITLE
    private final Set<Integer> generados = new HashSet<>();

    ItemWriter<ContratoDevoluciones> writerPara(int nodo) {
        generados.add(nodo);
        return almacen.writer(nombre(nodo));
    }

    /** 70000000-FIN-PROGRAMA: cada nodo del CSI sin casos recibe un listado vacío con su cierre. */
    void generaVacios(int csi) {
        props.nodosReporte().get(csi).stream()
             .filter(n -> !generados.contains(n))
             .forEach(n -> almacen.vacio(nombre(n), "TOTAL NODO " + n));
    }

    private String nombre(int nodo) {
        return "%02d/%s".formatted(nodo, props.reportes().devoluciones());   // WKS-TIT-R00-NODO + NOM-REP
    }
}

/** 60011010-VAL-COMIPEN: B12 trae 99 importes acumulados por tipo de comisión. */
static ComisionesContrato clasifica(B12Compen b12, P320Properties.Comisiones cfg) {
    BigDecimal total = ZERO2, otras = ZERO2, chqDev = ZERO2;
    for (int i = 1; i <= 99; i++) {
        BigDecimal imp = b12.acumulado(i);
        if (imp.signum() <= 0) continue;
        total = total.add(imp);
        if (!cfg.identificadas().contains(i))      otras  = otras.add(imp);
        else if (cfg.chequeDevuelto().contains(i)) chqDev = chqDev.add(imp);
    }
    return new ComisionesContrato(b12.contrato(),
            b12.acumulado(cfg.manejoCuenta()), b12.acumulado(cfg.renta()),
            b12.acumulado(cfg.chequesGirados()), chqDev, otras, total);
}
@Bean
Step comisionesPendientes(JobRepository repo, PlatformTransactionManager tx,
                          JpaCursorItemReader<B12Compen> b12, ContratoRepository b03,
                          JasperItemWriter<RenglonComipend> comipend, P320Properties props) {
    return new StepBuilder("comisionesPendientes", repo)
            .<B12Compen, RenglonComipend>chunk(500, tx)
            .reader(b12)                                               // SET S500B12COMPEN TO BEGINNING
            .processor(r -> {
                ComisionesContrato c = clasifica(r, props.comisiones());
                if (c.total().signum() <= 0) return null;              // W77-TOTCOM-CTO > 0
                return b03.findById(r.contrato())                      // sin B03: se omite
                          .map(ct -> RenglonComipend.de(ct, c))        // incluye B03-MESES-SINMOV
                          .orElse(null);
            })
            .writer(comipend)          // título "COMISIONES PENDIENTES SIN IVA", sucursal 3006 fija
            .build();
}

Riesgos de migración
Ventana de meses rotulada como actual

El total del bimestre suma B20-DEV-MES-ANT y B20-DEV-MESANTANT (líneas 919-920) y los escribe como mes actual y anterior. RN-S500-427 habla de mes actual y anterior; la semántica depende de cuándo se ejecuta el paso respecto al cierre de mes.

Conteo de clientes por renglón

WKS-TOTS-NUM-CTOS suma uno por renglón (contrato y medio de acceso), así que los totales de clientes con devoluciones se sobrestiman si un contrato tiene varios medios.

Promedio anual sin meses en cero y truncado

El promedio anual excluye los meses con promedio cero y se trunca a dos decimales porque el COMPUTE no usa ROUNDED (líneas 983-984).

Listados vacíos para un nodo 00

En el CSI 10 la tabla WKS-NODOS-VDM tiene tres posiciones en 00 (línea 286) y 70006000-ARMA-REPVACIOS abre para ellas listados 001DEVOLBIM vacíos de un nodo que no existe.

Desbordamiento del total de comisiones

W77-TOTCOM-CTO es PIC 9(08)V99 sin ON SIZE ERROR; la suma de 99 posiciones puede truncar los dígitos altos.

Hardcodes

Umbral de 2 devoluciones, listas de nodos por CSI, posiciones de comisión 2, 5, 16, 22 y 50, sucursal 3006 del encabezado y nombres 001DEVOLBIM y 002COMIPEND. Se trasladan a application.yml.
