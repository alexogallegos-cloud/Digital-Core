1. Resumen funcional

P107 es el programa de bitácora contable diaria del sistema S151 (Contabilidad / Libro Mayor de Banamex sobre Unisys ClearPath MCP). Según su propia cabecera [P107 L6-10], "genera la bitácora de movimientos transmitidos para las sucursales, el cuadre contable, la actualización de conceptos en S151BD11SDOS, el manejo de defaults para los datos erróneos, y además genera los archivos de interface para el S028, S254, S120 y DATOTECA". Es la versión "con acumulación de totales por proceso, reporte y archivo de rechazos" [P107 L17-18].

Recibe por parámetro el sistema origen W77-SISTEMA-PARAM (p.ej. 151, 252, 402, 403, 404, 600) que gobierna nomenclatura de archivos, servicio y ramas de formato (BR: RN-S151-753). El flujo maestro [P107 L5119-5175] es: inicializa entorno y resuelve versiones de librería vía CTLVERS (BR: RN-S151-754) → carga estructura de sucursales/nodos → carga catálogos desde S080 (monedas, tipos de fondo, leyendas de transacción, transacciones/esquemas, tipos de crédito, libros, desvíos, catálogo 209/BIVA) → procesa el archivo de movimientos (LOG151 + complemento LOG151-COMP), clasificando cada clave de transacción, validando y aplicando defaults a datos erróneos (desvíos A–G), y grabando archivos de trabajo (MOVIMIENTOS contables, CVETRAN, MOVCONTABLES, ATLAS para S403, PUNTEO, MOVSCIG/CIG, archivo AM de activo fijo para S600) → genera la bitácora impresa ordenando por nodo/sucursal/caja y produce en paralelo el archivo de interfaz MOVSXTERM (S028) con cortes por caja, sucursal y CSI → genera totales por clave (TOTCVETRAN + reporte de cuadre contable) y por proceso (interfaz Mercator/INTELAR).

La Banda B1 cubierta en este documento va desde el inicio real de la PROCEDURE DIVISION (PROCEDURE DIVISION USING W77-SISTEMA-PARAM, [P107 L5118]) hasta [P107 L8728] (fin del párrafo 35000-GENERA-TOTXCVE, justo antes de 35100-ENVIO-INTELAR). Comprende: el párrafo raíz, la inicialización, toda la carga de catálogos, el procesamiento y clasificación de movimientos con validación de desvíos, la generación de la bitácora impresa y del archivo S028, y el inicio de la generación de totales por clave. Las reglas de negocio del catálogo asociadas a P107 son RN-S151-750 a RN-S151-755 (BC-13, Contabilidad GL A).

2. Datos y archivos

Todos los archivos se declaran en FILE-CONTROL [P107 L22-95] y FILE SECTION [P107 L97-419]. El título físico (VALUE OF TITLE) de casi todos se resuelve en runtime con variables WKS-TIT-* (dependen de sistema/fecha/CSI y del modo "S"/"C" fijado por RN-S151-753).

2.1 Entrada — log de movimientos

  • LOG151 — REG-LOGS151 PIC X(450) [L99-105]. Log de movimientos del día (secuencial). Se lee con REDEFINES A00-R00-HDR-MOV (header "HD"+fecha) y A00-R01-REGMOV (registro de movimiento).
  • LOG151-COMP — REG-LOG-COMP PIC X(540) [L107-113]. Log complementario (acceso RANDOM por ACTUAL KEY W77-APUDES); aporta datos adicionales (fideicomiso, programa, tipo-crédito-alfa, folio/línea AM, leyendas) enlazados por A00-R01-APUDES (clave de apertura/destino del movimiento).
  • LOGERR — REG-LOGERR PIC X(540) [L115-123]. (Declarado; no abierto en esta banda.)

2.2 Trabajo y ordenamiento (SORT)

  • MOVIMIENTOS (secuencial) / SMOVIMIENTOS (SORT) — REG-MOVIMIENTOS [L134-167], registro contable clave (todo COMP): RM-NODO-IMP, RM-SUC-INIC, RM-CAJA-INIC, RM-TIPO-CRED, RM-FONDO, RM-SUC-PROM, RM-CONTRATO 9(16), RM-CVE-TRANS, RM-TM, RM-IMPORTE 9(14)V99, RM-AUT-APLIC, RM-AUT-3NIVEL, RM-AUT-S151, RM-MONEDA, RM-REFERENCIA 9(20), RM-ORIGEN, RM-HORA, RM-FECHA-REAL, RM-FECHA-VALOR, RM-NOMINA-OPER, RM-CVE-MDA, RM-MDA-SUC, RM-MDA-CTA, RM-ESTATUS, RM-TIPO-PROC, RM-LIBRO, RM-NATS28, RM-TC-ALFA X(08). Campos clave de negocio: RM-ESTATUS (1=vivo, ≠1=eliminado), RM-NATS28 (naturaleza contable 1=cargo/2=abono, BR: RN-S151-750), RM-AUT-3NIVEL/RM-AUT-APLIC (autorización, BR: RN-S151-751).
  • CVETRAN (secuencial) / SMOVCONTABLES (SORT) — REG-CVETRAN [L215-230] (RMC-*): totales/detalle por clave de transacción para cuadre. Layout: RMC-FECHA, RMC-NPROCESO, RMC-LIBRO, RMC-MONEDA, RMC-FID, RMC-TIPOCRED, RMC-FONDO, RMC-EVENTO, RMC-CVETRAN, RMC-TM, RMC-SUC-PROM, RMC-SUC-INIC, RMC-IMPORTE 9(14)V99, RMC-TIPOCON.
  • TOTCVETRAN — REG-TOTCVETRAN PIC X(78) [L232-237]. Totales por clave (salida).
  • MOVCONTABLES (X60) / SMOVCONTABLES — movimientos contables de trabajo [L266-275].
  • MOVCONERROR / SMOVCONERROR — REG-ERROR [L289-305] (RE-*): registro de rechazo con RE-TIPOERR, importes y llaves; alimenta el flujo de RECHAZOS (BR: RN-S151-755).
  • PAQCONTAB2 (X300), CVEMARCATOR (X162, interfaz Mercator/INTELAR), MOVSCIG (X810, CIG), A01-ATLAS (X60, interfaz ATLAS/S403), PUNTEO (X48), FILE-AM (REG-ACT-FIJO X142, activo fijo S600).

2.3 Salidas disco (interfaces)

  • MOVSXTERM — REG-MOVSXTERM PIC X(60) [L327-331]. Interfaz S028 (movimientos por terminal): header A00-R00-HDR-S028, detalle A00-R02-REGMOV-S028, trailer A00-R03-TRAILER-S028.
  • CUADRECON — REG-CUADRECON PIC X(55) [L277-282]. Archivo de cuadre contable (BR: RN-S151-752).
  • DESVIOS — REG-DESVIOS PIC X(130) [L395-402]. Movimientos desviados a default.
  • ERRORES (X100), MOVSCIG, A01-ATLAS, PUNTEO, CVEMARCATOR, FILE-AM (ver 2.2).

2.4 Reportes impresos (PRINTER)

BITACORA (X132), TOTALESTRANS (X132), REPCONTABLE (X132), REPORTE (X132, reporte de desvíos), RECHAZOS (X132), TOTRECHA (X132), V00-REP-CVES (X132, resumen totales por clave / cuadre), V00-REP-PROC (X132, resumen por proceso).

2.5 Librerías / servicios externos (CALL … IN / OF)

  • S151LIBCONTROL — base de control S151: CONSISDIA (fecha de proceso B01), CONSISMEN (mensajes B03).
  • CTRLVERS (func. CTLVERS) — DAME_TIT: resuelve título/release de librerías (BR: RN-S151-754).
  • S080BD01CON — catálogos: L700_CONSUL_DESC (descripciones), L710_CONSUL_DETALLE (detalle/parámetros).
  • ESTRUCTURA (LIBEST) — estructura de sucursales, nodos de impresión, nombres largos de sucursal.
  • SOPORTECOMS (CSIID) — obtiene número de CSI del host.
  • LOCSUP (CONVERT-DATE) — conversión de fechas.
  • LIB-REGISTRA (CONTROLES) — cierre/registro de archivos de movimientos y descripciones.
  • LIB-DISP (LJ) — bitácora de incidentes / log de eventos (LJ = log journal).
  • OUTBOARD (ESENDAUTO) — envío automático de alertas de desvío (mensajería operativa).
  • ADMONXFERS, S006/P940 (WKS-START-PROG) — administración de transferencias / FTP de control.
