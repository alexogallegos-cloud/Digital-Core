S151 · P131 a Java 21 Spring Boot

Lee el archivo AGRUPADO que deja P130 (header, detalles con clave 5 u 80 a 89 y trailer) y, para cada detalle, resuelve contra catálogos KEYEDIOII la unidad de negocio, la moneda alfa, el producto alfa, el departamento y el par de cuentas cargo y abono. Escribe el registro traducido en AGRUPCONT y dos registros de 90 bytes en PAQUETECONTABLE (naturaleza 1 y 2) más uno en PARES; los movimientos con clave distinta de 05 van además a CUADREESPECIAL. Al final compara registros e importe contra el trailer y aborta si difieren, ordena el paquete para las interfaces de S254 y genera los reportes de cuadre contable, doble registro FOBAPROA y pares. Para los sistemas con Full Suite repite el proceso sobre AGRUPADOFS con registros de 126 bytes.

/** REG-PAQUETECONTABLE: contrato de 90 bytes con S254. Un movimiento produce dos registros. */
public record PaqueteContableRecord(
        String cveReg,          // X(02)  "01" normal; otra clave va también a CUADREESPECIAL
        String unidadNegocio,   // X(05)  UNINEG (catálogo COPC/COPCN o "BNMEX" de desvío)
        String libroContable,   // X(10)  siempre "CONTABLE  " (20440-MUEVE-MONEDAS)
        String fechaContable,   // X(10)  AAAA-MM-DD ya formateada
        IdAsiento idAsiento,    // X(04)+X(03)+X(01)+X(02)
        int monedaOperativa,    // 9(03)
        String monedaAlfa,      // X(03)  "***" si no hay equivalencia
        String departamento,    // X(10); RP-DEPTO-1P lo reinterpreta como 9(04) en los reportes
        String productoAlfa,    // X(06)
        String intercompany,    // X(05)
        String cuentaAlfa,      // X(06); RP-CUENTA = primeras 4 posiciones
        Naturaleza naturaleza,  // 9(01)  1 = cargo, 2 = abono
        BigDecimal importe,     // 9(15)V99 sin signo -> escala 2, siempre >= 0
        int indProducto) {      // 9(02)

    public enum Naturaleza { CARGO(1), ABONO(2);
        final int codigo; Naturaleza(int c) { codigo = c; } }

    public record IdAsiento(String sistema, String csi, String version, String resto) {}

    public PaqueteContableRecord {
        if (importe.signum() < 0 || importe.scale() != 2)
            throw new IllegalArgumentException("RP-IMPORTE es 9(15)V99 sin signo");
    }

    /** Columnas fijas para el FormatterLineAggregator del writer. */
    public static final String FORMATO =
        "%-2s%-5s%-10s%-10s%-10s%03d%-3s%-10s%-6s%-5s%-6s%1d%017d%02d";
}

@Configuration
public class TraductorContableJobConfig {

    @Bean
    Job traductorContable(JobRepository repo, Step cargaCatalogos, Step validaHeaderTrailer,
                          Step traduceAgrupado, Step interfacesS254, Step traduceAgrupadoFs,
                          Step interfacesFfs, Step difAlfaVsFfs, Step reportes,
                          SistemaDecider sistema) {
        return new JobBuilder("S151P131", repo)
            .start(cargaCatalogos)                 // 12000-CARGA-CATALOGOS (L700/L710)
            .next(validaHeaderTrailer)             // 17100 / 17200 / 17900
            .next(traduceAgrupado)                 // 20000 + 21000-VALIDA-TOTALES-TRAILER
            .next(interfacesS254)                  // 25000 sort + 40000 + 50000 vacías
            .next(sistema).on("FFS").to(traduceAgrupadoFs)   // W88-SIST-INT-FFS
                .next(interfacesFfs)
                .next(difAlfaVsFfs)                // sólo W88-S804 OR W88-S404
                .next(reportes)
            .from(sistema).on("*").to(reportes)    // 60000..71100: contable, especial, FOBAPROA, pares
            .end()
            .build();
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class TraductorProcessor implements ItemProcessor<AgrupadoRecord, MovimientoTraducido> {

    private final ClaveRegistroValidator claves;
    private final UnidadNegocioResolver unidades;
    private final MonedaAlfaResolver monedas;
    private final ProductoAlfaResolver productos;
    private final DepartamentoResolver departamentos;
    private final ParesContablesResolver pares;
    private final TotalesAgrupado totales;            // W77-TOTREG / W77-TOTIMP

    @Override
    public MovimientoTraducido process(AgrupadoRecord r) {
        if (r.cveReg() == 9) {
            return null;                              // trailer: no se traduce ni se acumula
        }
        totales.suma(r.importe());                    // COMPUTE W77-TOTREG / W77-TOTIMP
        var t = new MovimientoTraducido(r);
        t.cveReg(claves.valida(r));                   // 20410
        t.fechaContable(r.fecha());                   // 20420: AAAAMMDD -> AAAA-MM-DD
        unidades.resuelve(r, t);                      // 20430
        monedas.resuelve(r, t);                       // 20440
        productos.resuelve(r, t);                     // 20450
        departamentos.resuelve(r, t);                 // 20460
        pares.resuelve(r, t);                         // 20470: guía o CXEV/COCO, cuenta final
        return t;
    }
}
// AT END -> 20610-GRABA-TRAILER: se escribe en el footerCallback del writer de AGRUPCONT.
@Component
public class ClaveRegistroValidator {

    /** 5 = proceso normal; 80 a 89 = procesos especiales. Cualquier otra aborta el día. */
    public String valida(AgrupadoRecord r) {
        int cve = r.cveReg();                               // PIC 9(002)
        if (cve == 5 || (cve > 79 && cve < 90)) {
            return "%02d".formatted(cve);                   // MOVE 9(02) a X(02): "05", "80".."89"
        }
        throw new ErrorFatalException(                      // 90500-ERROR-FATAL: STOP RUN
            " CLAVE DE REGISTRO INVALIDA %02d. NUMERO DE REGISTRO %d"
                .formatted(cve, r.numeroRegistro()));
    }
}

@Service
@RequiredArgsConstructor
public class UnidadNegocioResolver {

    private final ConvOpeContRepository copc;      // ARCH-CONV-OPE-CON, llave libro + moneda
    private final ConvOpeContAreaRepository copcn; // ARCH-CONV-OPEN-CON, exclusivo del 403
    private final MonedaValidator monedas;         // 20433-VALIDA-MONEDA
    private final P131Properties props;

    @Transactional(readOnly = true)
    public void resuelve(AgrupadoRecord r, MovimientoTraducido t) {
        if (props.sistema() == 403) { resuelve403(r, t); return; }      // 20432-UNID-NEG-403
        t.libro(r.libro());
        int moneda = monedas.valida(r);              // aborta si la moneda no está en catálogo
        t.marcas(0, 0);                              // W77-BAND-DREG, W77-IND-CENT
        copc.findById(new CopcId(r.libro(), moneda))
            .ifPresentOrElse(c -> {
                t.unidadNegocio(c.unidadNegocio());
                t.departamentoCatalogo(c.departamento());     // W77-DEPTO
                t.libroDesvio(0);
                t.marcas(c.indDobleFobaproa(), c.indCentraliza());
            }, () -> resuelveDesvio(t));                   // 20435-OBTEN-UNI-DE-NEGO-DESVIO
    }
    /** 20436-LIB-DESVIO: segundo intento con el libro de desvío y moneda 1. */
    private void resuelveDesvio(MovimientoTraducido t) {
        int libroDesvio = props.libroDesvio();                 // WKS-LIBRO-DESVIO (13900-CARGA-DESVIOS)
        t.libroDesvio(libroDesvio);
        copc.findById(new CopcId(libroDesvio, 1))
            .ifPresentOrElse(c -> {
                t.unidadNegocio(c.unidadNegocio());
                t.departamentoCatalogo(c.departamento());
                t.marcas(c.indDobleFobaproa(), c.indCentraliza());
            }, () -> {
                // Último recurso: movimiento no clasificado.
                t.unidadNegocio(props.desvio().unidadNegocio());    // "BNMEX"
                t.departamentoCatalogo(props.desvio().departamento()); // 907
                log.warn("Sin COPC para libro {} ni libro de desvío {}: se asigna {}/{}",
                         t.libro(), libroDesvio, props.desvio().unidadNegocio(),
                         props.desvio().departamento());
            });
    }
}

@Component
@RequiredArgsConstructor
public class PaqueteContableWriter implements ItemWriter<MovimientoTraducido> {

    private final FlatFileItemWriter<PaqueteContableRecord> paquete;    // PAQUETECONTABLE
    private final FlatFileItemWriter<ParesRecord> pares;                // PARES (74 bytes)
    private final FlatFileItemWriter<CuadreEspecialRecord> especial;    // CUADREESPECIAL

    @Override
    public void write(Chunk<? extends MovimientoTraducido> chunk) throws Exception {
        var regs = new ArrayList<PaqueteContableRecord>();
        var prs = new ArrayList<ParesRecord>();
        var esp = new ArrayList<CuadreEspecialRecord>();
        for (var t : chunk) {
            String cve;
            if ("05".equals(t.cveReg())) {
                cve = "01";                                  // proceso normal
            } else {
                esp.addAll(CuadreEspecialRecord.de(t));      // 20590: claves 80..89
                cve = t.cveReg();
            }
            regs.add(t.aPaquete(cve, CARGO, t.cuentaCargo(), t.importeCargo()));
            regs.add(t.aPaquete(cve, ABONO, t.cuentaAbono(), t.importeAbono()));
            prs.add(ParesRecord.de(t));                      // cargo + abono + importe del abono
        }
        paquete.write(new Chunk<>(regs));
        pares.write(new Chunk<>(prs));
        especial.write(new Chunk<>(esp));
    }
}
@Component
@RequiredArgsConstructor
public class CuadreTrailerTasklet implements Tasklet {

    private final TotalesAgrupado acumulado;        // W77-TOTREG, W77-TOTIMP (9(15)V99)
    private final TrailerAgrupado trailer;          // W77-TOTREG-TR, W77-TOTIMP-TR leídos en 17200

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        String archivo = trailer.titulo();          // WKS-TIT-AGRUPADO
        if (trailer.registros() != acumulado.registros()) {
            throw new ErrorFatalException((" ARCHIVO : %s TOTAL DE REGISTROS DEL TRAILER  %d"
                    + " DIFERENTE DEL TOTAL DE REGISTROS DEL P131 %d")
                    .formatted(archivo, trailer.registros(), acumulado.registros()));
        }
        if (trailer.importe().compareTo(acumulado.importe()) != 0) {
            BigDecimal dif = trailer.importe().subtract(acumulado.importe());   // escala 2, exacta
            throw new ErrorFatalException((" ARCHIVO : %s. TOTAL DE IMPORTE TRAILER  %s"
                    + " DIFERENTE DEL TOTAL DE IMPORTE DEL PROGRAMA  %s DIFERENCIA %s")
                    .formatted(archivo, trailer.importe(), acumulado.importe(), dif));
        }
        return RepeatStatus.FINISHED;
    }
}

Riesgos de migración
SETID, versión y tipo de transacción compilados

En 20500-MUEVE-RESTO-TRADUCIDO (líneas 7366-7369) y su gemelo FS (7392-7393) el SETID BNMEX, la versión 1 y el tipo de transacción 10 están escritos en el código; el mismo SETID aparece también en desvíos, compensación directa y en las interfaces S254 y FFS (líneas 10806 y 10843). Cualquier cambio de entidad obliga a recompilar y a reprobar contra S254.

Fallback silencioso a BNMEX / 907

Cuando no existe COPC ni para el libro original ni para el libro de desvío, el movimiento se asigna a BNMEX con departamento 907 sin aviso ni archivo de rechazo (líneas 6363-6366 y equivalentes 6380, 6397, 6413). El movimiento llega a S254 como no clasificado.

Campo FIDEICOMISO con el área

La línea 7371 que movía el fideicomiso está comentada y la 7372 mueve el área al campo A01-TRAD-FIDEICOMISO del registro traducido. El nombre del campo no corresponde a su contenido.

Detalle FS escrito con el layout del trailer

En la ruta Full Suite, 20490-GRABA-ARCHIVO-TRADUCIDFS (línea 7345) y los párrafos de doble registro FS (7595-7607 y 7656-7669) escriben AGRUPCONTFS desde A03-TRAILER-TRADFS en lugar de A01-REGDET-TRADFS. Si alguien consume AGRUPCONTFS, recibe registros con clave 09 en lugar de los detalles traducidos.

Marca de moneda prácticamente inalcanzable

La moneda alfa *** solo se asigna si la moneda existe en WKS-DES-MONEDA pero no en WKS-MONEDA-ALFA; una moneda inexistente ya abortó el proceso en 20433-VALIDA-MONEDA. Las pruebas de equivalencia deben cubrir ese caso específico.
