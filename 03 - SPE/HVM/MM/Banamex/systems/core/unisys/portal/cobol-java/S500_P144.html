S500 · P144 a Java 21 Spring Boot

Abre en modo consulta S500BD07ATRIBUCTA (B01CONTRATOS y B02CONTROL) y S500BD01CAPTACION (B03CONTRATOS). Toma la fecha de lote y de línea de B02, determina el CSI local por el nombre del host y recorre completo B01CONTRATOS. Por cada contrato del CSI local busca su par en B03: si no existe lo anota en el archivo de problemas y, si existe con un indicador de ordenante distinto, escribe un movimiento 0935 sin importe en BIT-ACTBANDERA. El archivo lleva encabezado MARCA MASIVA ORDENANTE y un trailer con el total de activaciones.

/** WS-ARCHSINCB03-REG: 240 bytes, tres vistas REDEFINES discriminadas por el primer dígito. */
public sealed interface ActBanderaRecord permits ActBanderaRecord.Header,
        ActBanderaRecord.Detalle, ActBanderaRecord.Trailer {

    String toFixed();   // FlatFileItemWriter escribe exactamente 240 posiciones

    /** WS-ARCHSINCB03-HDR, tipo 1. */
    record Header(int nodoOrigen,          // 9(02)  CSI local
                  String fecProcesoAmd,    // 9(06)  AAMMDD, sin siglo
                  long sistema,            // 9(12)  500
                  int numArchivo,          // 9(04)  9
                  String descripcion)      // X(36)
            implements ActBanderaRecord {
        public String toFixed() {
            return Fixed.of(240).num(1, 1).num(nodoOrigen, 2).str(fecProcesoAmd, 6)
                    .num(sistema, 12).num(numArchivo, 4).str(descripcion, 36).spaces().build();
        }
    }

    /** WS-ARCHSINCB03-DET, tipo 2: movimiento 0935 sin importe. */
    record Detalle(long numSec, int sucursal, int caja, long numTran, int claveTrans,
                   int tipoMov, int tipMedAcc,
                   int sucPromotora,       // TARJETA-R: 9(04) ...
                   String contrato,        // ... + 9(12); String para conservar ceros
                   BigDecimal importe,     // 9(14)V99, escala 2
                   int moneda, long referencia, int movForzado,
                   int indMarcaOrdenante,  // WS-SNC-C935-IND-MARORD-A 9(02)
                   String fecMarcaAmd)     // WS-SNC-C935-FEC-MARORD-A 9(08)
            implements ActBanderaRecord {
        public String toFixed() { return Fixed.detalle935(this); }   // FILLER X(152) a espacios
    }

    /** WS-ARCHSINCB03-TRL, tipo 9. */
    record Trailer(long numAbonos, BigDecimal impAbonos, long numCargos, BigDecimal impCargos,
                   long numNoContables)    // NUMNCO 9(08)
            implements ActBanderaRecord {
        public String toFixed() { return Fixed.trailer(this); }      // importes 9(16)V99
    }
}

@ConfigurationProperties("p144")
public record P144Properties(ActBandera actbandera, Problemas problemas) {
    public record ActBandera(String titulo, long sistema, int seccion) {}
    public record Problemas(String titulo, boolean appendSiExiste) {}

    public String tituloActBandera(int csi, LocalDate fechaLinea) {
        return actbandera.titulo()
                .replace("{csi}", "%02d".formatted(csi))
                .replace("{fecha}", fechaLinea.format(DateTimeFormatter.BASIC_ISO_DATE))
                .replace("{sistema}", "%012d".formatted(actbandera.sistema()))
                .replace("{seccion}", "%04d".formatted(actbandera.seccion()));
    }
}

@Configuration
@EnableConfigurationProperties(P144Properties.class)
public class MarcaMasivaOrdenanteJobConfig {

    /** 00000000-CONTROL-PROGRAMA: INICIO, PROCESO y FIN en secuencia. */
    @Bean
    Job marcaMasivaOrdenante(JobRepository repo,
                             Step validaVersion,       // 10000100-VERSIONES + 40002000-TITLE-LIBRERIAS
                             Step contextoEjecucion,   // 40003000-IDENTIFICA-HOST + 40005000-VALIDO-FECHA-PRO
                             Step reconciliaB01B03) {  // 40006000-OPEN-ARCHIVOS + 50000000-PROCESO + 70000000-FIN
        return new JobBuilder("S500P144", repo)
                .start(validaVersion)
                .next(contextoEjecucion)
                .next(reconciliaB01B03)
                .build();
    }
    // ATTACH ... EXCEPTIONEVENT / ALLOW INTERRUPT: el handler solo pone TASKVALUE en cero.
    // En Spring Batch la interrupción se atiende con JobOperator.stop(); no hay equivalente que migrar.
}

@Component
@RequiredArgsConstructor
public class ContextoEjecucionTasklet implements Tasklet {

    private final ControlAtribuctaRepository control;   // S500B02CONTROL, OPEN INQUIRY
    private final CalendarioBancario calendario;         // reemplaza S006 LOCSUP
    private final TopologiaCsi topologia;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        var b02 = control.findFirst()
                .orElseThrow(() -> new ProcesoAbortadoException("ERROR B02CONTROL"));
        LocalDate fecBase  = b02.fechaLote();          // WKS-FEC-BASE
        LocalDate fecLinea = b02.fechaLinea();         // WKS-FEC-LINEA
        LocalDate fecProx  = b02.fechaLinea();         // WKS-FEC-PROX

        // WKS-TSK-FECH > 0: en el fuente nadie carga TASKVALUE en WKS-VALUE-PASO, así que hoy
        // nunca se cumple. Se expone como parámetro de job opcional para no perder la intención.
        LocalDate forzada = ctx.getStepContext().getStepExecution()
                .getJobParameters().getLocalDate("fechaProceso");
        if (forzada != null) {
            fecBase = forzada;
            fecProx = calendario.proyecta(forzada, 1, 13);   // LOCSUP función 13, formato 12, +1
        }
        boolean esMensual = fecProx.getMonthValue() != fecBase.getMonthValue();  // WKS-ES-MENSUAL (no se usa)

        var ec = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        ec.put("csiLocal", topologia.csiLocal());
        ec.put("fechaBase", fecBase);
        ec.put("fechaLinea", fecLinea);
        return RepeatStatus.FINISHED;
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class ComparaMarcaOrdenanteProcessor implements ItemProcessor<ContratoAtributo, ActBanderaRecord> {

    private final ContratoCaptacionRepository b03;      // índice B03SXCTO por número de contrato
    private final ActivacionFactory activaciones;
    private final ProblemasWriter problemas;
    @Value("#{jobExecutionContext['csiLocal']}") private int csiLocal;

    @Override
    public ActBanderaRecord process(ContratoAtributo b01) {
        String contrato = b01.numContrato();            // WKS-CONTRATO-B01
        int datoMatch   = b01.numDato(1);               // B01-NUM-DATO(1)
        String fecAct   = b01.numFecProAct(1);          // B01-NUM-FECPROACT(1)
        boolean local   = csiLocal == b01.csiContrato();

        Optional<ContratoCaptacion> b03Reg = b03.findByNumContrato(contrato);   // FIND B03SXCTO AT
        if (b03Reg.isEmpty()) {                          // 90000001-CTO-NOEXISTE
            if (local) {
                problemas.escribe("CTO NO EXISTE " + contrato + " EN B03");
            }
            return null;                                 // contrato del otro CSI: se ignora en silencio
        }
        // 98000000-COMPARACION: mismo contrato, CSI local y marca distinta
        if (local && datoMatch != b03Reg.get().indMarcaOrdenante()) {
            return activaciones.nueva(contrato, datoMatch, fecAct);   // 50009000-ESC-REGISTRO
        }
        return null;                                     // sin diferencia: no se genera movimiento
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class ActivacionFactory {

    private final P144Properties props;
    @Value("#{jobExecutionContext['csiLocal']}") private int csiLocal;
    private long consecutivo;                    // WS-CONT y WKS-CONTADOR llevan la misma cuenta

    ActBanderaRecord.Detalle nueva(String contrato, int indMarcaOrdenante, String fecMarca) {
        consecutivo++;
        var m = props.movimiento();
        return new ActBanderaRecord.Detalle(
                consecutivo, m.sucursal(), m.caja(), consecutivo,      // NUM-SEC = NUMTRAN
                m.claveTrans(), m.tipoMov(), m.tipoMedioAcceso(),
                m.sucPromotora(csiLocal), contrato,
                BigDecimal.ZERO.setScale(2), 0, 0L, 0,                 // importe, moneda, referencia, forzado
                indMarcaOrdenante, fecMarca);
    }

    long generados() { return consecutivo; }     // alimenta TRL-NUMNCO
}
@Bean
@StepScope
FlatFileItemWriter<ActBanderaRecord> actBanderaWriter(
        P144Properties props, ResourceLoader rl,
        @Value("#{jobExecutionContext['csiLocal']}") int csi,
        @Value("#{jobExecutionContext['fechaLinea']}") LocalDate fechaLinea,
        ActivacionFactory activaciones) {

    var header = new ActBanderaRecord.Header(csi,
            fechaLinea.format(DateTimeFormatter.ofPattern("yyMMdd")),   // WKS-FEC-LINEA-06: trunca el siglo
            props.actbandera().sistema(), props.actbandera().seccion(),
            "MARCA MASIVA ORDENANTE");

    return new FlatFileItemWriterBuilder<ActBanderaRecord>()
            .name("bitActBandera")
            .resource((WritableResource) rl.getResource(props.tituloActBandera(csi, fechaLinea)))
            .lineAggregator(ActBanderaRecord::toFixed)
            .headerCallback(w -> w.write(header.toFixed()))             // OPEN OUTPUT + WRITE header
            .footerCallback(w -> w.write(new ActBanderaRecord.Trailer(
                    0, BigDecimal.ZERO.setScale(2), 0, BigDecimal.ZERO.setScale(2),
                    activaciones.generados()).toFixed()))               // 50003400-TRAILER
            .shouldDeleteIfExists(true)
            .build();
}

Riesgos de migración
Sobrescritura de fecha inalcanzable

WKS-TSK-FECH (línea 27357) nunca se carga desde MYSELF(TASKVALUE); la interrupción incluso pone TASKVALUE en cero. El IF de la línea 28087 nunca se cumple y la proyección con LOCSUP función 13 es código muerto. WKS-ES-MENSUAL se calcula y no se usa.

Errores de DMSII tratados como inexistencia

En 90000001-BUSCA-CTO (líneas 28849-28859) cualquier excepción del FIND sobre B03SXCTO ejecuta 90000001-CTO-NOEXISTE; el MOVE DMSTATUS está comentado. Un error de E/S o de bloqueo se reporta como contrato huérfano y el contrato se salta sin abortar.

Lectura del área de B03 tras un FIND fallido

90000001-WRITE-PROC-ARCH (línea 28839) mueve B03-NUM-CONTRATO aun cuando el FIND falló. La comparación de la línea 28887 evita la escritura solo porque ese valor corresponde al contrato anterior; en Java se reemplaza por Optional.

Mensajes de error copiados

40001000-OPEN-BD07, 70001000-CLOSE-BD01CAPTACION y 70001000-CLOSE-BD07ATRIBUCTA (líneas 27933, 28469 y 28489) emiten 'ERROR AL ABRIR LA BD CAPTACION' sin importar la base ni la operación.

Hardcodes de topología y movimiento

CSI por nombre de host, ocho pares de transferencia, sucursales promotoras 0432 y 0366, sucursal 0511, caja 05, clave 0935, sistema 500 y sección 0009 están compilados. Cualquier host o CSI no reconocido cae en el valor de Monterrey sin aviso.
