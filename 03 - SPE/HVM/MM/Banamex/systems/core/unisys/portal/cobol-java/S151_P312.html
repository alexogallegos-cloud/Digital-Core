@Component
@RequiredArgsConstructor
public class InicioS084Tasklet implements Tasklet {

    private final ControlSistemasClient control;   // CONSISDIA / CONSISMEN IN LIB-CONTROL
    private final BaseSaldosResolver bases;
    private final P312Properties props;

    @Override
    public RepeatStatus execute(StepContribution c, ChunkContext ctx) {
        var dia = control.consultaSistemaDia(props.sistemaSaldos());
        if (dia.result() != 0) throw new ControlSistemaException("CONSISDIA " + dia.result());
        var men = control.sistemaMensual(props.sistemaSaldos());
        if (men.result() != 0) throw new ControlSistemaException("CONSISMEN " + men.result());

        // OPEN INQUIRY BASESDO: si la base no abre, el step falla aquí (el original sigue).
        bases.verificaLectura(men.nombreBdSaldos());

        var ec = ctx.getStepContext().getStepExecution().getJobExecution().getExecutionContext();
        ec.put("fechaConsulta", dia.fechaConsulta());      // WKS-FECHA-LINEA (B01-FECCON)
        ec.put("fechaProceso151", dia.fechaProceso151());  // WKS-FECHA-PROC para el header
        ec.put("baseSaldos", men.nombreBdSaldos());
        return RepeatStatus.FINISHED;
    }
}

@Component
@StepScope
@RequiredArgsConstructor
public class ContratoS084Processor implements ItemProcessor<EstadoCuentaB80, DetalleS084> {

    private final SaldoMensualRepository b20;   // B20SXSDOMENCON
    private final ApunteMensualRepository b21;   // B21SXSDMENCON1
    private final ConceptosS084 conceptos;
    private final P312Properties props;

    @Override
    public DetalleS084 process(EstadoCuentaB80 ec) {
        var lista = new ArrayList<ConceptoS084>();
        var saldo = b20.findFirst(ec.contrato(), ec.anioMes(), 1, 3, 1);
        saldo.ifPresent(s -> conceptos.deB20(s, lista));
        boolean tieneApuntes = saldo.map(s -> s.apuntadorImportes() > 0).orElse(false);
        if (tieneApuntes) {
            b21.findAll(ec.contrato(), ec.anioMes(), 1, 3).forEach(a -> conceptos.deB21(a, lista));
        }
        // Comportamiento del fuente: el WRITE está dentro del IF B20-SDO-APUIMP > 0.
        if (!tieneApuntes && props.soloConApuntes()) {
            return null;                         // el contrato no llega a S084
        }
        return DetalleS084.de(ec, saldo, lista);
    }
}

// En DetalleS084.de(...): la sucursal promotora se toma siempre de B20 cuando existe.
static int sucursalPromotora(Optional<SaldoMensualB20> b20, P312Properties p) {
    if (p.replicarSucursalCero()) {
        // Conducta actual: cuando hay apuntes, 02140 no mueve B20-SDO-SUCPRO porque
        // W77-ERROR-BASE ya vale 1 al terminar el ciclo de B21.
        return b20.filter(s -> s.apuntadorImportes() == 0).map(SaldoMensualB20::sucursal).orElse(0);
    }
    return b20.map(SaldoMensualB20::sucursal).orElse(0);
}

    private void agrega(int clave, long movs, BigDecimal saldo, List<ConceptoS084> destino) {
        if (!props.conceptosValidos().contains(clave)) return;
        // Se exporta si saldo > 0 o movimientos > 0: un saldo negativo sin movimientos se omite.
        if (saldo.signum() > 0 || movs > 0) {
            if (destino.size() == DetalleS084.MAX_CONCEPTOS) return;
            destino.add(new ConceptoS084(clave, movs, saldo));
        }
    }
}

            agrega(clave, a.cntMov(pos), a.saldo(pos), destino);
        }

Riesgos de migración
Contratos sin apuntes no se exportan

En 02100-DET-PROC (líneas 1004-1007) el PERFORM 02170-GRABA-REGDET está dentro del IF B20-SDO-APUIMP > 0 porque no hay END-IF ni punto intermedio. Solo se escriben contratos con apuntes en B21.

Sucursal promotora en cero

Para los contratos que sí se escriben, W77-ERROR-BASE vale 1 al volver a 02140-DATOS-B20 (línea 1069) y B20-SDO-SUCPRO no se asigna. Todo detalle sale con sucursal promotora cero.

Archivo vacío ante falla de la base

Si OPEN INQUIRY BASESDO falla (líneas 965-969), el programa continúa y entrega a S084 un archivo con header y trailer de cero registros, indistinguible de un día sin movimientos.

Arrastre de datos entre contratos

Solo se limpian 15 de las 25 posiciones de conceptos (línea 1023) y el campo de cantidad de conceptos nunca se asigna. Si B20 no existe para un contrato, se usa el B20-SDO-APUIMP del contrato anterior.

Hardcodes

Sistema 500, PIM 1/3/1, nodo 04, sistemas 151 y 084, la lista de 16 conceptos, la ruta de la librería de mensajes y la ruta de respaldo de LIB-CONTROL en CMEMP están compilados. Se trasladan a application.yml.
