T-PAY-002 · Validación contra catálogo 174 (CVETXN autorizado)

S500 P020 LINCOMS Tipo: validación Frecuencia: Online — por cada transacción Regla: RN-S500-116 Confianza: Media

Flujo de tarea (L5)

busca en WKS-CAT174-CVETXN → 174-OK=0 → autorizado → 174-NF=1 → I02-PROBLEMAS

Camino exitoso — 174-OK = 0

WKS-CVETXN-174-OK = 0
El CVETXN está presente en el catálogo 174 dinámico. P020 continúa al siguiente paso del flujo de autorización (T-PAY-001 ya aplicado). La transacción es elegible para posting y asiento GL.

Camino de rechazo — 174-NF = 1

WKS-CVETXN-174-NF = 1
El CVETXN no está autorizado en cat-174. P020 desvía la transacción a I02-PROBLEMAS sin generar asiento en S151 ni registro de posting. El canal recibe respuesta de error por COMS.

Reglas de negocio

RN-S500-116 — Validación contra catálogo 174 (CVETXN-174)
REGLA-BANCARIA-MX RIESGO-EQUIVALENCIA Regulador: Interno Confianza: Media
P020 mantiene una tabla dinámica del catálogo 174 (WKS-CAT174-CVETXN). Para cada transacción verifica si su CVETXN está en dicho catálogo. El flag WKS-CVETXN-174-NF (valor 1=no encontrado) indica que el CVETXN no está autorizado en cat-174. El catálogo 174 es recargable en caliente. La lógica exacta de bloqueo no es visible en el rango leído.
IF WKS-CVETXN-174-NF (= 1) → transacción NO en catálogo 174 → desviar a I02-PROBLEMAS → sin posting, sin asiento GL IF WKS-CVETXN-174-OK (= 0) → transacción autorizada en catálogo 174 → continúa flujo de cargo/abono Sistemas downstream: Rechazo → I02-PROBLEMAS Éxito → continúa T-PAY-004 (posting S02) → T-PAY-005 (asiento S151)
⚠ Excepción documentada: El catálogo 174 tiene un mecanismo de recarga separado de TASKVALUE=3040 (que recarga cat-1789). El TASKVALUE o procedimiento de recarga específico de cat-174 no está documentado en las reglas leídas — requiere identificación en el código fuente completo.

Vocabulario

WKS-CAT174-CVETXN
Working storage · tabla dinámica
Tabla del catálogo 174 cargada en memoria de trabajo de P020. Contiene la lista de CVETRANs autorizados para operar. Es recargable en caliente sin reiniciar el servidor COMS.
WKS-CVETXN-174-NF
Working storage · flag · PIC 9(1)
Not-Found flag. Valor 1 indica que el CVETXN de la transacción no está en el catálogo 174. Activa el desvío a I02-PROBLEMAS y corta el flujo de posting.
WKS-CVETXN-174-OK
Working storage · flag · PIC 9(1)
OK flag. Valor 0 indica que el CVETXN está autorizado en el catálogo 174. La transacción puede continuar al flujo de cargo/abono y posting.
I02-PROBLEMAS
Archivo DMSII · tipo destino de rechazos
Archivo de destino para transacciones rechazadas. Recibe tanto los rechazos por catálogo 174 (T-PAY-002) como otros errores de validación. Es el punto de revisión operativa para transacciones no procesadas.
Catálogo 174
Tabla de configuración dinámica
Lista de CVETRANs autorizados para operar en el sistema S500. Se mantiene como catálogo dinámico recargable en caliente. Su mecanismo de recarga es independiente del TASKVALUE=3040 (cat-1789).
I10-POSTING-E
Archivo DMSII · tipo errores de posting
Archivo de errores de posting (distinto de I02-PROBLEMAS). Recibe transacciones con CVETXN autorizado en cat-174 pero cuyo posting S02 retorna error. Contiene POSTERR-DET-CVETXN para identificar el CVETXN fallido.
