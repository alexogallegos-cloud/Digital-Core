Reglas de negocio

RN-S500-113 — SMCOMS-DISABLE: apagado controlado por TASKVALUE 3004/3104
OPERATIVO CONTROL-MCP Regulador: — Confianza: Alta
El operador MCP puede apagar P020 de forma controlada usando el mecanismo de interrupción TASKVALUE. TASKVALUE=3004 apaga todas las copias del gateway COMS. TASKVALUE=3104 apaga únicamente COPIA-1, permitiendo mantenimiento selectivo sin interrumpir el servicio completo.
TASKVALUE → Acción 3004 → SMCOMS-DISABLE todas las copias (1-5) P020 deja de aceptar transacciones Cierre de sesiones activas de forma controlada 3104 → SMCOMS-DISABLE COPIA-1 únicamente Copias 2-5 continúan procesando Permite mantenimiento de COPIA-1 sin downtime total
Nota de migración: TASKVALUE es un mecanismo de control MCP no equivalente en arquitecturas cloud. En Kubernetes/ECS, el equivalente es `kubectl delete pod` o deregistrar instancias del load balancer. La semántica de "apagado controlado de una copia específica" se logra con rolling updates o pod draining.
RN-S500-114 — Toggle S151 en caliente: TASKVALUE 3027
OPERATIVO TOGGLE-S151 RIESGO-GL Regulador: CNBV Confianza: Alta
TASKVALUE=3027 actúa como interruptor para desactivar o reactivar S151REGISTRA (libro mayor GL) sin detener el procesamiento de transacciones en P020. Cuando S151 está desactivado, P020 continúa procesando pero sin registrar asientos contables — comportamiento de bypass silencioso que no genera error ni log al canal.
TASKVALUE = 3027 → Toggle S151: Si S151 activo: CANCEL REGISTRAS500 P020 continúa sin GL (bypass silencioso) Si S151 inactivo: reload LIB-S151L002R500 S151 operativo nuevamente Riesgo MR-INT-02: - Transacciones procesadas por P020 sin asiento en S151 GL - Sin error al canal / cliente - Sin log de las transacciones no contabilizadas - Desincronización entre estado S500 y libro mayor S151
⚠ Hallazgo crítico: El bypass silencioso de S151 es el riesgo operativo más alto identificado en P020. En modernización, este mecanismo debe reemplazarse por un circuit-breaker con encolado garantizado (dead letter queue) y alertas. Ninguna transacción debe perderse silenciosamente.
RN-S500-119 — Ciclo EOD: CANCEL 7 librerías, WAIT 5s, reload
EOD BATCH-NOCTURNO LIBRERÍAS Regulador: — Confianza: Alta
Al inicio del proceso de cierre de día (EOD), P020 ejecuta un ciclo de refresco de librerías dinámicas: cancela 7 librerías del sistema, espera 5 segundos y las recarga con versiones actualizadas. COPIA-3 adicionalmente cancela la librería S500L050DYR que las demás copias no tocan.
Ciclo EOD de P020 (todas las copias): 1. CANCEL lib-1 (catálogo CVETRAN) 2. CANCEL lib-2 (parámetros tarjetas) 3. CANCEL lib-3 (tablas IVA/ISR) 4. CANCEL lib-4 (parámetros sucursal) 5. CANCEL lib-5 (librería S151) 6. CANCEL lib-6 (parámetros EPP) 7. CANCEL lib-7 (catálogo productos) WAIT 5s (garantiza liberación de memoria) reload libs 1-7 (versiones EOD actualizadas) COPIA-3 adicionalmente: CANCEL S500L050DYR (solo COPIA-3)
Nota de migración: El ciclo CANCEL/WAIT/reload es un patrón MCP para actualizar librerías en caliente. En arquitectura cloud, este patrón se reemplaza por ConfigMaps/secrets con hot-reload, variables de entorno inyectadas, o feature flags. El WAIT 5s es dependiente de que MCP libere memoria — en cloud no aplica.

Vocabulario

TASKVALUE
Mecanismo MCP · interrupción operador
Mecanismo de interrupción del sistema operativo MCP que permite al operador enviar comandos de control a programas en ejecución. P020 interpreta valores específicos (3004, 3104, 3027, 3016, 3019) para ejecutar acciones operativas sin reiniciar el programa.
SMCOMS-DISABLE
Control P020 · apagado COMS
Acción que desactiva el gateway COMS de P020. TASKVALUE=3004 la ejecuta en todas las copias; TASKVALUE=3104 la ejecuta solo en COPIA-1. Cierre controlado del servicio de procesamiento de transacciones online.
Toggle S151
Control TASKVALUE=3027
Interruptor en caliente para activar/desactivar S151REGISTRA. Sin reiniciar P020 ni interrumpir el flujo de transacciones. Cuando S151 está desactivado, las transacciones se procesan sin asiento contable — riesgo MR-INT-02.
LIB-S151L002R500
Librería MCP · S151
Librería dinámica que contiene los entry points de S151REGISTRA. Al hacer reload de esta librería (TASKVALUE=3027 con S151 inactivo), P020 recupera la capacidad de registrar asientos en el libro mayor GL.
S500L050DYR
Librería MCP · COPIA-3 EOD
Librería dinámica adicional que solo COPIA-3 cancela durante el ciclo EOD. Las otras copias (1, 2, 4, 5) no tocan esta librería. Contiene parámetros específicos de COPIA-3 para el proceso de cierre de día.
EOD
End Of Day · cierre nocturno
Proceso de cierre de día bancario. P020 ejecuta el ciclo CANCEL/WAIT 5s/reload de 7 librerías durante el EOD para actualizar parámetros, catálogos y tablas a sus versiones del nuevo día sin detener el sistema.
Bypass silencioso GL
Riesgo MR-INT-02
Cuando S151 está desactivado (TASKVALUE=3027), P020 continúa procesando transacciones sin generar asientos en el libro mayor. No hay error al canal ni log de las transacciones no contabilizadas. Riesgo de desincronización S500/S151.
REGISTRAS500
Entry point S151REGISTRA
Punto de entrada de la librería S151REGISTRA. CANCEL REGISTRAS500 desactiva el registro GL en caliente. Los parámetros WKS-S151-PARAMS con TIPO-PROC se envían aquí para registrar asientos contables en el libro mayor.
