Cómo alimenta la decisión
Este assessment no refactoriza: produce el insumo estructural. Baja mantenibilidad (24/100) + alto acoplamiento en CAPTACION → candidato a Rewrite; CONTABILIDAD con menor densidad → candidato a Refactor. La deuda cuantificada → días de remediación para el pricing; el mapa de riesgo → prioridad de golden-masters para equivalence testing. Ejecutado por el Specialist · Code Quality Assessment (HVM-wide).
