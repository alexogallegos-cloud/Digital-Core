```

  0  → modo LINEA    (procesamiento en línea, ventanilla activa)
```

| **Regulador** | CNBV |
| **Programa ejecutor** | P010 |

| **Dataset DMSII** | Análisis interno: derivar de Campos COBOL / DASDL |

**Fórmula/pseudocódigo:**
```
CALL Fraud Manager (FM) de forma asíncrona

SI FM responde dentro del timeout:
  Procesar respuesta de scoring
  SI score FM = RECHAZAR → rechazar transacción con código FM
  SI score FM = APROBAR  → continuar flujo normal

SI FM NO responde (timeout):
  Adquirir lock sobre registro B01CONTROL (B01M)
  Registrar WS01M-HORA-RECFM = hora actual de timeout

```

**Vocabulario en la fórmula:** FM · B01M · WS01M-HORA-RECFM · fail-open

**Excepciones:**

- La política fail-open implica riesgo regulatorio: transacciones no evaluadas por FM quedan en zona gris de responsabilidad por fraude.
- El HI taskvalue=1016 también inicializa S500L030 y MAPLI simultáneamente.

**Estado validación:** Verificado en fuente COBOL
